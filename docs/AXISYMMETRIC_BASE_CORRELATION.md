# 轴对称底压与代表底热关联（v53）

`solveAxisymmetricBaseCorrelation.m` 已完成公开公式复算和针对性测试。`solveSharpConeBaseFlow.m` 使用项目内部 Taylor–Maccoll 解提供尖头直圆锥肩部外流，不需要导入 CFD。两者目前是独立区域模块，**尚未接入真实网格的底面识别、压力场或热流场**；本阶段没有新增真实箭体底面已求解面积。

底热输出 `heatFluxRepresentative` 是关联式的代表量。现有资料未重建径向测点或面积平均定义，因此不能将这个标量涂满底面，不能把它计入全面积热流覆盖，也不能据此声称底面三维气动热已经完成。

## 采用的公式与参考量

下标 `inf` 表示自由流，`e` 表示圆锥肩部边界层外缘，`b` 表示底区。`s` 是鼻端到肩部的表面母线长度，`mu_e` 为肩部动力黏度；本实现的所有输入采用 SI 单位。

```text
Re_e,s = rho_e U_e s / mu_e
C_e^4 = [1 + 2 / ((gamma-1) M_e^2)]^(-2)
A = p_b / p_inf
```

圆锥层流底压，Eq.(8b)：

```text
A = 3.05 [M_e^2 / sqrt(Re_e,s)]^0.6 / C_e^4
```

圆柱湍流底压，Eq.(10)：

```text
p_b / p_e = 0.05 + 0.967 / [1 + (gamma-1) M_e^2 / 2]
```

此处 `p_e、M_e` 对应报告的圆柱肩部 `p_1、M_1`。程序以输入肩部状态为参考，不能直接把自由流 Mach 套入任意锥柱的底压计算。

细长圆锥湍流底压，Eq.(11)：

```text
J = 1.7 / ln(21 / theta_c)     （theta_c 的数值单位是度）
A = (p_e/p_inf)^2 [0.025 + 0.906 / (1+(gamma-1) M_e^2/2)]^J
```

圆锥层流代表底 Stanton 数，Eq.(17)：

```text
St_b = 1.0e-4 [A C_e^4]^1.8
```

圆锥湍流代表底 Stanton 数，Eq.(18)：

```text
B = sqrt[A (p_inf/p_e)^2]
St_b = 8.3e-4 B^1.85
```

**平方根作用于整个 `A (p_inf/p_e)^2`**。程序和独立公式测试均按此顺序复算，并与原报告 Eq.(18) 及表 3 的排版核对。

报告第 27 页的总焓差定义用于换算热流：

```text
cp = gamma R / (gamma-1)
H_inf = cp T_inf + U_inf^2/2
h_w = cp T_w
q_b = St_b rho_inf U_inf (H_inf-h_w)
```

正值表示流体向壁面供热，给定壁温高于总焓参考温度时允许负值；总焓差为零时允许物理零热流。`heatRecoveryReferenceTemperature=H_inf/cp` 是定比热模型的能量参考温度，**不是底区静温、外缘温度或已求解壁温**。

标准表面压力系数使用 `Cp_b=(p_b-p_inf)/(rho_inf U_inf^2/2)`。报告中底阻系数的相反符号定义不与该场量混用。

## 本实现的适用门限和仍需证明的前提

模块只接受零攻角、零侧滑、独立轴对称物体、平圆底面，无尾撑、无底部喷流，且鼻端钝度 `r_n/r_b <= 0.3`。当前采用 `gamma=1.4`、`R≈287.05287 J/(kg K)` 的定比热空气模型，并检查自由流、肩部理想气体关系和共同总焓的一致性。它不能代替真实气体、化学非平衡或稀薄流求解。

| 分支 | 当前程序门限 | 已有来源与限制 |
| --- | --- | --- |
| 圆锥层流底压和代表底热 | 半锥角 9–10°；自由流 Mach 2–20；肩部 Mach > 1；`Re_e,s >= 10^5` | 比原底压公式的几何范围更窄，以当前底热证据为界；不修改低 Re 指数补值 |
| 圆锥湍流底压和代表底热 | 半锥角 6–12°；自由流 Mach 2–20；肩部 Mach > 1 | 9° 钝锥为主要实证，其他允许角度属于报告建议的工程估算；未采用更大角度的临时底热外推 |
| 圆柱湍流底压 | 肩部 Mach 1.2–15 | 只计算底压；没有建立对应圆柱底热关联 |
| 圆柱层流 | 拒绝 | 本模块未建立闭合，不套用圆锥公式 |

Mach、钝度及温度的代码门限用于防止明显外推，**不是一个已由实验逐点验证的矩形有效域**。80–2500 K 只是本实现的温度筛选；给定 `gamma=1.4` 也不代表真实空气在整个温度区间都具有恒定比热。更高焓工况需要独立热物性与关联适用性论证。

连续流筛选使用自由流、肩部及 `T_b≈T_0` 底回流筛选近似的最大平均自由程除以底半径，要求 `Kn < 0.01`；配置 `maxContinuumKnudsen` 只能进一步收紧。`T_b≈T_0` 仅服务这个筛选，程序不将它输出为底区静温解。筛选通过不能证明整个尾迹的局部 Kn 或非平衡状态均满足无滑移条件。

肩部层流/湍流类别是调用者的输入，必须由前体边界层/转捩计算或有依据的算例声明提供。原报告排除了厚湍流边界层，而当前接口没有计算或审核肩部动量厚度比；因此调用前还需证明其符合薄湍流边界层前提。不能把输入类别或未经审核的厚度状态当成区域求解结果。

`solveSharpConeBaseFlow` 只对明确声明的尖头直圆锥内部计算肩部，使用 `s=r_b/sin(theta_c)`。它不能替代球鼻锥体、锥柱组合、尾锥或有攻角模型的真实肩部状态。一般底关联要求肩部各输入同时提供 `sources.*`，可接收后续内部前体求解器的有来源结果。

## 输出身份与接口

```matlab
% 独立底关联：肩部状态必须已经求得，并附逐字段来源
r = solveAxisymmetricBaseCorrelation(fs,shoulder,geometry,Twall,cfg);

% 尖头直圆锥封装：内部计算肩部，随后调用同一底关联
r = solveSharpConeBaseFlow(fs,geometry,Twall,cfg);
```

`geometry` 声明几何族、底半径、半锥角（圆锥）、钝度、边界层类别、尾撑/喷流状态、平圆底及独立轴对称身份，并保留 `source`。`Twall` 是给定边界条件。每个输出通过 `fieldMetadata` 分别记录输入、计算或未解身份和来源。

- `basePressure`、`baseStantonNumber`、`heatFluxRepresentative` 仅在对应门限通过时提供；壁温缺失时可保留已算底压和 Stanton 数，热流仍为 NaN。
- 圆柱湍流分支可有 `pressureAvailable=true`，但 `available=false`，因为该汇总标志表示底压和代表底热同时可用。调用者应读取逐场量标志。
- `baseEdgeTemperature`、`baseVelocity`、`solvedWallTemperature` 保持 NaN；模块未求解这些量。
- `geometryVerified=false`、`pressureRequiresMeshAssociation=true`、`eligibleForSurfaceCoverage=false`、`radialHeatingDistributionSolved=false` 明确当前没有真实面元关联和完整底面热分布。

关联代表底压有近似均匀的物理依据，但当前仍未识别真实底面、核对肩部状态或完成面积映射。在这些检查完成前，不能把标量底压当成整模型已接入的压力场。
