# 当前工况科研导出

新增 `web/export.js` 与工作台“全表面 CSV”按钮。CSV 导出当前物理量的所有面元，保留从 1 开始的真实面元/顶点编号、三角形坐标、重心、面积、区域、场量与单位、原始精度数值、状态、算法编号/文字、逐面元适用范围、时刻、工况及当前色标。编号与 MATLAB 网格一致；算法编号仍按 JSON 的从 0 开始约定。

状态优先于占位数：未解面元输出空数值，工程计算和给定条件分别标识，给定值不进入计算面积。源状态有效但没有有限数值时，导出为未解并记录矛盾。源热流缺失原因只写入热流字段，不作为压力或其他温度的缺失原因。时间字段只在显示场量具有实际离散时间站时填写；静态场量保持单点工况标识。

“保存图像”保留当前视角和真实比例，另设自动换行的标题、坐标约定、色标及五个刻度、当前工况、面积状态统计。图内明确当前 CSV 文件名；所选面元还保留状态、实际数值、算法与适用范围。小视口至少使用 720 像素逻辑宽度排版，图注长度决定图像高度，不使用固定 110 像素页脚或固定色标高度。未解状态即使残留有限占位数也显示“未求解”，不附数值单位。

PNG 与来源 CSV 使用同一个显示快照。保存 PNG 时同步准备同名来源 CSV 的持久下载链接，点击“下载来源 CSV”保存；不一次自动触发两个下载，兼容内嵌浏览器。单独“全表面 CSV”按钮直接触发下载并保留可再次点击的链接。颜色范围和导出时间记录在 CSV 中，不改变计算数据。

## 验证边界

`tests/testWebExport.js` 使用独立 CSV 解码器逐项验证中文、逗号、引号与换行；校核零值、缺失占位数、给定条件、状态矛盾、逐面元范围及实际时刻。小画布和长工况/范围通过独立字体度量桩检查全部文字不越界、完整保留，以及模型宽高比不变。

运行方式：

```text
node tests/testWebExport.js outputs/v51_validation/actual_rocket/results.json
```

实际数据校核覆盖 19,752 面元的表面压力、热流、输入壁温、未解壁温与恢复温度；逐面元比较原始数值、状态、算法、范围、几何/编号和面积。真实浏览器的下载落盘、PNG 字体渲染和 MATLAB uihtml 握手另行测试，不能由纯 Node 测试代替。

该模块改善结果可核对与交付能力，没有新增物理求解覆盖；全区域气动热求解仍按项目目标推进。

2026-10-13 的实际浏览器复核：887×871 视口检查热流 PNG 和带面元 #8901 来源的未解壁温 PNG，实际中文字体、五级色标、工况和完整图注无截断；未解壁温不带数值。标题/按钮改用正常文档流，下载链接出现或换行后不再遮挡色标。两张浏览器生成图片及工作台截图保存在本地 `outputs/v53_validation/`，交付包包含相应验证证据。

本机内置浏览器的下载工具未返回 PNG 落盘回执，不能声称浏览器下载已通过。上述 PNG 是直接读取页面实际生成的 data URL 保存并目视核对；来源 CSV 已生成持久链接，其独立解码验证由 Node 完成。MATLAB 真实 uihtml 另行通过 19,752 面元非零像素绘制、WebGL 错误码 0 和压力更新握手测试。
