## 当前模块实际做什么

`nonsimilarLaminarResidual.m`实现NASA TP-3271式1–4层流极限的物理弧长s、壁法向n薄层方程。保留沿程质量、速度和总焓的变化：

- 连续：`d_s(r*rho*u) + d_n(r*rho*v) = 0`，从壁面无吹吸条件积分求v；不额外指定外缘v=0。
- 动量：`rho*u*u_s + rho*v*u_n + p_s - d_n(mu*u_n) = 0`。
- 总焓：`rho*u*H_s + rho*v*H_n - d_n(k*T_n + mu*u*u_n) = 0`，`H=h(T)+u^2/2`。

球鼻使用`r=Rn*sin(s/Rn)`；忽略薄层阶的法向曲率修正。该假设需要独立检查层厚/鼻半径，不能推广到当前20°箭体横流、分离或底部回流。

`advanceNonsimilarLaminarStation.m`用真实上游剖面进行隐式Newton/线搜索，联合解当前站u/T。一份历史用BDF1，两份用不等步长BDF2；当前没有任意步比稳定性证明。给定边界为壁u=0/T=Tw及外缘u=Ue/T=Te。失败保留NaN热流，不拿初猜代替终解。给定壁温与未求壁温分开；整段均匀Tw或完整Tw(s)历史必须保留，不能只按当前Tw合并路径。

NASA7计算保留原焓零点，`k=mu*cp/Pr`；不裁温、速度或热流。入口必须有同一物理n网格上的u/T剖面，不能用Thwaites厚度标量或相同eta编号冒充。已有质量坐标剖面可按`n=K*integral(T/Te)deta`恢复物理坐标，完整数值域与有限物理边缘分别处理。
