# v262 静止空气节点探针

主工作台的「输入模型」和已可用的「查看结果」里增加了「静止空气 · 节点探针」。点击后在中央区查看归档，切换回原步骤即可继续当前工况。也可以直接打开[离线节点页](validation/v262/evidence/workbench/index.html)。该文件包含页面、脚本和两组原始记录。

## 可核对的读数

用 Z 截面切换位置，点击网格中的节点编号，或直接输入原编号。节点编号从 0 开始。切换配置和源帧后仍选中同一节点。默认配置的反算方法是 TOMS748，另一份记录为 STABLE_PIECEWISE。初帧和结束前帧均来自静止空气初始化，物理时间步为零。

| 位置 | 流体节点温度 | 给定壁温 | 壁面热流与求解固体壁温 |
|---|---|---|---|
| 0 号，立方体角点 | 300.123 K，原始帧回读 | 300.123 K，三个相交壁面在配置中给定相同值 | 未知 |
| 62 号，立方体中心 | 300.123 K，原始帧回读 | 不适用 | 不适用 |

「导出所选节点 CSV」写出五项物理量，每行带原编号、坐标、单位、身份、方法、源帧和文件 SHA256。未求解或不适用的数值格为空。温度反算方法从实际记录读取。旧格式缺方法时显示「未记录」，节点方法与工作对象记录冲突时读取器拒绝该数据。[边界节点 CSV](validation/v262/evidence/workbench/static-air-default-initial-node-0.csv) · [内部节点 CSV](validation/v262/evidence/workbench/static-air-stable-terminal-node-62.csv)

## 验证范围

- 在本机 MATLAB 从主窗口「输入模型」的实际按钮进入，完成 5 次节点选择确认并返回，输入版本、工作流状态与求解任务均已核对。「查看结果」的同名入口使用同一回调，本轮实测从「输入模型」进入。[主窗口回执](validation/v262/evidence/workbench/report.json)
- 对两种配置、每种两帧、每帧 125 个节点独立核对，共 500 次节点选择、2500 行导出量。主窗口的五份 CSV 与独立页面生成内容逐字节一致，读入时还用固定清单核验了原始配置和帧。[逐节点审核](validation/v262/evidence/node01/debugger.log)
- 隐藏 HTML 组件内测试了截面选择、节点按钮、配置和源帧切换，读取实际表格，并核对下载字节。首次测试在点击下载后使用 fetch 读取本地 Blob URL 失败，原始回执已保存。更正后按下载地址核对交给原生 API 的同一个 Blob。稳定配置结束前帧的 62 号节点下载共 1983 字节，与主窗口 CSV 完全一致。系统保存对话框和独立浏览器中的实际保存操作未测试。[首次记录](validation/v262/evidence/controls01/debugger_process.json) · [控件与下载回执](validation/v262/evidence/controls02/report.json)
- 主窗口验收 44.391 秒，独立逐节点核对 0.218 秒，控件补验两次分别 18.563 秒和 18.375 秒。最高采样进程组内存约 1.31 GiB。四项任务均有终态记录，原始输入稳定，进程组为空。开发、资料读取与归档另计。本轮执行输出共 269063 字节，含留存的首次失败。[资源与资格汇总](validation/v262/evidence/summary.json)
