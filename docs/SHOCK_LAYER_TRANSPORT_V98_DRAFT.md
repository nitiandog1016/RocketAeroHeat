## 模块与方法

- `parabolicShockSample.m`、`ellipticConicShockSample.m`：同一共同曲面的三维一/二阶几何，正定K控制横向形状；二次曲线的参数B控制纵向形状。
- `solveParabolicShockLayerColumn.m`、`solveEllipticConicShockLayerColumn.m`：上游投影质量、同流线激波熵、显式薄层压力/法向速度、同cp热力恢复，以及保留非正交Jacobian的法向距离反算。
- 三个`fit*ShockToBody.m`研究入口分别比较4/5/7个全局几何参数，共用原面元射线交点和相同残差/门槛；没有为每个面元单配激波角或压力。阶段原型分别保留，便于核对模型表达带来的差异。

这些是工程薄激波层原型；没有完整求解Euler方程、驻点极限、跨声速整体匹配、下游波系、分离/再附或底面。数值守恒/积分通过不能替代其适用域和实验精度验证。

`exportShockLayerStudy.m`与独立科研视图已实际导出、核对及浏览器验收：同栏五步骤、整箭/鼻部、四组47法向列/112保存站点、逐变量算法、三维拾取、滑块和CSV。视图展示已保存研究，法向列不称为表面流线，层内温度不称为Te/Tr/Tw，候选生成体表端点不称为真实壁面。原生产工作台不修改。三个视图修订的数值JSON逐字节相同，实际下载的13行CSV与冻结MAT逐值完全相等；浏览器留有一条既有同签名MutationObserver诊断，未宣称控制台干净或完全归因。完整记录在验证索引。

## 共同几何及质量坐标

内部迎风坐标的第一基向量沿实际来流，原模型全局X轴、鼻尖+X和零攻角来流−X保持。设横向坐标q为米、对称正定K为1/m：

```text
s = q' K q / 2
F + B F^2/2 = s
r_shock(q) = origin + e_flow F(s) + E_transverse q
```

B的单位为1/m。B=0逐值退化为原抛物分支；非零B用稳定二次根。根失去单值性、法向Mach不满足压缩支、物性失效或法线坐标聚焦时拒绝，不裁剪几何/温度，不切换气体。

以下质量关系是对这类共同几何的解析推导，而非直接抄写原报告的经验系数。均匀上游在横向投影中的质量向量为`(rho_inf U_inf/tr(K))*Kq`，其散度严格等于`rho_inf U_inf`。沿同一激波线回溯：

```text
m = psi_s / h_beta = rho_inf U_inf |Kq| / tr(K)
q_entry = exp(K log(eta)/tr(K)) q
```

eta=1为当前激波，eta=0为生成体表；eta趋零时取同一曲面驻点的法向激波熵极限。这里的熵极限不等于已经完成整个驻点区流场/脱体距离求解；q=0的有限列明确拒绝。

每个eta的熵来自`q_entry`处同一共同激波的守恒跃迁，而非把当前列局部激波熵冻结贯穿整层。不同列中同一物理流线的eta可以不同，回溯到的入口点和熵相同；总焓来自同一均匀上游，不重置总压。

## 压力、速度与SI约定

采用[NASA TP-3018](https://ntrs.nasa.gov/citations/19900017750)式(17)、(18)的薄层近似，并显式还原SI量纲。κt/κb为流向/横向法曲率，us/vs为激波紧后切向/法向速度：

```text
P1 = us*m*κt
P2 = vs*m*tan(Gamma)*(κt+κb)/2
p(eta) = ps + P1*(eta-1) - P2*(eta^2-1)
v(eta) = vs*[1 + m*(κt+κb)/(rho_inf*U_inf*cos(Gamma))*(eta-1)]
```

P1/P2为Pa；速度式中`rho_inf*U_inf`不能从无量纲原式中漏掉。T由同一入口熵与当前p求根，rho由EOS求得，切向速度由总焓扣除静焓与法向动能恢复。低于80K/高于2500K、非正压力或负的切向速度平方都拒绝，不补零。

压力及法向速度式属于工程近似，不是全体动量方程已精确满足的证明。NASA7分支沿用已验的连续cp积分约定；原生产`airThermalProperties.m`不改。

## 非正交度量与厚度

流向/横向曲率矩阵S包括交叉曲率。距离n朝激波内侧时，法线坐标的切向变换为`I-n*S`；实现保留它的完整行列式和非正交项。质量距离与几何距离满足：

```text
integral_0^n det(I-z*S)/sqrt((1-z*κt)^2+(z*κtb)^2) dz
    = m * integral_eta^1 1/(rho*u) d_eta
```

本实现定义正向质量以及内法线距离，因此`dn/deta`为负。对照原报告印刷式(10)时必须注意取向：实现用Cartesian连续式及正向投影质量推导、验证该符号，不用绝对值修补距离。法线Jacobian翻向或过第一聚焦点时停止。

两阶Gauss积分差值单列为分辨率指标，不作为严格误差界；独立程序另用QUADPACK积分和Brent距离根，不复用保存的Gauss质量积或曲率矩阵。
