# v176 原面区域结果、验证资格与科研工作台

本版把工程结果和内嵌SU2研究结果接入同一套逐变量区域查看与导出功能。直接使用已有原19,752面，没有新增CFD、改变物理数值或增加通过物理验证的面积。完整气动热目标仍未完成。

## 使用方式

MATLAB运行`main`进入既有五步骤工作台。在工程结果或内嵌研究结果的“区域结果与验证”页选择压力、热流或不同身份的温度；点击区域表查看原面描边，点击模型查询面元并更新该X位置的周向曲线。固定色标按变量保留，区域选择不截掉其他面元、不改变色标或物理值。

“当前变量证据CSV”导出该变量的全部原面，含原编号、区域、面积、值、单位、计算身份、验证资格、算法、适用范围及拒绝原因。旁车JSON记录来源、CSV的SHA和各变量面积汇总。选择一个区域后，CSV仍导出全模型。截面导出保留真实三角面与X平面的交线、原面来源和未知断点。

## 实现与证据约束

- `buildAerothermalEvidenceLedger.m`建立原面几何、工况、来源及逐变量内容绑定。值身份互斥，验证资格单独统计，p/q共同资格取同面交集；不会把验证面积再加进总面积。
- `buildSU2EvidenceViewerData.m`只读适配现有研究结果；完整来源、检查点和热审核合同齐备才保留SI声明，缺项不凭接口名授资格。仅明确的标量给定壁温可展开，其他物理场必须有逐面数据。
- `createAerothermalEvidenceView.m`与离线`web/evidence.*`复用WebGL和真实截面核心。每次更新重建证据绑定，清除旧选中面及回执，拒绝旧版本消息。
- 工程页和研究页各使用相同区域组件；研究几何标签只有在原V/F相同的情况下复用，几何标签不转移工程流动物理资格。

证据记录采用`RAH.AerothermalEvidenceRecord.v1`，证据文件采用`RAH.AerothermalQualificationProof.v1`。记录与文件SHA、几何/工况/来源/变量内容/原面集一致才继续审核。变量内容绑定包含值、旧状态、方法、范围及来源身份，因此同值换方法或状态也使旧证据失效。

证据必须保存参考来源、适用条件、比较量及数值准则；条件匹配、变量参考比较、数值精度、模型区域适用性均需明确。热流还要求热边界/物性与近壁分辨率。单个`passed`字段、有限值、exit0或其他变量通过均不够。相同证据去重，同ID冲突拒绝，明确失败不被通过记录覆盖。合成证据只用于明确标记的合成数据。

这些检查验证证据的绑定与完整性，不自动证明参考文件的科学真实性；真实资格仍需匹配来源和适用域的审查。本版没有为真实箭体注册新物理通过证据。

## 验证范围与保留限制

不等面积真值总面积63，合成p通过面积7、q通过面积3、交集3；18个拒绝案例覆盖错来源、工况、变量、面序、冲突、给定/未知误升级等。最初主界面测试在行/列数组比较处失败；准确失败保存，随后只修正测试的方向假设并保存实际绘制状态，没有放宽数值端点或物理门槛。

工程与研究原面组件在一个真实MATLAB宿主内完成集成，原值、范围、探针、92段截面、未知/给定温度和旧帧拒绝通过。Python从原面MAT独立核对几何面积、字段、统计及5份各19,752行CSV，2,147,005项检查通过，输入保持不变。没有重新运行旧五步数值链或大体场热审核。
