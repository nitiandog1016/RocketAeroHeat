# 球鼻局部相似层流热边界

`solveSphericalNoseLaminarHeating.m` 是给定单时刻壁温下的**区域工程近似**。它沿已核验的球鼻弧线建立压力、外缘和局部相似剖面，直接由壁面焓导数求热流；不使用驻点热流乘余弦。它不代表全箭体气动热计算已经完成，也未通过公开实验热流验证。

## 来源与模型

- [NASA SP-8062, *Entry Gasdynamic Heating* (1971)](https://ntrs.nasa.gov/api/citations/19710021703/downloads/19710021703.pdf)，§2.3.2（PDF第16页）讨论局部相似近似，明确其适用于中等压力梯度，在接近分离的逆压梯度或强顺压梯度下价值下降；§4.2.1（PDF第36页）说明钝鼻外缘可按驻点熵与局部静压恢复，细长后体需要进一步的熵分布分析。2026-10-13重新核对原文，报告、提取文本和这两页原图保存在 `outputs/v53_validation/sphere_source/`。
- [NASA TP-3271 (1992)](https://ntrs.nasa.gov/api/citations/19930006245/downloads/19930006245.pdf)，*Finite-Difference Solution for Laminar or Turbulent Boundary Layer Flow Over Axisymmetric Bodies With Ideal Gas, CF4, or Equilibrium Air Chemistry*：式6给出流向变换，式18–25给出边界层方程，式56给出热流。**本程序只解去掉沿程非相似项的局部层流 BVP，不是该报告的完整非相似推进程序，也不继承其实验精度。**

几何与外缘重用 `solveSphericalNoseEdge.m` 的真实球面检查及同一物性正激波总状态。球半径为 \(R_n\)，迎流极角为 \(\phi\)：

\[
s=R_n\phi,\qquad h=R_n\sin\phi,\qquad
p_e=p_\infty+(p_{02}-p_\infty)\cos^2\phi.
\]

外缘按同一驻点熵和总焓恢复，积分

\[
\xi=\int_0^s\rho_e\mu_e U_e h^2\,ds,
\quad U_{e,s}=-\frac{p_{e,s}}{\rho_e U_e},
\quad \beta=\frac{2\xi U_{e,s}}{\rho_e\mu_eU_e^2h^2}.
\]

驻点使用解析极限，而非任意小的启动位置：

\[
a=\sqrt{\frac{2(p_{02}-p_\infty)}{\rho_s R_n^2}},
\qquad p_{e,ss}=-\rho_s a^2,\qquad\beta=\tfrac12.
\]

每个角度站调用 `solveAxisymmetricLaminarMassProfile.m`，由同一速度/总焓剖面得到热流、剪应力和物理质量厚度。恢复温度是该 BVP 的 \(q(T_w)=0\) 根；换热系数是 \(q/(T_{aw}-T_w)\) 割线，绝热附近采用显式 1 K 温差的边界导数。给定壁温、恢复温度和任何后续求解壁温分别保存。NASA7 焓零点移位仅用于数值变量，不改变物理热流与温度。

## 本阶段范围

只接受实际来流沿 **−X 的零合成攻角**；轴线为 X，鼻尖 +X，采用 SI 单位。独立球鼻外缘模块允许的斜来流几何范围，不能作为轴对称热边界的适用依据。本阶段未找到足够依据来把该轴对称热边界应用到有攻角箭体，故热模块明确拒绝非零攻角。

球鼻必须通过重新生成的当前网格、多尺度球面拟合、完整前缀、特征面及拓扑检查。默认外缘极角上限 60°，本项目允许配置到 80°；这是研究筛选范围，**不能据此认为该角度内热边界必有有效解或已验证准确**。剖面自身仍须满足所有附着支、单调性、有限外缘、动量兼容和原物性域检查。

当前显式筛选是来流平均自由程/鼻半径 \(Kn_\infty<0.01\)、给定壁温 80–2500 K、局部 \(Re_s<\mathrm{transitionRe}\)（默认 \(5\times10^5\)）及给定壁温剖面的 \(\delta/R_n\le0.05\)。这些是项目接受准则，不是文献给出的普适精度界限。NASA7 越域不静默回退定比热。该模块不解转捩、横流、熵层吞入、横向涡量、鼻部到后体接口或非相似沿程推进。

默认每 2° 建一个局部 BVP 角度节点；可选 0.25–5°。**本轮实际收敛对照是5°/2.5°，整链路使用5°；默认2°没有在本轮重新做性能与收敛检查，其耗时不能沿用5°结果。**只在**同一给定壁温、两个相邻有效节点**之间线性插值，保留两个节点编号和权重，不跨越未解节点。最多支持 16 个不同给定壁温；大量独立壁温不以未经验证的粗壁温插值替代。单时刻近似不能直接用于壁体热响应或飞行热历史，返回 `historyCompatible=false`。

## 绝热根的数值诊断

原草稿直接要求冷端 \(T_e\) 和热端 \(T_0\) 两个壁温剖面都有效。M4、20 km、球半径 0.1 m 的 NASA7 40° 站，\(T_w=T_0\) 试探被剖面内核的附着单调支检查拒绝，但 860 K、870 K 剖面均有效，热流分别约 +744 和 −1925 W/m²，表明较低壁温内有有效绝热根。

修正只改变根括区：高温端被拒绝时，在 \([T_e,T_0]\) 内逐步寻找**两个有效、异号**的剖面，再求根并复查热流残差。拒绝试探的温度、状态、原热流保存在 `adiabaticBracketTrials`；不放宽 BVP 门限，不使用无解热流，也不跨拒绝节点插值。

同一算例 44° 及以上依然不能在当前受约束剖面支上找到有效异号括区。例如 44° 最后有效热壁试探仍有约 +1433 W/m²，继续提高壁温则被剖面内核拒绝。这表示**本模型和现有受约束支未取得完整热边界**，不是已证明真实流场不存在绝热温度。此类节点和涉及它们的面元保持未解；未把冷壁热流单独取出算作完整已解面元，也未用旧余弦方法补齐。

## 验证证据

正式校核程序是 `tests/testSphericalNoseLaminarHeating.m`，输出至 `outputs/v53_validation`：

- 独立定比热法向激波/驻点状态、球面压力和等熵外缘公式；均匀弧线独立积分 \(\xi\)，驻点压力曲率和外缘动量梯度。
- 物理壁坐标下的焓导数独立重建热流；绝热根热流残差与有限外缘检查。
- 5°/2.5° 角度表收敛、逐面元节点/权重追溯、冷壁加热与高于当地恢复温度的暖壁冷却。
- 非零合成攻角、非球几何、未知/域外壁温、Kn、Re、过厚边界层及未解析有限外缘的明确拒绝；缺失值保持 NaN。

2026-10-13 **正式测试最终退出码0**，终态日志为 `outputs/v53_validation/sphere_laminar_final2.log`：978 面的半球头柱体，95 个球鼻外缘合格面元中 57 个得到完整区域热边界；5°角度表有12站、154次剖面调用，约80 s。另有4°完整烟测（15站、197次调用，约102 s），同样为57个有效面元；修正前草稿为40个。正式摘要保存为 `sphere_laminar_summary.json`，可复用的 `sphere_laminar_case.mat` 包含 `mesh/cfg/fs/meta/result`，完整对照数据在 `sphere_laminar_results.mat`。之前失败试跑是测试工况/断言诊断，保留记录，不能视为最终通过。

计数分母必须分开：此几何有186个通过球面几何检查的面元；默认60°及热力/流向筛选后，外缘合格为95个，最终完整热边界为57个。主链路测试所报57/186是相对几何球鼻面元的计数，独立热边界所报57/95是相对外缘合格面元的计数，均不是面积覆盖率，也不等于978面全模型的全面积热边界。

已检查的独立 \(\xi\) 最大相对差约 \(2.48\times10^{-9}\)，动量梯度差约 \(9.76\times10^{-16}\)；5°/2.5° 的热流最大相对差约 0.0538%，恢复温度最大差约 0.037 K。它们是此经典工况的解析/数值一致性校核，**不是实验误差、全几何准确度或全面积求解证明**。主链路和 GUI 验证由 `tests/testSphericalNoseWorkbench.m` 单独记录。

## 使用

2026-10-14 v54更新：经原页和独立直接绝热BVP核对，暖壁的内部速度小幅过冲允许存在，删除了错误的全域单调/速度上限判据（见[暖壁附着支说明](WARM_WALL_ATTACHED_BRANCH.md)）。原几何、零攻角、物性、Re/Kn、有限外缘与薄层门限均保留。同一978面算例、相同95个外缘合格面现全部得到热边界，较v53新增38面、0.012871116760 m²。该区域模块计算面积占全模型5.2008643%→8.948307864%；这不是全模型总热流覆盖率，更不是整个球鼻186面都已解。

默认2°与1°细表均完成实际测试，最终MATLAB任务退出码0。2°有29站/257次BVP、137.689 s；1°有56站/501次BVP、282.749 s。全有效区域热流最大相对差0.0182323%，恢复温度差0.0113827 K；45°以上分别为0.00381989%和0.00834084 K。性能只适用于本机此次运行和该算例，非全几何性能承诺。首次1°任务被中断，默认表已保存；最终任务严格核对缓存工况/几何/配置后复用2°表并实际完成1°，日志为 `outputs/v54_validation/sphere_default2_convergence_final.log`，结果为 `sphere_laminar_angle_convergence.json`。中断日志不是通过证据。

真实GUI方法回调在同一窗口完成95/186几何球鼻面计算，并明确断言45°以上有效面全部计算；旧后体、压力和历史保护保持相应回归。日志为 `outputs/v54_validation/spherical_workbench_high_angle.log`，任务退出码0。界面例子采用5°表，默认2°完整独立结果另存MAT文件，不混淆两者。

```matlab
cfg.heating.noseModel = 'sphericalLocalSimilarity';
cfg.heating.sphericalNoseAngleStepDeg = 2;
cfg.flight.alpha = 0;
cfg.flight.beta = 0;
```

默认生产选项仍是既有 `cosineExtension`。选择局部相似法后，核验球鼻中的未解面元不会沿用旧鼻部或侧壁热流充当有效覆盖；球鼻外缘与热边界分别标明来源和状态，后体与区域接口不由该区域法改写。未通过的面元可以在工作台点选查看真实原因。
