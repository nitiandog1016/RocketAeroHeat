# 三维静止壁速度切向约束（v83已测数值模块，未交付）

此模块服务真实20°箭体收缩—后体近壁计算，保留X主轴、鼻尖+X、SI、原网格及完整三维动量。v82已冻结交付；本页描述之后的显式新选项，不把有限研究场计入正式合格覆盖。

## 问题与方法

旧墙梯度仅修正`G*delta=Uw-Uc`。在斜体质心位移下，该条件没有同时约束常数静止壁的两个已知切向导数。真实冷点CV14281的dn约9.763μm、切向偏移37.086μm；旧切向速度梯度范数约4.84e7/s，旧墙机械内能温度率约−5.34e10K/s。

对明确给定的常数静止Uw=[0,0,0]，逐笛卡尔速度分量的壁面切向导数为零。设流体外法向n指向墙，`delta=xwall-xcell`、`dn=delta·n>0`，显式采用：

`G=(Uw-Uc)⊗n/dn`。

Newton应力为`mu*(G+G'−2/3*tr(G)*I)`。静止壁牵引满足

`tau*n=−mu/dn*(Uc+(Uc·n)*n/3)`，

所以邻壁速度代理的机械内能转换`−Uc·(tau*n)`非负。该诊断不是壁面外功；静止壁外功仍为零。速度仍由保守均值恢复后用作体质心点代理，不声称精确FV速度均值、二阶近壁精度或一般熵稳定性。

算法沿用已有`axisymmetricWallVelocityGradient.m`的静止壁已知切向导数处理，并扩展到三个速度分量/两个切向方向；真实墙距处理与三维温度梯度模块一致，没有采用裁速度、改壁温或删除尖角面元。

## 接口和作用域

显式设置`boundary.solidWall.velocityGradient='dirichlet-tangent'`。缺省或`'legacy'`保持原完整rate/info。当前只支持常数静止墙；非零/函数墙速、额外速度表面导数、全局错放字段和开放面边界选用新策略均明确拒绝。

新增完整文件为`cutCellWallVelocityPolicy.m`、`cutCellWallVelocityGradient.m`；原空间内核只在solidWall的Newton应力处选用新梯度，批量保存新旧梯度及真实几何。原WLS、内部对流/黏性/算术功、墙压、墙温梯度、Fourier、外部边界以及单元Q保持；同Q仅墙动量通量和相关动量残差改变。各变量和墙梯度审计保留算法/给定量来源。
