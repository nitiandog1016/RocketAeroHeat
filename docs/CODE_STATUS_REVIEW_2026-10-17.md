v61最新保存证据已经超出最早0.1°短段：40°→60°五组对照均实际结束。60°处N61/N91/N121热流约80.016/80.311/80.397kW/m²，N91→121相差约0.108%；流向0.5→0.25°相差约0.000213%。同内层网格截短外缘缓冲影响很小，但仅对该次缓冲范围成立。2°/4°/8°入口在同一91点物理n网格推进到60°的三组也已结束，最大末站q差约0.000281%。这支持所检查的有限角入口近似，不能当作精确驻点启动或20°箭体求解。

无源相似极限新增细化中，N241/32步q误差约−0.01361%、剪应力−0.01014%；同32步下法向加密使积分能量账/壁热功率缺陷由约−0.307%降到−0.0183%。点式方程没有精确离散乘积法则，因此小Newton残差并不等于严格能量守恒，时间与空间误差也可能抵消。v60的0.357%制造场结果和这些v61数值误差均不是实际气动热/实验误差。

**当前瓶颈按实际影响排序。**

1. 物理模型及区域接口：大攻角收缩/后体的外流与边界层入口尚不一致，是最大面积缺口。需要守住总焓、熵、质量/位移厚度和流管度量等合同；单纯拼接局部p/T不能完成衔接。
2. 分离/再附与底热：目前能识别疑似分离并阻断；底压关联与代表底热不能给完整径向/周向分布。底压不能确定回流温度、速度、壁面梯度及再附热峰。需要匹配真实前体/边界条件的分布模型，或受控的内部黏性区域解。
3. 数值库到实际空气算例：控制体、通量和精度基础已有，但真实边界、近壁分辨率、变物性/湍流、稳态及网格/外域敏感性未闭合。继续增加制造场小数位不能替代这些工作。
4. 验证层级：解析校核、关联式复算、制造解较多，实际独立实验误差闭环不足。NASA球锥资料已有原文/转录，但工况、壁温和测点平均需正确重建。公开激波表核对不等于热流实验验证。
5. 集成与维护：生产、独立实验库、outputs草稿成熟度不同；历史专题和主侧栏尚未完全统一。需要区域方法注册、标准输入输出和清晰回归门槛，并将程序依赖、验证数据与开发历史整理成容易使用的交付。
6. 最终目标的流态/Mach跨度：Kn筛选已经存在，但没有滑移温跳、过渡流或自由分子求解；主工程链还要求M>1，连续流也未覆盖亚声速/跨声速。固定组分80–2500K不能无条件覆盖高焓再入。

**后续技术路线应采用区域分级的混合工程架构。** 保留MATLAB计算后端及现有离线WebGL工作台，保留表面网格算法；按区域和工况选有来源的模型，输出统一数值、身份、方法、范围、未解原因和数值/物理收敛状态。附着区优先使用代价较低的激波/膨胀及积分/非相似边界层；复杂横流、强收缩、分离和回流区采用经过验证的专用工程闭合，必要时调用程序内部局部黏性求解。Euler/NS是适用区域的求解层，不成为所有UI或简单工程方法的前置条件，也不要求用户导入外部CFD。

推荐实施顺序为：先将v61收口成可复用、条件明确的区域模块；随后把主要计算资源转向当前5483面的大面积外流/入口缺口；并行补底面与分离再附分布及公开验证；每恢复一个区域即接回真实三角面和统一工作台，以面积、数值、来源、热功率/接口检查验收。达到明确目标几何/工况的单时刻全表面里程碑后，再复用已有时间与材料能力。其后扩展滑移/温跳、自由分子极限和有验证依据的过渡流方案，并补齐所需亚声速/跨声速及越出当前热物性域的情况，最终形成跨流态飞行热环境。

当前最需要的是把已有数值基础转化为有边界条件、有适用范围、有验证记录的区域求解能力，并接入统一工作台。不能把文件增多、测试增多、绘制完整或覆盖审计本身当作目标已经完成。
