# v99 一般共同激波的投影质量与入口熵映射

本轮已实现并测试一般凸共同曲面的投影质量连续式、同流线入口映射及层内反算接口。它消除了v98只能使用`F(q'Kq/2)`曲面族的入口限制，但**没有完成真实体形、驻点整体或热流求解，新增正式合格面积仍为0**。

真实45列采用同一固定全局形变，不作新拟合。原9个位置与36个独立位置的最大体形偏差分别170.222、187.519微米，未通过原10微米门槛，也未改善v98端点。独立审核确认数值实现，不赋予该几何或近似新的物理资格。

同时发现更重要的下一步约束：当前显式一阶压力式在轴线的解析延拓不能同时满足精确总焓与零切向速度。在本M5输入下，定比热/NASA7端点分别留下60.608/55.407m/s余速。因此下一步应先补充法向动量/质量及驻点正则性闭合，而非继续只调曲面形状。

## 一、一般共同图的投影连续式

内部迎风坐标写作`r(q)=origin+frame*[f(q);q]`；世界X轴、鼻尖+X、零攻角来流−X和SI单位保持。`q`为米，`g=grad(f)`无量纲，Hessian为1/m。当前限定单值图、均匀上游和沿回溯线严格凸的曲面，驻点位置必须显式给出且梯度为零，不自动修正几何。

激波面上均匀上游的切向投影，其横向坐标方向与`g`一致。沿梯度线定义`dq/dtau=g`，同一流管标签方向为`b`，投影面积Jacobian为`Jq=det(g,b)`。均匀上游投影质量源为`rho_inf*U_inf`。令投影流量向量为`rho_inf*U_inf*a*g`，其中`a`为米，则：

```text
div_q(a*g) = 1
g·grad(a) + trace(H)*a = 1
da/dtau = 1-trace(H)*a
a(apex) = 1/trace(H_apex)
```

最后一式是正定驻点附近的有限、正则质量系数极限，不等于已经求解驻点流场或脱体距离。横向固定f的宽度为`|b-g*(g·b)/|g|²|`，因此每单位激波横向宽度的正向质量：

```text
m = psi_s/h_beta = rho_inf*U_inf*a*|g|
```

对同一激波线，不同位置的入口质量比由实际投影质量积分确定：

```text
d(log psi)/dtau = 1/a
eta = psi_entry/psi_current
```

v98二次曲面族中`a=1/(F'*trace(K))`，可解析退化为旧`m=rho_inf*U_inf*|Kq|/trace(K)`及矩阵指数入口。一般曲面不再使用该矩阵指数。

## 二、数值推进与范围

`buildShockSurfaceMassMap.m`先沿`dq/ds=-g`向驻点回溯几何、对数投影面积W和面积积分，再从驻点方向稳定推进a与log(psi)。两种质量系数构造单列比较；不使用`1-已累计质量/总质量`计算接近驻点的小质量比。

驻点尾部使用明确的线性化极限，Hessian接近程度、尾部投影面积和两遍质量差值均保留为分辨率指标，不称严格误差界。数值网格保存Hermite数据，不保存闭包或借用旧Q41矩阵。`shockSurfaceMassSource.m`在对数质量比区间内二分寻找入口；超出已分辨范围拒绝，eta=0只返回入口熵的驻点极限。

`deformedConicShockSample.m`为实际测试提供共同二次曲线上的整体方向四次形变及精确一/二阶导数。形变不是逐面压力参数。`solveGeneralShockLayerColumn.m`通过新质量映射回溯入口熵，继承原薄层压力/法向速度、统一总焓、同cp恢复与完整非正交法向厚度接口；它仍是显式薄层近似，没有自动求解完整体积连续式及全体动量方程。

## 三、实际测试与独立复核

- 四个原抛物面/二次曲线、定比热/NASA7列通过严格数值退化。数值ODE与旧解析路径不宣称逐位相等，原数值门槛保持。
- 整体三方向四次形变的入口相对旧椭圆映射差约37.820微米，确实使用新映射；同一流线从不同列回溯入口差3.133e-14m。
- 相邻列Cartesian差分的`div(a*g)`依次约1.00000032、1.00000008、1.00000002，随步长减半约二阶改善；层内积分及映射网格加密的最大厚度差2.999e-11m。
- 可分离四次图另有闭式梯度轨迹及流映射Jacobian，独立QUADPACK/Brent源点差9.267e-14m，不依赖MATLAB质量ODE。
- 独立DOP853使用完整2×2变分矩阵与实际投影通量积分，另核对跃迁、入口熵、曲率、状态与厚度。6个数学列及真实45列冻结后通过；真实列最大相对状态差5.165e-10、入口坐标差3.672e-13m、距离差2.165e-11m。属于数值复算，不是实验验证。

## 四、显式一阶压力的轴线限制及后续闭合

对规则驻点，当前显式式在`q→0`时有`P1→0`、`C→1`、`P2→rho_inf*U_inf*vs/2`，因此：

```text
p_explicit(eta) = ps + rho_inf*U_inf*vs*(1-eta²)/2
v(eta) = vs*eta
```

同一激波后熵下，精确轴线总焓要求`h(T)+v²/2=H0`且切向速度为零。显式式使用一阶压力增量，与这一完整等熵关系有截断差异。本工况端点压力比精确轴线驻止压力低约0.4700%/0.4192%，由完整总焓恢复便留下60.608/55.407m/s切向余速。这是当前近似适用性诊断，不能把该余速当作真实已解流场，也不改动从未使用本原型的既有正式关联式面积。

下一步以包含密度变化的法向动量与质量耦合为主线。按当前向内法向取向，有限列的法向Euler关系包含：

```text
dp/dn = -rho*(kappa_n*u² + u*dv/ds_t + v*dv/dn)
dn/deta = -m*h_xi/(rho*u*J)
```

应保留或明确估计流向法向速度导数`dv/ds_t`、非正交几何及入口熵变化。只解独立一维列并省略这些项不能称完整三维Euler解。驻点需先建立正则变量和独立轴线极限，再检验有限列/真实体形、相邻列动量、跨声速与边界匹配；不通过压力混合、裁速度或放宽原10微米门槛制造通过。这部分本轮尚未实现或测试。
