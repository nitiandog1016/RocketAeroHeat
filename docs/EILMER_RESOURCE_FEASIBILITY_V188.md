# v188 完整域资源结论与启动拒绝

本轮闭合了v187遗留的资源判断：**当前固定完整域初始化必要分配下界为8.14GiB，8GiB入口不可行，维持关闭。** 新增资源核算与启动前明确拒绝，没有新CFD、构建、MATLAB或UI任务，没有新增原面p/q或物理资格。

[详细账与源码依据](validation/v188/RESOURCE_ACCOUNTING.md)逐项覆盖原网格对象、两份拓扑、顶点、邻域、气体缓冲及准确GC最小规格。有效载荷下界8,396,552,330字节，加最低分配差346,571,578字节，得到8,743,123,908字节；超过原限146.09MiB。完整运行峰值仍未知，不能据此声称9GiB或16GiB必定够用。

`eilmerResourceBudget.py`只对准确v187包/原网格评估；`readEilmerNative.py`在准备/运行前给出字节数与关闭原因。即使更大资源未被下界排除，旧候选仍不准入。原几何、物理、四层TVD RK3和所有热验证门槛保持，29项并发文件与大场不动。

核算与独立分组一致；16项拒绝及真实运行入口提前拒绝通过。准备入口旧大输入哈希使用既有回执替身，小例仅检查分派，不称旧全套来源重验。首版测试调用签名错误和准确源保留；修正通过，三个父过程共0.924394秒，开发协调另计。证据见[索引](validation/v188/README.md)。

本轮有限核对未找到已证明相容且能装入8GiB的成熟替代布局，不再逐小数组优化或重新试跑。下一数值任务须先确认更大可用计算环境，或已有完整相容的成熟紧凑实现。32GB以上主机/16GiB求解预算仅为开发建议，未证明最低值或收敛。当前已询问用户可用环境，尚未得到回答；没有修改WSL或交换，没有创建远程连接。详见[下一决定](validation/v188/NEXT_DECISION.md)。总目标保持进行中，单工况全面积和科研UI仍最高。
