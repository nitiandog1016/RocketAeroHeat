# v83 原三动量法向列预条件研究

本切片延续 `CONSISTENT_SCHUR_MOMENTUM_V83.md`：旧三动量全局ILU虽有合格局部逆，完整作用却放大约1e219并溢出。本研究不再调用该逆，而是在原三动量A上检查独立法向列与明确的安全替代策略。全部217272个CV和原A连接保留，物理网格与原NS不改。

## 方法与原方程的关系

每个原面有11层、每层3个动量量，形成33阶原主子块。常规预条件列取全部原列内连接，作可逆行列尺度、行主元LU并缓存原单位逆。跨列连接不进入这个局部预条件块，仍全部参与 `applyRocketMomentumGraph` 的完整A作用。

显式 `lineFailurePolicy='certified-CV-diagonal'` 对无法通过精度检查的整列，改用该列全部原CV的3阶对角块作为预条件。整列逆的拒绝另存，不把替代块宣称为原整列逆；该列内原耦合仍在完整A迭代中保留。默认策略仍是 `strict`，遇到不合格整列即拒绝。

`solveRocketMomentumKrylov` 对完整原A只作一个32方向GMRES周期。法向列预条件器固定线性；内部GMRES映射随右端和停止条件改变，不能直接当作固定线性Schur作用。它没有调用原NS、更新物理场或增加区域资格。
