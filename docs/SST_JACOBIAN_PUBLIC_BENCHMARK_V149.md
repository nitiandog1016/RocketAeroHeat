# v149 SST 线性化核验与公开轴对称热流基准

本轮从 v148 的已交付进展接续，于 2026-11-01 开始核验，2026-11-05 完成公开算例启动及记录。完整三维热环境目标继续进行中，新增物理资格面积为 0。当前成果包括五个可执行 Python 文件、准确源码证据、公开参考数据和目标更新。

## 已完成的线性化决策

固定 SU2 8.6.0 源码提交 `7048fd35f56d4bf52e586429d6746a36a10255f8`，从既存归档逐字提取八个函数体。一次独立编译 1.922 秒，一次批量执行 0.438 秒，均 exit0。完整监督 13.594 秒，来源稳定。十组均匀、非均匀及真实相邻状态覆盖三条路径，共 1,410 次原生函数调用。

独立复步物理导数、两档中心差分与解析矩阵复核得出以下结论。

- 均匀数值通量与含 k 的物理通量一致，两侧同时扰动的独立导数误差最大 1.85674e−11。
- 当前实际使用的 Roe 近似矩阵，其中心部分遗漏冻结 k 的导数。令 `D=J_left+J_right−J_physical`，均匀状态满足 `D[momentum,rho]=(gamma−1)kN` 和 `D[energy,momentum]=(gamma−1)kN`，解析预测误差最大 1.50e−16。
- 合成 k=60000 J/kg 时，均匀矩阵尺度化缺项可达 0.07113。两条真实采样边的中心缺项分别为约 1.39e−5 至 4.58e−5，采用明确标记的诊断法向。
- 非均匀 Roe 矩阵具有近似性质。真实样本的全部矩阵与数值通量导数差约 0.32–0.40，须与上述特定代数缺项分别解释。
- accurate 选项的真实样本差约 3.90e−5、5.04e−5，合成非零 k 样本差可达约 0.06464。v148 的实际配置使用近似路径。

本轮决定停止这条局部线性化支线。完整域停滞的因果证据仍不足以支持据此构建新引擎或启用 accurate 选项。准确原函数、测试状态、全部数值输出、编译/执行回执和独立解析复核均可追溯。下一项数值进展转向具体公开热流问题。

## 公开算例及实际入口

采用 NASA TMR 的 Mach 7 轴对称压缩拐角 ACC-SBLI，20° 表示扩张段的压缩转角，攻角为零。真实箭体主线使用 20° 攻角，两者的资格范围分别管理。基准采用公开截断计算域的边界条件，实验完整上游历程的差异继续单列。

`prepareSU2AxisymmetricBenchmark.py` 读取原 PLOT3D 两个 81×101 块，转换厘米至米及 `X=−x`，合并 101 个共享节点。原出口倾斜形状和实际半径 0.10150094 m 保留。161 个壁节点、160 条壁线段、16,261 个总节点、16,000 个四边形的全部正性、边配对、源坐标和旋转几何核对通过。

| 几何量 | 实际值 |
| --- | --- |
| 完整旋转流体体积 | 0.7372892389067335 m³ |
| 壁面积 | 0.7265222893082404 m² |
| 最小平面单元面积 | 9.39475022436e−9 m² |
| 单元矩与边界积分的体积相对差 | 双精度记录为 0 |

配置使用 `AXISYMMETRIC=YES`、`SST_OPTIONS=(V1994m,VORTICITY)`。原生日志确认 SST-1994m 与涡量生产项。WIND 样例给定 M7.11、总温 1600°R、总压 364.8 psi、Tw559.8°R，入口湍流强度 0.021%、湍黏比 0.001。Pr=0.72、Prt=0.9，定比热空气与 Sutherland 参数显式登记。

换算静温 80.00497631 K、静压 550.19563990 Pa、速度 1274.90242263 m/s。单位 Reynolds 数 5.57407445e6/m，相对公开示意图的 5.706e6/m 低 2.31205%，该差异保留在输入清单。公开测站的 576 Pa、9300 W/m²用于对应实验归一化。新增两份 WIND 参考曲线及下载哈希独立保存在 `tests/data/tmr_mach7_su2`。

## 唯一原生启动与后验结果

`runSU2AxisymmetricBenchmark.py` 自动调用本地固定官方 SU2，限制两线程、两更新和 60 秒。唯一任务 0.578 秒正常退出，监督 1.094 秒，输入稳定。两次后验均只读同一终态。

| 检查 | 实际结果 |
| --- | --- |
| 全节点同阶段 EOS 相对误差 | 7.77e−16，通过 |
| 独立壁热梯度相对误差 | 1.76e−15，通过 |
| 黏度相对误差 | 6.66e−16，通过 |
| 原生历史 HF 平面积分复核 | 2.88e−10，通过 |
| 旋转热功率解析积分与两点高斯复核 | 双精度记录为 0，通过 |
| 原启动要求的保存壁节点 T=给定 Tw | 161 个节点全部未过，最大差 903.6392 K |
| 原四项残差 −8 门槛 | 未达到 |

固定源码在等温壁面弱施加能量通量，热流显式使用给定 Tw，输运系数使用保存的流体节点状态。当前给定 Tw=311 K，保存壁面流体 T=1212.028–1214.639 K。初始均匀来流与无滑移处理形成较大的启动温度偏差。原温度通过条件记录为失败，第二次后验也以 exit1 保留这个结果，同时完整记录其余热状态检查。后续报告须分别保存给定 Tw、壁面流体 T 和具备热边界后才能求得的固体 Tw。

启动热流为 −2.0162 至 −1.3242 MW/m²，符号定义为流入壁面为正。当前热流及 y+99≈2.61975 处于启动阶段，实验误差评估待收敛场产生后执行。

固定源码的 `HF_Visc_Local` 累加 `HeatFlux*Area`，该路径的热量累计省略了用于力积分的 `AxiFactor`。本次原生 HF=−1,411,041.436 W/m。新增审核逐线段精确积分 `2*pi*r*q*ds`，得到整周旋转热功率 −992,346.562 W。量名和单位分别输出，避免把该原生 HF 当整周功率使用。
