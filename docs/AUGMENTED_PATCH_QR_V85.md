# v85 完整增广像分块 QR 右预处理

## 目的与当前身份

本阶段沿用 v84 的实际较好接受态（显示别名 krylov25），处理真实 20° 箭体内部 NS 方向的数值求解。旧 v84 两组均只接受一步，第二方向拒绝；不重复该 15 列选择或通过增加同一旧线性预算追逐接受。

这里改变的是完整线性问题的求解坐标。压力、热流、温度仍由原 NS、墙本构及 Fourier 算法取得；新方向的线性检查不能赋予实际流场、区域适用性或正式面积资格。所有原正性、80–2000 K、原 NS 方向 0.1、内部 C 1e−3、空间 1e−9、稳态最大残差 2e−6 /s、定常边界 5e−10 门槛保持。

## 为什么增加这个模块

旧方法以原 C 组内块的逆再逐列归一作为右映射，全部组外连接仍在完整 C 中。然而，同一组各映射列的完整增广像可能几乎线性相关。逐列范数为 1 并不消除这种相关性，LSQR 因而需要花费方向去区分它们。

在当前同一个冻结系统上，独立 Python 逐组诊断发现：旧映射归一后的增广像，最差局部奇异值比约 1.0456e−5。它只是局部像相关性的证据，不代表百万未知量完整问题的条件数，也不能独自证明非线性停滞原因。

## 数学定义

保持同一完整目标：

`min_v ||C v − b||² + penalty² ||W v||²`。

其中 `b` 为当前原 NS 缩放残差，C 是当前完整五量近似矩阵，W 是已冻结的当前状态峰值软权重度量。penalty 仍为原先的 `0.1*||b||/metricNormalization`，不因预处理或迭代变化。W 的链式系数已经含峰值行权重，构造时不能再次乘权。

对每个既有强连接组 G，收集 **所有** 受影响原 C 行，构造 `B_G=[C(:,G); penalty W(:,G)]`。先取严格正列范数 D，再作薄 QR：`B_G D⁻¹ = Q_G R_G`，右映射为 `P_G=D⁻¹ R_G⁻¹`。完整增广 LSQR 使用分组 P 及其精确转置；没有建立全局正规方程、截断奇异值、删除原 CV、补物理对角或修改残差范数。组间耦合仍经完整 C 保留。

这是分块列正交化的右预处理，结合既有 Paige–Saunders LSQR；不是新的 CFD 离散或工程热流关联式。每组增广像 Gram 与单位阵的偏差要求不超过 1e−8。该算术检查不能替代全局收敛。
