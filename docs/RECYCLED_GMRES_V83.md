# v83 SVD多方向增强重启（研究）

本模块针对同Q单方向重启在约0.2缺陷附近停滞的证据。原NS、原CV/原面、气体/边界/尺度、温域、下降、守恒与稳态门槛不变。它是线性数值方法研究，不新增区域物理适用性或合格面积，也不宣称是谐Ritz/GMRES-DR的已验证实现。

## 当前方法

`solveRocketRecycledGMRES.m`以物理方向保存右预条件结果。保留未知量与像满足`A*U=C`、`C'*C=I`，其中`A=-J`为当前完整选中分支作用。每周期先投影当前剩余，再对新预条件方向及像同步消去保留分量：`z=P*v-U*(C'*A*P*v)`。两遍正交化构成`A*Z=V*H`，每周期完成后用当前作用重新计算完整模型残差。

小矩阵`D=diag(I,H)`表示`A*[U,Z]`在`[C,V]`中的关系。SVD选择小的非退化奇异方向，仅处理小代数空间的数值秩，不裁细层像非零或物理CV。新保留方向再逐列调用当前A，QR归一化并用新组合探针验证`A*U=C`。这会增加模型作用，必须与Arnoldi步数分开计数。基础图/粗空间预条件器固定；增强空间只在周期边界更新。

主求解器通过显式`recycledKrylov`启用。`maximumKrylovIterations`给出本段总Arnoldi预算；周期长度、周期数、保留数和基数据存储上界单列。增量解直接相加到同Q初猜，最终由原NS重新计算总方向；仍以原`norm(R)`为分母和0.1验收，不使用增量最小二乘或小预条件残差代替。

## 预算与证据

每个Arnoldi方向有一次基础预条件调用、一次完整模型作用；每周期有一次模型残差重算，保留k列另有k次当前作用和一次组合探针。固定上界为`maxArnoldi + maxCycles + (k+1)*(maxCycles-1)`，超界明确拒绝。向量存储的保守上界包括V/Z、旧/新U/C与临时向量；若显式保存单位完整基证据，另计各周期数据。该上界不是MATLAB进程峰值，也不包含原几何/粗像/模型缓存。

正式792维粗像仍遵守原256MiB限制。真实增强研究另设1536MiB基数据预算，保留最多8个方向；新增的是迭代信息，物理网格不改变。原NS总方向验收保持，线性目标不通过则不提交候选。
