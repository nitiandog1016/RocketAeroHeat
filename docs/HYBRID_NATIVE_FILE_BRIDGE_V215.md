# v215：原生区域文件桥接通过，物理终端与整体数值接受仍待闭合

本轮接通 **原生导出 → 磁盘文件 → 独立进程原生导入 → 冻结 mapped 六组交换**。复用原13列/416棱柱/32层/2微米控制，无新网格、残差/Jv查询或流动发展。总目标 active；新增热面积和区域物理资格均为0。v214整体中心差分失败保持。

## 1. 实现及真实字段

新增 `rah_frozen_file.d`，使用既有 `FrozenMappedDonor` 与 `RAHFrozenMappedCellCopy`。导入只临时建立一个 staging cell，深拷贝后返回快照，不保存 donor cell/block 引用。`fileBoundary` 是可调用的原生构造入口；本轮实际调用它并执行几何、状态、重构梯度、黏性梯度、湍流输运和激波标志交换。**尚未把它登记为通用 lmr JSON/Lua 边界类型，也未运行生产调度或外迭代求解。**

`RAH.FrozenMappedSnapshot.v2` 采用JSON身份/映射与逐分量IEEE754十六进制位串。每个原生 number 的实/虚部各16位，避免JSON NaN及原生结构体 padding/大小端问题。布局为10几何＋25状态＋14×6重构＋7×3黏性＝140个原生标量/面。没有伪造总焓字段，v1/48拒绝原样保留。

| 类别 | v2具体处理 |
|---|---|
| 有效状态 | rho/p/a/T/u/mu/k、速度、SA第一槽、湍流输运和激波标志必须有限、实数；同一具名物性和输运独立核验，不裁值 |
| 未使用槽 | 原生 `rho_s` 初始化值、第二湍流槽、关闭MHD的存储、未用梯度等按位搬运，保留NaN/负零；不修成rho或填0。无限值及有限非零虚部拒绝 |
| 几何 | 位置、体积、三长度、Lmin/Lmax按母几何精确绑定；非轴对称三维areaxy为未用槽，实际为0，不能照搬v1全部几何>0 |
| 重构 | 复制实际梯度、phi和min/max，使用rhou与SA有效槽规则；未使用不等于物理解为0 |
| 不复制的量 | `lref`、electric_field、黏性p_e、dwall不在原生相应copy路径。本合同关闭相关电磁/等离子功能，局部尺度/全壁距仍由受体配置和母网格负责 |
| 额外物理量 | h0和六式积分通量不属于原生mapped复制量；后续物理守恒审计须从实际求解另导出，不把省略它们称为守恒已完成 |

准确实现依据为固定提交 `f53f4609a0331d48efee69a4e4f3c3598378cc03` 的GasState、FlowState、LSQInterpGradients和FlowGradients，摘要与构建输入绑定。本轮没有重算物性/几何资格。

## 2. 身份与母面映射

文件绑定实际构建、适配源码、气体表、母网格、离散配置、初始原生帧、制造状态配方及外迭代/顺序/物理时刻。母面使用排序后的**母节点编号元组**作规范键，不捏造尚未建立的全局数值face ID；母单元编号及实际受体face ID另列。调用方提供预期身份、准确映射和文件SHA，文件不能自证来源。

本轮来源明确是 `manufactured-native-donor-state-not-a-flow-solution`。原生实际导出文件SHA为 `80fa6fcf16fec41f3de3618c4b27acbccb4ca0b7009d58ef3bcf683af508a3da`；初始帧＋配方不是已求解donor场。未来真实调度必须绑定实际已保存来源帧/配置、完整全壁距及轮次，不能更改origin就授物理资格。

独立Python读取器核对文件身份、全部288母面/母单元映射、有效量和物性；原生导入用受体边界的实际face/母几何重排。16MiB文件上限是本软件入口限制，未证明所有未来区域接口都满足；实际接口规模必须计入完整资源方案。
