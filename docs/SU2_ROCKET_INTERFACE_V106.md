# v106 完整三维箭体体网格、原面映射与外域对照

2026-10-31。承接已交付v105，**本版已测试三维几何／实际启动／原面映射，尚未完成收敛的完整箭体气动热解**。目标没有缩小为接口工作，新增经验证箭体面积仍为0。具体输入、源版本、失败与终态见[交付绑定](validation/v106/delivery_manifest.json)，运行前约束见[PLAN](validation/v106/PLAN.md)。

## 本版实际完成

- 复用已有 `buildRocketTestBody` 与 `buildRocketAxisymmetricDomain` 的几何，新增 `buildSU2RocketVolume` 生成真正三维体域；没有重复旧轴对称/Euler物理解。原模型为无突起、分辨率24的参数化完整箭体，2,448个原三角面、面积0.9332096015m²。它不是19,752面真实回归箭体。
- 三维域有12,978节点、11,712体单元（11,328六面体、384三棱柱），轴节点共享。全部内部面两侧共享、声明边界完整，分解四面体体积为正；原表面面积和实体体积保持。鼻部、锥段、柱段、收缩、后体、底面六区均保留。当前只支持原生轴对称几何，突起／任意STL继续显式拒绝。
- `writeSU2RocketCase` 写出完整网格、定比热SI物性与来流。实际进行了0°／0°侧滑及20°／5°侧滑的**一步**Navier–Stokes启动，均正常退出并返回真实壁面p/T/q；日志三分量与项目来流方向一致。它们未收敛，负热流等初始值也原样保留，不赋予气动热资格。
- `buildSU2WallProjection` 和 `mapSU2WallResult` 将全部1,442个壁节点映射回2,448个原面，不改变分母，不填最近面补漏。节点位置、连接和原几何一致性均核对。采用节点双网格面积片常值表示，再按真实平面交集求原三角面均值；不是高阶点值重构。
- 平板外域从0.06m增至0.12m，只追加顶部层，原5,265节点逐值不变。对照在15148次迭代达到原残差门槛；原定0.04—0.16m比较区的p/q在VTK输出精度下无变化，通过运行前1%壁压／5%热流的有限外域筛选。不能据此称任意外域或整个平板误差为零。

## 本版发现的限制及修正

### 加密算例没有通过

120×96、首层1µm的平板算例在720秒预算到达后由执行器终止，MATLAB返回失败。最后保存历史步索引29245，能量log10残差−6.4629，未达−8；没有有效壁面VTK或重启动场，不能给出面热流网格误差或网格无关结论。监测HF11142.00117、maxHF9202916.334仅作为当时未收敛历史保留。

原先仅在结束时写场不适合预算终止，已改为每1000步覆盖写一套restart／壁面文件，外域对照实际使用并产生中间输出；不无限累积历史场。没有延长时间门槛，没有重跑同一加密冷启动，也没有把残差接近或总热流变化小写成通过。下一步须采用已收敛粗网格生成有来源初始场，并先核对插值边界／物性和守恒；它是本程序内部解，不是外部CFD输入。

### dryrun不能证明真实网格加载

SU2 8.6.0的dryrun明确记录 `Using Dummy Geometry`。本版两次dryrun只检查配置、字段和来流约定，不计真实网格预处理。另行两次实际一步启动才确认读取12,978节点／11,712体单元，最小双网格控制体积为正。

SU2自动调整了384个棱柱和全部边界面朝向，导入后的体积与独立几何账一致；不能把其自动调序隐藏成原输入已满足引擎全部方向约定。域最小正交角约6.8332°、双网格子体积比最大117.121；8层射线网格只适于当前接口检查，近壁／远域解析度尚未合格，不能直接承诺高精度三维热流。后续应改进近壁法向层和原生导出方向。

### 面平均热流和原生热负荷必须区分

SU2固定版的 `CFVMFlowSolverBase.inl` 在壁节点使用合成面积向量的模积分HeatFlux。曲面/尖角处，这与相邻分片标量面积和不同。本模型的物面标量面积0.93320960m²，节点向量模之和约0.92073986m²；局部两者比值最低约0.72186。

因此输出并保留两种量：

| 字段 | 含义 | 积分口径 |
| --- | --- | --- |
| `heatFluxRaw` | 原始节点q按真实物面面积片投影的原面平均热流 | 原三角面物理面积 |
| `conservativeHeatLoadDensityRaw` | 引擎节点热负荷分配到原面后的单位面积负荷 | 先以SU2节点向量面积形成负荷，再按面积交集保守分配 |

没有修改引擎原q、没有将两字段合并或用统一系数伪造热流。20°单步场中前者积分−627.919203W，SU2报告−616.079535W，差约1.9218%；后者积分−616.079540W，重现引擎报告相对差8.52e-9。二者的投影守恒误差约1.7e-16，只证明各自离散口径的传递正确，**不能证明这个初始场的物理热流或当前网格准确**。差异应随曲面／尖角解析度研究，不能通过改面积或隐藏字段消失。

原面面积最大相对闭合误差1.04e-14，源节点面积4.92e-15；全部原面保留，常数场和有符号非均匀场通过。原始流体节点温度仍与给定Tw及壁体温度解分开。
