## 2. 受限基准与物性

项目生成二维平板：长0.2m，上游0.04m，外域高0.06m；80×64单元，64个板面线段／65个壁面节点，第一层2µm。主轴X、流向−X，前缘X=0，上游X>0。前缘前的下边界为对称面，板面等温无滑移，顶部／入口远场，末端为超声速出口。

M4，T∞300K，p∞5000Pa，给定Tw300K；定比热理想气体γ1.4、R287.05287J/(kg·K)，Sutherland黏性 `1.458e-6*T^1.5/(T+110.4)`，Pr0.72。SU2明确使用SI及DIMENSIONAL。这不是NASA7／变比热／反应空气，也不是原真实M5、30km、20°箭体工况。超声速出口附近的黏性亚声速层、外域和前缘离散仍需独立检查。

使用SU2的Navier–Stokes、无湍流模型、AUSM二阶重构、隐式伪时间和BCGSTAB/LU_SGS。先按官方配置语法核对，再由本项目生成自己的几何和工况；**不是对官方预制网格／重启动测试的精确复现**。

## 3. 输出合同与实际发现

1. `SURFACE_CSV`在这版实际产生保守变量重启动式表格，没有p/T/q。首轮仅证明调用生命周期，不能称热流接口通过。
2. `SURFACE_PARAVIEW_ASCII`实际写出legacy `surface_flow.vtk`，不是XML VTU。第二轮SU2正常结束，但最初MATLAB读取器查找VTU失败；保留该失败后直接读取已有VTK，没有为修读取器再算一遍。
3. `Pressure`为流体节点压力，`Temperature`为流体节点状态。SU2等温边界在能量方程中弱施加热通量，因此导出温度可能偏离给定Tw。原始Temperature不能重命名为给定壁温，也不能称壁体温度解。二者分别保留，不把偏差裁成300K。
4. 固定版本源码 `CNSSolver.cpp` 的等温边界说明弱施加；`CFVMFlowSolverBase.inl` 第2651—2658行等温输出为 `k*(T_neighbor-Tw)/d*RefHeatFlux`。冷壁时正值进入壁面；本例以保存重启动场的相邻温度和物性独立复算。通用读取器仍不擅自判断任意配置的单位／符号。
5. 平板前缘是对称面／等温面的共享节点，有明显温度偏差和热峰。它单列保留，不纳入零压梯度相似解的内部区比较，也不因此从完整几何中删除。下游比较不能证明前缘热峰正确。

上述官方源码摘录保存在 `validation/v105/upstream/`，保留上游版权和许可证声明；不修改引擎。

## 4. 实际任务与证据等级

| 任务 | 实际状态 | 能证明什么 |
| --- | --- | --- |
| plate01 | MATLAB/SU2 exit0；2500步未收敛，能量log10残差−1.09538 | 调用、终态和保守量读取；没有p/T/q |
| plate02 | SU2 exit0，135.063秒；12000步未收敛；MATLAB因VTU文件假设exit1 | 保存了真实p/T/q；失败不能抹去 |
| reparse02 | MATLAB exit0，读取65节点；没有启动SU2 | 旧VTK解析修复，保留原结果 |
| plate03 | MATLAB/SU2 exit0；172.031秒，步索引15183满足预设残差 | 自动建网格→计算→读取65节点p/T/q完整链通过；网格／物理资格另算 |
| contracts01 | MATLAB exit0；内部有一次预期SU2配置失败和一次1秒预算终止 | 缺失字段／截断拒绝、负热流保留、温度身份及真实失败／超时终态通过 |

plate02能量残差从首轮−1.095降至−6.350，密度−12.131，但目标为−8。plate03最多20000步是根据已观察到的下降进行一次有预算的收敛检查；原判据保持。最终密度−13.7603、能量−8.00009，满足预设停止条件。不能据此取得网格或物理独立性。最后501条总热流历史在保存的小数精度下不变，不代表数学上完全静止。

独立Python审核从保存的保守量复算p、节点T和壁面梯度热流；再用SciPy求解零压梯度Levy–Lees平板相似方程，背景见[NASA TP-3271](https://ntrs.nasa.gov/api/citations/19930006245/downloads/19930006245.pdf)和已有[同剖面说明](ENTROPY_MASS_COUPLING.md)。这里令平面度量为1、压力梯度为0并采用定比热，未复现原报告全部非相似或高温物性。与现有 `solveAxisymmetricLaminarMassProfile` 属同一边界层近似，独立实现／积分不等于独立实验。法向无量纲域16和24的解核对截断影响。比较区间在读出差异前固定为0.2L—0.8L。

plate02：热流梯度复算最大相对差 `3.35e-7`；压力EOS `9.59e-8`；温度EOS `1.66e-7`。这验证字段／单位／符号读取，不是物理精度。内部区SU2与边界层热流相差−4.706%至−1.800%，RMS2.971%；两模型方程和前缘相互作用不同，不能把该差异直接叫实验误差或通过率。

plate03的差异仍为上述范围。MATLAB与Python读取的65组p/T/q逐值完全相等；壁面线积分11150.834079 W/m与SU2的11150.83423 W/m相对差1.35e-8，单位为单位展向长度热功率，不是箭体总热功率。最终独立报告为 `plate02_audit_final.json` 与 `plate03_audit_final.json`。

曾错误假设节点温度应与Tw逐点相等，独立审核因此失败；核对上游弱边界实现后将节点温度改与同一重启动EOS比较。原失败版本另存。没有把原Tw误差门槛放宽以获得物理解资格。plate02前缘节点温度560.091K，内部比较区最大偏差0.0517K，都保留在报告中。

5项MATLAB任务全部终态：4项exit0、1项VTU读取失败；SU2另有3次正常退出、1次故意无效配置失败和1次预算终止。脚本审核还保留过一次NumPy布尔量JSON序列化错误、一次来源绑定发现遗漏中间版本；均已修复并重读现有结果，无额外物理求解。旧CSV将节点温度列名误写为Twall的审计输出只作过程记录，最终CSV已明确为 `Tfluid_node_K`，JSON未知监测量使用null。

## 5. 运行与后续

在项目根目录安装运行时：

```text
python scripts/installSU2Runtime.py
```

必要时通过该脚本的显式 `--proxy` 参数使用本机代理；不写入全局Git／系统配置。MATLAB研究入口示例：

```matlab
addpath('tests');
studyEmbeddedSU2FlatPlate('outputs/my_new_plate', struct('iterations',20000), 'python');
```

目录必须是新的；真实失败／超时保留原回执，不能覆写旧任务。将第三个参数替换为本机可用Python路径。独立数值审核另需NumPy与SciPy，本次使用Python3.7.7／NumPy1.21.6／SciPy1.7.3。

下一步先完成有预算的网格／外域与前缘检查、匹配公开热流基准，再建立完整光顺箭体体网格、0°／20°配对和压力／热流原面元映射。分离、底面和突起要有三维RANS／必要非定常方案及验证，不能由这个层流平板自动获得资格。主工作台的引擎操作、进度、取消和逐变量来源随首个箭体接口一起推进；工程结果继续作为快速对照。
