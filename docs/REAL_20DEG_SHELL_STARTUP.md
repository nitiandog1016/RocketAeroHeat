# v80：真实20°箭体三维计算域与墙面热边界

本阶段沿用原19,752三角面，建立承载三个动量分量的真实外部计算域，并在同一域执行完整五量黏性空间算子及三步共享时间步RK2。**尚未收敛，不是单时刻飞行气动热解；生产合格热流覆盖仍为66.5626327424%，新增0。**

## 原几何与工况

读取v56保存模型的V/F、工况和配置，不将其中的工程压力或热流填入计算体入口。模型9,878顶点、19,752面；M5、30km、攻角20°，给定来流速度为`[-1417.5670073437011,0,515.95219575092631] m/s`，给定无滑移等温墙Tw=300K。SI、X鼻尖正向和零攻角速度−X保持。

`buildRocketTriangularShellDomain.m`将每个原面对应的层间区域分为真实三角面封闭的控制体，公共开放面只存一次。近壁节点按角度加权顶点法向外移；外部层围绕由全部原面半空间求出的轴线上核点整体相似放大。无正核点或出现非正体积时拒绝，不能使用体积绝对值掩盖翻折。这是独立计算体网格，不替换旧表面重网格器；尚未认证任意附件、悬挑或非星形几何。

默认近壁层高为`[0,20,80,320] μm`，随后整体缩放`[1.0002,1.001,1.005,1.02,1.08,1.32,2.28,6.12]`，共11层、217,272控制体、869,088共享开放三角面。所有体积、质心到边界面的有向距离为正；第一层真实壁法向距离8.012—9.9998μm。向量闭合误差约1.19e−15，九矩/V最大误差5.03e−11。

独立Python以长双精度三角四面体积分核对全部体积、质心、共享面几何和总壳体积；最大体积相对差9.32e−12。另用独立线性规划核对核点。以上是几何校核，不是近壁解析度、网格独立性或流动物理精度证明。

## 修正等温墙的热梯度约束

气体使用γ=1.4、冻结来流μ=1.4752077234993085e−5 Pa·s、Pr=.72、80—2000K的常物性层流研究模型。没有湍流输运、变量比热/输运或真实高焓空气资格。远场为完整三分量特征储库；域面法向使用真实三角法向，`axis`仅选择相同的显式储库，不代表笛卡尔面法向。

均匀初猜气体约226.509K，低于给定300K墙。旧完整位移梯度修正在收缩附近184面产生了正向入壁热流，这是该初态下的错误导热方向。旧结果保留用于失败对照，未作为气动热结果。

新增显式选项`boundary.solidWall.thermalGradient='dirichlet-tangent'`。常数壁温的两个切向导数严格为零；函数壁温必须另给`temperatureSurfaceGradient(point,wallID)`的完整切向向量。缺失、非切向或与常Tw矛盾的输入拒绝，不静默投影。

设流体向墙法向为n，δ为墙心减单元体积质心，d=n·δ>0，则

`g = gt + n * (Tw − Tc − gt·δ)/d`，`∂g/∂Tc = −n/d`。

该选项只替换墙面Fourier温度梯度及相应总能残差。默认`legacy`完整数值和info逐字段精确复现；新模式的质量、三个动量、内部通量、WLS梯度和墙压不变。新初态184个错误热向面变为0，没有符号裁剪。解析三维仿射场与六类非法输入拒绝已测试；实际靠墙温度扰动下，完整NS导热通量变化与一致扩散模板的相对差2.3234e−13。

`buildCutCellDiffusionStencil.m`仅按真实约束数量预分配装配数组，保留原约束顺序、求解和秩门槛；旧动态实现作为仅改名完整参考。小几何两种热策略的完整模板精确一致；实际模板13.66s。不能将未完成的旧动态运行用于宣称精确加速倍数。

## 三步实际启动与成本结论

正式`advanceCutCellNavierStokes`未改。保持共享正dt、SSP-RK2、完整HLLC/温域/正性护栏及原1e−9累计五量守恒门槛。接受3步、拒绝重试2次，无状态裁剪；启动积分t=2.8753146856e−9s，原L/U∞=1.9080128127e−3s，二者比值1.5069682271e−6。该积分时间不是轨迹飞行时间。

原空间残差仍7.92324e7 s⁻¹，远高于2e−6标准。五量累计账约1.28e−16；独立长双精度积分约1.51e−16。独立核对全部保存阶段的EOS/温域、RK2算术、通量散度、边界积分、原面压力力与热功率映射。它不是第二套完整NS，不证明所存HLLC/WLS模型的物理精度。

三步实际146.19s。按这三步平均推进率线性外推，一个L/U约需199万步、9.70e7s计算时间；这只是**当前显式微步不可作为主路线的成本警示**，不是运行时间承诺或稳态收敛预测，不能据此外推真实流动所需步数。

后续选择：优先研究保留完整三维五量残差的隐式/直接稳态区域求解，先测真实图结构、线性系统存储和残差调用成本，再安排有界试算。二维轴对称Jacobian不能直接套用；全局差分Jacobian或无预条件矩阵自由Newton也不能在未估算代价时长跑。薄层/PNS仅适用于入口和推进条件已闭合的附着区，不能替代本几何收缩、分离、横流或底面。显式推进保留为有界验证路径，不继续盲跑百万步。上述隐式路线当前尚未实现或验收。

## 失败、终态与交付身份

最初将法向层逐顶点混到归一径向层，在尾底邻圈产生46个负体积；`domain01`实际exit1，`probe01`只是成功捕获失败，不是网格通过。改为整层相似放大后`domain02`通过，独立审计保留46个负体积符号。

`thermal01`因动态约束装配耗时，在核对任务PID后主动停止，实际退出4294967295，不计通过；停止后才修改源码。`thermal02`实际exit0且源码稳定。`initial01`、`advance01`、独立几何/热边界/启动算术审计均实际exit0。

首个工作台测试错误要求面积积分再除面积后的Tw逐位等于300，实际仅有乘除舍入；改为4个机器epsilon的单位量级界限，并继续独立核对原映射值，没有修改物理输入或结果。开发脚本曾使用当前Python不支持的`Path.write_text(newline=...)`，该写入失败后改用显式打开文件，不影响数值证据。
