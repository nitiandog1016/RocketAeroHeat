## 诊断限制与纠正

准确`fluidblock.d`的`evaluate_jacobian`保存/恢复的是`GlobalConfig.interpolation_order`，并非调用前块级阶次。本诊断矩阵调用后，部分后置实数Jv使用的R0与一阶Jv不匹配，产生约7.96e7和1.62e9的巨大比值。这些比值不能称为生产物理导数误差；保存的R0偏移可以在约5.2e−16尺度解释其代数差异。

这既没有证明v181实数/复数差异的唯一病因，也没有隔离全部状态/缓存影响。首版`scope01/report.json`曾过强断言“矩阵后残差等于原二阶残差”，实际最大差初态0.406264、末态0.008629。最终`scope02.json`明确撤回该解释，保留原报告与原数据，不重跑或追改失败。前置Jv/稀疏矩阵的初态门槛仍未过，因此没有依据放行实数NK完整域或宣称生产内核已修复。

正式D文件只在执行后追加三行限制注释；准确编译源是证据中的`build01/executed_diagnostic.d`，两者SHA分列，不冒称同一字节版本。
