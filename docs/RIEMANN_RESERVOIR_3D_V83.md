## 新的显式边界方法

启用方式为 `struct('type','riemannReservoir','primitive',[rho,u,v,w,T])`。原 `type='characteristic'` 及其两个 mode 保留原路径，不自动回退或替换。

`resolveNSRiemannReservoir3D.m` 将域内状态作为左态，给定储库作为右态，真实单位法向指向域外。它调用程序内部定 gamma 精确 Euler Riemann 求解器，在 xi=0 采样真实原态、星区或稀疏扇；三个动量均保留，切向速度来自实际选中侧。

返回真实采样状态和 Godunov 通量；以实际质量通量是否小于 0 决定入流。入流给出采样面的速度/温度约束，出流沿用明确的零法向黏性梯度闭合。恰零质量不伪造入流。正性、原 80—2000 K、真空条件、正压力根及原根容差全部保留。

`buildCutCellRiemannReservoirBoundaryState.m` 按六个边界组批量求解，沿用原 axis/side、owner 和法向；不在每面重复求压力根。完整 NS 直接采用返回的向外对流通量，梯度模板使用同一采样状态和流向。

这是一种新的数值开放边界，不是外部 CFD 数据，不是完整非反射 NSCBC，也没有凭此扩大气体物性或湍流适用范围。真实域大小、边界位置和黏性闭合仍需敏感性验证。

## 直接原 NS 方向初猜

新边界不能使用旧边界的粗层像或资格。当前路径使用显式 `jacobianAction='original-difference'`，没有声称为新储库实现完整解析方向模型。

新增 `ns-probe` 入口绑定当前基态文件中的 Q/rate/物性/边界、独立完整几何及 15 项空间计算源。保存方向可以有任意数值来源，但必须在当前完整 NS 上重新检查，且不能继承种子的旧导数。没有构造或伪造粗层像。

加载时从保存率、原步长和原分母重算缺陷、下降界和扰动状态；主求解器再次用原 NS 检查初猜和总方向，并执行全部原状态、温域、RMS 下降、守恒与稳态条件。这两次实际导数调用明确计入 NS。
