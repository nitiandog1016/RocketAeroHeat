## 方程与回映

对已保存的完整二跳密度/总能量矩阵 S，先取 R 为行无穷范数倒数，再取 C 为 R*S 的列无穷范数倒数。全部尺度必须有限且为正；零行、零列、尺度溢出、非零系数下溢均明确拒绝。没有补对角、替换零主元或改变物理方程。

T 为原字段顺序到同 CV 相邻顺序的双射。实际分解矩阵是

`Ahat = R_ordered * (T*S*T') * C_ordered`。

MATLAB 的 `milu=off` 关系是 `L*U ≈ P*Ahat`；原右端 b 的回映为

`x = T' * C_ordered * U^(-1) * L^(-1) * P * R_ordered * T * b`。

探针中的 PAhat-LU 属于均衡坐标诊断。它不能代替原单位 S、完整五量 C 或原 NS 的剩余验收。原 0.1 总方向、80–2000 K、下降、空间/稳态/边界及 1e-8 组合门槛保持。
