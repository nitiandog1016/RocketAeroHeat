## 实现与合同

`buildRocketShellGraphPreconditioner`以原法向线为基础，同步替换所有侧面的本格对角和左右邻居非对角块。全部内部Euler采用原精确Godunov选中波系导数，保持五量守恒变量缩放；黏性仍为冻结两点近似，外边界仍为原储库近似。它不是完整WLS/特征边界/NS Jacobian，正式空间方程不改变。

原面双图确定性着色，同一颜色内没有侧向邻居。实际19752面使用3色，651816个侧面均通过颜色冲突检查。每条原面法向线缓存5×5 Schur逆和上块。`solveRocketShellGraphPreconditioner`从零开始，按固定次数正反颜色扫描，用更新后的邻居形成右端，再解完整法向线；不按右端或容差早停，因而在已核对的浮点精度内是固定线性映射，能够接入现有固定右预条件GMRES。

`applyRocketShellGraphOperator`应用完整近似`B=I/tau−Jgraph`，返回的预条件器残差只是B系统中的扫描诊断，不冒充精确图解或完整NS线性精度。实际稳态方程仍为`(-J_full_NS)δ=R`，每个组合方向用原完整NS差分重新验收；负模型斜率、图残差小都不能代替完整NS目标。

显式选项：

```matlab
options.linearEquation = 'steady-newton';
options.normalEulerLinearization = 'exact-branch';
options.rightPreconditioner = 'lateral-colored-line';
options.graphSweeps = 1; % 固定对称扫描次数，不是收敛容差
```

缺省或显式`rightPreconditioner='normal-line'`保持原输出合同。最终小域中，旧缺省、保守、显式pseudo-transient完整输出对原快照逐字段重放通过（只排除运行耗时）；显式normal-line的直接稳态完整结果也逐字段复现newtonunit03。未把新策略隐式接入旧调用。
