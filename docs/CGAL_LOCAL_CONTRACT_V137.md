# v137：局部重网格接口已测，真实选区不满足直接导入条件

2026-11-01。本轮完成固定CGAL原生模块的构建、局部修改/冻结边界小型验证，以及真实原网格的只读适用性审核。**没有新真实网格，没有SU2/MATLAB运行，没有新增物理资格面积。** v136的205个低质四面体仍未解决，原网格和失败状态保持。

## 发现与路线修正

v136提出优先CGAL局部重网格，但尚未核对输入数据结构的完整前提。固定6.0.1源码`IO/File_medit.h`明确要求输入四面体填满所有顶点的凸包；`remesh_boundaries(false)`保护已有边界，不会解除该要求。直接导入有孔流体外域或非凸局部片区不适用。不能重新Delaunay化、填实箭体空腔、绕过有效性检查，或者把文档能力当成原域已通过。

这里的凸包体积差仅作为**必要条件的反证**。即使体积相等，也不足以证明没有交叠或全几何有效。当前证据否决的是本轮直接导入方式，不是固定接口不可改善的数学证明，也不排除以合法零子域补全数据结构的其他CGAL用法。本轮不为补域重新构造整箭内部四面体。

## 固定原生模块与小型实测

CGAL 6.0.1官方发布源码，Boost 1.87.0头文件，复用本机GCC16.2.0。使用EPICK内核、Boost多精度精确数后端，关闭GMP依赖，保留断言和有效性检查。独立静态入口只导入原连接，不生成初始Delaunay；仅子域1参与一次局部重网格，所有边界冻结。

一次编译18.140秒、exit0，监督峰值进程族RSS约1.75GB，低于240秒/6GiB预算。只依赖KERNEL32/msvcrt系统DLL。19724项源依赖在构建前后核对；二进制、源码、命令与日志归档。准备回执的83.875秒字段是在全文件清单哈希前取值，**不代表安装全部墙钟时间**；本轮准备开始约10:01，构建和复核在10:06前完成，未超900秒累计预算。

## 下一步：匹配实际网格输入的成熟方法

优先验证固定MMG3D版本的现有四面体域输入、`RequiredTriangles`/`nosurf`及`MMG3D_Set_requiredTetrahedron`。官方5.8.0头文件已归档，明确提供冻结三角形/单元的接口；本项目**尚未安装、构建或测试MMG**，也未证明它可以改善当前固定几何。源许可证为LGPL3+。

下一轮先做一个含孔、含冻结邻域的小型算例，证明孔和原边界保留、未选单元不变、节点身份可恢复、质量实际改善，再从v136显式域执行一个有预算的真实局部候选。优先保持完整原四面体域并冻结非选单元，避免切出片区带来非流形边或遗漏接口；不把所有单元都设required而禁止了全部改善。参数、质量/规模/时间/磁盘限制在运行前固定。

所有原壁/棱柱/金字塔/远场接口、正Jacobian、完整面配对、体积≤2e−10、四面体SICN≥0.1、节点≤400000/单元≤900000门槛保持。接口能力失败与真实固定几何的改善失败分开判断。只有后者有充分证据时才转向轴向渐变层终止；不继续CGAL邻域扫描、整域Gmsh重生成或无限补域基础设施。几何通过后再建立支持局部19层/金字塔的一般初场迁移。

完整域流场、公开条件匹配热验证、高效热物性、分离再附/底面/突起及科研UI仍服务最高目标；网格模块不是物理解。累计热量和轨迹后置，原残差门槛及工程覆盖保持。
