# 内部黏性区域数值基础与当前结果说明（v57）

本轮已把三维空间草稿完善为项目 `internalFlow/` 中的独立实验数值库：实际计算HLLC对流、Newton黏性应力、Fourier导热，并以共享全局步长SSP-RK2推进质量、三方向动量和总能量。它为程序内部的回流、横流与区域能量闭合提供基础；当前尚未接入真实箭体收缩/底部区域，新增箭体热流求解面积为 **0 m²**，不能用这些校核替代全面积求解。

## 三个模块分别做什么

| 完整文件 | 用途与输出 |
| --- | --- |
| `internalFlow/compressibleNavierStokesResidual3D.m` | 均匀笛卡尔控制体共享面通量、阶梯固体墙、压力/黏性力/墙热、五量边界积分；不单独推进或证明区域解 |
| `internalFlow/resolveNSCharacteristicBoundary3D.m` | 根据明确储库及可选出口静压构造法向开放面状态；远场与压力出口分别处理入射/出射特征、回流和黏性数值闭合身份 |
| `internalFlow/advanceCompressibleNavierStokes3D.m` | 真实全局RK2、对流/声学和黏性/热扩散步长、候选失败整步减半、持续残差停止、累计五量守恒账及终态墙量 |

保守量为 `rho,rho*u,rho*v,rho*w,rho*E`，SI。定比热理想气体必须给出 `gamma,R,mu,Pr,temperatureRange`；mu/k为常数且正。固体Q和残差保持NaN，不参与流体积分。墙面直接施加无滑移速度和给定Tw，不构造负温度ghost，不裁密度、内能、温度、HLLC星压力或法向速度。

`wallTemperatureValueKind='prescribed'` 始终表示输入；墙压力由终态邻近流体压力外推，墙热由终态Fourier通量求出。`wallFieldsConverged`与`steadyConverged`由持续真实空间残差取得；到达targetTime与用完maxSteps另列。没有网格/边界收敛和区域适用性验证时，`physicalSolution`与`eligibleForSurfaceCoverage`保持false。程序/算子合同异常原样停止；只有明确的候选流体、HLLC或特征状态失效才减步重试。

## 开放边界的来源和限定

本轮取得并核对 [NASA/TM-2011-217181](https://fun3d.larc.nasa.gov/papers/NASA-TM-2011-217181.pdf) 完整38页原PDF，SHA256为 `cd03112b94852807ef5c941fc322088688fe3f3d4503c88f5cc4f1b68af56451`。原文和印刷4–6页对应的图像/文本保存在本轮验证 `characteristic_source/` 中。

以域外法向n定义 `un=u·n`、`K=p/rho^gamma`、`J±=un±2a/(gamma−1)`。远场使用内部出射J+、明确储库入射J−，按实际面流向选择熵和切向速度。压力出口保留内部J+/熵/切向速度，只施加出口静压；若实际面转为回流，改用明确储库入射J−/熵/切向速度，出口静压不再同时强加。分支方向不自洽、声速转换或非正声速明确拒绝。

原报告印刷式(14)把声速系数写成 `4*(gamma−1)`；视觉及文字均如此，和式(8)的均匀状态不变量反解不一致。按式(8)代数反解应为 `(gamma−1)/4`，照印刷系数代入相同内外状态会得到16倍声速。本实现采用反解关系并独立核对均匀流，不宣称逐式照抄；原报告零面速时用储库熵，本库零面速显式采用内部熵/切向速度，政策另列。压力出口组合由同一关系推导，不使用原报告§2.5强制正出流速度的做法。

黏性出口采用显式零法向u/T梯度近似；回流以面特征值与内部值计算半单元梯度。它们是数值边界闭合，未继承FUN3D隐式Jacobian、完整非反射NSCBC或熵稳定性。仍需域长度、边界位置、反射与真实回流条件检查。

## 本轮结果UI及实际箭体身份

覆盖标题随当前变量变化，静态热流缺口只在单点热流显示；求解壁温未提供时明确说明，不用热流拒绝原因代替。面元探针逐字段列缺失原因；实际浏览器拾取#10717可见外缘静温210.77 K/外缘压力0.93073 kPa有效，而热流/恢复温度因未知上游缺失，输入Tw300 K给定、求解Tw未解。#10739的有效热流与对应算法正常显示。冻结工况条只取结果保存的自由流和热边界，不读取后来编辑cfg；PNG/CSV来源列继承高度/p∞/T∞/壁温输入类型。旧JSON缺记录时明确缺失，不推断。

## 下一步必须实际补齐什么

下一步按已有真实大圆柱—31°收缩—小圆柱、底部几何构造明确的内部区域控制体/曲面映射和入口热边界层/总焓/熵数据，再检验三维横流、再压缩与回流。必须进行近壁、网格、下游域长度及开放边界敏感性/收敛，逐量映射压力/热流与来源；阶梯墙粗网格通量不能直接涂到原始三角表面。变物性、湍流/分离闭合及可追溯同工况实验对照仍缺，鼻部到后体的非相似/涡量接口仍未解。
