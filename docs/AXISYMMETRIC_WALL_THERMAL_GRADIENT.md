## 问题与边界合同

冻结v65稳态的墙面61/63存在负signed热流，而owner的EOS温度约597/611K、高于给定墙温311K。旧位移修正保持`g·delta=Tw−Towner`，但没有同时强制常温斜墙的零切向导数。在真实偏斜、拉伸近壁网格上，旧墙切向梯度达到约−2.15e6/−2.30e6 K/m。

这不允许直接取绝对值或重涂热流。新方法显式选择：

```matlab
boundary.jMin.thermalGradient='dirichlet-tangent';
```

以真实流体外法向`n=[nx,nr]`、切向`t=[−nr,nx]`、owner体质心到墙面积质心的位移`delta`定义：

```
dn = delta·n > 0
dt = delta·t
g·t = gt
g·delta = Tw − Towner
gn = (Tw − Towner − gt*dt)/dn
g = gt*t + gn*n
q_into_wall = −k(Tw)*g·n
```

常数墙温的`gt`严格为0。函数墙温必须显式给出`temperatureTangentialGradient`，它是沿上述`t`的有符号K/m导数；允许标量或以墙面坐标为输入的函数。不能对未知边界函数暗中数值微分。常数墙温配非零导数、导数没有显式策略、legacy配导数、非wall边界配策略、非有限状态或非正法向距离均拒绝。

省略两个新字段仍逐值重放旧算法；显式`legacy`也保留旧梯度，但提供空策略audit。新策略只改变墙面Fourier温度梯度；同一Q下内部WLS、状态、SA标量墙梯度、黏性/导热系数、动量和第五量输运均保持。新梯度进入能量残差、完整Jacobian和隐式推进，不能对旧稳态热流作后处理后称新解。

## 单点代理与适用限制

`EOS(守恒控制体均值)`是当前重构的温度单点代理，一般既不是真单元平均温度，也不等于体质心处的精确温度。只有常密度、零速度、线性温度等受控场，线性守恒量真体积分才可与此一致。测试使用独立两三角Duffy/Gauss的r权保守积分核对该条件。

强切向拉伸、曲壁和非线性边界层的误差可能含`O(ht²/dn)`项；公式满足Dirichlet约束不等于热流已达物理精度。独立审查包含真实r权二次温度反例，不用变正的q替代网格/入口/实验验收。SA墙重构本轮保持不变，以隔离能量边界改动的因果。

## 验证与使用

`testAxisymmetricWallThermalGradient`包括真实斜墙、冷热两种符号、函数墙温、独立保守体积分、非线性同Q隔离、四/五量账、完整Jacobian方向、14项非法输入拒绝，以及冻结v65完整默认重放。

`studyTmrAxisymmetricWallThermal`从冻结v65真实五量稳态取初场，只改变jMin墙热策略，使用原残差尺度和原`2e−6`连续3步及五量账门槛，实际重求完整新方程。输出禁止覆盖已有稳态证据。

`testTmrAxisymmetricWallThermalView`复用35项既有查看器拒绝，并追加8项热梯度策略/来源篡改拒绝。显式策略的完整audit和逐显示面映射接入研究页，面元算法及适用范围显示gt、dn、gn与单点代理限制。给定Tw、未知求解Tw/Te/Tr分开，signed q不裁剪；真曲面积/热功与弦面面积/热积分分别统计。

```matlab
addpath(pwd,fullfile(pwd,'tests'),fullfile(pwd,'internalFlow'), ...
    fullfile(pwd,'regionalFlow','axisymmetric'));
testAxisymmetricWallThermalGradient;
studyTmrAxisymmetricWallThermal;
testTmrAxisymmetricWallThermalView;
```

既有SA回归测试的默认目录仍属于v65。新版本复跑时必须明确给v66输出目录，不能覆盖冻结父证据。一次误用默认目录的本地输出已保存到v66并从交付ZIP逐字节恢复v65，原过程记录不改，最终回归使用明确新目录。
