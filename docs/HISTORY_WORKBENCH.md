# 三维工作台热历史（v48）

v50 已加入逐时刻压力、Cp、外缘压力和外缘温度，详见 [FLOW_HISTORY_WORKBENCH.md](FLOW_HISTORY_WORKBENCH.md)。下文保留 v48 的交付范围和当时验证记录；其中“压力保持单点”的限制仅适用于没有新版外流快照的旧结果。

本版把已有 MATLAB 热响应和热暴露结果接入离线 WebGL 工作台，未修改网格、外流或热响应求解方程。界面保持克制配色、固定布局和可核对单位。

## 使用

在统一 GUI 中完成壁温或变工况热响应计算，再进入“三维结果工作台”。选择“热响应壁温”“热响应对流热流”或累计热量字段，用时间滑块、前后时间站按钮浏览。点击面元后，侧栏显示该面元当前场量的完整时间曲线；点击曲线可以选择最近的实际时间站。时间控件按站点编号移动，曲线横轴按实际秒数绘制，没有时间插值。

全时域统一色标在各时刻保持相同上下限，便于比较；也可使用自定义范围。全模型色标按当前时刻自动调整，不能仅凭不同时间的相同颜色判断数值相同。当前时刻没有有效值时，默认色标不显示虚构的数值范围。

面元探针列出数值、单位、时间和状态，较长的算法与适用范围按变量展开。CSV 导出所选面元、所选场量的完整历程，包含精确数值、单位、每站工况、状态、算法和范围；缺失值留空。图片导出保留当前时间、热响应工况和色标。

## 数据边界

- 静态压力、外缘温度和单点热流保留各自原工况，始终标注“不随热响应时间变化”。目前没有导出逐时刻压力，不能把静态压力当作轨迹压力历史。
- `wallSolved`、`wallFinalFlux` 保留旧字段键以兼容已有导出，其显示名称已改为热响应壁温/对流热流；含历史时按所选站显示，顶层数值仍是末站快照。
- 新增外辐射热流、材料净输入热流、内表面温度、内侧净散热、已记录的恢复温度历史，以及已有热暴露中的对流/净/辐射/内侧累计热量。累计热量读取后端结果，不在网页另行积分。
- 初始材料温度是给定值；绝热内侧的零热流也是给定边界。未求解面元不能靠初温或零热流补齐。
- 有效标志和有限值共同决定逐站显示状态。后端对途中失效面元清空整条历程时，查看器照实保留，显示首次失效时间，不擅自恢复失效前数据。
- 耦合热流使用已记录的逐时刻热边界方法和湍流来源编号，名称来自同一求解器的方法字典；不以末站面元方法代替全部历史。未知名称明确保留为记录编号。
- 历史数组按时间站依次保存全部面元，使用一维数组，兼容 MATLAB 单面元/单时刻 JSON 维度压缩。时间轴不匹配或维度错误会显式拒绝。

## 验证

六项针对性 MATLAB 回归通过：`testAerothermalViewerHistory`、`testAerothermalViewerData`、`testWallThermalResponse`、`testAerothermalHistoryIntegration`、`testCoupledWallConduction`、`testFlightThermalHistory`。日志在本版交付包的 `validation/final_regression.log`，未声称重跑全库。

真实计算联调使用 24 档经典锥柱，1,184 面元，M4，时间 [0, 0.02, 0.06] s，高度 [20000, 19900, 19800] m，攻角 [0, 5, 10]°。沿程热边界与厚度导热耦合后，有效热响应面积 52.68%，最大离散储热残差约 1.57e-7 J/m²。内嵌 uihtml 的 WebGL 错误码为 0，绘制回执有 13,203 个有效像素采样。这是软件联调和离散能量核对，不是实验验证，也不证明全区域模型完整。

浏览器核对了实际模型拾取、初始/中间/末站、统一色标、曲线选站、灰色面元、单面元单时刻及人为中间缺失站的断线行为。面元 #880 的壁温为 300、301.83895351525257、303.85849151916545 K；导出 CSV 与计算数据逐项一致。人工缺失站样本只用于显示边界测试，不作为物理结果。
