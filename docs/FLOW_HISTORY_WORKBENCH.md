# 逐时刻压力与外缘温度工作台（v50）

本版把实际计算时间站的表面压力、Cp、外缘压力和外缘温度接入统一时间滑块、面元历史曲线、固定色标及逐变量来源查看。它沿用现有工程外流算法，未启用 v49 球鼻试验模型，也不是非定常 CFD。

## 使用与数据含义

重新计算飞行历程和壁温响应后，在三维工作台选择“表面压力”“压力系数 Cp”“边界层外缘压力”或“边界层外缘温度”。这些字段显示当前时间站及其工况。比较时选“全时域统一色标”，面元拾取和周向曲线随时间同步更新；“迎风侧”按钮使用该时刻记录的来流方向。

只做飞行气动热预计算而没有壁温结果时，也能导出已保存的外流时间站。旧结果文件没有外流快照时保留单点显示，不用末站值补出虚假的历史。

表面压力仍由修正牛顿方法和给定底压/背风边界构成；外缘压力来自内部切锥、切楔、膨胀或轴向推进，二者分别显示。给定压力在每个时间站都标为“给定条件”。外缘温度不是壁温，壁温失效也不会删除仍有效的压力。未记录的站点留空，曲线在缺失处断开。

## 实现与接口

- `captureAerothermalFlowSnapshot.m`：外流建立时截取四个显示字段、方法字典、适用范围、飞行条件和方向；不复制几何/流线，也不使用材料反馈 `referenceLaw` 中鼻部占位的外缘量。
- `calcFlightHeatingHistory.m`：保存原始实际计算站快照；连续相同工况复用同一状态。
- `calcCoupledFlightWallHistory.m`：同一时刻的壁温迭代共享外流快照，随热边界元数据交给导热求解器；只有其接受的时间站进入最终历史，拒绝步及自动子步不会误标时间。
- `buildAerothermalFlowHistory.m`：优先读取耦合接受步元数据；非耦合历程读取原计算站。核对时间、工况、面元数量及已有精确网格记录，拒绝错配，不插值。外流掩码与材料温度掩码分开处理。
- `buildAerothermalViewerData.m`：有外流历史时更新原字段，保持字段键唯一；无历史时兼容单点结果。`buildAerothermalViewerHistory.m` 继续负责壁温/热流/累计热量。

网页 schemaVersion 仍为 1，历史数组仍为 time-major。新增可选 `history.timeScope` 保存每站范围；`history.flowDirections` 按三个坐标列展开，长度为 3×时间站数。CSV 按每个站的范围输出，不把当前站范围套到所有站。代码与样式 URL 使用内容标记，避免浏览器沿用旧缓存。

PNG 和 CSV 生成后保留下载链接，允许内嵌环境重新尝试保存；切换物理量、时间或色标时清除旧链接。PNG 保留时间、工况、单位、色标及选中面元信息。导出兼容性见下方验证记录。
