# v122：真实完整箭体的HEOS初始化、异常保护与三维启动场

2026-11-01。真实19,752原面、面积1.9646292566 m²的完整域已用内嵌SU2/CoolProp产生三维压力、热流和流体温度启动场。**原−8收敛门槛仍未通过，新增正式合格面积0；单时刻全面积物理目标未完成。** 工程主链已有覆盖率不因这份研究场而改变。源码、小型证据和目标随GitHub交付，完整体场和运行包仍仅存本地。

## 实现与边界

复用v120控制场累计799及原18层、210914节点/520114单元完整域，没有重跑Gmsh，没有采用被否决的32层网格。从定比热守恒场恢复p/T/速度，再按固定CoolProp 7.2.0 HEOS Air重建ρ、ρU、ρE。全部节点PT→DE与独立p/T/速度校核通过，最大相对差约1.41e−13，速度差2.20e−16。

保持原p1197.0279007383137 Pa、T226.50908361133003 K、速度1508.5433002103648 m/s和20°方向；新EOS Mach为4.998034974966865。新物性的局部步号从0开始，源799不能加到新19称为818。密度、内能参考、对流通量AUSM→ROE及普通远场→特征黎曼边界同时变化，不称严格守恒迁移，也不能把结果差异单独归因于cp。

全远场6572三角形/3288节点独立审核：0/1/4/5个入射特征分别为1040/587/619/1042节点。超声速流出保持内部值，超声速流入保持外部值，亚声速法向状态只施加入射特征。法向闭合差1.07e−16、通量Jacobian特征值误差1.75e−13、投影幂等误差4.11e−15。该核对证明边界实现及初始状态一致，不证明外域独立性。

最终运行包是`rah-coolprop-recon-v3`：

- 仅在高阶重构的CoolProp异常处，恢复两端单元值并进入SU2既有局部回退。正常重构和原状态更新保留；没有全局降阶、裁温或吞掉任意异常。
- 修正固定CoolProp的`DP_flash`超域消息缺少`%g`参数的问题，使其返回原本应有的`OutOfRangeError`。EOS公式和拒绝温度阈值不改。
- EOS、cp和导数来自HEOS Air；实际输运仍为Sutherland黏度、`k=μcp(T,ρ)/Pr0.72`。不是反应空气，也不是采用CoolProp全部输运模型。
- 继续限定稳态、单区、层流、有量纲SI；本版没有SST、转捩或非定常验证。所有旧运行包和失败证据保持。

## 失败和构建勘误

1. 原actual01在22.437秒以3221225501终止，无保存场。诊断定位重构状态EOS异常先于原生回退检查；SIGILL来自C++终止器。首次GDB触及90秒调试堆限额，关闭调试堆后18.719秒定位，均保留终态。
2. 第一次ninja意外计划重编351项，95.734秒主动结束。随后单文件编译/索引/链接12.968秒完成，旧物性库SHA不变；正常20步控制8.781秒，场和表面与原版逐字节相同。
3. actual02在22.734秒失败；18.812秒诊断明确同一重构阶段的错误消息缺参。局部EOS保护已生效，消息格式异常不在其捕获类型内。
4. 首次消息修复构建误将普通CoolProp静态库当作薄归档，只刷新索引而未替换成员。recon-v2两二进制实际等同recon-v1，actual03的22.562秒属于无效复跑，其控制8.563秒及物性对照不作为修正生效证据。原脚本/记录不覆盖。
5. 真实替换归档成员后，独立提取SHA通过；Windows `ar p`管道换行导致的首个校核失败保留，改为原生提取而非放宽SHA。独立DP超温程序从原`argument not found`变为正确类型的超域异常，两个新二进制SHA确实改变。最终包全部原PT/DE输出仍逐字节相同，正常20步控制8.578秒、场和表面字节一致，才运行actual04。原源码已归还；构建缓存保留受控对象，不能假设其等同已还原源码。

真实域四次共654.936秒；三项正常路径控制共25.922秒，诊断/构建/状态查询另有逐项回执。没有隐藏失败或把分段耗时重置为零。详细决定与勘误见[有限重构修复](validation/v122/RECONSTRUCTION_DECISION.md)、[消息错误](validation/v122/FORMAT_DIAGNOSTIC_DECISION.md)、[归档成员勘误](validation/v122/BUILD_CORRECTION.md)。
