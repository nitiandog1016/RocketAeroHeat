# v94 压力驱动表面流线与流管横向度量

本版完成可复核的条件流线研究模块，并在统一五步骤工作台显示实际积分路径、站点探针和沿程曲线。它为后续外缘状态—边界层衔接提供流向和流管尺度接口；尚未新增真实箭体的合格压力、热流或壁温求解面积。最新真实NS状态仍为Q41，19次接受/82次主NS，未稳态；正式合格热流面积保持66.5626327424%。

## 方法与输入合同

参考[Riley与DeJarnette原文，NTRS 20040121205](https://ntrs.nasa.gov/api/citations/20040121205/downloads/20040121205.pdf)印刷第4页式(13)的物面切向动量关系，采用一般光滑曲面上的坐标形式积分流向。原文PDF的SHA256为`b2573bb83b44d490678a4c3831bc7b82e0321c5ba94804e0c88d2812a4ea387d`；关键页已读取和渲染核对。本模块没有实现该文完整VII/激波层或式(14)的完整耦合算法。

设弧长为s、单位流向为t、曲面梯度为∇ₛ，则流向的切向变化满足：

```text
Dₛ t = −(I − t tᵀ) ∇ₛp / (ρ U²)
```

曲面一、二阶导数构成坐标联络；压力的横向梯度负责转向。使用固定最大弧长步长的RK4推进坐标与坐标切向分量，保存真实积分端点、采样状态和停止原因。单位切向漂移超限会停止，不靠逐步重归一积分状态、裁温或重播种放行。

调用者必须明确提供以下相容输入，而非仅有一张压力云图：

- 曲面位置`position`（3×1）、一阶导数`firstDerivatives`（3×2）与二阶导数`secondDerivatives`（3×3，依次11/12/22）。
- 同一状态的压力、密度、外缘温度、速度幅值，以及它们对两坐标的导数（均为2×1）。
- 切向入口位置/方向、流管入口标签及其单位、严格递增且从零开始的弧长站点。
- 定比热气体的γ、R、参考温压与声明温域；每项输入的来源；当地光滑、附着声明。

每次采样核对EOS及其两向导数、沿程动量、总焓导数和熵导数，并核对同一射线与入口的总焓、熵。两坐标量纲差异通过缩放曲面基处理，不能把坐标尺度误判为几何退化。入口若含法向分量则拒绝，不能先投影成合法输入再声称已验证。

当前实现仅支持定比热完全气体。验证输入使用γ=1.4、R=287 J/(kg·K)、声明温域80–2000 K；这不是NASA7/变比热或该温域真实气体物理精度的证明。驻点、尖点、坐标退化、压力接口、分离/再附及未知外缘状态需要各自的入口或区域模型。

## 横向尺度与有效前缀

对入口标签β₀及β₀±Δβ/2、β₀±Δβ积分五条射线。在同一弧长站点，将标签中心差分投影到中心线的`n×t`：

```text
h_fine   = (n×t) · [r(β₀+Δβ/2) − r(β₀−Δβ/2)] / Δβ
h_coarse = (n×t) · [r(β₀+Δβ) − r(β₀−Δβ)] / (2Δβ)
indicator = |h_coarse − h_fine| / 3
```

这里的h是相对于入口标签的横向尺度，单位为m/标签单位；当标签为弧度时是m/rad。两条轨迹的总分离距离包含沿程分量，不能替代横向h。`indicator`只在光滑标签族下提示差分分辨率，**不是严格误差上界**；仍需独立步长、标签加密和区域适用性核对。

默认要求两间距指标不超过当地h的2%，并检查宽度正向、聚焦和单位切向漂移。任一相邻射线失效、流管反向/聚焦或标签宽度不可分辨后，流管有效前缀结束；中心流管结果保留NaN及原因。单独的`rays`是诊断记录，不能用于填补已经失效的流管站点。

最初三射线版本在解析聚焦点留下O(Δβ²)残宽；本版改用双间距判定，正确把s=0.8 m聚焦及之后标为未知。旧结果和修订前源码继续保留，未覆盖成新版成功记录。

## 代码入口与复现

`setupSurfacePressureFlow.m`只加载独立模块路径。核心为`regionalFlow/surface/pressureSurfaceFlowRHS.m`、`marchPressureDrivenSurfaceFlow.m`和`pressureSurfaceFlowOptions.m`；原有`traceSurfaceStreamlines.m`的面元准流线没有被替换。

在项目根目录的MATLAB中使用新的输出目录：

```matlab
setupSurfacePressureFlow;
addpath('tests');
testPressureDrivenSurfaceFlow('outputs/surface_flow_check_new');
studyPressureDrivenSurfaceFlow('outputs/surface_flow_study_new');
```

第二个入口生成四组模型和工作台。它会实际执行新的条件流线积分；已有结果直接查看即可，不必为切换页面重新计算。目录存在时拒绝覆盖。

从项目根目录启动本地静态服务后，访问生成的研究页。页面的全部资源均来自本地，不需要外部CFD数据或联网绘图库；嵌套页面消息交互目前按HTTP同源核验，不能把直接双击file页面也当成已测试。

```text
python -m http.server 8776 --bind 127.0.0.1 --directory outputs/surface_flow_study_new
http://127.0.0.1:8776/workbench/index.html
```

仓库另附461,095字节的小型最终核心MAT输入，无需MATLAB即可用Python/NumPy/SciPy独立复核。报告写到新路径，冻结输入和旧回执保持只读：

```text
python tests/auditPressureDrivenSurfaceFlow.py tests/data/surface_pressure_flow docs/validation/v94/raw/surfaceflowdual94_process.json --report outputs/surface_flow_core_recheck.json
```

对新生成的研究可执行以下检查；实际进程回执另行指定，不能捏造来源身份：

```text
python tests/auditPressureSurfaceFlowStudy.py <研究目录> <实际进程回执.json> --report <新的复核报告.json>
node tests/testPressureSurfaceFlowWorkbench.js <研究目录>/workbench <新的界面复核报告.json>
```
