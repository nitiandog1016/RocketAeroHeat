总温2000 °R换算为1111.111111 K。模型插入前的壁温约530 °R，即约294.444444 K；插入时间约0.2 s，温度瞬态初始部分 Tw/T0约0.27。报告沒有逐测点给出对应的精确壁温与采样时刻，因此294.444 K只能作报告初始壁温的近似重建，不能标成每个实验点的精确边界条件。

## 几何：可配对的小球鼻与不可直接等同的最钝模型

D-5450 印刷页4 / PDF页6及图2（印刷页32 / PDF页34）给出15°锥半顶角、底半径 rb=6 in=0.1524 m、尖锥参考轴长 L=22.39 in=0.568706 m，以及四种名义鼻半径：0、0.375、1.000、1.100 in。对应印刷钝度比为0、0.0625、0.167、0.183。

- **R=0.375 in=0.009525 m、R/rb=0.0625**：有热流表II；与 D-4909 的同半径小球鼻型号共享几何，是当前配对数据准备的优先对象。
- **R=1.000 in、R/rb=0.167**：D-5450 明确只用于表面油流线测试，没有给出该型号的热电偶位置及热流表；不能为它从相邻钝度比插值“造”实验热流。
- **Rnom=1.100 in=0.02794 m、R/rb=0.183**：有热流表III，但电铸鼻部略为扁球，比较仪测得驻点曲率半径为1.25 in=0.03175 m。名义几何半径、驻点局部曲率与热流归一化半径必须分别保留；报告没有给完整扁球曲面参数，不能把它当成精确 R=1.100 in 球面。

D-4909 印刷页3 / PDF页5给出15°、rb=6 in，以及R=0、0.375、1 in三个相切型号；其最钝型号 R/rb=0.167。因此不能把 D-5450 的0.183最钝热流型号与 D-4909 的0.167最钝压力型号当作同几何。这两组最钝实验只能分别保留。

## 热流定义、归一化与实验误差范围

D-5450 印刷页5 / PDF页7，式(1)用薄壁储热求实验加热率：

`q = rho_w c_w tau_w dTw/dt`。

模型为高纯镍电铸薄壳，壁厚约从鼻端0.10 in变到尾部0.03 in；热电偶为 chromel-alumel。温度时间曲线斜率由有限差分求得。该文给的是实验表面加热率，不能把式中的壁温导数误作定常壁温解。

表I、II、III的数值是 **q/q̃0**。q̃0是同 Re* 下“最钝模型”的**理论**驻点热流，按报告参考文献8（Fay–Riddell）和**实测驻点曲率R=1.25 in**估计；不是每种模型各自测得的驻点热流，也不是本项目当前算法算得的驻点热流。三种 Re* 的印刷 q̃0依次为11.2、19.0、22.9 Btu/(ft²·s)，见表II/III标题。

草稿主要保留印刷 q/q̃0，用于后续归一化比较。额外的 W/m²列采用明确声明的 Btu_IT = 1055.05585262 J，1 Btu_IT/(ft²·s)=11356.526682227 W/m²；三档 q̃0因此约为127193.10、215774.01、260064.46 W/m²。原报告未细分 Btu标准，单位换算列不能声称提高原始实验精度。未来绝对热流比较应同时保留这项约定与印刷 q̃0精度。

报告的误差说明是：最钝模型驻点重复测量与理论约在±5%内；零攻角锥面三条周向母线重复性约±6%；最低热流水平的精度估计约±20%。这些是原作者的重复性/精度估计，不能直接当成统一的1σ误差棒。当前 CSV 尚未按各点热流水平分配统计误差。

D-5450 印刷页6 / PDF页8还指出：小钝度比0.0625在较高 Re* 的尾部可能发生转捩；0.183的相应零攻角结果总体呈层流。因此表II的尾部点不能全部作为纯层流模型验收点，转捩位置需另按图4和原文逐工况核对。

## 配对激波层压力的数字化边界

D-4909 图3给出前站虚拟尖锥坐标 x/L=0.280、后站0.784。对于 R=0.375 in，小球鼻实际鼻端坐标分别印刷 x/R=13.9、43.9；R=1 in型号分别为3.4、14.7。这些压力站不等于 D-5450 的十个热电偶站，应分别保留坐标，不能强行一一对应。

零攻角测点在图4(a)、图5(a)左下角 α=0°子图，包含三种钝度比。其纵轴是法向距离 **η/R̃**，R̃为 D-4909最钝模型的**1 in**，即使读取0.375 in鼻部的数据，也不能改用η/0.375 in。横轴同时标 Cpp和Cps，采用**不同的刻度**；皮托与静压符号也不同。

压力系数定义为 `(p-p∞)/q∞`，q∞是自由来流动压。Cpp是皮托测量，不能直接当成外缘流线的无粘总压或 `p0/p0∞`；超声速探针前有激波，需要明确预测量或相应转换模型。静压也包含部分理论延伸：原文印刷页5指出某些曲线靠近激波处按斜激波理论延伸到由皮托穿越判断的激波位置，故数字化必须区分实际点、连线、理论延伸和激波位置横杠。

原文印刷页5 / PDF页7估计压力系数精度约±2%至±4%，角度±0.2°，探针高度±0.02 in；静压的大偏流测量未作修正，主要具有定性意义。这里优先索引零攻角，尚未数字化 Cpp/Cps点，也没有将曲线当作实测数组。

## 当前 NASA7 适用域不支持直接复算这组名义来流

报告给出Mach10.6、总温2000 °R，却没有直接列出数值自由来流静温。作为**定比热γ=1.4参考重建**：

`T∞ = (2000*5/9) / (1 + 0.2*10.6²) = 47.337726 K`。

在此同一参考假设下，三档 p∞约44.0204、132.0611、198.0916 Pa，U∞约1462.0168 m/s。这些是 CSV 中明确标为 derived 的名义参考值，不是原报告的直接测量；实际重建还应查风洞校准资料与量热不完全效应。D-4909本身说明来流有量热不完全性，但对其压力系数的影响较小，近似γ=1.4可用，不能据此宣称所有热流热物性误差也足够小。

当前 `airThermalProperties.m`只覆盖80–2500 K，80–150 K的低温冻结近似也**不覆盖47.34 K**。总温1111.11 K与初始壁温约294.44 K在当前范围内；主要缺口是上游低静温而非总温超过2500 K。本轮没有将47 K裁到80 K，也没有外推NASA7或自动切换物性让实验“通过”。

显式定比热模式可用于将来复算报告的理想气体压力近似，但在47 K下的输运性质、Re*一致性、边界层热流及实验壁温条件仍须独立论证。仅运行定比热并得到数字，不能当成NASA7热流实验验证完成。

## 后续可执行起点

3. 将表II后段的转捩点和纯层流比较范围从图4/正文逐工况核对；保留缺测和原印刷精度。
