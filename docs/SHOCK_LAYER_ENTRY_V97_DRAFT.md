# v97 原型：共同三维激波入口与真实面元几何接口

这是朝内部区域外流求解推进的组成模块。共同激波跃迁和原箭体几何接口已分别完成实际MATLAB及独立Python检查；完整的激波形状反算、跨激波层输运、壁面匹配和区域热流仍未完成。**本版不能作为真实20°整箭的边界层外缘，新增合格热流面积为0。**

## 为什么需要这一层

真实箭体基线有19,752面，M5、30km、攻角20°。旧工程外流按面元独立切楔/膨胀，再把自由流投影为方向；其背风收缩带与下游之间没有共同的激波熵链。v96的独立二维激波银行仅用于接口验证，不能构成同一张三维激波面。

本原型从同一个光滑候选激波面取得法向和法向导数，使用一个均匀上游计算三维向量跃迁，直接求激波面内的熵梯度。原箭体只提供真实几何和自由来流，未读旧压力、热流或未稳态NS状态作为入口。

输入的非轴对称抛物面是**给定候选几何**。它尚未与真实箭体通过激波层反算匹配，不是求得的真实脱体激波，也不能因为9条法线命中箭体就取得流动物理资格。

## 程序与守恒

- `setupEngineeringShockLayer.m`加载独立模块和既有同物性接口，不改变旧计算链。
- `shockSurfaceJumpState.m`求单个共同曲面点紧后的p、T、rho、三维速度、总焓、熵及导数。
- `sampleShockSurfaceInlet.m`确保同一回调曲面和同一均匀上游，记录几何、上游及跃迁方程来源。
- `intersectShockNormalsWithBody.m`沿内法线在原V/F上求最近进入交点，保留原面号、节点及重心权；不重网格或消除肩部特征。

设单位激波内法线为n，上游法向速度为w1，密度比为r。切向速度保持，法向质量、动量和总焓给出：

```text
w1 = V1 dot n
w2 = w1/r
rho2 = rho1*r
p2 = p1 + rho1*w1^2*(1-1/r)
T2 = p2/(rho2*R)
V2 = V1 + (w2-w1)*n
h(T2) + w2^2/2 = h(T1) + w1^2/2
```

对r>1取非平凡压缩根，要求法向Mach大于1+1e-5、物理熵增和法向下游亚声速。曲面退化、方向反向、无压缩激波、上游EOS不一致或总焓超出物性范围时拒绝。不会翻转法向、补作自由流、裁温或切换定比热。

NASA7分支使用v95/v96已有的continuous-project-cp-v1约定，生产`airThermalProperties.m`未修改。根括区遇到温域外试点时，只根据单调焓及已检查总焓决定严格正/负号，不把这些试点当作有效状态。

压缩根的隐式微分结合曲面一/二阶导数，恢复p、T、rho、速度和熵的两向坐标导数，再通过曲面度量转换为物理梯度。原始总焓梯度残差保留，不能补零冒充没有舍入误差。

## 已取得的证据

第一轮`commonShockEntry97`实际terminal/exit0，MATLAB引擎18132、运行期源码稳定。真实20°上游下，定比热/NASA7各9个共同激波采样点；另有4个平面激波，包括法向Mach1.01弱压缩支。曲面坐标变换、刚体旋转、三维向量守恒、导数加密及5项拒绝通过。

独立审核用完全气体闭式和另一个压缩变量的Brent热力根复算全部状态；五点差分从重新求解的状态检验两向导数，QR最小范数解检验物理梯度。18点最大相对状态差1.09624e-14、最大相对导数差1.64195e-10；1126项实际来源SHA通过。这些属于守恒/解析及同模型数值校核，**不是实验验证**。

`shockBodyGeometry97`实际terminal/exit0、引擎39032、源码稳定。9条候选激波内法线全部命中真实原面元；刚体变换、闭合定向检查、内部起点/不相交射线留NaN通过。独立平面交点与重心方程得到相同最近原面号，最大位置差2.86098e-17m。几何距离是将来反算的目标，不是已经求得的激波层厚度。

小型重现输入只提取原V/F/面积和均匀自由来流，334167字节；不复制旧外缘、热流或大矩阵。此输入与原值一致，不声称MAT容器字节相同。独立冻结输入重算commonShockFrozen97已terminal/exit0、全部来源稳定；1745个保存对象逐值一致，只排除MAT容器元信息。复制到仓库后的数学/几何冻结证据再次独立审核通过。完整区域模型仍为草稿，具体交付以本次GitHub提交及验证索引为准。

## 下一步必须完成的物理环节

1. 基于同一激波的流向/横向几何建立质量坐标，核对非正交度量和Jacobian；从同一入口追踪熵，不能逐站重置总压。
2. 实现并审核跨激波层的压力、速度和厚度关系，以本版的原三角面命中距离作几何匹配目标，实际求解候选激波形状参数。
3. 钝鼻亚声速—跨声速区先整体匹配，只有满足适用条件的超声速段才能向下游推进；不能由自由流任意播种到收缩后的圆柱。
4. 取得适用的壁面/有限外缘状态后再接v96流线、边界层、原面元与工作台，逐区域验证后才增资格面积。

Riley的薄激波层近似不能代替黏性主导的背风分离、再附和底面模型。真实20°横流—31°收缩—后体的大面积缺口仍是主线；本原型不是它的已完成替代品。Q41未稳态与正式合格热流面积66.5626327424%不变。
