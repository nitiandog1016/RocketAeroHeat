# 真实网格底面压力区域模型（v54）

`solveMeshBasePressure(mesh,freestream,cfg)` 已将 SAND93-0280 的层流底压关联计算到通过审核的真实底面三角形。当前支持孤立平圆底、9～10°尖头直圆锥、零攻角/侧滑、定比热 `gamma=1.4` 空气及薄层流边界层。它返回逐面元压力/Cp和来源，不直接修改 `mesh.pressure`。其他前体、湍流肩部及受干扰底面保持未解。

这一步求出了受支持几何的真实底面压力。底面热流、底部外缘/恢复温度及求解壁温仍为 `NaN`；没有把公开关联的代表底热涂满底面。真实箭体尚未因此获得全面积气动热解。

## 当前网格审核与输入

几何检查直接重算 `mesh.V/F` 的面积、法向和拓扑，不信任 `cfg.geometry` 名称、旧法向缓存或解析测试的区域标签。必须满足：

- 所有三角形非退化；整体为单一闭合、绕序一致、每边恰用两次的二流形，Euler特征为2，没有游离点或独立组件。
- 尾向外法向的底面位于真实最小X平面，构成无孔拓扑圆盘；一个简单边界圈，至少8点、最大角间隔45°。
- 底圈拟合圆的相对半径残差不超过 `1e-6`，三角面积等于真实边界多边形面积。计算覆盖按真实三角面积，不能拿理想圆面积替代。
- 鼻端为同轴单一尖点；全部前体顶点满足同一直母线圆锥，半径相对残差不超过 `1e-6`。前体三角形周向跨度不超过45°，外法向朝外/朝鼻。分片体积在解析圆锥的弦离散误差界内，保留拉链圈数变化的真实离散误差。

几何结果分别保留 `geometry.flatBaseVerified`（完整平圆底已核验）和 `geometry.verified`（整前体也为支持的尖直锥）。轻微倾斜、局部翘曲或非圆尾盖不会仅靠残留X极值平片获得圆底身份；调用方应明确拒绝应用该底压方法，保留原结果等待工况/方法修改，不能让未识别的尾盖残片暗中保留给定Cp。完整圆底但前体为锥柱等不受支持几何时，可以给整片已确定底面保留未解状态。

STL不能证明发动机是否喷流，因此还要求显式操作声明：

```matlab
cfg.basePressure.hasRearSupport = false;
cfg.basePressure.hasGasInjection = false;
cfg.basePressure.operationSource = '当前隔离无喷流工况的来源说明';
cfg.heating.airThermalModel = 'caloricallyPerfect';
```

声明记为输入。缺少来源、存在尾撑/喷流、默认热完全气体模式、非零攻角/侧滑、自由流总温/总压/理想气体状态不一致，均拒绝本关联。程序不会自动把默认NASA7模式切换成定比热。物理输入还限 `2<=Mach<=20` 和 `80<=T<=2500 K` 的无化学空气域。

## 内部肩部解和薄层证据

当前尖锥肩部由 `solveConicalShock` 的附体 Taylor–Maccoll 弱解计算，无需CFD。母线长度来自真实轴长和圆底半径：`s=hypot(L,rb)`；黏度用既有Sutherland实现。肩部 `Re_e,s` 送入 `calcTransition`，默认阈值 `5e5`，这是经验类别判断，并非稳定性/转捩预测。`Re_e,s<1e5` 低于报告层流关联范围，已转捩肩部也拒绝。

通过层流类别后，用 `solveAxisymmetricLaminarMassProfile` 在同一尖锥肩部解物理速度/总焓剖面，直接积分有限外缘物理厚度 `delta`。直锥外流恒定、轴对称度量 `h=s*sin(theta)`，有

```text
xi = integral(rho_e mu_e U_e h² ds) = rho_e mu_e U_e rb² s/3
beta = 0 ; dpe/ds = 0 ; dUe/ds = 0
```

剖面源为NASA TP-3271式6～7、17、25、54、56～61的局部相似工程近似，非相似项未解；尖锥没有球鼻熵层吞入/接口匹配问题。要求前体等温给定壁边界、剖面残差/物性/有限边缘等已有核查通过，以及 `delta/rb<=0.05`。这个0.05是本实现的显式保守工程门限，**不是报告规定的普适数值**。不以动量厚度乘一个任意系数冒充物理delta，也不因为压力缺口而放宽薄层条件。

湍流头部/肩部目前没有在本映射模块建立受验证的物理delta证据，因此不使用湍流底压关联填面积；圆柱、球鼻、锥柱和尾锥也需要各自的真实肩部状态/薄层模型。

## 压力求解和结果契约

通过上述检查后，调用已测试的 `solveAxisymmetricBaseCorrelation`，底压为 SAND93-0280 Eq.(8b)：

```text
C_e^4 = [1 + 5/M_e²]^(-2)
p_b/p_inf = 3.05 [M_e²/sqrt(Re_e,s)]^0.6 / C_e^4
Cp_b = (p_b-p_inf)/(0.5 rho_inf U_inf²)
```

报告打印页11支持低速回流区静压近似均匀，因此把已算底压赋到真实底三角形。该假设不解析底唇细节和三维回流场。低于肩部静压的底压及自由流/肩部/回流区Kn筛选仍由已测试区域关联审核，失败时不裁剪压力。

| 字段 | 含义 |
| --- | --- |
| `baseFace` | 从真实V/F检测的尾端平底候选面；即使后续拒绝仍可查看 |
| `computedFace` | 本次真正计算的底面压力面；拒绝时全false |
| `pressure`, `Cp` | `Nface×1` 数组；非底面及拒绝底面为NaN |
| `faceStatus`, `faceStatusNames` | 状态码为0时已算，其余拒绝或非区域；名称按码+1索引 |
| `faceMethod`, `faceScope`, `fieldMetadata` | 各面方法/适用范围，以及压力/Cp、壁温输入、转捩类别的身份和来源 |
| `shoulder`, `shoulderTransition`, `shoulderBoundaryLayer` | 内部外流、经验类别和同剖面薄层证据 |
| `summary.computedPressureArea` | 新求得底压的真实三角面积；独立于整模型其他压力模型 |
| `regionRepresentative` | 底热/St的地区代表量，`eligibleForSurfaceCoverage=false` |

底热、外缘/恢复温度、求解壁温面数组仍为NaN，`summary.computedHeatArea=0`。即使代表热流有限，也不能用于覆盖审计或映射成全面积底热。

原报告、公式复算和散点证据见 [AXISYMMETRIC_BASE_CORRELATION.md](AXISYMMETRIC_BASE_CORRELATION.md)。SAND93-0280 DOI为 [10.2172/10111104](https://doi.org/10.2172/10111104)。

## 已测试证据及限制

`tests/testMeshBasePressure.m` 用独立解析几何区域标签核对24个真实底三角形，独立复算Eq.(8b)/Cp、三角面积及剖面质量积分；测试平移不变，以及同时放大几何/降低压力、保持Re/Kn的相似尺度。还核查整体倾斜尾盖、局部变形仅剩22个平片、非圆底、错误法向、开口、钝鼻、锥柱、多组件、声明缺失、尾撑、喷流、攻角/侧滑、气体模式/总压不一致、转捩、厚层、未解析有限外缘和非均匀壁温拒绝。锥柱圆底可核验，但前体模型仍拒绝；变形残片不能冒充完整圆底。

名义工况为 `T_inf=180 K, p_inf=250 Pa, M=3, rb=0.2 m, theta=9°, Tw=300 K`。底压为 `140.345991 Pa`；24个底面真实计算面积 `0.124233142 m²`，占该离散全模型面积 `13.493%`。此百分比只指**本区域新增压力面积**。底热新增计算面积为零。

日志和结果保存于 `outputs/v54_validation/base_mesh/test_mesh_base.log`、`mesh_base_results.mat`、`mesh_base_summary.json`。这些是实际网格/解析几何、公开关联式和数值剖面校核，不是独立实验精度验证。阶段工程交付和主链路/UI整合应分别由相应测试确认；本独立模块测试不能证明整个目标完成。

## 当前工况和统一窗口接入

设置 `cfg.basePressure.model='sand93Laminar'` 后，`modifiedNewtonianPressure`在同次压力构建时调用本区域模型，保留迎风修正牛顿与明确给定背风边界。默认仍为 `prescribed`，不会未经用户选择改变现有算例。统一工作台的“底压方法 / 条件”在原宿主内提供模型、外流/热流空气物性及操作声明；切换物性明确重算当前外流/热流。

支持几何下若操作声明、攻角、气体或肩部筛选失败，完整尾底的压力/Cp/压力增量保留NaN，状态为未解，不退回给定Cp。未通过完整平圆底识别时，不能安全定位全部底面，明确拒绝应用该模型，避免部分变形尾盖残片被标成解而其余底片偷偷保留给定值。取消设置才恢复原结果。

压力探针、当前场量导出、面积统计均记录逐面元区域方法和范围，外缘压力/温度与表面压力保持独立。压力缺失时总气动力与力矩保留NaN并显示未解面积；不忽略缺失面、不补零、不把部分积分当整体载荷。`testBasePressureWorkbench`实际验证标准大气M3/40km尖锥的同窗口配置/取消、内部区域解、载荷增量、WebGL、域外NaN和斜/局部变形尾盖拒绝。最终任务退出码0，日志为 `outputs/v54_validation/base_workbench_release.log`。
