## 1. 实现与来源

新增 `calcWeightedReferenceLength.m` 和 `calcKinneyAcreageHeating.m`。在原工程链已经接受的侧壁上，提供 Kinney/CBAero 型参考流长／参考性质热流对照；默认仍为 `boundaryLayerIntegral`。鼻区、压力、外缘、网格、转捩和分离筛选沿用原链。

来源：David J. Kinney, *Aerothermal Anchoring of CBAERO Using High Fidelity CFD*, 2007，II.I，印刷页 4–5，[NASA NTRS 20070017947](https://ntrs.nasa.gov/citations/20070017947)。本轮已查看原文相应页；PDF 的位置、字节数和 SHA 记录在 [provenance.json](validation/v104/provenance.json)，PDF 保留本地。

令 `g=ρe μe Ue`，积分 `I=∫g ds`，背风加权流长 `Sw=I/g`；迎风使用原几何准流线距离。参考性质与热流使用：

```text
T* = (Te + Tw)/2 + 0.22 (Tr − Te)
Re* = ρ* Ue S / μ*
Cf_l = 0.664 / sqrt(Re*/Mf_l) × Te/T*
Cf_t = 0.37 / log10(Re*/Mf_t)^2.584 × Te/T*
St = Cf/2 × Pr^(−2/3)
q = ρ* Ue St × [h(Tr) − h(Tw)]
```

`ρ*` 取参考温度密度；默认 Mangler 因子层流 3、湍流 2。实现保留正、负、零热流及未知值的区别，不把热壁冷却裁成零。

本项目使用共享边图准流线、梯形积分、背风 5° 范围内三次 smoothstep 切换；切换形状／角宽是项目离散选择。原文采用 CEA，本程序沿用固定组分 NASA7 或定比热空气、现有焓恢复温度和常 Pr。它不是完整 CBAERO、CEA、真实三维流管变换或 CFD 锚定的复刻。

## 2. 入口假设与限制

现有图路径的起点不是经过核验的物理驻点／附着线。真实算例存在 711 个离散根，新方法接受的 11,880 个侧壁面元、1.2987844295 m² 全部继承离散起点零积分假设。非零起始距离可以使用常状态前缀；显式给定的未知入口则保持未知并阻断下游，不自动回退。

因此结果记录 `productionQualified=false`、`validationStatus='engineeringComparisonWithAssumedEntry'`、`historyCompatible=false`。原 Thwaites／Head 只继续承担入口、分离及关联式适用性筛选；这不证明真实三维入口已经合格。

本方法不提供新的外缘、波系／熵层接口、真实横流剖面、底面、分离或再附解。未解区域不重新播种、不补零；选中方法失败的侧壁保留专用拒绝原因。热历史／壁体耦合未验收，长历史试验的主动中断不能写成通过。

## 4. 主工作台与来源修复

从 `main` 进入同一五步骤侧栏，在边界条件的“附着侧壁热流”选择“边界层积分法”或“Kinney参考流长对照”，确认边界后显式计算。更改方法会使旧结果失效；浏览不暗中求解。

结果工作台增加参考流长和“原工程方法热流对照”，两种热流共享 0–382.1112188518 kW/m² 的对照色标。探针保留每个场量的数值、方法、范围和身份；恢复温度不标成 Kinney 热流公式的结果。输入 Tw300 K 与尚未求解的壁温分开。

[路线审查](reviews/TECHNICAL_ROUTE_REVIEW_2026-10-31.md)发现旧草稿把 1,811 个鼻区余弦延拓面统一标成边界层积分法。本次在替换方法前保存原来源，按原方法 ID 恢复鼻区、侧壁及 335 个受限脱体层流面的标签／范围。19,752 面的原热流值、状态和方法名称与原基线一致，最终物理字段逐位保持。

缺失或损坏的原来源明确拒绝导出。旧 v104 `actual03/current_case.mat` 是标签修复前的数值容器，不能直接用新导出器猜测来源；最终展示由 `testKinneyProvenanceExport` 从保存基线重新计算侧壁公式并核对物理量不变。只另存小型 `baseline_provenance.mat`，未复制整份大 MAT。

实际浏览器核对了云图、同色标切换、鼻区来源、侧壁探针、滑块、手填 X=-1 m 及求解壁温未知状态。截图与 AX 记录在 [browser](validation/v104/browser/)。X=-1 m 为 92 条交线、34 条未解，曲线保持断开。

导出按钮产生可见的 CSV 下载链接；两次下载事件等待和一次 `downloadMedia` 均在 15 秒后超时，未取得原生下载文件。随后从该可见链接捕获实际生成的 CSV，独立核对 92 行值、状态、来源及原三角形交点通过。这证明生成内容正确，**不证明内置浏览器原生下载成功**；也不据此认定所有浏览器均无法下载。该环境限制保留为 UI 后续项。

`published_workbench05` 是冻结结果查看器，不是可编辑的五步骤计算前端。五步骤另由真实隐藏宿主的控件回调验证，未宣称该宿主完成 WebGL 渲染；实际 WebGL 由上述浏览器检查证明。最终静态资源来自已交付 `0b5e285`，不混入 OpenCode 并发修改。

## 5. 验证与复现

实际 13 项 MATLAB 任务：9 次 exit0、3 次 exit1、1 次主动中断，全部终态。失败分别为初次测试入口整型角度及两次导出结构字段不一致；最终定向成功不覆盖历史失败。全部记录、日志和保守源码闭包见 [验证说明](validation/v104/README.md)。

- 经典锥柱 1,184 面；648 面参与方法对照，热壁负热流和 648 面有效零热流通过。属于解析／公式校核，非实验验证。
- 真实箭体独立 Python 审核 242,140 项值／约束；压力、外缘、网格不变，无新增面积。
- 五步骤真实控件流程完成两次方法显式计算，默认方法重放一致。
- 修复后原来源逐面核对、两种损坏来源拒绝；Node 检查 197,520 次探针和 40 份截面导出。
- 实际浏览器与 CSV 原三角形独立核对；原生下载限制单列。
