# v140 原近壁列的渐变终止验证

2026-11-01。小例通过；真实箭体在外域生成之前因138个过渡四面体质量不合格被拒绝。没有生成新的完整外域，没有运行CGAL自交、SU2、MATLAB或新UI测试，新物理解面积0。完整气动热目标继续进行。

## 本轮改变

v139固定外接口增点后仍有744个坏四面体。本轮复用v133原坐标和尾缘扇，在原壁X≥0.031232520723574634m的815点处保留19层，沿原表面边的最短图距离每跨一条边最多增加一层，最终接回32层。层高表不变，层数变化区的壁面X为−0.0549654—0.0274848m。

逐列终止不新增或移动任何点。原棱柱的3、2、1条法向边继续时，分别形成真实6节点棱柱、5节点金字塔、4节点四面体；全部结束时不再生成体单元。原面与层身份逐单元记录。该操作改变真实连接和体积划分，不是把已有坏四面体更名；每个新四面体仍执行SICN≥0.1。

## 实际验证

小例为宽3、深1的平面三角补片，层数沿X为1、1、2、3，层高0、1、2、3。一次进程0.672秒exit0：8棱柱、2金字塔、2四面体，解析体积5完全相等，独立构造的外边界和内面反向配对正确，最低一层保持。最小四面体SICN0.7745967，棱柱/金字塔全参考Jacobian为正。

真实唯一准备8.907秒exit1（监督器9.656秒，准备指标8.844秒）。产生605978棱柱、598金字塔、598终止四面体；313217个点被壳单元使用，保留的350632点原数组还含未使用的历史外域节点，不能把它当成新完整网格的节点数。全部9878原壁点、19752原面、最低19层375288个棱柱、2852尾缘扇棱柱及原远场连接/坐标精确保持。

新壳全参考Jacobian正、面配对完整，体积0.04512113277059464m³，对原壁与新外包络积分的闭合误差1.66e−14。外包络为原面逐列取层顶形成的19752三角面；尚未运行本轮自交检查，因此不宣称已经通过无自交门槛。

质量失败：598个新四面体中138个低于0.1，最小0.0731963。全部失败位于上层编号20、21、23，每层46个。独立行列式体积和逆矩阵SICN复核通过，与SVD质量差5.41e−16。坏单元法向高度0.233—0.494mm，最长底边7.319—11.570mm，高度/底边只有0.03176—0.04280。这解释了本次局部终止单元过扁；没有外域算法运行，不能把它归因于本轮Gmsh表现。

因此按事前计划停止。CGAL/Gmsh后续分支仅写入了研究入口，未执行、未验证，不能称完整流程已经可用。未修改默认网格或追改此前失败，原SST残差和7个omega下限点未重算。
