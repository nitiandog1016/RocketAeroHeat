## 2. 本轮真正新增的代码

[su2EnergyReference.py](../scripts/su2EnergyReference.py)定义显式气体/域/输运/能量参考的数据包，转换守恒量、通量、逐单元有符号残差及增量。内部固定e*=e+300000J/kg，外部仍hs298.15=0。残差必须转换后再求范数，SA的非守恒nu_tilde另存；旧OTH、未标记、非SI、错误形状和RMS残差拒绝。

原因是旧原生松弛以正内能量作分母，直接使用合法负相对内能会退化。全表最小Cv=715.1604414J/(kg·K)>0，e*(60K)=43997.3628006J/kg>0；在既有物性数学表域内固定坐标满足该前提。该平移不改变物理Cp、温度、热流或对外能量账，但会改变松弛路径，不能称逐步等价或保证收敛。接口本身不验证完整热力状态，也无法识别调用者故意错误标记的数据。

这还不是CFluidModel注册类，不曾启动新SU2。下一实现必须贯通初始化、所有气体setter、导数、边界、重启、热壁与原面导出；只换配置不能完成迁移。
