# 外缘物理场、诊断占位与上游失效（v56）

本次修正不新增收缩、横流、分离或底热模型。它纠正已有输出把域外定比热流向占位当成可用外缘温度及真实Kn证据的问题；未知上游仍阻断热流，不能提高门限来维持旧覆盖率。

## 状态分别表示什么

`solveExternalFlow.m` 在所选空气膨胀模型低于80 K下限时，原有定比热数值仅供几何准流线诊断。现在保留这些数值以核对旧问题，但另存物理场状态：

| 字段 | 含义 |
| --- | --- |
| `algebraicallyValid` / `numericallyTraceableFace` | 数值可用于现有离散流向诊断；不单独证明外缘物理场可用 |
| `diagnosticPlaceholderFace` | 已明确超出所选物性范围的定比热流向占位 |
| `thermalStateValidFace` | 当前外缘状态在其已声明的物性范围内；仍是有适用范围的工程近似，不是完整三维外流解 |
| `physicallyUnresolved` | 没有上述有效物理外缘；不因有有限占位数值而标成已求解 |

轴向波系推进重写面元后重新同步这些字段。查看器对占位外缘压力、温度输出NaN和未解状态；诊断数值不会以0.5 K“已计算温度”进入云图、周向曲线或全表面CSV。壁温边界与这些外缘状态各自保留身份。

## 连续介质和未知外流各自传播

`assessContinuumRegime.m` 只有在有效外缘状态上使用动理论平均自由程计算物理Kn。`diagnosticKnudsen` 另存原形式数值，明确不能作为真实流态证据。

- `directKnudsenUnresolvedFace` / `downstreamKnudsenUnresolvedFace`：有效外缘状态确实触发配置Kn门限及其下游。
- `directStateUnresolvedFace` / `downstreamStateUnresolvedFace`：外缘热力状态未知、域外占位或无法取得Kn及其下游。
- `unresolvedFace`：以上两类风险的并集。两者都阻断热流；未知状态不会因诊断Kn小于门限而获得放行。

沿同一已保存前驱图分别传播，仍检查路径成本严格递增。真实Kn超限保留原门限（最大0.01）及传播规则；本修正既不求滑移/稀薄热流，也不把未知状态称为真实稀薄区。

显示编号保留1–4流态和5上游有效Kn限制；新增6“外缘热力状态未解/占位”、7“上游外缘热力状态未解/占位”。热流面积报告保留原原因编号1–13，新增14“上游外缘热力状态未解/域外占位影响”。所选球鼻区域的专用原因依名称和实际偏移记录，不能用旧硬编码覆盖新原因。

## 剩余区域计算起点

主要缺口已确认在大圆柱→31°收缩→小圆柱的三维横流和再压缩接口。用全局自由流独立求两个状态会造成物性及总焓/熵链重置；在背风极母线理想二维假设下，20°再31°又可等价一次51°膨胀，所以仅改成前驱累计也不能证明修复。需要内部区域流动与能量闭合及相应经典几何验证，不能重新播种绕过未知带。

底热径向资料及鼻部/后体耦合分别见 `BASE_RADIAL_HEATING_RESEARCH.md`、`REMAINING_REGIONS_V56.md`。上述诊断和合同修正不是它们的替代求解器；第一阶段全面积连续流与最终跨流态目标保持不变。
