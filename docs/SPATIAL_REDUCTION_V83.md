# v83 空间五变量消元与跨组F耦合诊断

本轮沿用 `PATCH_HIERARCHY_V83.md` 的固定C/F预检，推进真实20°箭体三维区域求解。原物理CV、原NS、边界、物性和验收保持。数值模块已测试，但完整原C仍未收敛，没有新增正式热流面积。

## 完整程序和近似的范围

每个原局部组保留一个原CV的全部五量作为C点，其余原CV的全部五量为F点。全部原217272CV分成187749F及29523C，既不按物理场字段拆开，也不合并网格。

按F/C排列，完整矩阵写为[A B; E D]。M_F只包含原组内F-F主块的认证逆，跨组F-F项仍在完整原C中。因此构造的是明确的近似S=D-E*M_F*B，不能称完整A_FF的精确Schur。

固定预条件回代依次为：先求M_F*b_F，将b_C-E*M_F*b_F交给固定粗局部映射M_S，再用x_F=M_F*(b_F-B*x_C)补回F值。全部原矩形块、原C点对角及局部消元填充位置保留，不补对角或丢小非零。

完整MATLAB文件均已直接加入项目，带中文模块注释：

- `applyRocketRectangularCoupling.m`：原B/E/D全部矩形块作用。
