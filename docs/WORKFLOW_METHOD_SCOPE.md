# 五步骤工作台的方法范围说明（v56）

边界条件页和计算页增加可展开的“算法与适用范围”。默认收起，摘要先说明当前输入与所选方法的已知冲突；展开后说明几何、流态、物性和输入身份。展开、收起及切页只读取配置和已有几何，不启动自由流、外流、边界层或热流计算，不改变输入版本或求解编号。

这不是预先批准某个工况的适用性。说明中的几何初检调用现有 `estimateNoseRadius`，只核验球鼻几何；正式面元几何、连续流、肩部状态和物理剖面仍在显式计算时审核。界面不会因为摘要没有冲突就显示“方法可用”或“全面积已解”。逐面元最终方法、状态和范围仍从结果探针读取。

## 输入和求解的区别

- 统一或逐面元壁温是热流边界输入。当前单时刻定常链路不求解壁体温度；给定壁温、外缘温度、恢复温度、求解壁温分别展示。
- 给定背风Cp和给定尾底Cp不是尾迹压力解。Cp=0表示局部压力按边界取自由流静压，不能解释为程序求得“零绝对压力”。
- 选择 SAND93 底压后，给定底Cp控件禁用；原配置值保留，但所选关联不读取它，也不把它用作失败回退。
- 范围外的面元保留真实NaN及拒绝状态；分离、未连通外流或物性缺失不由零值填补。
- 外缘热力状态未知、域外定比热流向占位，与有效外缘状态的Kn超限分别记录。占位值不算已求外缘压力/温度，占位产生的大Kn也不是实际稀薄流证据；未知上游与真实Kn限制均阻断相应下游热流。

## 失败的恢复流程

计算失败时，计算页直接保留后端原始 `message` 和 `identifier`，同时提供“返回边界条件调整”。折叠说明、进入边界页再返回计算页都保留本次失败原因；编辑输入后由集中状态使旧失败/结果失效。用户重新确认边界并按计算按钮才重试。

SAND93选择不是必然抛异常：能完整识别底面、但关联不适用时，压力和载荷按后端真实未解状态保存；只有无法安全识别全部尾底目标等异常才停止链路。界面说明不篡改这两种状态，也不把几何审核拒绝简化成程序崩溃。
