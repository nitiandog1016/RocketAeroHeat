# 6.25 µs 步末的收支读回

首半步已正常结束并通过原生末窗，整步未过门。仅在半步已保存的初末场上核对当前质量与能量账。目标是区分远界流体状态积分对读取方法的敏感性与求解器实际加入方程的数值通量。锁定半步终帧 `7c783fbdee774c07729c86f6cc39daa778f84955a3111ef5de0fd10bea88f970`、原物理初场、原工况文件和 v366 的双线性求积。离线读回限单任务、30 s、1 GiB、10 MiB 输出，不启动求解器。

在同一远界折线上比较三项。先重现已有按边段高斯积分的远界流体侧质量与对流焓，再用各远界节点的两侧半边法向并按节点半径旋转积分。最后在相同节点、法向与权重上用固定版 SU2 亚声速远界公式重建特征边界状态，计算其单侧物理通量。用均匀来流验证闭合外界的正负抵消，并量化逐项的进出流与净通量。节点法向、轴线端点、静止网格与沿来流的求解器坐标须明确。三次均读同一时刻，均不代替原生左右状态间的 Roe 数值通量；原有保存场收支和全部原面结果保留。
