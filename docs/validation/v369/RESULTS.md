# M0.30 的首个步内收敛全壁研究场

从相同数值初场起算，**6.25 µs 的首半步通过了全部四个原始方程的末窗残差门槛**。该时刻的壁压与给定壁温下的对流热流已映射到 9,216 个原面，面积 0.935516891 m²。按 STL 积分的入壁功率为 **−1,045.057 W**。外壁全部向气流放热。工况为 5 km、M0.30、零攻角与侧滑，来流 255.68 K，给定壁温 300 K。时间从 v365 的数值初场起算，沿用全壁层流及轴对称假设。[原始工况与试算合同](PLAN.md) · [单步原面档案](evidence/surface.json)

12.5 µs 整步未通过。按事前合同结束该缩步配对，未启动第二个半步。相对 v368，新取得**处于同一次已收敛物理步的**壁压、热流及其交集各 9,216 面，面号 1–9216。用于最终交付的合格壁压、热流及其交集仍各新增 **0 面、0 m²**，三个新增原面集合均为空。同刻步长误差、原生全域边界收支、空间误差及转捩适用性尚待验证。五个飞行点的最终整件功率均未知。[其余飞行点的实算范围](../v368/RESULTS.md)

## 仍待解释的全域收支

在该半步内，按步初、步末体场求得流体储能变化率 +374.17 W；按旋转壁面求得入壁功率 −1,045.97 W。旋转曲面面积为 0.936287230 m²，原三角面面积为 0.935516891 m²，各自使用对应的积分权重。按保存场在远界的流体侧读数，远界向外总能流 −16,138.12 W，三项合计 **−16,809.92 W**，质量账差额 −0.0596563 kg/s。扣除来流总焓乘质量差额，剩余 −1,209.98 W。以上数值描述保存场的重构收支。[两步完整收支](evidence/runs.json)

同一批 109 个远界节点另做了读取方法对照。进出流各约 2,500 kg/s，净质量流依赖两者之差。均匀来流的节点积分净质量流小于 1.3 × 10⁻¹³ kg/s。只读流体侧时改变取样权重，使远界对流能流变化 −325.34 W；在相同的节点权重上重建特征边界状态，又变化 +3,126.59 W。固定版 SU2 在内侧与特征状态之间另计算 Roe 数值通量，并组装黏性贡献。单侧状态积分不足以证明原生残差如何闭合。[离线对照合同](BALANCE.md) · [节点与取样](evidence/far.json) · [SU2 远界实现](https://github.com/su2code/SU2/blob/7048fd35f56d4bf52e586429d6746a36a10255f8/SU2_CFD/src/solvers/CEulerSolver.cpp)

## 工作台与复现

工作台侧栏第 4 步的 M0.30 飞行档案优先显示 6.25 µs 的单步研究记录。选区可查区域积分；点选可查同一原面的绝对壁压、入壁热流、给定壁温、壁节点及第一层流体温度。实际绘制回执覆盖原面 26、1602、2017、6951、8900、9216，另核对了五点工况切换及旧尾部拾取。最终结果页仍按原全面积验收条件开放。[工作台](../../../rocketAeroHeatWorkbench.m) · [回执](evidence/checks.json)

在项目根目录运行 `python docs/validation/v369/verify_archive.py` 可仅用 Git 中的小型证据复核两份完整原生历史、逐面压力和热流、六区积分及远界读数。本机 `outputs/v369_validation/pair01` 保留原配置、初末场、日志和进程回执，`far01`、`process_ui01` 分别保留远界核对和工作台回执。复算使用 [short_step.py](short_step.py) 并指定该版本输出根下的新目录和 full、half1 分支，第二半步入口会检查两个首步。大型运行库和整域场留在 E 盘。发布基线及并发保护范围见 [计划](PLAN.md) 和项目约定。
