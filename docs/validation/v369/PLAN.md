# M0.30 的 12.5 µs 同刻热流对照

复用 v368 提交 `1058f4a89c0207ee0e02bfc3f0e59e348126eea9` 的简化民用试件，5 km、M0.30、零攻角、零侧滑、300 K 等温壁。保持全壁层流假设、原面编号、9,216 面及 0.935516891 m²。原网为 88 层、2 µm 首层、14D 远界，SHA-256 为 `f5656636b80e5a47a7d0cdb04b52f7a97e24fefb274f298ae1c31f3a42e4da68`。数值起点是 v365 warm2 的原生 9999 号帧，SHA-256 为 `998600a5f54616298783e53f78370ecd51b203f64e639835f598d4d8a7871346`。此前该稳态场未通过收敛验证。

沿用官方 SU2 8.6.0（可执行文件 SHA-256 `01f22d0c9de2e9a5feea666f67adf3957f503d2e14ca6fd998a9a28a11417bf7`）及 v366 time02/full 的配置（`2988b783e0eb9583d12f8f598b662ee994f1b60da3a954e6193a1a68e911563b`）。二阶空间重建、固定 CFL=3、后向欧拉、物性与层流壁面保持一致。第一组从起点走 12.5 µs；第二组从同一起点走 6.25 µs。分别核对进程、原生历史、保存体场与壁面、正性及实际初场。四个原生分量 log RMS 最后 20 行均须小于 −8。两组首步均通过后，才从首半步原生终帧再走 6.25 µs。任一首步未过门即终止缩步路线。

每个原生过程限 2 线程、150 秒、4 GiB、64 MiB 新输出，最多 2,500 次内迭代，顺序运行。保留起点和每个物理步的终帧、整段内迭代日志及原生回执。以连续历史核对末窗、是否曾有完整通过窗口以及此前固定 CFL 的同类结果。UI 检查最多单核 180 秒、4 GiB、20 MiB。独立目录内一次运行只创建新结果。

若三步通过，在相对于共同起点的 12.5 µs 对照所有原面壁压、热流、剪切，另列六区及两端圆柱面带的面积加权差、最大差、功率和回流面变化。沿用 v366 的局部热流 RMS <2%、功率差 <1%、壁压 RMS / 来流动压 <1% 条件，并核对各步同阶段储存量与边界收支。若失败，保存实际末窗及未过分量，工作台第 4 步给出原因，同刻差异保持未知。任何一次短步的数值结果均受人工初场及全层流假设限制。
