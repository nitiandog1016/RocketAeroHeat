# 为双支管名义银球建立可启动的流体体网

下一项使用本版已验收的名义外伸长度 1D、Re = 882、同一来流与银球测站。接头上有 112 个小于 5° 的原面，优先建立适形的交界环和近壁体网，并保留到全部原面及分区的保守映射。回到完整表面的压力和热流计算，不单独增加新的尾迹诊断页。[现有几何包](../../../cases/short_sphere/supported65.zip) · [接头质量与面积分母](RESULTS.md)

目前能闭合计算的是**名义有限长度装置**。首个可复算对照可明确选用两端封闭、暴露在空气中的短管，输出时把端盖的 p/q 和功率单列。这样流体湿表面包含 691.099217 mm² 球面与管外壁，以及额外 9.324636 mm² 名义端盖。原装置的接口面积身份及 1.0188 量热口径仍保留。球面温界沿用 Test 65 给定分布，管外壁和端盖若采用给定赤道温度，须在工况中注明这一对照假设。实验支管端温、夹具和沿程温度未知；名义管壁功率不能与实验的球体量热直接相加比较。

登记体网输入、物性、近壁尺寸、预算和停止条件后，在球面、正负管壁及两端盖分别核对面积、法向与同面编号。近壁体积为正、两个接头连续、分区映射守恒且全部端部有明确边界后，使用已核对的低速黏性求解入口启动该具名工况。任一边界或网格项失败即保存失败位置与数据，继续优先修复阻碍实际求解的环节。
