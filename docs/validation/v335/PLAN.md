# 双支管银球同一时刻的外域距离对照

基线为 v334 `ec457a3df93914b1dccbf753f4cbe2774ca0eac5`，物理基线为 v333 同刻整步和两半步。Short Test 65、Re = 882、球径 D = 12.7 mm，−X 均匀来流 1.237488 m/s，环境 310.99444 K、98767.398 Pa，温界和五区均沿用 v332。冻结准备回执 `22ef3bf27abf1a093fae6bfb03145fac1b9f401229f11a3d12042be19cd9a04c`、14D 体网 `a56a4c3dee8fd8bb74bc23ae4e85b71eaf7d5552dd99fccf8a6c8cb6a40789cd`、稳态终帧 `c23c9ca1beb024105c600642f3fb016c9b7077599c8cecff227eb6d3ab0dbe63`。本机查得同一带双支管试件的既有准备回执均为 14D。七站目标取 Short 原表 III；来源页注明实测风洞几何与球形计算边界的区别。

只试一种较远的半径 **20D**。从原 14D 湿壁至远场的每个单元、节点、编号、十层近壁、五区热边界及交叠均固定。在原 2,816 个远场片上向外接 16D、18D、20D 三层棱柱或六面体，新远场同角向离散。在原 261,708 点、397,824 单元上新增 8,070 点、8,448 单元。独立读回连通、标记、半径、体积及面锥正性和原网前缀。每一原面仍对应该试件的 32,480 面和 0.000700423853595 m²。用原通过的稳态帧在共同区作初猜，增加的外层从均匀来流和零超温开始；20D 的稳态收敛、热稳定与守恒均重新核对。

采用 v329/v332 稳态离散及 v333 相同步长的 BDF1，驱动只适配已核定的网格大小。稳态每段 200 步、最多 12 段、每段 ≤300 s、4 CPU 线程、4 GiB、450 MiB；连续两段末窗不改善即停。末 20 行六残差最大值 <−8，未限幅温差 RMS <1e−8，低阶和实际场的正性与温界逐段核查。保留初始、周期、正常终帧。在首尾端点复算独立释放壁行、共享远场通量、热稳定（<0.2%）及收支差（<0.5%）。只有合格基流才加同定义同幅度扰动。BDF1 整步、第一及第二半步各 ≤480 s；独立释放 ≤150 s，各 4 线程、4 GiB。按实际时间层核对储热、原生行、剪切、首层温度和壁面反力，采用 [v333 原门槛](../v333/PLAN.md) 并单列步长误差。

准备和后处理每项 ≤180 s、单线程、3 GiB，单次编译 ≤180 s、3 GiB。本机开始时 E 盘可用约 295 GiB，系统可用约 6.5 GiB。全轮独有新输出上限 9 GiB，原生推进与检查累计 ≤100 min。若实际网格、正性、能量、残差、时间或资源门槛失败，保留原始现场并停止该组合；实现问题依据实测原因单独更正。通过后在同一时刻、同一步长对照五区功率、外露银球折合功率、七站 Nu、热峰及全表面差，接入已有银球科研工作台。预期新增几何覆盖 0 面、0 m²。参见[上一决定](../v334/NEXT_DECISION.md)。
