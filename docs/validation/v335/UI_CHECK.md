# 外域结果的工作台与导出验收

在同一普通 STL 五步框架各运行一次标准米制整步、转向并重排的毫米两半步。首先绑定 14D，换至 20D 后检查原网、边界和结果失效；两套网应保留同一五区、温界、文件面号和物理时刻。观察 WebGL 绘制回执，核查七站表、两个差值场、最大差值面和截面。逐一核对全部 32,480 行 CSV 的数值、单位、基线帧与主帧；全表面面积乘导入网热流差之和应等于同刻向外放热差的相反数，误差 <1e−10 W。半步分支另核离线页与未求温度。实测 MATLAB 与原生求解串行，每个进程族限 4 GiB、240 s、单计算线程，输出表和页合计每次 ≤300 MiB。采用发布的 v334 前端隔离其他进行中的网页修改。
