# 让新安装能从银球 STL 生成单时刻结果

14D 至 20D 的对照已量化开放边界截断造成的变化。两个域均保留全部原面，两半步的外露银球量热偏差相差 0.01875 个百分点。下一项回到交付程序的实际依赖：从 GitHub 取源码的新安装可以直接读归档，但普通 STL 工作台的“从扰动初场重新计算”仍取用本机历史目录里面的专用体网、稳态帧和原生驱动。冷态网格生成、稳态验收和真实时间推进分别已有证据。[本轮结果](RESULTS.md) · [原生基线](../v333/RESULTS.md)

在独立安装目录为 **Short Test 65 的 14D 主工况** 接起这一条恢复路径。先以真实缺失依赖清单区分随版本交付的小型几何、可由程序生成的网格与初场、可从固定来源安装的内核。复用已通过的构建和求解入口，生成自己的基流、扰动和物理终点。工作台须明确区分首次准备、原生新算与读档。

验收时从没有历史输出的新安装导入指定 STL，核对实际进程及源身份，比较 32,480 面、五区功率、七站、热峰、物理时刻、同一步长和实验偏差，检查正常保存和重开。执行前登记下载、磁盘、编译及求解预算；某项源或门槛不成立时报告准确依赖或失败阶段。此任务优先解决用户能否在新安装生成同一单工况，其他物理模型和累计热量继续按各自证据排期。
