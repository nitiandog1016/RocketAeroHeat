# 固定低速风洞的同一物理时间层

基线 v353，提交 `ebc5f09b0add519f02fd4ff01c36d7904d291226`。仅用 0.05 m/s 轴向空气、300 K 环境、给定 300.001 K 壁温、恒密度恒黏度以及无浮力假设。原几何 9,216 面。复用 v352 已核对的 190,106 节点全周粗网、旋转初场与峰值 0.01U 的尾迹速度扰动；初始温度取 v353 粗热网的等温稳态场，物理时间从这组构造初态计起。

SU2 8.6.0 采用一阶对流与 BDF1，独立求解压力和三速度，不使用原生弱壁温焓。固定原外流边界和无滑移壁，保留真实种子与每个原生终帧。对照与扰动各取一个 0.125 D/U 步，再各取两个 0.0625 D/U 步到同一时刻（约 0.600 s）。每步最多 600 个内迭代、420 s、4 线程、4 GiB、400 MiB。验证实际输出字段、面号/坐标、壁速 <1e−9 U、正绝对压力、源帧、每一原生分量末 20 行均低于 −8。失败停在该分支，禁止使用失败末帧接续。初态与 BDF1 首个物理步的文件编号分别登记。

对通过的同刻动量帧将 x、径向、周向速度传至 v353 的 48 方位热网，核对壁面不可穿透、局部质量守恒和远界收支。通量投影总修正量按其 L2 标度单列（目标 <5%），离散自由行残差 <1e−8，温差无量纲界 [0,1]（容差 1e−12）。BDF1 计入流体显热储存，壁与远界收支相对误差 <0.5%。热步骤每次最多 240 s、1 线程、4 GiB、300 MiB 新输出。与两个半步比较，按同一原面核对总放热差 <2%、六区各 <5%、热流面积加权 RMS 相对差 <5%、压力面积加权 RMS 差 <0.02 倍来流动压。逐区热峰及周向差异另报；达不到辨识度的扰动效应保持未知。新时间层的联合结果通过前保留现有工作台默认主结果。

全六步与联合通过项完成后，在普通侧栏分别验收读档和“计算”。后者复用指纹相同的本机动量终帧，并重新计算六个显热步；在没有匹配可用的本机数据时从固定输入准备相应初场和动量步。读档验证限 240 s。复用已验收动量的入口复算限 600 s，整任务 4 GiB 和 1 GiB 新输出。归档回读和复算分别核对切换状态、相同时刻、热流和表压的原面探针、截面与全表面导出。默认仍为原稳态边界。
