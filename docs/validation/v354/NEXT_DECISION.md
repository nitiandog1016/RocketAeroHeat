# 核对 0.600 s 瞬态的近壁空间误差

继续以同一简化试件、同一组全周动量终帧及相同的物理时刻为目标。现有三维结果仅在粗热网上通过了时间步对照。下一步固定速度时间层和 14D 外域，单独加密热网的近壁与沿面间距，核对温度初态采用同一粗网基流、同一热边界求得。不得将已有细速度场替入后把差异全部归为热网误差。

比较原面壁热流、六区功率、鼻端热峰、四个平底环带以及扰动减对照的周向热信号。事前冻结准入误差及每进程 4 GiB 预算，先测一个细热步的内存、质量投影、储热和全域收支，再决定是否完成同刻配对。达到该单时刻的空间核对条件后返回完整工作台。对真实尾迹、实验精度及更长历程继续单独记账。[当前结果](RESULTS.md)
