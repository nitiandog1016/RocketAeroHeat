## 计算前固定的检查

1. 正状态、同阶段EOS相对误差<2e−12、独立热梯度相对误差<2e−6，给定Tw311K由输入和边界算子确认。保存壁面流体T、与311K的差值独立报告。固体求解Tw保持未知。v149“两更新时流体节点T精确等于Tw”的原失败归档。
2. 原四项logRMS均低于−8。新增密度/能量体积加权尺度化RMS，单元中位控制面积A_i，L=1m，分别采用A_i*rho_inf*U_inf/L和A_i*rho_inf*U_inf*h0_inf/L归一化，预设各<1e−5。原生RHS的二维积分定义与旋转加权报告清楚。
3. 全边界物理质量通量和能量通量采用原线段、分段线性节点量及2*pi*r权重。开放边界包含WLS重构的黏性功和导热，壁面使用已核对的原生热流。轴对称应力散度使用径向速度/r项。该后处理属于独立物理通量积分，原生离散残差另列。质量/能量净缺口各低于入口相应绝对通量1%，同时报告两种积分定义的范围。先用常量流及线性温度解析真值检查积分和梯度。
4. 最后至少1000更新的相同测站最大压力变化<1%、热流变化<2%、整周热功率变化<2%。分母分别取max(abs(终态值),576Pa)、max(abs(终态值),9300W/m²)，功率取max(abs(终态功率),9300*完整壁面积)。同时报告壁剪、分离/再附及局部热峰。y+99分位≤1。
5. 实验逐测站匹配，重复压力点按原合同排除，共24压力点、27热流点、21上游剖面位置。压力逐点相对误差RMS≤10%、最大≤20%。热流RMS≤20%、最大≤30%，峰值幅值差≤20%、位置差≤0.01m。上游U/Uref剖面绝对RMS≤0.05，总温比绝对RMS≤0.03，上游局部压力差≤5%、热流差≤20%。这些为本项目预设比较门槛，实验约±10%估计和参考量共享相关性另列。
