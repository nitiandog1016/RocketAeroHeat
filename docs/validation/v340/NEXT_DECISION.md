# 用反求壁温闭合空气导热系数

银球功率边界已求得 341.527781 K。现有膜温导热系数仍由实验平均壁温决定，限制了这个入口在未知表温工况下的使用。按本轮求出的壁温更新一次膜温，同一关联的导热系数变化 −1.497%。它对原面热流和反求温度的影响需要实际复算。[本轮温度与功率](RESULTS.md) · [导热系数定义](../../../scripts/shortSphere65.py)

下一项在同一 14D 名义试件、Re = 882、0.8271231935 W 球体功率下，让程序用来流与当前候选壁温形成膜温，更新导热系数及对应的 Pe，迭代闭合壁温和热输运。密度、由来流 Re 确定的黏度、湿空气比热及支管同温假设各自保留来源。实验平均壁温只在最终对照中读取。初次热解的物性由已知来流与选定试算温度建立，初值来源单列。

复用原面绑定、已有稳态流体初场、独立壁反力和工作台量热入口。先登记源文件、实际配置、最多候选数与预算。用实际对流热流积分闭合球体功率，并以最终壁温重新计算膜温导热系数和 Pe，核对与原生输入一致。报告相对 v340 的温度、五区功率、热峰、七站和实验误差。只接受同一原场的末窗、正性、温界、守恒与最终原生复算均通过的结果。若资源或门槛失败，保留回执并说明具体组合。形成自洽解或明确排除这条组合后退出本项。
