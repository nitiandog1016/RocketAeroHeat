# 一次壁面切向分辨率对照

在同一 Short Test 65 双支管工况上，以十层近壁网为基线，检查绕支管轴的周向间隔对背风两站换热及流向区间的影响。现有两网只改变了壁法向间隔，+Z 测线的流向变化都落在同一对相距 5.625° 的原生节点之间。两站分属顺向与反向区，七站换热 RMSE 仍为 4.659 Nu。对照优先改变直接限制这条测线角分辨率的离散方向。[本轮区域证据](RESULTS.md) · [法向加密对照](../v330/RESULTS.md)

下一项只做一档切向加密。目标是把上述区间一分为二，并保留旧射线。沿用十层近壁分布、14D 外域、同一几何与壁温定义、同一求解器和离散方法。先证明新壁片与 32,480 个原面的同区交叠、完整分母与功率可闭合，检查支管多边形及端盖的物理位置，记录外区随周向分辨率产生的改变。准备前按实际节点数登记内存、时间和磁盘预算。任一几何、传递或资源条件不能满足，就记录具体差异并停止这档比较。

若可推进，执行一次有预算的同工况稳态求解，保留原有残差、热稳定与边界守恒门槛。在同一组原面和真实七站上核对两处背风 Nu、变号区间、反向面积、25,055 号面与近峰集合、五区和整件放热，并接入工作台。本次对照只量化一档切向变化；实验误差还可能受名义支管温界、入口扰动与非定常尾迹影响。比较取得结果后重新决定主线。
