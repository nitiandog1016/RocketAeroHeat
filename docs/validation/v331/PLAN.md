# Short Test 65 双支管银球两网的近壁流向

一个原面若由投影符号相反的多个源壁片覆盖，数值平均仍单列显示，符号归入跨片混合。检查热峰和测站原面的共边邻居以及反向区连通分量，保留主分类和可重叠的原因标志。

基线 v330 `923acc184349702c31da1ff0da548ba1014d18ad`。只读 Re 882 民用试件的两个稳态终点，五层 `909f3fee3db8a16437e5b268bd823ae5707d17b9723503d717d0445f0c732490`、十层 `250c3b641f2551345b19a8143482f19743e198ea7930fb6c9056de7d851dbfa9`，以及 v330 壁面单位回执绑定的同刻表面 VTK。保留 v329 的 32,480 个原面与完整面积、两档热流、公开试验七站及 v330 定义的最高 1% 幅值带（各网 ≥99% 峰值）。本轮没有新流场推进。[上一决定](../v330/NEXT_DECISION.md)

逐节点核对 VTK 坐标、压力及源帧。从原生壁面摩擦系数得到壁面对流体剪切的反向作用（流体对壁面）在局部切面上的分量；按来流动压换算 Pa。首层流体速度按来流速度定标为 m/s。壁片上先切向投影、按节点对偶面积平均，再用 v325 同区交叠权重传递向量至原面，最终投影到实际三角面切平面。顺流基方向为 −X 在该面切平面上的单位投影。两有符号投影均负为局部反向、均正为顺向。记录各自的有符号值及切向模。VTK 的 Cf 精度用局部输入向量模的加权和乘 1e−6 加 64 倍机器精度作为符号判据的绝对带；速度从双精度重启场读取，按 64 倍机器精度及实际速度尺度判零。原面或支撑其插值的源壁片接触跨区共享顶点，均标注棱边影响，不在这些位置强判方向。切向来流模 ≤1e−10、球面迎/背流轴点邻面、符号接近零、两判据冲突各自保留，具体重叠用单独标志追溯。

七个试验测站另用上一版登记的真实原生弦端和权重插值矢量，在球面名义测站法向下投影，报告与对应原面平均量的区别。对 +Z 测线用相邻原生节点对顺/逆流的变化给出角度括区。对粗细网分别统计面积与正负热量，核对总分母、五区、同面交集及热峰附近的判定。局部反向只描述相对来流切向的分量。独立核对基向量、尺度和映射，抽查三维邻域与七站位置；全原面数值和未知理由接入现有离线工作台。源身份不符、重复映射、分母/功率不闭合或两套独立重算不能对应即停止交付。后处理、独立复核各 ≤120 s、1 CPU 线程、2 GiB；仅新增界面验收 ≤180 s、4 GiB。磁盘小结果与验证总预算 350 MiB，复用既有输入。
