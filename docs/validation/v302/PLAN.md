# 带线热敏珠的整件净对流功率边界

从 v301 提交 `8aeb277d9239b5d96c7d87b23e35664614b2b7f1` 接续，已核对本地与远端 main/v301、并发修改和原生进程。v302 空闲，E 盘可用约 326 GiB。按 [v301 下一项](../v301/NEXT_DECISION.md) 只用 [v300 已验收的带线加密网与一阶场](../v300/evidence/inputs.json)。空气 3 m/s、293.15 K、101325 Pa，10,272 个原面，七个暴露区域，12 K 参照温差与整件放热 10.878085695936079 mW；冻结物性与轴向对称稳态。输入功率是整件传给空气的净对流份额。积分包括引线侧面、接头、线端和珠面。所有暴露面共用一个稳态集总壁温。

登记一次半温差独立冷态。保持网格和初始流场，在自己的运行目录将原生强标量壁值由 1 改为 0.5，同时令弱焓壁边界及冷初场对应一致；强标量的量纲温差仍为 12 K，壁面实际为 299.15 K。按实际原生节点读取同阶段反力，逐原面与半倍参照热流对照。延续 20 次，核对现场原始装配与独立远场热量账。正式计算单线程、720 s、2 GiB、180 MiB、最多 7000 次，每 500 次及正常终点保存；反力/延续/独立单步各 60 s、2 GiB、180 MiB。复用已验收的 v300 同节点数观察器并核对文件指纹和同态单步输出。准备、审核及 UI 每批 180 s、4 GiB、200 MiB。超限或原生失败保留现场。

冷态及完整保存帧核对全域强标量 [0,0.5]（容差 1e−12）、正压、无滑移和壁值；两终点六项残差末 20 行各 <−8，20 次延续放热变化 <0.2%，独立远场收支差 <0.5%。同面反力积分与节点总功率一致。按 v285/v286 的线性对照门槛，半温差逐面相对热流误差及总功率相对误差各 <0.05%，首层温度误差、半温差功率反推壁温误差各 <0.001 K，压力差 <0.001 Pa。本次验证对应数值关系，实验对照仍只对应参照珠部平均换热。

在现有五步侧栏选择整件净对流功率，以 4 mW 演示七区全表面交付。验证 0、4 mW、上限、超上限和无效输入；核对给定/求解温度、功率方向、原面编号、冻结来源与状态失效，检查云图、探针、截面和导出。给定壁温老工况继续可用。原生半温差与功率反演独立核对通过，并交付实际工作台后结束。
