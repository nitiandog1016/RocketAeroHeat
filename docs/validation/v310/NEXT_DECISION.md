# 补齐带线热敏珠侧向来流的三维计算入口

同一轴向工况的珠部平均工程预测已经接入工作台。下一项回到全表面预测，在同一民用风洞试件上计算**侧向吹风**。保持带线 B 珠、10,272 个原面及面号、293.15 K 空气和 299.15 K 给定壁温；试件长轴沿 +X，来流取 [0, −3, 0] m/s。侧向吹风应能区分同一轴向位置的迎流和背流面，适合验收用户要求的周向压力与热流曲线。此工况单独建账。[当前轴向试件入口](../../../runThermistorLeadWorkbench.m)

现有 30° 轴向周期复制不能表示这一路侧向来流。第一步从已发布的带线实际网检查能否构造完整 360° 流体域，将全部原壁逐面映射至本域，核对轴节点、接缝、壁层和真实风向的外边界。用固定工况构造冷态输入，在运行前登记实际单元数、CPU/内存/磁盘预算和停止条件。若横流对称性或出口边界条件不足以闭合，先记录具体缺口，保留原轴向结果。具备条件后由程序在本机调用既有低速内核，保留原残差、热稳定、温度界限与边界能量账，检查是否需要转入有明确物理时刻的非定常计算。

交付时在同一工作台显示各实际方位的壁压、入壁热流、首层流体温度和七区放热，并导出一条随圆周角变化的同截面曲线。侧吹工况记录自己的原生源帧、边界和适用范围，珠部工程对照及实验精度按风向分别核对。
