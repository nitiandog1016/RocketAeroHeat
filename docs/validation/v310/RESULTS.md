## 算法、适用范围和原文差异

式（14）定义 L = 2V/F。采用表 1 的 B 珠代表长度 0.3430 mm、名义珠部面积 3.094 mm²、偏心率 0.53。按式（15）用名义旋转椭球重建的代表长度约为 0.32848 mm，工程预测采用实物表列长度。三维珠部功率按珠面及两个接头的实际面元积分，两种方法的平均系数均按表 1 面积与实际温差换算。[原论文，第 811、814–817 页](https://doi.org/10.1299/kikai1938.25.810)

膜温为 (299.15 + 293.15) / 2 = **296.15 K**。程序在该温度和实际压力调用内部干空气物性。理想混合气密度为 1.191924 kg/m³，Lemmon 低密度输运给出的运动黏度为 1.538426 × 10⁻⁵ m²/s、导热率为 0.02606592 W/(m·K)。物性表温区为 60–2000 K，在此次膜温对应的项目压力上限为 259738 Pa。三维层流解沿用其归档的恒物性，方法间差值同时包含物性口径、实际几何及离散影响。[物性入口](../../../phaseAwareAirState.m) · [输运原始来源](https://doi.org/10.1023/B:IJOT.0000022327.04529.f3)

Re_L = 66.8866，Gr_L = 0.033876。原论文在 Re_L > 20 的数据中观察到浮力影响已弱。本实现取正文数据范围与强迫分支的交集，20 < Re_L < 800、10⁻⁴ < Gr_L < 1.4。在本工况，式（32）的浮力项与惯性项之比 4Gr_L/Re_L² 为 3.03 × 10⁻⁵。用式（16）求几何极限项，再取 Nu_L = Nu₀ + 0.29√Re_L，得到 Nu_L = 3.0337793。最终 h = k Nu_L/L，Q = h F ΔT，正 Q 表示珠部向空气放热。[完整 MATLAB 方法](../../../thermistorBeadMeanConvection.m)

**表 1 的末位一致性检查未通过。** 式（16）在 ε = 0.53 时给出 Nu₀ = 0.66203744，表中为 0.664。用旋转长椭球的稳态导热形状因子、体积和表面积独立重建，得到 0.66203744；无量纲与量纲写法均复现 230.548806 W/(m²·K)。保持其余输入相同，代入表值使工程预测的珠部放热增加 **2.769 µW**，约 **0.065%**。原文差异原因未知。默认值取公式，配套导出同时保留两种极限 Nu 及功率差。[独立复算](verify_methods.py)
