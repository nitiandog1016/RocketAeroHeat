# 下一项：从五步工作台运行一个导入的完整低速试件

CM-011 的 +10° 工况已在其全部原面取得压力、热流和流体温度，真实截面的周向差可重现。当前计算入口仍由预设母线生成模型。下一项让用户从主工作台导入同一民用试件的 STL，按“输入模型、生成网格、添加边界条件、计算、查看结果”实际运行一次，无需指定旧计算目录或手动组织外流数据。[本轮结果](RESULTS.md)

用本轮以米为单位导出的 CM-011 STL 做端到端回归。先检查现有表面导入、内部体网和单工况调度入口，明确哪些步骤已经支持。保留导入文件自己的三角面和编号，登记与求解边界的几何误差、映射及局限。只有确认导入几何和工况与已有支持范围相符，才能选择相应适配器。显示的工况、云图、点选和截面 CSV 须来自这次点击计算产生的结果。任何局部坐标、单位或输入变更都要使旧结果失效。

这项验收优先于新增标准模型、累计热量或整段轨迹。+10° 的周向/近壁网格敏感性及实验精度仍待独立检查，保留原记录和各工况自己的面积分母。
