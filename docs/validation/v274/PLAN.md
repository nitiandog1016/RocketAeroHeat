# CM-011 低速试件在 +10° 入射时的全周壁压与热流

基线为 v273 提交 `273e599de9ff058d264481eedcad8c0a8765c443`。本次固定直径 3.949 mm 的 CM-011 光滑等温试件，空气 300 K、0.1 m/s、壁温给定 300.1 K，β=0，α=+10°。按 calcFreestream.m 的约定，来流方向为 [−cosα,0,+sinα]。迎流侧取 −Z，背流侧取 +Z。同一母线、四个几何区、14,140 个原三角面及其完整面积沿用 v271 细网试件（body.json 07588689…）。取锥面中部的一条预定母线环（细母线从零起第 28 行），从同一 x 的原生壁节点读取两侧和中间周向点，同时核对工作台按原三角面取截面的曲线。

只有 XZ 面保留镜像对称，求解 Y≥0 的完整半域，沿方位 −90° 至 +90° 用 12 个区间。两侧共面边界合并为一个平面对称标记；轴线为共享节点，允许沿 +Z 运动。全域热功率取半域原生边界的两倍。体网使用 v271 粗母线 49 站、24 个法向层、12D 外域。按母线参数与方位插值，将三维解映射到同一细网原表面，极点合并。单列体网和原面分辨率、曲面近似及未验证的空间误差。固定 SU2 8.6.0 官方程序（01f22d0c…），定常不可压层流动量和能量方程。初态保存全部五个变量，采用给定来流、壁约束和均匀流体温度；工况在本地程序内生成。

网格检查限 60 s、1 CPU、1 GiB、32 MiB。求解前锁定网格、配置、初猜、原几何与程序。单进程、1 线程，1 次最多 12,000 次更新或 720 s，2 GiB、160 MiB。固定 CFL 18，保存初场、每 500 次的原生重启动和壁面及正常终点。沿用五个原始 log RMS 最后 20 步均 ≤−8、壁热相对极差 <0.2%、物性、有限性、无滑移和对称面检查。只要资源超限、进程失败或输出身份不明即保留当前记录。若达时间上限但已有完整帧且下降速率支持，可在不改物理或离散的前提下登记一次有限接续；禁止无界扫参数。
