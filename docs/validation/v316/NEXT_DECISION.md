# 在同一 B 珠测点检验引线的热边界

独立冷启动已经覆盖七区的 10,272 个原面。珠面与两个接头均通过两种起步的逐面数值对照，模型珠部放热比图 7 中心读数折算值高 2.12071 mW。两种起步对珠部平均 h 的影响约 0.00011 W/(m²·K)。两根引线及端面的局部数值差异另有 648 面的台账，二次读数仍有 624 面超差，继续保留该限制。[本轮结果与超差位置](RESULTS.md)

下一项选同一个 3 m/s、12 K、96 档名义侧吹测点，检验“全长引线与珠面同温”的假设。先依坪内、佐藤第 811–813 页的实际线材、尺寸及支线散热式（5）至（13），核对珠端、支架端及论文电热扣损可确定的输入。将珠面给定温度、金属线的轴向导热、流体侧逐段对流功率与端部热流分别列账。两根外露线及端面当前向空气放热 1.21831 mW；沿支线导出的功率需要由线内能量方程单独求出。[论文与测量口径](https://doi.org/10.1299/kikai1938.25.810)

沿用同一空气动力场和原面，优先检查固定 SU2 标量壁边界对非均匀壁温的实际支持，再实施一个来源可追溯的引线稳态热边界对照。采用现有均温解作为控制，比较珠部平均 h、两线轴向温度、各端导热量、七区功率与同阶段守恒。支架温度或有效长度若缺少实测，只在有依据的区间内报告敏感性，标明各工况的给定量与求解量；缺少界限时直接指出欠缺的量。禁用从 v316 壁反力逐面乘温差比来代替非均匀热边界求解。

原面编号、分母、原残差、热稳定和收支门槛沿用 v316。取得一个可以分辨的物理对照后结束本项，记录引线假设能解释多少珠部放热差额及仍未知的部分。实际新计算依照输入、资源和停止条件另行登记。自绘模型维持各自的原面台账。
