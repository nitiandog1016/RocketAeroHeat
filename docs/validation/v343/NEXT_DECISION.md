# 把原壁与边界选择接入单工况计算输入

下一项从 RFZ-REC 的网格和边界页生成一份可重开的独立输入，让求解器接收与几何页相同的 130,044 个原面编号及壁面分组。对九处开口明确采用完整 CAD 还是论文封盖域，分别登记实体壁、参考用人工边界以及二者的面积。验收完整 CAD 时，封盖内侧 14,982 面仍有壁压和热流责任。内侧等温假设如被采用，须作为该项目工况的给定条件展示。参考点值仅用于后续对照。[本版归属表](RESULTS.md)

以工作台在同一工况中完成原面网格确认、壁面条件确认和输入重开为起点，进入独立计算。检查编辑关键条件后旧结果失效，再按实际网格登记求解预算、终止条件与输出内容。旧银球与自绘模型仍使用各自的分母和结果。
