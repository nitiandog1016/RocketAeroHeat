# 带线 B 型热敏珠的给定壁温输入

基线 v307 为 `66c1e1ee9e38656b65d010fcc32a7f18cbba4d54`。按[下一决定](../v307/NEXT_DECISION.md)使用 3 m/s、293.15 K、101325 Pa 的轴向空气。第二、第三档分别采用[第二档](../../../cases/thermistor_b/leadsMidbody3.json)与[第三档](../../../cases/thermistor_b/leadsThird3.json)清单指定的 305.15 K 参照包。面元数为 10,272，总面积为 3.19665061256752 mm²。半温差独立冷态表取 `outputs/v302_validation/native01/direct_wall.csv`，SHA256 为 `576007df9484f1d5012044996fdd35c927f51bf1dc85adbebbb53243d3e471c8`。

在侧栏输入 299.15 K，逐面核对两档的压力、正号入壁的热流、首层流体温度、给定壁温，验收七区及全件功率、探针、固定 X = 0.172 mm 的截面和逐面 CSV。第二档与独立冷态的逐面相对热流差和总功率相对差均须小于 0.05%，壁压和首层温度最大绝对差分别小于 0.001 Pa、0.001 K。第三档按本域参照核对。另测环境壁温、另一内部值、原端点、拒绝非法值和切换功率使旧结果失效。305.15 K 专属原生分带账仅在对应条件提供。

复用既有原生终态。侧栏验收每次一个 MATLAB 单计算线程，子进程族限 4 GiB、每次 300 s，导出限 450 MiB，E 盘可用约 325 GiB。逐文件校验输入，保留失败回执。指纹、终态、分母或验收阈值异常即停下该次核对。小型回执随源码发布，原面导出及三维页保存在 E 盘。实验精度沿用图 7 的珠部平均量，逐面联合实验支持面积单列。
