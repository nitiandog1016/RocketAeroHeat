# 固定SST更新与Jacobian范围复核

2026-11-01。复用v128实际场，不运行三维候选；9份相关源码与已核验的固定上游归档逐字一致，详见[source_binding.json](source_review/source_binding.json)。归档来源commit `7048fd35f56d4bf52e586429d6746a36a10255f8`，官方8.6.0运行包的二进制身份另由每项原生进程回执绑定。静态源码路径不等于逐点运行跟踪。

## 1. “精确湍流Jacobian”不是完整SST的精确Newton

调用链为CTurbSSTSolver.cpp:304 → ScalarFluxOptions::Interior → scalar_edge_flux.hpp:234 → turb_sst_edge_flux.hpp:134。选项打开时追加的是交叉扩散系数对两端omega的边导数。它不在独立的CSourcePieceWise_TurbSST源项实现中使用。

源项turb_sources.hpp:1022—1025的隐式矩阵保留耗散项导数和k—omega耦合，omega对k的对应元素为零；生产限制器、混合函数和全部流动耦合并没有因该开关而完整求导。不能将配置模板的笼统名称当作刚性源项已全面修复。

该边修正系数含(1−F1)，因此在F1趋近1的近壁极限趋零。v128未保存全部混合函数/线性增量，本轮没有声称146个节点的实际系数均为零，也没有把打开选项直接列作已验证修复。上游实现可查[固定8.6.0边通量](https://github.com/su2code/SU2/blob/v8.6.0/SU2_CFD/include/numerics/turbulent/turb_sst_edge_flux.hpp)。

## 2. 更新比例、正值与停滞须分别考虑

CTurbSolver.cpp:280—315按当前rho*k、rho*omega的相对线性增量取同一个松弛系数。每个变量的分母含EPS；系数小于1e−10时置零。CTurbSSTSolver.cpp:878调用MAX_UPDATE_SST，CConfig默认1.0。

CScalarSolver.inl:525—560使用当前密度同时乘旧值、除更新结果，然后调用CVariable.hpp:510—516作上下限裁剪。默认未启用DLL时，k下限1e−10、omega下限1e−4；修改LOWER_LIMIT_*因子并不会改变这个分支，不能以配置名臆测实际下限。

减小MAX_UPDATE_SST可以限制负向跳变，但也会降低松弛系数；在已有极小正值/巨大相对增量处可能更早触发取消更新。故“更保守”不等于能使已有下限口袋恢复。k和omega共用系数，一方刚性也会压住另一方。没有逐点LinSysSol和松弛，不对原生每个节点的实际分支作过度推断。

下一项三维改动需同时解决有依据的壁法向初态和保持正值的更新，不再调图口袋选择器或抬物理下限；任何候选都须同源控制、预算和事前收益指标。本轮未更改任何求解器源码、运行包、实际三维场或默认数值参数。
