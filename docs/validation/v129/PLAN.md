# v129事前计划：公开冷壁平板热流实际对照及SST机制复核

2026-11-01，v128已交付后制定。真实20°原面、研究场、默认方法不变。本轮不重跑三维空间诊断、口袋初猜或CFL扫描；用一个有预算的公开热流算例补上长期仅有输入合同的缺项。

## 数据与比较身份

参考TMR的Zhang/Duan/Choudhari 2018 M6Tw025，原始文件复用v119及其SHA；不是实验。参考只提供选定下游截面的统计量，没有可直接施加的完整DNS入口。不能把该截面当入口后又在同处计算误差。

本轮改用**相同来流/壁热条件、相同Re_theta的空间发展平板SST对照**：rho_inf=0.044kg/m³、U_inf=869.1m/s、T_inf=55.2K、Tw=97.5K、gamma=1.4、R=287、Pr=0.71、mu=1.458e-6*T^1.5/(T+110.4)。实际Mach由U/T计算，头部5.84为舍入值。SST-2003m，Prt=0.9，I=0.01、mu_t/mu=10是明确的研究入口假设，未测、无转捩模型。原生均匀入口和前缘发展，不导入DNS流场，不宣称原DNS域复现。不同入口历史及Reynolds均值对Favre均值的差别必须保留；后续需要入口敏感性。

参考测站Re_theta=2121，xa=88.6*1.3mm属于DNS入口坐标，不等于本平板距前缘坐标。按本解每列积分rho/rho_inf*(U/U_inf)*(1-U/U_inf)dy求theta，唯一内插到Re_theta=2121；只在0.05L—0.85L寻找上升穿越，无穿越/多穿越拒绝匹配，不外推、不按热流选测站。比较该站的原维度y剖面、Cf和入壁正热流。

主热流参考由原头部-Bq=0.14、utau=33.8m/s与原剖面壁压重构的rho_w、给定Tw计算；Bq末位舍入±0.005约3.6%，不作精确实验置信界。另列原剖面首3/4/5点多项式壁导数的热流/剪切，不用事后挑选最接近解的参考。给定Tw与流体节点T分开，SST含k能量及热阶段使用既有审核。

## 唯一实际运行与成本

MATLAB现有平板生成器新增可选R/Pr，旧默认保持；新完整文件直接更新。80×80单元（含上游），L=0.35m，上游0.02m，高0.04m，首层0.5µm。流向-X；官方固定SU28.6.0，现有AUSM/二阶流动/一阶湍流，原生MAX_UPDATE_SST=1、精确Jacobian默认NO保持。本轮不在该基准同时调湍流更新参数。

一次原生任务：2线程、最多10000更新/720秒，先到者停；仅保存5000及最后场（不足则按实际保存），无续跑/重试/网格加密。MATLAB一次真实调用/读取，使用当前源码锁；终态后只读比较/作图。计划总原生≤720秒，研究目录含别名≤100MiB，证据≤15MiB；不编译、不生成工程包，不清旧outputs。

## 事前判断

1. 输入身份、真实终态、具名状态、EOS/壁热梯度/有效y+按既有门槛；不因原生exit0判合格。
2. 原四方程-8门槛保留；最后200步热功率极差/均值≤0.5%。未满足仍可展示带明显未收敛标识的数值差，不能宣布DNS一致。
3. 唯一匹配站及邻站y+≤1，壁压偏离来流≤2%，局部|x/p*dp/dx|≤0.02。任一不满足则不作零压梯度合格比较。
4. 只有以上通过才报告“本单网格初筛通过/失败”：热流、Cf相对参考差各≤15%，0≤y≤1.5delta_DNS上U/U_inf的RMS差≤0.05，T/T_inf的相对RMS差≤10%。门槛是工程初筛、非实验误差界。还没有网格/外域/入口敏感性，任何结果都不新增箭体资格面积。
5. 不达标准则保留全部证据、停在终态，按实际机制决定下一步。不得借本例失败恢复盲目三维续算。
