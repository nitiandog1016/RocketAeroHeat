# 下一项：在 B 型热敏珠上求稳态热平衡壁温

v285 已提供给定壁温到整珠放热的定常映射，且 15° 网的中间温差和零温差已用直接原生计算核对。下一项给用户另一种边界输入：珠体可供空气对流带走的净加热功率。保持 3 m/s、293.15 K 空气、名义等温珠体与恒物性，用单时刻热平衡求均匀壁温，再取得同一原面的压力、热流和首层流体温度。[给定壁温与功率的关系](RESULTS.md)

只接受使解位于 293.15–305.15 K 支持范围内的净功率。原试验涉及引线与辐射损失，应显式区分电输入功率、已扣除其他损失的净功率和空气侧积分。工作台要区分「给定壁温」与「由净功率、等温集总假设求得的稳态壁温」，保存方法和源场。用零功率、中间功率及越界输入验收，独立核对各原面对流积分与给定功率。由既有数值功率反求原温度只证明数值闭合，实验精度按独立测量另计。实施前登记具体输入、预算和停止条件。本项不涉及累计热量、轨迹或材料瞬态。
