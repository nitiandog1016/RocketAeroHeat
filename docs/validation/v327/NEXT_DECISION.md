# 下一项：在同一银球试件上验证按节点温差余量限制的守恒修正

结束“逐边以两点项幅值为上限”的路线。实际八边和斜网解析反例表明，只要两端恰好等温，这个上限会把真实横向扩散一并去掉。下一项采用一个不同的限制依据：先得到有界的低阶节点更新，再按每个节点距温差上下界的余量分配允许的通量修正。同一条内部边由两端共同决定一个系数，保留成对反向的通量。只针对本低速双支管银球的主温差标量。[已关闭候选的反例](RESULTS.md)

已查 OpenFOAM Foundation 13 提交 `18870c24d21c6b982e2cdec27b2f59738cca5f90` 的 MULES 源码（GPL-3.0-or-later）。`limitCorr` 使用当前低阶场、体积、ρ/Δt、源项、基准通量、待修正面通量和上下界；内部修正系数依据通量方向取两端允许系数的较小值。随后以受限通量的离散散度更新。采用这个有界修正步骤作为参照。OpenFOAM 采用单元中心控制体，SU2 此处使用节点对偶体与局部隐式伪时间步，二者的更新质量、边界和阶段需要显式对应。本版没有调用 MULES，也没有验证其在本试件上已具备有界性或仿射精度。[修正与更新实现](https://github.com/OpenFOAM/OpenFOAM-13/blob/18870c24d21c6b982e2cdec27b2f59738cca5f90/src/finiteVolume/fvMatrices/solvers/MULES/CMULESTemplates.C) · [内部面与边界系数](https://github.com/OpenFOAM/OpenFOAM-13/blob/18870c24d21c6b982e2cdec27b2f59738cca5f90/src/finiteVolume/fvMatrices/solvers/MULES/MULESlimiter.C)
