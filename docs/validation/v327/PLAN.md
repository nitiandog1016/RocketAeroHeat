# 双支管银球的逐面扩散限制准入

基线 v326 `a694e4e3af31270ff018f720cab943792407aedd`。对象仍为 Short Test 65 名义双支管银球，Re 882、五区 32,480 原面、700.423854 mm²。先检验 v326 选定的系数 0.5。冻结扩散系数 1/Pe，复用 v326 归档 `37b679a7181e5d1a45855242f7caef298f8387a1a47e4ebd6fa882562ca9dca5`、工作台数据 `1c4fb8cff2b83f23ac4343b602b9b28a1c9d0f3026a4443928f366cc0b3c3a05` 与 SU2 标量通量源码 `028264b073e431948569d690a06cf89ae7086ea1a304ccd316d6f71c8cce33ab`。[候选及固定上游源码](../v326/NEXT_DECISION.md)

使用常量、三个坐标方向和一个斜向仿射标量场，先按 SU2 的沿边投影装配两点项，再把剩余梯度修正的幅值限到两点项的幅值，两端共享同一通量。与独立解析面通量比较。在节点 78423 的全部八条实际对偶边检查常量再现、反向交换、两点对角和各方向通量误差。同时检查正交与剪切 0.5 的规则六面体族，沿三个坐标轴记录积分截面通量；3、9、27 等分保证同一计算坐标中面位于节点对之间。用总通量检验细化，消除单个面面积缩小对误差的影响。常量、正交仿射和守恒误差须在相应自然尺度的 1e−12 内；原未限幅格式应在所有仿射试验达到同一容差。有限幅的斜网按每个方向各自核对，积分误差若超出该舍入容差须随三倍加密至少一阶衰减，且最细层小于对应截面自然通量尺度的 1%。自然尺度为扩散系数 × 梯度模 × 截面面积，常量按单位梯度标定。真实八边另报绝对法向误差及以各自自然尺度归一的误差。任一制造场门槛失败即以其原值关闭此候选，不运行冷态求解、不改变原面资格。

离线通量测试和独立复核各限 60 s、1 线程、1 GiB、20 MiB；工作台专项检查 180 s、4 GiB。输出包括有方向的解析与数值通量、加密误差、真实边号及对角核对、原始回执与准入决定。通过全部准入时才启用同网原冷态 200 次更新，4 线程、300 s、4 GiB、450 MiB，保存冷态、周期、终帧并按 v326 原门槛停止。开发、资料核对、工作台检查与物理推进分列。
