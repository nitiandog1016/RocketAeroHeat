## 方程与来源

来源：Hamilton、Millman、Greendyke，NASA TP-3271（1992），式6—7、19、25、27、54、56，[官方报告](https://ntrs.nasa.gov/api/citations/19930006245/downloads/19930006245.pdf)。准确本地文本摘要见执行证据。原报告为轴对称/二维方法，并采用线性化三对角求解；本项目采用同层流方程的耦合BVP，不声称复现原三对角算法或Keller-box。

令F=fη、m=lFη，g=(h+Ue²F²/2−hOffset)/H，n=(l/Pr)gη+(1−1/Pr)(Ue²/H)Fm。当前站沿程项为2ξ(FΔF−FηΔf)/Δξ和2ξ(FΔg−gηΔf)/Δξ。上游g使用上游自己的速度与温度解码，不能以当前Ue替换。使用用户已安装的MATLAB，未分发MathWorks源码；独立审核调用现有SciPy的物理温度变量BVP。

离散乘积差分不等于点式乘积：动量积分中的额外项为(2ξ/Δξ)∫(ΔF)²dη；能量额外项为(2ξ/Δξ)∫ΔFΔg dη。完整外边界项保留。审核同时报告未扣截断的守恒偏差和扣除已知项后的离散方程闭合，二者均按事前1%门限核对。
