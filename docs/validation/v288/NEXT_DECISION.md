# 下一项：在完整体网上建立满足连续性的启动场

B 型珠体 6 m/s 首步目前只有原焓残差超限。首次装配的同节点数据表明，连续性误差乘局部比焓几乎重现全部焓右端；镜像初猜中 91.5% 的焓残差平方和集中在轴线上，峰值位于下游外边界。镜像相较单射线的降幅只有 3.75 倍，已关闭从同一镜像种子直接重跑 180 次的路线。[证据](evidence/rhs.json)

下一次选用同速五射线基流，在 v287 的**完整体网**上使用原生连续性、动量、焓和强温差方程先作定常松弛，随后再施加一次相同的尾迹扰动。初始的镜像传递只能满足扇区自身的离散方程；全周轴线的控制体与外边界具有不同邻接。拟检验在实际邻接下减小质量不平衡能否得到成本可接受的首步。暂不把这种邻接差异视为已证实的唯一误差源。

开算前登记可接受的总成本、初场及停止条件。先在去掉有意扰动的完整域读一次原生右端作为对照，再判断全周松弛的必要性和收益；输出周期场、终点及节点右端，逐项核对原始残差和温界。保留物性、焓参考、全体轴线节点、外边界和原验收门槛。若松弛达到预算收益，加入原扰动并用同一物理步配置复验，同时读取末窗终点的节点右端，比较首步资格和基流总成本。代价或改善不支持时，保留证据并结束这一初始化分支。长时尾迹和公开平均换热对照在有接受的全周推进后继续。
