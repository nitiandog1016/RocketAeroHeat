# 下一项：用相同网格方法分离引线影响与离散误差

3 m/s 带线计算的珠体含接头放热为 11.94750 mW，原光滑珠体 7.5° 对照为 9.50885 mW。两次的外区网格、近壁层、壁面投影和几何都变了。首层减半只使带线珠部功率改变 −0.00112%，仍不足以解释它与公开实验平均换热的 +47.37% 差异。

下一次只改变是否包含引线。用 v297 的 Gmsh 子午外网与旋转混合体网、相同首层与外半径、相同的强温差方程和原生反力分配，对 v282 名义光滑椭球建立配对控制。以相同 3 m/s 来流和 305.15 K 给定壁温比较三项功率：新方法的光滑珠体、新方法的带线珠体含接头、原方法的光滑珠体。注明公共珠面与被接头替代的珠面面积，另比较公共位置的面热流和背流侧反向区。分别报告几何变化造成的模型内差值和同一光滑几何的离散差值。带线工况的原面编号、功率与云图继续保留。

以三项功率来源、六分量收敛、温界、同阶段守恒和原面积分均核实为结束条件。若主要差异来自外区离散，下一次加密应落在确有影响的外区和尾迹；若带线几何主导，优先核对等温引线与真实传导边界。原实验未提供逐面壁压、热流或两线暴露长度；本次对照只能检验数值模型内的来源。
