# 同步均温对照

引线工况原生弱焓和强温差均在变动，起步后动力场也会继续迭代。为辨别纯热边界变化的影响，从同一个 v316 正常终帧出发，保留均温边界，用官方 SU2 对齐引线工况实际接受的步数与分段。分别读取两个同迭代位置的原面压力、热流和珠部功率。它补充生产界面相对 v316 当时保存值的比较。

源为 `outputs/v316_validation/run01/steady04`，原温度单位 24 K，强壁值 0.5，网格及源 SHA 见 [计划](PLAN.md)。第一个 320 步的引线工况已正常退出但末窗未过，第二段运行中。均温分支最多五段、各段不超过 320 步，四线程、720 s、4 GiB、1.5 GiB；按实际需要停止。必须核对真实完成步数，提前原生收敛导致步数不同则按实际差异报告。均温解复用 v316 的两次壁反力、追加 20 步与独立观察器，预算和门槛相同。两条分支串行，不重复引线计算，并列两条实际解的六分量、同面压力差、珠部放热差及各自追加步漂移。
