# 平板首轮读回及一次续算

第一轮以均匀自由来流、CFL 20 起步，6,000 次后原生正常退出，末行能量 RMS 为 −3.014、ω 为 0.00019，未达原门槛。默认紧凑 CSV 只保存坐标和守恒变量，求解器明确记录忽略三个逐字段输出键。保存文件后缀实际为六位数。保留全部原文件，以原生守恒量独立读回首轮壁面剪力估计，并标清与原生输出的区别。

官方同档平板文件本身使用重启和固定 CFL 400。以首轮自己的真实末态作为重启种子，在独立目录恢复这两项官方设置，最多 10,000 次、180 s、1 核、4 GiB、60 MiB。维持模型、网格、边界、残差定义、六分量门槛和独立 Cf 门槛；改用非紧凑全场及带原生壁变量的表面输出，每 1,000 次及末帧保存。如再次未通过，关闭本组合，不启动整件试算。
