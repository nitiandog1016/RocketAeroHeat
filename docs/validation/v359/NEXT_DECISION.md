# 下一项聚焦 M0.30 的有温差换热证据

关闭本次 816 单元绝热平板的首轮与续算组合。两份同档参考的摩擦偏差及 ω 残差均未过门，本轮未启动整件求解。五工况的能力评估已经完成，新增飞行原面为 0 面、0 m²。[逐项读回](RESULTS.md)

下一项只核对一次已有亚声速方法及其公开等温壁换热对照，优先使用仓库已收录的空气试验。以 M0.30、5 km、300 K 壁为比较对象，逐项记录对照的来流、雷诺数、壁温、流态、实际测量的热流或换热系数、测站和不确定度，确定哪一种现有方法、哪一段表面可获得证据。先限于一次不超过 30 分钟的资料和代码核对，输出对应关系及采用或拒绝结论。若没有匹配资料，保留热流未知并说明缺少的具体测量；若有，下一次数值试验须同时交代本次未通过的动量条件、非零热流对照和完整原面验收条件。现有五点的热功率和实验资格沿用各自原始回执。
