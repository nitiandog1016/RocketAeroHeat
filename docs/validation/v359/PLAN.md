# M0.30 亚声速黏性与等温壁入口准入

基线 v358，`69c35883ee8dc53d9a85189a2074695f3c63c1a4`。冻结同一 9,216 面、0.935516891 m²，项目标准大气 5 km、M0.30、零攻角及侧滑、给定壁温 300 K。先核对现有官方 SU2 8.6.0 可压缩黏性算子。原 0.05 m/s 不可压恒物性层流结果与五工况实测回执继续分开保存。

1. 运行官方亚声速零压力梯度平板，取 35×25 节点、816 单元、M0.20 和单位长度 Re=5×10⁶。使用 SU2 的 SI 算例网格和边界，按 TMR 的 SST-Vm 版本运行，以原生远场初始化。最多 6,000 次迭代、1 核、180 s、4 GiB、60 MiB。保存初态及周期场，核查真实终点、变量身份和源文件指纹。按同一壁面 x=0.970084071 的局部 Cf 与 TMR 同档 CFL3D 和 FUN3D 各自相比，相对差各 <5%；最后 20 行密度、两动量、能量、k 和 ω 的原生 log RMS 各 <−8。使用热绝缘边界的该项只检查平板动量、壁面剪力和读数定义。
2. 核对目标工况的雷诺数、总温、热流方向参照和现有近壁距离。采信上游官方源文件中的无滑移和等温壁能量边界定义。按平板 Cf 只估算首层尺度，真实 y+ 须由本工况解读取。采用恒定比热理想空气、Sutherland 黏度及常分子／湍流 Pr 数的条件性全湍流 SST-Vm；自由来流湍流值采用可追溯计算设定，实际转捩及尾迹需独立考核。
3. 若平板数值门槛通过，执行一次同一 M0.30 试件的轴对称全域定常 RANS 准入试算。保留完整平底及真实的远界、轴线、300 K 无滑移壁，网格必须以米写入。初场为该飞行来流，运行最多 2,000 次、2 线程、300 s、4 GiB、300 MiB；至少每 200 次及终点保存，保留进程及日志。原生正常终态、所有六项末 20 行 RMS <−8、绝对压温正、实际壁面 y+≤1、正确定义实际壁温和原生热通量、末段热功率稳定且可由同阶段壁能量收支复核后，才考虑将结果接入原面。未通过项单列并终止本组合。空间／外域误差和匹配实验仍须独立验证，研究试算不开放最终结果页。
