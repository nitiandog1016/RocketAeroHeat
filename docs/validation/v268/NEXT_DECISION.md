# 下一项交付：一个冻结工况的一份整表面结果

v268 已验收低速球体的穿流接口，停止继续增加球体网格、切面或控制算例。项目里程碑仍以选定几何在同一时刻的全部实体外表面为分母。自绘模型现有 19,752 面中有 9,725 面同时具备工程壁压和热流，仍有 1.117875 m² 缺少至少一项。微球和风洞的面积各自属于其本身。[原面基线](../v263/evidence/saved_surfaces.json) · [微球结果](RESULTS.md)

**下一项是把同一工况的整表面结果直接交给使用者。** 常用工程入口目前只返回各变量各自的面积比例；混合入口已能返回同面面积和完整标志。先把已有工作台对同面交集、给定量、缺项和全壁功率的判据接到常用计算回执。验收时同一次结果要能回答三个问题：有多少原面同时算出了壁压和热流，剩余面积是多少，整表面热功率能否给出。使用冻结存档复核，保留有物理意义的零值和负值。接口交付单列软件收益和新增求解面积。随后的区域算法交付以同一工况实际新增的同面结果为准。

复用 [v263 已核对的原面记录](../v263/RESULTS.md)、[v266 部分与全壁功率](../v263/evidence/snapshot_power/summary.json) 和本次微球的完整结果。面积须与这三个已有对照分别吻合，已给定的量继续按给定处理。为此次接口核对预留 120 s、单计算线程、4 GiB 内存和 16 MiB 输出，遇到场量身份或分母不一致即保留差异。原面存档可回读，当前决定无需重启流场推进。

**公开模型的用途。** 用户确认 `cases/rocket.stl` 为自绘外形。已有 NASA 圆柱—扩张段有同工况压力与热流测站，可用于测站精度回归。另查到 NASA 收录的民用 Apollo AS-202 指令舱资料，其图 3 标示量热计位置，图 4 对比传感器 A 的飞行数据与预测。可作为以后热流测点对照的候选；本次只核实资料和可测变量，尚未配准几何、时刻、热流定义或同站压力。资料中的预测和测量需分别保存。选择公开模型不会替代某一工况的逐面计算。[已用风洞实验](../v263/TMR_RESOLVED.md) · [Apollo AS-202 热流资料](https://ntrs.nasa.gov/citations/20110024180)
