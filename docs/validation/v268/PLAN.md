# 等温微球的连通外流穿流接口

基线 f6952d10。v267 中间切面的法向质量通量为零。本轮通过同一单工况入口求解均匀低速来流中的静止恒温实心球。球外邻域解黏性 Stokes 方程，外侧用至无穷远的衰减模态消去外域自由度。匹配速度及应力后，由内侧解反算外侧系数。热问题保留有限 Péclet 数的对流和导热，外侧 8 倍半径处为恒温热浴；交界温度由两侧热流平衡共同确定。球壁是唯一计面积的壁面。

固定半径 1 mm，均匀速度 20 µm/s，密度 950 kg/m³，动力黏度 5 Pa·s，导热系数 0.15 W/(m·K)，比热 1500 J/(kg·K)，球壁 302 K、热浴 300 K，远场压力 101325 Pa。无重力、恒物性，忽略惯性与黏性发热。用项目的公开几何生成器建立分辨率 64 的整球。核心对照为半径比 2 的内部切面，另在 3 处移动切面。原面按中心径向投影取样，平三角面积与球面带面积分列。

动量对照取 Shreyas Mandre《Fluid Dynamics Lecture Notes》第 9.3.7 节，式 (9.88)–(9.94)，转换到静止球参考系。温度用独立的整壳球坐标对流扩散方程配点解比较；静止极限用有限热浴的球面导热解析解比较。上述均为方程或数值对照，实验精度另行报告。[球体平移公开解析解](https://notes.shreyasmandre.com/fluid-dynamics-notes/Ch9.html#S3.SS7)

径向近区与外区各取 12、24、48 个控制体，极角余弦分别取 16、32、64 个带。密网每个带的热流相对独立解的最大差按 k|ΔT|/a 归一，门槛 0.5%；总功率相对差 0.2%。切面 2→3 在同一物理热浴下按相同门槛核对。Stokes 速度、压力扰动与穿流量相对解析尺度误差 <1e−6，径向配点相对残差 <1e−8；接口传递差 <1e−8，热离散残差 <1e−10、全域能量差 <1e−9。零速解析功率相对差 <1e−9。分别保存正、负半球质量交换，要求非零来流时两者均非零。原面覆盖、负热流和方法通过常用入口和工作台导出回读。另核对热平衡零值、适用域和不闭合网格拒绝。

MATLAB 单线程、1 CPU、4 GiB、120 秒、32 MiB 新增输出，独立 Python 校核单线程、512 MiB、60 秒、8 MiB。直接稳态边值与稀疏线性求解保存初猜、最终配点场和温度场；各计算分别保存停止信息。接口或守恒未通过时保留该次结果，不以试验量补值。自绘主算例本轮不增加计算或验证面积。
