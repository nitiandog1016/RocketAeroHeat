# 在保留的细网上独立估计 6.25 µs 壁面结果的时间误差

同一数值起点后的两网 6.25 µs 整步均收敛。外层加密使整域质量、总能量和参考焓换算后能量差的绝对值均下降，原面壁压与热流对本次改网的变化已经量化。保留 91×109 的细网和 v371 的 6.25 µs 整步作研究参照。−45.40 W 仍是带符号的整域余量；空间收敛阶、成熟流动和实际转捩资格待验。[本轮证据](RESULTS.md)

下一项在同一细网、相同物性/空间离散和 v371 的精确初场上安排两次 3.125 µs 半步，终点仍为 6.25 µs。第一半步通过原末 20 行四分量 <−8 的门槛，才用其原生步末场启动第二半步；任一步失败即保留现场。按实际时间层与回执核对接续，两个半步的储能与边界收支各自审计，再按持续时间形成整个区间的质量及能量账。两半步均通过后直接与已保存的整步逐原面比壁压、热流、壁剪、六区功率、局部峰及圆柱两端的热流 RMS。只为这个明确的共同终点检验时间误差，原网 12.5 µs 已关闭组合继续留档。局部近壁空间与适用性各有单独要求。
