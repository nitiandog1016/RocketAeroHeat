# 显式过渡通过拓扑后的独立HXT对照

本计划写于显式Delaunay唯一候选终态之后，不回写原门槛。该候选21.953秒exit1，完整配对/正体积通过、体积差7.00e−15，但205四面体SICN<0.1。其中204个四顶点均在固定接口上，204个在X>0鼻部；1个在原主体外壳。单三角边界面自由顶点的最优SICN下界分布最小0.189527，没有单面必然迫使SICN<0.1；这不证明整域一定可达质量门槛。

现在已有无自交、真实配对且全部为三角面的外域边界，不再需要Gmsh自动金字塔。官方4.15.2手册将HXT（Algorithm3D=10）定义为独立的并行Delaunay实现，可在这里采用，而此前自动混合四边接口不适用。依据：https://gmsh.info/doc/texinfo/gmsh.html#Choosing-the-right-unstructured-algorithm 及同手册Mesh.Algorithm3D。

唯一新对照使用固定Gmsh4.15.2/HXT、2线程，直接复用已保存的显式598金字塔、保留棱柱、内/外三角边界，不重新准备几何/自交检查。仅改变外域生成算法，不扫描尺寸、层数、金字塔高度或优化上限。保持全部原壁/近壁/尾缘/远场，原节点数400000、单元900000及所有四面体SICN≥0.1、体积差≤2e−10门槛。180秒单项上限，本轮输出总预计≤80MiB（独立运行时另计）；先存原始网格，失败停止，不自动再试。

此为新成熟算法的单次有依据比较，不是默认切换；通过后仍须几何/原面独立复核，再另定初场迁移和有限流场。本计划无SU2，物理资格不变。
