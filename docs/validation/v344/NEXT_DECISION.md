# 从已确认工况进入独立计算

使用[完整 CAD 标准输入](../../../cases/rfz_rec/full_cad_input.json)作为下一轮唯一输入，沿用原模型朝向及明确标注的内壁同温假设。原壁、内腔和论文封盖均已有独立身份。下一项应处理空气域与物理原壁的对应关系，使内部计算能消费当前工况；需要核对体单元与每个实际壁面的连接、分组面积及给定温度。几何页、边界表和保存重开已达到本轮验收终点。

在实际计算前根据采用的网格与内核登记准确来源、CPU、内存、时间、磁盘及停止条件。按真实计算报告首次同时得到压力和热流的面数与面积，或保留具体失败证据。各区仍需满足原适用性与验证要求，九处参考封盖独立列账。[本轮全表核对](RESULTS.md)
