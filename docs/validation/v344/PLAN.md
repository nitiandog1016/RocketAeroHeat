# 完整 CAD 原面进入网格、壁面边界与工况重开

基线为 v343 `1ec6ace44b07b960b1a872cfe9592d2e944ee760`。按[上一决定](../v343/NEXT_DECISION.md)使用已验收的米制 STL、原面分区和论文工况。完整 CAD 是本轮模型域。九个人工封盖保留参考身份；当使用完整域时，内腔 14,982 面需要自身的壁面条件。

使用固定的小型来源文件和本机 `outputs/rfz_rec_geometry/RFZ-REC_m.stl`。实窗每轮限 240 秒、4 GiB、单计算线程、200 MiB 新文件。检查达到完整输入确认和恢复即结束；没有体网与物理结果的操作不计流场迭代。
