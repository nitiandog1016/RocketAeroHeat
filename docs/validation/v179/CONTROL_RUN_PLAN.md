事前观察/停止：出现非有限状态、原生不可接受更新/异常或预算耗尽即停止，不重跑同初态/CFL。至少达到二阶阶段且末100对早100同阶质量/能量残差平均下降≥0.5log，并有两个完整壁面保存结果，才视为有发展收益；未达到则不自动增加步数。短窗筛选不是物理收敛时限。原−8残差、后两保存q面积L1≤1%、p≤.5%、峰q变动≤2%、严格热/近壁/网格及外域敏感性分别记录；未满足不授资格。

比较不做反标：q和p按原表测站线性插值，只在已算壁面支撑区间内；不跨越几何拐角插值，不覆盖未知的有限测头面积。给出逐站SI差/相对差、峰值/位置、工程归一化残差和未映射原因。实验逐点不确定度未知，不虚构置信通过。模型差、网格误差、未收敛误差不能互相归因。
