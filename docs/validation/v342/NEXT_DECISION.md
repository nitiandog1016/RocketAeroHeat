# 核对同一 REC 工况的物理壁面与参考数据边界

以本版 130,044 个原面为固定输入，在作者未偏舵的 REC 候选工况上落实计算边界。先区分实际暴露壁面与论文计算中额外引入的人工封盖，核对点云覆盖的半域、压力定义、壁温和热流方向，在同一张区域表列出依据和未决项。当前有 1,407 个参考点距本版三角面超过 50 mm，其具体原因仍待识别。依据应来自作者模型和原件；纯几何最近点只提供候选位置。[几何对照](evidence/reference.json) · [作者说明](https://github.com/rfz-model/RFZ_data/blob/3a174ee3d0b0626d6029e9608d862b674f3b266b/Aerodynamics/Stage_1/EUCASS_2023/readme)

验收以工作台可核对的壁面清单、完整 CAD 分母、单列的人工边界及可以独立计算的冻结输入为终点。参考值只进入对照列。缺少证据的区域继续保留原面、面积和待定身份。下一次独立计算根据确认的边界登记预算、收敛与守恒门槛。银球与原自绘算例各自保留原覆盖记录。
