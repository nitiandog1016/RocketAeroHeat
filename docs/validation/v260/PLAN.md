## 精度、模型与实际收益合同

1. 旧/新均保持相同输入/数据/能量身份；新状态与原独立物性参考的缩放误差≤2e−10，所有准入域及有限性保持；节点/端点身份按明确合同核对。
2. E/H高精度参考使用80位Decimal逐段积分和二分（不用新实现的有理化公式），以实际double表节点/系数为数学数据；温度绝对误差门槛2e−10 K。浮点表锚点极小跳变或节点目标舍入的特殊点单列，不假称跨跳区有唯一精确根。正负/低温/参考零点保持。
3. 每个原节点的sigma−base、half−base温差与高精度温差逐一比较，报告绝对差及实际有信号点的相对差。采用收益要求：实际E重放新最大绝对温度误差不大于旧的0.5倍，且成对温差误差RMS不大于旧的0.5倍；否则明确未证明足够收益，不扫参数或追加上限。精度通过不等于CFD方向/壁热通过。
4. E/H之外的函数和S反算仍是旧实现；实际p/T范围、原表/输运和未改源SHA绑定。不更改原线性1e−5、原方程−8、热稳定、边界守恒、空间/外域/近壁及公开验证门槛。
