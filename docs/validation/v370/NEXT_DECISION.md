# 优先核对外侧网格对同刻守恒与热流的影响

6.25 µs 步末的原生远界、热壁和储能项已逐项取得。原生边界与储能的质量差为 −0.05227594 kg/s，扣除参考焓质量输运后的能量差为 +140.18 W。沿中点半径分摊，最外两个节点层占几何总能量净项的 89.54%，占换算后的余量 34.27%。这给出了受控改网的位置，不能由这些占比推定细化后的收益。[本轮收支与定位](RESULTS.md)

下一项在同一 M0.30、同一 14D 外界与 2 µm 首层上，仅二分原节点层 86–87 和 87–88 之间的径向间隔，各插入一层，保持旧节点、全部壁面、远界折线、子午分辨率及壁温。把 v365 原物理初场按原单元双线性场转入细分单元，核对节点身份、正性和旋转域四守恒量积分。直接从同一数值起点做一次 **6.25 µs** 原生物理步，与 v369 首半步同刻比较；沿用 v369 原生残差门槛并保留完整终帧。试算前登记准确源及预算，限制为该单一细化方案。

若细网步内收敛，按同一原生取样合同重算质量、总能量及参考焓换算后的收支，比较六区壁压、热流、功率、两处圆柱端部面带及外层分布。依据完整收支及原面差决定外层细化的收益和是否保留。若该步不收敛或差额无实质改善，保留失败并复审全周守恒离散；不凭局部半径项变小升级整件资格。时间步误差与转捩仍分别待验。
