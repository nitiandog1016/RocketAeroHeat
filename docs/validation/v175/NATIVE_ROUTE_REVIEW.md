## 2. 等温壁实际计算行为

`CNSSolver.cpp:630–790` 的 `BC_Isothermal_Wall_Generic` 同时服务标量Tw、custom空间Tw及CHT。读取原法向邻点温度 `There`、给定或交换的 `Twall` 和原法向距离后，原生计算：

```
dTdn = -(There - Twall) / dist_ij
Res_Visc = thermal_conductivity * dTdn * Area
LinSysRes(iPoint, energy) += Res_Conv - Res_Visc
```

静止壁面 `Res_Conv=0`。层流导热率来自当前壁流体状态；有湍流时另加 `cp*mu_t/Pr_t`。程序继续推进壁节点守恒能量，未在此把保存的壁流体温度改成给定Tw。强制处理的是动量行的无滑移条件；隐式能量对角项是原生近似线性化，不能把它当成准确Jacobian后再据差异认定错误。

因此，给定Tw与壁节点流体温度之差本身不能证明边界实现错误，也不能通过覆盖保存温度修复。真实热流、能量一致性、残差与网格/壁距仍须分别审核。

没有在这条原生压缩流入口找到可直接将该弱等温壁切换为强温度约束的配置。`MARKER_HEATFLUX` 改成给定热通量，会改变待求问题，不能把已给定的q算作预测的气动热。CHT在 `CNSSolver.cpp:800–804` 仍进入同一弱壁函数；它还要求固体材料、几何及另一侧边界条件，当前NACA实测Tw问题不具有这些完整输入。两者均不作为本轮替代方案。

## 3. Riemann与Far-field确实不同，但旧边界不是全态强制

当前NACA外边界采用 `STATIC_SUPERSONIC_INFLOW_PT`，出口采用 `STATIC_PRESSURE`。准确 `BC_Riemann` 的实际步骤为：

1. 根据标记数据构造外部状态。静PT入口向量是Mach向量，速度为该向量乘局部声速。
2. 以**内部状态**建立特征矩阵及法向特征值 `u_n`、`u_n+a`、`u_n-a`。
3. 只对 `lambda<0` 的特征，将外、内守恒量之差投影回边界状态。
4. 用所得边界状态直接计算投影物理通量，并构造相应隐式贡献。

关键位置：`CEulerSolver.cpp:5492–5534` 和 `:5562`。所以，不能仅凭 `STATIC_SUPERSONIC_INFLOW_PT` 名称声称整个outer在所有法向流动状态下都被强制指定完整外态。

原生 `BC_Far_Field` 则执行不同的闭合：

| 内容 | 当前通用Riemann | 标准Far-field |
|---|---|---|
| 特征入/出判别 | 内态法向速度和声速 | 自由流法向 `Qn_Infty` 与自由流声速 |
| 构造边界态 | 内态特征线性投影守恒量差 | 组合声学Riemann不变量，按流向选熵及切向速度 |
| 对流边界通量 | 重构边界态的投影物理通量 | 内态与重构外态进入既有上风数值通量 |
| 关键源码 | 5492–5562行 | 5147、5157、5179、5224行 |

二者在自由流一致状态或某些完全超声速极限下可能给出相同结果，但不是一般等价算子。这一差异足以说明它不是单纯改名；却不能证明它造成或能消除v174鼻前第13层的温域失败。该失败的唯一原因没有由本审阅建立。

`CIntegration.cpp:130–140` 存在两条独立原生分派。`CConfig.cpp:3693–3699` 明确认可 `IDEAL_GAS`；`:4620–4635` 对非理想流体禁止Far-field。故标准Far-field可作为当前定gamma原生模型的能力保留，**不能直接套用于原Lemmon变cp/OTH路线**。现有项目case验证器及父包限制仍绑定既有边界合同；源级支持不意味着当前应用入口已支持任意Far-field配置。

## 4. 官方热壁用例及完整入口缺口

准确源码树中的 `TestCases/navierstokes/flatplate/flatplate_supersonic.cfg`（SHA `b8b8137730d13e875729d6af9b138bffa168818de90fdfead8e6abf492532746`）确实使用M4、T∞300K、Tw300K、`MARKER_FAR(INLET)` 和超声速出口。它说明这种原生边界与等温热壁组合有官方配置依据。

但该配置声明 `RESTART_SOL=YES`，并引用本地未提供的CGNS网格和restart；目录仅有配置文件，没有可在此直接独立核对的热流参考表。它也不是完整的NACA半球柱基准。常规 `lam_flatplate.cfg` 使用 `MARKER_HEATFLUX=(wall,0)`，属于绝热控制，不能替代非零热量验证。官方短步回归的固定数值也不能自动充当独立实验热参考。

本机v105/v108已有收敛平板由控制审阅另行绑定：其Far-field、热壁与局部热参考可以作为已有能力证据，但热流参考只覆盖明确的局部区间；前缘壁流体Tw差及其他限制保留。它不能直接授予曲面、鼻尖、分离、底面或突起资格。

若将来具备重开条件，唯一保留的成熟边界方向是给定gamma的标准外流Far-field，覆盖开放outer及出口，保留原wall空间Tw和对称面。其物理量必须继续明确为 `e=cvT`、`h=cpT`，保留原M/Re/T0和相容静态条件；使用新的具名case合同，不能静默更改原NACA合同。原mesh02和fresh初态的身份、近壁分辨、数值选项、热量比较方式都须一次登记；不通过扫描CFL、通量或初猜选择“成功”结果。

目前尚未闭合的关键项是：NACA同工况可独立核对的热量归约与外缘/恢复状态、该有限外域及出口的物理适用性、完整热壁推进收益的验证依据。只证明边界算子不同，并不能补足这些项。

## 5. 单一路线决定与重开条件

**本阶段停止当前NACA发展支线，保存数据、接口和已知能力，返回真实20°全区域工程方法/区域入口及科研UI主线。** 不从100帧接续，不重跑同500步，不扩大360K上界，不为了Far-field更名另跑一次CFD，也不启动自研回滚内核。

将来重开必须同时具备：

1. 一项完整、具名且能复现的成熟热壁控制，准确几何、边界、初态、近壁、数值选项与独立热量参考齐全；只给官方cfg不够。
2. 对目标NACA几何和工况闭合开放边界/外域及热量比较合同，明确哪些仍是模型近似，不能借平板局部通过宣称NACA通过。
3. 事前固定唯一候选的总时间、输出、物理接受与停止条件；原v174失败、原−8、150—360K、热流/y+及实验门槛不追改。

本审阅新增CFD、构建、大场读取、工程物理资格均为0。源级Far-field支持和一般不等价性属于保留的技术事实，不计作已求解面积或新的热环境结果。
