# v175：已有收敛平板控制的适用范围

结论：v105/v108确有来源闭合、达到原密度/能量−8的层流等温平板解，但它们是**冷壁传热控制**，不能单独构成新的完整加热半球柱/NACA启动方案。两次都沿用原生弱等温边界；v108的有效改变是从同条件已收敛粗网格解插值到细网格。当前没有对应的已收敛NACA粗解，不能把平板场或v174失败100帧代作这种初态。仅替换AUSM或自适应CFL也不能据这两次结果宣称已形成完整成熟方案。

本审阅按[v175计划](PLAN.md)只读小回执、准确归档源码与配置；不运行CFD、引擎构建、旧回归或相似方程，不遍历旧/新体场。证据为 `outputs/v175_validation/control_review02/report.json` 及其监督回执，执行脚本为 `scripts/reviewConvergedThermalControlsV175.py`。源文件按v105/v108交付清单原始SHA核对；未以当前共享源码冒充历史运行源。当前EXE和大网格/体场没有重新哈希或复算，历史运行包/网格/场身份来自原始回执。首次监督回执目录缺失在子进程前拒绝；control_review01随后因Python3.7不支持`utf8-sig`别名在首个读取退出（0.156秒），准确失败脚本/报告保持，仅改为标准`utf-8-sig`后在02恢复；总程序预算仍≤40秒。

## 能量参考、热边界与参考量

两例都是原生IDEAL_GAS：γ1.4，R287.05287 J/(kg·K)，e=cvT、h=cpT，无OTH偏移，层流不扣SST k。Sutherland μ=1.458e−6 T^1.5/(T+110.4)，Pr0.72。与v174的能量零点类型相同，但R、输运细节、流场和几何不完全相同，旧守恒场不能直接复用。

M4、T∞300 K给出总温1260 K，层流平板恢复温度估计约1114.587 K；Tw300 K明显低于恢复/总温。因此原参考q为**正入壁冷却热流**，不是v174 Tw333.409–336.354 K高于T0=316.667 K的电热壁向气流供热。v105归档官方平板示例本身也不是本项目算例的精确复现：示例使用外部restart、p70.47 Pa、不同线性容差/CFL/1000步，不能把示例成功资格直接移给本项目。

准确 `upstream/CNSSolver.cpp` 729行附近明确能量弱施加；`upstream/CFVMFlowSolverBase.inl` 2651–2658按原壁法向邻点输出 `q_into_wall=k_wall(T_neighbor−Tw)/d`。给定Tw用于热通量，不逐点强制导出流体温度；近似隐式壁对角并未因此成为错误Jacobian证明。本轮没有发现旧控制采用不同的强制温度/共轭热壁启动算法。

热参考是独立SciPy实现的零压梯度、定比热/Sutherland/常Pr Levy–Lees相似边界层，`q_ref(s)=12264.843223508966/√s W/m²`（s以m计）。η上限16和24的系数一致性来自已存审核，不是本轮重新求解。固定比较区间s=0.04–0.16 m：粗网格q差−4.7061%至−1.8000%，RMS2.9711%；细网格−3.3889%至−1.1583%，RMS2.0403%。两网格34个粗中段节点上p最大变化0.04720%、q1.38227%，只是原p≤1%、q≤5%筛选。

旧近壁梯度/输出一致性最大相对差约3.35e−7和3.94e−7，符合当时六位VTK文本；粗网格全壁线积分11150.834079 W/m与原生11150.83423 W/m差1.35e−8。单位为单位展向长度功率，不能当箭体总功率。参考与全NS使用不同近似；独立实现不等于实验真值。

## 已验证与未验证

已验证的是本地完整调用链、定比热输出/EOS/热流符号和梯度身份、原残差收敛，以及固定中段的相似参考与两网格筛选。原前缘/等温–对称共享节点保留：粗/细流体温度560.091/516.8124 K，较Tw偏差260.091/216.8124 K；中段最大偏差仅0.0517/0.0135 K。前缘未进入相似比较，不能凭中段或残差收敛称前缘、全长、完整NS、网格独立或实验合格。分离再附、底面、突起和真实20°三维全面积资格均未取得。

v129另是M6Tw025条件的SST-2003m/DNS比较，原−8及外缘压力门槛失败。它不是这里的收敛层流控制，不能混用其热参考、壁温、k能量或资格。

## 可回到完整域主线复用的能力

- 原生进程预算、终态、准确输入/输出来源绑定，以及p/T/q回读的身份规则已经验证；这些可服务完整域研究入口，不以正常退出冒充物理解。
- 在相同IDEAL_GAS合同下，`ρE/ρ−|ρu/ρ|²/2=cvT`、正入壁符号、给定Tw与流体节点温度分开等审核规则可直接保留。完整域热流复算必须采用其真实壁面法向、原法向邻点和本模型物性，不能搬用平板的y距离。
- “先验收同工况粗解，再限定凸插值/拒绝外推/正内能/积分差”的初始化合同有实证。当前实现只针对同一矩形物理域的张量网格，不是三维全域守恒映射器；没有合格对应源时必须拒绝。它不能直接生成真实20°分离再附、底面、突起或NACA初态。
- 固定中段Levy–Lees及两网格比较可继续作为已有局部数值控制证据。无需为返回完整域主线再跑已过平板，也不能把其局部资格加入真实箭体面积分母。

本分项决定：保留已有收敛冷壁控制作为明确范围内的数值依据；不重跑平板，不把它包装成新的NACA候选，不做CFL/通量扫描。若另一项准确官方入口审阅也无法给出条件闭合、不同实际行为及独立热量验证的完整加热壁方案，应按总PLAN停止当前NACA发展支线，回到真实20°全区域与科研UI主线。v174温域拒绝、未知瞬时场和全部原门槛保持。

执行结果：control_review02外层0.234秒exit0，内部0.078秒；32份输入原始SHA稳定。与01的0.156秒合计程序监督0.390秒；目录缺失拒绝没有创建子进程。新CFD/构建/体场读取/旧回归/相似方程重算均0。文档检索、人工源阅读、开发和协调的墙钟不计为求解时间，也不冒称上述0.390秒涵盖整段工作。
