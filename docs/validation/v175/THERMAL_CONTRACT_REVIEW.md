# v175 独立热壁物理与数值合同审查

2026-11-06。依据本轮 [PLAN](PLAN.md)、已归档的真实平板控制和 v174 准确引擎执行源。这里只新增只读审查与小代数证据，没有修改生产入口、目标或旧计划，没有 CFD、编译或大场遍历。

**决定：当前尚无来源闭合、热量参考完整且能直接替代 NACA 失败入口的成熟完整方案。按 v175 计划停止 NACA 发展支线，保留其数据、接口和全部失败，回到真实 20° 全面积计算与科研 UI。** `BC_Far_Field` 是确实不同的成熟边界算子，但只改这一项不能称完整热壁修复，更不能以新的温域判法重跑 v174。

## 1. 三个不同层次的“合法”

| 层次 | 要回答的问题 | 当前能作的判断 | 不能据此宣称 |
| --- | --- | --- | --- |
| 代数模型定义域 | 守恒变量能否形成有限、可计算的状态？ | 原生定 γ 理想气体要求 `rho>0`、`rhoE−|rho*u|²/(2rho)>0`，因此 `T>0`。Sutherland 代数式在本模型正温度内可计算；实际经验精度另验。 | 所有正温度都符合低焓空气物性、实验或工程精度。 |
| 稳态伪时间发展态 | 非线性迭代是否还可继续？ | 未收敛保存态不是已经实现的真实时间轨迹；大残差、暂态热流反号或超出预计终态温区均须保留并解释。真正 EOS 查询越界、非正内能、NaN、失控或资源耗尽仍须按事前合同停止。 | 第 100 次迭代的 450.97 K 是真实环境温度；或只因代数可算就值得继续。 |
| 终态热环境资格 | 该状态可否作为目标工况的可信输出？ | 还须原残差、严格能量/热流、物性适用域、近壁、热流稳定、网格/外域、局部外缘、实验参考和区域适用性等独立门槛。 | 程序退出 0、热流公式一致或 `y+99<1` 就解决了全部区域。 |

v174 的 `[150,360] K` 是事前登记的低焓开发适用范围与停止条件，不是理想气体方程的数学正性上界。本次真实保存场超过它，因此旧候选仍然失败。守卫按计划停止是正确执行合同；本审查既不把这个合同追改为“错误”，也不把 450.97 K 改写为合格物理解。

将每个稳态试探态都限制在预计终态物理温区，并非一般非线性求解的数学要求。不过“观察到 450.97 K 后把上界提高一点”或只将同一任务的停止条件移到最后一步，仍然是事后放宽，当前禁止。

未来若有独立的新成熟方案，必须在其结果未知时分别登记：代数可接受状态集合；数值算法实际采用的域保护和停止方式；最终物性适用域；残差/热流等最终验收；资源预算与失败去向。若试探态使用超出物性验证范围的算子延拓，须事先说明定义、依据和范围，不能把这种延拓称新的物理精度。不得根据本轮最大温度挑选新上界，不得以此重新开放 v174。

## 2. 现有平板证明了什么

准确历史目录是 `docs/validation/v108/engines/warm`。原回执锁定的初始化源为 `source_versions/prepareSU2FlatPlateWarmStart.py.4865173ac3120306.raw`，SHA `4865173ac312030691ab71596f5041d5b126c4e1191dca44d2b3f39c2dbd5192`。`a91...` 是此前将数值打印格式误判为配置改变的失败源，不是成功执行源。

v108 将内部已收敛的 v105 平板 5265 节点守恒场，双线性凸插值到相同工况/域的 11737 节点；随后 `RESTART_SOL=YES` 读取 `initial_flow.csv`。物理和离散配置保持，允许变化只有更新上限和输出安排。无外推、裁密度或裁温；节点积分变化最大 `4.69741089e−6`，但不是严格保守重映射。真正起作用的是一个已经有相容收敛种子的粗到细过程。

其完整配置是原生理想气体、M4、T∞=300 K、p∞=5000 Pa、给定 Tw=300 K、`MARKER_FAR`、超声速出口、AUSM、Venkatakrishnan–Wang 限制器、隐式 Euler、BCGSTAB/LU-SGS、10 次线性上限与 `1e−5` 线性目标，以及原生自适应 CFL。562.984 秒后原生终态达密度 `−13.63134544`、能量 `−8.000124765`。

但是该控制是冷壁超声速平板：T0=1260 K，和 NACA 的 M1.97、T0≈316.667 K、加热壁 Tw 高于总温、空间壁温/曲率/鼻尖以及原测量参数均不同。没有可直接映射到 NACA 的同工况收敛种子，不能将旧平板数值直接塞入半球柱或称它已经验证新入口。

原热量比较只覆盖 `s=0.04–0.16 m` 的附着中段；Levy–Lees 是独立边界层数值参考，不是实验或完整 Navier–Stokes 真值。中段 q 相对差约 `−3.3889%` 至 `−1.1583%`；两网格 q 变化约 1.38227% 是筛选，不是网格无关。前缘仍在几何和结果中，但未被该比较授予资格。其壁流体温度与给定 Tw 的最大差中段为 0.0135 K、前缘为 216.8124 K，不能只报中段然后宣称全壁已强制满足等温条件。

因此，应复用这份已成功的控制证据，停止重复平板运行；不能从中挑选一个 CFL 或通量参数组成新的无依据扫描。更完整的准确来源见 [控制审查](CONVERGED_CONTROL_REVIEW.md)。

## 3. 弱热壁公式、守恒映射与独立反例

实际弱热壁必须同时说明给定 Tw、壁流体节点温度、邻点温度、原法向距离/投影、壁处导热系数、热流符号和能量更新阶段。不能用给定 Tw 覆盖保存的流体温度，再把覆盖结果当边界满足或能量验证。

在明确固定正导热系数的示例中，入壁热流 `q=k*(T_neighbor−Tw)/dn`：k=0.02 W/(m K)、T_neighbor=320 K、Tw=340 K、dn=0.0001 m，得到 −4000 W/m²。若错误地把 Tw 换成保存的壁流体 450 K，变成 −26000 W/m²。这个反例只区分变量身份；完整原生导热系数仍可能随实际壁流体状态变化，不能据此宣称热流与壁流体温度无关，也没有代替原生热边界测试。

另一个独立反例说明“守恒变量凸插值保正”不等于“温度被端点温度包住”。两份正密度状态都为 300 K，速度分别为 0 和 1000 m/s，各取一半的守恒状态，其速度为 500 m/s，而未解析的速度方差进入内能，温度为 **474.186211815 K**：

`T_mix = 300 K + 125000 J/kg / cv`。

这是精确守恒代数，不是 NACA 实际初场或 v174 失败原因；它说明只检查插值权重非负还不足以取得物性温域或热量资格。

## 4. `BC_Far_Field` 是可检验差异，尚不是完整修复

绑定的准确源是 `outputs/v174_validation/build01/executed_sources/SU2_CFD/src/solvers/CEulerSolver.cpp`，SHA `199e03e4dc258fdd040e3f74510ffd79aff13114caf96c7523c41ab5eedc3f67`，不是凭当前共享树推断。

当前 `BC_Riemann/STATIC_SUPERSONIC_INFLOW_PT` 先按给定静压/静温与 Mach 向量建立外态，再按内态特征值选取负特征的守恒跳跃，形成边界态并计算其物理投影通量。它并非所有边界节点都直接强制成为给定来流。

原生定 γ `BC_Far_Field` 用自由流法向特征选择内/外 R±，按流入/流出选择熵和切向速度，形成非线性边界状态，再调用内态与边界态之间的上风通量。这是不同计算行为；不能据名字相似认定两者等价。

独立的一维、无量纲正状态反例取 γ=7/5、内态 `(rho,u,p)=(1,1/5,5/7)`、外态 `(1,1/10,81/140)`，外法向为 +1。两种重构都保持正状态，但得到：

| 重构 | rho | u | p |
| --- | ---: | ---: | ---: |
| 内态守恒特征投影 | 0.983142857143 | 0.217146178437 | 0.697370764313 |
| 非线性远场 R±/熵 | 0.815372697600 | 0.400000000000 | 0.536748198649 |

同态与全部超声速入流的身份检查另通过；有理数投影与独立矩阵求解的最大绝对差 `1.66533454e−16`。这只证明重构不等价，没有调用原生引擎、没有比较最终上风通量、没有证明 NACA 超温因果或新入口收敛。

要成为可运行的新完整方案，还缺相容的有限外域/出口合同、相同冷热壁关系与空间 Tw 的可靠热量参考、入口发展和局部外缘归约、合理初始化及最终物理验证安排。尤其不能把平板的超声速出口直接套到含近壁亚声速部分或回流的边界后称全域相容。当前 runtime 的旧受限合同仍是静 PT Riemann/Roe；任何未来边界方案都要另立具名合同，不能修改旧 metadata 来追授支持。

这些缺项没有在本轮闭合。只改 FAR 不是满足本轮出口条件的成熟完整方案，故不登记新的 NACA CFD 任务。准确原生源审查见 [原生路线审查](NATIVE_ROUTE_REVIEW.md)。

## 5. 建议写入目标的验收与止损条款

1. **最高优先级保持单时刻真实 20° 原 19752 面的全区域 p/q/温度身份与统一科研 UI。** 先逐区列原面数、真实面积、当前方法、适用域、缺口和下一项能减少该面积缺口的具体计算改动；不得用缩减几何或小控制替换分母。
2. **验证支线必须有主线出口。** 启动前明确它验证哪一条区域算法/边界合同，成功后接回哪段真实面积和 UI 功能；只增日志、源码审核或合成精度不计作区域计算完成。
3. **每项候选事前冻结完整方案与一次总预算。** 包括准确模型/引擎、域/边界/网格/初态、推进、热量参考、成功条件、失败原因分类和自动续算=0。已关闭任务不得通过重新命名、仅延长步数、换一组参数或放宽停止门槛复活。
4. **有限评估必须产生二选一出口。** 来源闭合且实际改变计算行为的成熟完整方案，才另登记最小接口与至多一个实际候选；否则冻结支线并返回主线。不得把“还可多查一点”自动延长为下一轮验证任务。本轮 NACA 选择后者。
5. **覆盖率分层显示。** “有数值”“热/能量接口一致”“方法在适用域内”“实验或独立物理验证通过”分别统计；未知、给定量和失败不得填成已解。UI 点击面元须显示方法/版本/温度身份/适用性和证据状态。
6. **测试只跟随实际变化或未闭合故障。** 已通过的网格、物性、输出、UI、平板基线优先复用；无新计算行为时不重复同样测试。预算上限是工程筛选条件，不是物理收敛时间定理，但达到上限失败也不自动授权续算。
7. **几何难区不删。** 分离/再附、底面和突起必须保留真实面积；无适用方法时明确未知并优先安排具名成熟区域求解。累计热量、全周期与稀薄扩展继续后置。

这些条款不会降低全面积最终资格要求。它们使后续工作直接面对区域能力缺口，并防止用越来越多验证版本掩盖主线长期没有新增可信面积。
