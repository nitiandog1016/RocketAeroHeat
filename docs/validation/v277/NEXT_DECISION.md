# 转入有实测热分布的民用风洞工况

CM-011 的 STL 和半周网格对照到此结束。两种周向离散已回答这次研究问题，肩部 202 面的局部压力敏感性保留在 [原面清单](evidence/sensitive_faces.csv.gz)。下一项使用带测点的公开工况检验程序计算的局部换热。

选用 NASA Lewis 光滑无冰圆柱、低湍流的横向来流风洞实验。原报告图 5 对应的换热试件直径为 **6.6 cm**、长度 **15.2 cm**。**5.1 cm** 是生长冰形的原始圆柱直径。图 9 给出 **Re = 177,000** 的周向换热分布，同图还有其他粗糙度和湍流度的数据及理论线。选取光滑、低湍流实验点，记录铜带测量区间、角度、归一化、测量误差、热损失修正和真实加热边界。只使用对应的实验量作独立精度检验。此工况有明确用途，可检验所计算的迎流侧局部热分布，并为将来带突起的民用风洞模型保留同源对照。当前未采用此实验验证壁压或 CM-011。[NASA 原文及下载入口](https://ntrs.nasa.gov/citations/19840006395)

下一次交付的具体结果为这个工况的原始测站表、可运行的单工况计算及在相同铜带范围内的预测与实测对照。首先从原图表核对热边界、Re 定义、来流和几何；执行前登记预算、匹配条件和停止判据。若缺少决定绝对热流的输入，保留未知，只比较有完整定义的换热量；给定加热量不当作求得的壁热。试件与风洞相接的端部、加热和未加热面分开记账。局部测站精度、试件完整面积和自绘原面的覆盖继续分别计量。累计热量与轨迹后置。
