# 接通普通 STL 导入与民用温度探头全表面计算

图 7 的引线边界和电阻测温两项对照已结束。后一项只能解释原长引线珠部功率差额的 4.41%，逐面实验验证面积仍是 0 m²。保留剩余偏差及来源，不继续围绕这个单一平均量调参。[本轮终点](RESULTS.md)

下一项回到“输入模型 → 生成网格 → 添加边界条件 → 计算 → 查看结果”的一般使用流程。当前 B 珠入口直接加载登记的顶点和面数组，建网入口要求数组与归档逐项相等。用户从普通 STL 导入同一民用探头时，文件可能重排面序、拆分共享顶点和使用不同长度单位。优先解决这种条件下的原面身份、区域边界与求解结果回传。[现有几何入口](../../../thermistorWorkbenchModel.m) · [体网入口](../../../prepareThermistorLeadMesh.m)

以同一 3 m/s 名义风洞测温探头为首个验收对象。把米制外形通过标准 STL 写出，经工作台普通导入路径重新进入五步流程。保留用户导入的原面编号和总面积，由程序核对单位、朝向、几何对应、壁面区域及映射覆盖，再将内部计算的壁压、热流、边界温度、首层温度和方法映回导入面元。可复用经实际几何确认的同一体网和已通过的求解器，内部生成和新算入口都要可用。验收包含面序改变、共享顶点重建和圆角附近相邻面区分，检查热峰、七区积分、截线及导出。来源不一致或对应含糊的三角面需报告具体位置。先完成该公开民用试件在普通入口的全链路，其他形状的通用体网和实验精度另行验收。
