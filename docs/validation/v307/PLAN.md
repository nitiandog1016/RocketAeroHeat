# 带线热敏珠固定节点换边的方向改善上界

基线为 v306 提交 `e9c02df7dbebd2222243ba41560c412b73d832a3`。本地及远端 main/v306 一致，v307 空闲，未见本项原生进程，E 盘可用约 325 GiB。执行 [v306 下一决定](../v306/NEXT_DECISION.md)。从原第三档基线网开始，核对 [第三档输入](../../../cases/thermistor_b/leadsThird3.json) 的六份输入指纹及 [v306 实网读数](../v306/evidence/measurements.zip)。基线网格 SHA256 为 `9a68642cbb22450aecc5f3133decdad33de254ae27c639398f64c0a682f3016c`，工况为带线 B 型热敏珠、3 m/s、293.15 K 空气、101325 Pa、给定壁温 305.15 K。

一次换边取原网中相邻的两个子午三角形，四边形须严格凸且位于前中段母线条带 [54,70)、壁距 0.015D–0.1D。外圈、全部节点、原面及近壁层保持。每个原三角形最多参与一次。以各三角形面积乘其最接近壁法向的边的夹角为代价。两个旧三角形与两个新三角形的代价差为一次换边收益，分母沿用完整目标区原有的面积加权角度总和。新旧交点逐射线比较，保留四边形边界已有的交点。约定原中点测线的交点容差为 10⁻⁹D；作上界时对接近边界或数值上难以判开的情形作有利于换边的放宽。

先列举候选并形成可检验的上界。对每个原三角形赋非负上界分量，每个正收益换边两端分量之和须至少覆盖该收益。任何互不争用三角形的换边集合，其总收益都不超过分量之和。逐项复核此证书，并保留三角形编号、对角线标识、各边收益和冲突关系。若上界低于原定 20% 改善，本轮关闭固定节点单轮换边方案，停止在几何阶段。

只有可实现的组合达到 20% 才构造一张实网。核对完整三维体单元、全体坐标、正体积、原面和内层，重读原 16 条测线的全部交点。另在同一 16 个母线段的 1/4 与 3/4 位置固定 32 条交错测线；按 v306 的 ±15% 合并分位数、±20% 逐线区间数与 ±25% 逐线最大间距界核对。夹角 ≤15° 的唯一边比例须提高。允许候选资格低于数学上界。达到全部几何门槛才按实际规模另登记一次同工况冷态计算及工作台交付，原残差、温界、热稳定及独立反力门槛沿用。

本轮枚举、优化、独立核对每步单线程，限 180 s、4 GiB、200 MiB。输出基线定位、枚举表、上界证书、独立核对和具名决定。前中段对应原面 1,536 个，完整原物理表面 10,272 个。几何阶段不计入新增壁压或热流面积。
