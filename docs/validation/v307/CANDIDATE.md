# 单套候选的构造顺序

原第三档数据得到的覆盖势上界为 40.509914%，足以进入候选构造，计算见 [证书](evidence/bound.json)。此时尚未生成候选或读取候选的四分点测线。

从已枚举的正收益换边中，对两个原三角形组成的整个区域进一步证明壁距和母线范围成立。用三角形子区中心和半径保守限定其中任意点到目标壁段及其他壁段的距离。原八层及其已用单元、带外网格共用既有三维输入。对十六条中点法线，以四边形四条外边和实际对角线交点的并集进行严格核对。

按收益从大到小、同收益按枚举序选取已经严格核对的换边。每个原三角形只用一次，完整目标区累计角度改善首次达到 20% 即停止选择，以减少干预的区域。选择过程不读取 32 条交错测线。随后只写一张候选体网并从成品核对全部准入项，不按四分点读数回调选边。
