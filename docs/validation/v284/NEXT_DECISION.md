# 下一项：让壁温成为 B 型珠体可调整的边界输入

现有五步主流程覆盖两档真实体网，但边界页只支持一个给定壁温 305.15 K。下一项选用同一民用试件、3 m/s 空气、293.15 K 的环境温度和已核对的恒物性范围，在该范围内支持调整给定壁温。变更后通过同一流程重新取得并标明对应工况的热流与首层温度。

先核对本分支方程与归一化方式。恒密度、恒物性、无浮力反馈、无源条件下可检验温差标量的线性缩放，压力、无量纲温差解和壁面热反力各保留来源。以原工况重放、中间温差和壁温等于环境温度的物理零值作判据。热流、首层温度、整表面功率、面积、色标和逐面导出须相符，未求得的固体壁温仍单列。图 7 的固定实验点只与它实际对应的工况比较。实施前登记具体范围、误差检查和预算；如改变气体物性、速度或适用性，另行求解与验证。[五步流程验收](RESULTS.md)
