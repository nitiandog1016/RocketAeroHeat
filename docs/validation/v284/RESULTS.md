# B 型热敏珠的单工况五步计算

B 型热敏珠现可从主侧栏选择模型、生成体网、确认边界、计算，并在同一窗口检查结果。用主窗口的计算按钮在 15° 体网上从冷初场运行，全部 **5,216 行**原面结果与 v282 已核验的原面表逐字节相同。总面积 **3.08983026 × 10⁻⁶ m²**，整珠向空气放热 **9.38210 mW**。7.5° 网格在同一流程中回读了 v283 的全表面场，放热 **9.50885 mW**。相对 v283，热敏珠和自绘模型分别新增 **0 面、0 m²**。本版解决了确认的网格与实际求解输入、结果来源及结果有效期之间的衔接问题。[冷启动逐项复核](evidence/fresh_audit.json) · [两档归档与失效操作](evidence/archives.json)

## 在主窗口运行

1. 在 MATLAB 项目根目录运行 `rocketAeroHeatWorkbench`。在「输入模型」点「选用 B 型热敏珠」。程序读取米制原面和长轴方向。
2. 在「生成网格」选 **15°** 或 **7.5°**，点「生成热敏珠体网」。中央区显示所生成 30° 扇区的实际壁面，四边形边界按三角形显示。两档体网分别有 9,359／15,533 个节点、6,144／12,288 个体单元，结果使用同一套全珠原面编号。
3. 在「添加边界条件」选择「3.0 m/s · 热珠等温」，确认 −X 向来流、空气 293.15 K、101325 Pa、给定壁温 305.15 K。
4. 在「计算」选「从冷初场计算当前试件」或「读取当前网格的已算结果」。前者调用内嵌求解器，后者核对工况、几何和网格指纹后打开归档。新计算在独立目录复制已确认的真实体网，并在求解前后按字节核对。
5. 在「查看结果」点选原面，切换压力、入壁热流或首层流体温度。7.5° 网格另有与 15° 基准网的同面差值。区域页可导出全部原面的压力、热流和方法。页内标明此次结果来自归档还是本次冷启动。

主流程的网格生成需要项目 Python 环境，冷启动另需项目固定的官方 SU2。输入页原有热敏珠快捷入口保留，可直接在 MATLAB 中打开小归档。当前主流程的几何限定为沿长轴来流的光滑名义珠体，边界页提供已核对的冻结点。[本机冷启动三维结果](../../../outputs/thermistor_0ba7e8dd-6d95-4a96-aeab-777f7b0d3228/workbench/index.html) · [本机冷启动逐面导出](../../../outputs/v284_validation/fresh01/wall_15.csv)

## 网格、状态和结果如何核对

网格步骤调用与 v282、v283 相同的内部生成器。每种离散各自绑定体网、节点映射及预处理回执。实际调用 SU2 时，预处理目录的三个输入都出现在三维阶段的运行记录中。对 15° 新计算核对了确认目录、三维前驱和强温差终场的网格字节。原生强标量终场为 `51340277bbc3e147ec3cf57372e28b99559d660dac37e6e1b9f45d9932ab06ac`，逐面表为 `08fea8e578f50c45168b2c221e9e4d8150e64b8bbafa871d4aa80e8fe9640bfe`。7.5° 另用保存的前驱场恢复该路径的三维初猜，体网、节点、初猜和配置与 v283 实际输入逐字节相同。[六份新原生回执](evidence/native_receipts.json.gz) · [两档网格输入复核](evidence/bindings.json)

工作台实际回调验证了撤销边界后保留网格、清除旧结果，切换周向离散后撤销网格和边界，更换模型后恢复初始选择。即使求解编号和版本有效，15° 快照也无法作为 7.5° 的结果接收。两个归档和冷启动均通过主结果页的 WebGL 回执，已选取工作台面号 5204，并将每份导出的 5,216 行按原面核对。[归档交互](evidence/archives.json) · [冷启动交互](evidence/fresh.json)

这些操作验证的是结果身份和全流程可复现性。公开实验只测整珠平均换热。15° 与 7.5° 网的平均换热系数分别比实验图读值高 15.73% 和 17.29%，逐面壁压、热流的联合独立验证面积仍为 0 m²。固体壁温未求，305.15 K 是边界输入。[物理精度对照](../v283/RESULTS.md)
