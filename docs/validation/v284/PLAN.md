# 民用 B 型热敏珠的主侧栏五步流程

基线 v283 提交 `9cf6b040a77564a7cf404d6535ba1547abf225d9`。从已归档的名义珠体原面载入几何；用 v282／v283 的生成器产生 15° 或 7.5° 实际体网，登记网格及节点散列，显示原生扇区壁面。确认固定物理边界后，分别提供显式读取归档和从冷态计算。接受结果要核对原面、物理条件、网格、源身份及当前工作流版本。切换网格／模型、撤销边界与失效来源须关闭旧结果。

两档匹配网格的 SHA-256 见 `cases/thermistor_b/grids.json`。归档输入为已有 `surface.zip` 与 `surface_7p5.zip`，逐面比较的参考表见 v282 与 v283 报告。网格预处理每档 1 线程、60 s、1 GiB、16 MiB，生成时不运行流场。两档归档与失效状态在真实 MATLAB 工作台验证，单批 180 s、1 计算线程、4 GiB、80 MiB。

本版新鲜计算路径首次由主工作流提供已生成网格，需证明求解器实际消费了确认的网格且终场返回同一窗口。对 15° 网格做一次由计算按钮触发的全链集成，复用现有门槛和 3 m/s、293.15 K、101325 Pa、305.15 K 的已知参考结果。原生各阶段沿用 1 线程、2 GiB、每目录 180 MiB，前驱和强标量每次最多 360 s，反力／延续每次最多 60 s。整个集成检查 480 s、4 GiB、300 MiB 新增文件；保留初场、周期帧、终场、输入版本、原生回执与配对原面表。7.5° 仅验证网格生成与归档，已通过的数值试验不再重复。试件原面分母与自绘模型分开报告。
