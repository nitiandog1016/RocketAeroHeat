## 几何、坐标与测量身份

圆柱直径0.203 m、半径0.1015 m，外扩半角20°，外扩起点在原鼻尖后1.39 m。原子午面坐标`x`沿流向增加；`S`为沿壁距离，原点在圆柱/外扩接点。圆柱段`x=S,r=R`；外扩段`x=S cos20°,r=R+S sin20°`。项目采用接点`X=0`、`X=-x`，保持鼻尖+X、来流−X。剖面`y′`从圆柱壁面量起，与网格半径关系为`r=R+y′`。

TMR网格的实际圆柱壁半径为0.10150094 m，与说明中0.1015 m有微小差别；原节点保持原样，不静默缩放。`grid_inspection.json`记录五档真实节点数及第一层节点距离。最细两区均321×401，共257442个子午面节点；两区最小第一层节点距离约2.540 μm、1.624 μm。**这不是单元中心距离或已验证的y⁺**，尚未得到求解壁面剪切，不能据此宣称近壁足够。

2026-10-18独立读取五档原节点还发现：外扩段直线拟合角约19.999867075°，相对名义20°外扩线的最大径向差约0.617213 μm；这是已保存源网格的几何精度，不应静默修改成严格解析20°。五档网格均核对两区接口一致和逐隔点嵌套。测点合同沿名义20°转换；将来求解与比较时应保留原网格、名义实验几何各自身份，并评估其影响。

原几何图只给鼻部类型/10°前锥等概况，未提供本切片可用的精确鼻部圆弧半径；截短基准不需要伪造完整鼻部。二维网格是轴对称方程的子午面，不能当作平面二维问题；也可按来源旋转成1°周期扇区，必须保留轴对称通量/源项或正确旋转周期。

## 归一化与数据问题

1. `inf`为相互作用前、`x=-6 cm`的当地边界层外参考，仍位于前体/入口激波层内。它不是任意远场，也不是M7.11计算入口。压力TMR头为`Pw/Pw-inf`，NASA作者表写作`Pw/Pinf`，作者条件给576 Pa；报告壁热参考为9300 W/m²。合同提供同一参考下的量纲转换，同时保留原比例。
2. TMR写`Qw=-k(dT/dy)w`；原数据正比例本身不能确定新求解器的壁法向和符号。合同中的量纲热字段明确定义为**原报告正的加热幅值**，不是未经法向核对的有符号Fourier通量。将来比较必须另外核对正热流到壁面的约定。
3. 入口21行的`TT/TTinf`是总温比，不能直接当静温比。所选实际下载文件没有数值化实验`TTinf`；合同保留`null`，不能套用888.888889 K计算入口总温。未测湍流剖面也保持`null`。
4. 压力TMR文件有27行，但最后`S=14.1 cm, ratio=12.5`连续出现4次；NASA原表只有该位置一个测点。保留全部原始行及`source_row`，比较选择稳定的首次出现，共**24个独立压力点**，不重复加权。热流27点，入口21点。
5. 原作者文本首个热位置写成`+12.06 cm`，同源Tecplot、TMR及报告Table IV(a)为`-12.06 cm`。合同使用后者，并保留双方原文件和这一差异，绝不静默修改源文件。
6. Tecplot压力区的`QQInf/Tau_TauInf=0`、热流区的`PPInf/Tau_TauInf=0`是未提供字段的占位，不能导入为零热流、零压力或零剪切。读取器只提取对应测量列。
7. 2013数据库README称20°附着，原报告及作者条件记分离点`S=0`、再附位置未确定；不得据此编造有限分离泡长度或实验再附点。本轮不把30°/32.5°/35°数据并入20°合同。

表面压力、热流原文估计不确定度±10%；速度±3%、总温±1.5%、剖面法向位置±0.02 cm。来源没有置信度、逐点协方差或独立比值误差传播，合同不补这些值。

## 一个区域求解器的选择依据

| 路线 | 本切片可复用 | 还必须实现/验证 | 判断 |
| --- | --- | --- | --- |
| 子午面贴体可压缩FV＋轴对称项 | NASA五档嵌套、拉伸近壁网格和明确边界；单一20°简单几何 | 曲线坐标/壁法向黏性通量、轴对称质量/动量/能量项、壁面导热、变物性、外域/出口；无黏/层流基线后再加确定版本的湍流输运及刚性推进 | **建议作为本基准首选的受限实现候选**。只承诺此轴对称区域；不是任意三维箭体求解器，也没有执行时间保证。 |
| 三维cut-cell区域黏性解 | 现有CV几何/矩/温度重构基础、与真实三角面的几何映射方向 | 高Re近壁各向异性分辨率、温度均值与守恒变量EOS的配套、黏性稳定性、湍流变量重构/壁距、合并单元热梯度及体域收敛 | 保留为复杂突起/局部三维候选；现有制造场和固定Dirichlet标量谱不能替代本实验完整NS/RANS验证。当前不能认定它已比贴体更快或更准。 |

若用SA，必须固定TMR对应的方程/开关、壁距、入口变量与Prt；一个输运变量较少，但高Mach转捩延迟和热流误差不会因此消失。若用SST，须明确是SST、SST-Vm还是其它版本，不能只写“SST”；两变量、混合函数/交叉扩散及正性增加实现负担。[TMR官方SST-Vm页](https://tmbwg.github.io/turbmodels/axiswblim7_val_sstv.html)明确本例SST与SST-Vm可产生明显不同结果。

来源比较中SA两代码使用参考SA变量/层流黏性比5；SST-Vm的CFL3D使用TI=0.1%、黏性比0.01，WIND用TI=0.021%、黏性比0.001。这些是**计算给定**，不是实验测得的湍流入口。TMR还声明没有彻底网格研究，示例CFD曲线是代表结果，不能当成真值或实验数据。本轮保存这些说明，不导入那些CFD解代替内部计算。

下一步只选择一条受限路线：先实现/验证源网格读取、轴对称无黏/层流黏性与壁热守恒；再加入一种明确的湍流闭合，核对`x=-6 cm`入口、压力分布和热分布，做网格/外域/入口/出口敏感性。是否继续采用SA或切换SST-Vm要由同一合同下的可复现证据决定，不能同时铺开通用SA/SST/三维RANS开发。本基准外扩压缩与真实31°收缩、20°攻角横流仍是不同问题，成功后也不得自动给真实箭体29.335%缺口计覆盖。
