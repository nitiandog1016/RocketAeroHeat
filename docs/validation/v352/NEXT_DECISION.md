# 同一低速风洞工况的三维热输运

已关闭两种空间离散下的全周动量与原生弱壁温焓联合试算。现有实测表明完整动量粗网能放入本机内存，下一项先解决对最终热流有直接影响的三维显热离散。

先用已验收的 0.05 m/s 轴对称速度场作为三维热输运的可复现对照。保留 48 个方位和完整平底，优先沿用已有的守恒有限元算子，分块装配，再测实际峰值。比较相同轴向与近壁分辨率下的三维回转对照与 v350 粗热网，核对温界、各区放热、底面径向积分和全域收支；事前冻结准入误差与 4 GiB 预算。若粗热网不能通过就结束该组合。通过后才评估与独立恒物性动量方程同一时间层的传递和流体储热，轴对称速度对照不能提供实际的周向尾迹变化。[已测资源与失败](RESULTS.md)
