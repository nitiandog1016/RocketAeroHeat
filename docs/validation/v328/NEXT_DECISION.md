# 下一项只统一双支管银球远场的实际质量通量

保留 v328 已通过的节点余量修正、隐式预测、六分量门槛和原始冷态。唯一更改是从不可压流动求解器的远场 FDS 残差中逐边界节点取得真实质量通量，在同一状态、同一节点和同一外法向下，同时用于标量远场迎风项和质量散度修正。v328 的两个端点都存在约 12.87 mW 的壁面与标量远场差额；用已测流动质量通量做同态求积，首端点的差缩小到约 33 nW。两种边界质量通量有一个节点的符号不同，迎风状态也要据实际传入值选取。[物理收支与逐节点明细](RESULTS.md)

在固定 SU2 8.6.0 的 `CIncEulerSolver::BC_Far_Field` 记录流动实际装配的质量分量，使 `CScalarSolver::BoundaryFluxResidual` 的试件分支直接使用这一数据；散度项的残差和对角一致更换。公共默认驱动保持可复现。核对当前流动迭代、边界节点一一对应和方向，拒绝复用旧帧通量。原生函数的实际采样入口在本版只读观察器中已验证。[观察器构建与数据](endpoint.py)

用同一网格、定温、Re = 882 和冷态推进。首轮固定 4 线程，每 200 次 ≤300 s、4 GiB、450 MiB；保存周期及终点，沿用已有界限、末窗残差及停止条件。检验两处远场通量逐值相同、入流使用给定标量、出流使用内值。收敛后重复给定壁温的释放反力、追加 20 次热稳定及两端点物理差额 <0.5% 检查。采用新方程所产生的真实场和远场输出。通过后立即按 v325 五区交叠返回原面，区分计算覆盖、空间分辨率与实验精度，接入同一工作台的逐面结果。若仍失败，保留第一次失败状态及实际边界贡献。
