## 成熟方法取舍

PETSc已固定到官方标签[v3.26.1](https://github.com/petsc/petsc/tree/v3.26.1)，标签对象`ad945ac5124a1c59e557fb8a196df057711726a2`；6份完整官方文本逐个Git blob核对。其FAS允许逐层平滑器、可选粗修正线搜索及函数域错误处理，细层默认NRICHARDSON、粗层NEWTONLS，FAS不支持变量bounds。当前没有现成的SU2六状态/逐层函数、预条件、状态恢复与能量接口桥接，**暂缓完整替换**，未安装或编译PETSc。初次release API 404、tags连接器不支持均保留，标签列表通过只读Git取得。

选择已有SU2 8.6 `CNewtonIntegration`作一次真实整体相容控制。它调用原生空间残差、原生预条件和FGMRES差分乘积，再由原`CFluidIteration`完成独立SA更新。`AddSolution`是`Solution_Old + increment`，不是累计叠加多个Krylov扰动；Jv还包含伪时间对角项。`nkRelaxation`用于重构/近似算子，**不等同于残差回溯**。源码明确仍有back-tracking TODO；它不是已实现完整残差线搜索的方案。

采用理由是能够复用现有物性、实际残差、原完整几何、湍流和成熟对象，避免再开发通用求解内核。是否更能收敛仍须有限发展验证，不能凭库名或一次成功授予生产。

- 唯一1次完整flow-SA：80.031秒、exit0、1CPU，峰2487496704B（约2.32GiB）。只薄构建6.578秒，成熟数值对象零重编。
- 实际工厂`dynamic_cast<CNewtonIntegration*>`通过；5次flow空间评估、1次SA评估，20条flow空间/6条SA阶段记录完整。按固定源及关闭启动期推定4次差分乘积，与原生4次线性迭代相符；并非直接保存了每个乘积的方向向量。
- 原生线性残差log为−6.062916848；这是原生线性报告，非独立Jacobian或稳态证明。SA仍是原生分步更新，不称五量/SA单体耦合。
- 0次物性恢复；若差分期间触发旧态恢复则控制拒绝，不能把恢复后的函数值用于声称有效Jv。

- 新末温度最低61.58886K，仍接近60K域下界；不能据此预承诺后续安全。一步后的工作RHS不是末状态空间残差，本轮没有再执行冻结整域评估，也没有证明非线性残差下降。

有限差分步由内部能量坐标范数产生，不能声称任意能量零点下完全相同或准确Jacobian。下一必要任务须明确乘积/试探/实际接受阶段，见[执行点](validation/v249/NEXT_DECISION.md)。
