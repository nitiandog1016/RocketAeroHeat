## 存储与恢复

对象库位于 `outputs/mat_history_store_20261031/objects/`。本目录 `manifests/` 中20份 `.matmap.z` 保存记录顺序、原文件SHA、每块SHA和原MAT头。对象库仍仅存在本地，GitHub同步源码和小型清单不能替代对象库备份。不能单独删除对象库中的文件。

旧结果目录旁的 `EVIDENCE_ARCHIVED_20261031.json` 提供恢复入口；旧MAT路径不再直接可读。更早的 `LINE_CACHE_PRUNED_20261031.json` 仍表示当时的矩阵清理，顺着本轮标记即可找到完整保留数值。旧审计若要求这些MAT，应先恢复到新目录并明确更新输入路径，不能将对象库当作可直接交给MATLAB的MAT。

在工程根目录恢复一份旧结果到新目录：

```powershell
python scripts/archiveMat5History.py restore --store outputs/mat_history_store_20261031 --manifest docs/validation/storage_20261031/output_review/manifests/v83_krylov20.matmap.z --target outputs/restored_history/v83/krylov20/wall_velocity_krylov_evidence.mat
```

恢复程序不覆盖已有文件；必须完整恢复并通过输出的 `passed-exact-original-file-SHA` 检查后再使用。当前环境为Python3.7.7/zlib1.2.11；逐字节恢复压缩容器要求同版zlib，不匹配时明确拒绝，不承诺跨版本压缩流SHA自动一致。全部原始MAT元素已保留，归档不是重新计算。
