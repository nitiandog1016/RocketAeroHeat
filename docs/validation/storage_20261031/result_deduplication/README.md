## 审核与删除

1. 13项测试通过，覆盖原MAT字节恢复、科学类型/特殊浮点、并发共享、损坏拒绝、当前状态/越界拒绝和新增共享对象计量；PowerShell语法通过。
2. `scope.json`、`inventory_before.json.gz` 绑定固定范围和清理前实际占用。
3. 归档器完整重构每份MAT的SHA；另一进程使用独立实现再次重构，输出 `predelete_archive_audit.json`。
4. 原生PowerShell在核对全部共享对象、保护文件、工具、恢复清单、原SHA和硬链接范围后，逐个删除原容器。每份旧结果旁先写恢复标记，不递归删除目录。
5. 删除后再次核对其余原文件、保留依赖、全部共享对象及恢复清单，分别记录净数据长度和磁盘空闲变化。

`postcheck.json` 记录完整SHA后验；`final_postcheck.json` 记录仅更新README之后的全目录身份复核和小型说明SHA，不重复读取整库大数据。两份完整目录盘点与最终盘点分别保留在压缩JSON中。`readme_update.json` 和 `outputs_README_before.md.raw` 保存用途说明变更；27份精确工具/清单Git字节已核对。本轮没有运行MATLAB，没有改写原失败身份或改变区域资格。

## 恢复

旧结果旁的 `EVIDENCE_ARCHIVED_20261031.json` 指向本目录 `manifests/`。恢复到一个**尚不存在的新文件**后使用，例如：

```powershell
python scripts/archiveMat5History.py restore --store outputs/mat_history_store_20261031 --manifest docs/validation/storage_20261031/result_deduplication/manifests/v83_krylov01.matmap.z --target outputs/restored_history/v83/krylov01/wall_velocity_krylov_evidence.mat
```

恢复需要完整对象库和对应清单；对象库不能直接作为MAT加载，不能单独删除共享对象。逐字节恢复压缩容器使用记录的Python3.7.7/zlib1.2.11，并验证 `passed-exact-original-file-SHA`。本轮SHA属于已经剥离旧矩阵的保留结果，不是最初含矩阵的v83完整容器；旧矩阵仍需按此前记录在新目录重建。

源码、测试、小型清单和回执按约定同步公开GitHub，大型对象库保持本地，不生成工程ZIP或隔离工程副本。当前科研目标和下一次计算起点保持。
