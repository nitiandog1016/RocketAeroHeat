# 核对球形远场对带线热敏珠侧吹结果的影响

20D 全周侧吹已得到完整壁压、热流和七区功率。下一项把同工况的远场半径从 20D 移至 30D，用程序内部新算的完整场验证目前采用的弱远场截断。面向 299.15 K 给定壁温、3 m/s 沿 −Y 的来流，保持 10,272 个原面、原 20D 内所有单元和壁邻层。以 v311 热峰、X = 0.172 mm 周向曲线和七区功率为针对性比较项目。[20D 全周基线](RESULTS.md)

先核对既有外接网壳工具能否在完整 360° 域保留接缝和原生壁节点，检查原 20D 边界能否成为合法内面，记录 30D 实网的内存、磁盘及每步耗时预算。原物理门槛沿用。按相同原面报告绝对压力变化、入壁热流变化、七区及整件放热变化、热峰位置与两侧截面功率密度。该项结束后单列外域差异，近壁／周向离散误差仍需自身证据。
