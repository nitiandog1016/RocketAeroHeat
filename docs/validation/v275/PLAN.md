# 从导入 STL 在五步工作台上计算低速 CM-011 试件

基线为 v274 提交 `7dfcf9cd8441c4f8938330a2c4288b00acecc8aa`。使用 v274 已导出的米制 CM-011 STL（92ca7196ee04bcbe99bd2878beaab2435e1bdee1d02009ed65257a09debf1609），速度 0.1 m/s、α=+10°、β=0°、空气 300 K/101325 Pa，给定壁温 300.1 K。保留该 STL 的实际坐标、拓扑及三角面编号。对照试件的原面参考为 v274 body.json（07588689…）。仅接受与该试件几何、尺寸、朝向和有向三角面一一对应的导入表面。允许顶点和面列表重排及循环换序。逐点几何容差 5×10⁻¹⁰ m，覆盖 STL 单精度舍入。重新从导入坐标测量各环的 x 和半径，据此生成三维半域体网和角向映射；校核单位、原面编号及几何偏差。

在同一宿主五个步骤中加载 STL、确认朝向、生成体网、确认固定工况、显式求解、显示与导出。浏览页面不重新求解，网格实例可用于再次显式计算，各次使用独立目录。测试原文件和打乱编号的对应关系，拒绝坐标超差、错误尺度、拓扑改变和不支持的边界；修改上游输入后不能访问过期结果。原有工程入口沿用原验证合同。

几何核对和网格准备限 60 s、1 CPU、1 GiB、32 MiB。沿用 v274 固定 SU2 8.6.0 官方程序及低速半域离散，最多 12,000 步、720 s、1 线程、2 GiB、160 MiB。保存完整初场、周期重启/固壁和正常终态。五分量最近 20 步原始 log RMS 均小于 −8，壁热相对极差 <0.2%，检查有限性、正压、无滑移和对称面。用同工况 v274 原面结果按实际编号独立对照压力、热流、温度、面积、功率及截面 CSV。预定容差为壁压表压差 10⁻⁵ Pa、热流差 0.005 W/m²，功率相对差 0.1%。MATLAB 主界面实际控件回调端到端一次，进程组限 420 s、4 GiB、160 MiB；允许失败后只修复对应软件问题，保存失败回执。程序化调用回调和离线截面代码，不使用 computer-use。此轮验证导入/计算的完整性，实验精度另列。

二进制 STL 独立预读确认 7072 个顶点、14140 面。最大顶点偏差 1.442×10⁻¹⁰ m，最大环拟合偏差 1.089×10⁻¹⁰ m。按参考编号稳定加总实际环半径后，体网 SHA-256 为 adfd4123…，初场 8eb498ab…，配置沿用 f93b190b…。工作台新生成的网格和初场应与本次 STL 预读一致。

新网格与 v274 几何略有差异。对达到数值门槛的新终场另作一次独立边界能量审核，复用 v274 已编译的同一 15325 节点低速观测程序。官方与观测各单步、单线程、限 30 s/1 GiB/32 MiB。要求完整初态五变量逐点一致，更新后两种程序的最大差小于 2×10⁻⁷，镜面净通量为零，原生壁面与远场热差小于壁功率的 0.5%。保留独立回执，不借用旧工况的收支。
