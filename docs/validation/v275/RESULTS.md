# 在五步工作台从 STL 计算 CM-011 的 +10° 全表面场

主工作台现可直接导入以米为单位的 CM-011 低速缩比试件，生成三维体网，从均匀初场计算并在原窗口查看结果。实测 **14,140 / 14,140 个导入三角面**均有壁压、入壁热流、壁节点流体温度和首层流体温度。总表面积为 **3.734978857×10⁻⁵ m²**，原面积分入壁功率 **−111.163300 µW**。负号表示 300.1 K 的试件向 300 K 的空气放热。自绘模型的同面工程覆盖仍为 **43.10%**，本轮新增 0 m²。[本机离线结果](../../../outputs/v275_validation/gui01/workbench/index.html) · [原面独立核对](evidence/verification.json)

## 在主窗口中使用

在 MATLAB 项目根目录运行 `rocketAeroHeatWorkbench`。随版本提供的 STL 来自本项目 v274 的缩比几何导出。[米制 STL](../../../cases/CM011-mm-scale-SI.stl) · [试件几何及工况来源](../v271/RESULTS.md)

1. **输入模型。** 将「原坐标 → m」设为 **1**，选择 `cases/CM011-mm-scale-SI.stl`，确认主轴 X、鼻尖 +X。
2. **生成网格。** 在「网格方法」选「CM-011 低速半域」，点击「核对原面并生成半域体网」。此时可查看导入面数、体单元数和几何匹配偏差。
3. **添加边界条件。** 在「试件工况」选「CM-011 · +10° 等温」，确认边界。该工况为 0.1 m/s 来流、空气 300 K 和 101325 Pa、给定壁温 300.1 K、零侧滑。
4. **计算。** 点击「计算 CM-011 全表面压力与热流」。程序为本次计算创建独立目录，通过内部 SU2 求解三维不可压层流和能量方程。
5. **查看结果。** 在原窗口选「相对环境壁压」或「入壁热流」，点选原面或调整 X 截面。在导入模型的锥面环 **X = 0.0014800255885347724 m** 处，工作台截面由 69 段组成。压力和热流 CSV 均保留原面编号、单位和算法。[压力 CSV](evidence/pressure_section.csv.gz) · [热流 CSV](evidence/heat_section.csv.gz)

## 导入面与求解面如何对应

加载时绑定 STL 字节指纹和单位，生成网格时核对已经确认朝向的 SI 坐标。当前适配器支持与这份 CM-011 试件的顶点及有向三角面一一对应的输入，可以改变顶点和面列表顺序，也可以循环改变三角面的起始顶点。节点容差为 5×10⁻¹⁰ m。实测最大点距为 **1.442×10⁻¹⁰ m**，与二进制 STL 的单精度坐标舍入相符。MATLAB 导入后的 90 个顶点编号与原预设不同，网格、结果、探针和导出均使用实际导入的 V/F。

由导入节点重新计算各环的 x 及半径，最大环拟合偏差为 1.089×10⁻¹⁰ m。体网取自这些实测环，沿用 49 个求解母线站、24 层法向网格、12 个半周角向单元和 12D 外域。生成的 15,325 节点、13,824 单元体网与预设网格的字节指纹不同，与另一程序从同一个 STL 独立预读后生成的体网一致。完整面积使用导入三角面自身的面积。空间、近壁及实验精度待独立验证。[网格和注册误差](evidence/geometry.json) · [运行合同](PLAN.md)

## 验收范围

实测主界面的五步控件回调。更改工况选择、网格方法、朝向和单位后，状态控制器撤销旧结果；工况变更后销毁旧结果页。错误尺度在生成体网时被拒绝。对调顶点和面列表仍能得到同一物理对应；局部坐标超差、反向面、重复面和错误的准备回执均被拒绝。另从当前状态尝试接收不同准备回执的旧快照，完成动作拒绝了该快照。切回常规工程模式后，原工程飞行设置恢复。[工作流回执](evidence/workflow.json) · [拒绝与设置恢复](evidence/rejections.json)

分别对已导出的压力和热流 CSV 逐行检查原面编号、场值和方法。用真实运行的 MAT 快照测试 MATLAB 结果宿主：WebGL 报告 14,140 面、696 个可见像素采样、错误码 0。向选面回调送入第 1、7000、14140 面事件，三处的顶点索引、壁压和热流都与同一导入面一致，越界编号被拒绝。这项检查未执行实体鼠标拾取。[探针与绘制回执](evidence/probe.json)
