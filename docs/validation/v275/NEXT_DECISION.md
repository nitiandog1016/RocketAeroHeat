# 下一项：让同一低速试件接受不同的 STL 三角剖分

五步工作台已能从真实导入面生成体网并计算 +10° 全壁场。当前几何准入要求顶点和三角面与参考剖分一一对应。CAD 导出时仅改变三角剖分也会改变这两组数量，这是下一项要解决的实际限制。[本轮结果](RESULTS.md)

仍使用公开 CM-011 光滑缩比试件和已经核对的低速等温工况。用第二种独立表面剖分导出 STL，从实际导入坐标判断尺寸、朝向、闭合性、旋转外形和各区范围，建立与求解壁面的几何对应。用输入文件自己的三角面数、面积和编号返回结果，保留实测偏差及拒绝原因。先用原剖分回归，再比较第二种剖分在相同物理位置的壁压、热流和全壁功率。两组均通过后接回现有工作台。空间与实验验证资格继续单独报告。
