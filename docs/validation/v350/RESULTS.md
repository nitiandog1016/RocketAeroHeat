## 方法与误差

压力来自 SU2 8.6.0 恒密度不可压层流动量方程。零攻角使本次数值模型可在子午面求解。能量采用单向耦合的稳态轴对称对流扩散方程，含半径积分权。Gmsh 4.15.2 独立生成近壁热网。在同一流体域内插值 SU2 速度，流函数最小二乘投影保证质量通量连续。温度采用线性三角形有限元、守恒低阶代数上风和强等温边界，轴线上使用对称条件，开放出流。对原面面积积分分配壁反力，底面从轴心积分至外缘。SciPy 稀疏直接法解线性方程；每个工况的源帧、表面和结果表分别具有校验值。矩阵的低阶对称扩散采用 Kuzmin 和 Möller 在 *Algebraic Flux Correction I: Scalar Conservation Laws* 中描述的成对消除正非对角项构造。[风洞流动入口](../../../scripts/simpleLauncherTunnel.py) · [显热与映射](../../../scripts/simpleLauncherTemperature.py)

粗细网整件功率差 **2.13%**。固定细网速度场只改变热网间距时为 **2.52%**，固定热网目标间距只改变速度网时为 **0.38%**。远场半径由 14D 增至 22D 并相应调整径向层数后，整件功率差 **0.068%**。粗细网原面热流的面积加权相对 RMS 差为 2.79%，壁压 RMS 差为动压的 0.61%。局部放热密度峰值更敏感，粗细网相差 **8.49%**。底面区域总放热粗细网相差 **4.69%**，扩域差 **1.44%**。这些数值衡量离散和外域的影响，尚无同形实测误差。

发布网原生四分量末窗均低于 −8。无量纲温差全域介于 0 与 1，前后两个速度保存帧的整件放热相对变化为 5.6×10⁻⁹ 以内。温度原方程归一残差为 2.6×10⁻¹⁵ 以内。壁反力与远界显热对流、导热的同态离散收支相对差低于 6×10⁻¹⁵。速度流函数投影的面积加权通量相对差约 0.81%。求解器未对温度场裁剪。[发布面表 ZIP 内的 summary.json](../../../cases/simple_launcher/wind_tunnel.zip)

## 已拒绝的热场

首个二维弱焓结果的壁温偏离给定值，三维对称扇区的原生强温差仍有 94 个流体节点越过低温界。沿用流场射线节点的有限元显热计算满足温界与守恒，但粗细网放热相差 34.96%，也未用于最终图。独立热网解决了当前工况的数值敏感性问题。初始界面回读另发现识别代码放在 RFZ 恢复路径，导致普通 STL 仍按旧工程模式重构；已改至实际文件加载入口。工作台按原 STL 面号接受结果，输入几何的普通重构对照（13,338 面）单列保存。[运行合同](PLAN.md)

## 一次点击与独立复算

从默认五步工作台点击计算，程序在新目录执行三次 SU2 冷启动及四次独立热网计算。点击到最终 WebGL 云图为 **418.19 秒**，含启动 MATLAB 和检查导出的整个测试为 442.03 秒。冷启动产生的三个原生终场及 9,216 行壁面表与先前独立运行逐字节一致。最终同工况归档从点击到出图为 **4.75 秒**。两条路径都在六个区域完成面元拾取，取得 X = 0.7 m 的截面并导出全部原面。壁压与热流导出保留方法和单位。首次冷启动测试后完善了来源标记，最终归档导出逐面标有可追溯的源帧。独立读回两份导出表，将壁压换算为 Pa 后与原结果逐项相同，热流和整件热功率也相符。[运行、输入指纹与导出核对](evidence.json) · [独立核对程序](verify_delivery.py) · [本机三维工作台](../../../outputs/v350_validation/ui_archive03/workbench/index.html)
