# 简化运载火箭外形接入

基线为 v349。用户要求更换 RFZ，使用正常火箭的完整简化外形。采用项目已有光滑箭体的 48 点周向版本，以米制 STL 随项目交付，作为工作台预选模型。原自绘模型和 RFZ 各自保留编号及来源。

核对实际交付 STL 的完整面序、分区、单连通闭壳、绕向和尺度。用默认 MATLAB 工作台加载、确认朝向并生成表面网格，分别记录输入面数和重构网格面数。验收运行使用一个 MATLAB 进程、一个计算线程，预算 180 秒、4 GiB 内存、30 MiB 新测试输出。触及预算或断言失败即停，保留回执。此次验收对象是几何与导入，不测热流。

## 用户确认的低速风洞工况

在上述几何检查之外，用户已授权实际计算低速风洞工况。采用原尺寸、零攻角轴向均匀来流 0.05 m/s，环境 300 K、101325 Pa，全部实体外壁给定 300.001 K。取项目现有 300 K 常物性空气值。气动模型为无支撑、远场自由来流近似的轴对称层流强迫对流，忽略浮力、辐射和固体内导热。三维原面从同一轴对称解积分取得。

先复用官方 SU2 8.6.0 的不可压黏性与能量方程，冻结 9,216 个 STL 原面。粗网、近壁及沿面加密、扩域三步顺序核对。每网保留初场、周期场、末帧及真实终态；单次最多 720 秒、1 核、4 GiB、2 GiB 输出。末 20 行四个原生残差均低于 −8、热功率波动低于 0.2%。核对全场温界、入壁符号、壁面覆盖、能量收支及网格与外域差异。热功率守恒差目标 0.5%，两网整件热功率差目标 5%，逐区差异及局部峰值另报。两轮同类失败停止该组合，不裁剪温度、不放宽门槛来发布云图。几何文件可以先行交付。

初次二维原生弱焓收敛后，其壁节点无量纲温度为 1.997037–2.025667（给定为 2），域内最低 0.989555（来流为 1）。保留该失败。下一组合改用项目已有的三维对称扇区、SU2 强等温被动温差和释放壁反力。恒密度常物性使该标量与显热方程相同。由当前 STL 从静止壁、均匀来流及温界产生初场。全部六分量末窗 <−8，强温差全域须在 [0,1]（舍入容差 1e−12），热稳定和能量门槛沿用上文。相邻扇区按几何镜面对称延拓。仅该固定低速工况可使用这条分支。

三维原生强温差末步 5165 有 94 个节点低于 −1e−12，最小 −0.0026006704，故关闭射线网原生标量候选。固定同工况，采用单向耦合的二维 SU2 恒密度动量场与轴对称稳态显热输运。用 Gmsh 约束三角剖分并保留原壁，流函数投影保证离散质量守恒。采用线性有限元与守恒的低阶代数上风扩散，强制等温壁及入流温度、自由出流。该格式更耗散，须通过同一网格和外域热功率门槛；不得用裁剪代替温界检查。线性原方程归一残差 <1e−8，温界及能量门槛沿用上文；用不同的已保存速度帧独立复算热稳定。独立温度步骤每网 180 秒、单线程、4 GiB、100 MiB。

基于原流场节点的低阶热网通过守恒与温界，但粗、细两网整件放热分别为 1.48730、1.10203 mW，按细网计相差 34.96%。停止使用射线节点作为热网。保留同一速度求解与温度格式，只改为按离壁距离布点的独立 Gmsh 三角网，壁边保留原形，线性插值同域速度。壁边目标间距粗/细为 0.004D / 0.002D，在同一速度场与两档速度场上分开检查热网误差和动量场影响。沿用 5% 总功率、0.5% 守恒门槛。另列原面压强、热流加权 RMS、各区功率及热峰敏感性。独立网若仍未达到门槛，不将已有候选值当成最终云图。

独立热网和 22D 外域通过后，用 MATLAB 默认五步入口分别验收同工况归档及“计算”按钮冷启动。冷启动含三次顺序求解及四次显热求解，整体预算 2,400 秒、4 GiB 内存、6 GiB 新输出，各子步骤保留上述限制。记录从点击到完整云图可用的时间。两次比较全部原面、总功率、六区拾取、截面和导出。
