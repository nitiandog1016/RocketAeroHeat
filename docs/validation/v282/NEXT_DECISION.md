# 下一项：检验热敏珠角向离散对壁面换热的影响

B 型珠体的 5,216 面已有完整的同工况壁压与热流。现有三套网格都采用 15° 角向单元，因此扩域前后平均换热系数只差 0.53% 仍不能判断角向误差。整珠平均 h 比图 7 的点读数高 15.7%，近壁／子午网格变化引起的最大局部热流差达 14.08%。[全表面结果](RESULTS.md)

下一次只改变该名义珠体 20D 扩域网的角向分辨率，将同一 30° 扇区的两个单元细分为四个。保持几何、固定原面编号、来流、物性、近壁与子午网格、强等温标量及收敛要求。实施前另登记输入、资源与停止条件。用原生壁反力、同阶段边界热量账、整珠平均 h 和原面热流差判断角向离散能解释多少偏差。达到一次对照终点即记录结果；若差异远小于实验偏差，保留安装和名义形状的影响待定。自绘模型原面和全周期目标继续各自记账。
