## 下一项有条件采用成熟线性求解方案

现有真实配置使用BCGSTAB、LU_SGS、线性目标1e−5、最多10次。当前历史只有原非线性残差/气动/热指标，缺少实际线性迭代次数和达到的误差。固定源已核对`LINSOL`及流动/湍流记录，并确认原生FGMRES与ILU(0)入口。此依据支持一次有界对照，实际原因和效果待检验。

1. 逐字复用v160局部149作为两个候选的共同冷重启源，使用已有phase-v2。原网格、原面、物性、SST、Roe、二阶/WLS、CFL及给定Tw保持。分别标注源149、本段局部步号和累计更新，冷重启会重建自适应及线性历史。
2. 运行前登记一项控制最多50更新/300秒/2线程/4GiB。仅增加原生`LINSOL`历史记录，输出0/49，预算1024MiB；按实际原字段再次核对容量。恢复合同仅允许有声明的历史诊断及随后线性方案差，来源和输入SHA始终核对。原生编译和同类小流场预算0。
3. 检查控制段的实际流动与SST线性迭代数/误差。若多数更新达到10次上限且误差仍高于1e−5，才实施同源FGMRES+ILU(0)候选，线性上限50、容差1e−5，至多50更新/300秒/2线程/4GiB/1024MiB。这是一次预先定义的线性求解组合，禁止扩展参数扫描。
   候选使用显式线性数值对照身份并记录允许差异。当前`samePhysicsAndNumerics`合同仍只适用于原数值设置，新增候选须单独验证物理/空间离散相同及线性设置差异。
4. 控制已能达到线性目标时停止该候选支线，形成后续完整域决策。即使候选改善线性求解，也须检查四项原logRMS、阶段热状态、温区、y+、壁温满足误差、区域p/q及热功率，物理资格按原完整门槛继续验收。
5. 两段相同本地更新数才作末20平均log及末帧对照，提前异常/超时单列。采纳筛选要求密度及能量末20平均log均改善至少0.3，k/ω恶化不超过0.1，阶段/温区通过，y+及相邻区非物理极值无恶化；具体尺度在启动前登记。未过时关闭该线性组合，不自动续跑或叠加新参数。
