# v216已知拓扑缺口的单次连接决定

原design03七域完整覆盖，但afterbody有两个连通分量，因此原分区拓扑接受为false；该结果保持。出现原因是轴向几何选取与唯一责任并集可以包含独立外域单元，不是原母网格断开。其余六域连通。

另登记**一次只读最短图路径补齐**：在已验证的母单元面邻接图上，从小分量到主分量找最短无权路径（SciPy现成图算法/确定性BFS），只把路径中缺少的完整母单元加入该求解域。原单元责任、原壁责任、已有覆盖、所有坐标/连接均不改，不删除孤立单元，不扫描区域宽度。路径必须不新增物理壁面，并使该域单连通；失败则关闭本修复，不另尝试。预算≤30秒/4GiB/128MiB，包含在原120秒离线总额内，无网格/原生准入。

v2接口按已存在的供体责任域分为自然邻区patch。单大文件超过16MiB不放宽；每个邻区patch独立绑定同轮次/构建/源帧/母面集。当前只核算最小负载和在64KiB元数据前提下的紧凑格式上界，实际大接口导入峰值/生产分派仍未测。

数值numerical01正确计算了高精度求和，但在±结果相减前转回double，不构成全程70位差分。保留其原报告，numerical02让相减及除以2h也在70位进行，仅最终差分转double；无需任何新原生数据。该只读恢复同属原总预算，不改变h/尺度/门槛。
