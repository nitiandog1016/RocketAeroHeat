# 回到冻结工况的原面缺项

首要交付是一个选定时刻的全表面三维壁压、入壁热流和有物理定义的温度，并能在同一工作台查看。自绘主算例已有 9,725 / 19,752 面同时具有工程壁压和热流，尚缺 1.117875 m²。低速圆柱的两种初步推进方案均已比较，六站实验及三维诊断保留为独立测试资产。该参数试验至此结束。[主算例面积分区](../v263/RESULTS.md) · [圆柱比较](RESULTS.md)

下一项恢复 v263 已具名的**同一工况侧壁缺热区域**。从已定位的 936 个有工程壁压、缺热流的原面交付首个具有适用输入的子区域。该组面积为 0.0957078182 m²，是候选范围。按原面编号在同一冻结时刻交付有依据的热流、所用方法、相关温度与状态，在原工程台账上核对新增交集，并在同一三维工作台查看和导出。已有来源复查、失效位置和被拒候选直接复用。启动新数值工作前登记相应输入、边界、预算、停止条件。没有适用来源的面逐项保留未知。退出本项的依据是实际新增同面结果，或证明某个具体候选因缺失输入无法产生结果并转向下一个有依据的区域。[具名任务与已查明的缺项](../v263/SIDEWALL_TEMPERATURE.md)
