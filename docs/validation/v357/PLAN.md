# 0.600 s 低速风洞动量网格对照

基线 v356，提交 `4b06dbc09795fc33a99e74fc9f303ac5feeee20f`。固定 0.05 m/s、300 K 空气、300.001 K 壁温、14D 外域、48 方位、原 9,216 面及弱扰动初场。将原子午面全部 108 个沿壁间隔二分，36 层中的内侧 16 个间隔二分，得到 216 个沿壁间隔、52 层。旧节点、外界折线、壁面轮廓都保留。原首层射线边长 0.960 mm，新值为 0.480 mm，另量取相对于壁面的法向高度。初始压力和速度按 v352 实际两份种子在原子午三角形上线性延拓，不独立重选稳态解或归一化扰动。热网及温度初场分别绑定 v355 的 624b1cec…、05bb19a5…；复用 v356 已验收的粗动量对照。

预计 547,066 节点、539,136 体单元。粗动量首步 190,106 节点、峰值 1,212,968,960 B、171.56 s。按节点线性估算为 3.25 GiB，另留 15% 后约 3.74 GiB。建网与初场限 240 s、1 线程、4 GiB、600 MiB。先核对实际间距、节点数、正体积、内外边拓扑、原面与远界面积、共有点初场、热网指纹，再允许一次首步。SU2 8.6.0 沿用相同空间格式、0.300 s 物理步、每步最多 600 次内迭代、4 线程、4 GiB RSS、720 s、600 MiB 新输出。仅当原生正常终态且末 20 行四个压力／速度分量最大 log RMS 各 <−8、正压、壁速 <1e−9 U、输入稳定时继续第二步。超限或科学拒绝即归档该尝试。两个动量步均通过才比较 0.600 s 的全表面。

显热使用同一 v355 热网、初始温度、两半步与守恒投影，逐步检查原方程相对残差 <1e−8、归一质量差 <1e−8、总投影修正 <5%、温界和含储热收支差 <0.5%。每次限 240 s、1 线程、4 GiB、300 MiB。用相同原面面积及邻接面序核算壁压差的面积加权 RMS（以动压计，目标 <5%）、热流相对 RMS（以加密动量结果为分母，目标 <5%）、整件放热（<5%）、六区及鼻端热峰（各 <10%）。固定 48 方位，不推断周向收敛阶。已保存的原面压力采样定义需保留；若加密产生新的壁面采样点须交代原面面积积分。单列首层温度采样位置。若数值超限，仍报告差异及范围。只有完整同刻新结果才接入工作台，并核对面表、来源和单位。全程使用独立目录。
