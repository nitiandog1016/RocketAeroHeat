# 共享入口回归与原面出口

新旧动量网共用了扇区展开、物理步终态核对及显热推进。原几何生成器在独立空目录执行一次文件重建，限 180 s、1 线程、4 GiB、300 MiB；核对 v352 已发布的体网、两支速度种子与测站文件的四个 SHA。已通过的粗动量步从原回执读回。

仅在两步动量和两步加密网驱动的独立显热都通过时，打包 0.600 s 的原面数据。运行普通侧栏“读档”和“计算”，前者限 240 s，后者限 300 s，每次 1 核、4 GiB、300 MiB。依次核对正常三维渲染、对照网壁压与热流、两项差值和首层流体温度、六区探针、X=0.7 m 的实际截面、共同及差值色标、9,216 行导出和压力／热流联合表的主结果身份。没有匹配的可选对照来源时保留已有主工作流。大体场留在原作业目录。
