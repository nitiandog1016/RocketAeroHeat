# 在带双支管试件上求首个有时间步对照的物理时刻

回到单时刻全表面交付。选定同一 Re = 882 双支管试件，以 v332 的 128 扇区、十层网稳态终场及给定温界为基线，建立同一初场的一整步与两个半步，在一个明确的物理时刻交付两套全表面结果。两轮空间对照显示，整件放热和热峰变化都很小，七站 RMSE 仍约 4.9 Nu，背风反向区和变号位置对切向网距敏感。本次结束稳态周向加密对照，优先检验非定常尾迹与壁面换热能否在带支管的完整装置上作同刻核算。[本轮证据](RESULTS.md)

先核对双支管当前有界温差更新与物理时间项能否在同一离散收支中闭合。光滑球已有构造扰动、真实时间与同刻比较的实现；双支管需要自己的体积、壁片、给定温界、共享远场质量通量和未限幅残差。只复用物理定义相符的部分。固定一个可追溯、离开湿壁的局部扰动；登记扰动前后初态、精确时间步、源与预算，采用已验证的时间格式或另作一致性验证。检验每个物理步的实际内迭代、温差界限及包含流体储热的壁面—远场收支。不能从稳态功率差或伪时间历史推定真实瞬态。

通过后在相同终时刻比较全体 32,480 面的压力、入壁热流、温度身份、两站 Nu、热峰与反向区，标明 dt 及物理时刻并接入工作台。一个时刻只验收该时刻的解和步长差；实验精度及周期统计另计。若时间项、储热账或资源不满足，保留原稳态结果和失败的具体步骤。下一次运行前按本机实际规模另行登记预算和收敛／步长误差门槛。[光滑球同刻对照](../v322/RESULTS.md)
