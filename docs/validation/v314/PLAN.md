# 同一带线热敏珠的 48／96 周向间隔对照

v313 的发布提交为 `6c5cccbe4fdc40711cb3ee1fa70f60c449e1d930`。恢复时本机与远端 main、v313 一致，v314 空闲，无本轮求解进程。基线取前端面已细化的 20D 热敏珠，3 m/s 沿 −Y、空气 293.15 K、101325 Pa、给定壁温 299.15 K。使用 v313 的原网与正常终帧，逐项核对网格、原面、工况、末窗、壁反力与能量回执。本机基线位于 `outputs/v313_validation/prepared01`、`steady01`。[来源指纹](../../../cases/thermistor_b/sidewindTipSpacing.json) · [上一决定](../v313/NEXT_DECISION.md)

在每一对相邻子午面之间插入周向边的弦中点，原壁、原远场、所有旧节点和 10,272 个原面保持原位。完整体域内每个单元沿周向分为两半，轴线和接缝共享编号。新增流体节点初猜取其两个端点的平均，随后求解全部自由度。对 96 档原生壁片三角剖分，将它们与每个原报告三角形相交。按交叠面上的线性形函数积分分配壁反力和压力。核对逐原面面积、逐细面面积与一阶矩、非负权重、原面覆盖、全域拓扑和体积。温度取两网共有的 v313 实际首层节点。建网和独立读回各限单进程、240 s、3 GiB、500 MiB。网格或映射存在未解释的几何误差即不启动原生求解。

按实网登记分段原生预算，保存初场、周期场、正常终点。沿用六项 log₁₀ RMS 末 20 次低于 −8、正压无滑移及温界、热稳定 <0.2%、独立反力与同阶段边界能量相对差 <0.5%。在原面上比较压力、入壁热流、相同位置温度、七区及整件放热。独立检查 X = 0.172 mm 的迎背风周向分布、引线端面热峰与主工作台导出，单轮工作台限 180 s、4 GiB、180 MiB。已有 48 档求解复用其正常终帧；侧吹局部实验精度继续单列。
