# M0.30 原面六区的证据核对与几何定位

基线 v362（`125796e55e6d0357ffb0c639688f93370803b379`）。回到 `cases/simple_launcher/launcher-m.stl`，5 km、M0.30、零攻角和零侧滑、300 K 等温壁。按原面号核对六区完整分母，再检查项目已登记的同形风洞、飞行试算、球体压力及平板换热四类来源。核对它们的几何、工况、实际求解或观测变量、原面对应关系及外域证据。只有吻合的资料才支持对该区附着、回流、壁压或热流作出判断。给定壁温及没有返回面场的记录各自标识。

将区域、面号、面积和证据范围接到现有记录侧栏。允许用鼠标或列表定位三维几何，选择区域时核对面积分母和缺项。工作台测试使用真实控件、当前导入的米制 STL 和现有风洞归档，覆盖六区、不同马赫记录、退出视图及读取已完成的结果。档案核对与交互测试每次限 180 s、1 核、4 GiB、20 MiB 新输出。此轮对应已登记资料的适用性审核，无新 CFD 计算。
