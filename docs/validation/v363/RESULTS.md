## 工作台操作

在第 4 步“查看该模型的飞行工况记录”中选择区域，三维窗口显示对应原面的区域线框。点选三角面时，侧栏切到相应区域，单独描出所点三角形并列出其原始面号与面积。全表面表以整件面积为分母，分区表以本区面积为分母，另列本区占整件的百分数。M0.30 的说明区展示该区流动状态及同形风洞的对照范围。档案浏览只显示几何与覆盖身份，最终云图仍依赖完整的物理结果。[完整工作台文件](../../../rocketAeroHeatWorkbench.m) · [几何视图文件](../../../updateAerothermalGeometryView.m)

五个工况共 46,080 个“工况—面”组合。逐面核对 v358 原掩码，再合并连续相同的压力身份和热流标志。M2.00 圆柱段有 4,848 面返回工程热流，占圆柱面积的 99.02%，圆柱壁压全部为给定值。点选相邻的 2064 和 2065 号面，前者热流缺项，后者有工程热流。切回“全表面”可见全模型两量同面的面积仍为 14.75%。本次展示只使用档案实际保存的状态。[逐区与逐面读回](workbench.json)

## 验收与复算

基线为 v362 提交 `125796e55e6d0357ffb0c639688f93370803b379`。从普通 MATLAB 工作台打开档案，验证六区选择、由网页拾取消息切换区域、七个指定面的工程状态、过期消息与越界面号拒绝、切回全表面及原风洞归档。每个选区均取得实际 WebGL 渲染回执，核对了高亮面数、被点面号、可见像素以及没有物理场图层。自动化在拾取消息入口注入面号，未进行人工鼠标操作。浏览期间计算边界、输入版本和求解编号保持一致，回到风洞后可读取原 9,216 面完整结果。[完整交互核对程序](check_region_review.m)

首次回归在返回风洞时把关闭探针后省略的可选字段当成必有字段，测试以错误退出。更正测试判据后通过。随后加入历史外域数据和逐面状态，并统一文本来源指纹的换行处理，使 Windows 工作区和 Git 中的记录可复核。最终分区及全表面两组回归共 55.55 s，峰值常驻内存约 1.79 GiB，输入指纹稳定且进程正常结束。各轮回执及失败日志保存在本机 `outputs/v363_validation/process_ui01` 至 `process_ui05`。本次 CFD 耗时为零，开发及归档用时另计。
