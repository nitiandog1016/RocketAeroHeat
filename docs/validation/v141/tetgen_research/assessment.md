# TetGen 有限调研：已有带孔域的重建与质量修复

2026-11-01。结论是下一候选的接口依据，尚未安装、编译或运行TetGen，不是成功保证。

[WIAS官方说明](https://www.wias-berlin.de/software/index.jsp?id=TetGen&lang=1)列出TetGen的约束四面体能力、独立程序形式，并将1.5.1列为稳定版本。优先固定该版本；1.6.x的存在不作为自动升级理由。[官方仓库v1.5.1](https://github.com/TetGen/TetGen/tree/v1.5.1)的文件元数据已通过GitHub连接读取，版本、大小和Git blob身份见`repository_files.json`。

[1.5官方手册](https://wias-berlin.de/software/tetgen/1.5/doc/manual/manual005.html)给出已有网格重建`-r`、固定表面`-Y`、质量细化`-q`、局部优化组合`-O`及新增点上限`-S`。它支持非凸带孔域；不能启用保留凸包的`-c`填实箭体。半径边长比/二面角指标不同于项目SICN，须独立复核。固定边界或锐特征仍可能留下坏单元，不能承诺质量必过。

建议先核对固定版本的实现与参数，再用已知体积空腔/固定三角接口小例验证真实导入、原点/原面保持、正性/配对和质量改善。通过后，仅对v141完整四面体域作一次有预算重建/优化，保留全部棱柱和物理表面，禁止高度/选区/参数扫描。优先复用原T连接，避免无依据重建整个包络。所有原SICN、节点/单元、体积与时间门槛保持。

v141独立检查没有发现单个固定边界三角形的最优SICN上界低于0.1，但这只排除单面形状这一种必要障碍，不证明全域可行。因此下一步应测试成熟工具的连接修复能力，不能继续把失败归结为缺少自由点或单纯改变外层高度。
