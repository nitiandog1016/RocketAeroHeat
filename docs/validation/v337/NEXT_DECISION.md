# 用同一瞬时场核对七站的周向变化

两种热流提取方法在指定 +Z 测线上均得到背风两站换热高低次序与实验相反的结果。本轮最大提取方法差仅 0.050 Nu。支管破坏绕来流轴的旋转对称，原表给了极角，缺少逐站的独立周向坐标。现有 14D 体场和原面映射足以量化方位对这个对照的影响。[七站复算](RESULTS.md) · [实验布置](../v324/RESULTS.md)

下一项在同一 **2.565681 ms、两个半步**的银球上，生成七个实验极角各自的外露球面周向壁热流和 Nu 曲线。以物理交线和同一局部温差、物性定义取样，保留 +Z 作为既有对照。显示实算最小值、最大值、原面位置，报告同一方位下 119.8° 与 166.7° 的高低次序是否可能变化。0° 迎风点只有一个位置。支管遮盖、接缝或缺少唯一球面交点的区段给出实际缺项和方位范围。七站共用方位；不逐站调角拟合实验。原压力与热流的全表面主解、功率及验证分母保持。

先用已存体场完成这一项，接入现有七站和三维工作台。若背风两站实验值超出计算周向范围，或所有可比共同方位都给出相反排序，形成明确排除结论，再为尾迹发展程度或有来源的物理边界差异安排一项受预算约束的对照。几何方位敏感性与真实试验方位的证据分别报告。
