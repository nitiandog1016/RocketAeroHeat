# Short Test 65 七站温度梯度与壁反力

基线 v336 `139bbe3fd7fd840b53634ea6d3b962a82b543612`。仅对 14D 名义双支管银球执行[已登记的七站决定](../v336/NEXT_DECISION.md)。相对 v336 预计新增 0 面、0 m²。使用既有原面、体场及实验原表，核对近壁热流的取值方法能解释多少局部偏差。

64 扇区五层、十层稳态使用 v329 与 v330 的合格基流和原面包，网格及帧绑定于 `supportedNearWall65.json`。128 扇区十层稳态绑定 `supportedAngular65.json` 的细网端点，14D 的整步和两半步绑定 v336 已核验的两个终帧。原面包中的 `stations.csv` 给出七个极角的测线、邻接节点与权重。每项先核对源摘要、工况、网格和保存帧指纹。

在 Y=0、+Z 测线上，以名义球面向流体的径向为法线，从实际体网的相邻四边形追踪每个近壁间隔。各层求射线与节点弦的交点，用实际法向距离和温度计算一次、非均匀二次单边导数，并以更宽的二次模板衡量距离敏感性。传导热流采用求解使用的膜温导热系数，Nu 按同站壁温导热系数换算。若面归属、法线或层连接有歧义，记录原因并保留缺值。纸面表 III 的 Nu 含整体量热标定；原始线温梯度单列单位。比较 119.8° 和 166.7° 的方法差、间距敏感性和实验差；七站结论只适用于测线。

已有场的归档读取和独立复算各限 3 min、单线程、2 GiB。新增复读工作目录 ≤ 0.5 GiB，不重跑流动。复用同源原生复读入口对一份实际任务生成对照，保留完成回执。工作台验收限 5 min、4 GiB，独立检查真实窗口数据、CSV、归档与本地任务的来源；同时核对不同工况的显示隔离。检查坐标、节点、时间、温界、符号、非均匀解析多项式和第三方原表。计算差与实验不确定度分别报告。超预算或源不一致即停止对应组合。
