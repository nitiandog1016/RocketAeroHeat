# 固定实数算子合同

一次选定`rah-nk-real-v1`，继承v180的物理、阶段、残差反馈、线搜索及ILU0，只改变计算数字类型及导数近似。`lmr-run`直接调用，原引擎不改不编。

Jv原生`newtonkrylovsolver.d:3194`的Knoll/McHugh(1994)尺度为 `sigma = mean(a*(abs(U)+1))/max(norm(z),sqrt(1e-7))`，`3662`起计算`[R(U+sigma*z)-R0]/sigma`。原生先应用列缩放于方向，外层另作残差行缩放；不是先把所有物理守恒量手工归一为1。预条件矩阵`fluidblock.d:1545`起及边界修正`1624`起，对每个守恒分量采用 `delta_i=a*(abs(U_i)+1)` 的前向差分，并恢复基态；不能把Jv的全局sigma照搬到各列。保留原生`use_scaling=true`。

两处`a`均固定为`2^-26 = sqrt(binary64 epsilon)`，源注释建议机器舍入量平方根的量级，也明确问题依赖；采用标准一阶截断/舍入平衡作初始选择，不把它称普适最优。禁止沿用复步长`1e-30`，不扫描扰动参数。数学小检查用跨量级向量、固定方向和独立解析Jacobian，事前相对门槛1e-5；实测Jv8.15e-8/列缩放Jacobian1.44e-7通过。这只支持差分尺度的可表示性/解析误差，不是原生NS算子验证。原生小例还须核对实际配置、两阶段历史及与同条件既有复数小例的场量差异。

原生实数预条件源码有针对结构网格恢复的备注并执行额外基态RHS重算；本项目仍用已审核非结构域，不删此恢复。实数有限差分与复步长不逐字等价，不能复用same-numerics身份。物性、热参考、网格和初场必须逐字保持。
