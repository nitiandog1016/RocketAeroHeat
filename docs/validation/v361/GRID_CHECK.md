# 同一球体的一次空间加密

首网的三个残差均已通过，前、后驻点 Cp 分别为 1.06411、0.72528。只改变压力零点时两点的最大绝对误差至少为 0.1694，仍超过 0.10。135° 的切向速度比解析值低 0.1191 倍来流，45° 的差为 0.0176。单个终场无法确定这种不对称是否随加密缩小。

为辨认空间离散的作用，本轮再取一张 128×72 间隔的网，首层从 0.004D 减半到 0.002D。保持直径、14D 外界、均匀来流初态、三个边界、数值选项、残差定义及全部原误差门槛。独立新目录，最多 3,000 次、180 s、1 线程、4 GiB 和 80 MiB。保存并核对初场、每 500 次及末态。对比两网同极角误差、后驻点、各自面积加权误差及远界数值。此对照仅改变离散；达到上限或误差门槛仍未通过就关闭本轮候选，不作第三档或参数扫描。
