# 低亚声速外流的下一项

两档恒密度无黏 SU2 球体计算均已结束。加密改善了压力和速度；后驻点压力、全壁切向速率仍超出原门槛。本轮不再加密此组合。M0.30 的原面外流和整件功率仍未知，已发布的风洞和飞行工况记录可在同一工作台分别查看。[两网核对与工作台](RESULTS.md)

本机已找到并启动 OpenFOAM 13 的 `potentialFoam` 帮助入口，构建号为 `13-18870c24d21c`，程序 SHA-256 为 `a3dac7d96f7f7e25ec772aa4621f4a891de63348476c321930804c79a897df41`。它提供直接求速度势的另一种低速无旋近似，本次只核实了可执行性。下一项限于用同一球体、同一压力与速度门槛做一次独立动量对照，先核对壁面速度、压力定义和边界收支。达到门槛后，才评估 M0.30 低速近似误差和实际附着区域。球体通过也不提供肩后、尾部、平底的黏性流动或壁热。若未通过，保留具体缺项和终态。
