# 低亚声速外流入口与轴对称动量核对

基线 v360，`e7b60c460a51786039b302008095c3b88ade887a`。先核对已安装的官方 SU2 8.6.0 恒密度无黏轴对称分支，以及同一简化模型在正常工作台入口实际能选择的工况。保持飞行与固定风洞的边界、原面台账和最终结果页各自的资格。

独立动量对照取直径 1 m 的光滑球体、1 m/s 均匀来流、密度 1 kg/m³、远场表压 0 Pa，球壁滑移、轴线对称。均匀来流初始化。64 个子午间隔、36 个径向间隔，外界半径 14D。用项目现有子午建网和未修改的 SU2，关闭能量方程。每 500 次及末态留存压力和两速度分量，保存实际配置及均匀初场定义。最多 3,000 次、1 线程、360 s、4 GiB、80 MiB 输出；只有实际终态、输入锁和字段身份均核实，才判数值结果。

比较全部球壁节点的解析压力系数和切向速度。按球环面积权重，压力系数误差 RMS < 0.04、最大绝对误差 < 0.10，切向速率误差 RMS < 0.03 倍来流速度；三项原生 log RMS 的末 20 行最大值各 < −8。报告壁面法向速度、远界净输运与有限外域的影响。动量未通过则停止该组合；通过仅表明该滑移球的理想流动对照成立，真实附着及压缩性、尾迹、外缘温度和壁热仍按各自证据核对。工作台复验使用同一台机器、同一 STL、输入与结果状态，最多 180 s、1 核、4 GiB、20 MiB 新输出。保留既有飞行点的缺项。
