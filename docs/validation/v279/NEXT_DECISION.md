# 固定物理初态，完成圆柱第一个收敛时间步

同一 2160 面风洞圆柱已有 220 面的有量纲工程壁压和热流。全三维网格已能推进、读回及映射全部圆柱面，安装交线热通量的标记问题已解决。当前妨碍扩大可信面积的是首个物理步中的非线性收敛；末端焓残差 −0.965、ω 残差 +1.353。未收敛终点继续只作诊断。[终场及回执](RESULTS.md)

下一次只比较**同一物理步**的伪时间推进。复用本版 73,800 节点网格、完整初场、入口、物性、边界、物理 Δt 与九分量门槛。采用固定 SU2 原生的自适应伪时间 CFL 候选，执行前登记上下限、升降规则与总耗时，确认其实际应用于流动、SST 和 LM 的方式。保存初始及最终的全部主量和两列转捩辅助量，报告线性求解是否充分、各分量下降速率和近壁/安装端最坏位置。与 120 次基线比较相同内迭代数和相同耗时，若在一次限定运行内无收益，关闭该组合并保留原始结果。不可将上次末帧当作新的旧时间层来假装继续同一步。

首步达到门槛后才进入后续非定常时间步。之后还需分离来流建立阶段与脱涡统计窗口，对照时间步、空间/近壁与截断边界，并核对全域质量和能量收支、六条铜带及端部适用性。单步合格仍不能代表稳定统计或试验精度。整壁工程功率在 1940 个缺项原面得到适用解以前继续为未知。
