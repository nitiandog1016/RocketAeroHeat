# 首轮实际耗时后的预算修订

原600步任务实际运行至约283步/433.25秒，线性估计600步约915秒，超过720秒上限；OUTPUT_WRT_FREQ600导致尚无中途壁面/体场。原生Windows进程没有本项目已验证的稳态温和停止并保存接口，未注入进程、修改已冻结配置或延长时间上限。

为避免继续计算而在硬截止丢失全部新场，按已有jobToken取消入口停止，保留实际历史和终态。这是准备时预算/保存安排不足，不是物理失败或收敛通过。精确进度/用时以`budget_revision.json`和原终态回执为准。

本轮明确允许一次预算修订重试：原初猜/原网格硬链接复用，**重新从原初猜开始，不宣称从取消时刻恢复**；只改ITER300、具名OUTPUT_WRT_FREQ150，其他配置逐行不变。实测预计300步约458秒，要求<576秒再启动，仍2线程/720秒、原−8及全部物理判据不变。保留150和最终300附近的真实具名场，防止只有监测没有结果。

这取代原计划中的一次600步安排；不得隐藏首轮取消或把300步结束算收敛。初始化、近壁/外域和湍流资格仍待物理验证，新增资格面积仍为0。完整域约21万节点的必要ASCII初态/具名体场预计超过100MiB存储目标，按实测单列，不能以删唯一状态凑预算；不重试被策略拒绝的旧缓存清理。
