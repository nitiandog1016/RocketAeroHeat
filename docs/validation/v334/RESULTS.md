双支管银球在普通五步侧栏中可读取扰动后 **2.565681445 ms** 的两套结果，并可选择从本机基流重新计算。此次解决的是文件导入后面号、温界、原生时间层和科研导出之间的对应。相对 v333 首次同时取得壁压与热流的几何面积为 **0 面、0 m²**。参考几何共 32,480 面、0.000700423853595 m²。原生方法为 SU2 8.6.0 三维不可压层流、BDF1 实际时间推进，正热流入壁。外露银球折合功率仍比实验量热值高 38.08%，七站 RMSE 为 4.888 Nu，逐面壁压和热流联合实验验证面积为 0 m²。[计划](PLAN.md) · [原生计算与实验对照](../v333/RESULTS.md)

## 使用入口

1. 从[几何包](../../../cases/short_sphere/supported65.zip)解出 `supported_m.stl`。在 MATLAB 运行 `rocketAeroHeatWorkbench`，选择该文件，原坐标到米的比例填 **1**。这个文件自身的支管沿 ±Y，直接确认朝向即可。
2. 在网格方法选择 **双支管银球 · Short Test 65**，点击 **核对 STL 原面并绑定试件体网**。这里复用已登记的 128 扇区、十层近壁体网和五区交叠关系。程序从文件读取所有三角面，核对米制坐标、唯一顶点、绕序、连接和逐面面积。
3. 在边界页核对 −X 来流、Re = 882、七站极角壁温和支管端盖温度。选择两个半步或一个整步，点击确认。切换步长使旧结果失效。
4. **读取所选步长的归档** 只需随版本发布的小型算例包。**从扰动初场重新计算** 使用本机 v332 稳态帧、体网、固定原生环境和脚本，生成新的独立任务目录。此版实际运行了两个归档分支，实测了新算按钮传给真实启动器的脚本、目录及参数；测试替身在启动进程前拦截了该动作，原生三步的数值与收支验收沿用 v333。[新算原生入口和依赖](../../../scripts/shortSupportTime65.py) · [原生终帧与复核回执](../v333/evidence/replay.json)
5. 在结果页点选任意面，查询压力、入壁热流、给定壁温、首层流体温度、近壁流向及方法。区域探针同时显示 STL 面号和试件参考面号。侧栏可定位两种面积测度上的热峰，七站表按导入文件列出对应面。完整面表导出带两套面号、单位换算、源文件/体网/终帧指纹、物理时刻及实际步长。[本机毫米副本三维页](../../../outputs/v334_validation/half01/workbench/index.html)

银球管壁有多个几乎并列的热峰。STL 单精度坐标舍入会改变三角形面积；在保持每面功率时，局部热流密度的排序随之变化。第一轮核对要求两种面积测度的峰值面编号相同，独立读回正确检出了差异。现在按文件面的真实热流查找导入网峰值，另从原生归档映射参考网峰值。两个位置均在真实侧栏用独立按钮定位。另一次测试中，颠倒绕序但保留原文件法向的负例已被文件面序核对提前拒绝。后续分别用 MATLAB 导入结果和严格按记录构造的面表验证拒绝位置。错误尺度、错误朝向、缺面、重复面、改动边界和过期来源均已拒绝。[完整对照与负例](check_import.m) · [分次运行与输入指纹](evidence/runs.json)
