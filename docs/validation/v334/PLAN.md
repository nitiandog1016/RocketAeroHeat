# 普通 STL 入口的双支管银球单时刻验收

基线 v333，提交 `990843b031a3dcef116a3a7c20e7313271d15e10`。对象为 Short Test 65、Re = 882 的名义双支管银球，扰动后 0.0025656814449917897 s。原几何包 `supported65.zip` 及其米制 STL 分别以 `d1f30c067083efb7731d1a9de74eed60064dc590b0277be2e7d59183a7d06778` 和 `eb4e406088070a7b1b80141c2f650469e46477845107439dfa39842636dcf0ff` 绑定。两种步长和端点源见 [v333 回执](../v333/evidence/replay.json)。共 32,480 面，预期新增 0 面、0 m²。

通过普通文件入口加载标准米制 STL，以及换算为毫米、重排面序、改变摆放的副本。在已确认坐标系中检查每个文件三角形、唯一角点、绕序和面积。每个面热功率与参考值相差须小于 1e−12 W，每区和整件须小于 1e−10 W。分别比较全部面压力、热流、给定壁温、首层温度、流向，检查七站、热峰、反向区、三维探针、截面及 CSV。拒绝错误单位、错误朝向、损坏拓扑和过期输入。选择整步/两半步时旧结果须失效。网页并发修改保留，发布口径使用已发布前端。

本轮改动是导入和传递，复用 v333 原生三步、储热与壁面反力检查。界面新算交给同一原生程序；查档只读随版本交付的结果。验证按钮派发与真实读档分开记账。每次 MATLAB 工作台串行运行，预算 240 s、单计算线程、进程族 5 GiB；独立逐面复核 90 s、1 线程、1 GiB。本轮新输出预算 0.8 GiB，开发、读取、验证和原生求解时间分别记录。首个失败保留日志，定位后在新目录复验。源码、负例及小型实测证据随版本交付。
