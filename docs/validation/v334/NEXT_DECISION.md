# 对照远场距离对银球五区及七站换热的影响

双支管银球已有通过能量核对的单时刻场和普通 STL 入口。外露银球按试验口径折合功率比量热值高约 38%。已有的法向与周向加密均使用半径 14D 的远场。下一项在同一民用 Test 65 的既有 14D 基线上增加一次较远外边界对照，量化这项尚未分离的空间误差。[法向对照](../v330/RESULTS.md) · [周向对照](../v332/RESULTS.md) · [现有时间层](../v333/RESULTS.md)

先核实原风洞尺寸、入口条件及已留存的同一双支管对照；合格的现有数据优先复用。新增计算须先在下一轮计划中冻结唯一外域、总预算和停止条件。复用同五区、原面、温界、近壁网及原生守恒定义，记录外边界位置、实际网距和入口量。按两套网各自的稳态基流施加同定义的扰动，在相同物理时刻、同一步长比较五区功率、外露银球折合功率、七站 Nu 和热峰位置。报告域变化带来的差值及与实验仍余的偏差。某一端点或资源门槛未通过时保留实测回执，停止该组合。
