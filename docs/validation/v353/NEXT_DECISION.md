# 同一物理步的流场与热量

已通过的全周热算子适用于固定的轴对称速度场，可以响应周向变化的壁温。接下来在同一 0.05 m/s 完整试件上，接通一个低速物理时间步中的独立恒物性动量与三维显热。采用 v352 粗网、无扰动对照和已冻结的弱扰动初场；动量分支显式采用无浮力、恒密度、恒黏度的压力与三速度方程，能量由显热分支独立负责。

先核对内核实际启用的方程、动量归一残差与真实终帧。对两支均通过的同一时间层，需要向热网传递完整三分量速度，核对质量通量、周向输运、壁反力以及流体储热与远界收支。周向变化的速度会使傅里叶模态相互耦合，不能沿用本次的独立模态直接解。事前登记物理时间、步长对照、同面误差与资源预算；新壁压和热流同时通过后再进入工作台。[全周稳态控制](RESULTS.md) · [原无扰动步的实际残差](../v352/RESULTS.md)
