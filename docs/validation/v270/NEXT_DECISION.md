# 下一项：从公开舱体几何进入一次给定壁温的计算

AS-202 的飞行量热资料已经完成取舍。飞行站点保留独立身份。停止从时间曲线寻找整壁输入或把相邻压力孔当作同站数据。[测站结论](RESULTS.md)

下一项用 NASA TN D-4185 图 1(c)、1(d) 的 **CM-011 公开几何**建立一个独立的给定壁温研究工况，经普通模型入口生成完整试件表面并调用现有适用方法。先区分图纸的坐标原点、主体外表面和有单独说明的构件，明确能够复原的几何范围和完整试件分母；简化部位在模型身份中列明。工作台显示这份输入、程序实际求得的压力与热流、缺项和使用的方法。飞行精度继续取决于实测与计算的时空位置、物理量和热边界是否一致。

采用条件是几何可以独立复读，温度边界与工况由该研究算例明确给定，求解方法支持这些输入。输入和运行预算在求解前登记。验收给出真实同面计算面积与剩余面积，并复用 v269 汇总；不因某次飞行缺少同站压力而搁置给定边界的程序开发。自绘模型和这份民用试件保留各自的覆盖记录。[原始几何来源](https://ntrs.nasa.gov/citations/19670027745)
