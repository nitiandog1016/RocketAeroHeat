# 在同一工作台接入第二组实测量热工况

Test 65 的等温银球已经能从功率、来流和几何自行闭合壁温、导热系数与原面热流。膜温更新只使壁温移动 0.243 K，背风两站仍反序。这个固定工况的物性闭合试验到此结束。[本轮对照](RESULTS.md)

下一项用相同试件的 **Short Test 63** 验收同一程序接受不同来流和加热功率的能力。原论文表 I 给出 4.06 ft/s、100.11 °F、2066.3 lbf/ft²、水质量分数 0.0081 及 Re = 888。表 II 的量热值为 1.1140 × 10⁻³ Btu/s；按已核实的面积口径折回球体后为 **1.153644 W**，高于本轮 Test 65 的高温端份额 1.082126 W。用 Test 63 自身的流动、物性与原生温界重新建立括区。实验平均表温 205.4 °F 及局部 Nu 留作求解后的对照。[Short 原论文，印刷页 76–78](https://doi.org/10.7907/6CZB-AW27)

把试验号、来流、功率、测站极角和来源写成独立工况记录，几何仍共用原 32,480 面。Test 63 的七站位于 0°、41.3°、59.9°、75.6°、90°、121.0° 和 168.7°，按其实际位置重新定位。先注册准确输入、适用于该温界的无量纲尺度、原生允许范围、运行预算和停止条件。增加这个工况只能通过有界原生求解和逐面收支核验，禁止把 Test 65 面表按功率直接放大。工作台提供工况选择并使旧快照失效。验收以一组新全表面结果、两份工况的隔离、可复核的实验偏差或具名失败原因为终点。
