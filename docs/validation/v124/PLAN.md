将固定官方 SU2 8.6.0 的 SST-2003m 接入现有完整域，解决当前代码只接受层流状态、按列数猜能量及固定层流标签的接口限制。保留原19752面、面积1.9646292565715553m²、M5/30km/α20°/β0°/给定Tw300K。不是把湍流开关当作收敛补丁。

首次选择已有32层、首2µm完整候选域及其v120局部199场作为初猜来源：其层流y+估计较小，适合检验解析到壁面的SST接口；该网格未获物理资格，不提升为默认。源为改网格后局部199，较早上游累计599单列，不能冒称同网格累计799。不生成新Gmsh网格。

明确全湍流研究假设：I=0.01、μt/μ=10、Prt=0.90，取值为本次受控比较输入，不是飞行测量或已验证参数。无转捩、无可压缩附加修正、无壁函数。先用定比热/Sutherland/Pr0.72，HEOS RANS继续拒绝。湍流输运先用原生一阶SCALAR_UPWIND、隐式时间推进及CFL比例1，需在后续空间敏感性验证中单列。

## 准备与验收

- 具名源场/真实终态/配置/网格/状态SHA；保持p/T/U，加入ρk，热内能扣k；非壁点k∞/ω∞均匀初猜，墙面k=0、ω由原生最近邻壁距定义计算。新模型局部步号0起，不当同物理续算。
- 固定源码区分两个距离：热梯度使用最大法向余弦邻点的法向投影距离；SST墙面ω和y+使用连接非壁邻点到完整墙面的最短距离。禁止把两者或层流Y+全零混同。
- 一个内部二维平板非零热流接口任务（40×32节点分段设置、100步、2线程、≤120秒），验证真实9列SST二维状态、EOS/k、热流与原生y+；不当公开基准或收敛验证。
- 接口通过后，唯一真实完整域任务100步、50步保存、2线程、≤600秒；预处理≤180秒，后验≤120秒，各阶段另计，不自动续算或重试失败流场。若接口/初始化失败则先修复原因，记录原失败和准确源码。
- 具名输出、原19752面映射及全部p/q/流体T与CSV最大归一化误差≤2e−6；给定Tw和未知求解Tw保持区别。
- 正ρ、热内能及ω；k≥0且墙面k=0；原生壁面EOS误差≤2e−6，非零壁热与法向温度梯度误差≤2e−6，实际y+独立重算相对误差≤2e−6。ω墙值记录旧/新流动状态时间层差异，不用裁剪制造通过。
- 首次小任务后的源码勘误：边界赋零后原生隐式更新可将保存壁k置为固定下限1e−10；仅接受0或该固定值，EOS扣实际k，壁面μt/μ须<1e−12并量化。原失败见`first_audit_failure/`，原场只读重审；其他门槛不变。
- 保留原密度/能量−8，加k/ω各−8及原起检步10；报告中期到末期面热流面积加权L1变化（目标<10%）、末25步热功率变化（目标<2%）、原生y+99分位（目标≤1）和超1面积。即使筛选通过，也不赋予网格/外域/公开热流/三维分离资格。
