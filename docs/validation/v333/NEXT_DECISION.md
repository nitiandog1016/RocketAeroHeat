# 让普通 STL 导入能走通双支管银球的单时刻计算

带支管银球已在明确物理时刻获得两套全表面场，热峰、反向区、能量收支和两步长通过核对。当前入口从 Short 算例菜单内部创建固定几何。下一项把同一民用试件接到用户日常的五步侧栏，从实际导入的 STL 开始，沿用 v333 已验证的计算条件和工作台。这个改动解决“选一次算例可查看”和“导入该试件可完整计算”两个入口之间的数据传递。[当前单时刻结果](RESULTS.md)

采用已发布几何包中的米制 `supported_m.stl`，先比对实际 STL 三角形与 32,480 个参考原面。用户导入后保留其面号、比例和朝向，对合法重排和单位换算按坐标及拓扑建立一一对应关系。可以复用已有民用探头的导入流程；银球五区及接头的身份须由银球本身的几何验证。普通路径在同一侧栏依次确认网格、实际壁面和远场条件、计算方式与物理时间，具备新算和读档入口。条件或几何变化要使不匹配的归档失效。先验收这件名义装置的一个确定工况。

用标准导入和一份重排并换算单位的输入验收同刻 32,480 面的压力、热流、五区功率和方法，核对入文件面号与参考面号、实验七站、热峰、反向区及导出。复用本轮通过的两步长与守恒检查，只有输入或计算实现实际变化时重算相关部分。这个早期时刻延续 38% 左右的量热偏差；长期轨迹、累计热量和发展尾迹实验精度后续另行排期。
