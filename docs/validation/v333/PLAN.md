# 双支管银球首个相同物理时刻

基线 v332 `d460bfa1b4e1df32594078ea8a34b8efe316f938`。仅计算 Short Test 65、Re = 882 的 128 扇区十层网，261,708 节点、397,824 单元、11,906 个湿壁点和原 32,480 面。用已通过守恒及末窗的第 1,000 次稳态帧 `c23c9ca1beb024105c600642f3fb016c9b7077599c8cecff227eb6d3ab0dbe63`，体网 `a56a4c3dee8fd8bb74bc23ae4e85b71eaf7d5552dd99fccf8a6c8cb6a40789cd`，准备回执 `22ef3bf27abf1a093fae6bfb03145fac1b9f401229f11a3d12042be19cd9a04c`。保留 v332 的温界、物性、空间离散、远场通量、限幅和交叠。扰动沿用光滑球算例的紧支撑矢势旋度（中心 x/D = −1.15、纵横半径 0.55D/0.45D，节点最大速度扰动 1% 来流）。逐点核对湿壁、远场及支撑外不变。粗细支从完全相同的初帧出发。[上一决定](../v332/NEXT_DECISION.md)

固定 SU2 8.6.0 静网恒密度 BDF1，物理步长 Δt U/D 为 0.25 和 0.125，交付 tU/D = 0.25（约 2.566 ms）。每步最多 360 次真实内更新，另加一次只读端点装配，读取时保持流动、温差解不变。原生已加时间项，修改只给核对账本加相同储热，防止重复装配。逐非壁节点要求原生行与无限幅空间行加储热差 <2e−13。低阶和实际阶段的温差域、对偶通量、壁温及原守恒门槛沿用 v332。剔除最后读数行后，最后 20 行实际六方程 log₁₀ RMS 均 <−8，含时间项的无限幅 RMS <1e−8。记录初帧、每步物理终帧及正常回执。

每个接受端点用两个实际物理层与原生体积独立重算储热；同态记录原生加时间项前后、强温界前后及共享的远场通量。复用独立释放壁行的读法，比较原节点反力，峰值归一差 <1e−5。边修正前后及壁面—远场—储热各自闭合。独立储热差 <1e−9 W，物理净差 <0.5%，最后两个实际更新及端点的壁放热相对变化 <0.2%。两支同刻压力面积 RMS <1% 动压，热流面积 RMS <1%、单面最大差 <5% 的细步峰值，总放热差 <1%。使用真实源帧计算首层温度、七站 Nu、热峰与双符号反向区。对比给定温界、时间单位、储热符号与工作台同面读数。

本机前一版真实峰值约 2.09 GiB，初查可用约 5.59 GiB、E 盘约 296 GiB。准备/独立读数每次 ≤180 s、1 线程、2 GiB；对象编译/链接每个 ≤180 s、3 GiB。原生串行运行各分支，每物理步 ≤480 s、4 线程、4 GiB、550 MiB 输出，释放检查每次 ≤150 s、4 GiB、350 MiB。全轮新输出 ≤4 GiB；MATLAB 入口 ≤180 s、4 GiB。首个未通过步保留检查点与失败原因，关联终点保持未知；软件接线错误允许有依据地修复。只在三个物理步及相应收支通过后发布同刻对照。
