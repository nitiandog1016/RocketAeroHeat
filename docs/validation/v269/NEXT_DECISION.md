# 下一项：带实测的民用模型单工况区域结果

常用入口的同面覆盖与热功率交付已通过。下一次区域工作以**一个冻结工况的实际壁面计算值**验收，并随结果交付工况、适用范围、面元方法和同一几何上的新增面积。累计热量、更多微球设置与独立界面美化继续后置。[本次结果](RESULTS.md)

采用已识别的民用 Apollo AS-202 指令舱热流资料作为具名测试候选。先在其原始来源固定一个测点所属的固壁区域和一个可对应的观测时刻，核实几何、边界输入与仪器报告的热流定义。若资料足以定义可复现的一次计算，面元预测和测点读数各自保存，当次用完整试件面积报告覆盖。若欠缺输入，记录具体缺项及其影响；测得的数值仅进入独立对照列。自绘模型继续以已有原面独立核算。已有材料确认了量热计位置图和传感器 A 曲线，尚未证明该测点存在同站压力或全壁实测。[NASA 收录资料](https://ntrs.nasa.gov/citations/20110024180)

这项预查只核对上述公开民用试验资料及其指向的一手记录，不重新开展求解器比较。资料相符后登记数值计算预算、输入和验收条件。后续计算须交付的量是原面壁压和给定壁温下的对流热流，测量定义不同的量分别说明。
