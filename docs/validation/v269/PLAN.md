# 单工况入口的原面覆盖与热功率

基线为 v268 提交 `e12e1ba002704e712ddce1025f6b2d32abc3915d`。常用工程入口返回的壁压、热流各自面积无法确定二者在同一原面上的交集。此次交付让使用者在一次计算后看到双量同面数、原面积与剩余面积，以及能否给出整壁有符号热功率。同一份定义供工程、混合入口和工作台使用。历史帧和带源曲面积的风洞数据沿用原有显示与积分规则。

直接读取 v104 原 MAT（SHA-256 `b4889e42a28131c253a56f06472a58c9d2cb290d7c9937935fbb4b5d7349488f`）及 v268 微球细网的工作台数据（`60ac0f63e2c0282efaa57d417afde4e0782af7e26c030cdc3baf47a5e8a100bc`）。对照为 [v263 原面四类面积](../v263/evidence/saved_surfaces.json)、[v266 实际积分](../v263/evidence/snapshot_power/summary.json) 和 [v268 独立结果](../v268/evidence/audit_result.json)。检查无缺项、两变量错开、压力给定、热流未知、全部无热流及真实零/负值。小型标准球通过普通 MATLAB 入口做集成测试，混合入口用已知逐面表验证回传。自绘模型只回读既有场。

验收要求面数完全对应，参考面积绝对差不超过 1×10⁻¹¹ m²，功率相对差不超过 1×10⁻¹¹（零值直接比较）。MATLAB 单计算线程，合计 120 s，4 GiB 内存、16 MiB 新输出。输入身份、分母、给定/未解状态或积分不一致时保留回执和差异。无需启动 CFD 或浏览器。软件和记录检查不增加求解或验证面积。
