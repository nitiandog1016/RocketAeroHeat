## 本轮明确实现

- 独立半球—圆柱层流准备程序，鼻尖 X=0/r=0、上游对称轴，轴向来流 −X。保存原弧长、全部边界、实测 Tw 插值及每个壁段的给定值；不套用旧 SST/311K/正半径合同。
- 优先原生多等温 marker。交界节点分别保留各 marker 的法向、邻点、面积和热通量，不用最后一个 marker 覆盖值代替合计。最后实测站后先固定末值延拓至物理圆柱末端；这是计算假设，出口/延拓独立性未测前不能授予实验资格。
- 原文局部 Nu_s/√Re_s 测量算子：弧长、局部外缘、恢复温度、热从壁流出的符号和段平均全部显式。图中理论/归约曲线只辅助归一化，不当热流实测。无法闭合的量保持未定。

## 小检查和预算

1. 先绑定 v159 准确构建源/运行包，定向核对真实 r=0 的一般 EOS 轴对称源项。用原函数逐字抽取的独立 C++ 小程序核验光滑轴线极限及调用顺序独立性，含正半径控制。只编小程序，不编 CFD 引擎；构建≤30秒/执行≤15秒/4GiB。
2. 独立几何/正面积/边界配对/旋转体积、Tw/共同节点、局部归一化与拒绝检查≤60秒，输出总量≤32MiB。失败与准确源保留；不得修改历史失败。
3. 仅轴线和热边界前置通过才登记至多一个原生小型层流检查（≤5更新/30秒/2线程/4GiB/32MiB）。确认真实输出阶段和热流后，另写具体正式候选计划；本计划不启动长任务。

若原生轴线路径在有区分力小检查失败，立即关闭当前二维轴对称长算入口。不以删轴、移动鼻尖或 r=ε 回避，也不无限自研轴线离散。保留与维度无关的几何、实测热边界和测量算子，明确转向成熟三维守恒路径的同一鼻部基准，作为下一次实施决定。现有原真实三维箭体不启用轴对称源，不能用新轴线缺项解释它或旧正半径 M7.11 的失败。
