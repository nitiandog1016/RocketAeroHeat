当前三维梯度来源包括Haselbacher与Blazek（AIAA Journal 38(11), 2000）和Nishikawa与White（JCP 411, 2020）的明确代码引用。后者题目为三角网格，不能由文献名称推断本项目三维棱柱已验证。真正需要的是准确原生点云、旋转/伸长情况下的一次有区分力梯度核对，之后才是热流/空间误差，不能改报别的网格指标来避开失败。

## 默认出口存在实际回流封堵行为

示例的`OutFlowBC_Simple`是`OutFlowBC_SimpleFlux`别名。`boundary_flux_effect.d:575–644`在出流时使用内部物理通量；**质量通量非正时把面当墙：质量、湍流等通量置零，动量只留压力项，静止面能量通量为零。** 这不是“已具备回流边界”，不能用于证明真实回流已经解出。因此不照搬该出口，也不改成隐藏零值。

其余原生选项也要如实解释：

- `InOutFlowBC_Ambient`只按内侧速度法向符号复制内态或环境态，没有声学特征数判断。不能因名称含InOut就认为亚声速压力信息相容。
- `OutFlowBC_FixedP`复制内态、指定外部压力，再经实际气体pT更新。它不含上述回流封堵，但本身没有完整回流温度/湍流来流合同，也不是已经验证的无反射边界。
- `OutFlowBC_FixedPT`额外指定温度，不会自动解决特征约束和回流来源；过度指定也是待检查项。

**后续设计限于已有FixedP原生压力出口加显式适用检查/截断对照，不自行开发通用特征边界。** 外部压力必须作为有来源的边界假设记录；p∞可作为远下游研究假设，不能作为当前切口真实压力答案。必须区分超声速外区和近壁亚声速影响，登记法向Mach、反向质量通量及比较区p/q变化。若出口出现回流或截断影响未过门槛，该候选拒绝/按预先登记范围扩域，不把回流当墙，也不依靠修改小参数消除报警。正式运行预算仍未准入。

外域继续复用v207鼻前圆盘、扩张侧边及环形出口设计；连接v208真实层列。切口最大轴向偏移2.3464微米，不能压平；层顶不是远场。比较区/扩域几何沿用v189设计，不根据本轮无流场结果臆造“分离已消失”。

## 返回H1后的具体实现选择

直接复用组合已拒绝；下一项是**有限的原生物性适配实施**，不是再换第三品牌或重复查表研究。设计名`rah-phase-aware-dry-air-eilmer-v1`，物理数据/域与v206、输运插值与v207一致，采用Eilmer已有GasModel扩展接口。实现必须与已有模型隔离，不覆盖CEA/工程默认或共享源。

1. 单伪组分、单温；保留固定标准干空气组成/R、相态有界60—2000K、原压力包络、hs298.15=0和u=h−RT。复用既有Cp节点的分段积分及线性mu/k表。EOS、Cp/Cv、h/u/s、声速、输运及pT/rhoT/rhop/rhou/ps/hs所有必要入口一致，不重新拟合或扩大来源范围。
2. 实数反算复用原生有界Brent，在量热表区间内定位，最后再核对联合p/T域；不得让未满足最终联合域的状态进入求解器。数值根试探与真实状态接受分别处理，不裁目标能量、温度或压力。
3. 官方NK使用复数扰动；不能简单把输入转实数而丢掉Jacobian。需给出相同物性分段内的解析切向导数/隐式逆导数并验证；Cp和输运节点处采用明确单侧定义，区分函数连续性和高阶导数不光滑。仅实数标量相等不准入NK。
4. 异常必须是GasModelException，才能经现有decode路径转为FlowSolverException；adjust_invalid_cell_data、低温修复和辐射丢能关闭。原生最小能量默认查询10K/1atm不符合此模型，需明确处置；本轮lmr定向扫描未见直接调用，不假称已触发。边界阶段的异常也不得被补值吞掉。
5. 原生接口/负内能合法状态/实复数导数通过，仍不等于区域准入。之后按同一设计完成真实棱柱点云和存储成本核对、FixedP出口合同、必要外域、公开热及截断验证；原−8、能量、热流、y+等门槛保持。

只允许新增具名气体类及登记/构建清单的最小适配，不重写通量、推进、Jacobian、线搜索或通用内存内核。若无法在这个边界内实现、原生梯度不适用或准确资源下界不能容纳，应关闭该候选并给出具体H1修订；不能宣称当前组合已闭合或自动延长试错。
