# 固定节点和测线间距，检查局部换边是否足以改善前中段排列

切向移动节点把最靠近法向的边的平均夹角改善了 8.30%。局部最宽间距会随交点移动，62 号条带超出了本次对照的 25% 上限。结束这一候选。下一项只在原第三档子午网的前中段检查局部换对角线的方案，从第三档原坐标与有序单元重新开始。[实测结果](RESULTS.md)

选择完全位于目标区的两两相邻三角形。候选对角线须形成严格凸四边形内的有效连接，固定内层、外区、全部节点及周向分辨率。排除会改变十六条登记测线穿越位置的换边。选择互不争用三角形的换边，并先估算所有有益换边可实现的夹角降幅上界。若上界达不到原 20% 对照目标，记录上界并关闭本轮固定节点方案。无需扫描移动量或启动求解。

上界足够时只构造一套候选，按实际成品对照原十六条法线，并在各母线段预先固定的四分点加查交错测线，以检验未锁定位置的法向分辨率。记录换边数量、真实夹角与相邻区间变化，达到几何准入才登记一次独立冷态。原压力、热流、能量和温度门槛沿用。本项检验排列对给定工况预测的影响，独立实验精度仍按原公开数据判定。
