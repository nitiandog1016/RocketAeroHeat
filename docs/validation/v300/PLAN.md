# 带引线热敏珠中段加密与四场配对

起点为 v299 提交 `2033ae3ed34eef1febbd51346fe35cee971dec30`。本地和 GitHub main、v299 一致，未见本机热敏珠求解进程，E 盘可用 326 GiB。保留并发 Web、研究和测试文件。沿用 [v297 带线输入](../v297/evidence/fine_inputs.json)、[v298 粗网配对](../v298/evidence/comparison.json)、[v299 光滑加密网](../v299/evidence/inputs.json) 及 [下一决定](../v299/NEXT_DECISION.md)。

仅在带线 B 型热敏珠的共同珠面中段应用 v299 的边切分，固定真实 10,272 个原面、原七区、引线长度与圆角、0.001D 首层、周向 7.5°、30° 扇区、外半径 20D。工况为 3 m/s、293.15 K、101325 Pa、全壁给定 305.15 K。先在成品网逐面核对几何、映射和首层坐标；量取实际改变的单元范围，并检查引线和接头附近的旧单元及远域。60°、85°、120° 法向在距壁 0.015D–0.1D 的最大穿越间距均须缩小，比较两种几何真实共用的中段单元与三条读数。几何不合格时停止求解，保留记录后处理几何。

新网只作一次独立冷态推进。原 SU2 8.6.0 及 Gmsh 4.15.2 的版本和物性不变。准备与审计每批 180 s、单线程、4 GiB、200 MiB；正式计算 720 s、1 线程、2 GiB、180 MiB、最多 7000 次。保留初场、间隔 500 次的周期帧与正常终点。六项原残差末 20 行均低于 −8，绝对压力为正、无滑移、全域强标量温界 [0,1]（容差 1e−12）。独立反力与原面积分须一致，延续 20 次放热变化 <0.2%，同阶段独立远场收支差 <0.5%。编译/链接各 120/60 s、3 GiB；反力、延续与独立单步各 60 s、2 GiB、180 MiB。UI/导出每批 180 s、4 GiB、200 MiB。超限或不合格保留现场。

在同一冻结工况下对 10,272 个带线原面计算加密前后变化；再与 v299 光滑控制逐一配对 6,144 个共面。两套分母各自积分，报告四种解的珠部放热、引线两侧/端面与接头功率、反向面积、局部峰值及平均 h。论文图 7 只提供整珠平均量。新结果进入带线试件的五步侧栏，并用实际导出核对全表面和截面。完成这一次配对即结束本项。
