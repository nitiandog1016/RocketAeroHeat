# 固定带线试件，检查温差输运离散对壁热的影响

等温带线试件已有 10,272 面完整的压力与热流。中段网距变化使珠部放热降低 14.01%，同网距的引线几何作用仅从 −0.36120 变到 −0.34942 mW。现有平均换热仍比实验高 26.73%。结束带线/光滑四场配对，下一项只在 **v300 同一带线体网** 检验一阶迎风输运对当前壁热的影响。[四场对照](evidence/comparison.json)

候选为固定 SU2 中温差标量的 MUSCL 重构配 Barth–Jespersen 斜率限制。已检查固定源中的 `CConfig.cpp` 的 `SetSpeciesParam`、`CScalarSolver.inl` 的 `CommonPreprocessing` 及 `scalar_edge_flux.hpp` 的 `ComputeFlux`。标量端点可以独立重构，流场端点的重构另受流场选项控制。保留原流场离散和边界、同一独立冷态、驻留全窗的标量限制器和关闭标量裁剪。早期未限制二阶流场重构曾越界，保留该失败记录。[旧试验](../v282/PLAN.md)

执行前核对本机官方程序与固定源码身份、限制器作用的实际迭代区间、同阶段反力观察器与两次读数的配置继承。只登记一次对照，在相同网格、残差、全场温界、热稳定与守恒门槛下比较七区、峰值和整珠平均量；同时核对压力/速度的一致性。若超温、未收敛或收支失败，保留原始输出并关闭该配置。若通过，在原带线科研页接入方法差；即便平均 h 更接近实验，局部精度和空间收敛仍各自保留待验证。大型场不重复生成，下一阶段只新算此具名输运方案。
