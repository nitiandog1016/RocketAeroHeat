# 壁邻采样到工程外缘：身份、物性与资格合同

本轮已实现`hybridEdgeSampling.py`。它接收既有同EOS审核的`RAH.HybridExternalState.v1`，输出`RAH.HybridEdgeCandidate.v1`。旧v191/v192读取器和工程默认未改。

## 已实现与已测

原壁三角面与原生三角/四边面按连接双射，保留原面顺序。显式保存原生面号、唯一邻单元、原生导出的单元位置、原壁中心、法向距离和切向偏移；法向由原生流体域边界符号确定，不能假定控制面文件与原箭体法向相同。逐项核对p/T/rho/e及三维速度与所指原生单元一致，绑定原壁指纹和源文件SHA。

v192细场480面真实原生读取通过，独立列规律定位的owner/位置逐字相同；真实19752面仅使用v193源体网格检查三角分派，法向距与独立CSV差0，**没有真实箭体原生准备或流场**。10项拒绝覆盖坐标、缺面、重复面、ID、p/T/U、缺EOS审核、重复原生映射和非流体侧位置。首次括号语法失败与第二次输入schema误判均保留，sampling03只读恢复通过，CFD重跑0。

输出温度身份为“Euler壁邻有限体积单元平均流体温度”，不是Te、Tr、给定Tw或求解固体Tw。`attachedEdgeQualified/engineeringHeatReady/physicalQualification=false`，q和求解固体Tw保留null。此模块只形成真实采样候选，没有实现附着边界层外缘的自动认证或将其接入工程热求解。

## 进入热计算仍需的证据

| 对象 | 必须核对 | 当前状态 |
|---|---|---|
| p、T、三维U、rho、h0、s | 同一工况/源帧/几何/物性及实际取样位置；全域正性、残差与局部状态稳定 | 小控制已通过数值与代数检查；真实箭体无新流场 |
| 外缘取样 | 空间及外域敏感性、激波/熵层与流线来源、壁邻距离影响 | v192膨胀T仍约+4.70%，近壁熵超量约45—46J/(kg·K)，不直接标Te |
| 工程区域 | 附着/三维横流/曲率、压力梯度、边界层入口和转捩假设适用 | 不由粗sidewall标签、有限值或局部法向速度决定分离 |
| 黏性区域入口 | 相容p/U/T/rho剖面、h0/熵、湍流量、流量与截断影响 | 单个Euler壁邻状态不等于完整边界层剖面 |
| 物理验证 | 与几何/Mach/Re/Tw/物性/测站匹配的公开热参考及误差 | 未闭合；数值收敛或接口通过不授予热资格 |

## CEA与NASA7相容选择

准确源见`evidence/assessment01/source_excerpts.json`。当前Euler为官方伪空气CEA9，R=8.31451/0.02896，接口声明200—6000K；工程`airThermalProperties.m`为固定N2/O2/Ar质量混合NASA7，声明80—2500K并具有低温近似。共同声明温区仅200—2500K，不因为目标有低温膨胀就自动延伸CEA接口范围。

这不是两个可互换的名称：R、cp(T)、焓/熵函数、组分和输运来源均须分别核对。CEA800—1200K线性系数混合段的cp不严格等于dh/dT，既有说明保留。NASA7在1000K的拼接小差也保留。

正式热链优先采用与外流一致、经过原生验证的物性回调贯穿参考焓、恢复温度和边界层输运；本轮尚未修改MATLAB物性分派。若保留异模型耦合，必须独立量化共同温域内Δh(T,Tw)、Δs、rho、cp、mu、k及三维动能与总焓的一致性，明确保持的物理状态与误差，不能仅平移焓零点或用同一数值T替换模型。没有通过该项的转换方案时，候选不进入工程热流默认链。
