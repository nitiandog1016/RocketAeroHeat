# 下一项：核对缩比试件的离散能量收支

这件低速 CM-011 试件已有同工况完整原面数值。当前精度问题是细网壁面放热与由远场节点重建的向外热功率仍相差 6.59%，扩大外域后为 5.97%。首先复用已保存的 `fine02` 和 `outer02` 终场，核对同一阶段、同一轴对称面积基准下的求解器壁面及外边界离散能量通量，区分对流、导热与净质量通量带来的焓参考项。[数值与原面结果](RESULTS.md)

若原生文件只含节点场，就定位当前固定版本已有的边界输出或最小观测接口，先核实其量纲、法向和旋转面积。仅当需要新的原生边界输出时，才从已确认的完整终场登记一次固定步数的观测运行。不得用另一个工况、另一步或远场单侧重建替代原生同阶段热量账。输出须量化 7.429 µW 差额能够解释的部分，其余继续保留。自绘模型面积和飞行测站精度依旧独立。
