直径 3.9492174 mm 的光滑舱体试件处于 300 K、0.1 m/s 的空气流中，壁温给定为 300.1 K。细网格的 **14,140 / 14,140 个原面**均取得壁压和入壁热流，三角面总面积 **3.734979×10⁻⁵ m²**。总入壁热功率 **−0.112632 mW**，热量由试件流向空气。该工况实现了全面积数值覆盖。外域热收支的独立重建仍有差额，实验精度尚未验证。自绘箭体的工程覆盖仍为 43.10%，本轮新增 0 m²。[打开本机三维工作台](../../../outputs/v271_validation/fine_view01/workbench_final/index.html) · [细网原始结果](evidence/fine02.json)

## 实际求解了哪个模型

公开图纸给出了钝端烧蚀层球面、锥面、肩部和小端球面。图 1(d) 的 155.481 in 为本试件采用的外径，176.600 in 为另一条型线的球半径；本例盾面采用图上标出的 180.890 in 烧蚀层近似球半径。两侧肩半径取算术均值，按共同切线生成闭合的独立试件，并按 1:1000 缩尺。项目 X 原点在小端极点，+X 指向盾面，来流速度矢量为 [−0.1, 0, 0] m/s。实物的偏心、倾角、局部厚度、天线、窗口、整流罩、孔口和支撑均不在这份几何内。原三角面通过闭合性、边方向、拓扑和解析面积／体积检查。此模型与 AS-202 飞行量热记录各有独立的几何、壁温和工况身份。[NASA TN D-4185，图 1(c)、1(d)](https://ntrs.nasa.gov/citations/19670027745) · [几何及导出复核](evidence/export_check.json)

项目内官方 SU2 8.6.0 求解轴对称、定常、不可压层流动量与能量方程，实体壁为无滑移等温壁。试件雷诺数为 25.18，Péclet 数为 17.84。近常温空气采用计划列出的恒物性，忽略浮力和黏性发热。SU2 网格和方程以直径、来流速度、密度、0.1 K 温差归一化；单工况程序在返回原面时换回 SI。远场截断半径、体网格及迭代单独记录。三维场沿周向由轴对称解展开，仅适用于此零入射、轴对称边界的试件。[运行合同](PLAN.md) · [固定版本求解器](https://github.com/su2code/SU2/tree/v8.6.0)

## 运行和复现

在仓库根目录的 MATLAB 中运行：

```matlab
[model, report, page] = runCM011TunnelCase();
disp(page)
```

默认生成新的粗网目录。细网可用 `runCM011TunnelCase(fullfile(pwd,'outputs','cm011_fine_new'),'fine')`。程序内部生成气体网格，从普通单工况入口调用项目内的 SU2，再返回各壁区实际数值。需要 Windows MATLAB、PATH 上的 Python（NumPy、SciPy）及项目固定的官方 SU2；安装脚本为 `python scripts/installSU2Runtime.py`。输出包括以米为坐标单位的 STL、可继续读取的 MATLAB 结果和离线页面。此次集成实测了粗网从零计算和细网终态回读，两页的所有原面均与原生压力、热流和壁节点温度核对。另用 13.219 s 从相同存档重导页面，将混合壁面的通用工程提示改为真实的研究数值来源。两份最终页面均已逐面核对。默认输出名另用已保存的粗网结果验证，用时 14.328 s。[默认路径回执](evidence/default_path_process.json)浏览器鼠标交互未复测。[MATLAB 入口](../../../runCM011TunnelCase.m) · [集成回执](evidence/matlab_process.json) · [最终页面回执](evidence/view_process.json)
