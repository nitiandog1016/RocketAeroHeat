# v267 通用工程与局部黏性求解入口

基线 `678863d3`。本轮验证 MATLAB 单工况入口能先执行工程计算，按仍缺压力或热流的原面分区调用局部求解器，并在同一原面上归并实际计算的压力和有符号入壁热流。实验数据只用于事后比较。原算例和各次已结束的运行保持原样。

用两个由恒温板隔开的独立平行间隙作软件与方程对照。轴向和展向周期，各间隙有两面实际湿壁，每面由两个有面积的三角形表示。静止间隙两壁 300/330 K，用恒物性稳态导热和封闭质量求压力；另一个间隙两壁 300 K、上壁以 3 m/s 移动，从静止均温初态调用既有 `internalFlow/advanceCompressibleNavierStokes3D.m`。沿用该程序 Couette 验证的气体参数、8 个法向单元和停止标准。两个流体域由实体壁隔开，这个控制只检验两种方法共同求解一份完整壁面，不验证连续外流跨区接口或飞行工况。

一次 MATLAB 单线程对照含启动、求解和导出合计限 180 秒、1 CPU、采样进程树内存 4 GiB、输出 16 MiB。局部稳态限 4000 步，连续 8 个残差 ≤2e−6/s，累计守恒相对差 <1e−10。逐面压力相对解析差 <1e−4，热流及壁功平衡相对差 <1e−5。工程单独覆盖须为 1/2，两种算法合并须为 1；关闭或拒绝局部求解时完整功率未知。另核对乱序原面、混入别区的编号以及网页导出。输入、代码身份和终态由运行回执记录；首次非零退出保留。存档重读和记录检查单列。

首次局部推进保存完整初场、首步、每 50 接受步和正常终态，后续导出因 MATLAB 嵌套函数共享变量覆盖逐面方法名而退出 1。修正名称作用域，只从该次终态恢复原面输出并作上述对照，不补跑流场。离线审核另限 90 秒、1 CPU、4 GiB 和 16 MiB，输入绑定终态和原运行回执。

第二个对照检验单一流体域内的传递。沿间隙法向在半高处分区，下壁 300 K、上壁 301 K，上壁 3 m/s。工程端由界面切向牵引、能量连续和封闭质量计算交界状态，局部 FV 只解上半域；沿壁充分发展，无穿透、无流向与展向梯度。实体壁共 2 m²，中间切面只核对通量。一次 MATLAB 单线程，120 秒、4 GiB 和 16 MiB，沿用前一对照残差和守恒门槛。两壁压差相对全隙解析解 <1e−4、两壁热流相对误差 <1e−5，界面压力匹配 <1e−4、切向牵引及含剪切功的总能量通量匹配 <1e−5，数值切面法向通量按本例零穿透边界核对。科学资格仍按算例与变量分别报告。

连通域首算从静止均温开始。4000 步后残差为 1.800e−5/s，质量和能量分量为主，超过事前阈值，拒绝该区域。保留初场、周期场、终态和回执。一次初始化对照只改变初场：在计算得到的切面与实体壁之间线性插值速度和温度，由明确的局部总质量初始化等压密度；初始温度缺少黏性发热产生的弯曲部分。保持同一半域、物性、总质量、步数和全部阈值。另限 120 秒、1 CPU、4 GiB、16 MiB，失败即保留连通域未通过的结论。
