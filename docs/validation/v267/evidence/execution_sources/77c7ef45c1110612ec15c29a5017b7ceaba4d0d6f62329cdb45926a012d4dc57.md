# v267 通用工程与局部黏性求解入口

基线 `678863d3`。本轮验证 MATLAB 单工况入口能先执行工程计算，按仍缺压力或热流的原面分区调用局部求解器，并在同一原面上归并实际计算的压力和有符号入壁热流。实验数据只用于事后比较。原算例和各次已结束的运行保持原样。

用两个由恒温板隔开的独立平行间隙作软件与方程对照。轴向和展向周期，各间隙有两面实际湿壁，每面由两个有面积的三角形表示。静止间隙两壁 300/330 K，用恒物性稳态导热和封闭质量求压力；另一个间隙两壁 300 K、上壁以 3 m/s 移动，从静止均温初态调用既有 `internalFlow/advanceCompressibleNavierStokes3D.m`。沿用该程序 Couette 验证的气体参数、8 个法向单元和停止标准。两个流体域由实体壁隔开，这个控制只检验两种方法共同求解一份完整壁面，不验证连续外流跨区接口或飞行工况。

一次 MATLAB 单线程对照含启动、求解和导出合计限 180 秒、1 CPU、采样进程树内存 4 GiB、输出 16 MiB。局部稳态限 4000 步，连续 8 个残差 ≤2e−6/s，累计守恒相对差 <1e−10。逐面压力相对解析差 <1e−4，热流及壁功平衡相对差 <1e−5。工程单独覆盖须为 1/2，两种算法合并须为 1；关闭或拒绝局部求解时完整功率未知。另核对乱序原面、混入别区的编号以及网页导出。输入、代码身份和终态由运行回执记录；首次非零退出保留。存档重读和记录检查单列。
