# 把温度的物理含义和实际反算方法接入科研工作台

v261 已验证单线程配置选择、节点温度及越界恢复。默认算法仍为 TOMS748。静止控制没有新的流场和壁面热流，真实外表面新增合格面积为 0 m²。[本轮审核](evidence/audit/report.json)

下一项按 H5 接入这次新增的实际方法身份。复用已保存的两份静止空气记录，检查现有结果读取、探针与 CSV 导出能否同时保留节点编号、气体温度、单位、实际工作对象的方法和源帧。六壁给定温度与气体温度数值相同，应可从名称和来源区分。此算例的壁面热流和求解固体温度保持未知。较早的数据没有记录反算方法时，显示来源未记录。

优先复用现有结果组件，在已有证据能区分两个文件之处只补缺失字段。以相同节点在两份存档间切换做验收，界面读数、方法和导出行应逐项一致。该验证使用已保存数据和离线入口，复用前轮通过的网格与基础交互，避免重建或重新求解。本地共享界面有并发编辑，动手前先核对实际差异并登记受影响文件与验证预算。

这一项落实科研显示。全局外流、工程边界层和局部黏性区域的入口及反馈仍按项目目标保留原责任，界面验收单列。
