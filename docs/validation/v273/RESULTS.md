# 同一 CM-011 低速试件的三维全壁计算

在 0.1 m/s 空气来流、300 K 环境、300.1 K 给定壁温下，三维扇区解已映射到同一试件的 **14,140 / 14,140 面，3.734979×10⁻⁵ m²**。原三角面入壁热功率为 **−112.407 µW**，比二维轴对称解的放热量小 **0.200%**。同一残差装配中，三维壁面向空气放热 **112.400296 µW**，远场向外输送显热 **112.387458 µW**。两者只差 **0.012839 µW（0.01142%）**，通过事前约定的 0.5% 数值收支门槛。此前二维离散在相同 12D 外域上相差 **7.899%**。[三维原生能量账](evidence/energy.json) · [二维原生能量账](../v272/evidence/fine02.json) · [本机对照工作台](../../../outputs/v273_validation/workbench02/workbench/index.html)

两种方法在整壁热功率上接近，边界收支对离散方式更敏感。三维比较同时改变了体积几何、周向通量和轴对称源项的处理，无法单独确定每个变化对旧差额的贡献。试件始终为零入射、光滑、等温、周向对称的独立缩比模型。压力和热流的同工况实验精度待验。自绘模型的同面工程覆盖仍为 0.846754 / 1.964629 m²（43.10%），本轮新增 0 m²。[试件来源与适用条件](../v271/RESULTS.md)

## 几何、方法和收支

固定 SU2 8.6.0 解三维定常不可压层流与能量方程。模型沿用细网母线、原 42 层法向网格和半径 12D 的远场。6° 扇区含两个 3° 周向单元层。86 个轴线节点由各射线共享。轴旁 168 个三棱柱与 7,896 个六面体形成连通域。按面体积与母线一阶矩独立算得 120.471018235 D³。原生程序按其格式调整三棱柱及边界面朝向，读入后的总容积为 120.471 D³，最小对偶控制容积为 5.89×10⁻¹⁰ D³。60 个扇区的弦面面积比同母线的旋转面积小 0.0278%。两对称面的交线上，SU2 对约束法向作正交化。[网格核对](evidence/geometry.json) · [SU2 几何实现](https://github.com/su2code/SU2/blob/v8.6.0/Common/src/geometry/CGeometry.cpp) · [SU2 对称边界实现](https://github.com/su2code/SU2/blob/v8.6.0/SU2_CFD/include/solvers/CFVMFlowSolverBase.inl)

从 v271 的二维完整细网终场旋转速度矢量，生成三维初猜。随后由三维求解器更新压力、三速度和焓。绘图时按镜像对称找到每个原顶点所属扇区，在实际三条射线间插值，再映射回原三角面。按弦面三角形独立积分得到 −112.427 µW，原面映射为 −112.407 µW。原生壁热监视量折回整壁为 −112.400 µW。三种数值的积分面积和权重均随结果保存。[原面映射代码](../../../scripts/readCM011TunnelSector.py) · [逐点独立回读](evidence/final_export.json)

单步观测与官方对照从三维正常终场的同一保存态开始。观测读取的五个状态量与原生重启动逐节点完全相同。单步后官方与只读观测程序的状态最大绝对差为 1.14×10⁻¹³。归一化参考焓取自同次远场调用的全部实际边界节点。全壁尺度的远场原始焓功率为 112.450957 µW，净质量流量带出的参考焓功率为 0.063499 µW。相减得到上述显热流出。两个对称面的质量与显热增量均为零。内部面净显热增量为 −3.79×10⁻¹⁵ W。最终装配余量为 −1.284×10⁻⁸ W，与壁面和远场显热的差额方向相反、大小相符。[原生装配读数](evidence/sector_stages.csv) · [远场参考焓](evidence/far_reference.csv.gz)

## 运行与工作台

首次计算在 720 s 时限结束，历史最后索引为 13,993，完整重启动及表面配对帧为 13,000。该帧的焓残差为 −7.65，工作台对四个三维场量都标记“未达稳态验收”。根据下降速率与 147 MiB 的实测进程组峰值，另行登记一次相同配置的接续。三维初态使用完整 13,000 帧，接续正常结束于本地索引 4,999（5,000 次更新）。最后 20 步压力、三速度和焓的最大对数 RMS 分别为 −10.62、−8.79、−10.44、−11.62、−8.13；壁热监视量相对极差为 2.17×10⁻⁸。壁节点速度为零，两对称面的最大法向速度低于来流的 7.5×10⁻¹⁵。首轮后 993 个历史索引与接续重叠，不能把两段的最后索引直接相加。[两段运行合同](PLAN.md) · [首轮保存帧](evidence/first_frame.json) · [两种状态的工作台对照](evidence/first_export.json)
