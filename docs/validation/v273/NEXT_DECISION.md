# 下一项：低速民用试件的非零入射单工况

相同零入射工况的二维／三维对照已经得到全壁压力、热流和同阶段边界热账。关闭本次扇区计算。其物理边界和几何都有周向对称性，只能回答零入射试件的数值问题。[结果](RESULTS.md)

下一项使用同一公开 CM-011 光滑低速试件，在 0.1 m/s、300 K 来流与 300.1 K 给定壁温下计算一个非零入射工况。要回答的问题是同一条圆周上迎流侧和背流侧的压力与热流如何变化。先核实该工况保留的几何镜面对称性、全周分母、网格与本机预算，再登记唯一工况和停止条件。原有 6° 扇区的镜像展开仅用于零入射对照。以新工况实际求得的三维场映射回全部原面，逐变量报告同一轴向位置的周向分布、功率和边界收支，并接入同一工作台的选面、曲线和导出。

实验对照只采纳几何、工况、壁温和测量定义相匹配的资料。自绘模型的工程覆盖另计，累计热量、轨迹和跨流态仍后置。
