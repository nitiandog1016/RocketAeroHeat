# v172 同模型层流冷重启与自适应推进合同评审

日期：2026-11-06。父任务指定基线：`2865300`。本项只读审阅现有合同和小型 JSON，不运行 CFD、不构建、不修改旧生产源。本文是待实现设计，不能作为新能力或物理资格回执。

## 1. 决定与适用边界

可以复用 v171 的完整保存 `1500`，设计一个具名的同网格、同物性、同空间壁温层流冷重启入口；在准确官方实现核验和有区别小检查通过后，才允许唯一事前登记的自适应推进候选。它是从明确保存态开始的新任务，不是恢复超时瞬间，也不把旧任务追改为正常完成。

新入口应与 `naca-tn3344-spatial-wall-laminar-v1` 分开命名，例如：

- `caseKind = naca-tn3344-spatial-wall-laminar-cold-restart-v1`；
- `initialization.kind = same-mesh-spatial-wall-laminar-state-v1`；
- `advancement.kind = su2-official-adaptive-cfl-v1`；
- 运行包继续为 `rah-ideal-air-spatial-wall-v1`，不为改变配置重编引擎。

新 case 下仍须逐项锁定配置，不能把新策略塞入旧 `variant`、允许任意 CFL/初场/网格或增加一个跳过验证的开关。`MGLEVEL=0`、弱等温公式、三维层流、原 `−8` 和严格热流门槛继续保持。

## 3. 准备与来源合同

建议新增独立准备模块和合同模块，现有分派点只按新 `caseKind` 转交。准备目录必须独占，发布 `preparing` 后才生成输入；全部验证通过再原子发布 `terminal/exit0`。准备失败目录和准确源保留。

源选择须同时满足以下条件：

1. 明确指定 `real01` 的保存1500，禁止自动使用 `restart_flow.csv` 别名、1715、最后历史行或“最近可用帧”。小检查可使用具名已审核的小型非均匀Tw来源，实际候选源则固定1500。
2. 源回执已经终态；输入稳定记录非空且全部为真，无监督完整性错误。实际来源只接受已登记的超时终态，不将一般异常、取消或容量超限自动纳入本轮实际候选。
3. 显式调用保存帧选择/重清点：核对 history 哈希、连续历史、双文件哈希、原节点、字段及阶段。存在完整1500不代表保存之后的1716次更新可恢复。
4. 读取并锁定现有 `audit_real02/report.json`，要求其异常保存帧身份正确、`savedFrameInterfacePassed=true`、输入稳定、存在1500且其严格误差仍满足原阈值。比对审核报告绑定的源回执、体场和相关输入散列，不能只相信一个布尔值；严禁要求或伪造旧 `interfacePassed=true`。
5. 运行包清单、实际可执行文件、来源 runtime flavor、物性模型、OTH能量基准、60—2000 K温区均与源相同。二进制未改仅证明同引擎，不能证明自适应配置与原固定推进数值等价。
6. 复用完整原网格、geometry、mesh_arrays、单 `wall` 标记和130站Tw表。绑定本任务精确路径；若合法来源同时锁有上游同名mesh，不按basename数量误拒。离线搬迁只有在所有同名候选哈希一致时才回退。
7. 校验源Tw表、原应用回执、输入声明和新表全壁覆盖/插值一致；保持表头、SI单位、递增X、不外推、温区。不能把给定Tw覆盖写入流体守恒态以制造热边界收敛。
8. 抽取五个守恒量 `rho, rhoU_x, rhoU_y, rhoU_z, rhoE`，保留原PointID和坐标，以17位ASCII写新 `initial_flow.csv`，重读后逐元素相等。只复用同模型物理状态，不混入SST的k/omega或额外能量扣除。
9. 由原始守恒态独立恢复 `e=rhoE/rho−|u|²/2`、T、p，并检查正密度、有限量、物性温区、原字段与恢复量相容。错误能量、坐标或节点顺序须在原生前拒绝，禁止裁温或重新构造来流初场。

历史源锁不能全部要求当前工作树逐字不变：v171运行后审核器已有具名修改。可复用旧 `historical_locks()` 的思想，但必须提供明确的原路径→准确快照→原SHA映射，只对允许的源码路径重绑定；几何、Tw、场和来源回执不能替换。新执行源另锁，不把最终源码当作旧实际执行源。

建议在新初始化清单中独立记录 `sourceReceiptPath/SHA256`、`sourceAuditPath/SHA256`、双帧身份、`sourceTermination`、`selectedSourceStage`、`priorSuccessfulUpdates=1501`、`sourceLastFiniteHistory=1715`、`sourceAbnormalInstantStateAvailable=false`、精确历史源重绑定和新 `initialStateSHA256`。源已审核不意味着源已收敛。

## 4. 局部、累计与终态身份

沿用当前冷启动语义：`RESTART_SOL=YES`、`SOLUTION_FILENAME=initial_flow`，不设置 `RESTART_ITER`，新history从0开始。源1500已经完成1501次更新，因此：

| 新任务状态 | 本段成功更新 | 累计成功更新 |
| --- | ---: | ---: |
| 新任务初始输入（尚未更新） | 0 | 1501 |
| 保存 `localIteration=0` | 1 | 1502 |
| 保存 `localIteration=j` | j+1 | 1502+j |
| 正常完成N次，保存N−1 | N | 1501+N |

原任务1501之后、直到1715的215次已知历史不属于这条恢复轨迹，不能把新offset写成1716。累计更新也不是物理时间；不能据此计算累计热量。

新 `inventory()` 复用原双文件/阶段检查，但从新初始化合同取得offset；拒绝负数、越预算、重复步和断裂历史。正常任务必须有首帧、全部到达的周期帧和真实正常末帧。异常任务只要求事前周期计划：不能强制最后有限历史对应瞬间场；缺帧/半帧均报告，不补造。默认完整任务审核仍拒绝异常，显式研究模式仅审核完整保存帧，终态成功与保存帧接口成功继续分列。

冷重启会重建梯度、限制器和求解历史，自适应CFL也从新配置初始化。记录 `uninterruptedTrajectoryEquivalent=false`、`solverHistoryReset=true`、`adaptiveCFLReset=true`。对自适应候选应写 `samePhysicalModel=true`、`sameSpatialDiscretization=true`、`samePhysicsAndNumerics=false`，并准确列出推进变化；不要沿用SST准备器默认的数值等价文字。

## 5. 官方自适应推进的最小接入范围

本评审未替代准确二进制源路径审核。应先确认已链接实现确实从当前三维层流入口调用官方CFL反馈、控制量如何读取、何时重置、减小/增长/饱和条件以及物性异常的行为。共享源码树中出现函数不等于该运行包已支持。

新配置只允许：`CFL_ADAPT=YES`、显式完整 `CFL_ADAPT_PARAM`、事前固定的ITER/输出周期和必要的诊断输出。初场、网格、通量、阶数、限制器、线性方法、容差、来流、Tw、Pr和能量基准保持。允许变化应以配置键白名单及其固定值核对，禁止未登记键或重复键。

共享 `config_template.cfg` 当前示例为六项 `(0.1, 2.0, 10.0, 1e10, 0.001, 0)`；不能依赖其宽界默认值，尤其原CFL为0.4而示例下界10。应根据准确官方语义显式登记降低/增长因子、下上界、反馈阈值、启用迭代，并证明新记录字段确实反映原生使用的CFL。本文不擅自决定最终数值，也不提出参数扫描。

资源使用新具名 `resourceProfile` 和v172计划SHA；不能扩大v171的1800秒/2000步限制或普通720秒入口。输出估算继续包含具名双帧及末帧别名，新增CFL/时间步体场列须计入容量。独立列准备、小检查、实际求解、后处理、纠错及协调墙钟预算，设父子监督和停止策略，自动追加0。

## 6. 最小有区别实测和拒绝项

**一次具名小型冷重启。** 从已严格审核的非均匀Tw小场选完整保存2（源已有3次更新），运行最小足以跨过官方启用点的本段；若事前将启用点设为0，可采用4次更新、每2保存，检查0/2/3分别对应累计4/6/7。不能重复v171常值/无表四组合。检查新初场五个守恒列重读逐字相等、原Tw应用值、每帧阶段热审核和新offset。

**区别必须真实出现。** 事前指定“至少一次CFL更新/缩减或增长可观测”判据；如果4次窗口没有触发，就只能说冷重启接口通过，不能宣称自适应推进已实测有效。可由准确源独立算例检查增长/下降/边界和启用分支，但合成分支不替代原生执行；没有触发时不自动延长或扫描参数。

**离线拒绝至少覆盖：** 未终态/不稳定输入；1715无完整对；源场或审核散列错误；旧包/错误物性或SST场；网格/节点/表变化；不覆盖壁面或超温表；守恒能量越域；累计off-by-one；半帧/缺周期/正常缺末；历史负数/重复/断裂；未知策略/非法CFL界/非零MGLEVEL；改变原−8/Pr/通量；预算或计划不匹配。用独占小夹具与内存回执，原真实大场不改。

旧v171合同至少做读源码确认和一次具名来源只读兼容检查；旧case加入自适应、改初场或prior>0仍拒绝。源已变化时正确使用准确旧快照，不通过修改旧证据解决兼容失败。

实际候选收益/停止门槛必须在启动前固定：rho/rhoE、p/q面积L1、壁温偏差、总热功率、正状态、实际近壁尺度、质量/能量核查和完整输出均列出。沿用固定CFL旧发展史只能提供参照；冷重启重建历史未排除，不能把全部差异归因于自适应。计算结束不正常或预算耗尽就停止，不补跑控制或接续。
