## 算子定义与适用界限

对每个原区间，变化权重为`|f[j+1]-f[j]|`，等于分段线性表示中`|df/dy|dy`的积分。10–90%位置从累计绝对变化求出，不能用节点梯度直接求和。每带保存原包围节点数、带内节点数、相交区间数、最小/最大间距及最大间距/带宽；峰值另存`|Δf|/Δy`、其原节点索引、间距和区间变化量。非单调曲线的绝对变化带可以跨越多个结构，是累计变化包络，不是物理层厚。

每个量均分别报告三种范围：完整59节点列；固定近壁1mm窗口；剩余外侧窗口。1mm来自已经明示的初场壁距混合厚度，仅用于本轮分区诊断，**不是新外缘判据或真实热层厚度**。窗口端点取最后一个不超过1mm的原节点：index29，实际距离0.984067974mm；两窗口共用该节点，没有补造分界处状态。近壁温度带接近窗口端点时，不能认为整个热层都包含在该窗口。

对T、p、法向速度、切向速度模及速度模均生成以上指标。外侧压力变化峰只标为可观测跃迁候选，不能自动等同弓激波；壁温首邻突差留在近壁窗口，不称作弓激波。没有新的经验通过阈值、没有新的δ99、没有自由来流替代、没有外缘平台门槛修改。旧平台拒绝及资格状态原样保留。
