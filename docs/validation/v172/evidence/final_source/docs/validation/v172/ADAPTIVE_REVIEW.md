## 官方反馈实际做了什么

`CFluidIteration.cpp:81–99`先进行隐式流动更新，再调用`CSolver::AdaptCFLNumber`，随后监视与输出。MGLEVEL=0、直接求解、无Full-MG爬升时路径激活；CConfig本模型门禁和CFL门禁均未禁止本层流组合。空间Tw仍明确拒绝非零MGLEVEL，不新增多重网格能力。

`CSolver.cpp:1903–2130`使用三类反馈：

1. 流动与存在的湍流/组分线性残差最大值；本例只有流动。控制容差为`max(acceptableLinTol,LINEAR_SOLVER_ERROR)`。低于该值才允许增长，高于其1.2倍才请求下降，介于两者之间保持；线性残差大于0.99则全域重置下界。
2. 五个守恒方程RMS残差的**log10均值**，不是壁热误差或功率。历史长度`min(100,ITER−1)`。达到窗长后，符号变化次数超过窗长整数四分之一且总变化大于−0.5时下降；总变化大于2 log时重置下界并清空环窗。不得另设OUTLIER_MITIGATION_PARAM绕开该规则。
3. 各节点隐式更新松弛因子：小于0.1则下降；0.1到1之间保持；等于1且全局允许增长才增长。全局下降/重置优先，随后夹到上下界。冷重启从局部迭代0重新计数。

反馈在更新**之后**改变下一步局部CFL；history中的CFL是调整后的值，DT来自刚完成那次时间步估计，两者不是同阶段的直接比例对照。若第一步全松弛且无反馈拒绝，实际首步使用0.4，首行报告CFL可为0.48。

```text

CFL_ADAPT_PARAM= (0.1, 1.2, 0.4, 100.0, 0.001, 0)
```

准确`CConfig.cpp:1937–1944`原生默认为`(0.1,1.2,10,100,0.001,0)`。仅把下界10改为现有起点0.4，避免首次更新直接夹到10；因子、上限、反馈容差、启动时刻保留原生默认。`config_template.cfg`中的`(0.1,2,10,1e10,0.001,0)`是另一组示例，不能混称原生默认，本轮不采用。

保持线性实际目标1e−5、最多10次及原BCGSTAB/LU_SGS。0.001是自适应的控制容差，不是把线性目标放宽；它可能在尚未达到1e−5时仍允许增长，所以候选必须保留实际LinSolRes，分别报告两种判断。上述100上限也不是本例稳定性保证，不因失败追加其他上限或常CFL扫描。

## 原生保护的明确边界

`CEulerSolver.cpp:2567–2602`以原生MAX_UPDATE_FLOW=0.2限制密度和静内能密度的相对改变；小于1e−10的松弛因子置零。通用隐式更新沿同一松弛比例更新各守恒量。本层流没有SST的k换算。

这不是60–2000K可接受域证明。准确`CNSVariable.cpp:153`在旧态回退检查**之前**调用`SetTDState_rhoe`；当前包没有v164/v167的异常回退/能量约束。IdealAir反解遇温区外目标立即抛domain_error，自适应反馈来不及补救。候选必须保留原温区、异常记录及终止，不裁温、不改变能量参考或移植其他包能力。

通用时间步取对流`CFL·V/λinv`与黏性`CFL·0.25·V²/λvisc`较小者，再受MAX_DELTA_TIME限制；精细首层确可限制推进。黏性特征值保留原生配置Gamma近似，源码已有general-gas说明；本轮不改该估计，也不据全局最小DT独自判定病因。

`CFVMFlowSolverBase.inl:854–1017`由按全局点号排列的restart读取坐标之后的5个守恒量，重新执行预处理；保存文件中的温度、梯度和壁热不是直接恢复的独立状态。原网格、节点身份、物性、Tw表和边界必须逐项保持，源1500须与v171完整帧及严格审核绑定，不能用只有history的1715。
