## 实现范围

将原三角壁距和C1速度/总焓规则接到固定理想空气e(T)/h(T)。保持输入Mach、静温、静压和流向，使用同一核求声速、SST来流和初场能量。固定常Tw、SST-2003m、实际三维混合坐标与完整远场。

通过轻量批处理适配复用现有IdealAir.hpp，按PT、Ph和rhoe查询。独立小型编译上限60秒/4GiB，源码与运行库散列绑定。SU2运行包复用rah-ideal-air-v1。

初场准备采用独占记录，完整计算和审核后发布配置与清单。失败或部分发布的目录在求解进程创建前拒绝。验证序列包含温区端点/越域、远场距离不足、原始输入不匹配、初场篡改和旧合同读取。
