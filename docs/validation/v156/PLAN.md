# v156 稀疏阶段保存与重启动计划

本轮执行目标B2，复用v155初场、v144混合几何及v154物性核。真实整箭原生任务预算为0。新增物理资格为0，原收敛和热流门槛继续记录。

## 阶段合同

固定SU2的SOLUTION组输出当前后更新k。RES_TKE为线性系统残差，Solution_Old还受壁面条件写入，均不足以作为全节点独立流动阶段来源。新增Flow_Primitive_K在CNSVariable::SetPrimVar入口逐节点直接记录传入的turb_ke，随对应p/T保存。当前rhoE及后更新k/omega继续作为冷重启动输入。读取原始守恒态，重新构造热状态和湍黏性，CFL适应、线性求解器及残差历史重新开始，连续运行与分段运行分别评价。

只对显式新变比热运行包增加FLOW_PHASE输出组和稳态局部0保存，局部0对应第1次完成更新。常规间隔按原生局部索引取模，正常末次仍强制保存。运行包采用独立flavor，历史v154/v155保持准确来源。

## 构建和测试预算

1. 一次必要全量构建，至多720秒、2线程、4GiB。复用固定归档、工具链和已有构建/恢复流程，先做准确修改单元语法检查。构建或语法失败立即保留记录并停止数值阶段。
2. 新小型三维初场直接逐字复用v155，按旧准确源快照及输入散列确认来源。禁止追改旧初始化合同中的当前源码散列。最多三项正常小例，完整6更新、稀疏6更新及从局部2冷重启动3更新，每项60秒。保存间隔1与2只改变输出设置，比较共有帧全字段。
3. 全节点独立CoolProp核对流动阶段能量、EOS、壁热梯度和p/q同帧身份。首帧k与原始初场比较，后续可用前帧k交叉检查。阶段差须实际可区分。重启动输入逐字取同模型守恒量，累计次数只累加选定源帧以前的更新。
4. 取消、时间预算、进程异常及截断保存的终态管理用有限专用回归验证，每项至多10秒。保存最后完整场，缺失/部分文件单列，异常瞬间未保存的场明确标记。任何异常记录都不能取得成功或物理资格。
5. 输出计划按节点数、字段数、表面连通及历史行数保守估计，限制总长度，进程期间执行限额。研究小例新增输出上限32MiB，源码/小证据公开同步，运行库仅本地。无工程包及独有数据删除。
