# 双支管银球远场质量通量统一与原面交付

基线 v328 `e826ffe75ad75d3046cdf0f781cbd92fc8f537ae`。仅针对 Short Test 65 名义双支管（含两个湿端盖）、Re 882、给定温界。复用准备回执 `ca9c622e056924cb0482e06e5f3561b402d7c40df079da93dd62cd61a98587b0`、混合网 `2bb3aebc0bc1f28d24526f872c213433b92712961f4bb9065eb021b233987e9a`、冷态 `916603c257c841a37b5ec727ccdbb76829dd48917ea1b8567b50f60e22dd34bf`、配置 `f1e0a615abb10c46560e1c446d5d8b61db9eac8d968aab748534fc1ca41a01cf`、v328 有界系数/求解器和固定 SU2 8.6.0 源包；旧计算不重启。[上一决定](../v328/NEXT_DECISION.md)

只改变远场标量迎风与散度配对项及其对角所用的质量通量。每次直接从流动远场 FDS 连续性残差写入，按迭代、标记、顶点、全局节点与有向法向核对。实际温差迎风值要吻合正确的入口/出口状态。任何值无来源、重复、方向不符或使用过期时刻即停止。编译每个对象/链接 ≤180 s、3 GiB。冷态每段 200 次、4 线程、300 s、4 GiB、450 MiB，总量 ≤12 段及 6 GiB。保留初态、100 号周期帧和 199 号终点。沿用温差上下界容差 1e−12、六项末 20 行均 <−8、未限幅 RMS <1e−8；连续两段不改善或任一原有门槛失败即止。

通过后从同一终点再推 20 次。两端点分别作一次只读观察及一次独立释放壁行，另从首端点执行单步普通驱动对照。每次 ≤150 s、4 线程、4 GiB、450 MiB。用两份完整逐边数据独立重建每个节点净通量，两端点都须满足壁放热与标量实际远场出热差 <0.5%、20 步变化 <0.2%、观察全场扰动 <2e−12。流动与标量远场质量通量在每个节点必须逐值一致，散度源单列。

通过后以首端点映射压力、给定壁温、第一层流体温度和入壁为正的热流，按 v325 已核准的五区交叠分配至全部 32,480 原面（700.423854 mm²）。逐区核对面积、瓦数和面号，功率回算差 <1e−10 W，零值与负值保留。对照七个实际测站与外露球面量热。记录名义支管端部、测量与分辨率限制，计算覆盖和独立验证分别记账。统一工作台增加三维查看、探针及局部结果出处。后处理及独立复核各 ≤150 s、2 GiB；界面核对 ≤180 s、4 GiB。物理拒绝、编译/脚本错误和监督状态分别记录。
