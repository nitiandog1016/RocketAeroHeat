# 下一项只检验双支管银球的近壁分辨率

v329 已求出名义装置完整湿壁的压力与热流，两端点物理收支通过。外露球面折合量热高 38.43%，119.8° 和 166.7° 的局部 Nu 偏差方向相反。−Y 支管靠近端盖的热峰分布在几块几乎等值的原面上。目前只有一个通过求解门槛的体网，无法将这些偏差分解为近壁离散、表面/外域离散、支管假设或稳态流动模型的影响。[当前解和局部证据](RESULTS.md)

固定原面、表面壁片拓扑、同一 14D 外域、混合外区、给定温度、流动/标量共享远场通量及节点余量算法。只将原来五个近壁间隔逐个对半分，使第一层法向距离由约 25.4 µm 减为约 12.7 µm，保留近壁区外边界位置。登记粗细网的实际节点数、原面与源壁片身份、逐点定温和冷态，各自验证网格正性及同一五区交叠。把 v328 试件驱动中对原体节点数的固定检查改为与该试件新网回执绑定，仍然核对所有边界节点和输入身份。

粗网基线直接用 v329。细网从自己的原始冷态求解，事前按实际网格规模登记预算，沿用有界、六分量残差、未限幅方程、热稳定和同阶段 0.5% 守恒门槛。取得合格端点后在完全相同的 32,480 原面上比较五区功率、壁压、热流分位数、峰值及近峰区域，同时比较七站 Nu 和折合量热。工作台保留粗细网身份、共用色标及同面差值。两层分辨率可测敏感性，空间收敛阶仍需更多证据。若细网失败，记录真实失败点，保留 v329 已交付场，避免用实验值调网格或壁温来制造一致。
