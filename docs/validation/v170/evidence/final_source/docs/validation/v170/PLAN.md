# v170 测量段算子与实际三维网格：事前计划

2026-11-06，在网格生成、数值执行和主程序修改前登记。沿用 v169 正确 Mach1.97 的三维层流入口，不重复三更新、二维轴线、旧 SST 或已过 UI。

## 本轮可交付范围

1. 由原 Figure1(c) 的电极尺寸重建两经线、22个站和20个有限测量区间；保留旧图读表，区分图上横坐标、对侧温度站和电极中点。凡位置匹配超既存误差均单列，不修旧表以获得通过。
2. 实现有限区间面积积分，保留区间重叠，输出积分功率、平均热流和实验归约所需的局部状态。名义几何可用与实验归约资格分列；不能将重叠区间功率累加为全壁总功率。
3. 为已知法向列实现受限的局部外缘识别和独立合成真值/拒绝检查。无平台、激波污染、回流、驻点或多解不能用来流补值；此算子不授予三维分离适用性。
4. 独立新程序生成一个实际分辨率的四分之一三维验证网格，沿用真实鼻尖和法向张量积。原小例合同/旧输入逐字保持。节点、法向列、每个实验段和壁温来源可追溯，几何结果不等于物理解。

## 唯一网格规则和预算

- 轴 X、鼻尖0、来流−X、真实半球 R=0.0508m，至实验柱端 X=−0.127m。保留全实测热壁，末壁温明确沿用 v169 的常值延拓假设。
- 子午网格必须穿过名义电极端点、22个原壁温插值节点和肩点；每两个必要站之间确定性等分，使弧长步长不大于 D/64。
- 四分之一周向24等分；首法向层1μm，增长1.2，外偏移2D。最后两层合并规则事前固定：若精确外端产生小于前一层的尾层，则合并最后两层，不扫描增长率。
- 至多一个实际几何候选，≤240000单元、≤4GiB、准备≤180秒、独立检查≤180秒、总新输出≤128MiB。全连接配对/方向、所有单元正性、独立离散体积相对差≤2e−10、光滑域体积和壁面积误差各≤0.001。失败保留，不能自动细化或换参数再跑。
- 独立评估每带恒温的端点误差、marker共享节点跳变及 k·ΔTw/d 的热流放大尺度。这个尺度不是实际热流误差，也不能依小温差直接通过。优先复用已有成熟空间壁温接口，尚未完成新入口来源和边界测试前不视作可运行。

本轮不登记正式 CFD 长候选，也不再运行原三更新夹具；原生运行/引擎构建/MATLAB/UI预算均为0。测量匹配、空间Tw、外边界类型与局部外缘前置明确后，下一轮另登记新具名实际入口及唯一总预算，不直接放宽旧小例验证器。旧 source/合同、原−8及实际近壁/热流门槛不变。
