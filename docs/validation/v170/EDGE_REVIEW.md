# v170 局部法向列外缘提取：已测范围与限制

本项完成了一个**有明确拒绝状态的受限外缘诊断算子**，没有运行新 CFD，也没有给 NACA 实验或真实 20° 箭体增加物理资格。正式候选仍需局部流动、实验有限段、收敛、网格和外域证据。

## 1. 物理定义和文献边界

传统 `δ99` 表示流向速度达到外缘速度 99% 的位置，但复杂压力梯度和非平衡外流不一定存在可直接使用的常速度平台。[Griffin、Fu、Moin，Physical Review Fluids 6, 024608 (2021)](https://doi.org/10.1103/PhysRevFluids.6.024608) 对此给出基于局部无黏速度重构的推广；[作者机构页面](https://fpce.stanford.edu/griffinfumoin2021a) 提供同一论文的摘要和书目信息。本次仅核对了这些一手摘要中的定义与适用问题。

**当前实现不是该论文的无黏重构法。** 当前使用传统 99% 定义，并增加项目自定、完整记录的保守平台识别规则。下述 0.5%、1.5 倍跨度等都是诊断策略，不能称作文献验证过的普适常数，也不能把它们当作实验不确定度。

适用范围为本零攻角层流基准中存在已解析局部平台、近似二维附着的法向列。显著法向外流变化、熵层、回流、速度过冲、强横流、驻点与多平台可能没有这个定义。本程序返回拒绝及原因，不能为了闭合 20 段而调整门槛或代入自由来流。强变化识别不是完备的激波探测器；即使返回接受，真实剖面是否位于正确的激波后区域、是否受熵层影响仍须独立审核。

## 2. 接口和保留身份

程序：`scripts/nacaBoundaryLayerEdge.py`

```python
extract_edge(profile, normal, tangent, station_s_m, provenance,
             policy=None, evaluate_sensitivity=True)
```

`profile` 必须包含同一法向列的 `distanceM`、`coordinatesM`、`velocityMS`、`pressurePa`、`temperatureK`、`densityKgM3`、`enthalpyJkg`、`specificHeatJkgK`、`viscosityPas`、`conductivityWmK`。首项必须是壁点，距离从零严格增加；坐标必须与指定外法向一致。`normal` 和流向 `tangent` 必须正交且归一化。此模块不自行做体场插值；真实网格已有法向节点时应直接传入这些节点，其他网格必须先有可审核的取样器。

`provenance` 必须说明 `stateKind`（`computed-solution` 或 `synthetic-test`）、`flowStateSource`、`normalColumnSource`、`thermodynamicModel`。来流替代标签拒绝。该标签检查不能证明调用者的来源声明真实，正式调用还应绑定原场、列节点和输入哈希。

返回的 `edge` 只有现有 `heat_parameter` 所需五项；`speedMS` 是所选同一节点的完整速度大小。`edgeSample` 同时保留真实节点索引、坐标、距离、流向速度、完整速度、压力和全部热状态。**不分别平均温度、密度或输运量**，避免用均值拼成不相容的状态；本算子不替代原有 EOS/能量审核。

`delta99M` 是流向速度比例插值得到的位置；`edgeSample.distanceM` 是平台内实际选样位置，两者不同。平台在法向跨度上的几何中点就近选择一个实际节点，并保存其全部原值。

## 3. 当前固定判据

1. 拒绝缺失、非有限、非正热状态，错误法向、非零壁速度、驻点和明显回流/横流。
2. 三条相邻边范围内，压力和密度同向变化分别达到 log 0.10/0.05 时视为强外场变化屏障；向壁侧再保留两点间隔。屏障以外不参与平台搜索。这是保守预防误取激波前状态的规则，不证明该变化必然是激波，宽而弱的变化也不保证被这个传感器完全识别。
3. 平台窗口至少 6 个节点，外端/内端距离至少 1.5。流向速度、压力、温度、密度、黏度、导热率和总焓尺度变化全部不超过 0.5%。总焓差除以 `cp*T+|U|²/2`，不使用依赖焓零点的 `|h0|` 作分母。
4. 合并重叠窗口后重新检查整个区间的变化，拒绝缓慢持续漂移冒充平台。多个不相连平台直接报告歧义，不选对实验误差更有利的一支。
5. 在壁面至平台的剖面上分别寻找 98.5%、99%、99.5% 的唯一持续跨越。`δ99` 前至少 8 个样点，插值包围区间宽度不超过 `0.2 δ99`；99.5% 位置也必须位于平台内端之前。
6. 保留首尾、每隔一个节点再次完整提取。若提取失败、`δ99` 差超过 5% 或五项外缘量差超过 1%，原列不接受。0.985/0.995 结果单列为**定义敏感性**；隔点测试是**已有采样敏感性**，两者都不是独立网格加密验证。

完整策略作为 `policy` 写入每一项结果。`accepted=true` 只表示 `numericalExtractionAccepted=true`；`physicalQualification` 和 `experimentalQualification` 始终为假，不自动进入已验证面积。

## 4. 独立合成验证

测试：`tests/verifyNACAEdgeV170.py`；最新结果：`outputs/v170_validation/edge02/report.json`。

两类 401 点剖面采用已知有限厚度三次函数 `u/Ue=3η²−2η³`（0≤η≤1），外部为常值。独立 Brent 求根建立 99% 真值：`δ99=0.0018821937284436078 m`。其中一例外侧另置压力/温度/速度跳变，确认选择的是激波后平台而非最外来流。

| 检查 | 实际结果 |
|---|---:|
| 两剖面的 δ99 解析相对差 | 0.000591822741（约 0.0592%） |
| 两剖面所选本地 p/T/U | 60000 Pa / 250 K / 400 m/s |
| 含外层跳变例最外 p/T/U | 26000 Pa / 178 K / 527 m/s，未使用 |
| 选样同一节点全部原状态/EOS | 通过 |
| 静焓整体增加 10⁹ J/kg | 选择节点和 δ99 不变 |
| 规定拒绝检查 | 15 项通过 |
| 真实 CFD 法向列 | 0 |

拒绝检查覆盖静止/真实鼻尖、回流、横流、壁滑移、错误法向坐标、重复距离、NaN、来源缺失、来流替代、无平台、过冲造成双平台、两个不同平台、强变化进入边界层以及粗法向取样。

首项 `edge01` 的生产算子与通过版本逐字相同，但测试夹具使用固定数组下标施加 30% 速度增量；该下标实际处于低速内层，并没有产生承诺的过冲，因此测试断言失败。`edge02` 只把夹具改成明确 `0.0018≤y≤0.003 m` 的位置，真实过冲/多平台随即被拒绝。原执行源、部分输出与失败保留，未改门槛，也没有 CFD 重跑。两次工具实际终态分别 exit 1 / exit 0，工具观测耗时约 1.462 / 1.507 秒（包含命令启动，不宣称求解器时间）。

## 5. 下一步连接条件

实际三维基准场准备好后，按明确壁面站/周向角/原节点编号提取法向列，并先进行原有温度、EOS、能量与多 marker 热流审核。逐列保存选样平台、激波屏障、98.5/99/99.5 位置、采样差和拒绝原因。近驻点若必须比较，应另用有来源的驻点极限，不把这个算子的拒绝改成零或来流。

若主要鼻部列因熵层/曲率没有可信平台，停止给该平台算子扩大范围；再有针对性核验热力相容的局部无黏重构或原实验使用的外缘定义。不能把新外缘理论开发变成无限基准支线，也不能把未定义列拼成全面积验证通过。
