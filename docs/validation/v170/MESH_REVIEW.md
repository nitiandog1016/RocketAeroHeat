# v170 三维半球柱验证网格与空间壁温独立审查

2026-11-06。范围：只读 v169 生成器、专用合同、热边界后处理及与实际运行包绑定的 SU2 源码；未生成新网格、未编译、未运行 CFD、未重做 v169 三更新。下列数值分辨率是事前设计建议，实际候选的执行结果由主记录另列。本报告不授予物理资格。

## 结论与本轮边界

保留真实鼻尖的四分之一三维棱柱/六面体域是合理的近期验证入口。零攻角、轴对称几何/边界与两平面对称相容；它只检验本层流基准，不覆盖任意三维不对称失稳、20°箭体横流或底面。

本轮宜完成一个约 10 万至 20 万单元的实际几何及输入审计。将壁面统一为一个 `wall`，生成每个流向壁节点的准确 `X,Tw` 表。**现有 observed 运行包不能直接读取这张表**；在专用输入合同和准确运行包完成前，不生成可误启动的长算入口。实验段界和物性差异尚有缺口时，不以网格完成代替实验可比性。

原多等温带只是 v169 小例入口。随着首层缩小，两个 marker 在同一节点采用不同 Tw 会放大局部热流差，不能仅以带平均温度误差很小作为接受依据。单 `wall` 加逐节点温度可以消除这个人为多值边界；实际流体壁温仍由原弱等温能量方程推进，不做事后覆盖。

## 网格分辨率与确定性规模

- 保留 `s=0` 真实鼻尖，每个法向层的轴节点唯一，首流向带用棱柱，其他带用六面体；禁止用非零半径孔代替鼻尖。肩部 `s=πR/2` 必须是准确网格站，不能让单个单元跨越球/柱公式分支。
- 四分之一圆周 24 个区间对应 `Δφ=3.75°`。独立多边形几何因子给出体积系数 `sin(Δφ)/Δφ` 的不足为 **0.0713794%**，圆周长度系数 `sin(Δφ/2)/(Δφ/2)` 的不足为 **0.0178477%**。这只是周向贡献，实际全域体积与壁面积还须对解析光滑域分别积分；不是流动误差估计。
- 半球约 1° 的流向分辨可以作为候选。强制所有有来源的实验电极端点与肩部，避免在实验段平均时跨未知边界；原图读 Tw 节点不必全部成为几何站，只要每个几何节点从原 `Tw(s)` 精确取值，并量化节点间表示误差。
- 首层法向位移建议 1 µm，外层位移 2D=0.2032 m。若采用 59 层、首间距严格 1 µm，单次求解有限几何级数使最外点准确落在 2D，得到增长率 **1.196731595839051**，最末间距 **0.0334050 m**。这为确定规则，非候选扫描。直接采用 1.2 再裁最后一层会使最后间距只有约 7.554 mm，而前层约 32.609 mm；应明确这一突变或避免它。
- 59 法向层、24 周向区间时，20 万单元上限允许至多 **141 个流向区间**。140 区间对应 **198240 单元、210060 节点**。如果段界加密后超限，应在登记网格前重新确定规则，不在生成后隐去部分节点或缩短被测面。
- 近壁 1 µm 是输入尺度，不是 y+ 或热流通过证据。应由实际场的剪切、壁面密度与黏度计算 `y+=d_n sqrt(rho_w |tau_w|)/mu_w`，独立检查真实第一邻点、法向投影、层内剖面点数与热流的法向加密敏感性。层流原生 `Y_Plus=0` 不参与通过判定。

这里的 2D 外距主要给出远场容纳空间。纯几何级数会使外层很粗；弓形激波落在哪几层必须由真实解再确认。若冲击层只有一两个层间距，几何正性不能代替冲击层解析度。不得事前用自由来流厚度或简单球形脱体经验式宣布外缘已分辨。

## Tw 表与有限段热量的误差账

半球/柱 `X(s)` 在整个壁面单调，因此每个 s 节点转换成一个 X 节点并按 X 排序即可用原适配器。表值在每个壁节点与原 `Tw(s)` 精确相等；单 marker 不再存在同一点两种温度。表必须含真实鼻尖和最后壁节点；末测站以后的恒值延拓沿用显式声明，不隐匿成实测。

只将原 22 个实测点的 s 转成 X 后直接做 X 线性插值，会改变球段原 s 线性曲线；应使用每个实际 s 网格节点的精确表值，并分别报告节点输入误差、节点间 `Tw(X)` 与原 `Tw(s)` 的最大/面积加权误差和末段延拓面积。原壁温表最大分段斜率约 **168.3054 K/m**，所以不能仅凭总温变化不到 3 K 就判断分辨率足够。

原多 marker 方案的固定温度误差对瞬时导热计算的放大项为 `k_w ΔTw/d_n`。量化此项时必须标为给定相同邻点 T 的边界敏感性，不当成真实最终热流误差上界或实验误差。单 marker 表解决人为多值，但节点温度插值、法向导热和有限段积分仍需独立收敛证据。

实验区间交错、可能重叠，各区间应分别积分，不应强制拼成不重叠全壁分区。有限段热流应从实际壁面热功率除以对应表面积获得；同时报告离散网格面积与原解析面积的差别。后处理必须区分全旋转面积和四分之一实际计算面积，不能把四分之一功率除以全周面积。

## 外边界与出口

准确 observed `CEulerSolver.cpp` 第 5401 行使用 `STATIC_SUPERSONIC_INFLOW_PT` 构造指定外部状态，但第 5531 行以实际内部法向特征值 `Lambda<0` 只加入入射特征。因而本入口是一般 EOS 特征边界，不是根据名字把完整外部状态强行覆盖整片外壳。该澄清替代初步仅凭边界名称的判断。

外壳鼻前法向来流分量大，柱侧接近切向，必须分别记录法向 Mach、流向与激波距边界位置。M∞=1.97 并不表示每个边界点法向超声速。当前同一特征入口可作为明示范围的候选，扩大外域对测量段热参数的影响仍待量化。

出口 `STATIC_PRESSURE` 同样按特征构成边界；近壁亚声速部分会受指定 p∞ 影响。当前壁面在 X=−0.127 m 终止，未建实际实验支架和非轴对称电极后部。需要比较一个事前确定的下游延拓/出口位置，或给出测量区对其不敏感的证据；仅因最后热测点在出口前方不能宣布相容。现 `meridian` 的 `END` 是明确上限，延拓需另登记几何含义，不能越过断言后伪称原实验域。

## 独立几何与后续预算门槛

新网格应复用 v169 已测方法，但针对新规模实际执行：完整内面相反定向配对/边界封闭、无重复节点和单元、所有棱柱全参考 Jacobian、六面体全参考解析下界（适用的张量积结构须保留）、独立形函数/Gauss 体积与边界积分一致、解析光滑面积/体积差及每个实验段面积差。轴点合并后对称面不能重复或遗漏。

单 `wall` 后还应实际验证中位对偶法向、首层法向邻点选择和法向投影距离。上游 `GeometryToolbox::NormalDistance` 使用 `max(|n·Δx|,0.05|Δx|)`；当前 Python 热后处理仅用前者，因此必须证明所有新壁节点都没有触发 5% 下限，或在新合同里准确复现原生定义。不要用已有小网格通过替代此项。

本轮建议只运行几何/输入审核，生成明确不可执行的准备产物。完成实验段界、连续 Tw 运行入口及局部外缘后，另登记至多一个实际基准候选，固定线程、总时间、内存、输出/保存频率、残差与热稳定窗口、异常停止和不自动追加。具体秒数应根据新网格成本预估登记，不把 v169 小例毫秒耗时按单元数简单外推为保证。原 −8、严格热审核、历史失败及所有资格门槛保持。

完成后返回真实原面 20°完整域；本验证支线的新能力是准确边界输入、实际剖面与有限段热量对照，不是新几何/新版本号本身。
