# 下一项：让热敏珠全周计算能从独立安装恢复输入

同一工况的 6 m/s 计算目前复用本机已有体网、构造初场和固定端点观察器。一个新的项目检出可以读取随源码发布的原面快照；从侧栏重新计算时，还会读取 v289、v292、v293 的本机文件。对只保留 GitHub 源码、已安装原生内核和必要缓存的使用者，这些路径是实际依赖。

下一项是在已有计算入口前补齐该具名工况的输入准备。逐项列出几何、物性、两步配置、旧节点映射、体网、初场及观察器的真实来源。随源码的小输入直接核对，大型生成物按指纹复用本地缓存；缓存缺失时通过项目自身的准备或构建入口恢复。现有 56 层初场 CSV 为 33,358,206 字节，体网为 20,147,078 字节，观察器程序为 19,511,425 字节。[网格和种子指纹](../v293/evidence/grid.json) · [观察器来源](../v293/evidence/readout_build.json)

以独立输出目录验证准备，不移动或清理旧目录。在调用侧隔离历史目录，核对恢复的 5,216 个原面、各步配置、初场数值、实际网格和运行库。能精确再生的输入逐字节比较。若要换一种构造初场，需要单列新的起始状态、独立证明适用性并重新计算目标时刻。结束条件是同一五步入口在这个隔离条件下可产生全表面的本次场，保留同刻压力、入壁热流、功率、固定壁温和研究资格。单项准备先登记所需资源，首次算例优先复用本版已通过的对照。
