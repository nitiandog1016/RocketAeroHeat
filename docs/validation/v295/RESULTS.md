# 从主侧栏计算或恢复民用热敏珠 6 m/s 工况

在 293.15 K 空气、303.15 K 给定壁温下，从侧栏新算并接续至 7.809360865 µs，得到了 **5,216 面、3.08983026 mm²** 的同刻壁压与入壁热流。与 v294 相比，各算例首次同时有计算壁压与热流的新增覆盖为 **0 面、0 m²**。本版将此前的验证脚本接入普通使用者的五步工作流，并通过一次实际中断核实了恢复后的场来源。整珠放热 **10.69725502 mW**；与 v294 加密网同刻原面表逐字节一致。公开实验给出整珠平均换热系数，逐面壁压和热流的联合独立验证面积为 **0 m²**。[逐面对照](evidence/recovered.json) · [公开实验读数](../v287/evidence/measurements.json)

## 工作台操作

在 MATLAB 中运行 `rocketAeroHeatWorkbench`，选择 **选用 B 型热敏珠**。在网格页选择 **6 m/s · 360° 全周 · 56 层**，按 **核对并使用 56 层全周体网**。工作台核对该网、构造初场与原面身份，并用实际体网的壁节点生成预览。该网有 172,482 个节点、172,032 个体单元、3,072 个原生壁面，结果映射到整珠 5,216 个原三角面。

在边界页确认 6 m/s、293.15 K、101325 Pa 空气及 303.15 K 给定壁温。计算页提供三项操作。

- **从构造初场计算两个半步**。在 `outputs/v294_validation/workbench/<任务编号>` 新建独立计算，依次保存和审核两个物理半步。目标时刻为距构造初场 7.809360865 µs。阶段和目录显示在侧栏日志中。
- **读取已完成计算**。选择该次计算的根目录。程序核对两份真实终场、逐步状态和热量回执、两步间的源帧、比较回执与本次逐面表。随 Git 发布的 48 层归档仅提供对照。新算、读取和接续的主值都取自所选任务的 `second_energy/wall.csv`。
- **从已审核阶段接续**。用于本工作台创建的同一任务。再次核对已完成阶段的输入指纹与原始回执，通过后执行尚未开始的阶段。如果中断的是独立壁反力读数，且确认进程已退出、尚无保存帧、输入仍一致，会保留原目录并补做该项读数。其他终态不明、已失败或步骤缺失的情况均显示现场位置。重复提交正在运行的任务会被拒绝。关闭单个工作台窗口可释放界面；结束 MATLAB 或外层进程组可能中止后台任务，重开时可按目录核对并接续。

结果页保留压力、入壁热流、给定壁温和首层流体温度，可选择近壁差场、拾取原面及导出。给定温度和独立求解的固体温度分别显示。重新选择网格会撤销旧边界确认和结果页。每次查看的离线页都写入独立的 `outputs/thermistor_view_<编号>/workbench/` 目录。

## 已保存结果、错误输入和并发

用 v294 的两个接受端点经五步侧栏恢复。5,216 行压力、热流和首层温度均与该目录原表逐项核对；工作台得到入壁总功率 −10.69725502 mW。实际 WebGL 渲染回执无错误，探针定位到面元 5211。用另一目录提交同一几何和时刻的快照、将壁温改为 304 K，均被拒绝。将网格换回 3 m/s 扇区后旧结果失效。[恢复回执](evidence/restore_ui.json)

在正式第一半步原生进程活动期间，另行读取和尝试接续同一目录均被拒绝。按主进程身份、子进程身份和工作目录复核，再次接续未启动第二个求解器。独立的缺阶段样本也在启动前被拒绝。短时子进程另测了窗口关闭生命周期，关闭回调返回后同一子进程继续写出终态；3 m/s 净功率模式和已发布 6 m/s 归档通过读取回归。[并发核对](evidence/live_recovery.json) · [关闭与兼容性](evidence/controls.json)

首轮恢复检查把 Windows 原生路径和使用正斜线传入的同一路径按字符比较。规范化测试路径后重新通过。关闭生命周期检查的首次短命令在 Windows 参数传递中失去了内嵌引号，改为分别传入两个文件路径后通过。原始失败日志、执行检查器和后续回执均保留。

再次选择同一试件、网格和边界后，从计算页接续同一任务目录。工作台复用第一半步正式终场、状态审核和端点回放，保留未完的独立读数现场，重新执行一次单线程壁反力读数。第一步得到珠面放热 10.70261915 mW、远场流出 10.72656034 mW、空气储热率 −0.02394346 mW，收支差 +2.2593 nW。第二半步的初值取自该次实际接受的第一步终场。[恢复合同](RESUME.md)
