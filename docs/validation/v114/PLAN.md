# v114 经典完整模型与热边界计划（运行前）

以 v113 已测试的原面混合网格、SU2 8.6.0 和主工作台为基础，不重复真实箭体两步导入或旧3750检查点扫描。

1. 直接实现 Schaefer/Ferguson 1961 图1的10°锥柱扩张体。按1.80in直径、3.33/8.00/6.24in轴长和10°扩张角建模，明确鼻锥角舍入差；完整封底、保留全部面，支杆未复现。核对闭合、方向、分区、解析体积及周向离散误差。
2. 由 M4.98、710°R总温、1.6e6/ft单位Re及当前Sutherland物性反求静态来流。独立重算单位和EOS。约66K静温的物性/凝结适用性尚未验证，不能称实验条件完全复现。
3. 官方Windows包不含pysu2；原生配置只支持常量等温或热流边界。实现绝热原生配置；空间Tw只建立全模型坐标/正温度/覆盖校验，执行时明确拒绝，禁止静默等温降级或多标记共享节点覆盖。逐节点调用器为明确未完项。
4. 绝热q=0在云图/探针/截面/CSV标为边界输入，Tw未给定，原生壁面流体温度不称材料温度解。保留旧等温快照入口。
5. 一次经典完整模型实际研究：2线程、最多720秒、原残差门槛-8。初步网格以2µm首位移/1.25增长/24层形成约1.69mm近壁壳，结合单位Re下平板量级厚度约1.46mm说明仅为起始估计；压缩性/分离/底面不由该估计认证。周向32点、轴向步长8mm；远场2/1/1体长，四面体尺寸0.006—0.08m。最多20000迭代，每500步覆盖保存，限制本轮独立研究输出100MiB；若网格拒绝，先定位并保留失败，不重复相同任务。
6. 实际终态、残差、保存迭代与末监测分别记录；任何超时不自动收敛。本轮不设实验误差通过承诺，未数字化原测点、未匹配全热边界之前不计算虚假实验误差。
7. 只做与新热边界/经典模型有关的主UI测试。源码、中文文档、小型输入/回执绑定真实运行版本后同步GitHub；大型体网格/重启动留本地。不改OpenCode或历史共享对象。

验收：几何与物性换算数值一致，原生绝热实际运行/映射可追溯，给定零热流和未知Tw身份无误；仅满足这些不代表完整三维物理资格。单时刻全面积总目标保持进行中。
