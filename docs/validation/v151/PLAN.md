## 初场及唯一数值任务

沿用16,261点/16,000四边形、SST-Vm、定比热物性、AUSM、二阶/WLS、CFL0.4及原边界。固定SU2 8.6.0。先在原二维线段计算精确壁距和投影脚点，核对原生边界调用顺序。固定源码先处理超声速入口通量，再对等温壁强置零速度残差，能量采用弱热通量。共享入口/壁节点0按壁初态赋值，其入口通量使用原生给定外侧状态。出口/壁共享节点8260也按壁初态赋值。

初场复用现有C1速度/总焓构造。壁面脚点至入口的轴向距离为l，初始过渡尺度取经典湍流平板厚度估计0.37*l/(Re_unit*l)^0.2，l=0时过渡厚度为0。此公式仅确定启动分布，最终物理解由原生RANS及收敛/边界验证确定。固定这一规则，不以热流误差调参。入口及顶部非壁节点设精确来流。设b为壁距/厚度截断后C1三次平滑，u=b*Uinf，T=Tw+(Tinf−Tw)*b+Uinf²/(2cp)*b*(1−b)，p=pinf，k=b*kinf。omega沿用已有正数对数混合及60nu_wall/[beta1*(d+ell)²]规则，ell为脚点处相邻原壁邻点距离插值。rhoE包括热内能、动能和k。

先执行一个小型独立代数/几何/验收规则测试，核对精确线段投影、无滑移、含k能量/总焓、入口和共享节点优先级、跨帧跨度与误差门槛。准备原完整域后，至多一次实际SU2任务。最多1200更新、720秒、两线程、4GiB，新增文件长度192MiB。每100更新具名保存表面和完整体场，保持原始字节。1200上限用于在明确存储预算内取得早期状态以及跨度1000更新的候选验收窗口。首100更新内须有保存场，最终是否收敛按原门槛判断。发生失败不自动再启动、延时或扫描初场/CFL/通量。
