# 下一项：检查 6 m/s 热敏珠同一时刻的近壁网格敏感性

本工况全部 5,216 个原面的壁压与热流已经完成时间步长对照。下一项优先检验近壁分辨率对局部热流峰值和整珠功率的影响，保留原有 7.5° 全周分辨率、64 个母线分段、20D 远场与原面编号。[时间步对照](evidence/comparison.json)

在现有 48 层网格的最内 8 个法向区间各插入一层，使原节点成为新网格节点的子集，逐点核对两极、接缝、无滑移壁和远场。在相同物理初场上延拓新增节点的速度与温差标量，先核对原节点值、壁温、初场能量与热梯度变化。使用相同的物理时间终点，优先沿用通过验收的两个半步及固定端点读数。比较入壁热流及压力的面积加权差、局部最大差、峰位和整珠放热；近壁流体温度须在相同物理位置上配对。

先登记实际近壁厚度、单元数、延拓误差判据、时间／内存／磁盘预算及停止条件。若初场差异足以混淆近壁误差，保存证据并先修正初场传递。若可比且物理验收通过，将近壁对照接入同一工作台。该项只检验壁法向分辨率，远场误差、周向网格误差和发展后平均换热仍分别验证。
