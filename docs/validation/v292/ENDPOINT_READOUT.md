# 补充试验：在已接受的第一半步端点读取热量账

原回放已按 [PLAN.md](PLAN.md) 停止。全 148,274 个节点显示追加装配读取的压力和速度与观察器第 261 次终场逐点相等，而当前标量与第 260 次官方接受帧的最大差为 2.22 × 10⁻¹⁶。压力有 23,258 个节点超出 1e-8 容差。[阶段核对](evidence/assembly.json)

本次只校正第一半步的测量。固定已接受端点 7c45ee30136cd16b6459536ad83ddddeb71126225c6a1c8e1b528d3af5fcf789，初场和官方独立反力读数均复用。新建观察器在前 260 次执行完整方程。在同一物理步的附加装配中，照常刷新原生基本变量、梯度、空间通量、BDF1 项及边界条件，只跳过流动和标量的时间更新。两次跳过均记录实际步号和内迭代编号。这样可测得一个固定输入状态的离散反力。原求解器、260 次物理步内迭代、原终场和原失败回执各自保留。

新观察器只允许用于这个具名读数。与首份回放比较前 260 行原生历史应逐字节一致；与官方接受运行继续做历史差、整个观测态、原生储热及独立壁反力的原容差核对。另查附加装配的压力、三分量速度、温差标量与生成的只读终帧一致，并核对旧标量来自原始初场。附加读数不计为时间推进。编译、链接各 1 进程，3 GiB，120 s、60 s，合计 <300 MiB。观测回放单线程，420 s、4 GiB、350 MiB；回读每批单线程、120 s、4 GiB、100 MiB。任何门槛失败即封存读数，停止本次补充试验。
