# 辨别背风两站的尾迹时间效应

Test 65 的局部 Nu 从 119.8° 的 5.5 回升至 166.7° 的 8.8，当前稳态光滑球基流在相同位置由 13.16 降至 6.91。保留 v321 的几何、壁温、物性、热流符号与实验测线，下一项只改变时间处理，检验背风差异中可由非定常尾迹解释的部分。

用已收敛的全周基流作为初场，在尾迹内部施加可复现的小幅非轴对称速度扰动，核对壁面与远场条件不变。先按完整 3D 几何建立实际时间步的内迭代、压力和热流读出，并保存可接续物理终点。至少用两个时间步在相同物理时刻核对结果。实际步长、最大无量纲时长、资源、停止条件和统计窗口在运行前冻结。用尾迹横向速度、非轴对称分量、两站热流、总放热与含储能项的同阶段收支判断是否进入可重复的统计区间。

只有满足时间步与统计窗口要求，才报告同一测线的时间平均值和波动范围。未形成稳定统计时，交付实际到达时刻的全表面场，注明起始条件和剩余时长。支管影响、网格／外域影响和局部测量系统误差另列，均未被 v321 的背风偏差单独证实。[基流结果与来源](RESULTS.md)
