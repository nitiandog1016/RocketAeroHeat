# 同一简化外形的飞行工况能力检查

基线 v357，提交 `307a5f7469727acf0ed51e04828a7e82142fe7fd`。沿用 `cases/simple_launcher/geometry.json` 中的米制原 STL、9,216 面与 0.935516891 m²。选取五个独立标准大气单点 M=0.30、0.85、1.00、1.20、2.00。高度统一为 5,000 m，攻角与侧滑角为零，给定壁温 300 K，固定其他条件以检查马赫数的影响。各行的物理时刻彼此独立。0.05 m/s 的 v357 是单独的风洞回归。

检查两条现有入口。先向默认简化试件的边界确认入口提交实际飞行来流，记录其工况判定。再在相同原面上，通过公开单工况函数检查默认工程方法，逐次保留运行阶段、返回或拒绝代码。几何生成器仅提供原生截面拓扑，须先逐三角形、逐顶点核对已发布 STL；面积直接按该 STL 的实际顶点计算。程序返回数值时按原面交集复算压力、给定压力、有效热流及联合覆盖面积；缺项时整件功率保持未知，同时实测完整结果页的接收判定。按六区统计计数和面积，计算覆盖与实验验证分别报告。

沿用现有方法、正常适用域与默认配置。本轮交付为能力评估和可重复的验收记录。初次运行登记上限 300 s、1 核、4 GiB、100 MiB 新输出。单例物理拒绝保留原因后继续其他工况，几何不匹配、程序异常或资源超限时保留现场。只输出工况、方法、阶段和覆盖审计。各阶段定时从 MATLAB 实际计时取得。
