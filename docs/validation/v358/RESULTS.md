# 简化箭体五个飞行工况的实测能力

**当前版本在五个飞行工况上均未得到整箭全面积壁压与热流，整件热功率均未知。** 低速风洞全周结果已有独立回归。导入同一个米制 STL 时，工作台按文件指纹选用固定风洞后端。其边界确认入口拒绝了五组飞行来流。另以相同原面直接调用项目现有的通用工程单工况后端，测得以下结果。[低速风洞结果](../v357/RESULTS.md) · [模型识别](../../../rocketAeroHeatWorkbench.m) · [通用单工况入口](../../../runAeroHeatSingleCase.m)

测试固定标准大气高度 5,000 m、零攻角、零侧滑、给定壁温 300 K。项目大气模型给出 255.68 K、54,048 Pa。全部工况共用 9,216 个原面、0.935517 m²。表中百分数按面积计算，“联合”指在同一面同时具有程序标为计算的壁压和有效热流。预设压力和给定壁温单列。表内“—”表示在来流阶段已退出，程序没有返回面场。

**M2 的主要差异在圆柱段。** 4,896 个圆柱面中，4,848 面有工程热流，但该段的壁压全部属于给定边界，所以圆柱段的联合覆盖为零。M1.20 的 1,776 个联合面和 M2.00 的 1,824 个联合面都在锥形头罩。两例的球形鼻端各有 336 个面被代码标为计算壁压，均未取得有效热流。收缩肩、尾段和平底在两例均无联合覆盖。两例全表面各有 6,960 个给定压力面，共 0.792322 m²。[逐工况、逐区域记录](evidence/cases.json)

**数值覆盖和预测精度有不同证据。** 迎风壁压采用修正牛顿法，模块注明其主要适用范围为高超声速迎风面。M>1 是通用链允许开始运行的条件；这次运行没有提供其在 M1.20 或 M2.00 的精度验证。热流后端采用 Eckert 参考焓、沿流线边界层积分与 Reynolds 比拟等既有工程方法。上述覆盖是当前实现返回的状态，五例均缺少对应的独立实验验证。[壁压方法及适用说明](../../../modifiedNewtonianPressure.m) · [热流方法](../../../calcSurfaceHeating.m)

## 验收与复核

基线为 v357，提交 `307a5f7469727acf0ed51e04828a7e82142fe7fd`。几何生成器提供截面拓扑，所有三角形的三个顶点以 STL 的单精度坐标和原面顺序逐个核对。用 MATLAB 验收驱动调用既有函数及工作台状态机，运行中没有修改求解器或切换物理方法。前 3 例在 `RocketAeroHeat:SingleCase:Mach` 退出，后 2 例执行到覆盖审计，并实际触发 `RocketAeroHeat:WorkflowIncompleteSurface`。通用后端的面积按计算、给定和缺项状态累计。风洞入口的拒绝码为 `RAH:Launcher:Boundary`。通用后端是在程序接口中直接测得；默认工作台载入此 STL 后显示风洞选项。

另用 Python 从 STL 重新计算三角面积，并用逐面状态掩码独立核对五个工况和全部六区的计数、面积、单位与工况身份。五例的全表面联合交付新增均为 0 面、0 m²。首次 MATLAB 进程正常结束，含启动与几何检查共 54.16 s，峰值常驻内存 645.38 MiB；M1.20 与 M2.00 的单例检查分别为 7.51 s 和 11.46 s。[事前计划](PLAN.md) · [MATLAB 完整检查程序](check_flight_cases.m) · [监督回执](evidence/run.json)
