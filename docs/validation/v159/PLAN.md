# v159 轴对称变比热公开运行合同

复用v158相容来流、64,000单元网格、测站定位与近壁选择。本轮实现二维轴对称SST-Vm及同阶段保存，并按有限预算开展实际计算。真实三维整箭本轮运行预算0，现有UI复测预算0。

## 已核实的边界缺口与必要构建

固定源码的`CEulerSolver::BC_Supersonic_Inlet`使用p/(rho*(gamma−1))构造能量，入口和出口的对流路径均未设置一般EOS导数。`BC_Riemann`按流入特征选择外态，静压出口在近壁亚声速区约束一个入射声学特征。公开边界使用全状态入口/顶部和外推出口，应保留其类型。v158提出的Riemann替换须按此核对结果修订。

仅对新变比热模型补原生全状态入口的e(T)及EOS导数，出口设置两侧同一局部EOS导数和黏性导数。原有一般EOS Roe、SST和轴对称源项继续采用固定引擎实现。单独发布`rah-ideal-air-axisymmetric-v1`，保留旧运行包。

按已验证增量构建流程，恢复phase-v2准确源码树并核对298个对象，只编译CEulerSolver.cpp一次、链接一次，合计180秒/2线程/4GiB。保存准确执行源、对象身份和恢复回执，编译失败停止数值阶段。当前检查已确认一般EOS轴对称源由CDriver选择，压力和导数由实际节点传入，SST按半径源项路径执行。该源码检查只说明调用关系。
