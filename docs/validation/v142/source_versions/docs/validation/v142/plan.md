## 数值运行前固定的接口与参数

官方源已下载，9文件与官方Git blob逐字相等，准备5.672秒。以下记录在编译及任何TetGen网格运行前写入。

- 小例和真实候选使用同一串 `rY1q2/5O2/7S10000zVC`。`r`从原连接重建非凸/带孔域，不使用`c`填凸包；`Y1`禁止表面细分/合并，重复`YY`在此版本只是再次赋值，不具有额外保护意义。`q2/5`指定半径/最短边比2与最小二面角5度；`O2/7`为默认等级2（三轮上限）、翻边/平滑/劣单元分裂组合，默认最大二面角目标165度。`S10000`限制新增Steiner点，`z`零编号，`V/C`输出诊断与一致性检查。此目标不是SICN门槛的等价换算，最终仍独立检查所有SICN≥0.1，不按结果调参。
- 实际源码`reconstructmesh`约23294行直接导入原四面体；约23841行在`Y`条件下不把原VOLVERTEX转为FREEVOLVERTEX，故不能声称所有原内部点可平滑。本轮允许原生翻边/增点，是否改善由唯一小例判定。
