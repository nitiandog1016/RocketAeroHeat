# v173 层流、空间壁温与同守恒方向限步组合评审

2026-11-06。本项读取既有v165源码/准确归档、真实类检查及builder，并结合v172失败与本轮准确覆盖结论。本文不重跑旧测试、不编译、不启动CFD，也不把当前待执行夹具称为已通过。v172实际异常调用者仍未知。

## 1. 建议的唯一数值改动

在准确 `rah-ideal-air-spatial-wall-v1` 基线上，仅对 **CNS原始节点态首次rhoe查询的物性域拒绝** 采用v165已有的有限同向回溯：验证旧态后，沿五个守恒量共同的旧态→试探态方向依次尝试 `1/2 … 2^-32`，第一个完整EOS接受的状态生效；全部失败则恢复合法旧态并明确记录零步，旧态非法则终止。

本轮应具名为独立层流+空间Tw数值组合，如已选 `rah-ideal-air-spatial-step-v1`。物性模型/OTH能量基准/60–2000 K、原网格、Tw表、弱热边界、Roe/WLS/二阶和已登记推进参数保持，`samePhysicsAndNumerics=false`。层流调用固定 `k=0`、涡黏度0，不把旧14条SST事件称为新层流证据。

查询上下文属于另一个明确的**诊断改动**：只给本物性模型的 `domain_error` 加上模式、输入和可获阶段再抛出，合法物性结果逐值不变；不改变边界压力，不把边界异常恢复为旧缓存。CNS具名trial/old/backtrack/zero-step/legacy-recovery，活动Riemann具名internal/exterior/mixed。原始节点只有已知局部编号时，global/marker/inner须保持unknown；默认0不能冒充实际编号或迭代0。

此组合是有范围限制的可接受性候选，**不是已证实的v172根因修复**。它也不意味着v165旧收益失败已撤销；没有触发限步的小CFD只证明合法路径相容，不能证明限步对真实发展有收益。

## 2. 数学与物理保证的边界

令 `U=(rho,m_x,m_y,m_z,E)`，其中E是体积总能量，层流静内能为

`e(U)=E/rho−|m|²/(2rho²)`。

接收态按 `U(theta)=U_old+theta(U_trial−U_old)` 构造，同一个theta作用于全部五个分量，不逐分量裁剪密度、速度或能量。物性接受条件应由同一核实际执行：正有限密度、有限查询、原温区以及该核其余数值范围条件；不能另用固定gamma近似或“能量大于0”替代OTH基准下的温界。

在该理想空气e仅依赖T、cv>0的前提下，下温界可写为

`E−|m|²/(2rho)−rho*e(60 K) ≥ 0`。

其左侧对正密度守恒态为凹函数，因此下界超水平集具有凸性。但上温界是同类凹函数的次水平约束，**不具有同样的凸性保证**：两个合法高速反向流态的中间混合态可以因动能转为静内能而超上界。故本规则只能逐候选调用完整EOS，不能用单调区间二分或仅检查两个端点宣称整个线段合法。

有限回溯具有以下可核查性质：

- 合法试探态不改任何守恒量；修正只在具名模型的物性域拒绝路径执行。
- 接受的离散状态通过真实EOS，且保持一条五维共同方向。它不是最大允许步长求解，不保证接受态之前整条连续路径均合法。
- 严格内部合法旧态由连续性支持足够小邻域，但32次有限搜索不保证找到所有存在的正步；精确温界的向外方向可无正步。
- `theta>0`仍需核对接收态是否在浮点数上实际不同于旧态，避免舍入回旧态却报告正进展。`theta=0`和多次零步必须明示。
- 各节点不同theta会改变伪时间更新与原离散残差的关系。共同缩放五个量不等于全域边界通量闭合、物理时间守恒或收敛证明；积分修正账也不能代替这些验证。

原v165补丁在 `SetPrimVar()` 后处理阶段改变Solution，**不更新原生UnderRelaxation/alpha**。官方CFL反馈可能仍读取原alpha；不能宣称新增theta自动参与其下降判据。当前建议保留这一准确语义并分别记录alpha/theta与阶段，不顺手增加alpha*theta反馈。若今后要联动，必须另行证明调用时序和数值合同；不能在本轮同时改变控制器来混淆比较。

## 3. 保护覆盖与仍然存在的缺口

| 查询/阶段 | 本轮拟定行为 | 不能声称的能力 |
| --- | --- | --- |
| CNS原始节点态rhoe | 具名同向有限回溯，旧态也须合法 | 全域正性或全部物性查询均受保护 |
| 接受态的焓、声速、cp、黏度、导热 | 沿用原生尾部重算；独立核对同阶段结果 | 用旧缓存代填失败字段 |
| MUSCL/general-EOS重构 | 保留已有成对primitive/secondary异常回退 | 新节点限步独立保证重构合法 |
| Riemann内部/外部Prho及混合rhoe | 附准确阶段/节点信息后仍严格拒绝 | 修改规定压力、回填来流或隐式边界恢复 |
| 其他边界/未具名物性调用 | 保留原行为；可用模式/输入和unscoped标注 | 已定位所有阶段、已覆盖本次未知调用者 |
| 非本模型或非domain_error | 原样透传 | 广义catch-all恢复 |

已有空间Tw只说明给定温度表实际施加，不能令边界混合态或物面流体温度自动合法/收敛。若下一实际异常发生于未保护边界，必须按新上下文记录拒绝，不以更低CFL、改压力或继续添加恢复分支绕过。输入表、给定Tw、壁流体T、独立求解固体Tw继续分开。
