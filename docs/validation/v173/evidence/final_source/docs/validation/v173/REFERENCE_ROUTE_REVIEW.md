## 首项检查：累计计算≤120秒，不构建、不CFD

开发/审阅墙钟与检查执行时间分开记录。只产生小型准确源码/模型差报告，不复制大场。建议按以下范围分配并共同受120秒上限约束：物性与能量归约≤40秒，准确分派与v115复用范围≤40秒，独立合同/小型代数与拒绝检查≤40秒。若某部分不适用，不能把余额变成实际候选许可。

1. **固定独立模型及原实验锚点。** 保持实验M1.97、Re_D、T0、D和原实测Tw/段界身份。显式登记gamma、R、Sutherland、Pr以及可比较的温区。按该模型重新推导相容来流；p、rho、U和静温中哪些为实验量、哪些为推导量必须分开，不同时强行保持互不相容的新旧派生量。
2. **量化原输入决定的物性差。** 主比较域由相容T∞到原T0及实测Tw覆盖的温度集合确定，并列必要的物理余量及来源。对相同T、相同压力/密度定义比较cp、cv/gamma、声速、μ、μcp/Pr和相关归一化。焓只比较共同参考温度下的增量，不拿不同零点的绝对h比较误差。定比热a²=gammaRT与变比热局部gamma(T)必须分别使用。
3. **测量归约保持身份。** 分列原文局部Nu_s/√Re_s、恢复因子、Tr以及局部外缘物性的模型差；不能用来流替代拒绝的外缘，不能把原热参数当W/m²。原输运表差异、后6段中心未闭合继续单列。容许模型差与实验误差口径须在后续候选前明确，不能看到结果后调整通过阈值。
4. **新能量合同。** 原生IDEAL_GAS按其e=cvT等确切定义形成初态和热审核；旧OTH守恒rhoE不得逐字重用。保留相同物理几何、边界Tw和实验锚点不等于能量列可直接继承。若使用旧场的p/T/速度仅作为研究初猜，也须明确全部重新映射和来源，并另行登记，不能称连续等价或默认开启。
5. **严格检查分派与保存。** 查实际选定包的准确源码/对象和气体分派，确认原生壁温表、17位保存、阶段能量/热流及容量清点。输出/验证器显式区分新模型，不把旧变比热拒绝项删掉来让它通过。数学往返与错误模型、能量参考、温区、Tw覆盖等拒绝使用小型输入，不重复旧三更新。

## 反对理由与风险

- 定比热并不能解决未知进程退出、网格/出口/外域离散问题或非线性不收敛；这条路线没有宣称v173根因。
- 固定低总温不代表未收敛局部状态都低温，也不保证定cp导热与原实验归约足够精确。
- 更换模型使同源逐字对照失效，成本在于独立能量/来流/审核合同；不能再以大量接口版本挤占真实全面积目标。
- 原生弱壁的给定Tw、保存壁流体T和独立求解固体Tw仍不同。不得强行覆盖流体T来满足输入壁温，或把给定温度称已解温度。
- 本评议仅支持一个有限低焓成熟基线；如仍无法形成稳定且可比较的热结果，应明确停止本支线并回到主目标路线取舍，而不是继续增加小型补丁。
