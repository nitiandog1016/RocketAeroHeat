# M0.30 同一流场的重建对照

五个飞行点按 v358 的原面状态复核，沿用其 9,216 面分母。当前实算限光滑民用试件、5 km、M0.30、零攻角与侧滑、给定壁温 300 K 和全壁层流假设。基线 v367，提交 `57ad61a5e636b50a05bab4ca962dadb541164215`。原网 SHA-256 为 `f5656636b80e5a47a7d0cdb04b52f7a97e24fefb274f298ae1c31f3a42e4da68`；官方第 249 次组装前状态为 `7092b9a754666270f8a5918bcb2afbccdd41bbadddef0f9c6fbffc7cd362fa49`；物理上一步为 `998600a5f54616298783e53f78370ecd51b203f64e639835f598d4d8a7871346`。复用 v367 的 matched01、official_prefix01、build_match01、build01 及固定版 SU2 8.6.0。在独立目录仅重编 SIMD 通量的取样对象。

在原 50 µs 物理步的同一基态上各组装一次。基准继承黏性梯度的加权最小二乘。候选仅将上风重建梯度改为 Green–Gauss。核对实际生效选项、两组时间层、基准四个原生残差及 v367 节点右端。取第 35 层第 10–15 列之间的五条子午边，记录几何面向量、两侧原始/重建的速度、密度、焓、温压、限制器、退回一阶的权重、中心与 Roe 质量和能量通量。用面值独立还原中心通量，绝对差须小于 1e−12。在列 11–14 的 348 个节点核对能量组装。收支同号约定见 v367。

选择试算的条件为候选同时降低节点 3828 的绝对能量右端和四列整体的右端二范数，且四个全域分量的最大 log RMS 有改善。若不满足，结束此重建候选的物理步试算。若满足，用官方程序在同一原网上从原物理初场做 50/25 µs，沿用 v366 的全部门槛和 250 轮预算。第一半步通过才推进第二半步。给定流场的离散对照单列，全面积功率需其余物理门槛通过。

每次编译/链接限单任务、180 s、3 GiB，构建盘限 300 MiB。原生单次限 2 线程、150 s、4 GiB，输出限 64 MiB，保留输入、历史、终帧、取样、进程及停止原因。UI 回归限单核、180 s、4 GiB。对读数或输入锁不符保留现场，核实原因后在新目录恢复。五点沿用逐面档案；新证据仅随对应 M0.30 研究档案显示。
