# 回到 M0.30 同一时刻的原面壁压与热流

保留原网、加权最小二乘重建、全壁层流研究假设和 v365 的共同物理初场。停止尾部三个间隔二分及此次 Green–Gauss 候选。下一项直接检验时间步能否跨过原生残差平台并得到同刻原面热流。v366 的固定 CFL=3 在 25 µs 上的末窗优于 50 µs，两者均未通过；v368 的单次冻结组装没有改动这个结果。[历史两种步长](../v366/RESULTS.md) · [重建对照](RESULTS.md)

仅安排原配置下的一组短时配对，先以 12.5 µs 和首个 6.25 µs 从相同初场推进。两者各限 2,500 次内迭代、2 线程、150 s、4 GiB、64 MiB，启动前在新计划中绑定源文件、初终时刻及输出。四个原生 log RMS 的末 20 行仍须全部低于 −8。两种首步均过门才续第二个半步并比较同一 12.5 µs 的全部原面壁压、热流、六区功率、两处圆柱端部面带和同阶段守恒；报告耗时及空间误差。任一首步未过门便结束本轮缩步路径。即便配对成功，12.5 µs 只是数值起点后的首个对照时刻，50 µs 或成熟流动的热载荷仍须各自验收。
