# 下一项对照两套稳态解的近壁流动方向

五个近壁间隔全部对半后，外露银球折合功率仍比试验高 38.61%，119.8° 和 166.7° 两站分别为 12.02 和 3.77，实测为 5.5 和 8.8。先判断两个偏差方向相反的背风测站在当前解中分别处于何种近壁流动区域，并检查 −Y 管热峰附近的壁面切向流动。复用 v329、v330 已收敛的终帧、实际首层速度和已确认存在的原生表面摩擦系数向量。该项无需重跑冷态求解。[本次网格敏感性与壁面单位](RESULTS.md) · [已有同态读数方法](../../../scripts/thermistorLeadNearWall.py)

分别绑定粗细网现场及原生表面坐标，在球面、管壁和端盖使用当地壁面切平面，并将来流方向投影到该平面。记录实际切应力、首层速度的投影方向和幅值。驻点、投影退化位置、几何棱边以及两种判据冲突的面单列；给出共识反向区的面积及热量、两网同面重叠、七站位置和热峰邻域。三维分离、再附拓扑需要邻域变化和流向证据，单个负投影只标局部反向。对照结果接入该工况的原面探针和工作台。完成后依据区位证据选择下一项需要的流动模型或空间分辨率检查。
