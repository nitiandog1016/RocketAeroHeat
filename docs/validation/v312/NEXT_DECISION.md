# 检查前引线端面放热峰对近壁网距的敏感性

20D 和 30D 上的放热峰都落在前引线端面第 10267 面，峰值只相差 0.573 W/m²。下一项固定 **20D**、3 m/s 沿 −Y 侧吹、给定壁温 299.15 K，保留 48 个方位、10,272 个原面和编号，复用 v311 的全周解作基线。优先检验端面附近的壁法向分辨率。用同一物理面比较热峰和端面放热，可直接判断局部高值对离散的依赖。[两域热峰与七区对照](RESULTS.md)

先准备一套局部加密候选，记录端面及相邻引线的实际首层法向距离、受影响单元和过渡范围。核对壁面编号、全域体积、界面绕序和截面位置。两网的第一层位置将改变，温度对照需采用共同物理采样位置。建网及读回先各限单进程、180 s、3 GiB、300 MiB。若无法在保持原面的条件下获得有效网格，保留失败现场并结束该候选。

网格通过后按实测规模登记一次同工况全域计算的时间、内存、磁盘和终止条件，再启动求解。沿用六项残差、温度界限、20 步热稳定和壁面／远场能量账。将第 10267 面及邻面热流、峰值位置、前引线端面与整件功率、共同位置的温度及其差值接回同一工作台。完成这一组对照即给出近壁敏感性结论，两档网距可报告观测差值，空间收敛阶需另外的证据。
