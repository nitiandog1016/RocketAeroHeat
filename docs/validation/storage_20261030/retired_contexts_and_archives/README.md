## 占用说明

清理前28,042条文件路径按长度相加为150,279,149,522字节；按文件ID去重后的内容长度为72,872,173,628字节；再计入现有NTFS透明压缩，文件数据长度约69.57GB。三个口径不可混用，数据长度也不等同于精确磁盘簇统计。

## 旧研究如何复查

三份旧准备系统上游此前已经清理，不能直接运行仍引用原`direction_context.mat`或旧准备清单的历史恢复入口。先从计划中保留的原状态、几何与准确历史源码，在新目录运行`prepareRocketCurrentPeakSystem`建立新系统及来源绑定，再调用`buildRocketAugmentedPatchQR`重建构造。构造源码闭包逐项绑定；后续选行/受限求解不在本次重建范围内，其原记录已完整保留。不能承诺重建后的MAT容器SHA与历史相同，也不能把旧数值结果套进新来源清单。

ZIP成员可通过`zip_members.json.gz`找到精确保留路径和SHA；23份差异原文按内容SHA寻址。原ZIP容器、压缩元数据和旧下载链接不再保留，所有成员原始内容均有替代副本。
