# 旧MAT内嵌缓存清理

按用户对`E:\RocketAeroHeat\outputs`的再次清理授权，本轮回收11份历史MAT容器中的14项可重建构造变量。没有运行MATLAB或修改计算方法，单时刻全面积计算与科研UI目标继续有效。

## 实际空间变化

- 原11份容器合计3,973,338,510字节；非缓存结果迁存后合计1,039,015,529字节。
- 移除的缓存压缩记录共2,934,322,981字节，约2.93GB。
- 全目录去除硬链接重复并计入现有透明压缩后，数据长度由68,906,427,444降至65,972,315,101字节，约65.97GB。此口径不等同于磁盘簇统计。
- 从迁存前盘点到独立审计结束，磁盘可用空间实增2,952,527,872字节，约2.95GB；该值也会受其他进程影响。
- `execution.json`中的删除窗口增加3,973,128,192字节，包含此前已另存的1.04GB结果。**不能把3.97GB当成本轮净回收量。**

## 删除与保留内容

| 退役构造 | 移除内容 | 保留内容 |
| --- | --- | --- |
| v83的Galerkin、最小二乘、层加密、两种粗基、两次混合及局部粗基，共8份 | `coarse`构造缓存 | 原结果摘要、所有数值方向、残差、实际模型作用、独立对照和原始输入引用 |
| Q20完整Riemann储库导数研究，1份 | `cache`导数缓存 | Q、气体/边界/尺度、原NS残差与完整info、方向、实际模型作用、三个差分结果及失败判据 |
| 原Schur拒绝研究，2份 | `momentumMatrix`、`schurMatrix`、`couplingB`、`couplingE`及`M`分解构造 | 原来源绑定、构造摘要、排列、源码身份；独有`density_energy_failure.mat`及失败主元记录保持原路径/字节 |

每个非缓存变量均复制其完整MAT压缩记录，并再次独立打开两文件逐块比较；**不重新序列化科学数据**。182条保留记录的原压缩字节和MAT类型/形状核验通过。

迁存文件位于`outputs/retained_evidence_20261030/v83_validation/`，原研究目录增加`EMBEDDED_CACHE_PRUNED_20261030.json`指向精确位置。原容器路径已删除；新文件是缺少已列明构造缓存的证据文件，不能冒称原完整缓存或把旧来源SHA套到新文件。

当前Q41、最近方向/上下文、原几何、所有独有状态、数值结果、失败与线性检查点，以及v94—v100均保留。没有删除冻结目录，也没有原位改写历史硬链接文件。

## 以后复查旧研究

日常运行不要求全部历史输出，但这里的大型数据没有上传GitHub。保留的1.04GB证据仍需留在本地，才能直接查看这些已算出的结果。

旧完整审计和研究入口原来读取的MAT路径已缺少缓存，不能原样运行。按`plan.json`的`retained`读取迁存证据；若需构造变量，使用其中绑定的准确历史源码、保留Q/几何，在新目录依上游顺序重建，再建立新的来源绑定。Q17的packed C此前已清理，其重建依据在`upstreamRebuildEvidence`指向的旧回执中，不能把本轮迁存当作恢复了旧上游。

重建未在本轮执行；不承诺新MAT容器SHA与原文件相同，不将原Schur失败改记成功，也不把缓存回收当成新增物理解面积。

## 核验记录

- `plan.json`：固定11份容器、14项缓存变量、逐变量偏移/原SHA、27项保留依赖及796项准确历史MATLAB源码版本。
- `inventory_before.json.gz`：迁存前全部28,101条输出路径的身份及去重占用。
- `execution.json`、`operations.jsonl`：逐文件删除及删除窗口磁盘变化。
- `postcheck.json`：182条原压缩记录、全部28,090个其他原文件身份及保留依赖/源码SHA核验通过。
- `preflight/`：第一次Windows PowerShell中文编码解析拒绝的原文与说明；当时没有删除任何原文件。添加UTF-8 BOM后预检查通过，删除范围和核验规则不变。
- `outputs_README_before.md.raw`、`readme_update.json`及`final_postcheck.json`：独立审计之后仅更新输出目录说明的原文、身份与最终复核。

入口为`scripts/compactRetiredOutputCaches.py`（规划、原记录迁存和独立审计）及`scripts/Invoke-EmbeddedCacheCleanup.ps1`（固定白名单、逐项SHA检查后删除）。源码、说明和小型回执同步GitHub，不上传大型MAT或生成工程ZIP。
