# 区分局部热流差异中的时间与网格影响

同一 M0.30 工况下，两档圆柱功率相近，但局部热流 RMS 差 6.06%，约 74% 的加权平方差来自头罩和收缩肩紧邻的两圈。两档的稳态迭代均未通过末窗，现有差额无法单独归因于网格。全层流假设下，两套末三帧均在 6337–6816 号原面出现反向。终止当前稳态组合。

下一项在本工况已保存的同一细网全域场上，使用原生带物理时间的黏性推进，比较一个整步与两个半步到同一时刻的原面热流、压力及剪切。先登记该场作为数值起点，保持壁温、流向、完整尾迹、真实远界和原面分母，分别核对每个内迭代的四个原残差、同阶段能量收支和两端圆柱面带的时间误差。两个分支必须从同一份状态启动。该对照先判断能否分离数值时间误差，后续热稳定窗口和转捩敏感性仍需独立建立；起始试算段不当作已知飞行热历史。本项服务单工况的局部热流，不启动轨迹或累计热量功能。[本轮实测与范围](RESULTS.md)
