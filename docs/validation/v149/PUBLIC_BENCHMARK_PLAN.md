# 公开热流基准的执行补充：NASA ACC-SBLI M7

在本轮Jacobian小检查终态之后、公开基准准备/运行之前登记。原Jacobian计划和实际证据不变。该基准用于建立条件明确的热验证，不替代真实20°攻角整箭。

选择NASA TMR的20°轴对称压缩拐角，复用既有原始网格ZIP、NMF和实验数据合同，新增下载官方WIND参考曲线。计算使用轴对称方程（SU2 AXISYMMETRIC=YES），不是平面二维。两个结构块共享接口合并，保留源坐标的实际精度，cm→m、X=−x，半径不平移。只生成81×101两块对应的16,000个四边形；独立核对正性、内边配对、边界及旋转体积/壁面积，保留原网格与几何名义尺寸的小差异。

输入采用官方WIND样例M7.11、总温1600°R、总压364.8psi、壁温559.8°R。由gamma1.4/R287.058换算静态量，不把参考测站x=−6cm的p576Pa/q9300W/m²当入口。Sutherland参数明确保存，换算单位Re与图示5.706e6/m的差异单列，不静默改压强去凑Re。

模型采用与TMR参考对应的SST-Vm（V1994m＋VORTICITY），入口I=0.021%、mu_t/mu=0.001，Pr=.72、Prt=.9；来源为TMR模型页和WIND结果页。这是公开基准专用模型，不能冒充已有整箭SST-2003m。上游与顶部使用超声速给定来流、下游外推、壁面无滑移等温。近壁处理/生产项版本须核对固定源。公开参考是代表性CFD曲线，不是网格无关真值。

本轮仅一次官方原生两更新启动，≤60秒/2线程，外监督120秒/4GiB；运行前全源/输入锁定，结束后保存真实退出码。后验≤120秒，按原生具名字段检查正状态、同阶段p=rhoRT（误差<2e−12）、给定Tw、非零壁热及热梯度（<2e−6）。轴对称总热功率要核对原生径向权重，不套平面每单位展长积分。若热接口失败，保存失败且不重跑求解；先只读定位。两更新不作实验误差结论、不取得收敛/新增区域资格。主工作台不为两更新结果重做截图。

后续真正验证预先要求：配置/模型/坐标身份明确；原收敛门槛及局部p/q稳定、y+与网格/外域检查；在原21个上游剖面测点、24个独立压力点、27个热流点报告误差和测站；分开入口条件误差、数值误差和模型差。先过上游状态，再评估拐角热峰/分布。实验约±10%量级估计不作为自动放行容差，也不与同源归一化分母当独立误差相加。不同模型、入口或物性对照须事前声明，不以调q配合实验。
