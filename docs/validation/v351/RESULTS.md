## 公开测量能支持哪些结论

- **底面静压。** Pavia、Varney、Passmore 和 Almond（2019）第 II 节及图 2 给出 160 mm 平底体的 49 个压力孔，含中心孔与三圈径向位置。试验以模型直径定义的 Re 为 320,000，使用支撑与促转捩粗糙条，压力扫描器厂家精度为 ±1.47 Pa。本试件底径也为 160 mm，但按底径的 Re 仅为 510，具有收缩肩，无支撑。此次采用测点位置，不能由这组试验给本工况列壁压误差。论文 PDF SHA-256 为 `40fe26aab3108cabd385b454981e87ce6015653aaf73544ce372bc25987d74cf`。[作者论文](https://doi.org/10.1063/1.5078379) · [机构全文](https://figshare.com/articles/9224648)
- **鼻端换热。** Short（1958）第二部分表 I–III 的 Test 65 测量 12.7 mm 带支管银球，Re 为 882，在 0° 站报告局部 Nu 为 43.0。项目球冠的名义曲率直径为 50 mm，按该直径的 Re 为 159.4。后接锥段，最前面元覆盖有限面积，实验也没有给出该局部 Nu 的独立误差条。保留这组数据对原银球试件的验证，排除将 43.0 换算为当前箭体鼻端实验误差。[Caltech 原论文](https://doi.org/10.7907/6CZB-AW27) · [表值和量热定义](../v321/SOURCE.md)
- **尾迹流态。** Bohórquez 等在其细长平底体研究中报告了随长径比变化的分岔，涉及稳定轴对称、稳定非轴对称和非定常流动。其临界值无法直接判定本试件的尾迹状态。上述四个测点是本试件的稳态轴对称预测，实际周向和时间变化仍待验证。[作者论文摘要](https://doi.org/10.1017/jfm.2011.35)

## 工作台和发布

基线为 v350 的 `3f499116`。本版复用相同的低速终帧，新增壁压、热流及两者同面覆盖均为 **0 面、0 m²**，新增原面清单为空。计算覆盖仍为 9,216 面、0.935516891 m²，联合实验验证面积为 0 m²。此次解决了用一块原面的平均量与压力孔点值直接比较的问题，排除了上述两组错配的实验误差计算。

从 MATLAB 主工作台导入 STL、确认边界并读取归档，5.51 秒后显示完整结果。六区面元拾取、X = 0.7 m 截面和 9,216 行壁压/热流导出均通过。独立回读绝对壁压、相对壁压及热流三个全表面 CSV，每份均核对全部面号、数值、单位和取样范围。只有底面两个压力场带径向静压。测点附表与其发布指纹、几何、流场及面表匹配后才随探针显示。验收分别使用本机工作台脚本和 Git 发布版导出脚本。其他任务的前端改动保留在原工作区。[验收回执](ui.json) · [导出检查](verify_scopes.py)
