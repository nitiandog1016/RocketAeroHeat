# v122真实异常后的有限修复决定

原actual01按20步/600秒启动，22.437秒异常终止、无保存场。GDB首项因Windows调试堆触及90秒限额，关闭调试堆后的18.719秒诊断将异常定位到`ComputeConsistentExtrapolation → CCoolProp::SetTDState_rhoe`。异常为`D < DLtriple 4342.96 4879.38`，发生在原生重构有效性/局部一阶回退判断之前。SIGILL来自C++终止器，并非CPU指令集不支持。原初态全部节点通过PT/DE并不保证外推状态合法。

修复仅捕获重构中的CoolProp异常；两端重构数组恢复单元值并进入原生非物理边回退计数。有效重构、原状态更新、EOS公式/能量零点、CFL、网格、壁温、通量与边界配置均不改。黏性残差重新从节点读取原始primitive/secondary，不使用异常留下的重构数组。其他阶段若继续抛出异常仍真实失败，不无限添加捕获或裁温。

原包冻结；新包`rah-coolprop-recon-v1`记录局部异常边数和首例原因。ninja再生成意外计划351项编译，95.734秒主动结束且保留exit1；随后只执行构建图中的一个翻译单元、薄归档索引和链接，11.375+0.328+1.265秒成功。物性静态库SHA保持，旧查询器原字节复用；源码归还，原失败不覆盖。

预设接受步骤：先重做一项仅用于补丁等价性的已有20步非零热流控制，要求无异常回退且原保存场字节一致；通过后允许一次真实19752面20步/2线程/600秒重试。不是以重复小型物性探测代替真实域进展。控制已于8.781秒正常结束，case/mesh/restart/surface SHA完全相同、无回退。实际重试采用原初态/网格硬链接及独立新目录，仅重新绑定运行时，PT/DE不重做。

若再次在其他原生阶段异常，本轮停止自动重试并记录精确阻塞；主UI不开放未经验证的三维物性路径。若启动通过，核对全节点物性、原面压力/热流/温度、法向梯度、积分和新物性局部身份后接回科研组件。原−8、稳定性、网格/外域/热物性及湍流资格不因20步启动成功而通过。
