## 有限恢复许可与物理门槛

一阶场只是启动候选，不能代替二阶结果或授予热资格。以下**全部**筛选通过，才允许从first_order终态99另跑一次restore_second_order，恢复MUSCL_FLOW=YES，其他数值保持，100更新/每50保存/480秒。恢复条件：

- 两组原生正常终态、输入稳定、同阶段EOS/热梯度及正状态通过；源149不变。
- 候选末20更新平均rhoE残差至少优于control 0.3log；rho/k/omega各不劣于control超过0.3log。不同阶残差仅作启动筛选，不证明相同离散收敛。

- 候选max(流动primitive总焓/来流−1,0)不超过source149和control各自的75%。这里不含更新后的k，仅为同定义启动诊断。
