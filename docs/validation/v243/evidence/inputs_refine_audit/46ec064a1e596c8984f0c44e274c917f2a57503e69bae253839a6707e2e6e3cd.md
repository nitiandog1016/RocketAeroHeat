# 一次方法决定：拒绝质量投影直接供热，采用具名区域空间对照

2026-11-16，inspect02实际通过。仅210个已保存射线经过单元、6个真实停止壁面，原数据不改。

## 为什么不是换一条看起来更好的轨迹

四管共同前缀中，H总漂移最大2.142/2.947/1.358/3.571%；P1节点H本身的漂移已达1.853/2.815/1.052/3.597%，混合状态引起的沿程附加最大0.289/0.375/0.314/0.272%。这不是误差界相加，也不称独立真解误差，但明确源节点值随位置变化已足以产生主要漂移。单纯改插值或强制质量管闭合不会纠正这些供体热状态。

局部P1质量向量的|div(m)|·(6V)^(1/3)/|mean(m)|中位0.0383、最大0.2285；6个实际停止面法向质量比例0.00223—0.15044。它们不是SU2数值通量或原生残差。准确归档的BC_Sym_Plane对节点归一法向约束旧态和动量残差，原生MUSCL/Roe在节点双控制体面上运算，不能据此声称三角面内P1样本自动切向或守恒。

## 候选及采用结论

| RT/P0保守质量投影 | scikit-fem11.0.0，固定提交f598e787feadcc63f077e41bf95d93a784f6c172，BSD-3-Clause；实际ElementTetRT1是最低阶RT，ElementHdiv/Piola，官方ex37混合Poisson | 不安装/不调用。它可建立法向连续和散度约束，但没有本相态Euler热状态、Roe面通量或BL外缘供体。将投影质量速度替换原速度会造成动量/能量不相容；即使仅跟踪也不能消除主要供体H误差。拒绝其作为本次直接工程热入口，不否定将来有准确原生通量的后处理用途 |

## 新登记的唯一网格合同

原用户几何4434前体三角面、原坐标/原19752面/全分母全部保留。计算网格允许每原三角面**4个严格共面的子三角面**；每个父面必须按实际子面积准确聚合回原号，不能把17736子面当17736个新原面。原46环线段只增加中点，物理环/切平面/外域/体积不变。该计算面细化范围在执行前明示；不覆盖原壁数据或原黏性近壁资产。

只允许一次Gmsh4.15.2 refine()，1CPU/≤60秒/4GiB/整版256MiB；预计162216tet、原边中点新节点，不安装、不编译、不优化、不改参数。如质量或父子几何不合格即拒绝，不调用Netgen改变嵌套关系。本计划不授新CFD。

先完整保存原生节点/三角/四面体/质量，再审原点逐位、每新点原边中点、每母tet8子/每母面4子、母体积及母面积、闭合/连通/无重漏、正向与原SICN≥0.1、≤200000tet/≤50000点。网格通过只说明有可运行空间对照候选；真实迭代另定总预算和停止合同。审核仍计原240秒，准备仍计原120秒；无扫参数或盲续旧场。
