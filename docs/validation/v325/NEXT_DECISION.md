# 在同一低速双支管网格上检验标量对流质量通量

采用已验收的混合外区网 `2bb3aebc0bc1f28d24526f872c213433b92712961f4bb9065eb021b233987e9a`。同网冷态、壁值、近壁层、FDS 流动离散、扩散系数及守恒映射均复用。下一项只对照 SU2 8.6.0 原有的 `CONV_NUM_METHOD_SPECIES=BOUNDED_SCALAR` 与 v325 已运行的 `SCALAR_UPWIND`；后者直接使用已保存基线。[失败证据和两个网格](RESULTS.md)

核对固定版本源码发现，`CIncEulerSolver.cpp` 在启用该选项时保存流动数值通量的质量分量；`scalar_edge_flux.hpp` 用它构造迎风权重；`CScalarSolver.inl` 还包含质量通量散度修正。内部扩散仍使用经边向修正的平均梯度。这个选项提供一个具名的对流机制检验，不能仅凭 “bounded” 名字认定温差标量有界。归档包含与固定 SU2 源压缩包核对过的文件指纹。[核对的源码指纹](evidence/receipts.zip)

从原冷态启动一组同预算对照，记录首次越界的物理位置、修正前后保存帧和六分量残差，核对边界与内域的实际数值质量通量。若通过原标量界限和残差门槛，再执行既有的追加热稳定、释放壁反力和同阶段守恒检查，按五区返回原面。若仍越界，关闭该组合，在最早发生越界的节点分解对流、扩散和隐式增量，再选针对已识别原因的保守离散。两套 v325 外区的失败终帧均不作初态。
