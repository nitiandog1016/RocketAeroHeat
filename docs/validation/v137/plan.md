## 有限步骤与预算

1. 固定CGAL 6.0.1原生头文件和Boost 1.87.0，复用现有w64devkit编译器。先核对导入任意已有四面体连接（包括非凸/有孔域）的API和`remesh_boundaries(false)`语义；不得用重新Delaunay化冒充导入。现有Python自交包不包含此能力。
2. 安装/构建累计上限900秒，单编译上限240秒，至多一次接口修正重编。头文件/压缩源/二进制新增文件长度上限650MiB，研究结果上限100MiB，单进程内存监督限6GiB；明确退出码、实际源/输入/二进制SHA及许可证。网络失败允许换官方镜像一次，不无限搭建工具链。
3. 小型独立检查：已知体积的局部四面体网格含可改善内部点；只读导入必须逐点逐单元保持连接，重网格必须严格保持边界三角形与坐标、全正体积、内面双向配对和总体积，确实发生局部内部改变。另核对非凸/有孔输入的合法表示；若API不支持原域，停止真实候选，先修改路线，不偷偷填孔/删原体。小型任务每次60秒，总共至多3个不同的有区分力案例。
4. 小型接口通过才执行一个真实候选：坏单元的两层面邻接闭包为选择区，非选择区冻结；固定参数一次重网格迭代，目标尺寸由该选区原边长中位数确定，不扫描。执行上限180秒，且原输入不变。若小型测试表明该选区无法合法导入，使用完整原四面体连接及显式选区映射，但不得重生成完整外域。
5. 从输出坐标/连接恢复完整W/Q/T体网格，原固定节点精确匹配；独立复算全域拓扑、体积、质量及规模。通过标准：全正体积/参考Jacobian，无重复或非流形/同向内面，原边界不变，体积闭合误差≤2e-10，全四面体SICN≥0.1，节点≤400000、总单元≤900000。所有门槛同时通过才成为可接受几何。否则保存失败，不续试同参数/扩大邻域/改变目标尺寸。
