# OpenFOAM13具名部署与入口方案

SU2准确包核验已关闭直接Euler采用：配置明确只允许NS/SST，CEulerVariable物性异常先于旧态回退，普通Far-field使用常Gamma。旧资产保留，不增加通用内核修改。转用H1已登记的OpenFOAM Foundation13 shockFluid。

采用原生Kurganov中心迎风通量、全部面信号、受限线性重构、Euler时间推进；由psiThermo+janaf+perfectGas提供变cp。原生mu=0选择无黏，热交换后续使用成熟黏性域，不把q=0记作外流已求壁热。采用与工程NASA7一致的固定组分/能量参考前须独立核对，不能将CEA或OTH场直接重启。

准确固定参考源18870c24d21c6b982e2cdec27b2f59738cca5f90已读取三项：shockFluid支持无黏分派/守恒能量，janaf逐区间Cp是焓导数。janaf.limit会警告并限制温度，不能隐藏这一行为；新运行必须监听此警告并拒绝候选，同时核对保存的e/T/EOS。该守卫不能声称在每次瞬时查询之前阻止裁限，原生端点行为与工程资格分别记录。稳定性/守恒/外域/公开热验证仍独立。

Ubuntu24.04位于E:/RocketAeroHeat/tools/runtime/wsl/RocketAeroHeat-Ubuntu-24.04，新增系统库实际存储于E盘虚拟磁盘。用户已有必要依赖安装授权。采用官方dl.openfoam.org签名仓库，只加具名源和专用密钥，不改旧源、不全系统升级、不安装可选GUI、不修改交互shell启动文件，不重启。官方固定openfoam13包版本先查询并记录，再明确版本安装；不使用滚动dev或v14。发行包与H1源码的实际差异必须记录，不能用旧commit冒称全部运行源一致。

部署预算：仓库签名/元数据准备≤120秒；下载/安装总≤900秒、最多1GiB下载/4GiB新增安装空间，按apt模拟输出在安装前核对；网络失败只做有依据的恢复，不并行尝试多个来源。安装日志与精确包版本、运行二进制SHA、原生help/模块/物性及边界源码保存。没有引擎源编译。本计划只授权必要部署与只读入口核验，不授权CFD推进。
