# v108运行前合同

v107已交付且是实际进展；本轮不重跑其界面/取消试验。

1. 复用v105 plate03已收敛内部解，为与v106失败冷启动相同的120×96、首层1µm细网格生成双线性守恒变量初场。保持几何、边界、理想气体/Sutherland/Pr0.72；不插值物理资格，不裁温度。核对原/目标节点、凸权重、正密度/内能、壁面无滑移与初场积分差，积分相对变化筛选尺度0.5%。这只是初始化误差门槛，不是守恒离散方法或已收敛解。
2. 一次实际细网格重启动，2线程、≤720秒、原密度/能量log残差−8门槛、每1000步覆盖写检查点；不加时、不反复冷启动。与粗解固定0.04—0.16m区间比较p≤1%、q≤5%的原筛选尺度。没有收敛就仅保留状态和诊断，不作网格精度声明。
3. 三维箭体保持原表面及全区域，以分段平行偏置的近壁层替换射线近壁层，外部仍连接同一远场。对照相同层数/首层间距，核对墙面法向距离、正交性、全部子单元正体积、闭合和原面映射。检查SU28.6.0原生棱柱/边界方向要求，不依赖引擎静默调序。预计先24近壁层+16外层；法向间距/增长改善不等于网格无关或y+已合格。
4. 允许为改变后的网格运行一次实际短启动以验证真实导入，不用dryrun代替真实体网格检查。若几何质量或机制失败，先分析，不靠无限加层。全部研究输出目标≤100MB；不重跑v106外域，不重建旧矩阵，不修改OpenCode文件。
5. 本轮不承诺完整三维物理闭合；通过的几何选项接主工作台供明确研究使用。下一步仍主攻真实20°三维收敛、分离/底面及突起，不把平板扩成长期主线。
