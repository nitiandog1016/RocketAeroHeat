# 下一项：用公开低速加热球试验核对局部热流

带线 B 珠已有七区完整计算，在相同几何上，文件重排及两个邻接区域的平面内重剖均已通过工作台验收。现有图 7 只能对照珠部平均换热。继续拆分该模型的三角形无法增加独立测站。保留该试件及其结果作为日常全流程回归。

下一项是为民用温度探头的连续流分布精度选定一个公开低速加热球风洞工况。首先核对一手来源中的球径、气体、来流速度或 Re、壁面热边界、支撑布置、测角零点，以及可读取的局部 Nu 或热流数据。冻结一个工况、一条测线和相应的测量不确定度记录；若未给出不确定度，应据实标记。来源只有平均量时排除该条局部对照，不用平均值反推测站。

资料匹配后，以该球体作为独立民用对照件，按其本身的几何和热边界计算全表面；将测站位置、算法、实测值、计算值及误差接入同一科研出口。优先回答迎风至背风的局部换热分布能验证到哪些位置。试验未测的壁压继续单列数值结果。B 珠的原面编号及实验资格分别保留。数值预算和停止条件在确定具体来源后登记。
