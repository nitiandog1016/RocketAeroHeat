# B 珠局部重剖面及细壁积分

基线 v319 `d0b38337af4cfee3257d86139d0ee2bbc9757867`。3 m/s、293.15 K、101325 Pa 名义侧吹，96 档网。标准面 183（前接头）与 184（前引线）共边，关联的细壁三角从 1 开始分别为 363/365/366 和 367/368/370。每个标准面用内部重心坐标 (0.2,0.3,0.5) 的点分成三个子面，其他面保持，文件重排。写出时登记面号、坐标与真值。X 截面分别穿过两个重剖区，读取三角面探针、方法与 CSV。[上一决定](../v319/NEXT_DECISION.md)

冻结源为 v319 长引线终帧 a98cfbb17a2061e87dccd69fe0c1ebd712933e6f34b510ecb56ad2f11f0df5db 及同阶段壁反力；均温和电阻测温沿用 v315–318 的原帧、比例与对照来源。复用已接受的动力及标量解。从细壁三节点线性积分表压、壁反力密度和温度；首层温度在对应三角形的实际首层节点按同形函数取样，单列采样位置。检查子面与父面同向同平面、内部无重叠、无空洞，沿用 2e−10 m 顶点及 1e−5 相对面积容差。目标片与源细三角在父面坐标中裁剪；对每个父面核对所有分片的源形函数积分与已确认权重，相对父面积误差 <1e−10。单父面、七区、全件热功率误差 <1e−12 W。以独立交点枚举及原生数据复核；无对应或跨面输入须定位。当前实验支持范围保持。
