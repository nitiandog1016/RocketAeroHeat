# 对带线热敏珠做一次相同的中段加密

光滑控制的中段放热差额按历史原面缩小 71.98%，超过计划的 20% 排期阈值。整珠平均 h 仍比实验高 31.04%。下一次选择实际交付中的带线 B 型试件，检验中段离散在有引线及接头时的影响。v299 光滑加密解可直接作为对应控制。[当前结果](RESULTS.md)

用 v297 带线细网和逐面解作基线。固定 10,272 个原面、七个暴露区域、0.937 µm 首层、周向分辨率、远域、全部物理边界、求解配置和壁面反力映射。只在共同珠面的中段过渡网使用与光滑控制相同的局部边切分。实际网格须证明共同中段与 v299 加密范围相配、引线和接头近区保留，三条目标法向的过渡网距均缩小；否则先处理网格。

登记输入和资源后仅运行一次独立冷态带线计算，沿用本轮残差、延续、正性、温界与同阶段热量收支门槛。按 v297 原面报告加密前后差，按 6,144 个共同三角面与 v299 光滑解对照；分别列出珠部、接头、引线侧面及端面的放热和反向范围。把结果接回带线工作台并核对导出后结束这一配对。两种几何各自的一次网距变化仍不足以确定空间收敛阶或实验局部精度。
