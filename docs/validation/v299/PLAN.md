# 光滑热敏珠中段过渡网距对照

本次只计算公开 B 型热敏珠的光滑控制。以 v298 提交 `4d4b21cdbdbaad7888b00a9452d1cc982e14dd88` 及其 [准确输入](../v298/evidence/inputs.json)、[实测网距](../v298/evidence/spatial.json) 为基线。开始时本地与远端 v298 一致，v299 空闲，Windows 未见本算例求解进程，WSL 发行版已停止，E 盘可用约 326 GiB。并发 Web、测试与研究文件另行保留。

固定 3 m/s、293.15 K、101325 Pa、给定 305.15 K；6,624 原面、0.001D 首层、30° 扇区四格、20D 外域及 v298 原生配置。只在混合网子午三角形中标记内部边，按距光滑壁的距离和轴向位置渐退至原网。优先细化 |X/a|≤0.60、距壁 0.015D–0.1D，保持原近壁层接口和远域。读取新旧实际三维网，比较原面/首层节点、全部改变的单元范围、60°/85°/120° 的最大穿越间距。三条都须缩小，未满足则在网格阶段结束，不运行物理场。

单次独立冷态启动，SU2 8.6.0、Gmsh 4.15.2；先登记网格、节点映射、配置、初场和源文件。几何与审计每批 180 s、1 线程、4 GiB、200 MiB；正式推进单线程、720 s、2 GiB、180 MiB、最多 7000 次，每 500 次和正常终点保存。编译/链接观察器各 120/60 s、3 GiB，两次反力读取、20 次延续及独立单步每次 60 s、2 GiB、180 MiB。界面与导出每批 180 s、4 GiB、200 MiB。保留失败记录，超限或场检查失败即停止物理接入。沿用六项末 20 行各低于 −8、全域标量 [0,1]（容差 1e−12）、正绝对压、壁面无滑移、延续热变化 <0.2%、原面功率与壁反力一致、同阶段远场收支差 <0.5% 的检查。

用相同三角面计算四个轴向带功率、总平均 h、双重反向面积及局部热峰；另给出与 v298 同一历史原面的守恒对照。通过的结果接入工作台，核对色标、探针、切面与导出。实验只对照整珠平均 h，分母使用论文名义面积 3.094 mm² 和 12 K 温差。以中段回落是否大于已知中段差 2.09610 mW 的 20% 作为是否进一步研究同一加密的排期依据，两个网距不足以估算收敛阶。本轮到此结束，不连带重算引线。
