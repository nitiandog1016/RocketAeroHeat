# 从 M0.30 研究外流回到圆柱段壁热

保留本工况 216 个子午带的压力、两域差额和 9,216 个原面映射。下一项在同一低亚声速民用外形、来流与给定壁温下取得圆柱段的黏性近壁流向及换热证据。优先检查已有内部热壁求解入口在此 Reynolds 数和壁温下的适用性，评估鼻部至圆柱段的上游历史、实际转捩条件及近壁分辨率，再登记一次有边界与预算的试算。验收直接对准原面壁面剪切、压力、带符号热流与网格差，给定的 300 K 单列。若转捩条件缺失，明确模型假设及其影响。

本次滑移外流可作同形对照，单凭该场无法判定附着。仍保留肩、尾段、平底的完整面积。首要交付是一个飞行点的全表面结果，五点能力表继续按各自的实算记录更新。[此次对照](RESULTS.md)
