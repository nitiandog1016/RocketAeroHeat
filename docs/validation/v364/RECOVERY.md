# 保留原壁与远界，改变子午单元排列

首轮原生通量闭合，22D 的 3,216 个原面出现非正绝对压力，最小 −3.61 MPa。两网最大非正交角均超过 83°，14D/22D 分别有 3,171/3,244 个内部面超过 70°。五次线性求解中，最后一次开始的残差为 0.00753/0.00370。通量收支与一次线性末残差无法保证壁速准确。首轮所有文件继续保存在 WSL 的 fine01/outer01；[首轮映射](fields/surface.json)仅供复核失败。

一次受控恢复同时覆盖两档远界。仅更换子午单元排列，复用项目 Gmsh 4.15.2 与 simpleLauncherHeatMesh.heat_grid，壁面目标间距取 0.04D。检查 216 条原壁段逐条相同、外界仍在同一折线，保留两侧轴和楔角。原工况、均匀初场、求解器、非正交修正次数、通量门槛和远界条件沿用。新建独立目录；网格生成每档单线程、180 s、2 GiB、96 MiB。原生阶段预算同原计划。逐带及映射后绝对压力均须正，同时报告原始壁速和以自由来流声速折算的最大局部速度比；尖角下的局部加速不能凭此授予附着或热流资格。若结果仍失真，本轮关闭该组合并保留原始现场。按同一几何、同一工况比较，再决定研究页展示哪些数值。
