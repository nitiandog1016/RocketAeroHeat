# v215 物理终端与后续反馈决定

这是具体的方案选择和未满足条件记录，不是已验证边界。依据复用[v212分区](../../HYBRID_SEQUENTIAL_REGIONS_V212.md)及[v209准确边界源码](../../HYBRID_ANISOTROPIC_ROUTE_DECISION_V209.md)，没有新的CFD/来源扫描。

## 本轮明确关闭的入口

原近壁切口x=−0.894458635m、扩域x=−1.194277633m没有可信完整压力/热/湍流剖面。没有实际流场证明其近壁声学信息只能向外传播。不能在此把p∞当真实外压，不能用SimpleFlux把反向质量/能量通量置零，也不能将StaticProfile或文件可读视为完整边界闭合。因此**三域＋短后体人工压力终端组合继续拒绝**，本轮不能启动它。

## 采用的下一设计分支

选择“后续原后体/底面/尾迹邻域反馈 → 物理外边界”，作为下一次有明确退出条件的域设计审核。前面三域的原壁责任不变；从完整母网格和全部19752原面出发，核对后续域是否能用已有精确节点/单元映射、成熟热壁与外边界覆盖剩余10074面，必要时分成多个顺序驻留域。不得凭面积均摊载荷或把底面/尾迹裁掉。先只读既有完整母网格/外边界，只有确有缺口才另行登记保原面的网格预算。

该分支的作用是把**近壁人工切口变为内部交换面**；它不能自动解决最外层混合出入流，也不能宣称无需域独立性。物理鼻部发展、后体/底面反馈和必要上游影响应放在同一完整外迭代合同中。工程链仍在可信附着区承担计算和对照；没有为了文件接口把总目标改成“所有区域必须同一套RANS”。

## 数值接受仍独立

v214同路径基准/正式Jv/实扰动等价和SA链式组装通过，并不撤销整体中心差分失败。利用已有完整逐量数据，一次有预算地评估差分截断/舍入、拉伸梯度条件数和独立误差界，须给出可反驳的接受判断。不能仅以“薄层放大”解释就通过，也不能移动门槛/改尺度/扫扰动。

如果现有信息不足，则明确列出最小缺失观测与为何能区分，另登记预算；不能连续重做同三组控制。完整数值接受、生产调度及物理终端/外域峰值均完成后，才事前登记唯一真实区域候选。以上没有授予新CFD或构建权限。
