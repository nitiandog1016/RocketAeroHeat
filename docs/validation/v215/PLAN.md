# v215 事前计划：原生冻结接口的文件桥接

总目标 active。复用 v214 正式 NK 结果，整体中心差分失败保持；本轮没有流动推进、同三组 Jv、真实区域 CFD 或新增热资格准入。

## 范围与接口决定

已定向读取固定构建绑定的 GasState、FlowState、LSQInterpGradients、FlowGradients 及 mapped 复制路径。一次来源核对预算 60 秒（文件读取与摘要核验；开发协调另计）。v1 的 areaxy>0、全 state 有限、rho_s=rho 与推导 h0 不等于原生复制合同。v1 代码、文件及 48 拒绝保留。

新增具名 RAH.FrozenMappedSnapshot.v2：JSON 身份与映射，数值用逐个 IEEE754 实/虚部十六进制位串保存，避免 JSON NaN、ABI 填充与大小端依赖。仅支持单进程三维、单温单组分标准 Air、SA-Edwards、rhou、MHD/plasma/electric 关闭。交换所有原生 copy 使用的几何、状态、重构及黏性槽；未使用槽保留 NaN/零/符号位，不生成 h0、不修正原生 rho_s。lref、electric_field、黏性 p_e、dwall 不属于本合同的复制量；实际配置若启用相关功能则拒绝。几何 areaxy 在非轴对称三维为未用槽。

绑定实际构建、数据、离散设置、母网格、母面节点规范键、母单元 ID、受体面 ID、来源帧和外迭代/顺序/物理时刻。制造状态明确标记，不可续作物理解。调用方以独立预期身份/映射及文件 SHA 读取，错误或缺项必须拒绝。导入通过单个临时原生 cell 的 staging 构造既有 FrozenMappedDonor，完成后不保留 donor cell/block 引用；不改通量、Jacobian、推进或通用存储。

## 独立预算和验收

- 准备/来源/独立 Python 验证合计 ≤60 秒，1 GiB RSS、64 MiB 输出；运行于独立小目录。
- 一个隔离文件桥接 helper 构建 ≤150 秒、父180秒、6 GiB、512 MiB、2 CPU。若纯编译错误，可在同150秒总预算内最多一次确定性修正；不建第三包。
- 原生导出和独立进程导入/拒绝合计 ≤60 秒、各父90秒、1 CPU、2 GiB、64 MiB。只调用初始化和六组交换，不调用残差、Jv或发展。正向验证逐位保持和全部映射，独立 Python 检查实际物性/字段语义；反向验证错身份、轮次、SHA、重复/错面、截断、有效 NaN/复数、物性/输运、几何和不支持配置。额外回排/未用 NaN 保持必须通过。

所有原生任务有输入 SHA、采样 RSS、输出/时限及组清空回执。保持原13列/416棱柱/32层/2微米、原19752面/总面积/三域责任及29保护文件。并发 Web 修改不纳入本轮。编译器或接口失败原样保存，不为“全绿”追改既有失败。

桥接完成后直接给物理终端外压/混合回流和邻区反馈的具体合同与缺项；完整数值接受、外域与峰值仍是实际区域前置，不能用本软件验收替代。小源码/证据同步公开 GitHub，大资产留 E 盘，无包/独有删除、不新代理/computer-use。
