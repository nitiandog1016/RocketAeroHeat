# RFZ 完整原壁与空气单元的逐面连接

DLR RFZ-REC 的 130,044 个原面（740.729003 m²）均找到了唯一的空气侧四面体，包含全部 14,982 个内腔面。工作台现在可以点选任一原面，核对给定壁温、相邻空气单元编号及其形状质量。相对 v344，同面计算壁压与入壁热流新增 **0 面、0 m²**。本轮解决了实体表面与空气体网之间的连接。RFZ 的全部壁压、热流及总热功率仍待求。独立实验试件另有一份全表面验收。[原面与体网核对](evidence/independent.json) · [银球试件独立验收](TEST65.md)

## 几何与质量

用 Gmsh 4.15.2 将冻结的原 STL 作为内边界，在外盒内建立单一连通空气域。九处用于论文对照的人工封盖单列。两次独立建体产生相同的顶点、四面体、壁面、外盒面和逐面邻接编号。标准内外壁给定 300 K，内腔同温为项目假设。[标准工况](../../../cases/rfz_rec/full_cad_input.json) · [来源、算法版本和体积](evidence/air.json)

| 读回项目 | 结果 |
|---|---:|
| 顶点 / 四面体 | 66,378 / 185,078 |
| 原面 / 外盒三角面 / 内部共享面 | 130,044 / 824 / 304,722 |
| 外壁（含唇环） / 内腔面积 | 719.824895 / 20.904108 m² |
| 空气体积 / 相对体积闭合误差 | 318,502.899087 m³ / 2.22 × 10⁻¹⁶ |
| 最小四面体体积 | 1.69487 × 10⁻⁸ m³ |
| 最小 SICN / SICN < 0.1 的体单元 | 0.002981 / 61,769 |

独立程序从落盘 MAT 反查全部四面体连接，并与 STL 按面号、点序和坐标逐项相等比较。所有内部面的两个对顶点异侧，原壁对顶点均在空气侧，外盒六面的绕序及各自面积通过。独立复算全部体单元的 SICN，与原生值最大差 2.13 × 10⁻¹³。Gmsh 另按自身诊断报告 27 个形状不佳的四面体。SICN < 0.1 的相邻单元涉及 40,413 个外壁面（36.953649 m²）和 1,418 个内腔面（1.905437 m²）。这张网格的验收范围是几何连接。近壁热流分辨率、外域敏感性和解的精度仍缺证据。[独立核读程序](verify_air.py) · [原生警告及进程回执](evidence/runs.json)

## 工作台使用与复现

在 MATLAB 运行 `rocketAeroHeatWorkbench`，从“输入模型 → 选择模型或工况”打开 RFZ 标准 JSON，进入“计算 → 准备或读取空气体网”。首次使用时生成体网，再次打开时核对输入、生成程序、引擎包及 MAT 指纹。旋转后的模型按同一原面号复用单元连接，给定壁温取当前确认工况。两组实际窗口操作均核对首面、内腔面和末面。内腔原面 71,861 对应单元 9,354，SICN 0.069041。该面的探针随工况显示 300 K 或 315 K。修改为 316 K 并重新确认后，旧绑定已撤销。两类损坏缓存均被拒收。[工作台验收](evidence/workbench.json) · [绑定程序](../../../bindRFZAirVolume.m)

在项目根目录也可用下列 PowerShell 命令生成或核对缓存，并复核落盘资产。

```powershell
$airTicket = python scripts/prepareRFZAirVolume.py | Select-Object -Last 1 | ConvertFrom-Json
python docs/validation/v345/verify_air.py $airTicket.directory
```

本轮完整 MAT 为 8,126,160 字节，位于本机 `outputs/rfz_air_volume/` 下按来源摘要命名的目录。Git 保存生成代码、准确输入及小型核对回执。基线为 v344 `d287e0b915d1d457170bdad648637b67d3e5a8c5`，并发的 Web 导出和研究文件保持独立。首建 52.83 秒，使用发布入口重新建体 47.97 秒，后一次进程峰值约 391 MiB。发布版工作台两种工况在同一进程内完成核对，用时 30.05 秒。开发和归档工时未单独计时，流场求解时间为零。[运行记录与本机目录](evidence/runs.json) · [事前计划](PLAN.md) · [下一决定](NEXT_DECISION.md)
