# 从已连接的原壁取得第一组独立物理结果

RFZ 的完整域分母和原壁到空气单元的对应已确定。下一项以标准工况中面积最大的 CAD 第 13 区作为首个壁压、热流交付对象。它包含原面 4,727–27,578，共 477.366627 m²。选择依据是该区的原面面积和已核对的连接。整区的物理流态及某一方法的适用性仍需逐面判定。[原面范围](../../../cases/rfz_rec/cad_faces.csv) · [本轮体网核对](RESULTS.md)

先按该区实际输入落实能独立产生壁压及热流的方法，登记采用理由、物理输入、必要的网格精度、资源限额和停止条件。几何体网的正体积仅满足几何连接要求。对有充分输入和适用依据的原面，用同一工况核对两量、给定壁温、面积和方法来源。其余原面继续计入完整分母。若暂时没有可验收的新增面，以实际缺失的物理输入或失败证据决定下一次计算。作者公开数值场用于对照，实验试件保留独立验收记录。[完整工况](../../../cases/rfz_rec/full_cad_input.json) · [公开实测试件](TEST65.md)
