# 完整原面与空气体单元连接

基线 v344 `d287e0b915d1d457170bdad648637b67d3e5a8c5`。使用[标准完整 CAD 工况](../../../cases/rfz_rec/full_cad_input.json)、其指向的米制 STL 和已验收的 CAD 分组。原面 130,044 个，离散面积 740.7290034031088 m²。核对 STL 原有序顶点与面号、工况的几何及壁温指纹。已有运行中任务为零。

先用项目固定的 Gmsh 4.15.2，将原三角面作为内边界，在封闭几何盒中离散空气。外盒沿每个坐标方向从模型包围盒两侧各扩半个最长边，用于几何体积核对。此尺寸尚无物理远场精度结论。项目既有 Gmsh 双壳建体入口提供几何构造依据。此轮不生成近壁层或计算流场。首法若不能维持原边界，保存失败现场，可用已固定的 TetGen PLC 对同一几何补做一次独立候选；两种方法均失败即按实际证据收口。

一次建体限单线程、300 秒、3 GiB、1 GiB 新文件；最多 120 万四面体。判据为全部四面体严格正体积、内部面恰有两个相反绕序、每个实际壁面与外盒面恰有一个单元、空气域连通、原面顶点与连接一致，单元总体积与外盒减实体的相对误差 ≤2×10⁻¹⁰。核对外壁与内腔两类温界的面数与面积。单独核读限单线程、180 秒、3 GiB；工作台每轮 240 秒、4 GiB。完成终点按原面至空气单元对照、实际文件及原生运行回执认定。压力与入壁热流仍须独立求解。

首建后补充：工作台需要按原面读取相邻单元的形状质量。最终生成入口增加逐体单元 SICN，并按固定源文件及 Gmsh 包摘要区分缓存。使用同一输入、网格设置及原预算从最终入口再生成一次。独立读回复核全部 SICN、原面邻接和温界；用首建资产对照连接和编号。首建产物、警告和日志留存。
