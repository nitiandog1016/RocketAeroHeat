## 固定实施范围

独立运行包采用rah-ideal-air-observed-v1。数值基线固定rah-ideal-air-phase-v2，恢复其准确CEulerSolver源及对象，增加main的C++终止记录及ASCII的17位有效数字。终止记录包含异常类型、what、线程和Windows模块调用地址，刷新输出后转交原终止处理器。发生异常后进程终止，异常瞬间场按实际保存情况记录。

仅编译CEulerSolver.cpp、SU2_CFD.cpp、CSU2FileWriter.cpp三个翻译单元，编译总预算120秒、链接一次30秒、进程树4GiB。其余295对象逐字审核，CEulerSolver恢复后与phase-v2对象基线逐字比较。准确源和补丁保存，共享源恢复。禁止全引擎构建和混入v159轴对称边界改动。

先以同一记录头文件构建独立原生夹具，编译上限30秒。验证普通std异常、OpenMP异常、非std异常均记录并终止，确认实际C++科学计数法对真实邻点相邻9个温度逐位往返，并核对每标量32字节容量假设。
