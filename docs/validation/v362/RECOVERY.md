# 恢复面通量的独立存储

首轮四项原生程序均已正常退出，日志中记录了连续性误差，但在 Windows 挂载目录中，`case/0/phi` 和 `case/0/Phi` 均指向 inode 844424930727169，最终对象头为速度势 Phi。首轮回执及实际执行程序保留在本机 `outputs/v362_validation/sphere01`。缺失通量的首轮不能用于逐单元收支验收。

仅更换运行目录到 `/home/rah/.cache/RocketAeroHeat/v362_validation/sphere02`，位于 E 盘指定的 WSL 磁盘，文件系统类型 ext4。用同一配置和均匀初场在独立目录重复四项原生程序一次，沿用全部原门槛和资源上限。核对两个原生对象的类、维度和 inode，比较初始场、网格及两次保存的速度、压力。额外运行发生在独立目录，首轮原件保留。
