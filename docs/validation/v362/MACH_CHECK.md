# 球体在 M0.30 的低速近似差额

不可压球体对照中，速度势重建壁速和伯努利压力通过了既定误差门槛，原生附加泊松压力未通过。按上一版决定，在同一光滑球体上用 NACA TN 762 的公式 (17)、(23) 和表 I 核对可压缩性影响。仅取 M=0.30、作者的 γ=1.408。独立核对表 I 的赤道速率；按 v361 相同的 129 个极角和面积权重比较实际无量纲壁速、伯努利压力系数。分列不可压解析解与文献间的模型差、离散解与文献间的总差，以及二阶/四阶马赫展开项之差。文献属于理论近似，实际物体的附着及黏性条件仍待证明。

此项仅做代数读回，不重新运行 CFD。工作台回归限 180 s、1 核、4 GiB 和 20 MiB 新输出，核对研究状态、五工况及同窗读档。
