# 同一滑移球的独立速度势对照

基线 v361，提交 `6c09339e25390bee4489830d35fc17b18d79a802`。计算对象限于直径 1 m、来流沿 −X 速度 1 m/s、密度 1 kg/m³ 的理想无旋球流。复用 128×72 子午分辨率、0.002 m 首层和半径 14 m 的远界，绕轴取 ±1° 单层楔形域。远界速度均匀，球面滑移。先运行 blockMesh 与 checkMesh；网格错误、原生失败、非有限、预算超限时保留现场。每个原生阶段限单核、2 GiB 地址空间、180 s 和 96 MiB。保留初始目录、原生终场、边界流量与输入指纹。该程序没有物理时间推进，按源代码核对原生结束和实际线性求解。

固定 OpenFOAM 13 构建 18870c24d21c，potentialFoam 程序 SHA-256 为 `a3dac7d96f7f7e25ec772aa4621f4a891de63348476c321930804c79a897df41`。固定源码先组装面通量，求速度势修正使面通量无散，再重建速度。求解器会先将内部速度清零，显式初始化边界；保存实际输入及初始化规则。势和附加压力线性求解的末残差均须低于 1e-8，检查原生面通量的逐单元闭合、球壁穿透、远界净流量。线性残差与原 SU2 速度/压力方程残差分开报告。

比较两种有明确来源的压力。对理想均匀总压、稳态无旋流，按实际壁速和给定远场基准从伯努利式求静压；另读 `-writep` 的原生压力，它来自流向过滤的压力泊松方程。两者各自采用相同门槛，不择优换列。按球环面积比较完整 128 个面带，另将数值场投到 v361 的 129 个共同极角核对，包括两个驻点。内部节点取相邻面带插值，端点由最邻两带外推，压力按至极点角距离的平方、切向速度按角距离外推。每列 Cp 误差 RMS < 0.04、最大绝对误差 < 0.10，切向速度 RMS 误差 / 来流速度 < 0.03。输出包括可区分的压力来源、局部分布、速度、通量账、适用范围和停止决定。本项没有能量方程、黏性或壁面热流输出。
