# 返回 M0.30 原模型的适用区域

采用速度势重建壁速和伯努利压力作为固定低亚声速、无旋附着外流的研究候选。关闭本轮球体对照，保留原生附加泊松压力未通过的结论。M0.30 的理论比较已经量化了同一个球体上的可压缩性差额。[误差和原生通量](RESULTS.md)

下一项返回同一简化模型、5 km、M0.30、零攻角、给定壁温 300 K 的 9,216 个原面。评估这套近似在哪些位置有同工况附着证据，保留完整原面编号和面积。内部研究外流和具备物理资格的壁压分列。特别检查肩后、尾段、平底的压力来源、流动状态及外域误差，不能把滑移解提供的切向速度本身当作实际附着证据。已有平板热流数据只支持其已转捩、近零压梯度的试件。逐面热流及全表面功率需要本工况的适用换热方法，现阶段保持未知。
