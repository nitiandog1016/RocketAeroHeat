# 带线热敏珠同网格温差输运对照

基线为 v300 提交 `1567cea7b73f8bd688e9a6f26051bef1b59dd7d5`，本地与远端 main/v300 一致，v301 空闲。未见热敏珠原生计算进程，E 盘可用约 326 GiB。只处理 [v300 下一决定](../v300/NEXT_DECISION.md)，保留并发前端、测试和研究修改。

复用 v300 的 23,224 单元、16,581 节点、10,272 原面、节点映射和**同一冷初场**。准确来源为 [网格输入](../v300/evidence/inputs.json)、[原生终场](../v300/evidence/summary.json)。固定 3 m/s、293.15 K、101325 Pa、全壁 305.15 K、相同物性及无滑移和远场。仅将温差标量的一阶迎风改为 MUSCL 重构与 Barth–Jespersen 限制器。明确关闭阶数渐变和标量裁剪；限制器截止迭代 999999，覆盖 7000 次上限、20 次延续和每次单步读数。保持流场原离散。启动前对比官方压缩包、程序、固定源码及配置，登记新配置、冷态、原面和执行程序指纹。几何、初场、末帧分别校验来源。

新建独立运行目录，单线程、720 s、2 GiB、180 MiB、最多 7000 次。初场、间隔 500 次的周期体场和表面、正常终点都保留。沿用六项残差末 20 行均低于 −8、正绝对压、无滑移、全域强标量 [0,1]（允差 1e−12）。检查每个完整保存帧，记录时间、标量极值、越界数、所在节点；发生明确的保存帧温界失败时保留该帧，停止采用该配置。比较同一迭代或已收敛终点的速度和压力，区分离散变化与终止迭代差异。通过温界及残差后，执行原生反力、20 次延续、独立同阶段装配、七区功率与原面积分。热变化 <0.2%，远场收支差 <0.5%，节点反力和原面积分沿用既有门槛。编译/链接 120/60 s、3 GiB，反力/延续/独立单步各 60 s、2 GiB、180 MiB。准备、后处理及工作台验证每批 180 s、4 GiB、200 MiB。

本轮只运行一个物理方案。成功时比较完整珠面和引线、接头及端面的压力、热流、首层温度、反向范围、热峰、整珠平均 h，接入带线工作台并核对截面与导出。物理门槛失败则记录失败的量、位置和可比较的流场，保留 v300 为有效原面结果，关闭这一配置。实验精度只对照论文的整珠平均量；该试件无逐面联合实验数据。
