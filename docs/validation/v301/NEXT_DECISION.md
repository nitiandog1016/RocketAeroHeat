# 在带线热敏珠上由整件净对流功率求单工况等温壁温

关闭 v301 的 MUSCL/Barth–Jespersen 配置。约 4.79 × 10⁻⁸ K 的下越界在全部五个保存帧上持续，现有证据不足以断定原因。保留 v300 一阶强标量为已接受的计算来源，实验平均换热偏差 +26.73% 及无逐面验证的限制继续随结果显示。[本次对照](RESULTS.md)

带线工作台当前只能输入 305.15 K 给定壁温。下一项补齐一个真实缺项：选取同一 3 m/s、293.15 K、101325 Pa、v300 中段加密网，以**整件暴露面的净对流功率**为输入，求一个稳态集总壁温、七区各自的热流和完整压力。采用与 v300 相同的全体等温假设；无材料和接触数据时，不声称求得内部固体导热或引线轴向温度梯度。珠部实验对照仍用珠部含接头功率。整件输入功率还包含两条引线和端面对空气的放热。[光滑珠体已有的功率边界](../v286/RESULTS.md) · [带线全表面基线](../v300/RESULTS.md)

复用工作台已有恒物性被动温差场和集总热平衡逻辑。先核对带线分母与 10.87809 mW 参照功率。用一次带线半温差冷态独立求解及同阶段反力/守恒核验线性换算和反求壁温；覆盖正功率、零功率与允许区间之外的输入。零功率应给出全表面零对流热流，正功率以七区总和核对；给定壁温和求解壁温在探针、截面、导出中分别标记。沿用原残差、正性、全域温界、热稳定与守恒条件。已有同工况结果只在几何、体网、物性、输入身份完全对应时复用。以一个完整正功率工况的壁压、热流、求解壁温和实际工作台验收为结束条件。
