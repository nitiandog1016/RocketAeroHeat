# 新物性路线的公开热验证准备计划

本计划在下一整箭长任务前执行准备门槛。当前尚未启动新公开计算。原 v149–v152 的 16,261 点/16,000 单元、定比热 SST-Vm 系列已关闭，原失败继续保留。

## 数据与工况

继续采用 NASA ACC-SBLI 的两块 81×101 原网格、21 个上游剖面位置、24 个压力测点、27 个热流测点及 WIND 参考曲线。公开 20° 为压缩拐角转角，真实箭体 20° 为攻角，两者的验证范围分别登记。

WIND 示例提供 M7.11、总温1600°R、总压364.8psi、Tw559.8°R、湍强0.021%、湍黏比0.001、SST-1994m/涡量生产项。原定比热换算得到静温80.00497631 K、静压550.19563990 Pa、速度1274.90242263 m/s，单位Re相对公开示意差−2.31205%。新物性使用总焓/熵求相容静态后，应将新旧静态与单位Re的差单列，禁止同时强制互相不相容的总量、静量和Re。

## 启动新系列前的四项准备

1. 用已有独立物性程序与 MATLAB 入口求来流和壁面状态，明确新能熵参考、实际 Mach/速度、变 cp 总温和 SST-Vm 身份。当前 v154 新模型合同只测试 SST-2003m，SST-Vm 需独立显式合同和一次小型配置检查。
2. 对现有公开域的入口位置、上游壁长和全部21位置逐项建立坐标对应。先核对上游 U/Uref、总温和热流，再评估相互作用区。根据公开入口条件确定采用原截断入口或独立发展段，并量化缺失的上游信息。尚不能闭合时保持“入口待验”，先完成有已知入口的附着发展段验证。
3. 依据目标 y+≤1 及已存场的摩擦尺度确定首层和法向增长规则，保留物理壁形和原测站。先做唯一几何候选审核，再登记其预算。v152 的 y+99=1.924 和上游q差83.861%作为旧场诊断，候选仍须重新取得收敛和网格证据。
4. 在创建进程前完成失败态保存策略。明确原生异常发生前最后一个完整保存场、历史时刻与实际失败时刻，补实际异常状态或有限环形检查点，验证意外终止后的文件完整性。保存预算须覆盖最差情况，任何推断状态单列。重启动和稀疏同阶段输出合同完成后才运行新系列。

## 新系列验收

沿用原26项验收口径和原失败表。新方法的状态方程、变cp总焓、SST k与旋转能量积分需要按实际模型复算。门槛包括相容状态、四项原logRMS<−8、质量/能量缺口<1%、y+99≤1，以及跨度至少1000更新的压力变化<1%、热流和整周功率变化<2%。

原测点压力RMS≤10%、最大≤20%，热流RMS≤20%、最大≤30%、峰幅差≤20%、峰位差≤0.01m。上游速度比RMS≤0.05、总温比RMS≤0.03、参考站压力差≤5%、热流差≤20%。所有新运行次数、时间与文件上限在完成上述准备后锁定，单次到期或失稳即停止并形成采纳/停止决策。

单网格验收通过后，再安排明确的近壁/流向网格与外域对照。该基准只能取得其对应的轴对称相互作用资格。真实20°横流、底面与突起继续使用各自的三维区域证据，累计热量保持后置。
