# 采用决定：完整面时间尺度＋原生复数Newton–Krylov

准确源核验已产生明确替代：采用固定Eilmer5的**复数导数Newton–Krylov（NK）**，开启原生`inviscid_cfl_only`完整面谱半径、物理性检查与Armijo残差回溯。保留v196三行几何修正。没有新增通用回滚/保正内核，不把旧显式步数、CFL或通量扫描包装成修正。

固定来源为 `gdtk-uq/gdtk@f53f4609a0331d48efee69a4e4f3c3598378cc03`：

- `src/lmr/newtonkrylovsolver.d:1707—1724` 原生按**全部面**求 `Σ(|u_f·n_f|+a_f)A_f/V`；不同于显式`signal_frequency`只取三个选定面及长度。该模式不调用旧方向信号；全局/局部伪时间的定义重新记录。
- 同文件3742—3829按同一守恒更新方向约束相对质量变化并试解原始量，恢复原流态；引用Yildirim等2019 JCP。它不是任意EOS下全局保正证明，且不保证工程接口200K下界，完整场温域守卫继续独立执行。
- 同文件3835起为原生Armijo充分下降回溯；与仅增加显式`max_attempts`不同。显式重试减global dt，但原局部dt在重试循环中未重算，不能仅增加次数声称有效回退。
- `lsqinterp.d`内部面有原生局部重构/热查询失败回到单元态；普通限幅并非热力学全域保证。边界是否限幅取决于实际配置，不能由`apply_limiter`名字断言保护覆盖。
- 官方`examples/lmr/3D/cylinder-larc/job.lua`使用复数扰动1e−50、rhop重构/hvenkat及驻点过滤、物理性检查和线搜索；高Mach17.6、5组分2T热壁，**其cylinder.su2为3840个六面体，零四面体**。只能作成熟算法/配置来源，不能称本项目四面体/单温变cp/无黏控制已通过。
- 官方makefile的`lmrZ%`增加`complex_numbers`；直接监督新复数二进制，避免旧launcher退出码误报。旧v181/v182实数/状态混阶导数失败、v180完整域OOM仍保持，不能因换成小Euler域追称修复。
