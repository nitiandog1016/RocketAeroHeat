## 实现和方法

- `phaseAwareAirCaloric.m`：绑定同一3882节点Cp表SHA，60—2000K分段线性Cp的解析焓/标准熵积分。是用于寻根的数学量热接口，不能替代最终p/T联合域审核。
- `solvePhaseAwareWave.m`：显式同气体/线性mu-k/hs298.15=0。法向守恒使用压缩变量z=(Un1−Un2)/Un1，去掉z=0平凡根；根据T(z)与60/2000K交点分合法区间，不给超温中间试探伪造正负号。斜激波取弱支、保持切向速度；不把无热力解极线点当零角。当前若完整法向极线超温，保守返回“极线不完整”，不误称已证明脱体。膨胀按同总焓积分sqrt(M²−1)Cp/U²，再用同熵恢复压力。最终均调用`phaseAwareAirState`。
- `marchPhaseAwareWavePath.m`：同平面三维向量表达的二维折线，正转角压缩、负转角膨胀。每段继承上段p/T/U，保存方向和源状态。拒绝非共面输入、脱体和域外及其下游。它不是三维流管/横流求解，也没有边界层起点或入口剖面。
- `inspectPhaseAwareRocketInlet.m`：原节点、截面环及几何尖端读取。只作入口诊断，不用旧NASA7外缘/未收敛CFD壁值。

守恒/波系方程沿用项目既有`solveThermallyPerfectNormalShock`、`solveThermallyPerfectObliqueShock`、`solveThermallyPerfectPrandtlMeyerExpansion`中的Rankine–Hugoniot与简单波结构。本轮不是新文献模型或实验验证；改进是物性/能量身份一致、合法根分区、弱波及顺序继承。旧默认源文件未改。
