# 下一项：检查光滑珠体中段近壁层外侧的离散

同一光滑几何由原结构网改用配对混合网后，整珠放热增加 2.79986 mW。其中 2.09610 mW 来自 −0.5 < X/a < 0.5 的中段，占增量 74.86%。这两套网在半长轴、物性、等温条件及强标量输运上有直接对照。在距壁 0.015D 至 0.1D 之间，60°、85°、120° 三条法向的最大穿越间距在混合网上分别为 0.0236D、0.0289D、0.0225D，原结构网约为 0.0147D。带线旧试验只对首层减半，未检验这一段过渡区。[实际网格读数](evidence/spatial.json)

下一次在 v298 的光滑控制上做一次空间加密。保持原面、角向、等温和首层厚度、外半径、原生配置与反力映射。在珠体中段优先加密距壁 0.015D 至 0.1D 的过渡区，向两端平顺衔接，并从实际生成物复核这些法向间距。先记录附近和远处改变的单元范围，再从独立初场求解。按相同原面重算四个轴向带的功率、总平均 h、两项均反向的面积与热峰，同时执行六项残差、温界、延续热稳定和独立收支核对。

一次对照后按实际改变的网距与功率决定是否把同一改进用于带线试件。几何保持时若中段过量放热明显回落，继续做空间误差核对；若变化很小，则检查通量离散方向性或更宽的外区与尾迹。不能把与实验偶然接近当作网格收敛，也不能把 v298 的整套方法差额一次性分配给首层、外区或引线传热。
