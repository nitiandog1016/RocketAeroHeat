# 3 m/s 热敏珠的配对光滑控制

以 v297 提交 `c1eb8eebcf41d43b88052b14fa6b9e95f188fdae` 为起点。固定坪内、佐藤 B 珠的半轴与 v297 的共同椭球面全部 64 个母线间隔、48 个周向间隔。去掉两侧接头和引线，用同一解析椭球补足两个极冠，以中央母线角步长限定极冠的角步长。使用 v297 的冷态、强等温标量与不可压层流配置，3 m/s、293.15 K、101325 Pa、给定壁温 305.15 K、0.001D 首层、20D 外域、30° 扇区，4 个周向单元。

优先保留带线网格中可逐节点配对的外区。取距两极各 0.45D 内有顶点的子午外区三角形，分别打开局部网格，保留切口边与外侧单元，只在两端接入光滑极冠并重建内部子午三角形。以实际三维坐标和单元连接独立核对保留部分，注明改变的近极网格。若切口拓扑或正体积检查失败，保留几何阶段记录并更正，禁止将几何失败送入求解。公共三角面须直接核对三个顶点、面积与法向绕序。仅共同珠面作带线减光滑的逐面对照，两个极冠、接头、引线分别积分。v283 旧光滑原面编号与面积保留，三项功率都在自己的完整分母积分。两种光滑方法的差异包含全部离散变化，不能由一次对照细分为某个网格参数的影响。

固定 SU2 8.6.0、Gmsh 4.15.2 和已验收的 v297 反力读数。准备每批 180 s、单线程、4 GiB、200 MiB；正式推进 720 s、单线程、2 GiB、180 MiB，最多 7,000 次，每 500 次及正常终点保存。先登记体网、初场、小输入和运行程序指纹。接受标准为六项末 20 行各低于 −8，正压力、无滑移、强标量全域 [0,1]（浮点允差 1e−12），20 次延续放热变化小于 0.2%，原面放热与真实反力合计一致，同阶段独立远场收支差小于 0.5%。观测编译、链接各 120 s、60 s、3 GiB，单步读数和加 20 次各 60 s、2 GiB、180 MiB。界面、映射和归档每批 180 s、4 GiB、200 MiB。超限、非正常终态或门槛未过均保留现场。
