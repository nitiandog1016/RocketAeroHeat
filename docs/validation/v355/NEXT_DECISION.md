# 让“计算”直接生成同一时刻的细热网主结果

下一项仍针对这个 0.05 m/s 风洞工况。现有两条侧栏路径都能显示整件结果，当前点击“计算”新求的是粗热网，细热网来自经指纹核对的存档。将已通过近壁核对的细热网两半步接到日常计算入口，用户能从模型、流动与壁面边界直接生成同一物理时刻的 9,216 面壁压、热流及首层流体温度。对照网格数据标注来源，主结果、色标、探针、区域积分、整件功率和联合导出全部绑定本次真实终帧。

沿用本轮已有的两支整／半步对照。复算前登记初场、速度时间层、输入指纹和本机资源预算，分别核对有缓存和缺少细热网归档的正常入口。所有原面均有有限值、能量账闭合、主面表与科研出口逐行一致才结束本项。对已知底面弱信号保留时间步敏感性说明。固定工况的动量网与外域误差、匹配实验及其他工况的适用性继续单独记录。[当前已测范围](RESULTS.md)
