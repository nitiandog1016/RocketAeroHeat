# v133事前计划：原壁面尾缘棱柱扇与外域质量

2026-11-01，承接已交付v132。上一轮属于有效进展：确认保存场非正交负扩散，并通过实际WLS/GG对照否决直接切换梯度。

问题：原mesh32在侧壁/底面约90°凸棱边以单一角度加权法向挤出。拟在唯一尾端46条闭环棱边建立两侧法向列和中间棱柱扇，在原32层厚度内光滑接回原外壳。所有原9878壁点、19752三角面及坐标保持；底面并非数学平面，其中心约28.8微米偏移也保留，不将其拍平。第一层和末层使用三角横截面棱柱，中间四边形横截面分成两棱柱；不引入退化单元，不增加壁面，不改变外域。

阶段一：解析90°闭环凸角模型检查原壁面、正Jacobian、内部面配对、完整体积；一个真实完整mesh32几何候选，最多180秒，内存不超过项目既有400k节点/900k单元规模，新增输出预计<80MiB。不运行SU2、不重跑v132离散/旧流场。失败保留准确源，只修可辨别实现错误，不按不利结果扫描扇角/层数。

固定构造：侧/底面分别累积原三角面顶角权重法向；非棱边节点不动。法向分裂幅值由(1-h/H)^2平滑归零，原最后一层和四面体外域逐字几何一致。保持原壁点编号，在旧体节点之后追加底侧分裂节点。原面扇底部采用原侧/底界面端点的闭环，不假定圆柱或拍平截面。

基础几何门槛：所有棱柱全参考单元Jacobian严格为正；每个内部三/四边面正好两侧相反，边界恰等于原墙面和远场；完整域体积相对误差≤2e−10；所有原壁面坐标/面编号/面积保持。比较原7点相应两侧及邻域的对偶闭合、WLS条件、GG仿射矩误差、壁面法向夹角，不据单一质量数自动授予气动热资格。

阶段二仅在阶段一通过后：使用固定本地Gmsh4.15.2一个明确的内部四面体优化操作，目标改善既有17个SICN<0.1外域单元；固定原墙面、近壁层、外壳接口和远场。最多120秒，不作参数扫描；检查边界/正体积和低质计数，失败保留。此阶段允许改变内部四面体拓扑，但不得移动界面。
