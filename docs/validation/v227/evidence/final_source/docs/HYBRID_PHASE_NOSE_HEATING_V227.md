这是**具名旋转拟合球鼻局部相似工程近似**，不是全箭轴对称、真实三维边界层或实验验证。偏置驻点为解析球面位置，非原面中心种子；有效面完整短弧位于拟合球帽内，局部横向度量取Rsinθ。横向邻域采用球面延续近似，不声称整周向环都位于原帽内；真实非相似、熵层吞入和三维反馈尚未闭合。原零攻角模块守卫不变，鼻部以外全部原面仍计入未解面积。

## 算法及模块

- `solvePhaseAwareLaminarProfile.m`：NASA TP-3271式6–7、17、25、54、56–61的局部相似五状态BVP；舍去沿程非相似项。来源[原报告](https://ntrs.nasa.gov/api/citations/19930006245/downloads/19930006245.pdf)，复用项目既有来源证据，不沿用报告实验精度。
- `solvePhaseAwareNoseHeating.m`：复用v226同相态正激波/修正牛顿/驻点熵外缘；有限驻点a与压力二阶曲率、xi沿弧积分、2°角表、原面相邻插值和来源绑定。
- `runPhaseAwareNoseHeatingCase.m`：主工况新模式；新工况内部生产外缘，显式缓存复用须通过原面/工况/源指纹。旧NASA7结果从返回副本清除。
- `buildPhaseAwareNoseHeatingViewerData.m`：主工作台15字段，含q、壁剪应力、Cf、真实密度加权厚度。给定Tw、未知固体Tw、sqrt(Pr)恢复温度估计分别标明。

同一相态Cp积分、线性mu/k与hs(298.15K)=0；Pr(T)=Cp(T)mu(T)/k(T)。数值总焓作常量正移位，但输出物理零点不变。温度采用logit映射60—2000K，饱和拒绝，不裁温或外推物性。终解全部p/T另查气相/低密度联合域。

令F=u/Ue，m=lF′，g=(h+Ue²F²/2−offset)/H，n=(l/Pr)g′+(1−1/Pr)(Ue²/H)Fm。五状态保留变Pr总焓通量与黏性耗散。驻点U=metric=xi=0，beta=.5，K=sqrt(nu_e/(2a))；非驻点同一压力/速度梯度符合动量。固定32点Gauss–Legendre从驻点积分xi，无任意epsilon起算。

厚度从独立有限η边缘积分：δ=K∫(T/Te)dη，质量厚度=K∫Fdη，δ*=δ−质量厚度，θ=K∫F(1−F)dη。保留实际u/T/rho/h/mu/k/y剖面；不是Thwaites参考厚度换算。Cf以局部外缘动压定义，Ue=0时不伪造有限Cf。恢复温度仍是sqrt(Pr)估计，未解BVP绝热壁温。

固定数值/适用门槛见[事前计划](validation/v227/PLAN.md)。角表线性映射不是角向离散误差验证；有限边缘和输入物理联合域检查不是CFD入口资格。
