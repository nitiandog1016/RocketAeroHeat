# 银球背风换热的空间分辨率核对

下一项只处理 Short Test 65 的背风区。v322 在同一网格上将步长减半后，82.10 ms 两份结果的最大逐面热流差为 0.00002798 W/m²，119.8° 和 166.7° 仍分别高估 139.3%、低估 21.5%。扰动后速度接近原基流，现有时间段未产生可重复的统计周期。[六个同刻和实测对照](RESULTS.md)

先直接读取已保存的全域节点、单元和速度。量化球后回流长度、剪切层横向与流向网距、跨层有效节点数，以及这些区域与两站热流的关系。检查原生空间通量和限幅配置。先用两个已保存的末帧验证识别结果的步长敏感性，保持相同物性、温界、面号和测站。

这项只读诊断限一个批次，120 s、2 GiB、100 MiB。若能定位具体欠分辨区域，再单列一套有针对性的低速球尾迹网格对照，执行前登记单元、可比初场、预算和停止条件。若证据不支持局部加密，交付实际分辨率和仍待验证的因素，重新评估实验支管几何与当前模型的可比性。直接延长 v322 的同网同扰动运行不在本项计划内。
