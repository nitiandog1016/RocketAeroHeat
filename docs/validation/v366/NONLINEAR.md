# 对同一后向欧拉方程使用原生 Newton–Krylov

固定 CFL=3 后，50 µs 整步在内迭代 499、999、1499、1999、2499 的末窗能量分别约 −7.15、−7.12、−7.11、−7.12、−7.11。25 µs 半步的末窗能量为 −7.31。原生线性相对残差的 log 约 −4，达到配置的线性容差。缺少可以支持延长同一迭代的衰减率。关闭已测的两个常规隐式组合。

固定版 SU2 的 CNewtonIntegration.cpp 提供对实际空间残差的矩阵自由差分乘积和双时间项；沿用同一 50/25 µs 物理步、全域、给定壁温、原始物性、原空间重建及原初场，试一次该内置非线性解法。直接进入 Newton 步，固定 CFL=100（原适应范围上界），ILU 与至多 3 次近似线性迭代预条件，完整二阶残差差分。外层 FGMRES 相对容差 0.05、最多 20 次，差分系数 1e−6。每步原生最多 250 次内迭代、150 s、2 线程、4 GiB、64 MiB；线性目标仅用于更新，原物理末窗 −8 门槛保持。附带保存逐节点 RHS，用实际输出来定位未过项。两种步长的第一步均检查；未过的第一半步不向下游传场。此组合后结束本轮数值试验。
