# M0.30 同一原生初场的时间步对照

基线 v365 `d3b4acf0d9e34565ab5204dc3be4df251f00972c`。用简化民用试件完整的 9,216 个原面、0.935516891 m²；M0.30、5 km、零攻角及侧滑、给定壁温 300 K。冻结 v365 warm2 的 2 µm、88 层、14D 远界细网（SHA-256 `f5656636b80e5a47a7d0cdb04b52f7a97e24fefb274f298ae1c31f3a42e4da68`）和其原生 9999 号末帧（`998600a5f54616298783e53f78370ecd51b203f64e639835f598d4d8a7871346`）。原稳态残差未通过。把这份场定义为本次时间对照的数值起点 t=0，热壁、全层流、热物性、沿流向坐标、全平底和尾迹沿用原输入。

内嵌 SU2 8.6.0，用一阶后向欧拉双时间法从同一起点走 50 µs 和两次 25 µs。整步来流位移约 4.81 mm，约为一个圆柱原面轴向带宽的 31%。每个物理步最多 2,500 次内迭代、2 线程、150 s、4 GiB、64 MiB 新输出；全部输入、内迭代历史及每步末原生体场和壁面场留存。原生失败或步内四个物理方程原生 log RMS 末 20 行有任一 ≥−8，标记该步未通过，其末场不传给后续步。两种步长的第一步独立检查。若证据能定位到配置或求解条件，可在单独登记的新目录有限恢复。超预算后保留原现场。

核对真实进程终态、保存帧、无滑移、正性、给定壁温与壁节点流体温度、初场指纹和相对于共同起点的时间。全表面、圆柱及其两端面带（2017–2112、6817–6912）各自按实际面积比较热流、壁压和顺流剪应力，记录最大局部差异。以细步为参照，时间差准入参考为各区热流 RMS <2%、热功率相对差 <1%、壁压 RMS 差 <1% 来流动压；壁剪给出 Pa 和反向面集合。逐步核算流体能量变化率、终点远界向外能流、壁面入壁热功率，在同一几何分母上报告总能量账与质量账，并区分保存场重构和原生数值边界通量。未闭合的量和来源需列出。短时、全层流和人工起点资格随原面保留。

把实得的同刻数值和步长误差接入第 4 步的 M0.30 研究档案。由第 5 步发布全面积物理结果仍需适用、收敛、守恒与空间验证。工作台回归限单核 180 s、4 GiB、20 MiB。试算与开发时间另计。
