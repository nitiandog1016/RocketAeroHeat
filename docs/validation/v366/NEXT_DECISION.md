# 从尾部两列体节点定位物理残差，再回到原时间对照

在 M0.30 全域、2 µm 细网的 Newton–Krylov 末轮，平底边缘和相邻尾段两列占能量残差平方和 88.81% / 93.04%；峰值位于零基节点 3828 / 2738，均离开壁面。固定 CFL=3 改善了全域 RMS，但末窗仍未通过。记录尚不能确定具体误差来自几何、重建、黏性项或轴对称项。[本轮证据](RESULTS.md)

下一项只针对这两列及相邻对照列，选同一未改动的细网、同一 50 µs 起始状态和一个确切内迭代组装阶段，取得原生对流、黏性、轴对称源和物理时间项的带符号局部能量贡献。逐项和须能重现该阶段的原生右端；定位最大未平衡项后，再决定一处局部修正并用原时间步对照验收。保存场的远界收支单列，不用更新后的壁热抵原组装余量。保留原几何、平底、2 µm 首层、整个远界和 9,216 原面，不延长已经关闭的三种内迭代组合。
