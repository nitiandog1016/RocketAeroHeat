# 在珠面前中段检验沿壁法向排列的过渡网

第三档相对第二档的珠部放热减少 318.303 µW，其中 X 从 0 到 +0.369 mm 的前中段贡献 187.118 µW。共同近壁层的外侧扩散项在该带减少 159.599 µW。两档在这个切口的真实对偶面积一致。现有证据定位了最敏感的区域和传热项；珠部实验平均差仍为 +22.80%。[分带结果](RESULTS.md)

下一项选用同一带线热敏珠、同一 3 m/s 来流及第三档 20D 工况。在前中段的 0.015D 至 0.1D 过渡区构造一张沿珠面法向排列的局部网，目的是检验外侧温差分辨与传热预测对单元排列的敏感性。保留原面、全部共同内层、周向网距、远场及未涉及区的有序单元。只在衔接处使用必要的过渡带。先量取成品旧网和候选网各边与壁法向的夹角、法向间距、受影响的范围及单元总数。若方向一致性没有提高，或间距与数量变化太大以致无法作可解释的比较，就在几何阶段停止，并保留读数。

几何通过后按实测规模登记单线程预算，仅允许一次独立冷态，保持同一原生算法和残差、温界、连续热稳定、能量与独立反力门槛。按相同前中段 1,536 个原面、十个带和完整 10,272 面核对放热、热点、等功率壁温与珠部实验对照；分开报告前中段与邻带变化。通过时接回第三档对照页面。该试验检验具体网格选择，结论限于实测条件。
