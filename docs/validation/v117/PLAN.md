# v117运行前计划

v116已交付并产生新的机制证据，属于有效进展。本轮复用其24层对照输入，不重跑层数候选或旧3750研究。

1. 已核对v8.6.0标签对应7048fd35，现有源码与固定归档一致。四个鼻尖前低温节点在v114第2999步至v116对照600步后，五个守恒变量逐位不变。原生隐式更新按内能变化比例限制松弛，并把小于1e-10的系数直接置0；正内能恢复方向也可能被取消。尚须实际线性更新证明方向，不能仅凭低温断言原因已经完全闭合。
