# 定位两档热敏珠网的珠部放热差

给定 305.15 K 时，第三档相对第二档的整件放热下降 0.31517 mW。其中珠体含接头少放热 0.31830 mW，两根引线含端面合计略有增加。4 mW 反算壁温对这一档细化仍改变 0.13166 K，珠部平均换热仍比实验图读高 22.80%。这两次变化可用于定位离散敏感区，不能据此给出极限网距的实验误差。[三档同面结果](evidence/comparison.json)

下一项只用已保存的第二、第三档终场，在两网共用的近壁棱柱层内核对珠部热量穿过各段的位置及方式。先根据实际有序单元、节点和边建立相同的控制体集合，按珠面母线分带，明确两端与接头交换的通量。径向切口放在两档都逐点相同的内层，例如选择距壁不超过 0.011D 的节点，检查其外侧对偶面只依赖两网共有的单元。核对成功后从固定版本原生标量装配分别读取同阶段对流、扩散、壁反力和该组节点的残差，按真实扇区倍数及 SI 单位形成各带热量账。

先在两网各自复现既有同阶段壁反力及整件能量账，再核对各带闭合、相邻带界相消和七区功率。保留每一项符号、源帧及误差。输出应指明哪些带贡献了此次珠部功率变化、哪项通量随网改变，并将该范围标回原面。同一切口的两种通量变化不足以单独证明实验偏差的起因。若找不到相同控制体或同阶段量不能闭合，就记录具体切口和差额，停止物理归因。本项按读取终场和独立单步核对登记预算，无需第三次细化或重新冷算。
