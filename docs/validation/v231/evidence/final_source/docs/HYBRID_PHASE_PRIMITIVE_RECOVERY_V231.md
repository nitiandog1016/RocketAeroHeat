## 2. 修复如何工作

原CEulerVariable::SetPrimVar先调用气体`SetTDState_rhoe`，再检查原始量；遇到不合法状态时，原代码已有“恢复该节点Solution_Old、重算原始量、返回RightVol=false”的路径。新相态模型严格抛出域异常，使程序在到达原生判断前退出。实际多重网格积分先预处理、保存旧状态，再推进；更新后的预处理也调用同一变量入口。这里只使用MG0，不改变多重网格方案。

新具名适配`phase-euler-native-primitive-rejection-v1`只把CSU2PhaseAwareAir明确的输入/温度/压力相态域拒绝交给上述既有回退。合法状态的公式和数值保持；不会把T裁到60 K，不扩大物性表，不改CFL、通量、Jacobian或推进公式，也不把整个流场重置到自由流。反算不收敛、其他数值错误、其他气体的异常不被此适配吞掉。旧状态如果仍非法，原生第二次EOS调用继续抛出异常并停止。

适配没有改变气体定义或旧包：新CEulerVariable对象只在独立链接中替代原对象。原实现、失败输入和[完整源差分](validation/v231/evidence/recovery_prepare04/primitive_recovery.patch)保留。局部退回旧状态可能影响更新收支，**不是原生守恒、稳态或收敛性的证明**。
