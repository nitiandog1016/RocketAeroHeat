# 在带线试件上核对第三档中段网距

20D 到 30D 使整件空气侧热导只改变 −0.00427%，4 mW 壁温只改变 +0.00018847 K；给定壁温的珠部平均换热与实验仍差约 26.7%。相比之下，带线珠体上一次中段过渡网加密使珠部放热下降了 14.01%。结束本次外域对照，保留 20D 为工作台主域，30D 为可核查的外域敏感性结果。[外域差异](evidence/comparison.json) · [前两档带线网距](../v300/RESULTS.md)

下一项只在 v300 的 20D 带线加密网上，在已经定位的珠面中段、距壁 0.015D–0.1D 的过渡区增加一档局部细化。保留原面、首层、近壁层接口、周向分辨率、引线和接头几何、远域与同一一阶强标量方法。先从实际网格量取 60°、85°、120° 三处法向间距，并核对新旧单元的真实改动范围。若目标间距并未缩小，停止在几何阶段。记录新输入和预算后仅作一次新的 305.15 K 冷态，沿用原残差、温界、热稳定、独立反力和守恒门槛。

在 10,272 个相同三角面上比较三档网距的总热导、七区功率、局部热峰与同功率下的壁温和热流。分别给出此前与本次的变化量及其方向，核对工作台的原面和导出。三个局部非均匀网格不能仅凭档数给出收敛阶；以实测网距和热量变化决定剩余空间误差是否仍影响单工况验收。该项尚未启动。
