# v219 完整方案决定：采用隔离适配，尚不准入求解

本轮选择 `rah-su2-phase-air-saneg-eplus300k-v1` 作为下一实现组合：固定SU2提交 `7048fd35f56d4bf52e586429d6746a36a10255f8` 的实数稳态单域NS/RANS、原生general Roe、隐式Euler、原生SA-neg（NEGATIVE, WITHFT2）、v206相态标准干空气及v207线性分子输运。采用的是实施方案，不是已验证运行包或高超湍流精度；旧SST/OTH包及其失败不改、不续算。

重构/线性组合沿用旧实际配置的成熟部分：流动MUSCL＋VENKATAKRISHNAN_WANG(.05)，梯度采用实际配置/默认的准确源值并在新配置显式冻结；SA SCALAR_UPWIND、MUSCL_TURB=NO，因此边界按内/外速度均值作迎风。BCGSTAB＋LU_SGS、线性误差1e−5/最多10次、MGLEVEL=0；初CFL=.1及原生自适应(.5,1.1,.05,5)仅作为待验证固定组合，不扫描/声称改善。推进总步数、保存及剩余默认必须在下一运行计划中明确，旧200步不是自动续算预算。

## 1. 来源与气体接口

29个定向文件按v167真实构建source_tree逐字绑定；当前共享源不是默认真源。准确清单见source01/source02报告。旧CSU2IdealAir的60—2000K OTH参考、Sutherland/常Pr与当前合同不同；旧CConfig也拒绝SA。不能只更改配置标签。

新类/枚举独立注册，复用现有相态Cp积分和线性mu/k，不改旧类或工程默认。完整覆盖PT、Prho、rhoT、rhoe、hs、Ps、SetEnergy_Prho和ComputeDerivativeNRBC_Prho；有界成熟反算、最终联合p/T接受及状态原子提交。原60—2000K及p上限/低温露点裕度不扩展；未知或超域明确拒绝。线性输运节点导数的左右约定须沿用现模型，不能改成常Pr。

## 2. 能量坐标与接受条件

外部物理合同保持hs(298.15K)=0；内部固定C=300000J/kg：e*=e+C，h*=h+C，rhoE*=rhoE+C rho。C是明确数值坐标，不是增加物理能量；Cv>0使e在全表温区单调，须核验60K端点e*严格为正，不能靠裁负温或裁状态。

旧CEulerSolver::ComputeUnderRelaxation以max(rho e,EPS)作分母；直接传入合法负相对内能会导致松弛退化。采用固定坐标避免这一接口冲突，不修改松弛内核。伪时间迭代路径依赖能量参考，不宣称平移后逐步等价或保证收敛。

所有初场/边界/重启/输出同时标记坐标；禁止把旧OTH或未标记数据作新重启。通量F_E*=F_E+C F_mass、逐单元有符号残差R_E=R_E*−C R_mass，必须在求范数和无量纲化之前转换，不能用两个RMS相减。黏性质量通量为0，纯导热及黏性功不因C改变。SA的nu_tilde是独立非守恒标量，不拼成第六个守恒能量分量，不扣SST的k。

气体dp/drho|e*、dp/de*|rho及dT/de*|rho保持；general Roe的Chi*=Chi−Kappa C、H*=H+C，声速组合不变。热壁dT/drho|rhoE*需使用当前E*，不能把物理E混入旧链式导数。原生近似隐式Jacobian仍是近似，不要求或冒称完整精确Jv。实现范围是物性/能量身份接口、注册、热壁分派与诊断；不另写Roe/SA/推进。

## 3. 具名SA与热壁

采用原生SA-neg＋WITHFT2，关闭Edwards、转捩/曲率/旋转、DES、随机回散及壁函数；全湍流仅为候选假设，不能证明整箭实际转捩。入流nu_tilde=3nu；Pr_t=0.9为明确工程假设，后续热参考按同假设核验。[NASA迁移说明](https://www.nasa.gov/nasa-turbulence-modeling-resource/)指向[TMR具名SA公式](https://tmbwg.github.io/turbmodels/spalart.html)，该页引用[Allmaras/Johnson/Spalart 2012](https://www.iccfd.org/iccfd7/assets/pdf/papers/ICCFD7-1902_paper.pdf)。本轮读到TMR公式和原文引用，未另下载/核验整篇论文。

原生SA-neg在负nu_tilde时令mu_t=0，采用模型fn扩散与原生近似隐式；不是裁热力状态。正支/负支、壁面零值、实际壁距均需一次原生控制。当前准确SA-Edwards的Omega及r导数写法与旧Eilmer不同，未证明错误；不按同名继承资格，也不在本轮修内核。

原CNSSolver无滑移/固定Tw=300K、k_eff=k+Cp mu_t/Pr_t与变cp链式导数可复用；新枚举接真实导数分支。CNSVariable原domain_error恢复只识别旧类，新类必须接相同拒绝/旧态恢复身份，记录每次拒绝和未接受步，不能静默吞错误。给定Tw、壁节点流体T、固体Tw和外缘Te继续分开，正热流进入壁面。

## 4. 完整连通域与物理边界

局部短后体目前无可信压力/回流反馈，故此次采用有旧实测资源依据的完整连通域作备用候选，避免人工内部截口。复用原705490单元/335726点/19752物理壁面及原面积；完整母网格、32层2微米资产、历史19层/尾缘均保持，不重新生成网格。原生顶点中心有限体积的实际壁距/近壁尺度仍需原生核对，几何层数不等于y+通过。

对原物理外边界统一采用Riemann STATIC_SUPERSONIC_INFLOW_PT指定环境p/T和Mach向量。准确源码实际按内部Vn、Vn±a只投影入射特征，并非把所有面强制超声速入口；全出射时保持内部状态。由真实EOS填边界p/T/导数/Cp/mu/k，再计算黏性边界项。不得改用仍含定gamma能量公式的BC_Supersonic_Inlet或旧Far-field。

同marker在CScalarSolver分派SA BC_Inlet，GetInlet_TurbVal按标签取值，缺省为NuFactor_FreeStream；无需依赖普通INLET marker。该入口按实际边界EOS计算3mu/rho并以原生标量迎风方向选内/外值。对混合进出流及回流的实际分派、正负波速、扰动接近外边界和外域敏感性，仍须原生控制/完整候选验证，不能按源名授资格。统一外部参考只用于物理外边界，不用于内部截口。

v217的40°外壳是Eilmer专用连续设计，本组合不自动采用，不为迁移先造新壳；如果实际外域误差未过，另以证据设计扩域，原候选不作生产。Roe平均声速非法时原生存在零通量返回分支，必须在兼容性控制与运行诊断中可辨识；不能把零残差当收敛。若必须大改通量才可识别/接受则回到具体拒绝决定。
