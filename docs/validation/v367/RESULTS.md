## 同一状态上的算账

对象为同一低速民用试件，5 km，M0.30，零攻角和侧滑，给定壁温 300 K。沿用 v365 的 2 µm 细网、全壁层流假设及数值初场。取 v366 的 50 µs 后向欧拉整步，在内迭代更新之前读取节点账。确认了代码的实际调用顺序：Roe 上风和黏性通量在同一个 SIMD 边运算中组装，单看名为“黏性”的外层调用会漏掉黏性项。观察器读取每条有效边在 Roe 耗散之前、耗散之后和加入黏性之后的原生值。轴对称源、物理时间项、边界处理及隐式右端在同次组装逐阶段取样。[边通量源码](https://github.com/su2code/SU2/blob/7048fd35f56d4bf52e586429d6746a36a10255f8/SU2_CFD/include/numerics_simd/flow/convection/upwind.hpp) · [组装次序](https://github.com/su2code/SU2/blob/7048fd35f56d4bf52e586429d6746a36a10255f8/SU2_CFD/src/integration/CIntegration.cpp)

先在同一本地构建上按相同两线程启停观察。两个终帧的四个守恒变量逐点相同，四分量的全部 250 行 log RMS 也一致。直接比较本地构建与官方程序，末帧最大无量纲能量差为 0.004795，末行能量 log RMS 相差 0.2161。这使本地轨迹单独不足以解释官方末轮。

为对齐状态，另用官方程序取得更新 0–248 的末帧。其四项 log RMS 的 249 行历史与 v366 逐行相同。将该帧作为官方第 249 次组装的工作状态，时间层 n 仍使用原始数值初场。9,701 个节点的两组四分量数据均逐值复核；单次组装的密度、两动量和能量 log RMS 与官方该行在输出精度内一致。观察程序的随后一次更新只用于正常退出。全步的正式物理资格仍取决于 v366 的准入结果。[状态对齐合同](STATE_MATCH.md) · [官方前缀与单次回放](match_state.py) · [进程回执](evidence/processes.json)

## 节点 3828 的物理能量残差

该节点位于第 13 列、第 35 层（零基），模型坐标 X=14.493 mm，r=81.253 mm。下表各项采用原生无量纲残差的符号，正负可直接相加。隐式线性系统右端为其相反数。

| 同阶段的项 | 对物理能量残差的带符号贡献 |
|---|---:|
| 对流中心项 | −3.6456134e−5 |
| Roe 数值耗散项 | +8.8663304e−6 |
| 黏性边通量 | +1.2745910e−7 |
| 轴对称源项 | −2.1396067e−7 |
| 后向欧拉物理时间项 | +2.1675006e−7 |
| 净物理能量残差 | **−2.7459555e−5** |
| 准备隐式求解时实际读取的右端 | **+2.7459555e−5** |

中心项中，连向左右子午列的两条边合计 −3.6480077e−5，连向内外法向层的两条边合计 +2.3943015e−8。该分解给出了峰值节点上的方向，无法据此推断整件壁热峰。对中间两列全部 174 个内点，还用各项与净残差向量的内积除以净残差平方和，核对相抵关系。中心项、Roe 耗散、黏性、轴对称及时间项依次为 +58.72%、+43.42%、−0.10%、−2.28%、+0.24%。这里的比值有符号，和为 100%；它与 v366 用于定位节点的平方和占比含义不同。

对四列合计 348 个流体节点，用 787 条原生边独立还原节点边通量，再加上同一阶段的源和时间项。与实际隐式右端的最大闭合误差为 **4.34e−18**。用当前能量、时间层 n 的能量、节点体积和原生无量纲步长复算时间项，最大差 3.39e−21。v366 官方输出文件中的 `Residual_Energy` 是另一个读数：Newton–Krylov 的矩阵自由乘积还会计算显式扰动残差，输出列与本次基态物理残差的最大差为 2.13e−9。此次带符号核对直接使用隐式准备后的原生右端。局部方程项的记账闭合与 v366 的全域能量账分别验收。[原生边表](evidence/matched_edges.csv) · [原生阶段值](evidence/matched_stages.csv) · [逐点还原](evidence/matched_nodes.csv)

## 三个间隔二分后的实算

在原子午列 11–14 之间插入三个中点列。节点由 9,701 增至 9,968，单元由 9,504 增至 9,768。原节点逐点保留，壁、轴线和远界的几何折线一致。两网仍有相同的 88 层和同一批原三角面。原连续双线性初场限制到子单元后，旋转域体积及四个守恒量的积分相对差均小于 1.3e−15。这一检查对准初场插值；两套原生离散方程各有自己的控制体。求解器使用官方版本，除新网格和相应初场外，沿用原 Newton–Krylov 工况及预算。[加密与初场程序](refine_tail.py)

| 后向欧拉物理步 | 原网末 20 行最差 log RMS | 新网末 20 行最差 log RMS | 新网末帧能量残差归并到旧节点后的 log RMS |
|---|---:|---:|---:|
| 50 µs 整步 | −5.881 | −5.808 | −6.561 |
| 首个 25 µs 半步 | −6.151 | −6.095 | −6.451 |

新网两步均到达 250 次内迭代并正常退出。末帧归并量只描述该帧的空间分布；末窗仍须对四个原生分量逐项执行 <−8。第二半步没有获得可传递的第一半步状态。两网未通过的结果均留在研究记录中，三个间隔二分这一组合关闭。
