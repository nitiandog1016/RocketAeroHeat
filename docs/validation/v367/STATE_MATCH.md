首轮同一观察构建、相同两线程的启停对照产生相同的终帧守恒变量及能量残差。其首两轮全域原生能量 log RMS 与 v366 官方值相同到日志精度，但末轮相差 0.2161。首轮数据仍归属于自己的计算轨迹。

为直接检查指定的官方状态，用 v366 官方程序和同初场运行前 249 次更新（内序号 0–248）。只改内迭代上限，保留正常终帧，比较全部四个分量的逐行历史；原官方记录中该前缀每个 log RMS 差须 <1e−9。以其更新后守恒变量作为第 249 次组装的工作状态，物理上一步仍由原始 9999 号初场初始化。独立观察程序在第一次原生残差组装前装入这个工作状态，仅核读一次基态组装；输出的一次新更新不计有效物理步。逐点核对读取的当前/时间历史，不将此前试探态用作物理初场。

要求组装的四分量全域 log RMS 与官方第 249 行各差 <0.001；若未过则分开报告，不将其结果写成官方末轮。前缀运行与单次观察各限 2 线程、150 s、4 GiB、64 MiB；新增观察对象单独构建，沿用原编译预算。公式与原门槛不变。
