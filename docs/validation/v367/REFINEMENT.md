# 仅二分底缘及尾段的三个子午间隔

官方前 249 次更新的四分量历史逐行相同；用保存的工作状态及原物理上一步重新组装，四项原生 log RMS 与官方第 249 行差均为零（按日志精度）。在峰值 3828，中心对流的子午列方向净项为 −3.6480e−5，跨法向层净项为 +2.39e−8；Roe 耗散约抵消其中 +8.87e−6，黏性、轴对称和时间项分别约 +1.27e−7、−2.14e−7、+2.17e−7。物理残差为 −2.7460e−5。它指向一项可检验的空间分辨率假设；各项大小本身不能证明网格有错。

只把原子午间隔 [11,12]、[12,13]、[13,14] 各二分一次；从壁到远界各层连通一致，同一原折线、平底边、88 层和 14D 远界，原节点坐标直接保留。对体网格原始节点坐标使用 mesh.su2 的完整精度。将原数值初场的四个守恒量在同一双线性单元中作限制到子单元的插值；旧节点取原值，新增节点位于同一参数中点。复核原/新旋转域体积和四项初场积分 (相对于各分量绝对积分的差 <1e−12)。这检验连续重构的积分；不推断两网原生控制体离散完全相同。

在官方程序用相同 Newton–Krylov 设置各运行一次 50 µs 整步和第一个 25 µs 半步。每步不超过 250 次内迭代、2 线程、150 s、4 GiB、64 MiB。只有第一半步真正通过原生正性、末 20 行均 <−8 等原门槛，才继续第二半步。比较原面位置、同一时刻的资格与本地残差位置；新网额外报告按节点线性插值的转置归并回旧节点的能量残差，防止仅据全域点数改变判断改善。无论结果，保留两套网格和原失败场，本轮不再改变离散或调参。
