# 检查对流面值重建，再回到同一物理步

同一官方工作状态的节点账表明，峰值 3828 主要来自两条连接相邻子午列的对流中心通量不平衡。两列总体还存在与残差同向的 Roe 耗散贡献。仅二分左右三个间隔没有让任何物理步过门；不再延长这组。上述读数尚未确定面值重建、真实局部梯度及其耦合各自的作用。[同阶段证据与加密结果](RESULTS.md)

下一项回到原未加密细网和同一冻结状态，提取峰值处两条子午边及邻列对照的左右原始与重建面值，核对沿边速度、密度、焓及限制器对质量、能量通量的影响。用求解器已有的二阶重建梯度作一项对照，优先将仅供对流重建的加权最小二乘与 Green–Gauss 在同一状态上比较；黏性梯度、壁温、物理步长和原面责任保持一致。依据面值、局部右端及对照列选择是否进入 50/25 µs 原生试算，验收仍要求四个原残差、同刻原面热流和守恒。不能用降低单个点的残差替代两步通过。
