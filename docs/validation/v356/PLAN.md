# 从侧栏新算低速风洞细热网主结果

基线 v355，提交 `2f98057b66baeb60a5af05bd12df019adbefeb01`。固定原 STL（9,216 面）、0.05 m/s、零攻角、300 K 空气和 300.001 K 等温壁。沿用 14D 外域、48 方位、v355 的 0.002D 近壁热网和已完成的整／半步及粗／细网对照。只重算扰动支两个 0.300 s 显热时间步，以 0.600 s 末场为主。保持完整压力、温度和有符号热流的原面编号及六区积分。

输入为 `cases/simple_launcher` 的 STL、几何和工况、v352 的全周网与速度种子，以及 v354 的两个实际动量终帧。动量缓存须核对源配置、种子、原生残差及末帧。细网初场可复用 v355 已通过的稳态热网与初始温度，仅按真实指纹选用；缺少时从同一稳态基流重建。归档末场不参与计算。无缓存的动量仍走已有 420 s、4 线程、4 GiB／步合同，本轮复用已验收动量。初场准备限 180 s，每个显热步限 240 s、1 线程、4 GiB、300 MiB。保留两半步及源输入链，拒绝资源停止、非正常终态、源不稳或场指纹不符的阶段。

复核热网、两个流动时间层、温界、原方程相对残差 <1e−8、归一质量不平衡 <1e−8、通量投影 <5%、能量收支差 <0.5%。从原 STL 和原面热流独立积分六区及总功率，从前后温度场独立积分储热。各项通过才写完成回执。固定输入回归逐面核对 v355 参考值，包括有符号热流、壁压及首层流体温度；新算值来自本作业的原生面表。

在普通侧栏分别检查有缓存的“计算”、缺少细网归档且需重建细热初场的“计算”，及明确“读档”。各次有动量缓存的界面回归限 300 s、1 核、4 GiB、300 MiB 新输出。独立小型项目副本用于缺档测试，保留用户原目录。核对三维渲染、默认主变量、六区探针、截面、粗细网比较色标和 9,216 行联合导出。没有可配对的对照时，仍须能独立生成整件主结果。稳态与旧归档保留原语义。记录各阶段耗时、归档与新算身份、初末帧及底面弱信号限制。
