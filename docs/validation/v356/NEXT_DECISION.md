# 检查同一低速工况的动量网格误差

对已接通的 0.600 s 全表面工况，已知的是同一三维速度场上的热网差异。下一项固定 14D 外域、48 方位、物理边界与细热网，在同一简化试件上检验速度及压力的空间分辨率对壁压和热流的影响。先登记候选动量网的实际间距、节点数、初态构造、同刻对照、内存预测和停止条件。只允许一次有明确预算的首步容量与收敛核对，已验收的原速度场继续作为对照。

首步合格且本机资源足以到达同一时刻，再完成第二个半步，将变化映射回相同的 9,216 面，比较壁压、六区积分、鼻端热峰与整件放热。容量或准入不通过则保留原判定，记录具体阻碍。两种网格的末场放在独立作业目录。保持低速等温风洞范围，继续对外域与实验误差分别记账。[当前工作台与原面结果](RESULTS.md)
