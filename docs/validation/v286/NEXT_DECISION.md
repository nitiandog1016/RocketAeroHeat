# 下一项：核对 B 型珠体在第二档实测风速下的全表面计算条件

当前 3 m/s 的净功率边界已完成，包括全表面计算、工作台和两网积分。下一项选择同一公开 B 型热敏珠，考察原论文图 7 单列的 **6 m/s** 工况。此项检验程序能否在真实改变来流后重新计算动量及温差场，并用对应速度的整珠测量对照。先固定图上一个可定位的温差测点、读数范围和原始单位，核对该雷诺数下尾迹的稳态与对称性依据。[原论文图 7](https://doi.org/10.1299/kikai1938.25.810) · [本轮范围](RESULTS.md)

若原扇区和稳态假设有适用依据，登记网格、来流、物性、预算和停止条件后，重新计算该速度的参照场，核对全表面和原生能量账，再接入同一侧栏。若依据不足，记录需要的空间域或非定常证据及本机成本，由此决定可行性。3 m/s 的参照场只对原来流有效。目标是得到一个新风速下可复核的民用试件结果，实验只按实际测量量验收。
