# B 型热敏珠的净功率边界

基线为 v285，提交 `f9572ed545f28f741e7fbecea85e122bcbe10f3c`。仅对公开低速热敏珠实施。3 m/s、293.15 K、101325 Pa，原 5,216 面，15° 和 7.5° 网分别用随项目发布的归档（SHA-256 为 `11ba9c504f8df41a1be7c317d1047e77ab76800d3eae7b569d0b34333ffbb563` 与 `d02c8ac7fb41a7072e416e251efd2ccf8d19101ec388c98a46b3ed0a6e72449b`）。输入为扣除引线、辐射等其他损失后由空气带走的净功率。采用恒物性、无浮力反馈和等温集总稳态假设，在 0–12 K 的参照温差范围内按各网热导反求壁温。

检验 0 W、两网共同的 0.004 W、两网各自上限，另验 7.5° 网可解而 15° 网对照超域。拒绝给定温度与功率并存、非有限、负值、超限输入。核对给定温度旧接口、切换边界后的失效、研究场身份、探针、原面与 CSV。逐面面积积分与净功率相对差须小于 1e-11，零功率须严格闭合。使用 v285 原生独立半温差证据（native.json SHA-256 `41cec8d1f80bd116687b0c7911ab09f1921b867da2994d8949dce546cb547d09`）的壁面放热反求 299.15 K，绝对误差须小于 0.001 K。各网使用同一输入功率配对，超域时保留主场并说明缺失的对照。

每批 MATLAB 最多 180 s、1 计算线程、4 GiB 进程树、80 MiB 新增输出。使用匹配的原生参照帧，无需重跑 CFD。预算超限或结果不符即停并保留现场，修正后单独存放复验结果。小型回执随源文件发布。工作台数值回读、网格差值与公开实验精度分别报告。
