# 普通 STL 进入带线 B 珠的单工况计算

基线 v318 `619479a10f8ed8cb665a83804629e02bcd97abae`。同一民用试件，3 m/s 沿 −Y，空气 293.15 K、101325 Pa，96 档。原面数 10,272，源体网 fbd8114f786ad08ffbcb40dc2a4c32983f0a81275373f3113515a96426f8235b。保护并发 Web 等文件。自绘模型单独记账。[输入与上一决定](../v318/NEXT_DECISION.md)

在普通模型页导入后显式选用此方法。核对 STL 文件指纹、单位、实际三角形顺序、已确认的刚体朝向。允许平移、点号重建、共享点拆分、三角形循环置换和面序改变。按顶点和三角形拓扑一一匹配，角点位置差 ≤2e−10 m、各面相对面积差 ≤1e−5、法向点积 >0.999999。拒绝歧义、重复、缺面、反向、比例和形状超差。保留实际面积；用原面积比换算热流密度，逐面功率、七区积分及全件功率误差 <1e−12 W。压力、温度按同面对应。固定测试排列种子 319，在导出端按文件记录独立重算。

从普通入口实测体网重建、电阻测温全场换算和原生档案读取，以及长引线原生新算。后者复用 v316 已收敛的均温初猜 24ff2472e2467b929bc7ab7752f47bd2f402137504cf2c72408ceeb00d917754。原求解器按 v317 分阶段保存及监督，最多五段 × 320 步，4 线程，每段 720 s / 4 GiB；反力、追加步、独立回放各 ≤180 s。保持原连续六分量 −8、热稳定 0.2%、同态能量账 0.5% 门槛。总原生磁盘 ≤16 GiB，任一原生门槛失败保留现场。工作台测试（不含原生求解）每次限 360 s、单 MATLAB 线程、4 GiB，导出 ≤300 MiB，体网重建另留 1 GiB。核对真实 WebGL 回执、探针、截线、冷热变量身份、文件变化失效。科学结论只限本试件，实验面积沿用旧证据。
