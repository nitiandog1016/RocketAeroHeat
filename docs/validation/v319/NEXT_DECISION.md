# 同一民用探头的 STL 局部重剖面

下一项检验同一民用带线 B 珠在 CAD 导出时把部分三角面细分后的使用流程。优先取一个珠线圆角及相邻直引线，在原平面内分片，保持几何和 3 m/s 侧吹边界一致。现有整三角面匹配只接受三个角点完全对应的标准面，这类输入将报告缺少对应。

直接从已通过的细壁三角、节点场和壁面反力积分到每个新的物理子面。登记输入前列明子面、标准面和细壁面的坐标及编号。检查交叠无遗漏和重复，父面功率等于子面功率之和，子面压力、热流和温度按各自的积分或采样定义核对。首层采样需给出空间对应依据。用同一 GUI 查看子面探针及穿过重剖区的截面，按用户文件原面完整导出。单纯复制父面均值无法验收局部分布。

只验收该民用几何及上述重剖方式。若源面和目标面不同面、发生真实形状改变或缺少首层对应证据，记录实际受影响的面与面积。沿用已有 B 珠原生终场及公开实验口径，预算在下一轮计算前登记。[原任务范围](PLAN.md)
