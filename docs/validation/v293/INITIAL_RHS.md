# 若第一半步未达标，定位原网与加密网的起始方程误差

第一半步末窗若有未达标方程，先保留其真实失败终场。用原网与加密网各进行一次官方单内迭代读数，只读取第一次装配的六分量右端。参考源分别是 v292 第一半步与 v293 第一半步的真实种子、网格和配置，各自只把内迭代次数改为 1。每个读数单线程、100 s、4 GiB、新增 200 MiB；逐点读取与归档每批 180 s、单线程、4 GiB、200 MiB。不会将读数的输出场作为第二物理步的旧态。

原生历史的表头及第一行须与对应原运行逐字节一致，逐节点六分量 RMS 与历史对数差 <1e-7。对两网完整初始装配、相同节点的外域、原加密区域及新中点分别报告焓和压力方程的残差平方和分布。检查旧节点坐标对应、最大的局部差和新旧对偶体积的影响，再与 560 次终点的径向、周向分布对照。焓与连续性右端的相关性只用于判断耦合误差，原验收仍使用未变换的六项原生方程。缺少逐点前缀证据则停止归因。
