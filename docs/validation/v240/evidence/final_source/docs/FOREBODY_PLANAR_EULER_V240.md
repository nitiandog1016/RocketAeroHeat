# v240：真实前体区域外流与平面出口

本版实现了原四面体的共形平面裁切、成熟SU2三维前体Euler入口、实际出口特征守卫和原面科研出口。唯一真实任务完成200更新，正常触发预先登记的残差收益停止；**已内部产生研究场，但尚未获得外缘或热流物理资格**。不需要用户导入外部CFD，也不以等待大内存为前置条件。

## 方法选择及几何

v96沿给定压力计算表面流管，不能生产未知压力。Riley NASA-TM-107838第3章的空间推进还有鼻端/声速线及适用范围要求；本次复用已读来源，不把它称为实现了20°全箭PNS或薄激波层。选择成熟单区Euler时间推进，保留真实钝鼻和三维周向流动，未来再向适用工程边界层提供入口。

原v233锯齿切口有61面传入，不能直接设纯出口。新模块`scripts/clipEulerForebody.py`取原前体边界环的真实平面x=-0.33979348906555734m，46个环节点x逐位相同；保留x较大侧。共享边交点和确定性多边形对角线保证相邻单元共形，部分多面体在内部剖分。没有移动原壁点、分裂原壁三角形或删除其余区域责任。

## 原生成熟入口与真实运行

绑定实际v229 `CEulerSolver_observed.cpp`及已有相态Euler归档，气体身份16、同Cp/相态域/能量零点、Roe/二阶MUSCL/原limiter/CFL保持。`MARKER_SUPERSONIC_OUTLET`准确源缺一般EOS secondary设置，未直接采用。使用已验证的`BC_Riemann`一般EOS特征构造：仅当全部特征出射，储库状态才不参与边界状态。

一个必要CEulerSolver观察对象只在真实u_b构造后、EOS和通量提交前增加回调，要求un/a>1且五个u_b/u_i逐位相同；任何传入立即记录准确节点/阶段并拒绝。没有改动数值公式，其他成熟对象不重编。回调在真实任务中核对161400个边界节点调用、807000个分量逐位相同，最小实际Mn2.208213；没有发生出口守卫拒绝。原生末预处理拒绝数最大3，仅代表该阶段计数，不声称所有子阶段或实际ID已记录。

唯一区域任务从相容均匀来流启动，初0全部五量与v232均匀来流逐位一致。200更新13.188秒、exit0、采样峰RSS69,603,328B、1CPU，输入稳定、任务组清空。保存0/1/50/100/150/200完整场，正常末强制原生CSV；末坐标和五量与`restart_flow.csv`、`restart_flow_000199.csv`逐位一致。原800/199/92和v239没有续算。

## 映射缺陷、恢复和显示

首准备误取v229首次构建回执，找不到实际恢复源键，失败保留；使用准确recover_build与当时独立build_audit恢复，只复用已通过的裁切体积检查。

独立审核发现原在线压力统计将文件全局节点号当SU2内部重排后的下标。原完整场、出口回调和物理RHS不受影响，但首在线压力变化0.0256434%错误。修复显式global-to-local映射，仅重链薄驱动；同区域初始化后读保存200场，**零流动更新**实际调用修复函数，4434面与Python最大相对差1.123543e-15。原执行头/错误统计与首次审核失败保留，工作台采用修正后的独立原面值。原停止中残差恶化已独立成立，修正后的压力也不会改变停止决定。

恢复审核数值报告完整落盘后，监督容量重复计算整个BASE与两个audit目录，错误触发exit15；当时实际约90.8MB，未超256MiB。原失败回执不改，修正计数后只读接受既有完整报告/输入/读回，不重算流动或保存场。

工作台六阶段、39字段、159624个研究值逐数回读通过，实际前端纯函数验证区域外null/状态0、全面积分母、同变量共同色标及方法身份。全箭体显示，区域外为灰色；热流/固体Tw未解，给定Tw300单列。科研图含全体/前体放大、末帧总焓偏差、残差和出口Mn，末帧总焓采用同帧对称色标；原宽色标图也保留。图已视觉查看。没有修改共享WebGL、执行MATLAB或浏览器交互验收。
