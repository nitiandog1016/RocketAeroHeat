目标是消除离散锯齿法向造成的伪入射，并检验实际轴向特征，不能预称全部为超声速。对已有800研究场的新平面每个节点及每个三角面计算同相态气体un/a，全部必须严格大于1才考虑单向候选。未满足即拒绝这个平面纯出口组合，不补p∞、不搜索另一截面或删除背风面。此检查仅支持候选，后续实际求解必须逐更新核对出口特征，并以截断位置/外域与空间误差检验授予物理资格。
