# 接续到一个对流时间的银球全表面瞬时场

在 Short Test 65 目前的早期时刻，壁反力与近壁温度梯度给出相同背风排序。周向变化也无法达到实验中的反序。这两个诊断已完成。尾迹尚处于人为小扰动后的 0.25 个对流时间，实验测量没有与该扰动同步。下一项检验尾迹发展对同一试件全面积解的影响。[周向排除结果](RESULTS.md) · [原始时间层与储热定义](../v333/RESULTS.md)

选定一个较晚的单时刻 **tU/D = 1**（约 10.263 ms）。从现有整步和两半步各自通过审核的真实终帧接续，保持 14D 体网、温界、原面编号及原生 BDF1 方法。执行前登记新增三个整步和六个半步的准确输入、保存位置、机器资源和停止条件；先对首个接续步核对物理时间、前后层、原方程、流体储热和独立壁反力。新时刻的两种步长分别核对压力、热流、五区功率、背风共同方位差、七站和热峰，在五步工作台选择相应终点；旧时刻继续有独立来源标签。任一原门槛失败时保留实际终态，停止该组合。

以这两个已指定时刻的差值衡量早期尾迹影响，单独报告步长敏感性。在这个终点完成比较后再决定是否有依据研究更晚时刻或其他边界，不将早期单帧赋予实验长期平均的资格。
