# 同一时刻银球七个极角的全周换热

以 v337 `66ba1dcabf0d8081f6a7e403be0666514f24d372` 为基线。只读 Short Test 65 双支管银球 14D、Re = 882 的第二个半步，t = 2.565681445 ms。参考终帧 `0132e9b266ef344fcbf13fd9a7d3dd994fa56ef3192caa3fbf7c8fc1da5f002e`；网格、给定温界、独立释放反力和原面绑定同一任务。相对 v337 预计新增 0 面、0 m²。[上轮决定](../v337/NEXT_DECISION.md)

以 +X 为极轴、方位 0° 指向 +Z、90° 指向 +Y。把七个实验极角的锥面与实际湿壁相交，从同一终点壁节点反力除以集总对偶面积得到入壁热流密度。用分片线性插值取热流及壁温，以当地壁温导热系数与来流温差换算 Nu。求解壁与原 STL 分别定位，保留球面、接缝、管壁及湿端盖身份。共享几何点核对重合，异区接缝与被管遮盖处不填值。0° 只取一个点。原面均值和原面总功率继续使用既有守恒口径。

以锥面穿越三角边的方位给出连续区间，保留 +Z 和全周等角读数。报告有效与缺项角度、样本极值及所在面。相同方位直接比较背风两站；要排除全周反序，另需每个开区间的数值界和边界点检查。只靠有限采样不能排除区间内反序。若有反例则保留方位、定位、两个数值与源身份。独立复核射线几何、热反力、温界、符号、七站 +Z 的旧读数与新旧面号。结果接入 14D 两半步工作台、离线三维页与导出，复核其他步长或外域保持各自数据身份。

各次提取或独立检查限 180 s、单线程、2 GiB。普通入口的原生三步复读限 240 s、2 GiB。真实工作台每次限 300 s、4 GiB。仅生成小型曲线、导出与验收副本，额外磁盘 0.5 GiB。源帧、几何或热量账不符即停止。收口后依据周向证据确定一项物理对照，累计热量和轨迹保持后置。
