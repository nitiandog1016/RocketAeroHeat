# 将 Short 实验的赤道支管纳入几何对照

六个已算截面的速度恢复带各跨 7–9 条独立射线，粗细时间步定位一致。按事前筛选，本轮没有选出一个应当先单独加密的截面。空间离散误差仍未知。下一项转向已有直接装置证据的差异，建立**带两根赤道支管的民用银球几何与原面账**，把暴露银球、两处连接和支管外表面分别标识，为同工况全表面换热对照提供实际计算边界。[尾迹核对](RESULTS.md)

沿用 12.7 mm 球径、Re = 882 和七站测量定义。两根支管的登记直径为 0.096 in，即球径的 19.2%。先从原论文图及实验装置说明核对轴向、外露长度、截断处、温控和测线相对方位。已知、从图读数及缺失的尺寸分列。论文对量热面积使用的 1.0188 修正单列，不能直接乘到局部热流。原 4,464 面光滑球保留作对照；新几何如覆盖原球面的一部分，保留暴露面积、覆盖面积和对应原面号，不能将覆盖处再次算作外露壁。[装置与测量来源](../v321/SOURCE.md)

验收首先看闭合表面、两处实际交界、可回查面积和七站的空间位置。若来源足以约束计算边界，下一物理计算使用单独登记的体网、温界及资源预算。若支管末端位置或温度不能恢复，应将可计算的名义装置与实验复原的资格分别记录，并指出受影响的局部及整体量。保持既有光滑球的压力、热流和实验对照台账独立。
