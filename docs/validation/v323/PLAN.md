# Short 银球 Test 65 尾迹空间分辨率

基线 v322 `b254c3a5b2c7cbf38ab8095874d558d27b064cbe`。沿用 82.101806 ms 的粗步 32 终帧 `77275b46ad88ff1704dcd7b9aff4da661da7baff40120bc802bce417dc124dc1`、细步 64 终帧 `b19e8986b2d7e71bcb1021ce81963ce78873f358c858cb416fa4900de8323e19`，原网格 `09786503e47c6229c4a2e325da68ab85a4ce599f66240f0dcf0fbb85d73677e0`，工况及温界均取同一原生任务。核对两份原生回执、配置、保存帧、历史、发布包及七站测线。上一版已通过的数值推进和逐面热量账直接复用。[上次决定](../v322/NEXT_DECISION.md)

1. 从 SU2 体单元连接和坐标抽出与实验取样同方位的 +Z 母平面。用球后轴线的原始节点夹住反向轴速归零位置，给出距球尾的回流长度、插值与网格上下界。如没有贴尾连续回流，照实记录。
2. 在 x/D = −0.6、−0.75、−1、−1.25、−1.5、−2 六个截面，沿实际网格射线的相邻节点线性取样下游速度。以 r/D ≤ 0.6 内的最低速度和自由流为端值，取从最低点向外首次跨过 10%、90% 恢复幅度的位置。报告所得速度恢复带宽、带内独立射线数、相邻射线横距及各射线供值边的轴向跨度。逐项区别真实节点、网格线交点和插值边界。这是沿截面识别剪切层的操作性指标。两站用真实首层切向速度及同帧 Nu 建立位置联系。
3. 两步长分别提取。以恢复带内少于 4 条独立射线，或带宽小于所跨最大相邻射线间距的 4 倍，作为安排一次空间对照的筛选条件。轴向归零夹区若同时宽于 0.1D 及回流长度的 10%，单列轴向分辨率。以上仅用于排定对照，不由单网推断误差原因。两帧若对回流存在性或薄弱区域分类不一致，交付差异并停止加密决定。
4. 后处理一个批次，单进程、单计算线程，≤120 s、2 GiB、100 MiB。读取原场，不启动物理求解器；输入指纹、平面连接、坐标或原生终态不一致即停止。保存含原节点号的剖面、轴线、两站与粗细比较。独立复核用坐标重建采样，并用合成线性场检查读取符号与长度。工作台将只读诊断绑定到原包实际帧，新增页面单独验证（≤180 s、4 GiB、100 MiB），不改并发前端。现有几何面、热值及方法身份保持原台账。
