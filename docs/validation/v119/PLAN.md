# v119运行前决定：同物理有限续算与累计身份

上一轮是实际进展，v118固定原19752面/20°/精确来流完整域并得到可追溯场，但未稳定。本轮不改变网格、初始物理、AUSM/MUSCL、CFL策略、−8或等温壁；不以SST开关掩盖数值启动。

依据：299步所有守恒状态正，最低温142.698K，没有v117近零内能冻结证据；150→299压力L1变化8.4393%、热流32.8775%，能量残差下降但末50步HF仍变化20.9171%。因此先做**一次**从299步真实状态开始的300步续算，判别启动演变是否继续改善，不能据此直接判定网格充分。

机制：省去重复自由流/壁面初猜，保留所有原面和全体域。输入以原生具名文件/源回执/全配置和网格SHA核对，禁止跨工况、插值、裁剪或恢复取消的283步。伪时间/CFL历史会重新开始，累计更新数仅计迭代，不是物理时间，不能冒称与单个600步进程逐字等价。

本轮唯一流场任务：300步/2线程/≤720秒，150和299具名输出；预计约490秒，预算含余量。记录本轮与前次成功任务总用时，另列434.156秒被取消任务，不通过分段规避总资源说明。完整域检查点预留256MiB，初场/网格硬链接复用；不删唯一场、不重试v117被拒缓存删除。

数值继续的预定门槛：最终密度和能量log残差分别比v118末值下降至少0.3；本轮150→299热流L1变化小于16.43875%（原32.8775%的一半），末50步HF首尾绝对变化小于10%；全保存状态正、原面覆盖不变、来源稳定。任何一项不满足，不能自动再续算，须实施空间离散/物性模型方案。即使全部通过，也仅为数值推进，物理资格还须原−8、稳定、网格/外域、转捩/湍流及公开热流验证。
