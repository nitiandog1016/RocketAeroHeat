# 前端面细网的实测规模与原生预算

成品网有 158,469 个节点、279,024 个体单元。336 个父单元各分为两个子单元，289 个新节点均取原法向边中点。端面全部 336 面的首层法向距离从 0.937123 降为 0.468562 µm，另有 288 个相邻引线面的首层位置改变。父单元体积和的最大相对差 1.23×10⁻¹⁵，原 20D 全域体积、所有壁面、远场和基线温度采样点均已读回匹配。网格 SHA256 为 `288528682a52da82cf2c600738f1475ddd0d2792483d63a0b0e62164f0ccc8ee`，初猜为 `ced6ea47854c620380434970036a1da4fa48e674aace1f5b7f5cb38dc15d4217`。建网用时 4.44 s，独立读回 6.78 s。

采用官方 SU2 8.6.0，四线程。规模与 20D 基线接近，按已测约 0.54 s/步预留。首段最多 1000 步、720 s、进程族 3 GiB、目录 1.5 GiB，每 100 步和终点保存。若首段到步数上限，已核验的正常终场有界、残差下降而末窗未过 −8，可从该帧续一次最多 800 步，资源上限相同。原生发散、保存场越界、终态或输入身份异常则停止。保留原生 −11 收敛设置及六项末 20 步准入检查。

满足上述条件后，官方壁反力、追加 20 步和第二次反力各限单线程、120 s、3 GiB、450 MiB。官方与观察器同输入单步各限单线程、90 s、3 GiB、1 GiB。沿用基线能量守恒、独立反力与热稳定要求。合格后对接共同采样位置、七区积分、峰值与其邻面。
