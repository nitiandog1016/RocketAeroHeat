# 核对侧吹全表面分布对周向网距的敏感性

在 20D 与 30D、以及前端面两种首层厚度的三套结果中，热峰位于前端面的同一迎风小区。v313 将端面首层距离减半后，峰值放热密度变化 0.00228%，同网的两镜像面近乎等高。三套结果均沿用 48 个周向间隔；现有对照仍无法定量解释迎、背风曲线及双面热峰对周向分辨率的依赖。[端面与全表面对照](RESULTS.md)

下一项在同一民用热敏珠的 20D 侧吹工况下，以 v313 的细网及源场为基线，比较 48 与 96 个周向间隔。保留实际多面外壁和外边界、近壁法向位置及 10,272 个原面报告编号。先检验加密后的物理壁片如何保守积分回原三角面，核对每个原面的覆盖面积、方向、重复与缺失，检查轴线、接缝与完整体域体积。新顶点采用原网几何内部插值，并区分初猜和最终全域解。单次建网、一次独立读回各限单进程 240 s、3 GiB、500 MiB。若几何或原面映射不能验证，记录该构造失败，结束该候选。

网格通过后才按实测规模登记全域求解及能量复核预算。比较全表面同面压力、热流、同位置温度、七区及整件功率，重点核对前端面双峰区、邻带以及 X = 0.172 mm 的迎背风分布。在工作台交付本次两档观测差后结束周向对照。两档网与数值守恒均不能给出实验误差。维持对实际测量几何与变量的单独验收。
