# 20D 热敏珠侧吹的前引线端面近壁细化

基线为 v312（`5b929196c565489dcbe9e319ab1e525f8f18eada`），本轮启动时远端 main 和标签一致，v313 空闲，未发现本项计算进程。沿用 v311 的 20D 全周网、48 个方位、10,272 个原面、293.15 K 和 101325 Pa 空气、沿 −Y 的 3 m/s 来流及 299.15 K 给定壁温。网格、原面和工况指纹见[基线清单](../../../cases/thermistor_b/sidewind3.json)。该机 20D 输入为 `outputs/v311_validation/cold01`，初猜来源为 `steady02` 下已通过壁热与收支检验的终帧 `324fcdd08155996c0b3119223e34b459651292de205d6d97c61429ceb30a6cdc`。独立目标是量化峰值所在端面的近壁敏感性。[前一决定](../v312/NEXT_DECISION.md)

只二分前端面和相邻两排直引线的第一层，在再往内一排直引线完成过渡。所有旧节点及外边界固定，新增顶点取对应壁节点到原首层节点的中点。保留原首层采样编号，以便两网直接比较同一位置的流体温度。原场仅用于初猜，新增节点线性插值，成品全域重新求解。建网与独立读回各用单进程、180 s、3 GiB、300 MiB。检查原面、基线未动单元与受影响父单元体积、内面方向、轴线接缝、实际首层法向距离、原采样位置、温界及初猜来源。若不满足网格要求即关闭该候选。

根据实网规模另登记一次原生计算及热量核对预算。复用六项残差末 20 步低于 −8、正压与温界、无滑移、20 步热稳定 <0.2%、同阶段壁面与远场功率差 <0.5% 的门槛。给出 10267 号面及边邻面、两域热峰、端面功率、整件功率和原首层位置的温度。面号采用工作台从 1 开始的编号。仅合格的研究场接入工作台，并独立比对面元、峰值与导出。工作台测试一次限单计算线程、180 s、4 GiB、180 MiB。侧吹局部实验精度继续单独记账。
