## 假设与运行预算

1. 已收敛平板的内部热流可能受流向／法向网格和外域影响。复用80×64、第一层2µm、外域0.06m基线，新增120×96、第一层1µm的加密网格；另一个对照保持基线近壁网格并在顶部追加外域层至0.12m，避免把远场距离变化与重分布近壁节点混在一起。
2. 计算使用2线程、单次上限720秒，残差门槛仍为密度／能量log10小于−8。共先做2个物理算例，达到预算仍不合格就保存失败／状态并分析，不默认续跑。新增研究输出目标100MB、运行内存目标4GB；不保存大矩阵或项目副本。
3. 在原固定区间0.04—0.16m插值比较：热流变化5%、壁压变化1%作为本轮工程敏感性筛选尺度；若某一项超过则明确未通过，不事后放宽。这不是三网格阶次／GCI，也不是公开实验通过。前缘热峰、第一节点温度偏差和全板单位展向热功率单列，不因中段通过而授予前缘资格。
4. 独立边界层比较沿用定比热、Pr0.72与Sutherland，仍称数值比较。公开基准须先核对物性和壁面条件再运行，不能用不匹配的实验数字填表。

## 完整箭体准备

复用已有完整参数化箭体和轴对称外域几何，旋转为真正3D有限体网格，保留鼻部、锥段、柱段、收缩、后体和底面；保留所有原表面面元。检查体积正号、边界闭合、内外边界与原表面的面积／体积账，以及SU2实际网格预处理。几何和dryrun不计物理解面积，不以轴对称求解替代20°。

先使用无突起原生模型；显式拒绝目前无法保持的突起或任意STL。后续突起接入需要自身的完整体网格生成，不可静默抹掉。维持X主轴、鼻尖+X、零攻角来流−X。后续引擎选择和状态应接现有工作台，不能另立永远独立的研究UI冒充主流程。
