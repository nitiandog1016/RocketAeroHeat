# v134有界凸性候选失败后的成熟曲面平滑方案

原方案1.062秒正常终态exit1，HiGHS报告不可行；未构造新棱柱、未调用Gmsh或SU2。保留原1mm约束/参数与失败，不作线性规划上限扫描。固定YZ、只调整X不能在当前约束下修复该三角连接，不能推断所有三维移动都不可能。

按照目标的成熟网格路线，追加一次Gmsh4.15.2曲面节点重定位，使用真实球面CAD参数与Relocate2D（force=True，niter=5），保留原三角拓扑。拟合与X=0.03至0.04平滑区不变；选原壁X≥0.04的第一个完整周向环作固定球面圆边界，其内节点在球面上重定位。该处外壳最大相邻径向间距约4mm，事前将此独立方案的总位移上限设为2mm（约外壳高度的9.4%）；这是不同的三维节点平滑方案，不能追认原1mm方案通过。不得在看到结果后扫描次数/位移上限。

先保存完整原始曲面结果/原拓扑/每点位移，再检查局部凸性、原壁/近壁保持、全参考棱柱Jacobian与2mm位移限制。失败停止并保留结果。通过后按原计划仅作一次Delaunay外域重建，原远场三角面和原壁面保持，全部四面体SICN≥0.1、规模400000节点/900000单元，完整拓扑/体积独立审核。曲面准备单项180秒，重建单项180秒，最多一个曲面操作和一个外域生成，不调用旧Netgen，不启动SU2。新初场/流场需要几何证据后的独立计划。
