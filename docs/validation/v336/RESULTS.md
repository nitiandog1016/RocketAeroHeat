流场采用 SU2 8.6.0 不可压层流，标量与流动共用远场质量通量。冷态收敛后向尾迹 414 个节点施加速度扰动，峰值为来流的 1%。一个 BDF1 整步与两个 BDF1 半步到达同一物理时刻。正热流进入壁面，表中瓦数为向空气放热。壁压由壁节点和面积交叠映射，热流由同刻壁反力、边通量修正及独立释放行复核。固体求解壁温、外缘温度和恢复温度保留未知。[算法和测量口径](../v333/RESULTS.md)

## 从源码到重开窗口

独立目录取自 v335 提交 `59c17358d992fbba80b4d5a1a61f12e8d857da96` 的试件相关文件，叠加本轮改动。Gmsh 从 PyPI 下载。编译使用本机已有的五个上游原始包，另从各公开地址独立下载并逐个核对 SHA-256，共 101,320,030 字节。两个 SU2 静态库和四个银球专用程序均在该安装内编译。链接后的四个程序只引入 Windows 的 KERNEL32 和 msvcrt。体网有 261,708 节点和 397,824 单元，网格及冷态指纹均与冻结输入吻合。[准备与预算](PLAN.md) · [源码及运行身份](evidence/receipts.zip)

第一次解包工具链时，自解压程序把文件放到了下载目录，随后用 Windows tar 指定目录重新解包。首次四路编译达到 3 GiB 限额，两路接续同一构建耗时 393.70 s。第一次实窗从冷态进行 1,000 次稳态更新后，在磁盘保存值与原生值逐节点相等的检查中失败。恢复 ASCII 科学计数法的 17 位有效数字后，第二次从同一冷态重新计算。前后两个稳态观测端点的初始、结束标量分别复核，每表 261,708 个节点，全部逐值相等。失败窗口、已拒端点及原回执均保留。[初次失败与更正](RESTART.md) · [二进制与文本逐值对照](evidence/restart_io.json)

合格运行的专用编译、链接共 67.80 s。稳态五段及附加控制、观察、释放共 999.86 s，末窗六项最差 log₁₀ RMS 为 −8.94118。稳态热变化为 3.49 × 10⁻⁸ 以内。三个物理步原生计算共 894.38 s，三次独立释放另用 136.30 s。各步壁放热减远场输出减流体储热的相对差绝对值均低于 5.7 × 10⁻¹¹，原生计算进程族峰值 2.21 GiB。命令行从真实前后时间层与独立壁反力复读用时 43.55 s，完整重现本任务的两份结果包和时间层清单。跨运行的耗时及编译来源单独记录。同机两次安装的证据适用于本次工具链。开发耗时未独立计时。

成功新算的窗口写出了 `ui.json` 和全部 32,480 行 CSV。窗口退出后，旧监督程序尝试等待已被 Windows 服务复用的 PID，收到 AccessDenied，其自身以 1 退出。该窗口的 MATLAB 退出码和整体峰值内存未知。原生各阶段终态均有各自回执。修正监督程序的进程身份检查后，另一个真实窗口从本地任务重开，46.33 s 内以 0 退出，峰值 2.73 GiB。两窗 CSV 逐字节相同，WebGL 错误均为零；离线三维页与 CSV 的压力、热流、两种已知温度及三个未知温度逐面一致。缺少完成回执、损坏另一步长的面表、变更初场记录的三个任务副本均被拒绝。[新算、重开与复读](evidence/surface.json)

首次建网的受监督入口在临时目录复验耗时 16.92 s，峰值 0.37 GiB，生成的六项输入逐字节一致。再次检查运行库后，编译回执及三项缓存索引指纹均相同。改变适配源码、损坏时间驱动的两个测试副本均被识别。[缓存与受监督建网](evidence/cache.json)
