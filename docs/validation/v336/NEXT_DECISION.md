# 直接核对七个测站的近壁温度梯度

Short Test 65 用移动热电偶的近壁温度梯度得到局部换热分布，再以整体量热标定。程序的逐面主热流来自守恒壁反力。已有法向、周向和远场对照；新安装能否复现既有结果，与七站局部换热的实验偏差分开验收。[试验测量定义](../v321/SOURCE.md) · [远场对照](../v335/RESULTS.md)

下一项用同一 14D 银球的实际保存场，在七个原测站重建流体侧壁面法向温度梯度。先核对测线方位、角度插值、壁面法向、相邻层距离、温度单位与导热系数。在同一站分别列出由近壁温度得到的热流、主解的壁反力热流、用论文口径换算的 Nu 和表 III 原值。已有两种近壁间距的稳态场用于检查梯度的分辨率；两个网的稳态与指定物理时刻分列。重点跟踪 119.8°、166.7° 两站的误差方向，以及支管根部附近能否取得无歧义的法线采样。

先读已有体场，保留原面主解、七站位置和五区面积。逐站报告可用层数、法向距离、梯度重建误差与缺项。用这一项具体对照判断下一项应解决近壁热流提取、近壁空间误差，还是已有证据指向的其他物理差异。没有测线或近壁点对应证据的站点保持未知。结果接入现有七站页。累计热量和跨流态任务继续后置。
