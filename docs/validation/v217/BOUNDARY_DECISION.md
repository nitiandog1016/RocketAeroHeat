# v217物理外边界设计决定

采用固定Eilmer5已有的`InFlowBC_Supersonic`和`OutFlowBC_SimpleExtrapolate{xOrder=0}`作为**满足条件后**的外包络入口/出口候选，不采用SimpleFlux封堵或短后体p∞。当前只选设计，没有生成或运行网格。

实际固定源：入口将给定FlowState复制到ghost和边界face；出口的非结构分支只支持零阶复制，xOrder=1抛Error，face采用CopyCellData。不能从官方文档的一般选项推断本固定非结构实现支持线性外推。当前实/复数气体/输运身份和SA设置仍须显式传给新配置。

依据：[Eilmer v5参考手册](https://gdtk.uqcloud.net/docs/eilmer/eilmer-reference-manual/)第5.2.1与5.3.2节，超声速定值入口和外推条件；手册明确提醒亚声速外推可能不物理。[NASA Glenn CFD Analysis Process](https://www.grc.nasa.gov/www/wind/TFAWS2007/CFD-Process.pdf)第5、6、7页要求外域范围与波传播、网格和边界/区域接口共同考虑。本轮用固定源码核对实际动作，文档不替代运行验证。

v216圆截锥连续候选总体积3458.1555m³，原方盒381.5375m³；外增3076.6180m³。体积本身不等于单元数或内存。为让原六个方盒面与新六平面直接对应，**本轮优先选择同40°侧法向的方截锥设计**：前X3.2161519312m、后X−8.8727918394m、前半宽3.0222359426m、后半宽13.1660642018m。原前后边界均留0.1箭长外壳厚度；原所有壁、层、尾缘、流体单元保持。这个选择解决面片对应问题，并不宣称体积更小；总体积反而为3582.6811m³，外增3201.1437m³。

定义s=(x−xmin)/(xmax−xmin)，X=back+s(front−back)，H(X)=Hfront+(front−X)tan40°，Y=yH(X)/H旧、Z=zH(X)/H旧。该连续映射把原方盒边界映到六平面；四侧初态法向Mach为−3.0201（±Y）、−4.3301和−1.7101（±Z），前后−4.6985/+4.6985。实际生成的三角形法向、闭合/无交叠、原旧面一一配对和体单元正性仍未验证，不能把连续映射证明当作离散网格证明。

组合拓扑账：原6572个外三角若每个用一棱柱连到对应新三角，理论壳层6572单元、23002面、6576点、13144两侧ghost、9858内部面，固定配置必要payload378319594字节/0.352338GiB。**一层并非已验证分辨率，该下界也不包含分区调整、临时对象/GC/I/O/完整峰值**；没有据此放行8GiB。后续网格须复用成熟工具并验证实际计数/质量，不能直接把组合账当可运行网格。

局部母面/全壁距及接口要求：旧单元/面ID保持；新增实体使用独立后缀ID并记录新母网格身份，不能与旧编号混淆。原6面从物理外边界变成原域—外壳内部接口；区域切面应延伸到外壳，不能将原侧面留成假定p∞边界。各区域SA壁距仍参照全19752原壁，不能只用局部壁。

物理验收合同：入口内侧和给定态必须均满足相同相态/物性域、实际局部法向Mach<−1；出口必须法向Mach>1。给定态满足不代表发展场满足，任一回流/亚声速或显著扰动到入口均拒绝当前简化条件，不自动切封堵/裁状态。均匀M5的Mach角约11.537°，20°流向加40°侧面只是初态几何裕量；强激波、黏性影响和尾迹可能超出该线性波估计。必须规定独立外域敏感性，核对原面p/q、尾迹、外域梯度及有符号守恒，不能只看面值有限或出口正流。

结论：成熟边界动作和一个可离散实施的几何方案已明确，**物理边界资格、离散网格和峰值仍false**。先完成有限的完整数值参考决定，再另登记实际网格/生产调度/真实候选预算。无无限外域扩张或逐尺寸试错准入。
