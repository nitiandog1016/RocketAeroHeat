以原NIST固定组分值为待测值：rho及a相对偏差≤1%；Cp、Cv≤2%；统一焓零点后的H、E差除以max(Cp*T,1 J/kg)≤1%。焓零点为每个参照自身的p=1Pa/T=298.15K状态，既消除任意热化学常数，也记录有限1Pa残余，E使用同一焓偏置而非单独重置。不把近零焓当分母。
