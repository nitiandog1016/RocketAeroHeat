# 返回 M0.30 单点的内部亚声速外流入口

实际接口在 M0.30 的第一个缺项是模型自身的压力和边界层外缘状态。NASA 平板的 22 个测站已经给出局部换热公式在强制转捩、近零压梯度下的偏差，实验资料核对到此结束。[测量与程序对照](RESULTS.md)

下一项在现有单工况调用链中，针对冻结的 M0.30、5 km、零攻角、300 K 壁和原 9,216 面，检查并接通可由程序内部运行的低亚声速全局外流候选。先定位正常入口的实际分派、该分支支持的物理条件、现有网格及外域边界。通过独立动量核对的候选才能交付计算压力或外缘。若选用无黏外流，只检验其附着区职责，明确肩后、尾迹、平底等仍需黏性信息的位置；若选用黏性支路，须先说明怎样解决 v359 已实测的两项摩擦误差和 ω 残差失败。已关闭的原输入组合不续算。

数值运行前单独登记固定输入、同类型动量独立对照、原残差及资源上限。核对同一原面号上的压力、外缘速度/温度、方法和适用区域；未取得的量保持未知。任何后续热流对照使用本次实验实际支持的条件。只有同一飞行工况全部原面同时有适用的压力、热流和可复核面积积分，才开放最终结果页。若本机没有可进入试算的候选，记录具体缺失输入和失败条件，保留现有飞行表。
