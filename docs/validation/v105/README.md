# v105证据说明

本目录保存内嵌SU2的真实运行证据；结论与限制见[阶段说明](../../EMBEDDED_SU2_V105.md)。`delivery_manifest.json`绑定准确源版本、5项MATLAB任务、5项SU2进程和独立读取比较，全部任务终态。引擎与主流程成功不代表完整箭体物理资格。

- `cases/`：3次平板运行、故意错误配置和1秒预算终止的配置／进程／日志；有壁面VTK的任务保留原输出。
- `processes/`：MATLAB真实终态及其全源码锁定记录。全源码锁定不意味着每份源码都实际参与该任务；阶段清单仅列相关项目文件。
- `inputs/plate_mesh.su2`：本程序生成的80×64单元体网格，3次平板运行共用同一几何字节；其他小型输入可由绑定源码生成。
- `source_versions/`：SHA命名的准确字节。一个中间版研究入口由相邻版本改回`.vtk`后与原进程预先记录的完整SHA一致才归档；没有以当前源码代替旧运行源码。还保留失败的XML读取器、错误Tw断言和修正前JSON序列化脚本。
- `plate02_audit_final.*`、`plate03_audit_final.*`：最终独立参考比较，明确原始流体节点温度。早期无`_final`后缀的审计为过程记录：其CSV温度列名误写Twall；plate03早期JSON还有非标准NaN。使用最终文件，不能根据旧列名把节点温度当给定壁温。
- `contracts/report.json`：缺失热流／截断拒绝、负热流保留、温度身份，以及实际配置失败和超时终态。
- `upstream/`：固定版官方配置／相关源码，保留版权声明；许可证在`third_party/su2/COPYING`。第三方源码是参考，不是本项目原创计算核心。
- `runtime/`：实际安装清单与help输出；引擎ZIP／EXE不上传。清单绝对路径是本机证据，不要求其他机器使用相同盘符。

本地 `outputs/v105_validation/` 另保存体场restart、MAT及完整迭代历史。它们未随GitHub上传，不能宣称已备份。此批共约12.55MB；运行时含下载包约55.09MB。保留当前最小独有结果，无需再生成工程包，也不改动之前共享对象库。

复算先运行安装脚本，再使用MATLAB研究入口生成新目录。独立审核脚本只读旧数值并写新报告；不要覆盖旧进程回执。绑定脚本故意拒绝覆写已有交付清单，复核可按清单逐项SHA读取；不得删除清单后冒充新运行。原MATLAB日志中的中文乱码来自原进程编码，按原字节保存。

没有本版浏览器验收或主工作台SU2流程声明。前缘、网格／外域、公开实验、完整三维箭体、突起／分离／底面和表面映射均仍需下一阶段工作。
