- `cases/`：官方常量、受控常量、空间表的真实配置/终态/壁面VTK；三项均20步，没有重跑原绝热3000步。

- `build/`：固定上游/依赖/工具下载来源、SHA和配置；源码原文/补丁保留在`source_versions/`和`processes/`。没有上传运行时二进制。

- 两份`audit_*failure.py.raw`为真实失败审核版本；首次距离口径错误、随后CSV列名假设错误，仅修复审核并重读原数据。`build_compile02_source.py.raw`等保留构建失败时监督器源码。
