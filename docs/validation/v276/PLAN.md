# CM-011 低速试件的独立 STL 剖分

基线 v275 提交 `a7990930f22b3c824353e2424d675de276f33649`。冻结 +10°、0.1 m/s、300 K/101325 Pa 空气、300.1 K 给定壁温和原 12D 三维半域。旧 STL 92ca7196… 及 v275 的正常终场作为比较源。旧精确匹配路径先回归，要求保存的网格输入、编号映射和旧回读一致。以同一公开缩比外形的轮廓另外采样不同数量、不同方位和母线位置的顶点，并独立连接三角面。保存新 STL 的原始顺序和完整分母。

新剖分需核对闭合、连通、正确定向、以试件内部点为中心的径向覆盖、尺寸和轮廓。顶点到名义母线的允许距离保持 5×10⁻¹⁰ m，面心和边中点到母线的抽样偏差上限 5×10⁻⁶ m。后者限制三角平面对光滑 CAD 的逼近误差。用 97 个固定极向与 48 个均匀方位和实际 STL 三角面相交；核对周向半径极差、唯一交点和正半径。平均半径建立实测母线，每隔一站取实际体网边界。每个导入顶点按实际方位和母线线段上的连续坐标映射。面区域按其顶点的平均母线位置记录，跨区面单列。

几何生成/复核每次预算 60 s、1 CPU、1 GiB、32 MiB。新增算例从五步主工作台点击计算，求解前记录 STL 和预检查网格指纹。沿用 SU2 8.6.0 原配置 f93b190b…，最多 12000 步、720 s、1 线程、2 GiB、160 MiB；整批 MATLAB 限 450 s、4 GiB、160 MiB。保留初场、原生终场与检查点，五分量最近 20 步最大 log RMS <−8、壁热相对极差 <0.2%，检查正压、无滑移和对称边界。用缓存的低速观测内核和官方单步各 30 s/1 GiB 核对同阶段边界收支，差额绝对值小于壁功率的 0.5%。

按每份 STL 自己的真实面积独立积分，检查每一个面的方法、编号与字段、截面和导出。两份剖分在四个预定内部母线位置（原求解站 3、14、29、41 的实际 x）和半周 13 个方位比较，固定 x 并记录实际半径差。事前数值比较门槛为四截面最大表压差 2×10⁻⁴ Pa、热流差 0.15 W/m²、各自原三角面总功率相对差 <1%。截面离散读数和求解节点插值分列。没有匹配实验时保留实验精度未知。

原剖分回读、旧错误输入和重排测试已通过。第二份 STL 有 5042 个顶点、10080 面，字节 SHA-256 为 8931b619…，最大顶点轮廓偏差 1.369×10⁻¹⁰ m，最大面片抽样偏差 3.023 µm。独立预检的体网为 d3dc043b…，初场 9dfe539f…，4656 条径向读数给出最大方位半径极差 3.889 µm。主工作台从此文件开始一次实际计算。
