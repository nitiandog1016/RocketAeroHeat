# 下一项：在同一 CM-011 工况上比较两种离散得到的全壁热流

12D 与 20D 的原生壁面与远场仍相差各自放热的 7.90%、7.35%。同阶段读数已核实，继续读取同一组轴对称快照不会增加对壁热精度的认识。[定量结果](RESULTS.md)

下一项限一次同工况三维对照。沿用 CM-011 低速等温试件的母线、给定壁温和 12D 远场，先核实可用内核是否支持具有真实体积、轴线处理正确的三维旋转扇区及其对称面、等温壁和原生能量通量。核对弦面与旋转面积的换算、对称面净通量、输入身份和能否返回到全部 14,140 个原面，再登记网格、资源、停止条件和守恒门槛。采用三维体积和面通量可独立检验二维轴对称源项离散对全壁结果的影响。

验收同时比较各壁区逐面热流、压力、整壁功率和远场流出，按相同方向和相同面积给出差值。工作台接入同工况结果并保留两种算法的来源。如果实际内核、几何或本机预算不能满足上述条件，记录具体阻断并结束该对照。对照完成后带着实测的壁热敏感性回到单工况全表面交付。该试件的周向对称性、给定壁温及缺少同工况实验的限制继续随数据保留。
