# CM-011 低速等温试件的同阶段边界能量账

基线 `3068d9b9a6717a947709a0a82ea13cd49e37f914`。固定 v271 的 `fine02`、`outer02` 两个正常终场，原生 ASCII 重启动 SHA-256 分别为 `50745a4193f291386f8d6b25351ddd2e97f57a0162706b28610ab787a448b56b` 和 `5726ef71515a0f7c08d3a290e971555a9ef64b093166cb2dbf407381dfb64863`。原回执内绑定网格、配置、终场和物性。只研究原来的定物性不可压层流、等温壁及轴对称远场。

原 VTK 只保存节点压力、速度、焓、温度、热物性和诊断壁面热流。原始源程序在远场残差组装时分别加数值对流通量和减黏性通量；壁面残差在强边界调用中更新。按向外取正，保存这些调用实际产生的质量与能量项，并按同一控制体的 2πr 权重还原为功率。对流焓参考扣除使用同次计算的远场焓和同次质量通量；同时保留扣除前的量。分列内边、轴对称源、壁面和外边界贡献。同次观测的流体状态和旧存档之间先作核对。

只在独立目录编译只读观测，核对 SU2 固定源码包及活动源码。复用构建缓存，隔离替换最多两个对象、链接一次，不改共享源码、库或安装目录。每对象最长 120 s，链接 60 s；各进程上限 3 GiB，新增文件上限 200 MiB。两个旧终场各用 1 线程、最多一次迭代，分别对照官方程序与观测程序。另在细网对比观测开关的输出不变性。单次 30 s、1 GiB、20 MiB；保存输入场和正常终场。官方与本机构建的更新后原生 p/u/v/h 最大绝对差须小于 2×10⁻⁷，观测程序开与关要求重启动输出字节相同。跨版本或阶段数值不符则止于诊断；不续算收敛。

离线审核限单进程 60 s、1 GiB、10 MiB 输出。按原面温度、壁面读数、远场状态和完整通量重新组装。各阶段差分的热功率加总检查精度为 10⁻⁶ µW。7.429 µW 的分解与全离散能量平衡各自报告。没有新的物理验证面积或自绘模型计算面积。

在已有热流视图上显示核实的边界功率及内部项。显式提供的观测要与网格、配置、原生重启动、体场及壁面文件逐一吻合。用细网保存场走 MATLAB 原入口，另查错配、损坏及未提供观测的旧用法。集成回读限 90 s、单线程、4 GiB、24 MiB；不推进流场、不操作浏览器。
