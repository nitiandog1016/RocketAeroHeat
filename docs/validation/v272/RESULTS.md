# CM-011 低速试件的全表面热收支

同一细网终场上，试件壁面向空气放热 **112.677 µW**，远场向外输送显热 **103.777 µW**，两处相差 **8.900 µW（7.90%）**。此前用节点重建得到的 **7.429 µW** 差额已逐项复算。两种读法都显示壁面放出的热多于远场流出的热。离散方程的内部面和轴对称源项解释了这笔差在装配中出现的位置；壁面热流的实验精度仍待验证。[12D 原始账](evidence/fine02.json) · [20D 原始账](evidence/outer02.json)

本例采用源自 Apollo CM-011 图纸的独立光滑缩比试件，直径 3.949 mm，来流 0.1 m/s、300 K，壁温给定为 300.1 K。工作台上的三维场由零入射轴对称解沿周向展开。**14,140 / 14,140 面**均有该工况计算的压力和热流，三角面合计入壁功率 **−112.632 µW**。负号表示热从试件流向空气。自绘模型的同面工程覆盖仍为 **0.846754 / 1.964629 m²（43.10%）**，本轮新增 0 m²。NASA 飞行量热资料对应另一套工况。[本机工作台](../../../outputs/v272_validation/workbench01/workbench/index.html) · [试件几何与运行条件](../v271/RESULTS.md) · [飞行资料的适用范围](../v270/RESULTS.md)

## 同一次残差装配的读数

下表的壁面列均以壁向气体放热为正，远场以向外为正，单位为 µW。12D 和 20D 表示外边界半径与试件直径之比。各值保留六位小数，完整精度见原始账。

| 热功率 | 12D | 20D |
|---|---:|---:|
| 原旋转壁面积分放热 | 112.684849 | 112.691363 |
| 原远场节点重建 | 105.255674 | 105.966143 |
| 原生等温壁放热 | 112.677172 | 112.683695 |
| 远场原生显热对流 | 102.100169 | 103.443257 |
| 远场原生导热 | 1.676607 | 0.954121 |
| 远场原生总显热流出 | 103.776776 | 104.397378 |
| 原生壁面和远场的差 | **8.900396** | **8.286316** |
| 差额占各自原生壁面放热 | **7.90%** | **7.35%** |
| 内部面增量，含黏性 | −151.108050 | −176.953873 |
| 轴对称源项增量 | +160.008446 | +185.240189 |

壁与远场取自同一初态的同一残差装配。按各节点的旋转面积权重汇总，12D 的远场原始对流焓通量为 914.689101 µW。其净质量通量为 −2.715599×10⁻⁸ kg/s，携带的参考焓通量为 +812.588932 µW。相减后得到相对来流的显热对流 102.100169 µW。导热独立取自同次远场的黏性通量。节点单侧重建、原三角壁积分及原生数值通量分别列账。[12D 远场逐点通量](evidence/fine_far_terms.csv.gz) · [20D 远场逐点通量](evidence/outer_far_terms.csv.gz)

**12D 的旧差额可拆为四项**，均按使旧差额增大的方向记正。

| 项目 | 对旧差额的贡献（µW） |
|---|---:|
| 原旋转壁积分减原生壁边界项 | +0.007677 |
| 原生壁放热减原生远场流出 | +8.900396 |
| 原生显热对流减节点重建对流 | −1.518649 |
| 原生导热减节点重建导热 | +0.039751 |
| 合计 | **+7.429175** |

内部面使用固定 SU2 8.6.0 的迎风残差例程，该例程同时计算边上的黏性通量。原始观测中的阶段名 `convection` 指该例程完成后的快照。内部面与轴对称源项加总为 +8.900396 µW。将这两项、向外远场项和负的壁面放热项相加，12D 全装配显热余量为 8.30×10⁻¹⁴ W，20D 为 2.20×10⁻¹³ W。这证明对已保存的离散方程逐项读数相符。若只考察试件与环境交换的热，两个边界之间仍有上表中的差额；单凭这次装配无法把它定为某个局部壁面热流的误差。[观测与复核代码](check_flux.py) · [SU2 内部面实现](https://github.com/su2code/SU2/blob/v8.6.0/SU2_CFD/src/solvers/CIncEulerSolver.cpp) · [SU2 等温壁实现](https://github.com/su2code/SU2/blob/v8.6.0/SU2_CFD/src/solvers/CIncNSSolver.cpp)
