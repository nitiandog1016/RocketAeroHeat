# NASA Lewis 光滑圆柱的低速横流换热测站

基线 v277 提交 `6c9c43642730aa4adfbdee46d382b7e31f760bdb`。只使用 NASA TM-83557 图 9 的光滑、低湍流菱形测站，Re_D = 177000，D = 0.066 m，试件跨度 0.152 m，铜带轴向长 0.066 m、周向宽 0.0051 m。原 PDF SHA-256 为 `48f470f84a8d7ed11e9c3f4739f98ef119db5c39eec41869e6fde693e13967ea`。六个名义中心角来自表 III。读图用二维仿射标定消除扫描倾斜，保存像素、各站不确定范围、标定残差及原图。独立第二次按更高分辨率、不同刻度和符号上下边界复读。两读差超过 10 Nu 或归属不清时逐站标明。表 III 的回归值仅作同源读数交叉检查。

预测采用 Frössling 的圆柱空气四次截断式，NACA TM 1432 印刷第 20 页，原 PDF SHA-256 `8ee923bb4d35c5885a472d93cfe1ffc740c04e3d3401f64def7022e756d889d3`。该式使用 Hiemenz 在 Re 约 19000 的原外缘速度分布；比较时只代入试验 Re，单列外缘假设。用 x = θ(rad)/2，逐个在带宽上积分并与点值分开，完整计算六站的有符号相对差、RMS 和最大差。报告公布的是全体数据平均误差 5.7%、最大 7.8%，仅列与这两个尺度的关系，不据此给每站分配误差条。用独立数值积分核对闭式积分到 1e-8 Nu。试件基准限光滑低湍流空气、迎流驻点两侧 ±55°、中央测带跨度。绝对热流、绝对压力及固体温度缺少工况输入时保留未知；实验值不计入预测字段。风洞侧壁相接的两端面单列。

MATLAB 单计算线程、120 s、4 GiB、16 MiB 新输出；方程为直接计算，无 CFD 迭代。独立数据和绘图核对各限 45 s、单线程、1 GiB、16 MiB，文献原件及页面图像另计。使用既有 WebGL 和同窗测站对照，导出原面与方法；逐面复算区域和积分，变更前后的既有工作流及并发文件保护清单照旧。来源、投影、单位或字段身份不符时保留回执并停止相应验收。
