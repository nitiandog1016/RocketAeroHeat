# 下一项回到可输入边界条件的全周壁面计算

结束光滑圆柱图 9 的六站读图和 Frössling 前部公式对照。该角域和跨度下已经有可运行的预测及实测差，重新拟合六个数据点不能给出背面压力、热流或绝对热功率。[本轮结果](RESULTS.md)

下一项对同一 **66 mm 光滑民用风洞圆柱** 建立一个明确定义热边界的单工况，目标是在完整暴露侧壁上计算和显示有量纲的压力和热流，保留前部、背面尾迹影响区以及临近两个安装端的区别。沿用已测量的直径、跨度、风洞尺寸和低湍流横流身份；把由用户或算例给定的来流热力状态、壁温单列为新研究工况输入。优先沿用 Re_D = 177000 作周向 Nu 对照，先核对可支持的转捩、尾迹非定常和侧壁条件，再确定一次有预算的求解。若需要时间平均，注明统计时窗及波动，和冻结输入时刻分别显示。

验收要求为同一几何分母上的同面压力与热流面积、各区热功率、逐面算法和不适用原因。已有六条实测铜带继续用于独立局部比较。背面与端部须由适用方法给出；同一侧壁上的给定壁温、计算热流、实验换热系数和未知固体温度各自保留。优先交付带明确热边界的求解能力；当前 55° 外的缺口继续计入总面积，单独汇总平均换热系数不能完成该里程碑。
