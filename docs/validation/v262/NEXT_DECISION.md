# 回到有实测热流的连续流区域验证

v262 已将静止空气的气体温度、压力、给定壁温、实际反算方法和源帧接入工作台。后续新增壁热需要能区分局部位置的验证数据。下一项选择**空气横向流过加热圆柱的一个公开低速工况**，检验工程传热方法在不同周向位置的适用范围。选这个基准是因为局部换热和整周平均可以分别比较，气体温度正确也无法替代这项验证。

首先核对 Sanitjai 与 Goldstein 2004 年原实验里的一组空气数据。已查实论文题名、作者、页码及 DOI。具体壁面条件、试验不确定度、角度定义和可读取的局部测量仍待核实。[原论文](https://doi.org/10.1016/j.ijheatmasstransfer.2004.05.012)

只选一个可追溯工况，保留原始测量单位并区分局部与平均 Nusselt 数。在方法与边界相容、局部测量可复核时，再登记一次匹配的计算及误差比较。若仅能取得平均量或缺少关键边界，明确该数据可验证的量和仍缺的输入。已有静止空气和工作台测试继续复用。该基准的适用范围为所选圆柱与工况，实际箭体的全面积资格单独验收。
