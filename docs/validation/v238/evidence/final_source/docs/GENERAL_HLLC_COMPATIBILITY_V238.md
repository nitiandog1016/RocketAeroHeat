## 1. 已完成的有限修正

原SU2一般EOS HLLC星态Jacobian四处密度压力导数写为 `Chi - 0.5*Kappa*|u|²`。按守恒变量固定动量和总能量求导，`Kappa=p_e/rho`、`Chi=p_rho|e-Kappa*e`，得到 `dp/drho|rhoU,rhoE = Chi + 0.5*Kappa*|u|²`。本版只将两侧各两处改为加号，不另写通量或通用Jacobian。

准确原源SHA为 `7c389cbbf8c48f31e7d45d5cc56a19f0d2e58c98e0cef9fe8b531dbb67e4f1eb`，隔离修正源SHA为 `7c24f260e9116379e21d91ba9486a6aee26c69378ba7209841d452f44386ff6d`。路径重定位与数值四符号修正分别可见[准确补丁](validation/v238/evidence/repair01/hllc_pressure_derivative.patch)。旧ROE包与原引擎源保持。

原/新各24次原生调用、6类控制、3类非法输入拒绝。原亚声速一致态总Jacobian的最大缩放误差0.10452649095，超过原5e−9阈值；修正后全部适用控制最大误差2.8421709430e−14。包含一致态Euler解析通量/总Jacobian、接触通量、左右反法向成对通量、适用的成对Jacobian及物理能量坐标变换。

首审核额外要求静止接触`sM=0`切换处两种单边Jacobian相同，这一数学前提不成立。原失败保留，恢复审核单列不可微分支差异；原计划成对通量及其他阈值不变。**不声称所有非一致态近似Jacobian等于精确残差导数，也不声称HLLC严格保持相态联合域。** HLLC内部仍使用Roe平均。
