## 默认生产能力的边界

本阶段不改变默认生产物理或网格方法。既有M5/30km/α20°/Tw300K真实例子：表面压力工程计算50.2710%/给定49.7290%，外缘p/T计算95.5150%，热流与恢复温度工程计算66.5626327424%，输入Tw100%/求解Tw0%。条件模块不加入这些面积。

所有计算面积是现有工程方法的应用统计，仍需各方法适用性与独立验证；全模型可显示、数据合同完整和测试通过均不等于全面积求解完成。累计热量和长时程目标继续后置。

## 下一步采用的具体路线

当前不再扩写球鼻制造场或继续比较许多并行求解框架。先落地**一个受限贴体子午面轴对称有限体积区域路线**：

1. 读取已固定公开网格，建立真实轴对称体积、面积矢量、轴/壁/外域/接口标签；用几何恒等式、常场和轴对称源项独立核对，避免把平面二维格式直接当轴对称。
2. 接入单一完整守恒推进与黏性/导热壁通量，先通过局部控制体能量/质量账、壁热符号、已知层流基准及网格/边界敏感性。复用现有HLLC和气体库前先核对其网格及状态合同，不把标量重构库当完整NS求解器。
3. 只选择一种有明确版本和入口参数的湍流闭合，再按TMR原几何/实验参考比较表面p、q、入口剖面、分离/再附及不确定度。入口未知量保留为待确定/敏感性，不能凭空补成测量。
4. 以真实箭体入口合同同步约束区域接口，明确连续外流、横向动量、熵层及法向u/T/湍流剖面的缺项。轴对称零攻角外扩基准只验证自己的范围；向真实20°横流—收缩—后体扩展需要另行三维和边界验收。默认结果页只接收已验证适用的区域，不涂抹研究场。

对真实复杂箭体保留已有闭合参数化模型和突起对照；先检查鼻尖网格质量及特征保留。科研UI与区域求解保持并列优先，每个可验证区域立即接入五步骤工作台，不以长时程或更通用CFD为当前交付前置。总目标仍未完成。
