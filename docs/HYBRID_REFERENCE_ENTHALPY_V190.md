## 1. 实际改变的算子

`airReferenceTemperature.m`按[Riley NASA-TM-107838附录H.6/H.7](https://ntrs.nasa.gov/citations/19920016036)使用：

\[
h^*=0.5(h_e+h_w)+0.22(h_{aw}-h_e),\qquad h_{aw}=h_e+rU_e^2/2.
\]

用同一NASA7/低温冻结焓模型反解T*，再计算参考黏度/密度。46次二分及独立焓残差检查不裁温、不扩80—2500 K原范围，端点无效即拒绝。`cfg.heating.referencePropertyModel='linearTemperature'`明确复现旧温度式；定cp极限保持原式。保存实际参考焓、参考温度和方法身份。

接入`calcBoundaryLayerState.m`和`calcSurfaceHeating.m`。新热流仍由既有Thwaites/Head、转捩和Reynolds比拟得到，分离/物性/稀薄/鼻尾端的拒绝合同保持。热流总方法和层流方法均包含参考焓身份。未重写完整三维边界层或CFD内核。

必要的兼容改动只覆盖旧功能与新算子相接处：`evaluateWallConvection.m`用dT*/dTw=0.5cp(Tw)/cp(T*)更新导数；`calcWallThermalResponse.m`与`calcFlightHeatingHistory.m`构造同一参考基准。没有referencePropertyModel标记的历史law仍按旧线性参考温度。累计热量和轨迹仍后置；本轮没有跑新全轨迹测试，不把入口兼容改动称为全周期验证。

## 3. 新Euler准备器及外缘交换

`scripts/prepareHybridEulerCase.py`生成全新、有限的3D挤出控制：M3、p5000 Pa、T300 K、来流−X；s=0.2 m开始10°压缩，s=0.6 m回转10°，长1 m、宽0.04 m、顶部z=0.6 m。它是二维流动的三维网格控制，不是真实20°箭体。

实际2400六面体/3843顶点/8560唯一面/2720外边界面，壁面120四边形/240三角面；六四面体独立分解全正，体积0.022307260985198734 m³与解析值相同，外边界完整配对。生成SU2网格、surface.json、gas.inp、grid.lua、job.lua及绑定清单，未运行prep-gas/prep-grid/prep-sim或CFD。

具名配置为固定Eilmer5热完美伪空气、无黏/无湍流、AUSMDV、二阶、TVD RK3/局部伪时间、CFL0.3、400更新/200检查点设计。首次离线检查后的边界复审发现顶部来流法向Mach=0，已把顶部超声速全状态入口改为原生Ambient进出流边界；最终采用interface02/control，补检查通过，首次输入保留。与旧Wilcox完整域不同，旧准入不适用；生成Lua不能证明原生API/实际配置有效。400是预备输入，不是已批准运行或通用收敛时限。

`scripts/hybridExternalState.py`接收显式逐原面映射帧，绑定几何/工况/气体模型、原始源文件SHA和帧序号；逐面核对同EOS的rho/e/h/s、h=e+p/rho及含三分量动能的h0。物性计算由明确的模型回调提供；本轮使用独立理想气体合成真值检查，**生产Eilmer物性回调、原生读场和真实壁面采样尚未接入**。17种过期源、错误模型、重排/缺面、温域、能量等输入被拒绝。

成功输出仍是`engineeringHeatReady=false`、`attachedEdgeQualified=false`、`physicalQualification=false`，q和求解固体Tw为null。Euler面状态还需要边界层外缘定义/采样和适用性判断；不能直接写入旧NASA7外缘对象。Eilmer CEA伪空气和工程N2/O2/Ar NASA7的系数、能量参考及输运不同，名称“空气”相同不足以传递资格。合成source文件在最后一项拒绝测试中被故意改写，原字节以original别名保存；此前成功交换不能当作当前仍有效的生产帧。
