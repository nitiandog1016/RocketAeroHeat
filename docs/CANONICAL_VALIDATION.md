# 经典模型校核（v45）

本文保留 v45 基线及当时发现的问题；小角度切锥和半球头柱体断带已在 v46 修复，最新结果见 [WEAK_CONE_FIX.md](WEAK_CONE_FIX.md)。

本轮增加可重复的经典几何与完整工程链路报告，并修正球头局部半径识别。它没有完成全表面气动热验证，也没有新增实验对比或尾迹关联式。默认科研 WebGL 工作台保持 v44 的样式和交互。

## 运行

在项目根目录运行：

```matlab
report = runCanonicalBenchmarks(fullfile(pwd,'output','canonical'));
```

默认计算五种几何 × 两档周向分辨率（24、48）× 两个攻角（0°、20°），共 20 个工况。每个工况直接经过面几何、法向、曲面坐标、局部几何、内部外流、轴向推进、准流线和热流模块，不通过外部 CFD。生成 `report.json`、`report.mat`、中文 `report.md` 和细网格离线 WebGL 子目录。网页导出查看方式见 `WEB_WORKBENCH.md`。

若只运行某一工况：

```matlab
options = struct('kinds',{{'hemisphereCylinder'}}, ...
    'resolutions',48,'alphas',0,'exportWeb',true);
report = runCanonicalBenchmarks(fullfile(pwd,'output','hemisphere'),options);
```

## 几何与工况定义

`buildCanonicalBody` 生成 sphere、cone、coneCylinder、hemisphereCylinder、bluntedCone；球头钝锥与圆柱相接。默认半径 0.1 m，柱长 0.4 m，锥半角 15°，钝锥球头半径 0.04 m。纯尖锥没有柱段，球体直径 0.2 m。轴向和周向细化由同一分辨率控制，周向点数随半径减少。输出独立的解析面区域标签及精确面积、体积。此模块不修改现有 STL 网格算法。

默认工况 M=4、海拔 20 km、侧滑 0°、给定壁温 300 K。球头半径作为已知几何输入给驻点模块，但局部分布仍必须通过球形网格检查。没有求解材料壁温历程；报告中的 wallInput 是边界条件。

模型同时提供原生截面和环带拓扑。最终试跑中，零攻角尖锥、锥柱和球头钝锥采用轴向波系推进；球/半球头柱体缺少直鼻锥平台，保留局部外流。有攻角时不启用轴对称推进。JSON 中保留 `axisymmetricMarch`、`noseRadiusEstimate` 和 `streamlineSummary`，可核对每个工况的实际路径。

## 已验证与尚未解决

`testCanonicalBody` 检查全部五种几何的闭合、两侧边方向、Euler 示性数和面积/体积收敛；48 档最大面积误差约 0.421%，最大体积误差约 0.796%。这证明几何逼近改善，不证明热流收敛。

半径识别原先固定取最多 24 个轴向截面，半球后接柱段时容易把柱段带入球拟合。现在向内搜索连续鼻端前缀，至少六圈、三个嵌套尺度，保留原有残差、轴线、极点、半径一致性和最小物理深度条件。回归检查球/半球/球头钝锥，尖锥与横向拉伸的非球形模型仍被拒绝。过稀球头继续拒绝。

20 个工况已完成实际链路试跑。修正后半球头柱体 48 档零攻角的**鼻部**热流覆盖从 62.33% 提高到 86.93%；其全体覆盖仅 15.76%，因为柱段仍未连通。不能把鼻部改善推广为整模型已解决。

需要优先处理的失败证据：

1. 半球头柱体零攻角，24/48 档全体热流覆盖约 82.17% / 15.76%，柱段准流线连通性有明显网格敏感性。
2. 锥柱 20° 攻角，48 档热流覆盖为 0%；约 68.34% 面积被疑似层流分离及下游规则阻断，另有流线断连和几何限制。必须检查外缘速度、种子位置、路径与梯度，不能删除分离判据来提高覆盖率。
3. 粗球头钝锥的球面圈数不足以确认局部球头，仍有鼻端模型限制。
4. 所有底面热流仍缺少专门模型，底压仍是给定边界。球后部、肩部、分离再附等区域没有因为加入报告而变成已验证解。

下一步先用这些可重复失败算例修正准流线路径及沿程外流一致性，再引入有来源的区域关联式。不得靠扩大 Kn 阈值、重新播种下游或平板热流覆盖未知区来伪造完整解。

补充诊断：半球头柱体 48 档零攻角，在每条共享边上取 41 个候选穿越位置，保持原有两侧流向条件，仍得到 4990 条有向边、零个连通柱段面元，与边中点法相同。因此不能把本算例的断连简单归咎于中点近似；后续先检查无效外缘带和种子连通分量。此诊断未改变生产求解器。

进一步定位到 x≈0.4065 m 的第 32 环带：96 个面元均没有有效外缘，其上游第 33 环带 94 个面元全部连通，而后方柱段被隔断。独立调用变比热切锥求解器，在 M=4、20 km 下，3°、3.5°、3.75°、4° 均未找到弱解，4.5°、5° 则有解。下一次优先检查小半锥角、接近 Mach 波的弱支扫描/激波跃迁数值；当前“未找到根”不能被解读为真实脱体。诊断明细见 `validation/v45_crossing_diagnostic.json`，发布包另含小角度求解日志。
