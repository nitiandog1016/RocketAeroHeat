## 3. 压力模型不是实际箭体：几何、测点和支撑

打印4/PDF5和Fig4（打印18/PDF19）已视觉核对：

- 压力模型为钢制等直径圆柱，直径 **0.5 inch = 0.0127 m**，名义约10 inch长，后端悬臂式支撑。测站约距鼻端5 inch；不是无支撑自由飞行模型，也没有大圆柱—31°收缩—小圆柱组合。
- 同一测站有6个孔，孔径 **0.030 inch = 0.000762 m**，周向每60°一个。模型可以绕轴转动，从而测得多个周向位置；不能把6孔误解为只有6个最终周向测点。
- 使用与设计攻角相配的斜切端帽，使端面与来流平行，以减小端部效应。额外10°和30°锥鼻端只在约15°试验时用于比较鼻端形状；这些端帽不是当前箭体前体、肩部或收缩段。
- Fig4明确给随名义攻角变化的图示X尺寸。精确转录见 `penland_geometry_x.csv`：15°为2 15/32 inch；30°为1 1/2；45°为1 3/32；60°为29/32；75°为3/4；90°为5/8。**X是原图标注的尺寸参数，不能直接把这列当成鼻尖到压力孔的距离。** 后续建模须按原图各段尺寸和端帽几何恢复，不只设定固定5 inch测站。
- 量测和绘图都采用关于圆柱中心线的压力对称假设（打印7/PDF8），因此原图两侧对称不能当成独立量测的完整三维场证据。

力模型是另一组几何：6根0.5-inch直径圆柱，投影长度均4 inch，实际长度约4–15.41 inch，几何中心由支杆支撑；端面按名义攻角切割。不能把力模型的长度和中央支杆结构拿来复现压力模型。另有5/16和5/8 inch的90°圆柱用于长度/直径敏感性，亦不与主压力系列混同。

## 4. 压力和横流参考量：必须使用正确分母

打印2–3/PDF3–4定义压力系数：

```text
Cp_global = (p_c-p_inf)/q_inf
q_inf = rho_inf U_inf^2/2
beta = 绕体轴从当地迎风驻点量起的周向角
```

原图用 `Delta p/q` 标注，分母是完整自由流动压。β=0是圆柱迎风母线，β=180°是其背风母线；它不是沿X轴的鼻尖，也不是项目几何周向角的固定零点。项目比较须用来流在法截面的投影确定同一个迎风方向。

打印6及10–11/PDF7、11–12采用横流分解：

```text
M_c = M_inf sin(alpha)
q_c = q_inf sin(alpha)^2
Cp_crossflow = (p_c-p_inf)/q_c = Cp_global/sin(alpha)^2
```

这两个无量纲系数不能混用。Fig15的横流驻点及Fig16的背风压力使用q_c；Fig5/6周向分布使用q_inf。Fig7（打印22/PDF23）是 **迎风母线实测绝对压力 p_c / p_c(alpha=90°)** 与 sin²α 的比较，纵轴不是 `Cp(alpha)/Cp(90°)`；必须按p_inf偏置换算后才可比较，不能把该曲线直接当Cp比。

打印7/PDF8另给“绝对压力等于零”的参考线Cp≈−0.03。由γ=1.4和M6.86得到精确参考值−2/(γM²)=−0.030356642，这只是参考基准，**不是实验测得的真空状态，也不是把背风所有面设置成该值的物理方法**。

## 6. 横流独立性和分离限制：当前20°/M5尤其需要核验

原文打印8及10–11/PDF9、11–12明确：约15°或更低时，压力孔附近激波并不平行于体轴，导致按体轴攻角计算的横流驻点系数偏高。Fig15的异常点原文标作 **M_c=1.74**；改以激波方向计算横流Mach可使该点落到理论曲线上。这是端部影响的证据，不能在项目中随意改有效角度“校准”数值。

虽然α15°换10°/30°锥鼻或斜切端没有测得明显压力差，**不表示鼻端效应不存在**：三者孔附近激波角及离体距离也没有明显区别。作者认为孔到鼻端的距离比端帽形状更关键；α60°时约距端部9个直径的测站，激波近乎平行于表面。横流预测精度还依赖细长比、测站位置和攻角，不能只依据 M_c 匹配。

本项目M5、20°有几何横流Mach约 **1.7101007**，数值上接近原文异常M_c≈1.74。因后者恰好受端部效应影响，**这种接近尤其不能作为当前工况已验证的理由**。按原图实际α14.9°及M6.86重算 M_c≈1.763931，与正文1.74亦有小差异；两者原样分别保存，不悄悄改原数或把报告近似坐标当精确自洽工况。

打印10对高攻角圆柱在本试验范围内Re变化影响较小作描述（约80400–160800）。这是有限范围和高攻角的观察，不能扩成任意Re、任意低攻角或带收缩/再压缩区域的独立性。打印11讨论不同来源的背风结果可能同时含层流和湍流边界层，**没有给每个压力系列已确定的转捩/层流类别**。压力法比较不能同时宣布热边界层、分离再附及温度场已验证。

## 7. 对本项目可执行的后续比较条目

1. 在源工况的等直径圆柱上，按β迎风零点、q_inf分母和实际α复制压力法比较。先核对4个正文锚点，并对Fig5a/5b的本报告实验符号作可复现数字化；未数字化前不报告RMS误差。完整链路需另外审核源低静温条件。
2. 在相同几何/工况下对比当前修正牛顿及候选内部横流模型的迎风、侧部、背风压力和积分；保存计算方法/适用范围。端部、支撑、约15°异常和对称假设均写入误差解释，不能删除不利测点后宣布通用有效。
3. 独立检验带31°收缩和再压缩的几何，求得上游一致的压力、流向、熵和温度。Penland等直径圆柱资料仅是这一求解器的基础形状压力约束，不直接确定收缩出口恢复温度、下游热边界层或全表面热流。

尚未核定的源测点、缺少的逐孔量程及边界层类别继续保持未知。本阶段不创建热流/温度公式，不以压力曲线图补造热场，不改变连续流或物性门限。
