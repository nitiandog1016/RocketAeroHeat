## 发现并修复的兼容错误

- 草稿将RAH棱柱节点交换后传给Eilmer，准备exit0却得到−0.625m³。准确固定源码的wedge_properties要求这里保持原节点序，改为`expect_gmsh_order_for_wedges=false`后四类单元体积分别1、1/3、1/6、5/8m³，总17/8。参考形函数审核仍使用独立转换；没有改网格、取绝对值或放松正性。
- 原来放在Phase的CFL参数没有被原生配置序列化，实际默认为1；改在Global配置min/max/schedule后，最终原生配置和四步日志均为.1。这是API修正，不是CFL扫描。
- 初场dt_local为NaN表示还没计算伪时间步，单列未定义；p/T/rho/能量等仍逐变量要求有限，运行帧dt也必须有限。
- fixture03仍有一个旧true断言，失败源/日志保留，定向纠正后fixture04的独立几何及12项错误输入拒绝通过。没有为此重跑CFD。

## 调用与交付文件
