# v115：原生空间壁温与工作台

2026-10-31。受控 SU2 空间壁温输入已通过实际接口、数值一致性和主工作台测试；三维流场仍未收敛，新增物理资格面积 **0**。本阶段补齐 v114 缺失的逐节点调用器，不代表单时刻全面积目标完成。

## 实现与来源

固定 SU2 8.6.0 Windows 包不含 pysu2。采用独立受控构建 `rah-axial-wall-v1`，在上游已有 CustomBoundaryTemperature 初始化处写入严格 SI 的分段线性 X—Tw 表。没有改变 NS 方程或热流公式；另加遗漏自定义标记拒绝，并修复三个上游头文件相对路径。官方等温/绝热运行时保持原样。版本、归档 SHA、编译器及补丁在[证据](validation/v115/README.md)；本地运行时约19.58MB，仅依赖 KERNEL32/msvcrt。

支持范围：单区、固定网格、SI、MGLEVEL=0、串行 MPI/两线程 OpenMP、一个 wall 自定义等温标记。表需覆盖全部原壁节点，无外推，无缺值回退。轴向温度表不等于任意二维壁面温度分布；周向变化和多区输入尚未实现。

工作台第三步增加“沿X变化的壁温”和两列 `X_m,T_K` CSV 导入，将数值冻结入当前配置。统一标量温度框在空间模式禁用，来源/范围随结果保留。第二步新增复用本程序混合体网格，先核对原面、SHA、体积与完整边界，再采用该网格原参数，重新确认边界；此过程不导入外部CFD场。说明文字现使用真实层数/首位移，经典网格显示24层/2µm。

## 失败与限制

- 首次依赖解压因Meson自身符号链接测试夹具拒绝，随后只排除Meson测试夹具；未排除SU2数值源。首次构建监督器相对路径错误在编译启动前失败。
- compile02在约335.562秒失败，compile03约6.968秒失败，分别为上游头文件路径错误；修复后复用对象，compile04约51.250秒完成。完整失败来源与日志保留，没有从头重编冒充一次成功。
- 独立审核首次把斜棱柱边长误作壁法向距离；核对固定上游 `NormalDistance` 后改为投影距离，并检查5%下限未触发。随后一次CSV列名假设失败；均只修复审核并重读原数值，没有重跑求解器或放宽门槛。
- 首次截图后的侧栏点击遇到窗口状态变化，未计成功。第二个MATLAB任务只复开同一快照，已实际检查边界页并点击网格页。没有用失败动作证明UI通过。
- 合成Tw不是Schaefer/Ferguson实验壁温；图11配对数字化、低温物性、三维收敛、网格/外域独立性、转捩/RANS/非定常选择均未完成。不得给真实20°箭体、底面或突起增加资格。
