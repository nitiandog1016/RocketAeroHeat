# RocketAeroHeat 项目目标与技术路线

本文件保存当前有效目标、方法分工和验收要求，不保存逐版本流水账。**恢复工作的唯一当前状态入口是 [CURRENT_STATE.md](CURRENT_STATE.md)**；具体计划、结果和下一决策通过该入口定位。历史见 [EXECUTION_INDEX.md](EXECUTION_INDEX.md)，记录规则见 [RECORDS_GUIDE.md](RECORDS_GUIDE.md)。

## 1. 当前里程碑

**用户导入外形，给定一个飞行工况和壁面条件，点击一次计算，直接查看最终的全表面三维壁压和热流。** 日常对象为球头、扩张段、圆柱段、收缩段组成的外形，可带局部突起。建网后须能辨认原有特征。最终结果支持点选面元查询数值、单位和算法，并区分给定壁温与求解温度。

**工程计算、缺项识别和局部 CFD 补算都在程序内部进行。** 所有原面在同一工况下均得到适用方法算出的壁压和热流后，工作台才开放结果页和最终结果导出。计算期间显示进度；结束仍有缺项则显示未完成及原因。用户关注从点击计算到最终结果可用的总时间，分阶段耗时和面积增量留作诊断。底面、肩部、突起及实际分离或再附的区域均计入完整分母。

每次交付按算例及工况对比上一版，分别报告壁压、热流及两者同面覆盖。附新增原面清单、面数和面积。新增为 0 时写明“0 面、0 m²”及已解除的阻碍或已排除的路线。两者皆无则记录“本版未推进求解”。

自绘模型检验日常工程流程及同面覆盖。用户指定的 DLR RFZ 独立验收单工况全面积功能，并在同构型、同工况的共有外壁对照作者数值。独立实验用于评估相应位置的预测误差。缺少测量的区域仍计入求解责任面积。

工作台和计算回执共用原面台账，另列壁压与热流均通过独立验证的面积。公开民用试件单独验收。Short Test 65 按球、支管和端盖核对完整面积，并与实测球温及七站换热对照。独立界面、物性及公开试验按用户主流程的具体缺口排期，达到预定终点后退出。

已识别的局部热峰、分离区和再附区单列跟踪。即使面积很小，验收也须给出其位置、所用方法、局部结果及证据。仅由工程方法提示的疑似区域保留待核实状态。

公开模型试验开始前，列明它对应本次交付的哪个原面缺口、哪个物理量、哪项实验测量，以及何时结束对照。达到约定终点后回到同一冻结工况的原面计算与工作台交付。精度研究如需继续，在其结果确实影响该工况的求解或验收时另行排期。

固定主回归对象为原19752面箭体，总面积1.9646292565715553 m²；M5、30 km、α20°、β0°、给定Tw300 K。保持原壁、编号、完整分母、原32层/2µm及历史19层/尾缘资产。新外流网格无需照搬黏性近壁层；局部黏性网格须覆盖对应原壁、满足近壁要求并证明截断/映射适用性。局部化不等于删除剩余区域。

当前热量是q_conv(Tw_given)。给定Tw、壁节点流体T、求解固体Tw、Te、Tr分别保存。没有材料、初温、背面边界或独立热平衡时固体Tw保持未知；强回流区可无唯一Te/Tr，但p/q仍须求解。正热流进入壁面，零值和负值均保留。

长期目标是连续流、滑移/过渡流、自由分子流及跨流态全周期环境。当前优先连续流，累计热量、轨迹、壁体瞬态和长历史后置。高焓化学、辐射、烧蚀、尾焰均非默认已实现功能，需要时另建模型和验证。

## 2. 主技术路线与实现职责

2026-11-07用户确定：**低成本全局外流＋工程边界层＋局部黏性CFD**。MATLAB后端、X主轴/鼻尖+X/零攻角来流−X、SI、自定义离线WebGL和五步骤状态管理保持。内部自动组织网格、配置、外流与局部求解，不以用户导入外部CFD为前提。

| 层次 | 交付量 | 适用性与职责 |
|---|---|---|
| 全局外流 | 连续p/T/rho/U、H/S、激波和流向 | 采用有依据的成熟Euler、工程外流或必要黏无黏相互作用；不能各面独立重置来流。Euler不直接提供黏性壁热或完整边界层剖面 |
| 工程边界层 | 适用区域的u/T/rho剖面、q/壁剪、位移/动量/能量厚度及湍流信息 | 复用压缩性积分、非相似方法、参考焓/温度及关联式；明确层流/转捩/湍流假设，分离、强横流和超域拒绝 |
| 局部黏性CFD | 困难区p/q、分离再附、热峰及影响范围 | 优先成熟NS/RANS；必要且有依据时用单工况非定常统计。真实入口、法向/周向缓冲、尾迹和下游反馈须闭合 |
| 区域耦合 | 外缘→工程层→局部域的相容传递与反馈 | 项目重点自研；一致物性/能量参考、质量动量能量和模型身份。单向传递须验证，强相互作用应反馈或扩大域 |
| 统一结果 | 原面主结果、方法来源、资格、误差、热峰和功率 | 项目自研映射、监督和独立审核；一变量一面一个主结果，重叠不重复计面积/功率，不用平滑掩盖接口缺口 |

CFD优先复用成熟内核，SU2、Eilmer/GDTk、OpenFOAM等按固定版本的实际物性/湍流、边界、接口、算例、资源和维护成本选择；安装成功、品牌或README不构成采用依据。优先配置、原生回调和最小适配；若需长期重写通量/Jacobian/推进/内存内核，应复审收益。自研NS与激波拟合仅保留具名研究/独立校核用途。

变比热、目标工况适用的物性与一致能量参考继续保留；新局部候选不被旧模型永久绑定，但必须记录变化与验证范围，不能冒称精确续算或放宽旧失败门槛。各历史分支温域分开，不以更改输入或裁态满足准入。

## 3. H1—H5交付链

以下步骤按区域的实际依赖安排。工程结果在后台保留，局部 CFD 结果通过该分支的物理验收后计入合并覆盖。用户只接收全面积最终结果。

1. **H1 区域方案**：围绕具体缺口完成一手方法/开源对照，具名采用或拒绝；确定完整原面责任、可信入口、必要反馈、资源与参考验证。已有方案和失败直接复用，不等待更大主机或反复复述调研。
2. **H2 外缘与工程层**：从连续外流形成可追溯外缘和实际剖面。驻点起步、熵层、压力历史、横向度量与压缩性积分相容；积分厚度不能唯一决定完整剖面。研究输入资格逐级传播，不能把壁邻值、给定压力、未收敛场或假定剖面升为accepted-edge。
3. **H3 局部黏性与反馈**：同工况、同源剖面接成熟热壁/湍流入口，闭合入射特征、黏性/湍流输运和真实下游。全局超声速不等于近壁/分离区没有上游影响；不能在人工切口指定p∞或零梯度就宣称闭合。单向方案不成立时具名反馈/扩域，计入代价。
4. **H4 资源与精度**：在可比基态/工况/预算下报告各层及I/O总耗时、峰值和停止原因。原始分量残差、内部线性目标、实际非线性推进、连续窗热稳定、守恒及空间/外域/近壁误差分开；单元少不保证同比加速。两轮没有预定收益就复审或关闭候选，不无界续算/扫参数。
5. **H5 原面科研工作台**：新区域研究或合格结果及时接入原面台账，保留原完整分母；显示外缘/入口来源、主/对照方法、源帧、变量身份、拒绝与接口状态。源输入变化使下游旧结果失效，浏览不暗中计算。历史已过UI仅针对新变化补验。

当前具体任务、已关闭组合、进行中计算和预算只在 [CURRENT_STATE.md](CURRENT_STATE.md) 及其指向的计划中维护；这里不再保留多个版本的“下一步”。完整域可作有独立预算与资源证据的备用，不因历史入口OOM自动迁移云资源，也不自动重开旧分支。

## 4. 公开验证与资料采用

自绘研究外形 `cases/rocket.stl` 在固定 20° 主工况下验收三维集成、原面覆盖，以及计算结果与工作台显示、探针和导出的一致性。预测精度用带实验数据的公开模型检验，按几何、Mach/Re、气体、壁温、入口和测量定义匹配工况，逐项报告壁压、热流误差和实验不确定度。用于主算例某一区域的验证证据，须说明方法、流动条件及适用范围的对应关系。实验测站按位置计数，主算例覆盖按原面面积计量。[原面覆盖核对](validation/v263/RESULTS.md) · [公开模型同站对照](validation/v263/TMR_JOINT.md)

文献优先原论文、NASA/NACA及作者/机构资料；记录方程位置、假设和失效范围。GitHub优先官方仓库，固定提交、许可证/署名和实际接口，不用Star数或同名方法代替能力证明。旧TMR/Run14失败保留，不自动重启；燃烧产物/氮气不偷换为当前空气。研究围绕具体阻断形成可实施决定，不扩展为无界标准算例支线。

## 5. 单时刻全面积验收

- 计算覆盖与物理验证各有判据。只有每个原面均得到适用方法计算的壁压与热流，才标记该算例“全面积已算出”。测得的压力或热流用于独立对照，给定边界值、外推占位和超域值均排除在计算覆盖之外。受限的控制算例只报告自身的结果。
- 全原表面p/q交集均有适用、可复现、获得相应验证支持的方法；给定、未知和超域不计，分母不缩。
- 各分支沿用原验收门槛，按计划记录物性适用域、正性、输入来源及误差证据。全局外流核对外缘来源、边界守恒和网格／外域敏感性。需要迭代收敛的 CFD 分支按原物理分量与残差定义执行 −8 门槛，并注明归一化和取值阶段。[全局外流核对记录](HYBRID_PHASE_EULER_DEVELOPMENT_V232.md)
- 工程边界层逐区核对外缘、方法适用范围、热流误差和可用的匹配实验。局部黏性 CFD 另核对实际 y+、近壁分辨率、壁面热流、连续窗口热稳定性，以及入口、接口和下游反馈的守恒。入口、物性和湍流模型敏感性按各分支的事前合同评估。[工程剖面数值核对](PHASE_NONSIMILAR_PROFILES_V252.md) · [黏性计算核对记录](RESTART_BRANCH_V236.md)
- 温度身份及热流方向正确；研究迭代不当物理时间，未解区不补零。
- 同工况云图、面元探针、任意截面周向曲线、色标、逐变量面积、热峰、全表面功率与导出一致，区域重叠不重复积分；实际交互随新增能力核对。
- 准确源、第三方版本/许可、必要小输入和依赖可复现；大型场本地位置、恢复方式、未备份状态明确。

全部满足前仅称已测试模块、受限区域计算、工程对照或研究；路线、记录整理、软件检查和数据拼接不授物理资格，不承诺完成版本号。
