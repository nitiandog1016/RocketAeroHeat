## 1. 长期目标与当前边界

长期完成全飞行周期的连续流、过渡流、稀薄流气动热环境及壁体热响应。外流和区域入口由程序内部产生，外部 CFD 数据不是日常使用前提；公开实验和外部基准用于验证。

当前并列最高优先级：

1. **给定单一工况下，明确支持的完整几何外表面的压力、对流热流及有物理定义的相关温度。** 鼻部、侧壁、肩部、收缩、后体、底面和实际存在的分离／再附都在范围内。真实 20° 箭体仍是主攻对象，不能移除难区或缩小面积分母换取“全面积”。
2. **统一、克制、可定量核对的科研三维工作台。** MATLAB 负责计算，自定义 WebGL 负责结果；区域求解和可操作的五步骤侧栏同步推进。

这不是“任意 STL、任意 Mach／攻角均由一套关联式覆盖”的承诺。先明确几何、流态、物性、转捩／湍流和壁面条件的支持范围，再逐区域取得资格；一个案例通过不授权整个参数矩形。

单时刻主链求 **q_conv(Tw_given)**。给定壁温不算求得壁温；没有材料、初温、背面边界或独立热平衡，不能仅由 p、q 推得真实壁温。Te、Tr、给定 Tw、求解 Tw 分开。强回流区可能没有唯一边界层外缘／恢复温度，应记“不适用及原因”，但该区的壁压和壁热流仍须求解。

累计热量、长历史、轨迹耦合、瞬态导热和大规模历史加载后置。当前不承诺高焓反应、激波层辐射、烧蚀或尾焰环境已经求解；未来工况若需要这些机制，须另建模型，不能把对流热流当完整总热环境。

## 5. 验证、几何与里程碑

分别登记解析／制造场校核、公式独立复算、数值解验证、实验比较。测试数量、小残差或两个公式接近不等于物理精度。公开数据须匹配几何、Mach／Re、壁温、物性、入口、坐标、归一化和不确定度；TMR 压缩拐角不自动验证箭体收缩膨胀及再压缩。原候选来源见[算法调研](REGIONAL_ALGORITHM_ROADMAP_2026-10-17.md)，实施前须核对原公式和条件。

几何测试从球／锥／锥柱到同尺度收缩—后体、真实 20° 箭体和成对突起。先做单闭合截面可表示的鼓包，再独立评估尖角、薄翼、多闭环、悬挑。检查法向、拓扑、面积／体积、特征真值和重网格保留；当前重网格已有多闭环拒绝，不能写成已支持。几何通过不赋予遮挡、马蹄涡或热流资格；新增几何能力须显式入口和自己的验证，不改形后冒充原体。

单时刻全面积里程碑须同时满足：

1. 固定完整几何／工况，原全表面壁压与对流热流均有适用、可复现、经过相应验证的模型。给定压力、未知、超域面积不算求解覆盖，分母不变。
2. 区域入口／接口和所需物理机制闭合；报告网格、域、边界和方法敏感性。验收尺度运行前按用途／基准确定，不能事后放宽。
3. 温度身份正确；给定 Tw 模式不要求伪造求解壁温，回流区不伪造无定义的 Te/Tr，也不能据此免除壁压／热流。
4. 主工作台的 p/q/T、方法、面积、热峰、全表面热功率及实际浏览器／导出／当前工况一致性通过。
5. GitHub 源码、小型输入和明确依赖可复现；大结果的存放、恢复及未备份状态清楚。

此前交付使用“已测试模块／受限区域解／方法对照／研究”，不称完整气动热。之后复用已有热响应模块推进轨迹、跨流态及必要高焓机制；跨流态须分别验证连续极限、自由分子极限、中间区域与气体表面作用，不能仅靠插值宣称完成。
