# RocketAeroHeat 开发目标（2026-10-12 优先级更新）

最终目标是全飞行周期气动热环境：连续流、过渡流、稀薄流及随时间变化的壁体热响应。外流由程序内部计算，外部 CFD 不是使用前提。沿用主轴 X、鼻尖 +X、零攻角来流速度 -X、SI 单位和统一操作流程。

## 当前最高优先级（2026-10-12 确认）

**优先完成给定某一飞行时刻/工况下，整个几何表面的三维气动热计算，以及自定义科研 UI 的完善。** 两项并行推进：计算侧补齐全表面的压力、热流及相关温度场；界面侧完善统一操作、三维云图、面元拾取、周向曲线、色标和结果导出，并逐变量展示算法、状态及适用范围。

全面积计算包括鼻部、侧壁、肩部、尾锥、底面及存在的分离/再附等区域。覆盖审计用于定位缺口；仅标出未解区、给定边界或超出适用范围，不能作为全面积求解完成。给定壁温与求解壁温分别呈现，当前时刻的结果必须与所选工况一致。

**累计热量、长时程热历史、轨迹耦合、壁体瞬态热响应及大规模历史数据加载安排在后续，不能作为当前单时刻里程碑的交付前置条件。** 已有历史功能保留；除影响当前单时刻计算或 UI 的必要修复外，暂不优先扩展。最终全周期、跨流态目标保持不变。

## 当前第一阶段：连续流工程计算

界面风格补充：用户要求精美但不花哨，符合科研工作。采用克制配色、稳定布局、清晰单位与数值、可核对色标及算法来源；避免装饰动画和影响定量解读的显示效果。

科研 UI 的持续验收要求（2026-10-11 确认）：

- 云图与曲线占主要空间，常用控制集中放置，详细算法与诊断按需展开；保持统一窗口和稳定布局。
- 使用中性背景、有限强调色、清楚的文字层级和对齐；不添加装饰动画、发光、玻璃效果或无用途的仪表盘卡片。
- 颜色优先表达场量和状态。色标必须标明变量、单位、范围及截色方式；工况比较应支持固定范围，未解区与物理零值明确区分。
- 面元拾取保留坐标、面元编号、数值、单位、算法、计算状态和适用范围；不同温度和给定/求解值分别呈现。
- 当前云图、面元探针与周向曲线必须对应同一所选时刻/工况。后续热历史浏览必须标明当前时间及各变量的数据时刻；无对应时刻的数据不能冒充瞬态结果。曲线缺失处断开，并保留来源与有效状态。
- 图像导出应便于科研报告使用，保留必要的工况、时间、单位和色标；界面精美以信息易读、操作稳定、结果可核对为标准。

1. **最高优先级：单一时刻的全面积三维气动热计算。** 在给定工况下补齐鼻部、附着侧壁、肩部、尾锥、底面、分离/再附区的压力、热流及相关温度场，并分别统计面积覆盖率。先审计，再按有来源的区域模型逐个补齐。给定底压不算求得底压，缺失值不能补零冒充完整解。钝体、细长体、带折角几何的适用性分别说明。
2. **并列最高优先级：统一科研三维工作台完善。** MATLAB 保留计算核心，使用离线 WebGL 绘图。优先完善当前时刻的旋转、平移、缩放、真实比例、面元拾取、周向曲线、色标与导出；压力、热流、外缘温度、恢复温度、给定壁温、求解壁温分开显示。每个值具有算法和状态，未解面元仍显示并允许点选。
3. 多工程方法：保留修正牛顿压力、切锥/切楔/膨胀外流、驻点关联式、层流/湍流边界层与转捩；逐步增加具有独立适用范围的单工况对照方法。各变量分别记录来源，不能把牛顿压力标成边界层外缘压力。厚度导热与时域耦合在后续热响应阶段继续完善。
4. 验证：经典球体、锥体、钝锥、圆柱/锥柱组合；将解析校核、公开关联式复算、实验数据验证分开。实验记录必须包含可追溯来源、工况、坐标、单位、数据提取方式与误差。

当前单时刻里程碑验收：在明确支持的目标几何与工况下，全表面各区域的压力、热流及相关温度场均有适用模型与来源，并可在统一三维 UI 中核对云图、面元数值、曲线和色标。给定量必须标明边界条件；未解或超域面元保留真实状态，不能据此宣称全面积求解完成，也不得用“覆盖审计完成”代替“全区域求解完成”。需要方法说明和相应验证记录，壁温历程、累计热量与长时程功能不作为本里程碑的验收条件。现有 Euler 研究保留，但不是上述工作的前置条件。
