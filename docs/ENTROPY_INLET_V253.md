# v253 真实鼻部—前体交界入口的质量与变熵相容性

2026-11-16。基于科学交付78da62aa（v252）、当前本地基线65523caa，实现从原鼻部与3128目标前体的共同环到实际剖面/流管质量/匹配外缘的入口生产链。**独立数值核对通过，单次修正后的联合入口拒绝；没有新增合格热面积。** 本轮只在本地交付。

## 方法与实际程序

采用[NASA CR-112180](https://ntrs.nasa.gov/api/citations/19730005231/downloads/19730005231.pdf)印刷24—28页式65—69及B16的B=1起步；报告明确这是小横流和轴对称类比的工程近似。一般有限入口模块使用实际h而非轴对称半径，支持有来源的正上游质量/激波角；本次真实入口的上游供体仍限已具名旋转球帽，不宣称取得全箭三维激波面。

| 文件 | 模块职责 |
|---|---|
| `scripts/phaseAwareEntropyInlet.py` | 同相态压缩根、一般h激波质量表、有限球帽上游供体、实际剖面质量匹配与外缘恢复 |
| `scripts/produceEntropyInletV253.py` | 原壁共同边提取、实际横向标签、三分支剖面插值与物理守恒量生产 |
| `scripts/auditEntropyInletV253.py` | 独立压力比Hugoniot、直接RK45供体积分、全原面拓扑/积分/源身份审核 |
| `scripts/exportEntropyInletV253.py`、`web/entropy-inlet-v253.*` | 入口环选择、完整法向剖面、修正量/缺口与可追溯CSV；复用已有原面WebGL |

保持现有MATLAB后端和v252完整m文件。本轮为Python区域接口/独立验证，调用现有SciPy，不运行或修改MATLAB/CFD/引擎，也不分发第三方源码。

每条入口使用原共享边的J=dr/dφ、球帽工程流向t/法向n，取h=J·(n×t)，保留J·t和J·n。风轴方位χ与原机体方位φ之间的dχ/dφ也实际计算。剖面质量为m′=∫ρu dy，实际每标签质量Ψφ=h m′；供体表按风轴方位计量，故Ψχ=Ψφ/(dχ/dφ)。忽略这个标签转换会把不同流管的质量混用。

原v252有限剖面按相邻极角站和归一法向位置插值，601法向样本；保存u/T/rho、三维方向和物理五守恒量，ρE使用物理内能参考，没有加入SU2的300000 J/kg平移。供体逆查激波角，再保持同上游总焓、同物性熵及同一物理压力恢复Te/Ue。原剖面不被修正量覆盖，不产生SA供体或新q。

## 验证与失败

- 新一般h有限入口的非恒定尺度解析质量误差1.785e−11、常角差1.847e−11；标签重新参数化通过，五种非法源/尺度拒绝通过。
- 独立压力比压缩根与直接RK45供体积分：供体最大差1.610e−8，匹配质量对直接ODE最大差7.334e−7，均低于2e−5；源表逆查质量通过1e−8。
- 两种法向质量积分最大相对差1.797e−6，低于1e−4；波质量/动量/能量最大相对残差1.528e−15；独立Te/Ue最大相对差2.087e−14。
- 原拓扑共同环、独立Heron面积、标签差分最大相对差1.229e−10通过；缺失位置与源角域严格相符。
- 首生产多余右括号导致计算前exit1；修复后源表/控制完成，但5处超源范围导致IndexError。准确旧脚本/回执保留，第三次仅复用已存表/控制并补充未知传播，没有扩大物理范围。
- 首审核误要求ρ(u t)与(ρu)t逐位相同而失败。最大差7.105e−15；改为两次乘法显式4ε|参考量|舍入界后通过，未修改计算结果或物理门限。此为审核恢复，不是生产重跑。

这是同方程数值复核及真实几何入口诊断，不是实验验证、全三维外缘或壁热资格。
