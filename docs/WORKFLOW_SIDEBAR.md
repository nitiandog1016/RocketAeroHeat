# 统一科研工作流侧边栏

v55 已实现并定向测试用户于 2026-10-14 要求的五步骤操作流程。`main.m` 默认启动 `rocketAeroHeatWorkbench(cfg)`：同一个左侧栏依次提供输入模型、生成网格、添加边界条件、计算、查看结果的真实入口，参数区随步骤切换，中心区域显示离线 WebGL 几何或当前结果。MATLAB 保留计算后端，坐标、SI 单位和现有自适应网格算法保持原约定。

本次完成的是单工况流程迁移与状态管理。当前区域模型仍有未解区；侧边栏“已完成”表示已接受对应步骤或当前计算快照，不表示全面积压力、热流和温度都已求解。材料、壁体热响应、飞行历程和 Euler 等旧专题尚未迁入新默认侧边栏，原逐段脚本完整保留为 `mainLegacy.m`，通过该流程和 `pressureGUI.m` 继续使用。

## 五个实际入口

1. **输入模型。** 选择 STL，输入“原坐标 → m”的尺度系数并加载。STL 没有单位：毫米坐标通常用 `0.001`，米坐标用 `1`，需要用户核对。PCA 可对齐主轴，但无法判断鼻向；可翻转鼻向、应用增量旋转或恢复导入坐标，最后明确确认“主轴 X、鼻尖 +X”。鼠标旋转只改变观察视角，不能代替实际朝向确认。
2. **生成网格。** 在同一侧栏设置最小/最大尺寸、初始轴向间距、曲率角及周向点数，点击“生成并检查表面网格”。保留原截面重构和拉链三角化方法；完成外法向、拓扑检查、表面坐标和局部几何。带开口、非流形边或退化面的候选网格不接受为求解网格。几何视图显示真实 `V/F` 和网格线，侧栏保留实际节点/面元数及质量指标。
3. **添加边界条件。** 设置高度、Mach、攻角、侧滑、给定壁温，以及空气物性、鼻区、湍流、转捩和底压方法。受限底压模型的尾撑/喷流声明及来源也是显式输入，不能从 STL 推断。点击“确认当前边界条件”建立来流并审核输入；当前内部工程链要求 `M>1`。初次或修改后的确认尚未求压力或热流；未修改边界再次确认则保留当前有效结果，状态文字明确显示“结果仍有效”。给定壁温是边界输入，与求解壁温分开。
4. **计算。** 点击“计算当前工况”才执行压力、载荷、驻点、内部工程外流、轴向波系、准流线、热流和面积审计。日志显示实际阶段和失败信息；阶段比例表示完成的程序步骤，不能解释为求解面积或预计剩余时间。计算期间冻结输入并禁用编辑，只在完整链路成功后接受当前版本快照。失败留在同一窗口，没有中间快照冒充结果；可返回边界步骤修改、重新确认，再点击计算重试。
5. **查看结果。** 只有已接受的当前计算快照可打开结果页。在 WebGL 中旋转、平移、缩放，选择压力、热流或不同温度，拾取实际面元核对数值、算法、状态和适用范围。任意 X 截面的周向曲线、色标、全表面 CSV、定量 PNG 及“导出完整离线工作台”使用同一快照。浏览与导出不触发物理重算；未解值与物理零值明确区分。

## 当前输入与下游失效

`aeroHeatWorkflowState.m` 集中保存原始/已确认朝向几何、真实网格、配置、边界确认、步骤状态、输入版本和求解编号。页面切换只读状态；已完成步骤仍可返回查看。各入口标出待前置、待处理、已完成、计算中或失败，缺少前置条件时禁用。

| 操作 | 保留内容 | 失效内容及下一步 |
| --- | --- | --- |
| 编辑模型文件或尺度 | 新配置 | 原始/已定向几何、网格、边界确认和结果；重新加载并确认朝向 |
| 改变实际朝向预览 | 原始输入几何 | 已确认朝向、网格、边界确认和结果；重新确认实际朝向 |
| 编辑网格参数或接受新网格 | 已确认模型和配置 | 旧网格/相关质量或旧场量、边界确认和结果；生成后重新审核边界 |
| 编辑飞行条件、壁温或算法 | 模型和求解网格 | 来流确认及旧结果；重新确认并显式计算 |
| 未修改边界，再次确认 | 当前输入版本、求解编号和有效快照 | 不失效、不重算；状态文字显示“结果仍有效” |
| 仅切换页面或改变观察视角 | 当前输入与计算快照 | 不失效、不重算 |

模型或网格改变还会清除与旧面元绑定的逐面元壁温，避免把旧编号套到新几何上；新的逐面元边界须由配置重新明确指定。工作区中的 `mesh`、`cfg` 和 `freestream` 随当前有效状态更新，上游失效后不保留旧物理场冒充新工况。

求解返回时核对冻结的输入版本、求解编号、`V/F` 和必要结果字段，拒绝过期、错几何或不完整结果。计算失败后恢复父参数面板及子控件的可用状态，用户可以继续操作。当前界面没有独立的计算中取消按钮；不把失败恢复测试描述为用户取消功能。

## 几何、场量与适用性

输入和网格阶段使用 `createAerothermalGeometryView.m`、`updateAerothermalGeometryView.m` 及 `web/geometry.*` 的中性几何模式。传给网页的数据仅含真实顶点、面索引及显示信息，不添加虚构压力、热流或温度字段来复用结果查看器。

单工况后端 `runAeroHeatSingleCase.m` 调用既有区域模型，保留非均匀/未知输入壁温及逐场量来源；未知或超域值保持 NaN。输入壁温、求解壁温、外缘温度和恢复温度分别呈现。当前默认侧边栏未新增壁体材料求解，因此没有热响应结果时求解壁温仍为未解。

本次 UI 迁移不补齐底热、鼻部/后体接口或分离再附模型，也没有新增实验精度验证。本轮 20° 真实箭体的热流计算面积仍为 **77.4616%**。底压的模型与适用门限见 [真实网格底压](MESH_BASE_PRESSURE.md)，球鼻模型见 [球鼻热边界](SPHERICAL_NOSE_HEATING.md)。详细场量、截面及导出含义沿用 [单时刻工作台](SINGLE_TIME_WORKBENCH.md) 与 [单工况导出](SINGLE_CASE_EXPORT.md)。
