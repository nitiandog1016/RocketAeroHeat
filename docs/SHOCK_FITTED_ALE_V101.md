# v101：移动激波与三维共享面推进内核

本阶段把v100之后的第一组必要内核写成可复用MATLAB模块，并在原19752面箭体的483个鼻部面上建立真实三维体网格。移动激波、移动壁面功、网格几何守恒和限定活塞基准已测试；**真实曲面共同激波形状、真实箭体压力、外缘及热流尚未求得**。正式热流覆盖率保持66.5626327424%，新增合格面积0，完整目标继续有效。

## 模块与方程

入口为`setupShockFittedFlow`，计算模块位于`regionalFlow/shockFitting/`，全部采用中文模块注释。

| 模块 | 用途与范围 |
| --- | --- |
| `shockFittedState3D` | 三维五量和原始态互换；NASA7从同cp内能反解温度，严格检查声明温域 |
| `movingShockJump3D` | 用相对法向速度求同cp移动RH，重建实验室三维速度及五量通量 |
| `shockFittedALEFlux3D` | 常gamma精确Riemann在移动界面采样，全部五量共同变换；NASA7明确拒绝 |
| `shockFittedSlipWallFlux3D` | 镜像相对法向速度，Riemann求壁压及移动壁面功；没有给定壁压输入 |
| `buildShockFittedTetraTopology` | 每个共享三角面只存一份，构造owner/neighbour和稀疏拓扑关联 |
| `shockFittedALEGeometry` | 线性节点运动的扫掠体积、面积闭合、GCL及全过程单元翻转检查 |
| `advanceShockFittedALE3D` | 储库/壁面/移动激波边界的实际三维五量一步推进；另列激波压力相容差 |
| `solveShockFittedPiston3D` | 给定活塞速度与均匀上游，共同求未知激波速度，再推进三维基准域 |
| `buildShockFittedSurfaceShell` | 保留真实原壁面顶点与面号，生成共享顶点的偏移外壳候选及体网格 |
| `exportShockFittedKernelStudy` | 将保存基准与原鼻部几何接入同一科研工作台，未知场量保持空值 |

法向`n`显式指向激波后流体，移动激波速度为`D`。压缩根使用`w1=V1·n-D`，切向速度连续。实验室总焓满足

\[
H_2-H_1=D(V_{2n}-V_{1n}),\qquad [F(Q)\cdot n-DQ]=0.
\]

移动激波通常不能沿用驻定的实验室总焓不变。常gamma界面通量先在`D*n`移动系精确采样，再把质量、动量和能量通量一起变换回来，不能在错误采样态上简单减`D*Q`。滑移壁面的通量为`[0,p*n,p*D]`，其中`p`来自内部状态的镜像Riemann相容。

每个三角面的面积向量在线性节点运动下为时间二次式，用Simpson精确积分扫掠体积；共享面两侧使用同一数据及相反符号。单元更新为

\[
V^{n+1}Q^{n+1}=V^n Q^n-\Delta t\sum_f A_f\big(F\cdot n-w_nQ\big),\qquad
V^{n+1}-V^n=\sum_f\Delta V_f.
\]

几何体积为三次式，除端点/中点外还检查区间内导数根，能够拒绝中途翻转、最终又恢复正体积的路径。没有裁温、裁速度、压力混合或逐面增加形状自由度。

## 实际测试与独立复核

`shockFitKernel101b`实际exit0、引擎62056、源码稳定。原`shockFitKernel101a`实际exit1、引擎27204；可选参数数量判断将显式预算覆盖，最终拒绝测试发现问题。原源码/进程/日志保留，只把`nargin<9`修正为`nargin<8`，没有修改物理门槛。

- 两物性各3个移动斜法向激波，共6例，另有旋转、Galilean和同cp状态往返核验。独立Brent/NASA7复算状态最大相对差约5.76e-16。
- 活塞以给定法向速度差450m/s求未知激波相对入射速度：常gamma为674.880371893m/s，NASA7为674.412266691m/s。独立以密度比作根，速度差分别0和1.14e-13m/s。
- 常gamma活塞域48个三维单元，实际推进8步，状态保持最大相对差1.66e-15，全域五量账2.67e-17。NASA7只完成RH/活塞相容，**没有作NASA7 ALE推进**。
- 非相同左右态的独立实验室系`xi=D`采样，ALE通量最大相对差2.43e-15；压缩/膨胀/无相对穿透壁面的独立通量差约5.73e-16。
- 真实M5、30km、20°原输入，取483个原鼻部面，生成2898个三维四面体、6337个共享面。原壁面顶点和面号准确保留；外壳只是8mm偏移候选。
- 真实几何上的数学均匀态检查，MATLAB状态相对误差1.23e-15、GCL1.19e-15；独立四点Gauss/行列式核验GCL6.53e-15。**此数学均匀态穿过原壁面，不是该箭体真实外流，UI中没有把它画成求得的箭体压力。**
- 错误气体、法向、法向Mach、温域、中途单元翻转、预算超限等路径均有拒绝测试。

独立审核首稿两次在近零扫掠/能量通量的误差语义上失败，原文保留：端点恢复的扫掠舍入用实际面积×坐标尺度传播界；通量按各守恒量在全部实际面上的独立幅值归一，另存逐分量绝对差，范数门槛2e-12。没有改写MATLAB场或降低原物理守恒条件。

一步内核声明输入、缓存及Riemann/几何/更新临时数组上界，本例62,364,794字节，约59.476MiB；预算超限在推进前拒绝。**这不是MATLAB进程峰值实测，也不包含调用者保留的全部历史数据**。当前为空间分片常数、一步显式积分；均匀态与几何恒等式不证明任意非均匀问题的稳定性、收敛阶或物理精度。
