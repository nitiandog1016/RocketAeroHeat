# v143 固定表面PLC完整外域：31个坏单元减少到5个

2026-11-01。同一边界的TetGen PLC空腔小例通过，真实外域明显改善，但仍有5个四面体SICN低于0.1，**候选拒绝，不接流场**。没有SU2、MATLAB或新UI验证；新增合格气动热面积0，总目标保持进行中。

## 方法和实际执行

复用v142经SHA核对的官方TetGen1.5.1核心与精确谓词对象，独立PLC封装一次编译1.078秒exit0。原数值代码未改，许可为AGPL-3.0-or-later，二进制只在本地。

只输入原纯四面体域的闭合表面，使用facets与显式holelist；内部点重新生成，不继承v142被rY锁定的旧体内点。固定参数`pY1q2/5O2/7S30000zVC`在运行前记录于[计划](validation/v143/plan.md)。30,000个新内部点上限依据旧域20,616个内部点和不足10,000点净增加余量确定，没有按结果追加预算；实际仅生成5,006点。

小例复用v142同一64点/120面的空腔边界，孔种子(1.5,1.5,1.5)。唯一原生调用0.375秒exit0、整例0.407秒exit0。得到64点/156四面体，固定边界、体积26、空腔1、正体积/配对和单连通流体保持；最小SICN0.00225→0.774597，全部超过0.1。原偏心点从本次输入移除属于表面重建合同，不是调节小例边界。

真实候选从v141准确MAT提取13,166个边界点和26,324个三角面。两个闭合分量、方向和立体角检查通过；孔种子按原封闭壁面体积质心计算并核对位于内外壳内、流体绕数0。已通过CGAL的v141包络与本次内边界逐点逐面吻合，复用原证据，没有重跑自交检查。

## 独立复核和瓶颈

原生全部坐标、连接、标记与重组MAT逐项对应；独立字典配对/行列式体积/逆矩阵SICN复核通过，与SVD坏单元质量最大差9.71e−17。初次只读复核的NumPy多维列表索引错误已保存准确失败源；改为显式索引数组后复核通过，没有重跑原生网格。

五个坏单元中心X为−2.893025至−2.853253m，全部位于后体。固定顶点数分别2/2/2/3/2，完整固定面数0/0/0/1/0；没有远场点。固定顶点全部追溯到第32层、法向高度21.293943mm、原壁X在−2.828319954至−2.828291171m的尾部区域。这不同于先前以鼻部为主的失败分布。

原生q指标也未全部满足：五单元半径/最短边比3.55—6.41，四个最小二面角低于5度。固定表面约束下质量参数不是保证；不能简单说SICN换算不同是唯一原因，也没有证明固定边界数学不可行。五个单元仍有自由顶点，不能再用“所有顶点固定”解释本次真实失败。
