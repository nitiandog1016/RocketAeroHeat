## 实际求解与来源

`createRocketAxisymmetricSensitivityCase` 先完整核对冻结v75普通double根的SHA和原求解源码，再建立新的完整域；不能通过给旧RootCase改网格来绕过它的冻结输入检查。

数值初猜按相同流向墙条带，在真实体质心至墙心的距离上作五个守恒量的凸线性插值。父域内超出供体中心范围时用最近端格；位于父域外的格保留自由流初猜。三个对照分别有0、0、115个父域外格。记录逐格两个供体编号、权重、端点延拓和域外标志、父/新初积分。不裁负密度、温度或SA；**不是保守重映射、给定入口、已解区域或外部CFD数据**。

随后直接求同一原NS/RANS空间残差为零，保持原2e-6 s⁻¹及5e-10边界/源通量平衡门槛。三档实际分别8/9/6次Newton、1541/1730/1154次残差调用。每档单独保存原初猜、完整解、候选、成本、源码SHA及真实进程身份。

新根按其SHA与当前实际求解依赖重建后，另起不可变三步BE确认链。Newton准备不计BE步；全部为正的实际伪步，原BE绝对1e-11、相对1e-9、守恒5e-10及连续三步空间2e-6标准保持。各新根已满足原门槛，确认时没有内部Newton更新，Q保持不变；这不是物理时间推进。旧原大BE失败与本阶段无关，没有将其改判成功。

## 热流差异位于哪里

径向48层相对基线，球鼻区域总热功率−4.74%、锥段−20.19%、柱段−34.21%、收缩−40.58%、后体−42.58%、底面−11.31%。底面各位置的热流**变化量**方向不同，因此其面积加权绝对差异20.07%比净功率差更大，不能只比较总和。2026-10-23 v77核对原始数组后更正：v76这四档的墙热流本身均为正值，不能将变化量的正负说成热流有正负分布；冻结v76包保留原记录，本更正随v77交付。

径向加密造成的约54.07 kW净下降中，柱段约31.76 kW、锥段约16.50 kW、后体约5.16 kW，是大面积分布问题。减小首偏移时，球鼻与锥段功率则分别增加约41.41%和22.25%；这两项变化不能通过调系数抵消后宣称验证。

全墙压力的面积加权绝对变化相对基线分别约2.415%、0.619%、1.202%，热流分别约28.281%、13.809%、2.001%。压力较接近并不能证明温度梯度或热流已经可靠。

实际首层体质心墙距基线约9.9998–10.0036 μm；nearwall_half约4.99994–5.00089 μm。`firstNormalSpacing`为节点偏移，不是体质心墙距；外连接首长度2e-4 m也不是墙距。

本轮y+定义为 `d*sqrt(abs(tau_t)*p_owner/(R*Tw_prescribed))/mu(Tw)`，是使用owner压力及给定Tw构造墙密度的**诊断代理**。四档最大值约8.472、8.505、5.326、8.438；不能当成近壁充分解析资格。切向牵引定义为负的流体外向Newton牵引与鼻尖到基底墙切向的点积；底面径向牵引符号不能当作流向分离判据。
