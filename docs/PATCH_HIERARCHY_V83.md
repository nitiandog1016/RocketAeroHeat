# v83 强连接代数层次：真实粗校正放大及后续消元路线

本轮服务于真实20°箭体三维内部求解，沿用 `COUPLED_PATCH_PRECONDITIONER_V83.md`。物理网格、完整原NS、给定边界及原验收保持。本轮的V循环已测试，但未改善真实完整C的收敛，不能计为新增气动热区域能力。

## 完整程序和数学合同

每层以现有强连接局部组定义代数延拓P：同组共享五个守恒校正；R对每组成员作等权平均，因此R*P=I。它是代数限制，不是真体积守恒积分，不会把物理CV合并。每个粗层矩阵直接逐系数形成C_c=R*C*P，保留所有原连接的累加，包括恰好为零的结构位置，不按阈值删非零。

一次固定V循环先计算局部五量块逆作用x_l，形成完整该层剩余b-C*x_l，再限制至下一层、递归求校正并延拓回本层。没有按右端早停或事后调整权重。最粗完整五量矩阵以带主元稠密逆求解，并通过原输入逆残差1e-8；若最粗系统奇异，拒绝整个层次，不以CV对角替代最粗系统。

完整文件：

- `internalFlow/cutCell/restrictRocketPatchResidual.m`、`prolongRocketPatchCorrection.m`：固定R/P。
- `coarsenRocketPackedGraph.m`：直接汇总全部25个五量块系数。
- `buildRocketPatchHierarchy.m`：复用根局部因子，建立有预算的完整层次，逐层检查R/P及完整RCP探针。
- `applyRocketPatchHierarchy.m`：固定递归V循环及逐层作用记账。
- `solveRocketPatchHierarchyKrylov.m`：完整原C的单周期有界GMRES，保留原Arnoldi1e-8门槛。
- `compactRocketPatchHierarchyReport.m`：仅导出标量、计数与历史，不将V/Z写入JSON。
- `tests/testRocketPatchHierarchy.m`、`studyRocketPatchHierarchy.m`：小域参考与真实同Q试算入口。

真实预算为层次数组1GiB、构造数组估计3GiB、GMRES基1GiB，最多8层、每组最多8CV、最粗最多16CV；预算不等于进程峰值。物理场没有通过这些代数分组被平均或替换。固定V循环是线性预条件，但整个有界内部GMRES随右端变化，仍不能当固定线性Schur逆。

## 放大位置与被排除的简化方案

对同一保存右端，根局部作用剩余17.089，限制后第二层局部作用剩余107.925。根延拓粗校正的范数约为根局部值的206.776倍。第3层局部剩余约7.903，而更深几层较小。这定位了该固定右端上的传播放大，不证明全局唯一原因、矩阵秩或所有右端的行为。

在根局部像和当前完整粗校正像的二维张成空间内，独立归一化最小二乘诊断残差仍为0.999538565906，权重约0.001771及-3.3273e-8。它只是同右端诊断，没有新模型/NS或迭代；不足以支持仅调整两个标量就重跑真实32步。后续不重复这一组常数七层V循环、相同扫描或盲增迭代。
