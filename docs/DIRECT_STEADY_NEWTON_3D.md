## 直接稳态模式的实际含义

`solveRocketShellSteadyKrylov`现在支持显式设置：

```matlab
options.linearEquation = 'steady-newton';
options.normalEulerLinearization = 'exact-branch';
```

令U=Q/scale、R为同样缩放的原完整三维NS残差。新模式实际求`(-J)δ=R`，不含`I/tau`；tau仅保留在右预条件器。每个最终组合方向均重新调用原完整NS差分，保存方向、两侧残差、步长、实际线性缺陷及下降模型，包括失败方向。原Euler/黏性/墙温墙速/特征远场、80—2000K物性范围、正性、RMS下降、守恒与稳态门槛不改。

对实际差分作用核对`eta=||-Jδ-R||/||R||`以及`slope=R'Jδ/||R||² <= -1+eta`。仅有负斜率不代表达到线性目标；必须同时满足目标和下降检查才进入非线性候选。这个Cauchy界约束采用的数值方向作用，不是全局光滑性、真实空气适用性或物理精度证明。

缺省和显式`pseudo-transient`仍采用原`(I/tau-J)δ=R`及完整旧输出合同。最终兼容重放在`solvercompat05`通过，只有机器耗时被排除。第一次开发任务`newtonunit01`真实退出1，原因是MATLAB在restart等于系统维数时将MAXIT解释为总内迭代数，传1只执行一个内迭代；失败源/输出保留。新模式预算达到维数时改用`restart=[]`和明确总预算，旧模式调用不变。`newtonunit02`通过早期测试，包含失败预算和最终停止原因的完整测试以`newtonunit03`为准。

## 小域与真实箭体的结果必须分开

人为限定一个Krylov向量的真实小域求解得到缺陷0.27586184，未通过0.1；0接受、0候选、Q保持，失败方向和4次NS调用完整保存。正常预算和受限预算均由Python独立核对实际差分算术、下降界、候选与工作量。小域通过不能当作真实箭体收敛。

真实M5/30km/20°、Tw给定300K、19752原面/217272CV的`krylov06`从十二次接受端点精确接续，使用24个Krylov向量、0.1目标和tau=1e−4。实际缺陷0.99313220未通过，斜率−0.01368842，上界−0.00686780；0候选、0接受，停止原因为`steady-newton-linear-target-not-met`。该任务正常退出0表示执行完整，不表示求得稳态。

## 为什么下一步补侧向耦合

`studyRocketShellLateralCoupling`对**同一个已保存的实际方向**作如下比较，不新增NS调用，不提交更新：

1. 从原线预条件矩阵B代数恢复`J_line δ=δ/tau−Bδ`。
2. 保持原侧面冻结Rusanov/两点黏性导数，补上被法向线丢弃的侧面左右邻居非对角作用。
3. 再将整个侧面的Euler导数换成原精确Godunov选中波系导数，黏性和功速度仍采用原两点/冻结近似。完整侧面替换成对散度，五量体积积分相消。

| 固定方向的近似作用 | 小域相对原NS作用误差 | 真实20°箭体相对原NS作用误差 | 真实方向余弦 |
| --- | ---: | ---: | ---: |
| 法向线 | 0.03056590 | 1.34612778 | −0.25021403 |
| 补侧面邻居，冻结Rusanov | 0.02214180 | 0.54127059 | 0.85919324 |
| 补侧面邻居，精确侧面Euler导数 | 0.00033508 | 0.12879043 | 0.99175093 |

真实域651816个侧面按2048面批量处理；本机线作用0.082s、Rusanov侧面2.77s、精确侧面7.22s，四个导数批次缓冲合计最大1.6384MB。这些是单次研究记录，不是完整求解加速倍数。完整CSC图矩阵的结构上界约4790万非零、原矩阵约775MB，尚未包含装配峰值、排序和分解填充，不能称已经测得可用的ILU成本。

Python独立用守恒变量方向、本构公式和原共享面符号重建全部侧面作用；小域共96个侧面，小域与真实域各选65面用公开Clawpack压力曲线和独立Brent根差分抽查，最大差约8.65e−10/4.39e−10。所有近似全域作用和五方程统计一致，真实完整侧面替换的体积积分误差约9.81e−17。

这里的12.9%是一个保存方向上的**近似算子作用误差**，不是压力/热流误差、线性系统收敛或飞行精度。沿该旧方向，近似稳态缺陷仍约0.993；补齐矩阵后必须重新求方向，不能直接接受旧方向。精确侧面近似的连续方程作用误差约7.52e−6，但三个动量约7.88%、30.0%、49.3%，能量约9.98%，表明WLS黏性、功速度链式项和边界敏感性仍不能省略或当作完整NS Jacobian。

## 下一项实施与验收

优先将已证实重要的侧向邻居和精确侧面Euler导数纳入可控内存的右预条件器，先做完整小域装配/求解对照，再从同一真实端点有界重算方向。原法向线可作图系统的块平滑；若采用内层迭代，应明确固定线性作用或使用匹配的柔性外层算法，不能把随右端变化的非线性预条件当固定GMRES矩阵。不得先盲加旧方向数或放宽0.1/80K/原稳态门槛。

已有`buildCutCellDiffusionStencil`的WLS梯度可作为后续改进依据，但其冻结边界应力墙模板仍采用旧完整位移约束，没有当前静止壁速度切向约束；能量中速度乘牵引也需要链式导数。不能把旧扩散矩阵直接称为当前完整NS Jacobian。

真实区域还须完成收敛、近壁/网格/外域和边界敏感性、物性/湍流适用性及公开基准比较。上述研究只服务这一地区域求解，不能替代工程模型扩展或全面积验收；科研UI继续并列推进。
