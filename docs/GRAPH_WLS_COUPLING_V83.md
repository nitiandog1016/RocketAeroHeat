# v83 当前完整J与图近似的黏性耦合诊断

本轮沿既有真实20°箭体同Q继续，目的为选择下一项有证据的预条件器修正。没有推进物理状态，没有重建792列粗像，没有重复96步SVD配置，也没有改动原NS或验收门槛。这是已测试的方向诊断，尚未实现新的耦合块预条件器。

## 定义与分项

当前模型为已校核的选中分支方向作用`J*d`；图算子保存为`B=I/tau-Jgraph`，比较时严格使用`Jgraph*d=d/tau-B*d`消去时间项。这里的tau仅属于预条件器，不是物理时间。

完整J分为内部法向Euler、内部侧向Euler、外边界Euler、固壁Euler、WLS黏性应力、导热、`U*d(应力)`功和`dU*原应力`功。图近似内部Euler采用相同的精确选中波系，外边界冻结储库；黏性采用两点法向差分，功速度冻结，因此没有后一项功。

`tests/splitRocketGraphDirection.m`从当前缓存取得完整分项，并用独立表达式重建图分项，最后和保存的B逐方向比较。程序只接受明确的原面层域、精确内部Euler、静止Dirichlet墙及非wall外边界。分项总和是J作用，不是预条件残差，也不是非线性接受证据。

`tests/testRocketGraphActionSplit.m`使用已存32CV/160量完整Jacobian，未重新逐列构造。两组方向同时对照完整缓存作用、保存稠密矩阵和原NS中心差分。`graphsplitunit01`实际exit0、源码锁稳定，引擎60020；原NS差分相对差为1.91759e-9/2.18450e-10，分项与稠密参考差约2.41e-16/3.06e-16。新原NS共5次，单列于主链以外。

在总Newton方向上，外边界Euler的有符号贡献仅约3.07e-5；两项功分别约0.08471和0.14823。单独将应力分项替换成当前完整作用，方向差异预计由0.06685降至0.03261。这只是同一给定方向的代数替换，**不是已实现预条件器的效果、线性收敛保证或实际热流精度**。在剩余方向上，导热同样重要，不能只修应力而忽略能量耦合。
