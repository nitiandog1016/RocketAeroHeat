# outputs 目录用途与保留规则

`outputs/` 是本地运行数据区，不是源码目录。它包含历次计算结果、续算检查点、矩阵缓存、验证证据和三维工作台导出。整个目录受 `.gitignore` 排除，GitHub 源码同步没有备份其中的大型计算结果。

**2026-10-29最新清理：** 再次核对后删除五项v83旧分解因子和已被Q41替代的六项Q40准备矩阵，共11文件，文件长度4,267,156,908字节，磁盘空闲实际增加4,267,143,168字节，约4.27GB。独立全目录核对其余27,617个原文件的大小、修改时间和文件ID不变，49项保留依赖及734项历史MATLAB源码版本逐项SHA通过。Q41/Q40原状态、几何、方向、检查点、失败证据和现有工作台保留；没有重新求解。去重后的唯一文件长度现为77,455,110,739字节，约77.46GB；这是文件长度估计，不是磁盘簇分配空间的精确测量。详见[最新清理说明](validation/storage_20261029/followup/README.md)。

同日较早一轮已回收v83两组过时构造缓存9文件，磁盘空闲实际增加3,219,111,936字节，约3.22GB。该轮结束后又有新的v93本地计算输出生成，两个时点的剩余量不能直接相减当作本轮删除量。旧回执见[首轮说明](validation/storage_20261029/README.md)。

| 内容 | 用途 | 保留规则 |
| --- | --- | --- |
| 原几何、已接受状态、边界与气体参数、数值方向/检查点 | 继续当前计算，追溯已有结果 | 保留唯一副本；不能只靠 GitHub 源码恢复已算出的状态 |
| `current_peak_*_evidence.mat` | 缓存某一状态的导数、矩阵、分组因子与度量，避免重复构造 | 保留当前正在使用的系统；旧工况在输入与构造源码核对后可清理 |
| 工作台 HTML/JS/CSV、旧界面导出、重复隔离数据 | 查看三维分布，复核历史界面与交付 | 内容一致时共享磁盘数据，保留原路径；不再默认生成大型重复工程包 |
| 日志、小型 JSON、来源 SHA 与验证回执 | 记录成功、失败、方法和适用范围 | 保留，不能因为清理缓存就改写历史计算结论 |

## 是否需要把整个目录保存在本地

日常运行程序需要项目源码和选定模型，不要求随软件附带全部旧输出。但正在进行的研究还需要本地的当前状态、几何、检查点，以及用来核对已有计算结论的独有历史结果。这些文件未上传GitHub；直接删除整个`outputs`将失去原状态续算与部分验证能力。

旧矩阵/分解因子属于可再生缓存，确认不再使用且输入、构造源码已保留后可以删除；代价是以后复查时重新构造。历史日志、小型SHA回执和独有结果继续保留。已有硬链接按不同路径展示，却共用一份磁盘数据，因此删除一个重复路径通常不会释放相应文件长度的空间。

本次新清理的五项因子来自`patchhierarchyreal01`、`blockfillreal01`、`overlapFreal01`、`floworderfactor01`和`spatialreductionreal01`。五项旧试验的实际进程均已终态、exit0且源码稳定；原数值方向、结果、输入矩阵及依赖的其他因子保留。原构造源码由已发布Git字节或小型raw原文绑定。历史矩阵审计需要按记录在新目录重建构造阶段，不能直接运行已缺缓存的旧审核命令，也不能承诺重建MAT的历史SHA相同。此次没有删除独有的Arnoldi失败证据或中断检查点。

## 旧缓存清理后的复算

本轮只纳入构造源码仍与清单 SHA 完全一致的 v86—v89 十组旧准备系统。每组的 `peak_system.json` 保留为原始历史记录；清理后另加 `CACHE_PRUNED.json`，列明输入和被移除的六项派生缓存。旧清单不能直接恢复，需在新目录调用：

```matlab
addpath('internalFlow'); setupCutCellFlow;
prepareRocketCurrentPeakSystem(newFolder, sourceFile, geometryFile, 'domain');
```

`sourceFile` 和 `geometryFile` 来自清理计划对应条目。后续使用新生成的准备清单，不能绕过来源检查，也不能冒称重建 MAT 文件的历史 SHA 会完全相同。重建需要额外计算；本轮没有为了清理重新执行数值求解。

首轮因构造模块变化而保留的v84三组缓存，已在后续清理中找到并保存完全匹配的历史源码后回收。原始数值结果、检查点和失败记录保留。

v91完成实际试算与独立审计后，已另行核对并删除被替代的v90六项派生缓存，实际回收2094682112字节；Q37输入、Q38/Q39结果、几何、方向与v91最近系统保留。回执见`docs/validation/v91/obsolete_v90_cache_cleanup.json`，旧v90目录同样带`CACHE_PRUNED.json`。这不会恢复或改写被清理缓存的原SHA，也没有把GitHub源码当作MAT结果备份。
