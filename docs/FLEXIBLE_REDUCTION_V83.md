# v83 完整父矩阵的可变 F 内层耦合

本轮承接 `FULL_F_IMAGE_SCALE_V83.md`。此前保存向量在固定旧 C 值时，父方程剩余超过99.9%的平方范数位于C行。本轮重新纳入全部原C未知量，固定完整父矩阵作用，以有预算的F内解作为可变右预条件。这里的C既是完整父研究矩阵的名称，也用于C/F代表点；文中“完整父C”与“C行/代表点”分别明确，不把线性研究当原NS或新区域热解。

## 程序与数学范围

新增完整中文 MATLAB 模块：

- `applyRocketFlexibleReduction.m`：两次有界归一化F内解、一处旧粗局部映射、完整B/E耦合回代，并保存实际中间量。
- `solveRocketFlexibleReductionKrylov.m`：固定完整父C的单周期柔性右预条件GMRES，保留原正交/组合门槛，单列内层调用和未达目标次数。
- `compactRocketFlexibleReductionReport.m`：JSON仅保留标量/历史/工作量，完整V/Z和内层向量留在MAT。
- `tests/testRocketFlexibleReduction.m`、`studyRocketFlexibleReduction.m`：两排序稠密参考及同Q完整真实域试算。

把完整父矩阵按原CV全部五量分为 `[[A_FF,B],[E,D]]`。对每次完整右端 `(b_F,b_C)`：

1. `f_first=Phi_j(b_F)`，Phi_j是有预算、按原F残差报告的LSQR近似解。
2. `q_C=b_C-E*f_first`。
3. `x_C=M_S_old*q_C`，M_S_old只作用已有旧S的认证局部逆。
4. `x_F=Phi_j(b_F-B*x_C)`，回到全部F点；拼回原全CV五量顺序。

旧S来自 `D-E*M_old*B`，并非上述新F内解对应的精确Schur矩阵。它在这里仅作为明确的近似预条件对象。固定迭代上限的LSQR系数仍随右端变化，因此Phi_j一般不是固定线性映射。F内层未达到其原1e-3目标时仍明确记录“未达目标”，不称精确消元。

外层使用完整固定父C作用，按每次实际预条件方向Z建立Arnoldi关系，组合为 `x=Z*y`，不能以某次 `M*(V*y)`替代。现有稳健内核保存实际Z、同步缩放方向及完整像，使用单周期、0回收配置；新包装明确标为FGMRES。方法依据为Saad的柔性内外层预条件GMRES（SIAM J. Sci. Comput. 14(2),1993，DOI `10.1137/0914028`）。本实现用全部实际方向/完整作用核对，而不是仅凭算法名称判断可用。

原完整C目标不超过1e-3，原Arnoldi正交与组合门槛均为1e-8。内层F作为近似预条件不必每次精确求逆，但它的未达目标身份不能提升为F合格；最终原父C、选中J、原NS和区域物理资格仍分别判断，不能相互替代。

## 保存方向的精确误差分解

`diagnoseRocketFlexibleSchurDefect.py` 对每个实际预条件向量独立核对：

`b_C-E*x_F-D*x_C = (b_C-E*f_first-S_old*x_C) + E*(f_first-x_F-M_old*B*x_C)`。

第一项是旧粗局部方程缺陷；第二项是当前实际F映射与旧粗近似之间的差异贡献。8次核对的恒等式相对差3.07e-14—3.94e-13。按每次完整预条件右端归一，旧粗方程缺陷约1.03—8.06，差异贡献约31.66—96.57，后者每次均更大。

该差异项包含新F映射与可变内层误差的影响，并非已经独立得到精确Schur与旧S的差值。它只解释这些保存方向，不证明唯一全局停滞原因。它支持不再重复同一8方向/双32步配置，也不单靠提高旧粗逆精度继续试算。只读诊断另有旧S8次、旧F局部8次、矩形32次，均不记入原求解或NS工作量。
