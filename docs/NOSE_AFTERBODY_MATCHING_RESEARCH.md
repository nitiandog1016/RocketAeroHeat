# 球鼻到后体外缘匹配：公开资料研究与实现起点

日期：2026-10-12。状态：**文献公式已核对，已知激波穿越角的独立热力恢复内核已测试；几何与质量匹配方案仍为草稿**。新增内核没有接入默认外流，没有完成真实球鼻/后体匹配或实验数据对照。本研究沿用 v49 的接口诊断，不重新进行共享边采样或填补无效面实验。

## 当前结论

球鼻的正激波驻点熵与侧壁的局部切楔/切锥熵不能通过接缝位置插值总压来获得可靠统一外缘场。适合下一步实现的工程路线是：**内部近似激波形状 + 流管质量坐标 + 边界层吞入质量匹配**，由边界层外缘流线实际穿过的激波角确定外缘熵，再使用同一热物性下的局部静压、熵和总焓恢复温度与速度。压力模型、流向/流管度量和边界层厚度也必须一致，不能只替换速度或总压。

这条路线不要求用户导入外部 CFD，也不需要把全三维 Euler 求解作为 UI 或工程模型的前置条件。它仍需独立实现和验证，不能马上把 v49 球鼻模块启用为正式全区域外流。

## 原始来源和公式位置

1. **NASA SP-8062 (1971), 4.2.1，印刷页30 / PDF第36页。** 鼻部可使用驻点熵；稍钝细长体的外缘流线可能穿过较弱的斜激波，需要质量平衡求局部熵，并依赖激波形状与粘性流信息。[NASA 原始报告](https://ntrs.nasa.gov/api/citations/19710021703/downloads/19710021703.pdf)

2. **F. R. DeJarnette, NASA CR-112180 (October 1972), _Calculation of Heat Transfer on Shuttle-Type Configurations Including the Effects of Variable Entropy at Boundary Layer Edge_。** 采用近似 Maslen 激波形状与逐流线质量匹配。原始印刷页24–28（PDF第29–33页）公式65–74已在线读取，并把扫描页渲染后逐项核对。h 为相邻表面流线的横向度量；Γ 为激波与来流的夹角，避免与本项目攻角 beta 混淆。[报告与原始 PDF](https://ntrs.nasa.gov/api/citations/19730005231/downloads/19730005231.pdf)

   ```text
   d(sin Γ)/dS = (p_b − p_sh) h / (U_inf Ψ_sh)                (65)
   Ψ_sh ≈ ρ_inf U_inf ∫ sin Γ h dS                          (66)
   p_b = p_inf + (p_e−p_inf)(p_2−p_inf)/(p_stag−p_inf)        (67)
   Ψ_BL = ρ_e U_e h (δ−δ*)                                  (68)
   Ψ_sh(at crossing point) = Ψ_BL                           (69)
   δ−δ* = 5.27 theta_m                                      (71, 层流)
   δ−δ* = theta_m(10.3−H)                                   (73, 湍流)
   ```

   其中 p_2 为正激波后的**静压**，p_stag 为其后驻点压力。p_b 只用于式65，**不可写成 UI 的物理压力**。式66是报告的度量近似，不能当作任意三维激波面的精确质量积分。式71、73与报告的 Beckwith–Cohen / Reshotko–Tucker 及轴对称类比边界层定义相配套；现有项目的 Thwaites theta 并不自动满足这一关系。

3. **Inouye, Rakich & Lomax, NASA TN D-2970 (August 1965)，钝锥算例、图3总压剖面。** 原始报告检查了钝锥激波层的熵插值：压力/激波形状相近时，线性熵插值仍会错误降低总压峰值；一条无粘流线上的总压应保持对应的激波后值。这支持保留流线质量坐标，不能用距离平滑代替熵输运。[NASA 原始 PDF](https://ntrs.nasa.gov/api/citations/19650021355/downloads/19650021355.pdf)

4. **DeJarnette, _Approximate two layer (inviscid/viscous) methods to model aerothermodynamic environments_ (1992)，NTRS 19940034113。** 公开摘要把修正牛顿与近似激波形状的简单应用限制到例如15°–45°球锥，指出熵层吞入需要无粘/边界层耦合。完整报告在该条目没有下载，本次仅核对摘要，不据此推广到圆柱或复杂箭体。[NASA 条目](https://ntrs.nasa.gov/citations/19940034113)

## 建议实现的模块顺序

以下是基于来源的**项目设计建议**。前向跃迁与热力恢复已有独立内核；质量坐标匹配、激波/流管生成及一致边界层耦合尚未实现。

### 已测试的前向热力内核

`recoverShockEntropyEdgeState.m` 接收已知激波穿越角 Gamma 和输入物理静压，执行法向跃迁、切向速度连续及完整总焓/激波熵恢复。输入角度与静压具有独立来源字段，不宣称由内核求得压力分布、波形或穿越质量坐标。定比热模式与固定组分 NASA7 模式明确区分，默认物性域外返回 NaN 和真实状态。

`tests/testShockEntropyEdgeState.m` 已核对独立定比热公式、质量/法向动量/完整能量守恒、总压熵恒等式、Mach 波极限、正激波极限、标量/行列/矩阵广播，以及无效角度/静压/物性范围的拒绝和逐字段状态一致性。1200 K 上游弱激波用例采用同物性的物理声速（gamma=1.324429、Mn=1.02），避免旧名义 gamma=1.4 接口误拒绝物理超声速法向分量。该分支直接在密度比上求同一 NASA7 能量方程，不切换定比热或裁剪强度。

最终针对性测试退出码为 0，证据随 v51 归档。上述证据只支持热力恢复与软件输入合同；不证明激波几何、质量匹配、热流精度或实验一致性。内核仍未接入 `solveExternalFlow.m`。

### 1. 独立质量坐标恢复内核

建议先新增独立 `recoverEntropyLayerEdgeState.m`，不覆盖 `mesh.boundaryLayerEdge`。输入必须明确提供：物理 p_e、总焓、同一流管的 Ψ_sh–Γ 表、h、质量厚度 δ−δ*、几何/工况与每项来源。初始熵可用正激波值或前一站值；在迭代中用新 rho/U 更新 Ψ_BL，在单调质量坐标内找激波穿越点，计算该 Γ 的激波后熵/总压，再恢复同一热力模型的 T、rho、U。

先用定比热版本独立核对质量、能量和熵守恒，再接入固定组分 NASA7 物性。已知激波角的**前向跃迁**与给定壁面转角的切楔弱支求根是不同问题；应以 U_inf sin Γ 的法向跳跃并保留切向速度计算，不能把 Γ 当壁面转角传给 `solveObliqueShock`。

输入量属于边界条件或模型输入；输出应同时记录 `pressureSource`、`entropySource`、`shockShapeSource`、`massThicknessSource`、穿越质量坐标、熵/能量残差、迭代状态和适用范围。Ψ_BL 超出已有激波表、非单调质量坐标、物性越界、分离或无迭代收敛时返回 NaN 与真实状态。没有来源的 p_e/h/质量厚度，内核不得自行补出它们。

### 2. 先建立独立球锥的激波/流管生成器

建议先在来源能够支持的光滑球锥上实现 CR-112180 式65–67：使用一个贯穿球鼻与锥面的物理压力模型，按同一连续流线得到 S 与 h，生成 Ψ_sh–Γ 表。鼻端 Γ=90°、Ψ=0 有奇点；必须使用报告的驻点局部展开/激波曲率条件启动，不能加入任意 epsilon 代替边界条件。

零攻角轴对称几何可先由圆截面解析得到 h=r，作为数值核对起点。有攻角需计算相邻连续表面流线的度量与偏置驻点局部曲率，不能把 Dijkstra 前驱树当作已经求得的流管。保留现有网格与坐标约定，连续曲线只用于工程外流计算。

### 3. 边界层一致耦合与压力共同验证

独立内核校核不等于真实几何闭合。需实现与来源相配套的质量厚度，或通过可追溯的速度/密度剖面积分直接得到 ∫rho*u dy / (rho_e U_e)。每个迭代站更新外缘熵与边界层质量，并重新评估流向与 h；保留真实分离/相关式超域条件。

固定某条无粘流线的总压可以沿程输运；**边界层外缘却会在后续站选择另一条流线**。因此全后体保持驻点总压、或沿面元前驱链保持单一总压，均不能自动描述熵层吞入。

半球头圆柱的鼻部诱导压力与有攻角横流也尚未解决；上述球锥路线不能自动推广到它。当前球鼻压力与自由来流/切楔侧壁压力本身也有跳变，质量匹配只解决熵来源的一部分。需要同时验证 p、U、T、沿流线梯度及热流，不能把接口速度连续作为唯一通过标准。

## 验证与公开实验起点

建议按以下顺序积累证据，并保持“解析校核 / 方法复算 / 实验验证”分开记录：

1. 内核解析检查：正激波穿越极限、已知单一斜激波流管、守恒残差；检查 h 的坐标缩放同时改变两侧 Ψ 后，匹配结果不变；拒绝表外质量、错误物性和缺失来源。制造输入通过仅证明恢复内核，不能证明自算激波/边界层。
2. 独立实现来源方法：球锥鼻端启动、激波角/质量坐标/流线度量收敛，检查同一工况的网格、积分站和迭代容差敏感性。正式数据链路建立前不合并到默认解。
3. 公开实验的配对来源已定位：**Cleary, NASA TN D-5450 (1969)**，15°球锥、M10.6、攻角0°–20°、层流热流与油流线；与 **NASA TN D-4909 (1968)** 的同类激波层性质资料配对。已核对公开条目/索引，但本次浏览工具因大小/访问限制未完整读取两份 PDF，**尚未转录测点、误差或完成对照**。[D-5450 条目](https://ntrs.nasa.gov/citations/19690028226) / [原始 PDF](https://ntrs.nasa.gov/api/citations/19690028226/downloads/19690028226.pdf)；[D-4909 条目](https://ntrs.nasa.gov/citations/19690001458) / [原始 PDF](https://ntrs.nasa.gov/api/citations/19690001458/downloads/19690001458.pdf)。

源报告中已有实验图不能当成本项目已经验证。需要逐项保留工况、几何、壁温/热流基准、测点坐标、单位、数字化误差与原页位置，再与项目内部工程结果对照。
