# v83 鼻端局部细分与原始变量耦合粗基

本切片接续`LAYER_ENRICHED_COARSE_V83.md`。旧210维粗空间在真实`krylov10`方向剩余上接近其表示能力，约70%的剩余平方范数在鼻端轴向最后10%范围。本轮比较两种代数求解手段；它们不是新气动热物理模型，不改变原NS、物理网格、给定边界或正式合格面积。

## 两个候选方向

原始变量候选在相同42组/210未知量上采用组常数扰动[rho,u,v,w,T]，按当前每个控制体的局部状态提升到保守五量。密度扰动同时改变动量和总能量，速度扰动同时改变动量和总能量，温度扰动改变内能；再除以原保守量缩放。该提升是固定基态的线性切线映射，不是改变非线性候选坐标，也不按需要裁剪状态。

局部空间候选保留旧父组边界，选择原墙面质心轴向位置≥90%且位于前四层的控制体。每个父组中的目标单元按CV质心X中位数分开，非目标单元单列；沿正面积共享面重新划分连通分量，保留全部原控制体。真体积P/R和父空间嵌套通过检查。退化单点或同坐标组不强行增加自由度。

未细分父组的像列原字节复制，所有新子组方向单独调用当前完整细层模型。没有用“父像减其他子像”构造末子列，避免舍入残差变成远处稀疏非零项。模型构造作用和复制列数分别计数，不把复用列再次计为模型或原NS调用。

两者均以原缩放细层L2范数作最小二乘投影，稀疏像预算仍256MiB，小Gram条件与Cholesky门槛保持。源Q/几何/气体/边界/缩放及13个细层计算文件SHA绑定；原始变量提升另绑定提升文件SHA。
