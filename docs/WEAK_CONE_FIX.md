# v46：小半锥角弱解与柱段外流断带修复

本页保留 v46 验证记录。文末提到的细网格有攻角锥柱热流为零问题已在 v47 定位并修正，见 [SECTION_NORMAL_RECONSTRUCTION.md](SECTION_NORMAL_RECONSTRUCTION.md)。

本轮修正 `solveThermallyPerfectConicalShock.m` 的数值算法，保留原有固定组分空气、Taylor–Maccoll 锥流模型和气动热方法。没有放宽连续流、分离、物性或几何适用性判据。

## 问题与修正

v45 的 M=4、海拔 20 km、零攻角半球头柱体，在球头/柱段交界有一整圈 96 个面元没有外缘解，致使后方柱段准流线全部断开。独立调用确认 3°～4° 半锥角不能求根。主因是激波能量方程混用 0.5 K 表格插值焓与原始多项式焓；弱激波能量差很小，插值误差改变了非平凡压缩根的括区。

本轮采用：

1. 激波跳跃和锥流积分使用同一原始物性函数。能量方程消除无激波的平凡根：以密度比 r>1 表示原方程，再乘 r²/(r−1)，用焓割线比热计算，避免大数相减；近等温时使用比热极限。
2. 近 Mach 波增加对数分布的激波角候选。只接受首个相邻有效变号括区，求附体弱支。
3. 用自适应 ode45 积分，遇极向速度为零的锥面即终止，避免越过实体边界。射击时以锥面角误差或目标角处极向速度确定残差；最终仍检查实际到达角、无穿透及质量/动量/总焓/熵。
4. 数值未找到根时明确提示不能据此单独判断真实脱体。超出物性范围的状态仍无解。

## 独立数值校核

`tests/reference/generateWeakConeReference.py` 使用 SciPy DOP853 + Brent，从无量纲两变量定比热 Taylor–Maccoll 方程独立生成参考值，不调用 MATLAB。测试选取 T∞=100 K，所有局部锥流状态均低于 150 K，恰好处于项目空气模型的冻结比热域；gamma=1.3995928390635504，M=4。

半锥角为 0.5°、1°、2°、3.75°、4°、5°、10°。参考积分容差从 1e−11 收紧到 1e−12，最大状态变化约 8.6e−12。MATLAB 对照的最大差异：激波角 9.92e−9°、压力比 3.12e−9、温度 8.87e−8 K。参考 JSON 位于 `validation/weak_cone_reference.json`；重新生成参考值才需要 Python/SciPy，普通 MATLAB 使用不需要。

这是同一理论模型的独立数值实现校核，**不是实验验证，也不能证明热流关联式的精度**。另外对实际 M4/20km 的 0.5°～10° 九个角度检查弱支、压力单调性、无穿透和守恒；更广的 Mach、温度和极小角度仍需扩展验证。

## 整模型结果

最终 20 工况报告见 `validation/v46_report.md` / `.json`。相同解析几何、分辨率与配置下：

| 工况 | v45 热流计算面积 | v46 热流计算面积 |
|---|---:|---:|
| 球体，48 档，0° | 43.46% | 72.18% |
| 半球头柱体，48 档，0°，全模型 | 15.76% | 89.75% |
| 同一半球头柱体，仅柱段 | 0% | 98.39% |

半球/柱交界 96 面全部恢复有效外缘及准流线连通。该算例剩余未解热流主要是底面及端部特征面；底面仍没有求解模型，不能以给定底压替代计算热流。球鼻区域的热流仍包含驻点关联式低阶延拓，不因本次外流数值修复而获得新的实验验证。

20° 攻角的细网格锥柱算例仍因疑似分离及其他限制没有可用热流；粗网格半球/钝锥的有攻角流线敏感性仍存在。下一步优先定位这些失败算例的外缘速度、播种与沿程梯度，再推进底面/尾迹、肩部和分离再附模型。

## 发布验证与性能边界

新增 `testWeakConicalShock` 已通过；相关既有回归 5/5 通过：变比热切锥、轴向波系推进、真实箭体内置外流、连续流判据和查看器数据。20 个经典工况均完成；未重复整个测试库。v45 的长时热流/壁温/飞行历程集成通过日志也保留在包内，不能将该旧日志视为 v46 全库重测。

自适应积分和原始物性使真实箭体零攻角外流本次测试约为 10.0 s，原基线约 0.7 s（同机不同运行，非严格性能基准）。这是已知性能代价，后续应在独立校核保护下优化物性求值和重复工况缓存；不能退回不一致的插值焓计算来恢复速度。

完整包的 `example_web` 是本版半球头柱体 M4/20km/零攻角算例，完整经典结果在 `validation/canonical`。`preview` 中的旧 GUI 截图仅保留为历史界面示例。
