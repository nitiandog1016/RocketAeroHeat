## 显式选项与作用域

`solveRocketShellSteadyKrylov`可显式设置：

```matlab
options.normalEulerLinearization = 'exact-branch';
```

`buildRocketShellLineOperator`的第七参数为同名策略字符串。缺省或显式`rusanov-frozen`保持旧装配器和求解器的完整输出合同。

新策略只替换**同一原面跨层法向面**的Euler预条件导数；侧面、外边界、静止墙的原近似保持。原两点Newton应力、冻结黏性功速度及Fourier导数保留。当前真实217272CV域有197520个这样的跨层共享面。完整三维NS方向导数、非线性验收和实际面场仍来自原`cutCellNavierStokesResidual`。

`cutCellExactEulerBranchJacobian`先调用原精确Godunov通量进行基态、正根、真空和80—2000K检查，再对当前选中的波系分支求导。`cutCellExactLineFaceLinearization`用该Euler导数替换旧冻结Rusanov部分，保留原近似黏性部分。

这仍是预条件，不是完整NS Jacobian：WLS与横向黏性模板依赖并未全部进入线矩阵，侧向非对角项也没有新增。正式空间方程、给定Tw/墙速/远场、物性范围、守恒、线性0.2及原稳态门槛均不改变。

## 数学定义

两侧压力曲线满足`fL(p*) + fR(p*) + unR − unL = 0`。固定输入状态对任一守恒分量求导时，先由隐函数定理得到`dp*`，再传播到接触速度、星区密度和实际xi=0采样状态，最后重建三个动量分量及能量通量的导数。

激波曲线、等熵稀疏曲线分别求导；原态、星区、稀疏扇六种采样区分别处理。切向速度来自原算法实际选中侧，其导数与法向分量分开传播。

在接触速度或波速恰好跨过xi=0时，Godunov通量并非处处光滑。本函数采用原算法当前选择的分支，记录零接触速度数量，不称为全局光滑Jacobian或一般熵稳定证明。原精确压力曲线与波系来源沿用v82已核对的理想气体Riemann公式和Clawpack公开压力曲线；本轮没有新增真实空气/湍流或实验资格。

## 下一数值路线的历史计划（其实现状态以下方2026-10-24更新为准）

当前求解的是`(I/tau − J) delta = R`，其中R和J在原缩放未知量中定义。即使这个线性系统的缺陷较小，也不保证`R'*(J*delta)<0`，因此不能从“线性目标通过”推出原残差平方范数下降。当前有界线搜索失败是实际证据；尚未保存的失败方向不能伪装成已经独立求得的导数结论。

下一步拟显式求直接稳态Newton系统`(-J)*delta=R`，仍以原完整三维NS方向导数作为实际线性作用，法向线仅作右预条件。对采用的线性作用，若相对缺陷eta<1，则`R'*(J*delta) <= -(1-eta)*||R||^2`；波系非光滑或差分误差仍需原完整残差与状态护栏验收。将检查实际方向/缺陷/下降模型并保留失败方向证据，再做同一真实端点有界试算。

这一直接稳态选项尚未实现或验证，不能在配置中假定已经存在。实现时必须完整重放旧缺省路径，保持原空间方程、温域、RMS下降、守恒和稳态门槛，不能把前述停止伪装成已解区；不得另开独立Euler主线。
