# v83 完整父矩阵 LSQR 与原 NS 总方向检查（2026-10-26）

当前为已测试研究，最新正式工程交付仍为 v82。当前单时刻全面积与统一科研工作台的优先级不变。本文不增加生产合格面积，也不代表真实区域已经收敛。

## 模块用途与计算方法

- `buildRocketParentImageScale.m`：遍历完整父矩阵 C 的原块，计算固定五量局部映射 M 后的全部像列二范数，以正对角 D 在右侧归一。保留全部 217272 个控制体及 1086360 个未知量，不固定 C 代表点、不使用旧 Schur 近似、不形成全局预条件乘积。
- `solveRocketCoupledPatchesTranspose.m`：使用同一缓存局部逆的转置，提供与实际 M 配对的伴随，不能另求一个略有差异的逆作为参考。
- `solveRocketParentLeastSquares.m`：对 B=C M D 使用有界 LSQR，伴随为 D Mᵀ Cᵀ。求解后回到原单位和原完整 C 范数验收。原 C 目标 1e-3，内部停止精度至多 1e-12；原生 flag 不能代替原 C 目标。方法属于 Paige–Saunders LSQR（ACM TOMS 8(1), 1982，DOI: 10.1145/355984.355989）。
- `loadRocketValidatedDirectionProbe.m`：将同基态、已经检查原 NS 的总方向作为明确初猜。绑定状态、五量尺度、物性、边界、完整几何、13 项计算源码及来源文件 SHA；从原保存差分率重算缺陷和下降界。返回方向后，主求解器重新检查当前模型、原 NS、正性、80—2000 K 和线搜索。

初猜入口不制造原求解器的结果或接受历史，不复用旧导数为新的接受依据。旧 `result/limited` 初猜路径保留，完整回放通过。修改和新增 MATLAB 文件均以完整文件保存在项目中，中文注释说明模块用途。
