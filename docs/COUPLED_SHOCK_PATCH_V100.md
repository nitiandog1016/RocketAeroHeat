# 轴线正则的连续式—法向动量耦合激波层

状态：**已测试数值研究，区域模型尚未收口。** 两种物性的驻点极限和直接守恒加密已验证；高阶独立积分、长度缩放及外侧域检验存在未通过项。它没有替代真实20°箭体横流—收缩—后体的区域目标，也没有新增正式压力、热流或壁温资格。独立数值核验与实验验证分别记录。

## 为什么需要改变闭合

v99独立轴线延拓证实，旧TP-3018显式一阶压力与线性法向速度组合，在M5/30km工况的端点比正常激波后精确同熵驻止压力低约0.47%/0.42%。若继续使用完整总焓恢复切向速度，就会出现约60.61/55.41m/s的虚假轴线余速。继续只调共同激波形状不能消除这项闭合缺陷。

本分支保留原显式方法作为对照。新压力来自连续式、法向动量、同一总焓和流线入口熵的共同约束；法向速度不再预先指定为线性。没有压力混合、裁温、裁速度或逐面元独立激波角。

## 坐标、范围及共同几何

项目主轴仍为X、鼻尖+X、零攻角来流−X，全部SI。局部第一轴沿实际均匀来流，正交框架记为`frame`。以下`z=r²`是局部半径平方，**不是世界坐标Z**；`n`沿激波内法向为正，质量比`eta`从激波1走向候选生成体表0。

当前共同激波为轴对称二次曲线：

```text
f + B*f²/2 = k*r²/2,  k>0
L = 1 + B*k*z
W = 1 + k*(B+k)*z
f = k*z/(1+sqrt(L))
1/G = sqrt(L/W)
k_m = k/W^(3/2),  k_b = k/sqrt(W)
```

`B=0`为抛物面；`B=-k`为球形激波。整个域要求`L>0`和`W>0`。输入`K`须等于`k*I`；非轴对称几何显式拒绝，不取平均曲率冒充支持。给定轴对称激波和流场是额外假设，不代表原20°箭体绕来流轴具有对称性。

## 同一流线的入口熵与法向速度

均匀上游的轴对称投影质量满足：

```text
psi_s = rho_inf*U_inf*z/2
psi = eta*psi_s
z_entry = z*eta
S(z,eta) = S_shock(z*eta)
```

入口熵由同一上游的正常压缩跃迁求得。NASA7使用项目`continuous-project-cp-v1`连续焓/熵积分，不与旧总状态混用。通过隐式RH导数计算`S'_shock(z_entry)`，轴线上不把几何梯度再除以r。

以`u=r*w`保留有限的未知正则量w，令：

```text
h = 1 - n*k_m
g_b = 1 - n*k_b
J = h*g_b
mu = rho_inf*U_inf/2
Bmass = rho_inf*U_inf/G
n_eta = -mu*h/(rho*w*J)
bhat = 2*n_z/(G*h)
A = Bmass*eta/(rho*J)
v = A + z*w*bhat
```

最后一式来自完整轴对称连续式。`eta=0`时A=0，因而候选体表速度与所生成体表相切；这不等于其速度已经与真实原三角面相切。v作为独立状态推进，原约束只作回代检查，不用投影修改v以掩盖漂移。

## 法向动量及耦合推进

物理法向Euler分量保留：

```text
dp/dn = -rho*[k_m*u²/h + (u/h)*(dv/ds)|n + v*dv/dn]
Hstatic = H0 - (z*w²+v²)/2
```

把连续式、`dS/deta=z*S'_shock`及非正交坐标变换代入，得到每个径向节点的2×2系统。D是对z的径向微分矩阵：

```text
Rw = -T*S'_shock/w - mu*k_m/(rho*J)
     - 2*mu*(D*v)/(rho*J*w*G)

Jn/J = -k_m/h - k_b/g_b

C = Bmass/(rho*J)
    + A*[z*S'_shock/R - (Jn/J)*n_eta]
    + 2*z*w*(D*n_eta)/(h*G)
    + z*w*bhat*k_m*n_eta/h

[1                         bhat          ] [w_eta] = [Rw]
[-z*(bhat+A*w/a²)           1-A*v/a²      ] [v_eta]   [C ]
```

在连续式约束上，行列式等于`1+z*bhat²-A²/a²`。实际计算使用原2×2矩阵的行列式，不利用约束消去数值漂移。必须严格为正；法线聚焦、非有限值、切向倒流、温域超限或声速退化均拒绝，没有默认补值。

空间使用Chebyshev–Lobatto半径平方节点，轴线r=0参与耦合求解。`u(0)=0`来自对称性，而w、n、v都由方程推进。实际积分以`1/k`、`U`和`U*k`归一化n、v和w，径向矩阵也在无量纲坐标中构造；物理输出仍为SI。质量坐标方向使用MATLAB ode113及明确误差和步长配置。批量焓反解采用带括号Newton，已收敛根立即冻结；精确根不能因落在新括号端点而被替换为中点。

NASA7长度缩放2.3倍后的最大相对压力差为4.89e-7，未过原2e-9门槛；法向距离缩放差只有2.42e-11m。对0.028/0.032m外侧域，r<=0.02m同位置的厚度差约1.21e-11m以内；0.036m外侧域的两种物性在19节点右端评估中均触发声速行列式拒绝。拒绝记录是ODE试算点，不证明真实已接受流场的精确声速面。没有放宽门槛，也没有把拒绝记录写成完整场。

固定候选在原19,752个面上九条射线全部命中，但最大体形差为620.728微米，未过原10微米门槛；候选速度相对原壁面最大法向分量比例8.88%。这两项直接阻止将本分支作为真实箭体外缘。没有执行新的体形拟合。

完整记录见`docs/validation/v100/`。工作台新增四组粗/细对照，52条法向列、1,092个保存站点；算法、原面号、重心、未知热流/温度身份与数值一起导出。该页仍是保存研究的查看流程，不能作为新实时导入/网格/求解主程序的完成证据。

局部光滑Cauchy反算在亚声速区可能对径向高频和外侧截断敏感。有限节点上的加密趋势不证明任意形状、任意网格或全局边值问题稳定。真实箭体法向距离、原面元速度切向条件、三维横向动量和跨声速区域仍须独立验收。即使轴线上压力正确，也不能授予真实整箭或边界层外缘资格。

## 路线复核：不再靠继续增加Cauchy节点数解决全部缺口

本轮重新读取了[Hamilton的NASA TP-1154](https://ntrs.nasa.gov/api/citations/19780014389/downloads/19780014389.pdf)摘要、引言与方法开头。原文明确讨论给定激波向内反算的混合型初值问题及随线数增长的舍入不稳定。其特定算例的少线数经验不是本项目统一节点上限，也不是本程序的独立精度证据；但它与本轮实测的“守恒加密改善、独立高阶结果变敏感”相符。

[Barnwell的NASA TN D-6283](https://ntrs.nasa.gov/api/citations/19710021731/downloads/19710021731.pdf)摘要与引言给出含攻角、尖肩和部分非轴对称光滑体的非定常激波拟合路线。它以给定真实体形及全激波层的时间推进处理跨亚声速区，适用限制仍须遵守。另阅读了[2020年高阶激波拟合的NASA目录摘要](https://ntrs.nasa.gov/citations/20205002191)，涉及ALE移动网格与激波运动条件；本轮没有复现该有限元方法或移用其精度结果。

**项目下一步判断：**将本分支保留为驻点/热力/连续式核验工具，局部区域求解改为同时约束真实壁面与共同激波的边值/直接激波拟合形式。先核对移动激波RH、离散几何守恒及实际壁面切向条件，再用有预算的小规模钝体域检验外流；三维向量通量与横向条件在接口中保留，不能把轴对称结果直接复制到20°整箭。通过真实区域条件后接v96外缘与v61边界层、原三角面及统一工作台。该局部工程外流内核不作为其他区域方法、分离/再附/底面或科研UI的通用Euler前置。此处是下一步方案，尚未实现或验证。
