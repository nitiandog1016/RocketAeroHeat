## 原始变量总方向正则化研究

新增 `buildRocketPrimitiveUpdateMetric.m` 与 `applyRocketPrimitiveUpdateMetric.m`，在真实初态构造线性度量：相对密度、三向速度/当地声速、相对温度。完整保留密度—动量—能量链式耦合及其转置。

`solveRocketRegularizedParentDirection.m` 显式研究路径求

`min_v ||C*v-rhs||² + penalty²*||W*v||²`，其中 `v=initial+M*D*y`。

增广右端包含 `-penalty*W*initial`，因此约束总方向，而非只压小增量。penalty按原右端和初猜度量范数归一，原C残差仍以原右端验收。此路径不改正式NS方程、现有缺省算法、状态或任何接受门槛，也不以增广目标下降冒充原C或原NS通过。
