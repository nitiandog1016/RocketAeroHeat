## 实际实现

`writeSU2HybridInitialState.m` 在原三角棱柱—四面体混合域生成守恒初猜。令法向距离与显式厚度之比为 η，b=η²(3−2η)，在厚度外取 b=1；速度由无滑移过渡到精确自由流，总焓由 cpTw 线性过渡到自由流总焓。静温使用代数等价式

`T = Tw + (Tinf−Tw)b + Uinf²/(2cp) b(1−b)`。

因此初温不低于 min(Tw,Tinf)，没有温压裁剪；初始压力均为 p∞。完整外棱柱面、全部四面体及远场取精确自由流。该场是**数值初猜**，不是已求解边界层、激波或热环境。当前仅支持给定统一壁温和已核对的完整法向混合域，超出棱柱厚度或不支持的热边界在启动前拒绝。

主工作台边界页增加初始场方式、厚度和显式检查点空间上限。默认仍为自由流/100 MiB，旧快照不自动增加新字段。真实域可明确选择更大上限；该估计只覆盖检查点，不包括网格、初态、运行内存。控件测试覆盖 256 MiB 选择、过厚及绝热拒绝。未重新执行主五步骤完整求解，也没有新增原生窗口截图验收。
