# v83 完整 F 子系统的受限重叠试算

本轮承接 `FULL_F_SUBSYSTEM_V83.md`，复用冻结的完整 A_FF、相同右端、固定 C 值及核心/至多两个外邻 F 点。这里只研究预条件映射；不是新的三维流场、区域热解或实验验证。

## 程序与数学范围

- `factorRocketRestrictedOverlap.m`：从完整 A_FF 原系数构造扩展主子矩阵，缓存全部五量的完整扩展逆；按核心/扩展尺寸分桶，统一拓扑向量形状，检查核心覆盖与资源预算。
- `solveRocketRestrictedOverlap.m`：收集扩展右端，作用完整扩展逆，只返回原核心行。每个 F 核心输出一次，外邻输出不叠加或平均。
- `solveRocketOverlapFullF.m`：使用上述固定线性映射，对完整 A_FF 作一次最多 32 方向的 GMRES。内部求解不是固定线性逆，不自动替换旧 Schur 中的 M_F。
- `tests/testRocketRestrictedOverlap.m` 与 `studyRocketRestrictedOverlap.m`：分别完成小域稠密参考和相同真实输入试算。
- `tests/auditRocketRestrictedOverlapUnit.py`、`auditRocketRestrictedOverlapReal.py`：用独立数组计算核对拓扑、系数、逆、映射和完整算子最终像。

令 R_g 限制到扩展组，E_g 仅延拓该组的核心输出，则固定映射为

`M_RAS b = sum_g E_g (A_g^-1 R_g b)_core`。

全部原 F-F 连接仍在完整算子中。某个完整扩展逆未通过原输入 1e-8 证书时，明确退至通过证书的原 CV 五量对角；原完整逆的拒绝身份保留。CV 对角也不安全时拒绝整个映射，不替换原方程或裁剪系数。

## 已测试结果

`overlapFunit01` 实际 exit0、源码稳定，引擎 54448。两种排序的 24F 小域，13 步完整 F 相对残差约 2.95144e-11，固定 C 回代原 C 约 3.49960e-10。完整扩展逆/核心限制稠密参考、线性、零右端、零重叠退化、行列拓扑一致、预算/坏覆盖、奇异组明确对角替代与不安全对角拒绝均通过。独立核对全部小域物理 Arnoldi 方向通过。

`overlapFreal01` 实际 exit0、源码稳定，引擎 40364。187749F、27461 核心组，最大 8 核心加 2 外邻，242670 次成员记录。完整扩展矩阵内共有 863948 次原五量块记录。1 个扩展组使用明确的 CV 对角替代；最大原输入逆证书界 9.9959980479e-9。

| 同矩阵、同右端、32 方向 | 原组内逆 | F 内强连接逆 | 受限重叠逆 |
| --- | ---: | ---: | ---: |
| 完整 F 相对残差 | 0.278620811257 | 0.283052565822 | **0.308766398077** |

内部 F 目标为 1e-3，三者均未达到。受限重叠没有改善这次真实右端，不能据局部连接增加宣称收敛改善。F 分母是凝聚后的 F 右端；父 C 分母是原完整右端，不能混用。父 C 的 F/C 行分别为 8.45377214646 / 11.8446413639；F 行与完整子系统的关系差约 5.768e-15。

本试算 35 次完整 F 作用（求解 33 次、诊断 2 次），33 次受限重叠映射，1 次原 C 诊断。新图提取、S 装配、选中 J、原 NS、接受更新和新增合格面积均为 0。原生正交误差约 2.749e-12，组合关系差约 7.370e-14，通过原 1e-8 门槛。真实成功路径未保存完整 V/Z，不能声称独立逐列检查了真实全部 Arnoldi 基。
