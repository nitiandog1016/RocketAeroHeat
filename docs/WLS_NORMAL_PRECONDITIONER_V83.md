# v83 完整WLS同线五带预条件器研究

本研究针对`GRAPH_WLS_COUPLING_V83.md`的实测差异：总方向和最新增量主要受黏性应力及功耦合影响，剩余方向导热也显著。新方案只改预条件器，原NS、全部原CV/原面、边界/气体/尺度和验收门槛保持。它尚不是完整WLS全局Jacobian求解器。

## 提取与求解方法

令`DeltaJv = Jv_fullWLS - Jv_frozenTwoPoint`。只保留同一原面法向线上行列对应的块，形成`Bnew = Bgraph - restrict_line(DeltaJv)`。原图中的内部精确Euler、外储库Euler近似及不同原面之间的侧向两点块保留。

原WLS梯度的一环、共享面梯度平均及位移修正共同产生最多两个法向层的同线依赖，因此每条线是五量的五带块系统。装配直接传播当前EOS、WLS系数、特征样本敏感性、Newton应力、Fourier导热、`U*d(应力)`与`dU*原应力`；没有通过逐未知量调用完整模型构造真实大矩阵。当前静止Dirichlet固壁在两种方法中相同，墙修正严格为零。特征出流的功速度敏感性仍保留，即使它不是WLS的入流样本。

每条线按两个下带/两个上带作块消元与回代；原面着色和固定对称扫描保持。从零开始、固定扫描次数，不以右端/残差早停，因此可继续使用固定右预条件GMRES。不同原面之间的完整WLS耦合仍未包含，不能因线内块精确而称完整NS矩阵已精确求解。

新增持久块数据的保守上界为`5*25*Ncv*8`字节，显式受`maximumAdditionalBytes`限制；它不是进程峰值、临时分配总量或粗像存储。原粗像仍独立受256MiB限制。没有裁细像、删除原CV或改变方程。

## 完整程序

- `internalFlow/cutCell/assembleRocketWlsNormalCorrection.m`：直接装配同线黏性差异，显式五带及边界策略检查。
- `buildRocketWlsNormalPreconditioner.m`：与原图组合并缓存五带块分解。
- `applyRocketWlsNormalOperator.m`、`solveRocketWlsNormalPreconditioner.m`：完整近似矩阵作用和固定着色扫描。
- `solveRocketShellSteadyKrylov.m`：显式`wlsNormalCorrection.maximumAdditionalBytes`启用；默认完整输出合同保持。
- `solveRocketMinResidualCoarsePreconditioner.m`：新法向扫描后，继续用相同完整模型和已有粗像作细层最小残差粗校正。
- `tests/testRocketWlsNormalPreconditioner.m`、`testRocketWlsNormalIntegration.m`、`verifyRocketWlsNormalBlocks.m`：小域参考、主链原NS及真实原CV验证。

所有MATLAB文件均为完整文件，采用中文模块注释。示例配置：

```matlab
options.wlsNormalCorrection = struct('maximumAdditionalBytes',512*1024^2);
```

该选项要求显式`two-level-minres`、`selected-analytic`及`steady-newton`，不能在其他模式中悄悄生效。总方向仍由原NS复核，以原`norm(R)`为分母，实际目标0.1；随后才可进入原正性/温域/下降/守恒/稳态流程。
