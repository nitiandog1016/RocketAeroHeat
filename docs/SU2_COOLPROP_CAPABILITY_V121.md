# v121：内嵌可压缩变比热能力与实际热流链路

2026-11-01。本轮已完成受控构建、原生小型流场、物性往返、非零壁热及 MATLAB 回读测试，随本次提交同步 GitHub。**新增真实箭体合格面积仍为 0，单时刻全面积目标未完成。** 当前实现是通向真实 20° 完整域的物性接口，未升为主工作台默认求解器。

## 已实现及实际检查

- 固定 SU2 8.6.0 提交 `7048fd35f56d4bf52e586429d6746a36a10255f8` 和其指定 CoolProp 7.2.0 提交 `98b3523d5daa98454618d381d2ae53f7471d216b`。项目内 CMake 3.31.8、两线程构建，用时 685.375 秒，正常终态；没有覆盖官方或旧空间壁温运行包。包名 `rah-coolprop-v1`。
- 采用可压缩 `COOLPROP / HEOS Air`、有量纲 SI、ROE 及黎曼开边界。小型链路实际只测试 ROE；HLLC 被配置合同允许，但本轮没有其流场证据。守恒状态由原生 EOS 初始化，禁止直接加载旧定比热重启动。当前适配限定单区、稳态层流、MGLEVEL=0；空间壁温、RANS、非定常尚未在此包取得适配证据。
- **热力学与输运分别说明：** EOS、cp、cv、声速和导数来自 CoolProp；实际算例黏度仍为 Sutherland，导热系数为 `k=μ cp(T,ρ)/Pr`，Pr=0.72。同库查询器另输出 CoolProp 自身的 μ、k，但本轮引擎没有采用这两个输运函数。
- 24 个离散 PT 状态覆盖所选 T=140—1500 K、p=100—100000 Pa；不是整个连续参数矩形获得资格。PT→DE 最大压力往返误差 8.0453×10⁻⁹，其他状态误差更小；原生 DE 状态声速恒等式误差 4.44×10⁻¹⁶，焓恒等式 2.22×10⁻¹⁶，cp 有限差分误差 4.49×10⁻¹¹，四项缩放导数误差最大 6.10×10⁻¹¹。属于代数与接口校核，非实验认证。
- 数据库 Air EOS 声明 Tmax=2000 K、pmax=2 GPa（上限不代表本项目覆盖范围）；查询器检查声明范围及气相/超临界单相。真实 2100 K 拒绝进程已测试。没有裁温、补正值或改物性内核。
- 两项真实 NS 任务正常终态：第 0 步能力探测 1.719 秒，20 步非零热流任务 7.938 秒。均为 5265 节点/65 壁节点平板，**不是箭体算例**。前者 q 全零，仅确认运行能力；后者第 19 步 q 非零，原生梯度相对差 2.3024×10⁻⁷、压力/温度 EOS 差小于 3×10⁻⁷，积分热负荷相对差 8.5262×10⁻⁸。误用旧定比热的局部热流差达 10.2086%，证明读取必须采用实际 cp；这是启动场对照，不是物性改变后的收敛热流差。
- 第 19 步密度/能量 log 残差为 −2.473071241 / +3.997997129，未达原 −8；Tw=300 K 是输入，导出流体壁节点温度约 885—1163 K，不能称求解壁温或可信壁面温度预测。
- 一项 MATLAB 实际任务正常终态、源码稳定：新 EOS 审核、19 步具名身份、NASA7 对照、旧 v119 累计 599 步结果兼容均通过。只允许本版本未定义的 `Buffet` 诊断 NaN 单列；残差、HF 和其他必要字段非有限仍拒绝，已注入必要残差 NaN 作反例。
- 7 个错误配置反例及上述实际超温查询均按预期拒绝。工作台组件的物性说明改为按运行包身份显示，避免新结果误标为定比热理想气体；运行时说明同样用于探针、截面及导出。本轮没有完整 3D CoolProp 结果、新主五步骤入口/选择器、组件浏览器或原生截图验收，不能称 UI 全链已完成。

## 本轮异常与准确来源

1. 编译正常结束后，全树冻结校验因上游 `.fluiddepcache`、`.incompdepcache` 两个自动依赖列表变化而中止，首次安装因缺 `compiled.json` 在任何安装动作前停止。后验独立核对 10864 个源码/物性表及实际编译用补丁原文；只有这两项缓存变化，两个临时源码文件已还原。不重编译，由独立收口器登记。未来构建脚本已明确排除并记录这两项缓存；该小修正仅作语法与已有后验逻辑核对，未重做整次构建。当前二进制仍绑定实际旧脚本原文。
2. 原始 PT 缓存状态的声速恒等式首测 2.0242×10⁻⁹，未过预定 10⁻¹⁰，失败保留。SU2 原生 `SetTDState_PT` 先 PT 后用 ρ/e 调用 DE；采用同一原生序列后恒等式达 4.44×10⁻¹⁶。原门槛不变，原 PT 结果继续标失败。PT/DE 已完成查询直接复用，没有重跑流场。
3. 首步零热流不当作梯度通过，才追加运行前明确预算的 20 步任务。全部终态、准确源码/配置和必要的小型复现网格见 `validation/v121/`。源码归档脚本第一次读取中文文件使用系统 GBK 失败，改用 UTF-8 后仅继续归档，没有数值重跑。
