# v83 原控制体局部保守粗方向

本研究服务于真实20°箭体内部区域求解的收敛，不新增物理模型或合格面积。原217272个控制体、19752个原面、11层和全部空间五量方程保留。原NS、80–2000K温域、0.1实际线性目标、RMS下降与空间/定常验收不变。

## 选择这一方向的依据

`krylov12`原NS方向剩余的平方范数约94.47%在前四层，73.06%在鼻端最后10%轴向范围。按单个原CV继续核对，控制体78879/78906分别对应原面19623/19650、第4层，合计约10.0072%。两者通过正面积共享面相邻。前64个高剩余CV占26.5205%，其正面积一环邻域290个CV占29.1021%。这是缩放线性剩余的分布，不是压力或热流误差。

完整映射、质心/体积及正面积邻接见`outputs/v83_validation/localcells01/local_cells_diagnostic.json`。Python导出的候选顺序与MATLAB输入逐值核对，不通过删除小体积控制体降低残差。

## 数学与内存合同

旧混合空间的完整提升保持原样。新增候选为原CV的一个缩放保守量单位向量，逐个执行当前选中分支完整空间作用，存储单位化的`-J e_i`，提升记录对应的原CV、方程和归一化尺度。

必要时仅从旧混合空间的附加原始变量列中释放整列：每次按当前保存剩余上的精确小Gram投影损失/释放字节比选择。全部410个保守底空间列保留，原始473列输入与旧提升源码不改。禁止截细像非零、删除物理CV或修改原空间方程。

新局部列按Schur投影收益选择，并逐列检查完整Gram正定、`rcond>1e-12`和独立性。最终稀疏像仍不超过256MiB；此限制不代表MATLAB进程峰值内存，父像、候选和临时矩阵须另占内存。筛选仅在构造时执行；冻结后的逐列提升和投影对新右端保持固定线性映射。

`liftRocketLocalCoarse.m`、混合提升与原始变量提升分别绑定SHA；完整方向的13个原计算源身份沿用。缓存不跨Q、几何、物性、边界或公式复用。
