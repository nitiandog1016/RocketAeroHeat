## 3. 已作出的成熟接口选择

按实际构建来源绑定9份不同SU2源文件（12段带行号摘录）。旧源与本项目v167原生实现的准确SHA同时保留，不能泛称未经修改的官方发布版。

1. `CMultizoneDriver::TransferData`在受体为RANS时调用供体和受体的`TURB_SOL`。Euler供体没有对应SA求解器；`CSlidingInterface::GetDonor_Variable`还直接解引用供体。因此**现成配置不能直接把Euler区接到SA-RANS区**，本轮不以补常数SA绕过这一缺口。此判断来自源码，不声称已经运行过该错误组合。
2. 选择待验的**同相态Air、SA-neg/WITHFT2双黏性区**，使用原生Gauss–Seidel区域调度和滑移流体接口。上游域从真实鼻部发展出完整边界层；下游包括收缩、后体、底面和原物理外域，通过双向状态/SA交换获得入口与外压反馈。没有内部p∞边界，不需要把积分厚度伪装成剖面。
3. 这是用于补足上游剖面和困难区反馈的较大候选，并非已经证明更省内存或更快。全局Euler和工程热链继续保留；取得可信上游/区域解以后再评估能否缩小黏性范围，不把整片工程区域永久替换成CFD。

## 4. 观察缺口怎样处理

已定位未来必要观察的位置，见[准确源](validation/v233/evidence/source01/report.json)：

- 原`SetPrimVar`回退覆盖五守恒量之前记录当前/旧态、局部节点及映射后的全局ID、预处理调用阶段、轮次和异常原因。SA变量必须同时绑定自己的更新/接受阶段。现有800保存态已回退，无法反推出当时被覆盖的试探；**不为了补这些历史ID重跑800步**。
- `Space_Integration`最后调用Euler壁的`BC_Sym_Plane`。它投影旧态动量和动量残差；定常网格分支不显式添加完整pN壁面通量。应在壁投影前/后同阶段取样，分别记录原始动量散度、约束反力、同阶段pN，再核对它们的关系；不能预设其中任意两个在非收敛状态必相等。
- 原隐式更新后才读取的壁压不能和更新前RHS混称同阶段。v230/v232旧差值保留原数值和跨阶段身份。本轮没有新的原生观察或守恒结论。
