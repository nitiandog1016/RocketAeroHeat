# v107：内嵌SU2接入主五步骤科研工作台

2026-10-31。已完成定向测试，随本次提交交付。总目标保持进行中，**新增箭体物理资格面积0**。本版推进可操作的主界面和实际进程管理；不是收敛三维气动热交付。

## 从主程序使用

运行 `main`。在“输入模型”页选择“建立原生箭体 · 内嵌SU2研究”，然后依次操作同一侧栏：

1. 建立原生无突起完整箭体，主轴X、鼻尖+X、单位m。
2. “生成完整三维体网格”：保留2448个原三角面，11712体单元、8层射线网格。近壁质量尚未合格。此模型不是19752面真实回归箭体，不能用它替换那个案例的面积分母。
3. 设置高度、Mach、攻角、侧滑、给定Tw、最大迭代和时间预算；确认后从大气模型建立本工况来流。SU2分支明确使用层流NS、定比热理想气体γ1.4、Sutherland、Pr0.72、等温壁面，无湍流/转捩闭合。可输入的参数范围不代表已验证适用范围。
4. 显式启动内嵌SU2。2线程、最多720秒；异步显示实际耗时、迭代、密度/能量残差及原生HF。数值不会冒充面积完成率或剩余时间估计。取消及关闭窗口都由监督器停止它自己拥有的子进程，等待真实终态。
5. 同一中心区域查看原面元研究云图、固定色标、面元探针，导出CSV及身份JSON。压力、物面平均q、流体节点T、原生保守热负荷密度、给定Tw和未知求解Tw分列。工程STL流程及既有结果工作台保留。

运行时按v105安装说明配置固定版SU2。MATLAB可用 `cfg.su2.pythonExecutable` 指定Python；默认从环境找 `python`。研究数据写到 `outputs/embedded_workbench/<唯一任务编号>/`，不覆盖旧任务。

本分支尚未接任意截面曲线，也不支持任意STL或突起体网格。完整工程分支已有截面功能继续保留，不能据此声称新引擎分支的全部UI验收完成。

## 状态与结果身份

- 新增 `embeddedSU2Job.m` 管理隐藏监督器，返回实际进程对象；`scripts/runEmbeddedSU2.py` 原子更新JSON回执、逐条读取完整历史行，按任务令牌取消。不会按名称批量结束SU2。
- 锁定配置、网格、运行程序及读取/映射源码与显式输入快照。重启动配置启用时，监督器还要求显式初场文件并锁定它；本版没有运行重启动物理算例。
- `aeroHeatWorkflowState.m` 用独立 `researchResult` / `research-ready` 保存研究场，普通工程 `result` 保持空；输入版本、求解编号和原V/F核对通过后才接收。修改边界或网格立即使旧快照失效。
- “重开本程序同工况研究结果”读取保存的 `mapped_research.mat`、输入快照和实际回执，要求同几何、边界/物性与设置。保留原编号/来源，不隐式启动求解器，不是要求用户导入外部CFD。
- 成功退出、完整面元值、保守映射都不授予物理资格。当前收敛审核仍待接入，全部新引擎输出固定标为研究。真实壁温未知；Te/Tr没有擅自由节点T推定。

正常取消/关窗路径已经实际测试；强制结束MATLAB、操作系统崩溃、监督器异常终止的恢复不是本版已验收能力。

## 实际测试与失败

4项MATLAB任务全部终态：3成功、1失败。`workbench107_01` 的真实两步启动、原面回读、WebGL与CSV检查通过后，MATLAB `exportapp` 导出uihtml窗口失败。之后直接重开该结果；取消/关窗与最终布局均复用它，没有为截图重算数值。

`workbench107_02` 通过主五步骤、输入失效、拒绝不同边界旧结果、实际取消、关窗等待终态。`replay107_01` 通过最终布局、同边界再确认与无求解重开；实际Windows窗口截图和原生点击面元证据保存在验证目录。`guards107_01` 通过异步输入改变检测、过期编号/不同几何/伪造研究资格/取消结果拒绝，以及336面工程主链的状态回归。

共6个SU2进程：1个实际两步启动退出0，2个主窗口取消/关窗，1个输入改变后的取消检查，1个故意错误配置，1个1秒超时。全部已终态。错误取消令牌被忽略。没有把故意失败或取消计作物理算例成功。

Python生命周期测试在两项实际终态断言之后，汇总相对文件路径时失败；原版本与失败原因保留，修复后只审核已有终态并生成报告，不重跑那两个进程。证据汇总脚本也曾遇到研究目录相对路径错误，改为先解析绝对路径后完成；它未启动数值进程。最终残差解析核对了SU2含空格/引号的表头和未写完的末行。

独立SciPy/CSV审核核对三份界面导出与同一MAT：2448面、面积0.933209601542m²；五种数值列的最大归一化差约4.01e−15。给定Tw保持300K，求解壁温仍为未知，资格列全部false。

两步研究场的能量log残差为+3.06356，**明确没有收敛**。其物面平均q积分−44631.414456W，原生SU2负荷−44103.128477W，与HF监视值−44103.128030W按对应口径一致。这些负值仅作为未收敛初始场原样保存，不能据此解释真实箭体冷却。沿用v106的双面积口径，没有把保守负荷密度替换成物面热流。
