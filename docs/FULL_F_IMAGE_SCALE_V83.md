# v83 完整预条件 F 像列尺度与有界 LSQR

本轮承接 `FULL_F_LEAST_SQUARES_V83.md`。仍以相同真实 20°箭体、相同冻结 Q、187749F、29523C 和全部原五量为基础。数值研究中的 A_FF 与完整父矩阵 C 都不能替代原 NS 或区域气动热验收。

## 发现与方法

原全局最小二乘组合为 `B=A_FF*M_F`，其中 M_F 是已经认证的原组内五量逆。完整像列范数最小约 1，最大 441979.807610，相差约 44 万倍。仅看原 CV 对角或局部逆证书，不能发现这种完整作用下的列尺度差异。

令 `D_j=1/||B e_j||_2`，改用 `B D` 的右侧坐标，伴随为 `D M_F^T A_FF^T`。D 每项严格有限正；不做左侧行加权，不改变原方程、原右端、原 F 残差范数、原求解目标、F/C 身份或物理状态。零/非法像列明确拒绝，不补小数或截断。该尺度是代数预条件方法，不是新的压力/热流工程关联式。

新完整 MATLAB 文件 `internalFlow/cutCell/buildRocketFullFImageScale.m`：

1. 从全部原 F 块建立入列索引。
2. 每组收集与该组全部列相连的所有原行，形成小面板并乘缓存的实际局部逆。
3. 保存每个完整像列的范数及倒数，检查所有原 CV 五量列覆盖一次、全部原块按列所属组读取一次。

不形成全局 `A_FF*M_F`。真实最大面板涉及 44 个原行 CV，面板与像数组合计最大 123200 字节；额外算法数组上界 65399840 字节，低于 256MiB 工作区预算。该预算不含调用方已有图/因子、原生 LSQR 内部数组或进程峰值；没有峰值测量声明。

`solveRocketFullFLeastSquares.m` 增加可选第六参数 `columnScale`，正向、伴随和最终校正严格使用同一个 D。未提供时保留旧数值路径；本轮小域实际重放与上一版本的缺省结果和残差历史逐值相同，单位尺度路径也逐值相同。尺度数组单独保存在 MAT 证据中，不塞进 JSON 摘要。旧完整源字节保留在 `source_epochs/pre_image_scale_solveRocketFullFLeastSquares.m`（SHA256 b90a446d…841d8d）。所有新增/修改 MATLAB 模块都有中文用途注释。
