# 球鼻外缘研究模块（v49）

`solveSphericalNoseEdge.m` 是已完成独立解析与数值校核的区域模块，尚未接入默认 `solveExternalFlow`。它计算球鼻外缘压力、温度、密度、速度、Mach 和总状态，不直接计算热流，不改变 v48 的默认结果或界面。试验表明它能够填补半球头局部外流缺失，但与现有侧壁外流的接口仍不一致，不能把试验覆盖率当成正式热流结果。

## 方法及来源

NASA SP-8062, *Entry Gasdynamic Heating*, January 1971，4.2.1 节、印刷页 30（PDF 第 36 页），说明钝鼻外缘可利用驻点熵和局部静压确定，同时指出该近似不适用于已经穿过较弱斜激波的细长后体外缘；那类区域需要进一步的熵分布分析。原文已于 2026-10-11 在线核对：[NASA 原始报告](https://ntrs.nasa.gov/api/citations/19710021703/downloads/19710021703.pdf)。

本模块选择修正牛顿工程近似提供局部压力。设球面径向与逆来流的夹角为 theta，正激波后的总状态为 p02、T02：

```text
p = p_inf + (p02 - p_inf) cos(theta)^2
s(T02) - s(T) = R ln(p02 / p)
U^2 / 2 = h(T02) - h(T)
rho = p / (R T)
```

默认使用项目已有的固定组分干空气热物性及正激波守恒内核；也可显式选择定比热。二者各自在同一热物性模型内计算压力上限、总状态和局部恢复。温度相关模型超出适用域时返回 NaN，不静默切换定比热。速度方向沿真实三角面上的来流投影；球面解析法向只用于入射角，不改网格。

这是低阶无粘区域近似。报告为该方法提供来源，不为本项目的几何阈值、角度选择或误差背书。没有完成公开实验数据的数字化对照；NASA-MEMO-1-3-59L 的[公开条目](https://ntrs.nasa.gov/citations/19980228467)已找到，但未据此宣称实验验证。

## 范围和接口

- 每次重新执行多尺度球面识别，不信任旧驻点缓存或仅由用户给定的半径。
- 面元所有顶点须位于已验证球面前缀和前半球；检查球面误差、法向一致性、特征面及拓扑保护。
- 来流为超声速，实际方向与 -X 轴夹角不超过 30°。默认迎流极角上限 60°；研究时可通过 `cfg.externalFlow.sphericalNoseMaxPolarAngleDeg` 设为 (0,80]°。这些是项目研究范围限制，尚不是实验验证适用域。
- `algebraicallyValid` 只表示当前公式、数值及几何条件通过，不表示完整外流场已验证。域外场值均为 NaN；解析驻点速度为求得的零值。
- 输出记录压力方法、状态恢复方法、法向来源、速度方向近似、热物性范围、来源 URL 和逐面元状态码。状态码从 0 起，对应 `statusNames{code+1}`。

已完成几何预处理的模型可以直接调用：

```matlab
fs = calcFreestream(cfg.flight);
noseEdge = solveSphericalNoseEdge(mesh, fs, cfg);
```

返回独立 `noseEdge`，不会自动合并到 `mesh.boundaryLayerEdge`，默认 GUI 不显示它为已接入的正式全表面结果。

## 已执行校核

`testSphericalNoseEdge` 检查独立定比热解析公式、状态方程、能量/熵残差、切向速度、压力/速度随极角的单调性、严格驻点零速度、平移/缩放不变性，以及非球面、特征面、坏拓扑、大攻角、过稀钝锥和热物性越界拒绝。连同 `testNormalShock`、`testThermallyPerfectNormalShock`、`testSurfaceStreamlines`，四项针对性回归均通过。没有运行全库测试，也没有新增 UI 功能或重做 v48 浏览器验证。

四个现有 M4、20 km、20° 攻角的钝体算例由 `diagnoseSphericalNoseInterface` 读取，不重复先前的跨边采样诊断。以下数值来自仅在诊断函数副本中替换球鼻状态，再运行原流线与热流链路的试验：

| 几何 | 分辨率参数 | 球鼻有效面数 | 原/试验连通面数 | 原/试验热流面积占比 | 接口最大相邻速度差 / Uinf |
|---|---:|---:|---:|---:|---:|
| 半球头柱体 | 24 | 97 | 5 / 921 | 13.12% / 88.68% | 27.23% |
| 半球头柱体 | 48 | 370 | 1748 / 3511 | 52.45% / 86.66% | 19.47% |
| 钝锥 | 24 | 0 | 7 / 未试验 | 0.21% / 未试验 | — |
| 钝锥 | 48 | 0 | 2683 / 未试验 | 57.09% / 未试验 | — |

两档钝锥均未通过球鼻几何识别，未放宽判据。球鼻新增有效驻点候选面使原播种规则选择不同种子，因此这里的连通提升包含种子可用性的改变；没有改播种规则，也没有跨无解区另设种子。两个半球头试验都未新增分离起点，但这不证明接口正确。

为排除相邻面几何距离的影响，还在同一解析位置比较球鼻 theta=60° 与切楔转角 30°：

| 场量 | 球鼻模型 | 切楔模型 |
|---|---:|---:|
| 静压 Pa | 33380.25 | 50934.62 |
| 速度 m/s | 735.73 | 863.24 |
| 总压 Pa | 116933.12 | 327924.89 |

精确值以 `exact_interface.json` 为准。速度差为 Uinf 的 10.80%。两模型使用相同总焓，但不同熵/总压；只平滑静压不能同时恢复正确的温度和速度衔接。直接接入默认链路、或仅为降低数值跳变而插值，都不能视为该物理问题已经解决。
