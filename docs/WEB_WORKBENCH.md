# 三维结果工作台（v44）

本页保留 v44 基础交互记录。v48 已增加时间滑块、面元时间曲线、全时域统一色标和 CSV 导出，当前热历史说明及验证边界见 [HISTORY_WORKBENCH.md](HISTORY_WORKBENCH.md)。下文“仅末时刻”和“时间历史未完成”为 v44 当时状态。

在 MATLAB 中运行 `main`，按既有流程确认几何、网格和飞行条件，结果默认进入“三维结果工作台”。计算核心仍为 MATLAB；本页由本地 HTML/CSS/WebGL 绘制，没有 CDN、网络字体或外部 JavaScript 库。旧专题页保留用于参数设置和结果核对，尚未完成全部旧三维视图的替换。

## 科研查看

- 拖动旋转，滚轮缩放；Shift 拖动、右键拖动或勾选“平移”后拖动进行平移。“适配模型”恢复完整入框。默认观察迎风侧，几何始终按真实比例显示。
- 默认 Viridis 连续色图；可选蓝红工程色图。全范围、当前截面、2–98% 分位、自定义范围均只改变颜色映射，不修改数值。截面/分位色标会截色，不能用饱和颜色判断超限区内部梯度。
- 点选的是屏幕上最近的实际三角形。XYZ 为交点坐标，场值为该面元常值，不声称有更细的点插值精度。灰色未解区域仍可点选。
- 场量分别标注工程计算、给定条件、未求解。修正牛顿压力与内部工程外缘压力分开显示。热流输入壁温、恢复温度、外缘温度、热响应求得的末时刻壁温分开显示；只有已有热响应结果时才增加末时刻壁温和末时刻对流热流。
- 周向曲线按面元中心 X 选取轴向带，使用 36 个角度箱按真实面积平均；不是精确截线插值。点击模型或拖动滑块选位置，带宽可选，数据缺口处断开。
- 覆盖率按真实三角形面积计算，给定值单独统计。未解原因折叠面板按全表面积列出缺口，不能将该诊断视为新的区域求解模型。

## 模块与导出

`buildAerothermalViewerData.m`：验证几何，构建逐面元变量、状态、方法及面积统计；将有效标志为假的有限占位值也变为未解值，防止图中出现假解。

`createAerothermalWebTab.m`：在统一窗口嵌入 uihtml，处理就绪、渲染回执和面元选择消息。

`updateAerothermalWebTab.m`：同步新数据。`pressureGUI.m` 在热响应完成时调用，飞行条件重设时随页面重建更新。

`exportAerothermalWeb(mesh,folder)`：输出完整目录，包括 `index.html`、`viewer.css`、`viewer.js` 和 `case-data.js`。该目录必须整体保存。标准浏览器可打开 HTML；本次独立预览实测使用本机 HTTP 服务，Codex 内置浏览器禁止 file 协议，未在其中验证双击打开文件。MATLAB 内嵌本地 HTML 已实测。

“保存图像”导出当前云图、单位、色标、工况及已选面元数值。当前 MATLAB 的 `exportapp` 在包含 uihtml 的整窗截图上失败，本页导出不依赖它；旧版整窗导出功能不作为本版工作台验证依据。

## 本版验证与边界

8 项针对性回归通过：数据导出、实际模型 WebGL 内嵌、压力曲线、压力、表面热流、壁温响应、统一 GUI、main 入口。最终界面改动后再次通过查看器数据和内嵌测试。当前项目共 67 个 test 文件，没有宣称本轮重跑全部测试。

真实箭体：19,752 个面元，M=5，攻角 20°；热流已计算面积 79.47% 左右。未解首要原因包括连续介质判据不适用 17.13%、尾端 1.59%、空气热物性范围外 1.31%。这是该工况工程模型的覆盖诊断，不是实验验证或完整热环境求解。

浏览器验证了旋转、平移、缩放、拾取、截面色标、单面元 JSON 和带单位图像导出。另用独立三维射线相交算法核对已计算面元 #10075、未解面元 #10059，与早期默认相机下的实际浏览器点击完全一致。随后改为默认迎风侧视角；坐标和拾取投影仍使用同一相机。

未完成：全区域物理模型、公开实验数据验证、过渡/稀薄流模型、全部旧视图迁移、WebGL 页的完整时间历史浏览。保持这些任务在总目标中，不以 UI 完成替代物理模型完成。
