# v83 一致 Schur 与固定动量逆诊断

本研究服务于真实 20° 箭体的单时刻区域求解。前一切片已验证可逆行列尺度，但完整稀疏 ILUTP 因资源压力停止；这里没有重启该分解、重组原 S、扫描阈值或改变原方程。

## 为什么检查动量逆

原完整 C 的三动量/密度能量分块记为 `[A B; E D]`。此前保存的二跳矩阵是 `S_local=D-E*blockdiag(A)^(-1)*B`，而完整回代使用固定三动量 ILU 逆 `M_A^(-1)`。与同一个固定动量逆一致的作用应为 `S_M*x=D*x-E*M_A^(-1)*(B*x)`。

`applyRocketConsistentSchur.m` 明确实现该作用，不把它称为精确 A 的 Schur，也不据此修改 C 或原 NS。若固定动量逆本身不可用，不能继续把求逆 S_local 当作整个五量预条件器即将可用的证据。

## 已测试的小域能力

`consistentschurunit01/02/03` 实际 exit0、全源锁稳定。两种 CV 排列的完整作用及 B*x、三动量解、D*x、E*y 均与独立稠密参考一致；Python 最大完整中间量差约 1.87e-15/5.09e-15。线性检查通过。

新增 `observeRocketFieldILU0.m` 只作诊断，原 `solveRocketFieldILU0.m` 没有修改。有限完整输出逐值一致；在前代求和、回代求和或对角逆乘法首次产生非有限值时，保存真实行、依赖值、系数及逆，整个输出显式不可用并返回全 NaN。合成三个溢出阶段及旧入口仍拒绝均已测试。未访问行不作为零解输出。

## 真实失败与限制

`consistentschurreal01` 实际 exit1、源稳定，原入口因非有限动量解拒绝；没有保存中间量，原源文件与日志保留。观察器补齐后，`consistentschurreal02` 实际 exit0、源稳定，但数值结论仍是拒绝，并非可用预条件器。

同 Q 的第一次三动量凝聚返回有限值，却将方向范数相对于右端放大约 **1.773506e219 秒**，最大分量约 **1.427012e226**，凝聚后的两量右端范数约 **1.114837e234**。再次通过同一动量因子时，前代在代数行 **167894** 首次非有限，对应原 CV **4570**、原面 **4570**、第 **1** 层。已完成有限前代 167893 行、未进入回代；保存有限前缀的最大中间量约 6.614584e306。

这里完成了两次动量求解尝试，其中第二次观察提前停止；完整一致 Schur 作用 **0 次**，原 C/NS 方向检查 **0 次**。不能宣称五条方向比较完成。首个溢出位置属于代数传播路径，不证明该物理面元的网格或边界有错误，也不能用作此前标量 ILUTP 未知的零主元位置。

最终 Python 独立审计实际 exit0，复现同一前代首非有限行及阶段，保存行消元账的非有限掩码一致，失败输入 B*x 相对差约 1.24e-18。首次凝聚解在原三动量 A 上的相对剩余约 **6.106667e225**，直接表明该固定因子不是有效的 A 逆。它仍不能证明 A 本身数值奇异。

这说明当前三动量 ILU 的全局逆作用不适用。尚未证明原 A 或整个 S 数值奇异，不能仅依据该失败排除其他稳定的动量求解或分块方式。

## 局部诊断修正

原两量对角的闭式平方判别式在接近等奇异值时发生相消，独立 SVD 最大比值差 9.71778e-13，未通过既定 1e-14 诊断检查。原失败、源及 MAT 保留，没有放宽门槛。

`rocketTwoFieldSingularRatio.m` 改为逐块缩放与 hypot 公式，近等奇异值、近秩亏、零块以及 1e±250 尺度均通过独立 SVD 检查。`consistentdiagrefine01` 只读取原 MAT，修复局部奇异值诊断，在新目录保存；新动量求解/Schur/NS 均为 0。全部其他用户载荷逐值保留，原失败仍拒绝。MAT 文件头的创建时间属于容器元数据，不用于载荷逐值比较。

全部217272个均衡局部对角的奇异值比与独立SVD最大差 9.99e-16，仍按原 1e-14 检查；比值范围约 6.05291e-7～0.999946，低于1e-8或1e-12的局部块均为0。这个局部结果不能排除全局弱模、三角传播增长或近似Schur误差。

完整独立审计、工作台接入与来源身份以 `validation/v83/progress_consistent_schur.json` 的最终记录为准。局部奇异值比不代表全局数值秩；压力、热流、给定/未知温度、12 个接受步及正式合格面积均保持。

工作台 `outputs/v83_validation/workbench21/index.html` 共八条折叠研究记录，新增“动量回代溢出（已定位）”，原S块拒绝位置和未知标量零主元位置分别保留。MATLAB导出与三项假来源/伪合格拒绝、Node592560 CSV值行/6624截线样本/15同宿主事件及独立来源审计通过；六个原面数据文件与workbench20逐字节相同。此前完整MAT字段审计按该身份复用，没有新的浏览器/WebGL视觉验收。
