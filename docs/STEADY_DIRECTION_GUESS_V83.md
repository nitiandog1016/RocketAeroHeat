## 修正方程及两个分母

原缩放稳态方程为`-J*d = R`。用当前完整选中分支模型重新计算`J*d0`，增量方程为`-J*delta = R + J*d0`，最终方向为`d = d0 + delta`。

实际验收始终是原NS重新调用总方向后得到的`norm(R+J_NS*d)/norm(R) <= 0.1`，并满足原下降、状态/温域、空间及稳态规则。增量GMRES以其新右端为分母，故其相对容差换算为`0.1*norm(R)/norm(R+J*d0)`，最多为`1-eps`；这个值可能大于0.1，但原NS总方向目标没有放宽。实际线性日志分别保存分母身份、初猜当前模型值、新右端、增量、来源、有效容差及总方向原NS证据。

初猜若已经满足模型目标，可以跳过增量GMRES；仍必须对总方向调用原NS并通过原下降与候选保护。记录`gmresSkipped=true`，没有GMRES报告值；不得把跳过当作原NS已通过。接受新Q后不继续使用旧基态初猜；原粗像的新Q重建规则保留。

初猜模型作用单列且计入本段选中分支模型总数，不计作NS调用。增量预条件器仍固定线性，最后原NS检查直接作用于总方向，不将两个近似导数相加冒充该检查。
