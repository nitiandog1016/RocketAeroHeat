# 变比热状态约束更新的算法评估

本轮整箭任务通过原生旧态回退继续了50次更新，14次拒绝均来自热内能低于60K物性下界。下一项应把物性适用域纳入实际更新的可接受条件，并保持已有工程方法、内嵌SU2和工作台分工。这里列出的文献是适配依据，尚未在RocketAeroHeat中实现或验证为三维SST算法。

| 路线 | 公开依据 | 对当前项目的作用与边界 |
|---|---|---|
| 隐式高阶有限体积的保正修正 | Huang、Ren、Wang，2023，[原文摘要](https://arxiv.org/abs/2306.13483) | 讨论Euler/NS隐式中间态保正；摘要明确局部残差修正会破坏守恒，需要第二步修正。不能只移植局部修正便声称守恒，更不能直接等同本项目SST/OTH/有限温区。 |
| 不变域与凸限制 | Guermond等，2018，[论文](https://epubs.siam.org/doi/10.1137/17M1149961)，[作者版本](https://arxiv.org/abs/1710.00417) | 给出Euler密度、内能和熵约束的成熟框架。依赖相容低阶基线及高阶组合；将整个SU2离散替换为该框架代价大，当前不选为完整域前置。 |
| 一般/表格EOS的保正近似 | Clayton、Guermond、Popov，2022，[论文摘要](https://epubs.siam.org/doi/10.1137/21M1414097) | 针对复杂EOS的一阶Euler保正与波速界。可用于检查“ρ、p为正不等于热物性查询在域内”的设计问题，未覆盖这里的黏性、SST和上下温界。 |

建议先评估原生更新方向的有界步长及其接口，而非新增通量扫描。固定当前k时，热内能下界可写成 `ρE−|m|²/(2ρ)−ρ[k+e(60K)]≥0`，与ρ>0共同约束；上界需单独检查，不能直接套用下界凸性。当前采用OTH参考，内能为正本身不保证T≥60K。所有温界判定均调用同一已验证物性核，候选数值身份独立登记。

逐节点限步是数值可接受态处理，本身不等于全局守恒方法或物理解。实施前必须明确更新阶段、各守恒分量共同缩放、k的阶段、旧态无效处理、回退统计及残差/通量核对。现有14组状态可以先检验代数条件，但没有事件控制体积或原始线性增量，不能用于伪造全域守恒账。

此次调研只支持上述有限适配决定。公开热流、近壁网格误差和分离/再附/底面/突起模型资格仍按现行目标独立取得，不由保正论文或进程exit0替代。[执行边界与预算](validation/v164/NEXT_DECISION.md)
