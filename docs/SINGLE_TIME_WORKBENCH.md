# 单时刻温度来源与真实周向截面（v51）

日期：2026-10-12。本阶段完善单工况科研 UI，并实现独立的已知激波角热力恢复内核。主链路全面积气动热计算尚未完成。温度来源改动保留已有计算值，不增加虚构的壁温解。

## 工作台操作与数据含义

运行 `main.m`，沿用朝向确认、网格生成和工况计算流程，结果默认进入自定义 WebGL 页面。选择压力、热流、外缘温度、恢复温度、热流所用壁温或求解壁温；各场量分别统计真实三角形面积中的计算、给定和未解比例。

- 点击三维面元，把截面移到拾取点的真实 X 坐标；也可输入 X / m 或使用轴向滑块。截面不限定在圆柱段。
- 默认“实际截面交线”逐三角面与 X 平面求交，沿交线保留来源面元常值。白线标出三维截面；点击有效曲线段可查看对应面元数值、方法与适用范围。
- “当前截面色标”只使用实际相交面元；可切换全模型、分位或自定义固定范围。局部范围之外的值截色，色标说明保留该含义。
- 每个独立轮廓以自己的周长加权几何中心定义角度，+Y 为 0°、+Z 为 90°。0°/360° 的交线区间拆开绘制。凹轮廓可能在同一角度出现多个面元值，不做虚假的单值平均。
- 开放、分支、经过角度中心或退化为径向线的交线单独标明角度无效，保留三维交线和 CSV 场量，角度留空。几何角度无效不能计为物理未求解。
- 未解交线保留几何位置，曲线数值断开；给定值为金色，计算值为青色。没有求解壁温时，整个 `wallSolved` 字段保持 NaN/未求解，不把 300 K 的输入壁温当成计算结果。
- 若截面与网格环重合，采用 +X 侧面元常值；位于最大 X 时采用 −X 侧。共面端盖不作为周向交线，端点上的退化交点不画成线段。
- “带内面积平均”保留为可选近似，36 个角度箱内面积平均可能混合不同轴向位置，界面明确提示。

导出截面 CSV 包含 X、轮廓与面元编号、交点角度及坐标、交线长度、数值、状态、方法、适用范围、数据时刻、工况和网格环取值侧。未解数值为空。页面保留下载链接；本阶段通过链接中实际生成的数据独立核对 CSV 内容，没有把操作系统下载事件或默认落盘路径标为已验证。

## 温度逐字段溯源

`buildAerothermalViewerData.m` 分开记录热流算法与恢复温度算法。层流恢复系数为 sqrt(Pr)，湍流为 Pr^(1/3)；固定组分 NASA7 焓恢复和显式定比热恢复分别标识。球鼻沿用均匀驻点总温假设时明确提示，不能标为每个面元的局部恢复解。

外缘温度保留真实逐面元外流方法和热物性来源；已有低温膨胀的定比热流线占位状态单独解释。输入壁温是给定边界，求解壁温来自实际壁体热解；没有壁体热解时保留独立的未解字段。后续历史字段使用对应实际时间站的来源，不借用单点字段的逐面元适用范围。

## 已测试证据与限制

针对性证据归档在 `docs/validation/v51/`，实际结果示例及较大数据位于完整工程包的 `example_web/` 和 `validation/`。

- 温度来源及相关查看器数据、热历史、外流历史四项 MATLAB 测试通过；经典锥柱 1,184 面元链路保留原始温度值，NASA7 恢复焓残差小于 1e−5 J/kg。受控六面元样本验证状态与来源合同，不能替代物理精度验证。
- 真实箭体 19,752 面元通过 MATLAB 内嵌 uihtml 握手、非零像素绘制（WebGL 错误码 0）、默认页、新压力更新和旧专题页切换。几何复测使用已保存的真实网格/计算状态，不再次声称执行全部求解链路。
- Node 独立几何校核包含偏置方柱、断开的多轮廓、闭合环、面元跳变、缺失/给定、角度接缝、端盖、坐标缩放和平移，并覆盖共享边反向插值的浮点舍入误差、重复顶点及径向/开放/分支角度拒绝。
- 浏览器实际生成的 X=−1.1 m 截面有 92 段；独立 Python 程序逐行核对来源面元数值、算法与适用范围，以重心坐标验证两个交点在来源三角形内，并独立核对轮廓分组、闭合度数、周长加权中心与角度。周长 0.627573406083 m，与半径 0.1 m 圆柱的 2*pi*r 差小于 0.5%。压力 CSV 46 段为给定值；求解壁温 CSV 92 段全为空/未求解。
- 相同截面压力局部范围为 1.197–5.6308 kPa，显示有攻角柱段的周向变化。真实算例热流计算面积约 77.5%；其余区域保留未解状态。压力、外缘压力、恢复温度、热流所用壁温分别呈现，不能相互替代。

新增 `recoverShockEntropyEdgeState.m` 为独立热力恢复内核，定比热解析校核、NASA7 守恒与高温弱激波拒绝边界检查通过；未接入默认求解。文献公式与下一步几何/质量匹配路线见 `NOSE_AFTERBODY_MATCHING_RESEARCH.md`。本阶段没有新增实验热流验证，也没有完成球鼻/后体匹配、底面/尾迹或分离再附模型。
