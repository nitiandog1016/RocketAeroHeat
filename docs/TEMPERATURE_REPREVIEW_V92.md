# v92：投影后逐轮检查内部温域

本模块服务于真实20°箭体内部黏性区域的数值求解。目前是已测试的受限数值研究，不能据此认定全表面热流已求解。正式合格热流覆盖仍为66.5626327424%，新增合格面积为0；最新Q40尚未稳态。

## 问题与方法

v91从Q38推进到Q39时，自由候选未暴露的CV105088在投影后的1/8步候选中降至79.096026K，超出原80–2000K温域。它说明自由候选的一次前瞻不足以证明投影后的实际守恒候选合法。不能只手工添加这个CV，也不能将线性温度83.194260K当作非线性候选温度。

新策略为`original-and-iteratively-predicted-cell-and-interface-faces`，显式启用；原三种策略和缺省路径保持。每个当前状态仍重新构造自己的导数、C/W和方向，不继承旧状态的活跃集。

1. 自由方向只计算一次。使用指定步长的真实守恒候选`Q + alpha * directionU .* scale`检查全部CV温度，以及候选输入单元合法的全部内部Riemann面。相邻单元超域的面单列为阻挡，不能算作已检查。
2. 保留原10K温域行，加入所有预测越温CV对应的当前原态采样面及可检查的越温Riemann面。CV所需面必须有region1/4的原态身份和EOS导数核对；星区/扇区不能冒充单元EOS。
3. 累计保留此前全部必要条件、旧行和旧活跃面。共同面H、上下侧符号、原CV和波系元数据逐项相同才可合并；冲突明确拒绝，不覆盖旧条件。有限步已越域所需的面强制激活，即使该行一阶变化朝域内。
4. 每次投影后再次检查指定步长，补全全部新暴露的必要条件。最多三次受限求解、四次预览；真实研究每段128步，合计最多512次原生线性迭代。没有新可行动条件、预算耗尽或原方向精度失败均如实报告，不能无限重复同一组约束。
5. 通过方向门槛后，仍须原完整模型及新鲜NS方向缺陷不大于0.1，实际候选仍经原正性、80–2000K、下降及原线搜索验收。空间账1e-9、最大稳态残差2e-6/s和定常边界不平衡5e-10保持。

温度由理想气体守恒变量关系得到。它对密度和动量是非线性的，因此齐次一阶条件`H*u=0`仍可能在有限步上越域。该方法既不声称非线性约束优化最优，也不保证找到指定步长的可行方向。

## 两个不同结论

- `repreview.targetCandidateThermallyFeasible`：只表示指定alpha的全部CV和全部内部Riemann温域已检查且通过。若有阻挡面或单元状态不可评估，不能为真。它不包含开放边界、完整NS、下降、稳态或物理验证。
- `bandDirectionFeasible`：原128eps局部点积界通过，且所有累计必要条件确实经过受限求解。前一结论成立并不推出本结论成立。

所有原行都保留，只允许逐项完全相同的导数条件共享表示，不按秩删除面。行合并构造上界为`24*(5*n+1)+4096*m+65536`字节，仍不超过64MiB；其余原投影与预览预算保持。该估算不是进程峰值。

## 小域验证

`tests/testRocketTemperatureRepreview.m`使用随库32CV几何与两种代数排列的耦合C/W制造系统。它不是这些Q的物理NS Jacobian，不增加NS接受次数或物理解面积。三个新增小MAT的来源、种子和SHA见`tests/data/temperature_repreview/`。

- 中等动能例：初始越温CV1/9/23，首次投影后新暴露CV5；两次受限重算后目标内部温域和原点积门槛均通过。
- 高动能例：投影后新暴露CV19，有限步温度最终合法，但本机原128eps点积门槛仍拒绝；保留为压力测试，不放宽门槛。
- 非线性停滞例：新增CV16后，部分已有约束对应单元仍因曲率越域；正确报告没有可新增的原条件。
- 另验一次受限预算不足、零右端、原行侧别冲突及旧路径全部非计时输出逐值兼容。

最终MATLAB小域/兼容运行实际exit0且运行期源码稳定。独立Python对两排列8种情况核对每轮当时可见集合、累计强制面、原128eps界、全部稠密零空间方向和公开温度导数，最大稠密方向相对差约1.93503e-10，原1e-8门槛保持。真实逐轮审计函数另在这8种情况的22次预览上通过；大域仍只声明实际公开抽样范围。

原中间失败保留：输入scale保存为整数导致MATLAB类型错误；高动能例曾被测试误要求点积界必过，实际拒绝后修改测试分类，没有放宽算法门槛或引入多遍投影。界面夹具首次将MATLAB逻辑经SciPy读为整数，严格JavaScript断言拒绝；修复夹具布尔序列化后8种显示测试通过。

收口检查另补齐空约束集合的气体/缩放身份校验，将原校验移到提前返回之前；两种输入次序及两种排列共8项错误身份拒绝通过。`repreviewguard92`实际exit0/运行期源稳定，小域与旧路径兼容再次通过；独立对照5656项已有非计时对象逐值不变，仅新增拒绝测试字段。原真实Q39→Q40两轮合并均为非空集合，原来已执行相同身份校验；原真实运行时的模块字节另存raw，未为此重算NS或声称新增接受。

## 与物理主线的关系
