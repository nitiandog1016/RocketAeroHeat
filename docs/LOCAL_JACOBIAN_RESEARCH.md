# v74：局部保守量尺度的Newton差分研究

本阶段承接v73真实Q23/大CFL下的差分方向失准，服务于完整箭体内部黏性外流。原空间RANS/SA、壁面/远场、气体40～2000 K接受域及Newton/BE/守恒/稳态门槛保持。原生产求解器、Observed记录器和旧Jacobian保持v73原字节；新策略显式使用独立函数和新链，不重绑旧30步。

## 扰动尺度与模块用途

`axisymmetricJacobianLocalReference.m`在当前Newton点建立物理参考，再除以既有固定全局归一化尺度。对Q=(rho,rho ux,rho ur,rho E,W)，其中W=rho nuTilde：

- 密度参考为rho。
- 两个动量参考均为rho max(a,|u|)，避免零横向动量没有可表示扰动，并保持物理参考对速度旋转的一致性。
- 总能参考为|rho E|，不是温度或内能的替代值。
- W的实际初始物理扰动取max(h|W|,64 eps mu)，mu为当前分子黏性。严格零W仍可作可表示的单边扰动；没有向状态加该底限，也没有裁W。

`axisymmetricFVJacobianLocal.m`沿用原有色支持、逐分量解码、非均匀中央三点权重、扰动回退/拆列和完整调用计数，仅替换初始扰动参考，保存逐列实际正负步长（未使用方向为NaN）。参考只在构造当前Jacobian前计算，不作为残差中的新场量参与微分。

`advanceAxisymmetricSteadyLocal.m`以原Observed为基础，只将Jacobian调用替换为局部版本。源码可执行行比较通过；旧五个求解/残差源文件与冻结v73逐字节相同。新函数不是隐式自动fallback，不能由局部策略失败后悄悄切回旧Jacobian。

本策略是针对当前离散问题的数值实现，非通用误差最优或NS/SA正性证明。小扰动可能遭受消去误差，HLL波速分支及SA限制也可能不可微；不能以全部中央列或线性方程小残差代替真实BE验收。

## 已实际完成的验证

四/五量跨密度及SA尺度小网格，包括严格零W，独立逐列完整残差差分与有色结果一致；独立方向相对差约4.25e−10/9.58e−10，改变归一化尺度后的导数变换差约9.88e−11/5.74e−13。四量48列均中央；五量59中央、1正向，未使用负向步长为NaN。三个非法输入拒绝。第一次测试未显式提供RANS所需Sutherland输入，失败原源/身份保留；修正测试输入后完整测试实际exit0，未修改物理门槛。

固定v73保存的真实失败Newton12，原缺陷5.37460529、目标3.28465787e−8。局部相对步2e−6/2e−5/2e−7均13800列中央、191次残差调用；原方向对完整RANS方向割线的作用差分别约0.00258/0.01177/0.00046，最坏能量分量斜率均约+2.650673，与真实方向一致。三个新Newton方向均在原alpha=.5回溯条件接受。这仅是子步骤诊断。

随后固定同一Q23/CFL=1e8及原全部验收，局部相对步2e−6/2e−7的完整BE均实际0拒绝接受dt=1.4970288703702051e−4 s，17次Newton、3293次调用，末残差16894.25536275；原BE目标比约.091825/.091824，独立五量账约9.79e−18/5.80e−18。对照v73固定1e−9为18次Newton/4831调用；这里减少的是这个固定试验的调用量，不能外推普遍加速或热流精度。独立Python同输入/EOS/保存通量BE账通过，不是第二套完整RANS。

## 独立持久链与UI

`createRocketAxisymmetricLocalCase.m`明确选择`initialGuess='uniform'`或`'v73-uniform23'`。后者只读取内部冻结的完整域Q23，校验固定SHA256及几何、气体、边界、归一化尺度，不能改工况后沿用，也不能缺文件时静默退回均匀初猜。该初猜不是给定入口、不导入外部CFD，也不是物理解。

新默认链从Q23内部初猜开始，初始CFL/上限均1e8、局部相对步2e−6；均匀选择从CFL=.5开始。`studyRocketAxisymmetricLocalJacobian.m`逐BE保存不可变端点及源码，继承原连续三步2e−6稳态门槛。此前23步在初猜元数据单列，新链从0计步、账和伪时间重新起算；不是均匀新链，也不改写旧30步。

五步骤工作台的“计算”页增加实际Jacobian扰动和初猜来源，明确Q23的SHA、此前23步不计入本链、不是给定入口。逐场量的物理方法仍按实际HLLE/RANS/SA/Fourier等标注；数值Jacobian不是新的气动热模型。给定Tw、邻壁气体温度代理和未知Te/Tr/求解Tw分开。旧v73的30端点/15项导出拒绝及新链前三步重放、原面投影、周向曲线/CSV/同窗事件已通过；这些不包含新浏览器视觉或WebGL验收。
