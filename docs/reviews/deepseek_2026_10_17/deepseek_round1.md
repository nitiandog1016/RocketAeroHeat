## 三、对五个问题的直接回答

### Q1 六步顺序是否合适？v61 还值得收口多少？

**方向对，位置错。**

- 六步的"主题"（收口模块 → 主攻 20° 缺口 → 分离/底热 → 接 UI → 单时刻验收 → 全周期）是合理的。
- 但 **v61 不是 29.3350% 缺口的关键路径**。它是轴对称、层流、单切向速度的 s-n 模块；当前算例的缺口是三维横流+收缩+后体，v61 最多覆盖 115 个鼻面（0.1944%），且要求零合成攻角。把它放第一步，等于继续"内层精度"路线，v58–v60 已经证明这条路线不增加生产面积。
- 数值上，v61 已报告的 q 误差约 −0.0136%、能量账缺陷约 −0.0183%（`NONSIMILAR_BOUNDARY_LAYER_DRAFT.md:33`）。相对气动热工程 10%–30% 的物理不确定度，这已经足够；再追 0.01% 的边际价值接近零。
- **值得收口的只有五件事**（做完即冻结）：
  1. 源码/测试/输入哈希绑定，一条命令可复现（当前草稿在 `outputs/`，不是可移植库）；
  2. 能量账：接受点式离散的缺陷界（≤0.5%）或改守恒型；二者选一，不再加制造场；
  3. 入口与适用域合同：物理 n、u/T 剖面、缓冲、零攻角/层流/薄层/Re/Kn，写成可机检的拒绝条件；
  4. 真实面元映射：把 40°–60° 结果映到 95/186 个球鼻面，面外 NaN，逐面带来源；
  5. 明确"不得用于 20° 横流"并写入模块说明。
- **停止条件**：上述五条通过即冻结，不再做更高阶/更多网格；若第 2 条一次迭代仍达不到 0.5%，直接改用守恒型有限体积或退回积分 BL，而不是继续调。
- 建议 v61 与主线**并行**，不阻塞主线；主线的第一件事应是 Q4 的压力一致性，第二件是 Q2 的区域外缘。

### Q2 局部独立外缘、流向投影、图路径缺了什么？最小可行方案是什么？

**缺的是"场"，不是"阶数"。** 具体：

1. **上游熵/总压输运**：每面从自由来流重置（`solveExternalFlow.m:214-217`），没有沿流管的 `p0/T0` 守恒与激波熵累积；这是 336 个占位面的直接原因。
2. **流管面积/质量流**：没有相邻流线间距、没有流管扩张率，因此没有质量厚度、位移厚度反馈，也没有 VII 所需的吹吸边界。
3. **横流速度分量**：流向只是来流在面内的投影（`:337-345`），没有周向速度、没有横向压力梯度；20° 攻角下背风涡系完全缺失。
4. **上游影响（椭圆性）**：`traceSurfaceStreamlines` 是单前驱 DAG（`:98-102,114-126`），不能表达亚声速/分离区的上游传播、回流与再附。
5. **法向压力梯度/曲率**：薄层假设 + 轴对称 `r(s)`，没有横向曲率与法向动量。
6. **湍流/转捩状态**：没有输运方程，转捩是固定 Re 阈值（`calcTransition.m`），湍流是 Head 积分 + smoothstep 拼平板（`calcTurbulentBoundaryLayerState.m:127,145-149`）。
7. **底/尾迹耦合**：底压是给定或 SAND93 标量，没有回流温度/速度/壁面梯度；底热没有径向分布。

**最小可行"区域外缘—边界层"方案**（按依赖顺序，不是算法清单）：

- **A. 区域外缘**：取后体（从大圆柱某一站到基座，含 31° 收缩、后部小圆柱）为区域；在每个轴向站把流动拆成"轴对称子午流 + 横流"：
  - 子午流：现有的切锥/轴向推进或 2D 特征线，给 `p_axial/U_axial/T_axial`；
  - 横流：圆柱横流势流/阻力模型（含分离角判据），给 `U_cross(θ)` 与 `p_cross(θ)`；
  - 合成：`p=p_axial+p_cross`、`U=U_axial e_x+U_cross e_θ`，并输出熵/总压与分离角。
  - 这一步替代"逐面 PM 从自由来流起算"，是 336 面与 5147 面的共同前提。
- **B. 附着区边界层**：在 A 的外缘上用三维积分 BL（流向+横流两分量），或把 v61 扩成含横流动量方程；不能用现在的轴对称 v61 直接套。
- **C. 分离区**：分离角之后不再用 PM 膨胀，改用平台压力（底压 + 再压缩）与分离/再附热流关联；若要更可信，用局部 2D URANS 条带，而不是全 3D。
- **D. 底区**：底压给定量或关联；底热只在有径向分布数据的 `r/Rb≤0.8` 内使用，外圈明确未解。
- **E. VII**：把 B 的位移厚度反馈到 A 的外缘；这是最后一步，不是第一步。

**当前工程法无权覆盖的部分**（必须保持 NaN 或"假设"身份）：

- 占位外缘的 336 面：在 A 完成前，任何 BL 都不能把它们变成"解"；
- 无分离模型的回流区：B 的积分 BL 在逆流区失效，C 未完成前不能出 q；
- 无径向数据的底热外圈；
- 网格表示不了的几何（鳍/悬挑/多闭环）；
- 真实气体解离/辐射/烧蚀/滑移区。

### Q3 VII/3D 边界层 vs 局部 NS/RANS，先投入哪个？

**先投入"外缘"，不是两者之一。** 理由已在 Q2：336 是外缘伪值，5147 被外缘阻断；VII 和 RANS 都需要一致入口。没有 A，B/C 都是在拟合一个不一致的外界。

如果必须选一个"求解器"作为第一笔投入，我选 **轴对称 2D RANS**，不选 3D，也不选完整 VII：

- **具体几何/工况**：TMR Mach 7 轴对称压缩拐角（20° 外扩、柱径 0.203 m、Tw=311 K、入口按 TMR 的 M≈7.11、Re 与剖面），先复现其入口、几何与量纲（`REGIONAL_ALGORITHM_ROADMAP_2026-10-17.md:83`）。
- **为什么**：它是当前资源下唯一能较快拿到"分离/再附 + 热流峰值"实验对照的路径；网格/通量可复用现有 `buildAxisymmetricEulerGrid`/`axisymmetricEulerFlux`，只需加黏性项、SA/SST、y+<1 与收敛加速。
- **交付 D1**：p/q 沿外扩面与柱面分布、分离/再附位置、三套网格敏感性、SA/SST 对比；验收：q 峰值误差 ≤20%、分离位置误差 ≤1δ、三网格差 ≤5%、不确定度声明。
- **交付 D2**：NASA-TM-101075 的 3D 锐鳍（10/15/20°）压力与马蹄涡拓扑；验收：有测点处 Cp RMS ≤10%，鳍面热流只在有传感器处比较（原文鳍上未装测热）。
- **交付 D3**：真实后体（x≈−0.40 至基座、M5/30 km/α=20°/Tw=300 K）的 A 条带外缘 + B 附着区 BL；验收：5483 面得到有限 p/U/T 或明确原因，收缩肩部不再出现 <80 K 占位，热功率收支闭合，入口 ±10% 敏感性有记录。

**原理上能解决 vs 当前资源能实现**：

- 原理上：RANS（配 SA/SST）能表达分离/再附与底剪切层；VII 能表达附着横流与位移反馈；两者都不能自动解决转捩、真实气体、辐射、烧蚀。
- 资源上：2D 轴对称 RANS 可行；3D 局部 RANS（哪怕一个 180° 扇区）在 MATLAB + 当前一阶 cut-cell + 无湍流模型下不可行于近期；完整 Riley VII 是研究级实现，成本高于条带模型，收益要等外缘跑通后才显现。**因此"先条带外缘 + 2D RANS 基准，后 3D"是当前资源下的合理顺序。**

### Q4 两个压力来源、给定量/覆盖率是否误导？

**是，有实质性误导风险，主要有三处：**

1. **同一面元两个压力**：界面"表面压力"是牛顿/给定（`modifiedNewtonianPressure`），热流的"外缘压力"是切锥/切楔/PM（`solveExternalFlow`）；载荷用前者（`integrateAerodynamicLoads.m:25,96`）。在 20° 攻角压缩/膨胀区，两者系统性地不同，但界面没有把"哪个压力驱动哪个量"放在同一屏。
2. **49.7290% 的给定量**：背风 `Cp=0`、尾底 `Cp` 是输入，不是解；满色云图 + "压力"标题会让报告读者以为全表面压力已求得。`CODE_STATUS_REVIEW_2026-10-17.md:47` 有文字提醒，但 PNG/CSV 没有把"给定"做成不可忽略的视觉身份。
3. **覆盖率口径**：66.5626% 含平板回退与未验证的工程关联；95.5150% 外缘覆盖是否排除 336 占位面未在文档中交叉核对（见"推断/待验证"第 3 条）。单一数字不能回答"哪些面是求解、哪些是给定、哪些是假设"。

**建议（近期支持范围 + UI）**：

- **先统一表面压力**：有 `externalFlow.edge` 且有效的面，表面压力取外缘压力；否则用牛顿/给定并标方法。这样载荷、云图、热流共享一个 p，剩下的是"方法差异"而不是"两套场"。改动小、可测试，但会改变载荷，必须先记录基线。
- **标题只报三数**：每个场量显示"计算 X% / 给定 Y% / 未解 Z%"，禁止用一张满色图暗示 100%。
- **给定用纹理**：斜线/点阵叠加，而不是仅靠灰/彩色区分；导出 PNG 必须带"给定"图例。
- **探针显示来源差**：同时给 `p_edge` 与 `p_Newton` 及差值，注明载荷用哪个、热流用哪个。
- **证据等级**：A 实验对照 / B 有来源关联 / C 项目假设；按等级统计面积。当前真实答案很可能是"B 级 66.56%，A 级 0%"——这比 66.56% 更有科研价值。
- **支持域写死**：光滑旋成体、连续流、M>1、附着为主、Tw 给定、单工况；域外明确拒绝，不用"更多方法"填满。

### Q5 公开基准与自绘突起箭体的先后？几何/求解短板？

**顺序**：

1. **TMR M7.11 轴对称外扩**（`REGIONAL_ALGORITHM_ROADMAP_2026-10-17.md:81-85`）：有实验 p/q、入口剖面、成组网格，最适合先验证 RANS/热流。
2. **NASA-TM-101075**：先 20/30/32.5/35° 轴对称外扩（压力/热流，附着到分离），再 10/15/20° 三维锐鳍（压力、马蹄涡）；原文鳍上未装测热，不能用于鳍面 q 验证（`:75-79`）。
3. **收缩/boattail 案例**：需要另找膨胀拐角+横流的数据；若没有，只能用本程序 Euler/条带做网格/入口敏感性，并明确"未实验验证"。
4. **真实 20° 箭体**：在前三步的方法有适用域后再接。
5. **突起**：最后。短突起关联（Mazaheri/Wood，`k/δ<0.3`、以基体 q 为分母、峰值定义，`:54-58`）只能做峰值筛查，不能给分布 q，更不能用于锐鳍/悬挑。

**自绘箭体的定位**：几何/网格鲁棒性、特征保留、方法切换、UI 预览；**不是实验真值**。它现在的具体短板：

- `autoRemeshSurface.m:3403-3422` 取最大主环：截面出现机体+鳍两个闭环时，鳍会被丢弃；这是"看起来像火箭"但物理上已丢几何的机制。
- `buildRocketTestBody.m:5,180` 只生成单值径向图的光滑整流罩/纵脊，不支持独立鳍、悬挑、孔洞、多闭环；`ROCKET_PROTRUSION_TESTS.md:21` 已承认。
- 鼻尖约 2.1% 面积不满足 AR/最小角（`ROCKET_PROTRUSION_TESTS.md:36`），最差面在 `X≈1.420 m`；在局部加密/嵌入网格前，鼻尖热峰不能作为验证对象。
- 没有边界层分辨网格（y+、法向增长率），也没有鳍前缘/根部的局部加密；峰值关联不能替代分布解。
- 回流/分离没有区域模型；即使几何生成成功，也只能进"未解"。

## 四、我赞成的路线

1. **区域分级混合架构**：附着区用自算外缘 + 积分/非相似 BL；强干扰/回流用受控局部黏性解；PNS 只作受限加速。这与 `REGIONAL_ALGORITHM_ROADMAP_2026-10-17.md:11-24` 一致。
2. **保留 MATLAB 后端、离线 WebGL、NaN/状态纪律**；不引入外部 CFD 作为前提。
3. **公开基准优先于自造算例**：TMR、TM-101075、Marvin 数据库、Rabinowicz 底热；每个案例的记录要求（原表/工况/单位/壁温/测点/不确定度）应照 `REGIONAL_ALGORITHM_ROADMAP_2026-10-17.md:73` 执行。
4. **几何夹具与物理验证分开**：自绘箭体只做鲁棒性；实验几何另按来源重建。
5. **v61 的方程/入口/量纲/拒绝合同做得扎实**，作为"轴对层流模块"是合格的；问题在它的位置，不在它的实现。
6. **UI 的逐变量身份**（输入 Tw/外缘 T/恢复 T/求解 Tw/给定/未解）是真正的资产，应继续保留并扩展到新区域。

## 五、我反对或要求修改的路线

1. **反对把 v61 作为主线第一步并继续细化**：它不在 29.3350% 的关键路径上；应限五项收口后冻结，与主线并行。
2. **反对在全局外缘之前投入 3D BL 或 3D RANS**：两者都会把内层拟合到不一致的外界；先做 A（条带/近似三维外缘）。
3. **反对把"更多方法/更多有限值/更多云图"当作覆盖**：覆盖率必须按"计算/给定/未解/证据等级"四分，且每个数字可追溯。
4. **反对用峰值关联涂满突起/鳍**：`k/δ<0.3` 的圆钝短塞关联不能外推到锐鳍、悬挑、分布 q。
5. **反对在压力一致性未解决前做 UI 对比功能**：先把"两个压力"统一，否则对比视图会放大矛盾。
6. **反对把自绘箭体当验证真值**：它没有实验几何、没有传感器位置、没有边界层入口。
7. **反对继续追 0.01% 级数值误差**：v60 的 0.357%、v61 的 0.0136% 已远小于物理不确定度；应把资源转到外缘/入口/实验。
8. **反对把 95.5150%/66.5626% 直接当作"已解"**：前者需核对是否含占位，后者含平板回退与未验证关联。
