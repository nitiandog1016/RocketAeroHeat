# 2026-11-01 路线复审：从全域接口走向物理结果

本次在v123交付基础上检查工作台、异步监督器、状态读取、热流映射和固定SU2源码，承接用户“接受内嵌，优先完整计算”的决定。当前版本及实际终态以[目标文档](../PROJECT_GOALS.md)末尾为准。本文是定向架构/物理接口审查，不代表全库逐行审计或独立实验验证。

## 结论

MATLAB负责组织计算、工程模型与输入管理，自定义WebGL提供统一科研工作台，复杂外流由内嵌成熟NS/RANS求解器处理，这条路线合理。当前最需要改变的是成果衡量和执行顺序：完整数据链已经有基础，后续应优先获得真实完整域的稳定、可信p/q，而不是继续堆叠启动测试、层流续算或物性例外补丁。

“无需用户导入外部CFD”与内嵌全域求解完全一致。内部自动生成网格、调用求解器及读取结果是产品能力；公开DNS/实验输入只用于验证。不能把内部求解器当成只在工程区域入口全部具备之后才允许使用的最后选项。

## 当前瓶颈及处理

| 发现 | 影响与实施决定 |
| --- | --- |
| 工程外流与表面图路径缺少完整三维横流/回流信息 | 真实20°收缩—后体的大缺口不能仅由新增壁热关联填补；完整域黏性解作为复杂工况主路线，工程链保留快速估算和受限对照 |
| 三维已存层流场尚未收敛 | 退出0、全表面有限值及原面映射通过只证明链路；不能计入已验证面积 |
| SST原先只有源码合同，读取器按列数推维数、按末列取能量 | 3D SST多两列会误判维数/ρE；必须按具名列绑定，并从总能量扣k，增列不能伪装原9列层流继续计算 |
| 壁距语义有两种 | SU2的SSTω/y+使用连接非壁邻点到墙面的最短距离；壁热梯度用最大法向余弦邻点的法向投影距离。法向层高度不自动等于前者，层流Y+全零不作网格资格 |
| 入口湍流与转捩没有飞行实测依据 | 明确全湍流假设和I、μt/μ、Prt来源；SST不是转捩模型，也不是调整残差的工具；需针对区域热流做参数/转捩不确定性评估 |
| HEOS实际约29.36秒/步，存在大量重构回退 | 完成热力学接口不代表适合本低密度非反应空气任务。有限评估高效变比热理想气体/带误差界表化路径；不得把HEOS性能优化永久放在全域计算之前 |
| y+和全局热功率不足以验证三维分离热流 | 还须局部有符号壁剪、分离/再附位置、周向/轴向p/q分布、热峰、尾流网格和外域敏感性；平板DNS不授权箭底和突起 |
| 单次720秒限制是监督预算 | 不等于物理解理应在720秒内完成。后续可按已验证继续条件分段，但每次必须有机制/收益/总成本计划；当前失败筛选不能自动转为无限续跑 |

## 主线与物性决策

1. 完整域SST先以定比热受限研究实现状态、壁热、y+、来源和UI；不将它升为最终变物性环境。支持范围与研究/给定/未知身份贯穿原面、探针、曲线和导出。
2. 实际场确认之后，依据局部残差、热负荷变化、y+和分离机制选一个有物理依据的改动。若稳态假设不适用，改为同一飞行工况的URANS并预先定义时间步、内收敛、采样窗和统计稳定标准；这不要求提前实现轨迹或材料长历史。
3. 同步完成一个条件可匹配的公开热流对照。TMR M6Tw025已有输入，但温度、物性、入口边界层/湍流、测站、归一化全部要匹配；仅抄Mach、壁温或使用统一自由流起跑不构成DNS对照。
4. 在同一工况保持p/T/速度和热边界，有限比较成熟高效变比热路径。不能直接复制旧ρE，也不能把不同通量/边界/湍流模型的总差异归因于cp。
5. 返回真实全表面做网格/外域和区域验证，再以连续闭合的带突起模型扩大范围。鼻/侧/收缩/后体/底面不能删，平板或经典0°不能长期替代真实20°。

原流动−8门槛保留，SST同时报告k/ω残差。不同方程的有量纲残差不可横向当误差大小比较；后续应增加定义明确的归一化、守恒和工程量稳定性检查，任何门槛变更须另有事前依据，不追溯改写旧失败。

## 目标合理性与优先级

单时刻全面积壁压和给定Tw下的对流热流、与统一科研UI并列最高，是可执行的阶段目标。不能承诺任意STL/任意参数全覆盖。求解壁温需要额外材料与热边界条件；底区Te/Tr可能无唯一定义，应说明不适用，不伪造字段。

累计热量、轨迹、壁体瞬态、跨流态和高焓机制继续后置。它们保留在长期目标，不作为当前结果完整性或UI验收前置。小版本同步公开GitHub，源码和小证据交付；大场仍仅本地，不能把推送成功当作大输出已备份。

## 避免再积累“接口已通但区域未解”的版本

每轮说明对目标区域的实际收益；把接口通过、有限数值筛选通过、数值误差评估、公开数据比较和区域资格分开。继续使用既有主工作台，不为每个研究另开永久页面。来源核验和测试支撑结果，但测试数量、截图或版本号不是气动热完成率。
