## 下一项实现

1. 先在现有官方定比热运行包实现受保护的 SST-2003m 通路，保留层流和 HEOS 研究；不解除 HEOS 的未适配RANS拒绝保护。定比热 SST 是有明确物性误差的对照，不代替最终变物性热环境。
2. 写显式配置及状态适配器：输入全湍流假设、I、黏度比、Prt和来源；同 p/T/U 转换、k/ω初猜及ρE一致。迁移是新模型初猜，新局部步号从0记，源799或19不可累加。k/ω的非均匀初猜和壁面条件不能以随意裁剪实现。
3. 针对真实19752面20°完整域，复用已存18层和首2µm候选数据，先审核原生 SST 最近邻距离/壁面处理；v120 的层流估计y+99分位0.8363不是 SST 资格。根据实际湍流壁剪重新判断，不直接再加层或改默认网格。底面、横流、收缩、后体都保留。
4. 用一个小而有非零热流区分力的实际接口任务，核对原生11列、k能量扣除、EOS、壁温、热流和原面映射；与本次主工作台流程接回。先定预算和门槛，不重复HEOS20步、不用湍流开关掩盖能量不收敛。
5. 条件匹配后，使用已保存的 [TMR M6Tw025 DNS](https://tmbwg.github.io/turbmodels/Other_DNS_Data/supersonic_hypersonic_flatplate.html) 做热流/速度/温度对照。其T∞55.2K、Tw97.5K、R287、Pr0.71和原Sutherland律必须逐项匹配；原数据检查不算解验证，更不是实验认证。原M8输入失败和旧图11草稿仍保留。

## 验收边界

保留原流动残差−8条件，同时增加 k/ω残差、正状态、壁面热负荷与区域分布稳定性；设置门槛须在运行前记录。强三维分离若不能得到定常稳定解，再以明确物理时间/内迭代/统计窗准备 URANS，不能把任意定常迭代当飞行时间。

全湍流是假设，转捩位置仍未知。入口/Prt/网格/外域/物性误差分别列出；前侧平板对照不授予箭底、再附或突起资格。实际大面积预测与科研UI并行推进，每完成一项立即接回原面p/q/T、算法、状态和导出；资格仍按支持几何与工况逐项取得。

若后续需更高效的变比热路径，应优先评估适合低密度非反应空气的成熟理想气体热力学表/多项式或有误差边界的表化EOS。固定包的 `INC_IDEAL_GAS_POLY` 是不可压缩分支，`STANDARD_AIR` 仍是定γ，二者不能冒充已实现的可压缩变比热模型；Cantera等依赖也要先证明本地可用与适用性。此处没有选定或实现新的替代引擎。
