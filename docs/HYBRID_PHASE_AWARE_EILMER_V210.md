- 固定标准Air组成、R=287.0491267875601 J/(kg K)，60—2000K，原低密度压力包络及0.1露点压力距离。原数据SHA `7fdde65001d0d0aefe6b40136f269c5f512b8a94e327748854987cc831fe3985`嵌入并核验。
- 相同Cp分段积分、hs(298.15K)=0、hf=0、u=h−RT、相对s(298.15K,100000Pa)=0。合法负参考内能保留；没有把零点平移来满足旧LUT的u>0条件。
- 与v207一致的Lemmon dilute mu/k节点及线性插值，变Pr，不把低压气相自动当作连续介质。
- pT、rhoT、rhop、rhou、pu、ps、hs及热力学/声速/输运必要入口齐全；反算用固定原生`nm.brent.solve`求实根，最终联合p/T接受，不裁p/T/u。

## 失败保留及恢复的准确范围

1. build01在编译前源清单遇到名为`cuda.d`的目录；原生编译未启动。只补is_file过滤，原失败/执行源保留。
2. build02编译缺EQC的D模块导入目录；build03随后发现helper的file.write/stdio.write同名冲突。分别按已登记预算修复路径、限定readText导入，气体算法未改变。四次编译进程含两失败累计22.593143秒，不能只报成功构建耗时。
3. query01未知模型由官方factory抛Error而非普通Exception，真实exit1；stdout/stderr在limit60一行交错，后续差分未执行。保留失败并逐行复用117完整行，只补29行；复数为首次执行。累计查询监督1.046461秒。未知模型是已观察的进程级拒绝，不把旧query01改成passed。
4. audit01实值/反算/差分已过，但18项导数对“原意图节点的右斜率”失败，最大9.913e−4。24项返回温度落入相邻分段，例如80K返回79.9999999999997K；线性mu/k连续但斜率不同。audit02仅按**已经独立核对的实际返回实状态**构造参考Jacobian，同门槛通过，无编译或查询重跑。精确节点右侧约定保持；原失败不追改。

这证明分段内/约定单侧导数，没有证明表节点高阶光滑、跨节点唯一导数或NK收敛。源码与真实运行回执相互绑定，不把只读审核的passed升级成物理资格。
