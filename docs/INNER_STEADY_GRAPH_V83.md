# v83 近似系统求逆与五量稳态耦合研究

本轮承接`WLS_NORMAL_PRECONDITIONER_V83.md`：最新保存方向的五带图作用已经接近完整NS，但原NS总方向缺陷仍约0.198764，未达到0.1。本轮先区分近似矩阵误差、一次扫描求逆误差与时间正则作用，再检验整体五量稳态候选。没有进行新非线性更新或物理资格验收。

## 方程、程序与适用身份

- 完整稳态方向算子为`A=-J`。原图预条件近似为`B=I/tau-Jgraph`；tau不代表物理时间。
- 新`solveRocketInnerGraphKrylov.m`对传入的近似系统做有界右预条件GMRES，内部以固定一次五带着色扫描预条件。它复用既有两遍正交内核，仅一周期、零保留；当前完整J/NS不在内部调用。矩阵作用与扫描内额外B残差诊断分别计数。
- **内部GMRES的映射不能冒充固定线性外预条件器。** 即使固定步数，其最小二乘系数仍依赖右端；若以后接入外层，须采用保存物理Z方向的柔性方法并重新核对原NS总方向。本轮未接入生产外层或GUI计算配置。
- 新`buildRocketSteadyGraphPreconditioner.m`显式构造`C=B-I/tau=-Jgraph`，同时移除五量时间对角并重新分解线内块。不沿用B旧因子，不单独调整密度/能量，不改变物理方程。C仍缺少部分跨原面WLS耦合及外边界精确Euler敏感性，是近似矩阵。
- 六个新MATLAB完整文件位于`internalFlow/cutCell/`和`tests/`，均有中文模块注释。除两个构造/求解模块外，测试入口为`testRocketInnerGraphKrylov.m`、`studyRocketInnerGraphKrylov.m`、`testRocketSteadyGraphPreconditioner.m`、`studyRocketSteadyGraphPreconditioner.m`。

## 小域与独立代数校核

`innergraphunit01`实际exit0/源码锁稳定、引擎57928。沿用已保存32CV/160量完整A与五带B，不新增完整Jacobian列或原NS。两组内部B求解分别4/3个Arnoldi方向，独立稠密残差约1.43e-12/4.16e-11；零右端、存储拒绝和V/Z/H关系通过。另以160次固定扫描构造完整P用于独立比较，每次包含一次B诊断，不计作完整J/NS。

独立小域数据表明，`cond(B*P)`约1.013，而`cond(A*inv(B))`仍约6816；因此在这个小域上，B可以容易求准，但精确B逆并非稳态A逆。这不是实际箭体全局条件数的证据。

`studyRocketSchurReferences.py`仅对小域完整矩阵做稠密Schur参考。对原始当前小域右端，最优单方向模型缺陷为：全量保留正则0.26177、仅密度去正则0.96754、仅能量0.40911、密度+能量0.54874、全五量去正则0.004404。部分移除反而更差，故没有据“质量剩余大”就直接采用密度单字段修正。Schur与直接解相对差约3.7e-15～4.3e-14；这些是代数参考，不是已实现的真实Schur求解器或实验验证。

随后`steadygraphunit01`实际exit0/源码锁稳定、引擎50648：C与B减去全部时间对角一致，旧B保持；新五带扫描与独立稠密解差约1e-14，内部C九步达到约7.35e-12。二次去正则明确拒绝。Python独立C作用、逐色扫描、Arnoldi及新因子/旧B关系通过，未新增原NS。
