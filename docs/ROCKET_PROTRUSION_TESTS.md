# 自绘完整箭体及突起测试（2026-10-17）

本轮已实现、测试并导出的是**几何夹具和特征保留检查**。没有新增物理求解方法，没有把突起区计入新增已验证气动热面积。算法扩展建议见 `REGIONAL_ALGORITHM_ROADMAP_2026-10-17.md`，执行顺序见 `PROJECT_GOALS.md`。

## 模型和接口

`buildRocketTestBody.m` 直接生成一个闭合外边界，包含球钝头、锥段、柱段、约30.85°收缩肩、较细后体和底面。单位m，主轴X、鼻尖+X。光顺基线、单侧整流罩、纵向凸条和双突起均可重现，突起高度、长度、周向位置、宽度及轴向位置可配置。

```matlab
[mesh,meta]=buildRocketTestBody(struct('protrusionType','fairing'));
smooth=buildRocketTestBody(struct('protrusionType','none'));
demoRocketTestBodies; % 输出四组完整MAT、STL、JSON与审核摘要
addpath('tests');
testRocketTestBody;
testRocketRemeshFeatures;
testRocketTestGeometryView;
```

每个MAT保存完整 `mesh/meta/cfg`。JSON包含真实V/F、基础区域、突起支持域及逐面标签，F使用MATLAB的1起始编号；离线预览负载才转换为0起始。`meta`还含节点相对基体的径向高度、截面和解析基体面积/体积。互不重叠突起有解析体积；重叠突起交叉体积未解析时明确给NaN，不伪称真值。

当前突起是柱段上的单值径向图，使用连续光滑过渡。不能据此声明已支持独立鳍片、悬挑、孔洞、多闭环截面或任意CAD并集；构型不满足生成条件时拒绝。没有用相互穿透的封闭壳体代替真实外边界，也没有修改既有 `autoRemeshSurface.m`。

## 已完成的检查

MATLAB几何测试29项通过：边恰好两面且方向相反、Euler示性数2、一个连通分量、正面积/体积、法向、解析体积细化、突起支持域/峰高以及错误输入拒绝。四组48档演示模型的三角面数为9216、11172、10800、12600。光顺/整流罩/凸条的体积相对误差在细化后分别约0.2865%/0.2595%/0.2715%；这是几何离散误差，不是气动热误差。

重网格审核对同尺寸光顺/双突起模型分别调用既有网格器，再在每个特征的13×13个(X,θ)位置，直接做射线与真实三角形求交，比较径向差。预设门槛为RMS/高度≤10%、最大误差/高度≤20%、中心高度保留85%–110%。这避免只看整体最大半径而漏掉局部特征。

| 网格配置 | 特征 | RMS/高度 | 最大误差/高度 | 中心高度保留 |
| --- | --- | ---: | ---: | ---: |
| 默认 | 整流罩 | 1.949% | 7.473% | 95.07% |
| 默认 | 凸条 | 5.463% | 14.183% | 85.82% |
| 特征细化hMax=8mm、hMin=2mm | 整流罩 | 0.673% | 2.414% | 97.65% |
| 同上 | 凸条 | 1.720% | 6.908% | 93.18% |

两档特征保留门槛均通过，原始和重构模型均闭合、有向且连通。但**全局三角形质量门槛没有通过**：配置要求AR≤5、最小角≥20°，实际默认最差AR约7.43/最小角4.75°，细化后最差AR约21.60/最小角2.86°。带突起模型分别220/526面不满足质量要求，面积约2.15%/2.14%；最差面位于X≈1.420m的鼻尖环带。突起支持域的面元质量满足上述门槛。这说明全局简单加密不能保证极区质量，后续需专门处理，不可把“特征保留通过”写成“整张网格可用于热峰精度计算”。

## 自定义三维预览

`exportRocketTestGeometryView.m` 复用正式工作台的 `web/geometry.*`，提供离线模型选择器、旋转、平移、缩放和实际网格线。它只显示几何，页面明确没有物理场量。

```matlab
names={'smooth','fairing','ridge','two_protrusions'};
base=fullfile(pwd,'outputs','rocket_fixture_2026_10_17');
meshes=cell(4,1);
for k=1:4
    data=load(fullfile(base,['rocket_',names{k},'.mat']),'mesh');
    meshes{k}=data.mesh;
end
exportRocketTestGeometryView(meshes,fullfile(base,'web'), ...
    {'光顺完整箭体','带单侧整流罩箭体','带纵向凸条箭体','带两个突起箭体'});
```

导出函数已经核对V/F逐值身份、0起始转换、模型切换负载、中文物理身份和非法网格拒绝。实际浏览器检查包括四模型标题与面数、三维绘制及视角切换；截图和运行记录位于 `outputs/rocket_fixture_2026_10_17`。交付工程中几何与离线页放在 `example_geometry`，测试证据放在 `validation/roadmap_geometry_20261017`。

## 后续广度与物理验证

下一步将同类几何用于0°/10°/20°攻角、迎风/侧向/背风、凸高/宽度和网格的成组求解；本轮没有执行完整工况矩阵，不能把本报告的几何测试数写成气动热算例数。遮挡、激波干扰、马蹄涡、分离/再附和底部回流都需要适用区域模型与边界数据。

公开实验另按来源重建，不使用自绘箭体作为独立真值。优先候选为NASA-TM-101075柱面锐鳍/外扩面及对应TMR基准；原实验与调整后的计算入口、实际有传感器的测面、低温物性限制分别说明。待新的区域方法实际求解、验证并映回真实面元后，再增加生产已解面积和工作台方法选择。
