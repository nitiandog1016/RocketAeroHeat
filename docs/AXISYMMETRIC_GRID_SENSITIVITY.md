# TMR方向网格与冻结出口对照（v67）

本阶段沿用v66的真实SA五量方程、Sutherland输运和显式Dirichlet切向墙热梯度，检查流向、壁法向及出口储库影响。它是为真实区域模块提供数值依据的研究步骤，不是新的生产面积，也不是完整箭体或三维横流求解。当前生产热流覆盖仍为66.5626327424%，新增合格面积0。

新网格以逻辑父控制体复制全部五个守恒均值作为数值初猜。这不是保守重映射：细网格曲线的折线近似与粗格不完全一致，子体积和可与父体积不同，强行把两者称为同一保守账是错误的。每档保存实际初积分、相对父积分和按父分组的体积差；BE守恒账从新网格自身的初积分开始，不把初始化当物理时间推进。

气体、三条恒HLLE储库、SA、给定Tw311K、`dirichlet-tangent`、固定五量残差尺度和原`2e−6`连续3步均保持。没有因加密而裁N、热流或放宽稳态门槛。新网格的`gridStudy`对象描述初始化合同；最终是否稳态由`implicit.steadyConverged`及真实原残差历史决定，不能继承父网格资格。

## 出口储库对照与范围

真实v66出口25面全为实际质量出流，但首面owner法向Mach约.484，其余24面超声速。外边界和入口也不能整条视为法向超声速；把整条开放边改零梯度会丢失所需声学输入。

`outlet-profile`保持1000格与同一初场，只将iMax外储库改为冻结v66出口owner的四原始量及nuTilde，逐原面坐标采样。这是明确给定的数值敏感性输入，不随新Q更新，不插值或外推，也不是测得的外部压力或外部CFD数据。原入口、外域、Tw与SA/热物性不变，重新求完整稳态；不能挑选出口压力来拟合实验。

构造器保留原25面face/owner/坐标/四量/N。原MAT中匿名边界句柄作为证据保存；移到另一目录重放时，推荐以包内v66父MAT调用`createTmrAxisymmetricOutletCase`重建同一明确输入，再逐字段核对冻结剖面并加载新Q。这样不依赖旧工作目录的本地子函数位置。隔离复测将实际验证这条路径，不把源路径字符串当可移植性证据。

当前没有执行外域位置敏感性。独立只读检查提出的截最后一列、向内移动top仍只是缩域对照，不能证明更远外域收敛；由于强拉伸，不能把节点列数减半叫物理半高。具体边界法向、状态、HLLE同Q影响与建议见包内`validation/v67/review/BOUNDARY_SENSITIVITY_PLAN.md`。
