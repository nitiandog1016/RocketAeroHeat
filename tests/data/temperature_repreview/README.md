# 投影后温域再检查的制造场

这三个小型 MAT 只用于数值测试，**不是外部 CFD 场，也不是物理 NS 导数验证**。Q和几何来自已有32CV制造域；C/W来自随库耦合线性系统。右端以 `(C') \ ((A'*A)*desiredFree)` 构造，使自由最小二乘方向接近指定的制造方向。

- `late_exposure_closes_moderate.mat`：PCG64种子492，第208次制造，基态速度[1000,1100,1200]m/s；初始候选越温CV为1/9/23，首次投影后新暴露CV5。它检查通用补全及稠密方向，不在算法中指定这些CV。
- `late_exposure_closes.mat`：种子392，第91次制造，高动能基态；初始候选越温CV为3/10/13/32，首次投影后新暴露CV19。有限步温度合法与原128eps点积门槛分别核对，不能把前者当作后者通过。初次本机测试点积门槛实际拒绝，该结果保留为压力测试，未放宽门槛。
- `curvature_stall.mat`：种子92，第84次制造；初始候选越温CV为11/20/24/28，投影后新增CV16，但部分已激活CV仍因非线性曲率超域。必须如实报告无法保证有限步温域，不能无限重复同一组约束。

两种代数排列、全部投影方向、一次受限预算不足、零右端及原面侧别冲突分别验证。没有通过这些制造场授予区域求解或新NS接受资格。来源文件和SHA见`manifest.json`。
