This subdirectory provides the Database files for the Kussoy Mach 7.05 axisymmetric cone-cylinder-flare experiment.
The experiment was conducted in the NASA Ames 3.5 foot hypersonic wind tunnel using heated dry air.  This facility
is no longer operational.

Included in the database are data for 4 flare angle cases, including a 20 deg attached, 30 deg incipient separation
 and 32.5 deg and 35 deg fully separated cases.  In addition to the pressure and heat transfer measurements,
 boundary layer profiles are provided.

Nominal Test conditions (at X=133 cm from cone-cylinder nose tip) were:
 Minf= 7.05
 Uinf= 1274 m/sec
 Tinf= 81.2 K
 Pinf= 576 Pa
 Rhoinf=0.0252 kg/m^3
 Qinf= 9300 W/m^2

The data source documents are:
 Settles, G.S. and Dodson, L.J.
 Hypersonic Shock/Boundary-Layer Interaction Database
 NASA CR 177577, April 1991.

 Kussoy, M.I, and Horstman, C.C.
 Documentation of Two- and Three-Dimensional Hypersonic Shock Wave/Turbulent Boundary Layer Interaction Flows
 NASA TM 101075, Jan 1989.

See Also (for more information on geometry of nose tip)
 Kussoy, M.I. and Horstman, C.C.
 An Experiment of a Hypersonic Shock-Wave Turbulent Boundary Layer Interaction Flow-with and without Separation
 NASA TM X-62412, Feb. 1975.

Grids are given for all cases, along with the CFD solution for the 35 deg case.
 These are provided by James L Brown of NASA Ames, using the DPLR Navier-Stokes code.
