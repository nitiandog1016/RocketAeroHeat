# 共同激波层小型冻结证据

三份MAT分别对应v98已实际完成的抛物面、纵向二次曲线和顶点横向位置反算研究。它们只用于复核已保存数值与科研视图，尚未通过真实体形匹配，不是正式壁面、边界层外缘或热流结果。

每份文件均为原计算MAT的逐字节副本；来源、SHA、任务、独立校核、方法限制和复现命令见`docs/validation/v98/README.md`与其`raw/copied_evidence_manifest.json`。输入是项目冻结的原19,752面几何和M5/30km/alpha20自由流，没有外部CFD壁面场。MATLAB完整源码均在`regionalFlow/shockLayer/`，无需大型旧计算输出即可重新运行测试。
