默认使用方法（main.m）
1. 使用当前项目源码，或将已交付完整工程包解压到本地可写目录，在MATLAB中进入项目根目录并运行main.m。v56尚待最终surface测试与打包；最新已交付包仍为v55，旧包不包含本轮有效性修正。
2. “输入模型”：选择 STL，核对“原坐标 → m”系数并加载；毫米坐标通常为 0.001，米坐标为 1。使用 PCA、翻转或增量旋转核对实际主轴/鼻向，再点“确认主轴 X、鼻尖 +X”。鼠标旋转仅改变视角。
3. “生成网格”：设置尺寸/轴向/周向参数并点“生成并检查表面网格”，核对节点、面元、AR、最小角和拓扑。继续使用既有重构算法；不接受开口、非流形或退化候选网格。
4. “添加边界条件”：输入高度、Mach、攻角、侧滑和给定壁温，选择物性、鼻区、湍流、转捩及底压方法；底压受限模型还需要真实尾撑/喷流声明及来源。点“确认当前边界条件”；当前完整工程链要求 M>1，此步尚未求压力或热流。
5. “计算”：明确点“计算当前工况”，查看实际阶段日志。失败时保持同一窗口，在边界步骤改条件、重新确认后重试。输入版本/求解编号或网格不一致的快照不会作为当前结果接受。
6. “查看结果”：选择压力、热流或温度；点击三维面元，核对编号、坐标、数值、算法、状态和适用范围。点击模型、输入 X 或使用滑块查看真实截面周向分布。比较时可固定色标；灰色/空白表示未解，输入壁温不是求解壁温。网页可导出当前截面/全表面 CSV 和定量图像，侧栏可导出完整离线工作台。浏览与导出均不会重算。
7. 可返回任一步查看已经接受的设置。修改上游后旧结果入口失效；按侧栏提示重新加载/确认、生成网格、确认边界并显式计算。当前侧栏不提供材料/历史专题，需按下节使用保留入口。

v42 新增：受限线性重构、积分中心修正及独立外流验证

这是推进内置外流精度的一步，尚未完成完整气动热。默认仍是一阶算法；统一“Euler 外流验证”页新增“受限线性重构（试验）”。不要求外部 CFD 数据，未改变现有工程热流。所有模块均有中文说明。

计算模块：axisymmetricCellGeometry.m 用局部坐标三角形积分分别计算旋转体积中心、子午面积中心和 r 加权面中心；prepareEulerReconstruction.m 预计算真实坐标的四邻居加权最小二乘梯度；reconstructEulerPrimitive.m 对密度、两速度和压力使用 Venkatakrishnan 型平滑限制及正值斜率限制；solveAxisymmetricEuler.m 的空间选项 2 配合 SSP-RK2 局部伪时间，径向压力源按面积中心重构。边界/极值处可能退化为一阶，不声称全域二阶精度。未裁剪单元压力、重设温度/总焓或补造驻点零速度。

壁面结果：第一层单元、内侧重构迹和反射壁面数值通量压力是不同的诊断量。线性重构的面位置采用 r 加权中心，鼻端第一段约位于从鼻端起 2/3 段长；原一阶诊断仍是段中点。extractAxisymmetricEulerEdge.m 按实际位置求弧长/梯度；缺少二阶壁面迹时拒绝输入，不静默回退。两种空间重构不可混作纯网格加密对比。GUI 图例及算法来源随实际计算结果更新，而非随尚未应用的选择变化。

MATLAB 调用示例（已得到 grid、freestream 后）：
options=struct('spatialOrder',2,'fluxScheme','HLL','maxIterations',50000);
result=solveAxisymmetricEuler(grid,freestream,options);
edge=extractAxisymmetricEulerEdge(result);
% options.initialState=previous; 可沿用同网格同工况旧场；仍重新检查收敛。
% 默认 spatialOrder=1。order 2 默认 CFL=0.25，可用 options.CFL 调整。

验证结果：M5、10°圆锥，基础轴向 24/48/96/192，径向同步为其 0.75 倍；对独立 Taylor–Maccoll 解，所测壁段通量压力逐点 RMS 误差为 2.047%、0.570%、0.322%、0.150%；重构近壁压力 RMS 仍分别为 17.879%、9.107%、4.632%、2.301%。不能只凭壁面通量压力准确便把重构状态接入边界层。48→96 时有符号平均压力误差略增，RMS 下降；验证记录保留了初期用有符号均值要求单调而失败的断言，不把误差抵消作为精度证据。

半球鼻同一 64 段母线/64 径向网格、同一原 HLL 通量对照：一阶与线性重构均收敛且边界合格。首面通量压力相对中心线驻点极限的偏差从 -4.44% 变为 -2.27%；全场总焓最大偏差从 8.05% 变为 4.06%。首个速度取样点位置不同，不能把两点直接当相同位置比较；前六点二次外推的鼻端速度截距从 20.43 变为 6.46 m/s，仅为诊断，不能据此认证真实驻点梯度。线性计算先 CFL=0.12 运行 10000 步（未收敛），再 CFL=0.25 续算 10735 步收敛。HLLenthalpy 的旧版近常总焓特性不能直接假定在线性重构中同样成立。

实际箭体鼻部过渡网格 343×64，沿用 v41 同网格一阶 HLLenthalpy 初场、切换原 HLL 与受限线性重构：本轮 25000 步，残差 0.162623，收敛及边界检查合格=否；首点速度 17.0848 m/s，首面通量压力 36.5436 kPa，总焓最大偏差 7.6838%。这是一轮明确的算法切换，不能把与 v41 的差别都归因于重构。 当前这轮未收敛，所列场量只作诊断，不能作为稳态精度或热流入口的证据。后续保留同网格状态继续求解。

本轮通过 13 项针对性回归；项目现有 63 项测试，未全部重跑。包括几何矩/仿射场/正值与平滑限幅、解析壁面梯度、两种通量、新 GUI、原 Euler/激波/重启/网格对比、真实箭体原一阶 GUI、统一 main 等。另用 Python 从保存 SI 场独立复算取样弧长、速度投影、总焓及基准误差。preview/v42_numerical_comparison.png 和 linear_euler_cone_pressure.png 为本版新图；其余预览保留原版。

早期尝试记录：无约束边界外推在圆锥上不收敛；所有面硬限幅能使圆锥收敛，但半球鼻残差振荡；改用平滑限幅后半球鼻才达到原阈值。平滑限制允许尺度随网格减小的弱超调，故测试采用其独立有理函数超调上界和独立正值检查，不能继续套用硬限幅的严格极值不变断言。失败日志均保留在 validation，不宣称首轮全通过。快速关窗时旧有 MATLAB 内部 ViewModel 偶发回调问题不在本版修复范围。

后续：验证实际箭体近壁状态、总焓/熵与驻点速度梯度，继续做固定几何加密及独立基准；随后才建立热物性一致的 Euler—边界层入口。edgeStateAvailable、gridAccuracyVerified 继续为 false，未把定比热 Euler 静默混入 NASA7 工程热流。

v41 新增：鼻部法向网格、一般面法向 Euler 和固定外形母线细分

本版不改变 STL 表面重构算法。新增 buildNormalOffsetEulerGrid.m，改善无粘流场计算网格在钝鼻处的倾斜。支持完整法向偏移（光滑钝鼻）和鼻部法向—竖直过渡两种试验模式。壁面保留原始分片线性母线，所有四边形检查正旋转体积、凸性及几何守恒；凹肩部可能使完整法线相交，此时拒绝网格，不用坏单元继续求解。过渡模式只在鼻部逐渐使用法向，其余网格线竖直；它不平滑原始几何。

solveAxisymmetricEuler 现在支持两方向一般有向面面积。法向网格的鼻前一侧是 R=0 对称轴，不再错误地当作自由来流入口；来流位于外层曲边。原 X 截面网格仍采用原有上游入口。不同边界拓扑的场不能作为同网格重启。外流边界按真实法向检查超声速流出，远场仍检查完整状态扰动。

统一 Euler 页增加网格下拉框，默认仍为原 X 截面网格。当前箭体可选择“鼻部法向过渡（试验）”；完整法向网格更适合平滑半球鼻等外形，当前箭体凹肩部会被明确拒绝。更换网格需重新计算。算法说明记录实际结果采用的网格，不随尚未应用的下拉选择改变。三维压力、温度和速度云图与全部既有曲线均支持新网格。

新增“母线细分”1～8，对每条原始母线线段等分，保持折线外形不变；三种网格均可使用。仅提高“基础格数”可能仍未细分最前端原始小线段，所以需要这一独立控制。实际网格格数与输入基础格数不同。更改细分数会使已有场不再符合同网格续算条件。

options = struct('axialCells',120,'radialCells',64,'wallRefinement',1);
grid = buildNormalOffsetEulerGrid(contour,options); % 完整法向，适合光滑钝鼻
options.normalBlendLength = min(.15*(contour(end,1)-contour(1,1)),2*max(contour(:,2)));
grid = buildNormalOffsetEulerGrid(contour,options); % 与 GUI 相同的鼻部过渡
result = solveAxisymmetricEuler(grid,freestream);
% 原网格也可细分：buildAxisymmetricEulerGrid(contour,struct('wallRefinement',2));

v40 新增：Euler 近壁状态提取、速度梯度和网格敏感性检查

新增 extractAxisymmetricEulerEdge.m。沿 +X 鼻端到尾部的母线弧长排列第一层 Euler 单元，输出压力、密度、温度、投影切向速度、局部总压和速度/压力梯度。采用一阶近壁迹近似；热力状态来自同一单元的 p/rho，局部总状态由定比热关系计算，不套用自由来流总压，也不利用壁面通量压力强制修正单元温度。投影丢弃的法向动能、原单元法向速度和壁压差另行保存，可检查近壁误差。总压及梯度仍含离散误差，不等于已验证的真实外缘值。

非均匀三点二次差分沿 s 计算梯度；默认几何转角大于 5 度时分段，逆流区及不足三个点的短段不计算导数。端点采用单边差分，不在驻点人为补 U=0。options.cornerAngleDeg 可调整折角阈值，阈值记录在结果中。未收敛场可诊断；其壁面通量压力即使非正也保留原值并标记，不裁剪成正数。available 和 gridAccuracyVerified 始终为 false，禁止把这组候选自动当作热流边界。

统一 Euler 页增加六种图：三维近壁切向速度、三维近壁温度、切向/法向速度曲线、速度梯度、局部总压恢复系数和两种壁压估计对比。保持大画布，页面底部说明当前算法；近壁图的三维色值与提取数组一致。新结果保存在 GUI 的 eulerResult.edgeCandidate，不覆盖原有工程外流/热流。

新增 compareAxisymmetricEulerEdges.m：只比较同一分片线性几何、工况、通量且已收敛/边界合格的两套不同网格。在第一套弧长位置分段插值第二套，输出压力、温度、密度、速度、总压及梯度的差值、弧长加权 RMS 和来流尺度归一化最大差值。禁止跨折角/逆流插值或范围外外推。报告轴向节点及远场位置是否改变；同网格续算不能作为加密试验。双网格差值只能说明敏感性，不提供真实误差或 Richardson 精度认证。

v39 新增：Euler 总焓输运、通量对照和同网格续算

默认 Euler 数值方案改为 HLL 质量/动量 + 上风总焓能量通量（试验）。原始 HLL 保留为下拉选项“原始 HLL（对照）”。此混合方案只改变公共面的能量通量：F_E = F_mass * H_upwind，单元密度、动量、总能量仍按有限体积守恒方程更新；不重新设定单元温度或强行替换总焓。此方案不承诺精确解析接触间断，仍是一阶离散，需独立验证压力、速度及激波精度。

默认箭体 383×64 网格、Mach 5、零攻角的已收敛算例中，最大总焓相对偏差从原始 HLL 的约 13.80% 降至约 1.7e-9（相对量，即 1.7e-7%）。但壁面峰值压力仍约 47.1 kPa，几乎未变，说明总焓保持改善不等于压力/激波已达到网格无关精度。新结果仍不进入热流链路，edgeStateAvailable 与 diagnostics.gridAccuracyVerified 保持 false。

统一 Euler 页增加“迭代上限”和“沿用同网格初场”。默认上限 50000，可设置 1～200000。已有结果与当前网格一致时，勾选后可继续计算；修改格数或外边界后重新以自由来流初始化。切换通量也可沿用旧场，但会重新计算新方程的残差，不继承旧解的收敛标记。未收敛结果在页面中明确标记。算法说明显示当前图像实际采用的方法和初场来源，调整下拉选项后需按计算按钮才应用。

MATLAB 接口：
options = struct('fluxScheme','HLLenthalpy','maxIterations',50000,'CFL',0.5);
result = solveAxisymmetricEuler(grid,freestream,options);
options.initialState = result;       % 同工况、同网格的既有 SI 流场
options.maxIterations = 100000;      % 从已有场继续；此值为本阶段迭代上限
continued = solveAxisymmetricEuler(grid,freestream,options);
% 对照原方案：options.fluxScheme = 'HLL';

重启会核对几何网格、Mach/速度、热力状态、攻角/侧滑；拒绝不同工况、不同网格及非正/非有限状态。result.restart 保存是否重启、原通量、原收敛标记和原迭代数；result.iterations、elapsedSeconds 与 residualHistory 仅统计当前这一计算阶段，不把不同通量的残差曲线混为一条。

新增 testEulerFlux：常状态一致性、旋转、反向通量守恒、滑移壁零质量/能量通量，以及独立 Sod 激波管精确解的网格加密。testEulerRestart 检查从来流启动/从既有场启动的稳态一致、通量切换与过期状态拒绝。testEulerBluntBody 检查半球头驻点压力和总焓；testEulerBluntBody(true) 增加 96 径向格细化，可能需要数分钟。较粗/较细网格的驻点压力误差约 +1.25%/-0.76%，峰值压力偏差约 +7.32%/+2.25%；参考为法向激波后等熵减速的驻点压力。该基准通过仍不能代替实际复杂箭体的压力梯度、外缘速度、激波层精度验证。

v38 新增：内部轴对称 Euler 流场验证页

统一窗口增加“Euler 外流验证”。无需外部 CFD 文件，由程序内部求解定比热完全气体的轴对称 Euler 守恒方程，使用一阶有限体积、可选 HLL/总焓输运通量、反射滑移壁、局部伪时间推进和轴对称几何源项。仅限零攻角、零侧滑、截面近圆且中心线直的尖鼻封口回转体；尾端直接截断，要求超声速流出，不计算底部尾迹。几何模块从原生环截面及独立鼻尖节点提取轮廓，拒绝非轴对称模型；默认允许 2% 离散圆度/中心线误差。

点击“计算内部 Euler 场”，可切换子午面压力、马赫数、三维壁面压力、壁面压力曲线及收敛残差。子午面波系由守恒方程捕捉，激波会因一阶耗散呈现数个单元的厚度。默认使用压力对数色标，优先展示近体区域；可关闭对数色标或勾选“查看整个远场”。Euler 图保持真实比例，不使用顶部工程压力页的径向倍率；相关顶部控件在 Euler 页禁用，图像用页内按钮导出。

轴向输入格数是基础划分：所有母线折点和鼻前加密节点均额外保留，实际格数显示在状态行。径向默认 eta^1.8 加密，鼻前轴向以不超过 1.15 的增长比加密，避免仅加密径向而漏掉脱体激波间距。轴向/径向格数、外边界 R/L 可调整。

重要：该阶段尚未将 Euler 结果接入气动热。原压力/热流链路仍使用各自明确标注的工程外流方法，不把定比热 Euler 场静默混入 NASA7 状态或轴向激波—膨胀推进。result.available 仅表示迭代收敛且边界检查通过，不表示网格精度已经满足要求；edgeStateAvailable=false、diagnostics.gridAccuracyVerified=false。界面始终显示总焓最大偏差和精度尚未验证说明。实际箭体的压力/激波网格误差尚未充分验证，不能仅凭残差或总焓达标就把鼻部压力/温度作为热流边界。未收敛/边界受扰动的结果也可查看，但明确标记。

MATLAB 直接调用（mesh 为已有原生重构网格）：
[contour, geometry] = extractAxisymmetricEulerContour(mesh);
grid = buildAxisymmetricEulerGrid(contour, struct('axialCells',120,'radialCells',64));

save('euler_result.mat','result','geometry');

result 含 SI 制压力、密度、温度、轴向/径向速度、马赫数、壁面数值通量压力、靠壁单元压力、残差历史、边界扰动、守恒恒等式误差、壁面质量/能量泄漏及总焓偏差。壁面数值通量压力与靠壁单元压力是不同的离散量，不能混淆。局部伪时间步不是物理时间。

验证：testAxisymmetricEuler 检查轴线均匀流、精确网格度量平衡、独立 Taylor–Maccoll 锥流、网格加密、激波角、伪时间步一致性、近远场拒绝和正状态；testAxisymmetricEulerGUI 检查实际 STL、非圆截面拒绝、原热流保持、五种图、色标和远场视图。圆锥基准通过不代表实际复杂箭体已达到同样精度。整体气动热目标仍在进行中。

v37 新增：内侧对流/辐射边界与双面能量收支

统一窗口增加“内侧边界”页。默认关闭，保持原背面绝热条件；启用后填写内侧换热系数 h [W/(m² K)]、内侧流体温度 [K]、内侧有效辐射率以及辐射环境温度 [K]。h>=0，辐射率在 0～1，两个环境温度必须为正。h=0 可关闭内侧对流，辐射率=0 可关闭内侧辐射。输入由用户提供，不从 STL 或外流结果猜测内环境。编辑完成后到固定壁温/飞行历程页重新计算，修改输入本身不会改写已有结果。

MATLAB 接口：
material.backBoundary.type = 'adiabatic' 或 'convectionRadiation'
非绝热类型还需 heatTransferCoefficient、fluidTemperature、emissivity、radiationTemperature 四个标量字段。省略 backBoundary 或明确选择 adiabatic 时为绝热。启用时各字段为内侧环境的均匀、恒定参数；不沿飞行历程自动变化。

wallBackBoundary.m 验证边界并给出算法/范围。evaluateBackWallHeatFlux.m 计算
q内 = h内 (T背面 - T内流体) + ε有效 σ (T背面^4 - T内辐射环境^4)。
q内>0 表示材料向内环境散热；q内<0 表示内环境加热材料。内侧与外侧使用同一单位面积，属于平壁近似；有效辐射率是给定的交换系数，不代表程序已求出封闭腔体辐射网络或视角因子。程序不求内腔流动。

solveLayeredWallConduction.m 在最内节点的同一个隐式时间步加入内侧热流及精确温度导数。单层非绝热材料也复用这一守恒核，包括常物性和 cp(T)/k(T) 表，不按单一 Biot 数退回集中热容。每层物性、界面热阻、材料积分储热和初始/完整厚度剖面仍沿用 v36。外侧热流与壁温的沿程迭代、自动子步和内侧散热共同参加收敛与能量核对；不能只在求温度完成后减去一项内侧热量。

completeWallEnergyBalance.m 统一能量符号：
outerNetHeatFlux = 外侧对流输入 - 外侧辐射散热
backHeatFlux = 内侧对流散热 + 内侧辐射散热
netHeatFlux = outerNetHeatFlux - backHeatFlux
因此 netHeatFlux 现在始终表示材料实际净输入。旧绝热工况数值含义不变；非绝热工况不能再把外侧净输入全部视作材料储热。

mesh.wallThermal 新增完整面元×时间数组 backTemperature、backConvectiveHeatFlux、backRadiativeHeatFlux、backHeatFlux、outerNetHeatFlux，并保存 backBoundary.method/scope 与 energyConvention。失效面元保持 NaN。oneDimensional.backTemperature 仍按 oneDimensionalFace 的有效厚度求解行保存。新常物性/变物性单层计算也保存背面温度；旧绝热文件没有背温历史时不能反推或复制外表面温度来补齐。

calcAerothermalExposure.m 增加 cumulativeOuterNetHeat、cumulativeBackHeat、cumulativeBackConvectiveHeat、cumulativeBackRadiativeHeat、backPower 与相应已解区域能量汇总。所有热量按实际接受的右端隐式时间站积分；材料储热核对使用外侧输入减去内侧散热后的净热量。内侧散热有符号，内环境加热时累计值可以为负。非绝热记录缺少内侧热流，或净热流与两侧分量不一致时明确报错。驻点单点同样记录内侧热流/背温；驻点位置移动时仍不拼接不同材料点的温度历程。

壁温页增加“内侧净散热”“累计内侧散热”“内侧对流”“内侧辐射”，以及通用的背面温度显示。内侧热流与累计量使用以零为中心的蓝白红色标：蓝色为内环境加热，红色为向内环境散热。点击模型查看对应面元的时间曲线，标题标明实际内侧算法。原“累计净热量”改名“累计净入壁”，避免和外侧输入混淆。热量说明同时列出外侧输入、外侧辐射、内侧对流/辐射和材料净储热；内侧页单独编辑，不挤占三维画布。重新打开保存结果可恢复内侧条件。

v36 新增：多层壁面导热、界面接触热阻与厚度剖面

在“材料物性”页勾选“使用多层结构”，按外表面到内表面的顺序填写每层厚度、密度、常数比热、常数导热系数和温度节点数。Rc 列表示该层与下一层之间的面接触热阻 [m² K/W]；零表示完美接触，最内层这一列必须为 0。允许 1～10 层，每层至少 3 个节点，合计不超过 100 个温度节点。未提供真实材料推荐值，所有材料数据都需要用户给定。

每层可以独立启用 cp(T)/k(T) 温度表：通过编辑对象下拉框切换层，再勾选“当前材料使用温度相关 cp(T)、k(T)”。启用后，对应层的常数 cp/k 不参与求解。切换层、切换单层/多层模式不会丢失已编辑的温度表；重新打开已保存结果也能恢复分层材料。温度表须覆盖计算所需温度，不允许表外外推。发射率和辐射环境温度仍在“壁温响应”页填写。该模式下，壁温页的密度/cp/k 标量只读显示兼容接口的参考量，总厚度为各层厚度之和；求解、储热核对均不使用平均材料替代分层。Biot 输出为 NaN，GUI 明确说明多层不用单一 Biot 数分流。

MATLAB 接口：
material.layers 为由外到内的材料结构数组或元胞数组。每层包含 thickness [m]、density [kg/m³]、specificHeat [J/(kg K)]、thermalConductivity [W/(m K)]、可选 thermalNodes（默认 8），可选 propertyTable。使用温度表的层可只提供表内 cp/k，参考标量不是必要输入。material.contactResistance 是层数减一的非负向量，省略时为全零。material.emissivity 与 material.radiationTemperature 为外表面边界条件。多层与顶层 material.propertyTable 不能同时使用。

buildLayeredWallGrid.m 建立逐层节点控制体。完美接触的界面两侧共用一个温度节点，但两种材料的半控制体分别按各自密度和 cp(T) 储热；有限接触热阻保留同深度的两个温度节点，并用无热容热阻连接，允许界面温差。各层节点数和间距可以不同。物性表在完美接触的公共节点必须有共同适用温区。

solveLayeredWallConduction.m 使用逐层比热精确积分、层内 Kirchhoff 导热通量、接触热阻通量以及隐式 Euler/Newton 求解。layeredWallEnergyIncrement.m 与 layeredWallFlux.m 分别计算逐层储热和通量。接触热流按 (T外侧－T内侧)/Rc 定义向内为正；内部通量函数使用向外为正的符号，审计输出已转换。界面相邻连接通量在瞬态不必直接相等，因为界面半控制体也在储热；interfaceFinal 扣除/加上各侧半控制体储热后核对实际界面热流连续。

固定工况、飞行历程、沿程边界层壁温耦合、给定逐站 h/Taw 与驻点单点入口均接通逐层核。每一步接续完整厚度温度，不在外流改变时重置内层。累计热量使用实际接受的隐式时间站，并以每层自身储热核对守恒；不能对存在重复深度的接触节点使用全局 trapz，也不能用等效 cp 替代实际储热。

mesh.wallThermal.oneDimensional 保存 depth、finalDepthTemperature、backTemperature、materialGrid、interfaceFinal。矩阵行对应 find(mesh.wallThermal.oneDimensionalFace)，不一定覆盖全部面元。depth 在有限热阻处包含重复坐标；这一对节点的温差就是接触温差。interfaceFinal 只代表最后接受时间步，包含界面两侧温度、扣除半控制体储热后的两侧向内热流、接触热流及能量残差。零热阻处 contactHeatFlux 为 NaN（不用除以零），两侧审计热流仍有效；只有初始时间站时 available=false。

solveVariableMaterialConduction.m 的控制体储热为 rho*厚度权重*integral(cp(T),T_old,T_new)，不是当前 cp 乘温差。相邻节点导热通量为 integral(k(T),T_i,T_j)/dx，即 Kirchhoff 势差；同一界面通量在两个控制体中正负相消。使用隐式 Euler、精确三对角 Newton 雅可比及表内限幅/残差线搜索。外表面对流和辐射、背面绝热。温度表启用时，所有有效面元均使用完整厚度导热，不再由常物性 Biot 阈值分配集中热容模型。

v34 新增：变工况飞行历程的沿程壁温耦合

calcFlightStationState.m 统一建立一个飞行条件下的内置外流、轴向波系、三维准流线和初始壁温热流快照。calcFlightHeatingHistory.m 与新增 calcCoupledFlightWallHistory.m 共用此流程，避免固定/飞行历程的外流算法不同。history.couplingInput 保存生成历史时的气动热配置和精确网格顺序，壁温计算使用这份配置；修改模型参数后应重新生成飞行历程。若网格坐标或面元顺序改变，则拒绝使用旧历程。

默认 cfg.heating.wallCoupling='streamline'。calcWallThermalHistory.m 对完整内置历程进入沿程耦合：每个时刻按用户条件分段线性插值海拔、Mach、攻角和侧滑角，独立建立准定常外流快照；同一时刻迭代中固定外流/准流线，反复用当前非均匀壁温重积分 Thwaites/Head 和重判适用域，再解完整厚度导热与辐射。只缓存最近一种飞行条件，相同工况可复用外流，不能复用上一壁温的热流。自动二分子步在自己的时间建立外流，不沿用原区间终点的工况。材料厚度温度剖面连续传递，不在工况变化时重置初温。

solveCoupledWallConduction.m 支持 evaluate(Tw,time) 时间相关回调，保留原 evaluate(Tw) 固定工况接口。wallThermal.time 包含全部接受子步，热量按这些子步右端热流积分；wallThermal.flightHistory 保存对应实际飞行条件。coupling.boundaryMetadata 保存每时刻工况、外流方法、轴向波系状态、驻点边界和面积覆盖；coverageReasonCodeHistory 保存每站原因，faceMethodIDHistory/turbulentSourceIDHistory 保存当前面元的算法来源。自适应细分仅帮助非线性收敛，不是完整的时间截断误差控制；应继续通过减小最大计算间隔检查时间精度。

初始壁温基准历程中的覆盖率与真实热壁历程分别显示。冷壁有解不保证升温后有解；途中适用性失效的面元整条历程保守留空，不把未知温度作为冷壁继续向下游传递。GUI 飞行页显示基准各站覆盖率及实际热壁有解面积；壁温页的面元曲线标题显示当前时刻的热流算法和湍流来源，时间滑块对应实际接受站。右侧时长和时间点数只用于“计算固定工况壁温”，变工况时间由飞行历程表和最大计算间隔确定。

驻点单点与固定材料点有区别。攻角/侧滑变化使驻点移动时，不能将不同位置的驻点热流拼成同一材料点温度。新耦合历程会明确将这种单点温度标为不可用；鼻部各个固定面元仍按自己的热边界求温度。只有各站驻点均有效且位置保持不变时，才提供独立驻点材料热响应。该单点仍采用 Sutton-Graves/焓差反馈及材料模型，不冒充侧壁沿程积分。

给定 h/Taw 的旧接口或显式 wallCoupling='local' 保留原 Biot 分流与局部参考性质反馈，输出方法注明其范围。变工况链路不依赖外部 CFD，但仍是准定常工程近似，不解析完整三维非定常激波层、分离再附、横流边界层、解离/电离、烧蚀、温度相关材料和横向导热。完整气动热目标仍未完成。



v33 新增：固定工况壁温与沿程气动热的隐式耦合

有内置外流和准流线时，calcWallThermalResponse.m 默认使用 cfg.heating.wallCoupling='streamline'。新增 solveCoupledWallConduction.m 在每个隐式时间步反复调用非均匀壁温热边界接口，重算 Thwaites/Head 边界层、分离适用域和热流，再推进一维厚度导热及表面辐射。每次试探均从上一已接受时刻的完整厚度温度剖面出发，避免重复推进储热。所有有效面元均用一维导热；绝热背面，常物性均匀材料，不含面元间横向导热和烧蚀。外流快照及准流线路径保持固定，不是粘性-无粘耦合外流。

迭代必须同时满足壁温变化与能量/热流残差门槛；不收敛时自动二分时间步，失败试探的面元失效标记会回滚，不能以冻结旧热流冒充收敛。达到细分上限仍失败则明确报错。wallThermal.time 保存实际接受的时间站，驻点单点采用同一时间轴；热量积分使用全部已接受子步。初始无解或过程中失去适用性的面元保持 NaN；已接受步中失效面元的整条历程保守留空，其上游未知壁温可使下游继续失效。求解面积不是整箭体面积。

wallThermal.coupling 保存每步迭代次数、请求时间站、时间细分次数、最大热流残差、首次失效时间/原因以及逐面元逐时刻的热流算法编号和湍流来源编号。统一 GUI 壁温页显示方法、适用范围、失效数量和细分情况；点击三维面元查看时间曲线，滑块选取实际时间站。cfg.heating.wallCoupling='local' 可显式使用旧的局部参考性质反馈作对照。

湍流关联式域边连续处理：此前 LT 积分在 Re_theta=300 或 1e6 硬切换到平板状态，实际壁温迭代出现热流跳变。现在在关联式内侧 300~600、8e5~1e6 两个带内，以 smoothstep 权重连续衔接动量厚度 theta、形状因子 H 和 Cf；域外仍不外推 LT。段内范围只统计已接受 RK 阶段。GUI“湍流积分来源”增加编号 7“LT 域边与平板连续衔接”，结果保留 integralWeight 和 blendingReynoldsBands，纯积分与混合面元分别统计。带宽是工程数值选择，不是物理转捩规律，也没有实验校准；混合带中的状态不严格满足纯 Head 动量/卷吸积分方程。此修改会改变附近及下游的热流预测。

验证增加独立 ode45 半离散导热参考、时间步收敛、非局部非线性热边界、强制时间细分、能量守恒、失效面元和真实 STL 耦合测试；并检查 LT 两端及下游状态连续性。定工况已接通，变工况 calcWallThermalHistory.m 仍使用逐站外流加局部参考性质反馈，尚未在每步重积分非均匀壁温下的沿程边界层。下一步将把同一耦合机制接入飞行历程；完整气动热目标仍未完成。



v32 新增：非均匀壁温的沿程热边界重算接口

surfaceWallTemperature.m 统一读取面元壁温。cfg.flight.Twall 继续表示统一初始壁温和驻点单点壁温；可选 cfg.heating.wallTemperatureByFace 是当前面元壁温 [K]，按 mesh.F 的行顺序一一对应。行向量会显式转成列向量，尺寸错误、Inf、非正温度立即报错；NaN 明确表示壁温未知，不能以初始值补齐。

调用 updated=recomputeSurfaceHeatingAtWallTemperature(mesh,freestream,cfg,TwallByFace) 可在当前内置外流和准流线路径上重新评估非均匀壁温对应的热边界。calcBoundaryLayerState.m 和 calcSurfaceHeating.m 使用每个面元自己的 Eckert 参考温度、参考黏度和焓差，重新积分 Thwaites/Head 状态、重判分离适用域。上游壁温变化会通过积分状态传到下游，即使下游壁温自身未改变。外流快照、几何和准流线保持给定工况；不是粘性-无粘外流迭代。

v31 新增：可变形状因子的 Head 湍流积分与疑似分离筛选

默认 cfg.heating.turbulentModel='head'。calcTurbulentBoundaryLayerState.m 沿现有三维准流线推进准二维 Head 卷吸模型，marchHeadBoundaryLayerSegment.m 同时积分动量厚度 theta 与形状因子 H=delta*/theta，摩擦系数仍使用 Ludwieg–Tillmann。动量式为 dtheta/ds=Cf/2-(H+2)*theta/U*dU/ds，卷吸式为 d(U*theta*H1)/ds=U*E，E=0.0306/(H1-3)^0.6169。段内外缘速度和参考运动黏度线性插值，RK4 步长加倍控制误差。

Head 原两段 H1(H) 拟合在 H=1.6 相差约 0.02255。本实现小幅调整高 H 分支系数，使 H1 连续，避免跨分支时人为产生卷吸通量跳变；算法名称明确标为“H1 接缝连续化”。层流交接或缺少有效上游后的局部启动取 H=1.4，属于工程初值。Re_theta 仍限于 300~1e6，域外显式标记为局部平板回退。cfg.heating.turbulentModel='fixedShape' 可切回 v30 的固定 H 对照实现 calcFixedShapeTurbulentBoundaryLayerState.m。

H>=2.4 只表示疑似准二维湍流分离，不是精确三维分离线。该起点和全部前驱树下游保持热流 NaN，即使中间热物性无解或下游重新加速，也不假定自动再附；不能用平板回退或鼻端延拓补齐。数值/形状域失败使用独立标记，不等同物理分离。“未计算原因”增加 11=疑似湍流分离及下游、12=Head 积分失败及下游，原代码含义不变。飞行历程自动随原因表扩展。

画布布局额外固定内部坐标轴位置，并关闭面板对子对象的二次缩放，避免异步页面切换时偶发缩图。形状因子标题统计 H 自身有效值，分离筛选灰色只表示未触发，不暗示热流已有解。

GUI 同一气动热页面新增“湍流形状因子 H”和“疑似湍流分离及下游”，保留大三维画布；点击准流线会显示所选面元 H、Cf 和来源。算法说明列出分离/数值失效起点及下游数量。“湍流假设 q”图明确区分：已转捩区使用实际湍流模型，未转捩侧壁只给局部平板湍流假设对照。无三维流线时仍使用原平板模型。

验证涵盖零压梯度与不利压力梯度的动量/卷吸积分平衡、跨 H=1.6 连续性、步长细分、疑似分离位置收敛、输出空白和分支隔离，以及实际箭体上人工强减速后再加速时热流仍留空的端到端回归。人工减速外缘仅是测试夹具，不代表真实箭体外流。真实默认零攻角与 10° 工况均未触发新的湍流分离，10° 热流有解面积仍约 80.24%；数值有所变化不等于已经过实验精度验证。

适用范围：这是用 Eckert 参考黏度修正的准二维工程闭合，并非密度加权的完整可压缩边界层，也未求解横流、分离区、再附或激波干扰。壁温反馈仍采用局部 1/2（层流）、1/5（湍流）黏度指数和焓差更新，不随壁温重积分 Head 状态或重判分离；固定工况、飞行历程和 GUI 的方法范围均明确说明。因此“完整气动热”总体目标仍在推进。

v30 修复：热流空白后的转捩状态连续性

calcSurfaceHeating.m 原先先在有效外流路径上判转捩，再用热流可用面元掩码重新判一次。第二次判定会把热物性暂时无解的面元当成路径断点；若下游局部 Reynolds 数低于固定阈值，可能错误地恢复层流。现在 calcTransition.m 使用独立的流动状态掩码和可选热流输出掩码：前者决定路径上能否传递已发生的转捩，后者只决定哪些面元输出结果。热流空白处仍保持 NaN；外流、连续介质或路径真正失效时仍不能跨越传播。

mesh.heating.transition 保存 stateTurbulentFace、stateOnsetFace、turbulentCarrierFace、inheritedThroughUnavailableFace，以及热流域外首次转捩和下游继承数量。GUI 的“展开算法说明”与 main 摘要显示转捩状态连续性及来源。这里只传递经验层/湍流标签，不填补缺失热物性或动量厚度；下游没有有效边界层交接值时仍明确标为局部湍流启动或平板回退。转捩判据依旧是固定 Reynolds 阈值，本修复不表示已求出真实再层流化、分离或再附。

testTransition 检查被热流掩码隐藏的转捩起点、空白后继承以及真实路径中断；testSurfaceHeating 在实际箭体网格上构造受控热物性空白与低 Reynolds 数下游，核对热流仍选湍流分支、空白仍为 NaN，并确认旧调用会触发错误复位。

v29 新增：气动热三维云图空间与色标优化

v28 新增：沿准流线的附着湍流边界层积分

calcTurbulentBoundaryLayerState.m 从层流转捩点的动量厚度接续，使用固定形状因子 H=1.4 的 von Karman 动量积分式沿三维离散准流线逐段推进，并以 Ludwieg–Tillmann 关联式由局部 Re_theta 求摩擦系数。calcSurfaceHeating.m 将所得 Cf 经 Reynolds 比拟转换为已转捩侧壁的换热系数；Eckert 参考温度、干空气焓恢复、连续介质和分离路径筛选仍沿用现有模块。没有有效上游解时，以局部湍流平板动量厚度启动；关联式限定 300<=Re_theta<=1e6，超域时使用旧局部平板 Cf 作为明确标记的低阶回退。没有三维准流线路径时，仍使用原局部平板热流估算。

结果 mesh.heating.turbulentBoundaryLayer 保存动量厚度、Re_theta、Cf、外缘速度梯度、压力梯度参数以及每个面元的算法来源编号和数量汇总。GUI 可用云图查看这些量，并在方法说明中显示各来源面元数。该模型只适用于附着湍流的准二维工程估算；固定 H 和摩擦关联式不能预测三维横流、湍流分离、再附或激波干扰，局部平板回退也不能消除相关式超域的不确定性。

v27 新增：飞行历程内部时间站加密

这减少了长间隔隐式壁温积分的时间离散误差；解析恒定换热测试确认缩小步长会降低误差。它不能保证捕捉未知的站间峰值：输入飞行轨迹是线性假设，激波与热流在每个计算站仍按定常工程模型计算，壁温在相邻计算站间使用右端热边界。需要更细时间精度时可减小最大间隔，但面元数乘计算站数目前须不超过 1e6。

v26 新增：连续介质适用域与高空热流留空

airMeanFreePath.m 用 lambda=(mu/p)*sqrt(pi*R*T/2) 估算固定干空气平均自由程。assessContinuumRegime.m 以物理鼻端半径（可由 cfg.heating.continuumLength [m] 明确覆盖；无半径时以最大横向半径作替代尺度）计算自由来流和外缘 Kn，取较大值逐面元筛选；默认 cfg.heating.maxContinuumKnudsen=0.01，用户只能设更严格的阈值。超阈值面元及同一准流线下游不再套用无滑移边界层热流公式，Sutton-Graves 驻点也用 Kn_{∞,Rn} 检查。多站飞行历程保存逐站 Kn 和空白原因；GUI 显示 log10(Kn)、连续/滑移/过渡/自由分子区以及蓝色的“上游稀薄流影响”面元。平均自由程/鼻端尺度只是工程适用性筛选，不是局部梯度 Kn、滑移边界条件、过渡流或 DSMC 解。

默认 Mach 5、30 km、零攻角热流保持原结果。10° 攻角、30 km 的局部膨胀外缘压力很低；加入 Kn 筛选后，有解面积由旧版约 94.7% 降到约 80.2%，约 15.1% 的总表面积因稀薄流适用性首要原因留空。这说明旧版的部分背风热流依赖超出连续介质适用域的外缘近似，不代表已求出该区域真实热流。80 km 默认箭体已超过 Kn 阈值，现有连续介质驻点及侧壁热流保持未计算；需要另建稀薄流模型或更高保真度数据才能补齐。

v25 新增：三维云图径向显示倍率

v24 新增：边界层与热流使用一致的恢复温度
calcBoundaryLayerState.m 的 Eckert 参考温度此前仍由定比热温差公式给出，而 calcSurfaceHeating.m 已用固定组分干空气焓求恢复温度。现在默认模式下，Thwaites 型层流积分也用 h(Taw)=h(Te)+sqrt(Pr)Ue²/2 反解恢复温度；80~150 K 接 v23 的振动冻结低温模型。参考温度、参考黏度、动量厚度、局部压力梯度参数及层流摩擦系数因此来自与热流相同的热物性。显式选择 caloricallyPerfect 时保留旧定比热公式。结果结构体保存 recoveryTemperature、recoveryTemperatureMethod、thermalPropertyMode 和物性域外面元；GUI 的边界层方法说明会显示实际模型。默认算例有效层流面元的参考温度相对旧公式中位数约低 14 K。此更新改善热物性一致性，Thwaites/经验转捩仍不能替代三维可压缩边界层稳定性求解。

v23 新增：低温稀薄干空气焓/熵连续衔接
默认箭体 Mach 5、30 km 的肩部二维工程膨胀在约 4.2% 表面积上给出低于 150 K 的静温，定比热估算最低约 91 K、局部压力约 13 Pa。airThermalProperties.m 现于 80~150 K 使用在 150 K 与 NASA7 焓、熵连续的振动冻结定比热近似：cp=cp(150 K)，h=h150+cp(T−150)，s=s150+cp ln(T/150)。此区间的 N2/O2 转动自由度仍充分激发、振动自由度基本冻结；该模型只适用于稀薄且保持气相的固定组分干空气，不包含凝结、非平衡内能、稀薄流修正或三维激波层。该低温段的 Sutherland 黏度也属于工程外推，故热流精度仍待实验或更高保真度模型校核。150~2500 K 保持原 NASA7 模型，其中 150~200 K 仍为多项式少量外推；低于 80 K 不外推。
零攻角切锥、轴向膨胀/压缩、非零攻角局部膨胀以及恢复温度和热流现沿用同一焓/熵衔接。逐面元外流热物性编号为 0=无解、1=全局定比热工程解、2=NASA7、3=80~150 K 振动冻结近似；GUI 用独立颜色显示低温面元。默认箭体现在可完成整条变比热轴向推进，最低静温约 91.6 K；初步热流有解面积约 97.9%，10° 攻角约 94.7%。这些是工程模型的适用域内结果，不代表肩部真实波系、转捩、分离或稀薄流已得到验证。若轴向状态低于 80 K，仍将整条侧壁流管退回定比热并明确标记；低于 80 K 的非零攻角局部面元只保留流向占位，热流留空。

v22 新增：变比热切锥与零攻角轴向波系
solveThermallyPerfectConicalShock.m 以固定组分干空气 NASA7 焓/熵，在锥形激波处满足质量、法向动量和总焓守恒；波后用局部变比热声速积分轴对称 Taylor–Maccoll 锥流方程，反求锥面无穿透的附体弱支。局部切锥面元按静压和总压连续插值，再由同一 NASA7 熵/焓关系恢复外缘温度、速度和 Mach。零攻角近轴对称直鼻锥的轴向推进以这个切锥解为锚点，后续凸转角使用 NASA7 二维 Prandtl–Meyer 膨胀、压缩转角使用 NASA7 二维附体弱斜激波；膨胀段严格携带总压，压缩段总压下降。每个面元和轴向波段均保存算法及热物性来源，统一 GUI 可查看。
在 v22 中，默认 Mach 5、30 km 箭体肩部膨胀低于当时的 150 K 下限，因此侧壁轴向流管整条退回定比热。v23 增加 80~150 K 的明确低温模型后，默认算例不再触发此回退；低于 80 K 时仍整条回退。两种轴向链路都只是代表流管工程估算，并非轴对称 Euler 全场或三维激波层。

v21 新增：非零攻角背风侧温度相关二维膨胀
solveThermallyPerfectPrandtlMeyerExpansion.m 对固定组分干空气的局部二维超声速简单波积分 dθ=sqrt(M²-1)dU/U，以 NASA7 焓差恢复速度、局部比热确定音速，并以标准熵差恢复静压。它按指定凸转角给出静温、压力、密度、速度和 Mach，同时检验等熵及总焓守恒。Mach 5、30 km、10° 理想二维膨胀示例给出 T2 约 152.08 K、p2/p1 约 0.24835、M2 约 6.29987；独立自适应积分复核转角。
非零攻角的逐面元背风膨胀在 150~2500 K 内使用该模型；近切向自由流也采用相同 NASA7 总压和总温，使其与邻近切楔/膨胀面元连续。若指定转角需要低于 150 K 的静温，程序把这些面元明确标为热物性越界：定比热外缘状态只作为离散流向占位，以免少量低温面元切断下游整条准流线；越界面元本身的热流仍保持空白，不把占位值当作有效 NASA7 热力解。GUI“外流热物性模型”按面元区分 NASA7 与定比热占位，并在方法说明中显示数量。零攻角仍以定比热切锥为轴向推进锚点，轴向膨胀与压缩继续使用定 gamma；没有将不同热力模型混成一个未经验证的轴向流管解。

v20 新增：温度相关干空气二维切楔激波
solveThermallyPerfectObliqueShock.m 将入射速度分成激波法向和切向，沿法向用 NASA7 焓/熵及质量、动量、总焓守恒求跃迁，切向速度保持连续；由激波极线反求附体弱支角度和最大附体转角。recoverThermallyPerfectEdgeState.m 再从同一模型的静压、总压和总温以熵差/焓差恢复逐面元静温、速度、音速与 Mach。超过附体极限仍按原受限前体闭合处理，但闭合两端现在是温度相关切楔极限与法向激波滞止状态；这个闭合仍不是脱体激波层解。默认 Mach 5、30 km、10° 二维楔例的激波角约 19.379°、p2/p1 约 3.044，后温约 323.8 K。与定比热结果的差异随温度和转角变化。
原鼻端温度相关法向激波改用密度比求非平凡压缩根，修复法向 Mach 数接近 1 时弱激波被误判无解的问题。逐面元结果 thermalPropertyModeByFace 标记 0=无解、1=定比热、2=NASA7；GUI 同步显示。cfg.heating.airThermalModel='caloricallyPerfect' 可恢复旧版切楔及鼻端计算；若静温或总温超过 150~2500 K，切楔整组明确退回定比热工程模型并在状态中说明。v20 时零攻角切锥 Taylor-Maccoll、Prandtl-Meyer 膨胀、轴向波系推进仍为定 gamma；v21 已更新非零攻角的局部二维背风膨胀，切锥和轴向推进仍保持定 gamma。

v19 新增：温度相关干空气鼻端正激波
solveThermallyPerfectNormalShock.m 在已验证球形钝鼻的驻点中心线，使用固定组分 N2/O2/Ar 的 NASA7 焓与标准熵、质量/动量/总焓守恒和理想气体状态方程，反解法向激波后 p、T、rho、速度、Mach 及等熵减速总压。质量、动量、总焓残差和熵增随结果保存；超过 150~2500 K 时报告无解，不将高温解离气体伪装成固定组分空气。默认 Mach 5、30 km 案例的激波后温度约 1240.5 K、总压比约 0.0562；旧版定比热分别约 1313.8 K 和 0.0617。该差异只涉及鼻端单点法向跃迁，不是完整激波面或三维激波层。驻点热流用同一干空气总焓反解总温，并核对激波状态；cfg.heating.airThermalModel='caloricallyPerfect' 可同时恢复旧版鼻端法向激波与定比热换热。v19 时侧壁切锥/切楔、轴向波系推进和脱体闭合仍采用定 gamma；v20 已更新局部二维切楔与其受限前体闭合。

v18：温度相关干空气焓与高温适用域
airThermalProperties.m 使用 N2/O2 的 NASA 七系数多项式及 Ar 单原子气体近似，按固定干空气质量分数计算 cp(T) 和焓；airRecoveryTemperature.m 以 h(Taw)=h(Te)+rU²/2 求层流/湍流恢复温度，airEnthalpySecantCp.m 把焓差转换为现有壁温求解器使用的等效比热。Sutton–Graves 驻点冷壁参考值也改按空气焓差修正；壁温升高时，换热系数同时反馈 Eckert 参考黏度和焓差等效比热。GUI 与结果字段 thermalPropertyMethod/Scope 说明实际算法。cfg.heating.airThermalModel='caloricallyPerfect' 可明确恢复旧版定比热换热计算。
热物性模型限定 150~2500 K；150~200 K 是低温多项式少量外推。超过范围的面元不外推热流，云图首要原因标为“热物性”，flags.thermalProperty 保留逐面元标志。默认 Mach 5、30 km、零攻角案例的轴向推进在尾部一段给出低于 150 K 的外缘温度；新模型据此留空约 4.2% 的表面积，气动热有解面积约 93.67%（18,924 / 19,752 面元）。10° 攻角的逐面元膨胀模型在部分背风面也给出过低温度：30 km 工况有解面积约 93.75%，三站示例中 20 km 的 10° 站约 84.28%。这暴露了外流工程模型的适用性问题，不是材料热响应求解失败。热物性空白不会重置沿准流线已转捩状态，也不会误标成大片层流分离。
v18 只改进了热流和驻点焓差；v19 增加鼻端单点法向激波；v20 更新局部二维切楔；v21 更新非零攻角局部膨胀。切锥与零攻角轴向推进外流仍用定 gamma，Thwaites 参考温度仍按定比热恢复温度估算。2500 K 以上的解离、电离、高温化学、激波层辐射和真实气体效应未求解，因此不能把 NASA7 比热理解为完整真实气体气动热。

v17：零攻角轴向激波—膨胀推进
原逐面元外流从自由来流分别求每个截面：默认箭体直鼻锥附近的总压约为自由来流的 26%，到大柱段却恢复为 100%。沿同一代表流管，这种无外加能量的总压回升不合理。marchAxisymmetricShockExpansion.m 在零攻角、近圆截面、直中心线、能自动识别一段附体直鼻锥时，以该切锥状态为锚点，沿 STL 轴向截面从鼻向尾逐段推进。直段携带上游状态；壁面凸转角用 Prandtl–Meyer 等熵膨胀，保持总压；压缩转角用二维 theta-beta-M 附体弱激波，计算总压损失。遇到没有附体或等熵解的转角时，下游保持无解，不恢复自由来流。新增外流算法编号 6，并保存每段波型、压力、总压、Mach 和局部附体压缩波角。
默认箭体 Mach 5、零攻角的此低阶模型自动识别约 34.5° 的直鼻锥；大柱段总压约为自由来流的 0.262，后方小柱段约为 0.013。后一个数值包含强膨胀及后续附体压缩波，是模型输出而非实验或 CFD 验证。此法把锥面末端状态视为单条代表流管的上游条件，不解析真实轴对称激波层、曲面波相互作用、三维流线横向迁移、分离或再附。非零攻角、非轴对称截面或没有可识别直鼻锥时，保留原逐面元外流并在状态中说明原因。cfg.externalFlow.axisymmetricMarchEnabled=false 可关闭推进作对照。
统一 GUI 中“内置外流压力”显示推进后的外缘压力；可选“柱段专用色标”观察柱段压力。右侧气动力和力矩仍由独立的修正牛顿面压积分，与外流云图切换无关，不能把两者视为同一压力模型。

累计热量模块
calcAerothermalExposure.m 将壁温求解中每个时间段右端站点的对流热流和辐射热流积分，生成面元累计对流、辐射、净热量，以及离散时间点的峰值对流热流和峰值壁温。用真实面元面积汇总已求解区域的对流输入、辐射散出及净能量，并用材料最终储热核对隐式时间步的能量守恒。薄壁按面热容计算储热；厚壁按一维最终温度剖面积分。

非零攻角球鼻热流
当 STL 鼻端通过多尺度球形拟合、驻点候选只有一个且法向与来流对齐时，程序可把 Sutton–Graves 驻点单点估算沿逆来流方向移到球面，合成攻角/侧滑角不超过 30°，且偏移深度必须落在已验证的球面拟合范围内。球鼻面元使用相对偏置驻点的迎流极角作余弦低阶延拓，仍逐面元检查球面位置、法向和几何前半球范围。正攻角的热点移到 -Z 侧，负攻角移到 +Z 侧。超过 30°、几何未验证、存在多个驻点候选或半径不一致时不输出该模型结果。已验证球鼻的偏置驻点同时给出局部法向激波单点热力状态；Billig 轴对称激波曲面预览仍只在零攻角显示。

热流覆盖与空白原因
analyzeHeatingCoverage.m 汇总每类已解/未解面元数量及真实面积，并为未解面元分配一个用于显示的首要原因。其他同时存在的限制仍保存在 flags 中。该诊断不填补热流或改变求解；空白原因采用明确优先级，因此不能把一个标签解释成唯一物理成因。GUI 显示已解面积比例和最大的空白原因。默认箭体 10°、30 km 工况开启前体闭合及四步梯度时，旧版定比热模式有解面积约 98.00%；v18 变比热模式把低于热物性下限的背风面留空，有解面积约 93.75%。关闭前体闭合后有解面积还会降低。

多站飞行历程还会保存每站的原因代码、各类空白面积和有解面积比例，并报告全历程每一站都有解的面积比例。壁温和累计热量只覆盖这部分面元；任何时间站无解的面元保持 NaN。

v16：受限前体脱体外流闭合
非零攻角时，局部切楔转角若超过附体激波极限，二维斜激波方程没有附体弱解。solveExternalFlow.m 现在仅对光滑前体轴向前 10% 内、局部转角不超过 60°、且具备当前工况修正牛顿壁压的面元使用低阶闭合。它在附体极限处取切楔弱解的静压和总压，采用归一化的修正牛顿壁压角度趋势，向法向激波后的滞止状态过渡；然后用定比热等熵关系恢复局部温度、密度、速度和 Mach。静压与总压用同一权重插值，以保持附体极限附近连续及静压低于总压。超出条件的面元仍为无解，不会补成自由来流。
附体切锥/切楔和膨胀状态也改为只在角度节点求解析解，再按局部真实角度连续插值静压、总压和局部激波角；温度、密度、Mach 与速度由完全气体关系恢复。这样保留按角度缓存的计算速度，同时避免最近邻分箱制造阶梯外流状态。cfg.externalFlow.angleStepDeg 控制解析节点间距；默认 0.5°。此插值仍是面元独立的工程近似，不会解析波系相互作用。
外流算法编号 5 为此前体闭合，局部激波角为 NaN，因为该方法不求脱体激波角、激波面位置或波层内三维流动。由它驱动的热流算法编号 4/5 分别为层流/湍流。GUI 的“气动热工程估算”页可查看算法编号、闭合面元数量及热流面积覆盖。cfg.externalFlow.detachedClosureEnabled=false 可关闭此方法并对照有解范围。该闭合是工程估算，不能把新增有解区域当成已经完成三维脱体外流验证；强波系相互作用、分离和高温真实气体效应仍未解析。

v16：沿准流线的层流分离适用性筛选
calcBoundaryLayerState.m 用 Thwaites 型积分中的 lambda 判断疑似层流分离。离散面元和外流角度节点仍可能带来局部数值跳变；直接用相邻面元差分会放大梯度。本版默认沿上游四个准流线步长求割线，cfg.heating.gradientPathSteps 可设为 1~20。该值是数值梯度尺度，不是物理分离长度；改变它可能改变分离判断，不能把单一设置当作实验验证。
propagateSurfaceSeparation.m 只对尚未转捩的疑似层流分离起点，沿前驱路径标记下游无解。没有再附模型时，不能在下一面元因局部速度恢复或达到 Reynolds 阈值就自动恢复附着热流；球鼻余弦公式也不会填补这些路径。heating.separationTrace、heating.separationUnresolvedFace 和 heatingCoverage.flags.laminarSeparation 保存起点、下游与空白原因；统一 GUI 显示方法和面元数。默认 10° 案例用四步梯度没有触发层流分离起点；切回单步会产生疑似起点并降低热流覆盖。在 0.5°、0.25°、0.1°、0.05° 四种角度节点间距下，旧版定比热模式的有解面积均约 98.00%。这只是数值步长检查，真实分离/转捩仍需更高保真度模型或试验校核。

输出位置
运行 GUI 后，MATLAB 工作区中的 mesh.wallThermal 保存壁温、对流/辐射/净热流和材料信息；mesh.aerothermalExposure 保存累计热量、峰值、功率和能量守恒统计。mesh.aerothermalExposure.summary.resolvedAreaFraction 为已求解面积占比。未求解面元为 NaN，总能量只针对已求解表面，不能当作整箭体总量。

算法和适用范围
内置链路包括：局部切锥/切楔激波、零攻角近轴对称直鼻锥后的逐段激波—膨胀推进、受限前体脱体闭合及局部 Prandtl–Meyer 膨胀工程外流；Billig 球鼻激波预览；三维有向图离散准流线；Thwaites 型层流积分、上游多步速度梯度、疑似分离下游适用性筛选、Reynolds 经验转捩；可变 H 的 Head 湍流动量/卷吸积分与 Ludwieg–Tillmann 摩擦关联式及显式域边混合（可选旧固定 H 对照）；Sutton–Graves 驻点热流及球鼻低阶余弦延拓；Eckert 参考温度与局部摩擦系数侧壁换热；固定/变工况的沿程热边界—一维厚度导热耦合；给定边界/局部对照的 Biot 数分流；隐式 Euler 壁温与辐射平衡。各模块的 method/scope 字段与 GUI 文本给出算法来源及适用范围。

当前气动热链路仍是工程近似；新增独立 Euler PDE 验证页尚不驱动热流。偏置球鼻余弦热流并非三维激波层/边界层解，局部激波单点状态也不等于完整激波面。当前不解析复杂激波相互作用、分离再附、真实气体、高温化学反应、烧蚀和横向导热。多层材料已支持逐层 cp(T)/k(T) 和界面接触热阻，尚不含相变。材料参数不能由 STL 推断，必须由用户提供。峰值为输入时间采样点的最大值，可能漏掉采样点之间的短时峰值。

验证
