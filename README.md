# RocketAeroHeat

MATLAB 气动热工程计算后端与自定义 WebGL 三维科研工作台。

## 当前开发目标

优先完成某一给定飞行时刻/工况下全面积的三维气动热计算，并同步完善统一科研 UI。累计热量、长时程热历史及轨迹耦合安排在后续。完整目标、验收要求和最新执行记录见 [项目目标](docs/PROJECT_GOALS.md)，开发约定见 [AGENTS.md](AGENTS.md)。

最终覆盖连续流、过渡流和稀薄流。当前先推进连续流工程方法，外流由程序内部计算。全区域求解尚未完成；未解区域保持明确标识，各场量区分求解结果与给定边界条件。

## 运行

1. 将仓库下载或克隆到本地可写目录。
2. 在 MATLAB 中进入项目根目录，运行 `main.m`。
3. 按统一界面确认模型朝向、生成网格、设置飞行工况并计算。

详细功能、使用步骤和已知限制见 [使用说明](README_使用说明.txt)。当前源码含已测试的 v50 工作台功能；已交付工程包记录截至 v49，具体测试与交付状态以项目目标中的执行记录为准。

## 目录

- 根目录 `.m` 文件：计算模块与统一 GUI。
- `web/`：离线三维结果工作台。
- `cases/`：示例几何。
- `tests/`：测试与独立校核程序。
- `docs/`：算法、验证资料和项目目标。
- `outputs/`：本地生成结果，不纳入 Git。

坐标约定：主轴 X，鼻尖 +X，零攻角来流速度 −X，内部使用 SI 单位。
